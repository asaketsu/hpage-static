残差流中单一线性方向即可旋钮式调控 Agent 工具调用频率

Tunable Tool-Call Rates in LLM Agents via Representation Steering
👥 Yuqi Chen, Vincent Siu, Yang Liu, Dawn Song, Chenguang Wang   2608.25198

📋 摘要

核心内容：决定是否调用工具是 LLM Agent 的核心能力，但现有模型在过度调用（增加延迟、成本、不可逆副作用）与漏调用（自信地答错）之间平衡得很差，而后训练和提示工程成本高且难以在推理时调整。作者发现：无需任何训练，仅从模型自身的工具使用偏好信号中提取残差流里的一个线性方向，即可作为推理时干预手段。以强度 α 沿该方向调节，调用率可单调地从近 0% 拉到 90% 以上，且调用格式保持规范；调低可抑制调用，调高则精准诱发出模型自身知识无法回答的问题上的新调用。该方向可泛化到未见过的工具，不偏向特定工具。接入真实工具执行后，单次扫参即可描出成本/精度 Pareto 前沿，将开放域问答准确率从 0.29 提升至 0.56（近翻倍）；同一方法可迁移到 dense、MoE、多模态等多种架构，全程零训练。代码已开源。
💡 把「工具调用决策」变成可解释、可实时调节的旋钮，零训练成本跨架构通用，对 Agent 成本控制与可靠性都有直接工程价值。
