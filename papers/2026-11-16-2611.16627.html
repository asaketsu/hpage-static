三层可恢复折叠管理上下文，LOCA-bench 66/75 胜 Claude Code

Folio: Recoverable Multi-Resolution Context Folding for Long-Horizon Language Agents
👥 Yubo Ruan, Tao Peng, Jiao Zhang, et al.   2611.16627

📋 摘要

摘要全文：长时程语言代理不断累积工具结果与回复直至撑爆上下文窗口；现有代理靠模型摘要压缩，每次压缩都重读重写被替换内容。Folio 是一个通过同一组句柄记录、折叠、恢复历史的上下文管理器：运行时记录三个互链层级——模型回复中顺手写下的回合笔记（L1）、运行时自动生成的事件清单（L2）、捕获的原始记录（L3）。因视图本已存在，运行时以程序化方式折叠，为老回合选取更粗视图；折叠输出打印指向 L2/L3 的句柄，恢复工具可读有限页、在文件上对全文计算、把发现存入持久档案，以极少额外输入取回所需证据。折叠触发器为含保留预算的显式落点定价。75 个 LOCA-bench 任务上（后端同为 DeepSeek-V4-Pro），Folio 解出 66 题，同运行时配模型摘要压缩为 54 题，Claude Code/Codex/SoL-Pi 为 49-59 题；用时约其一半、成本低 2.4 倍，单次折叠中位 0.6 秒。
💡 上下文管理从“让模型写摘要”转向“运行时结构化折叠+句柄恢复”，成本 2.4× 降、性能反超一线 agent 产品，属 agent 基建级范式工作。
