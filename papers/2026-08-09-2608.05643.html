Answer First, Reason Later: Commitment Order in Diffusion LLMs 🔗 arxiv.org/abs/2608.05687 👥 Jewon Yeom, Jaewon Sok, Seonghyeon Park, et al. 📅 2026-08-06 | cs.CL 一句话总结：揭开 Diffusion LLM 推理失败的根因——生成顺序混乱导致"先出答案再补推理"。 核心摘要： Masked diffusion LLM（dLLM）以"任意顺序 commit token"为卖点，但本文发现这一自由度恰是推理任务的失败根源。对 LLaDA-8B 在 GSM8K 上的解码日志分析显示：无约束解码在轨迹 15-24% 位置就提交最终答案，而推理区还有一半被 mask；随画布增长，高达 90% 的问题退化为"只有答案"的输出。根因不是 EOS 压力，而是 sampler 能否在远距离位置执行终止信念。2x2 实验表明 CoT 仅在有序提交下有效（交互效应 +34.8 个百分点）。作者提出 frontier-gated commitment 单旋钮干预，因果性地恢复全部 gap（0.528→0.852），同时保留 4 倍并行解码。 💡 亮点：首次精确定位 dLLM 推理崩溃机制（commit order reachability），并揭示现有 window 采样器其实无意中"误打误撞"修好了这个病——深刻且实用。 ═══════════════════ 📄 3. LC-GRPO: Bridging Train-Inference Gap for Flow-Based GRPO with Langevin Correction 🔗 arxiv.org/abs/2608.05600 👥 Yingqing Guo, Hui Yuan, Zijian He, Mengdi Wang, Zheng Ding 📅 2026-08-06 | cs.LG 一句话总结：用 Langevin 校正弥合 Flow 模型 GRPO 训练（SDE）与推理（ODE）之间的分布鸿沟。 核心摘要： Flow 生成模型推理时解确定性 ODE，但在线强化学习需要随机 rollout 做探索，因此现有 flow-GRPO 方法用 SDE 替代训练期 ODE。问题在于：有限步离散下 ODE 与 SDE 的样本差异显著，SDE rollout 随探索噪声增大变得模糊，导致训练样本与测试 ODE 样本错配。本文提出 LC-GRPO：每个 rollout 过渡先做 ODE Euler 步（对齐推理），再加一个针对边际分布的 Langevin 随机校正。所需 score 直接从 flow velocity 恢复，无需额外 score 模型，且过渡保持各向同性高斯、似然可算。理论上证明单步 Langevin 校正可降低 Wasserstein 误差。在 SD3.5-Medium、FLUX.1-Dev、HunyuanVideo 上，LC-GRPO 稳定提升文生图/文生视频的奖励优化并保持质量。 💡 亮点：直击 flow-based RL 中被忽视的"训练用 SDE、推理用 ODE"的 train-inference gap，方案优雅（零额外模型），对多模态生成 RLHF 有直接迁移价值。 ═══════════════════ 📁 数据源：arXiv cs.AI/CL/LG new listings（curl 降级方案，web_search 辅助） 🔧 说明：今日 arXiv API 返回 429 限流，全程使用 curl + HTML 解析降级链完成，无数据缺失。
