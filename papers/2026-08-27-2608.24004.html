面向 LLM Agent 的结构感知投机解码，破解大 batch 加速退化

AgentSpec: Speculative Decoding for Batch Inference of LLM Agents
👥 Xin Wang, Ziming Miao, Yi Zhu, et al.   2608.24004

📋 摘要

投机解码能在不损失生成质量的前提下加速 LLM agent 推理，但现有方法在大 batch 规模下加速比急剧退化。论文系统分析出两大退化主因：投机 token 拒签率过高、动态 token 预算利用不足。AgentSpec 引入结构隔离起草（structure-isolated drafting），将投机限制在 agent 工作流中语义连贯的片段内，避免起草无关语义路径，实现极低拒签率；同时采用冗余感知的预算分配，利用 agent 级信息更充分地吃掉推理过程中的动态空闲 token 预算。该方法在 vLLM 中实现，跨 5 种工作负载、4 个 LLM 家族验证，全面超越现有 SOTA，已被 EMNLP 2026 接收。
💡 首个系统剖析 agent 场景批量投机解码退化的工作，且落在 vLLM 实测而非纸面加速，对 agent 推理服务降本增效有直接工程价值。
