免训练激活稀疏新方法，按 token 自适应稀疏度、按 block 敏感度分配预算

TopK-Guided: Adaptive, Budget-Aware Activation Sparsity for Efficient LLM Inference
👥 Mukund Agarwalla, Chih-Jen Lin   2610.01763

📋 摘要

激活稀疏通过将不重要的激活置零来跳过对应计算，从而加速 LLM 推理。现有免训练方法各有取舍：TEAL 等阈值方法可按 token 自适应稀疏度但无法严格控制实际稀疏水平，WINA 等 TopK 方法强制固定稀疏度却对所有 token 使用同一预算；两者还对所有 transformer block 施加相同预算，尽管各 block 的敏感度差异很大。TopK-Guided 同时解决这两个限制：将有界的 token 级稀疏自适应与敏感度感知的 block 级预算分配相结合。在 Llama-2 和 Llama-3 模型上，TopK-Guided 在保持与 WINA 基本相同的稀疏相关投影计算量的同时，困惑度与下游准确率均一致优于 TEAL 和 WINA，且高稀疏度下增益最大。消融实验表明两个组件带来互补的改进。
💡 融合 TEAL（自适应）与 WINA（严格预算）两家之长，免训练即插即用，对成本敏感的在线推理和边缘部署场景可直接参考。
