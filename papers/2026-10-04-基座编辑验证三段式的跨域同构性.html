摘要

软件智能体（Agent）与物理智能体（机器人）的策略改进长期被视为两个独立问题域，分属"LLM 编排"与"强化学习控制"两套话语体系。本文基于 2026 年 9 月最后一周（09-28 至 10-04）密集出现的两个独立社区工作——Stanford 的 EXPO-FT 机器人后训练框架与 TypeSafe 的 Jev 软件Agent决策层架构——提出并验证一个跨域同构命题：两个域的策略改进正在独立收敛到同一种"基座-编辑-验证"三段式架构。该架构的特征为：（1）一个大规模预训练基座提供行为先验；（2）一个轻量编辑/决策组件对基座输出做有界修正；（3）一个验证器在执行时刻从候选中择优或裁决放行。通过对本周 31 篇笔记的跨域交叉验证，本文给出该架构在两个域中五个维度的结构对照表，并指出验证器接口是两个域共同的薄弱环节。进一步，利用 DX Research Group 六个月 35 万回合的 LLM 交易 Agent 生产数据（arXiv:2609.05663），本文实证了"基座-编辑-验证"三段式在软件 Agent 域的有效边界：当验证器缺失（退出决策交给 LLM 自主判断），浮盈捕获率中位数仅 2.0%；当验证器机械化（固定止盈止损括号），每仓位回收 +39.0bps。据此提出三段式完整性定理：三段中任何一段缺失，策略改进退化为基座单段行为——在机器人域表现为动作饱和假通过，在软件Agent域表现为浮盈系统性归还。

关键词：策略改进；跨域同构；基座-编辑-验证三段式；EXPO-FT；Jev；验证器；Agent架构

1 引言

1.1 问题背景

强化学习（RL）领域长期以来用"策略 π(a|s)"这一形式化语言描述智能体行为，而大语言模型（LLM）Agent 社区则使用"prompt-工具-循环"的编排语言。两套词汇描述同一件事——"智能体如何根据状态选择动作"——但长期互不相认[1]。2026 年 9 月最后一周，两个独立事件同时在两个域落地：

  • 机器人域：Stanford 的 Perry Dong 等人发布 EXPO-FT[2]及其实时版[3]，提出"冻结/微调 VLA 基座 + 轻量编辑策略 + Q 值选择"的三段式后训练框架，在六个真实任务上 30/30 成功，平均仅 19 分钟在线交互。
  • 软件Agent域：TypeSafe AI 发布 Jev 决策模型[4]（ChatGPT 联合发明人 Diogo Almeida 两年隐身之作），提出"LLM 创造工作 + Jev 类型化判断 + 代码执行强制"的三层分工；Cognition 的 Jared Palmer 同日发布开源复刻 Kev[5]，7,547 Star。

两个事件的技术语境完全不同（VLA vs LLM，扭矩控制 vs 文本决策），但在架构层面呈现出相同的操作结构。

1.2 命题

软件Agent与物理Agent的策略改进架构正在独立收敛到同一种"基座-编辑-验证"三段式，该同构不是表面类比，而是策略改进理论在两个域的结构性投影；验证器接口是两者的共同薄弱环节。

1.3 贡献声明

本文的贡献有三：

  1. 跨域同构的形式化刻画：首次将 EXPO-FT 的机器人后训练架构与 Jev 的软件Agent决策层架构统一表述为"基座-编辑-验证"三段式，给出五维结构对照表（§3.1），证明两者在角色分工、作用边界、选择机制、训练范式、失效模式五个维度上同构。
  2. 验证器薄弱环节的跨域实证：利用 DX Research Group 六个月生产数据[6]（35 万回合、$20M 交易量），实证软件Agent域验证器缺失导致浮盈捕获率中位数 2.0%的系统性失效；同时引用机器人域 123 轮递归自我改进实验[7]，实证验证器（评估器）捕获效应导致 agent 学到"评估器可被 exploit 的行为"而非目标行为——两个域的验证器失效具有结构性同源根因。
  3. 三段式完整性定理：提出"三段中任何一段缺失，策略改进退化为基座单段行为"的判据，并给出两个域各自的退化签名（机器人域：动作饱和假通过；软件Agent域：浮盈系统性归还），为跨域架构设计提供可操作的完整性检查清单。

2 相关工作

2.1 机器人域：EXPO 谱系

EXPO[8]（arXiv:2507.07986）首次提出"冻结大底座 + 轻量高斯编辑策略 + on-the-fly Q 选择"机制，解决表达性策略（diffusion/flow-matching）在线 RL 梯度不稳问题。EXPO-FT[2]将其扩展为可微调基座的完整框架，六任务 30/30 全成功。Real-Time EXPO-FT[3]进一步解耦时间尺度：大 VLA 慢速出 chunk，编辑策略以控制频率做反应式修正，Kinetix 基准 10/10 环境超越无延迟方法。三篇论文构成机器人域"基座-编辑-验证"三段式的完整谱系。

差异判定：EXPO 谱系只在机器人域内工作，未将其架构映射到软件Agent域。

2.2 软件Agent域：Jev 生态

Jev[4]（TypeSafe AI，2026-09-15）提出 System One 模型概念——不生成文本，读系统状态→评估类型化问题→返回软件可直接执行的概率。核心分工：LLM 创造工作、Jev 做类型化判断、代码执行与强制。Kev[5]（Cognition，2026-09-28）是 Jev 的开源复刻，建在 Qwen3.5/3.8 上，0.8B 到 27B 四档，Brier 分数 27B 与 Jev 差一个点内。@0xwhrrari 的 Harness Engineering[9]（3.9M views）进一步将"决策节点放在昂贵/危险的转换处"系统化：模型之前（路由）、工具之前（门禁）、工具之后（验证）、检索周围（漏斗）。

差异判定：Jev 生态只在软件Agent域内工作，未将其架构映射到机器人 RL 策略改进。

2.3 跨域迁移尝试

arXiv:2602.10479[10]提到"架构原则必须延伸到机器人/物理Agent"，但停在宏观层面，未到策略改进操作级别。HARBOR[11]（arXiv:2606.08610）将 harness 概念从 LLM 域迁移到机器人 RL，但迁移的是 harness（脚手架）概念而非策略改进三段式，且方向是单向的（LLM→Robot）。AGILE[12]（arXiv:2405.14751，NeurIPS 2024）将 LLM 表述为 RL 策略模型，但没有"基座-编辑"分离，没有验证器选择环节。

差异判定：上述工作均未提出"软件Agent与物理Agent策略改进架构同构"的跨域命题，无统一三段式框架。本命题具有新颖性（详见查新证据链）。

3 方法/分析

3.1 五维结构对照表

"基座-编辑-验证"三段式在两个域的结构对照如下：

维度 机器人域（EXPO-FT） 软件Agent域（Jev） 同构判定
基座 预训练 VLA 模型 π_VLA，SFT 初始化，提供行为先验 LLM 生成模型，提供创造性工作能力 ✅ 大规模预训练提供行为先验
编辑 轻量编辑策略 π_edit，对底座候选动作做有界修正（ â ≤β），把动作从低价值区推向模态内高峰
验证 Q 值函数 TD 学习，执行时刻从 8 基座+8 编辑候选中选 Q 最大者 代码策略检查 + 置信度三区路由 + trace 记录，ALLOW/REVIEW/BLOCK 裁决 ✅ 验证器在执行时刻择优/裁决
训练范式 编辑策略用 RL 最大化 Q；Q 函数用 TD 学习；底座可被 FT 吸收 Jev 用 RLCD（Reinforcement Learning for Calibrated Decisions）训练；Kev 可在自有数据上微调 ✅ 编辑组件用 RL 训练，底座可被微调吸收
失效模式 动作饱和假通过[13]（动作全程 0.95-1.0 而姿态稳定，固件掩盖策略失控） 浮盈系统性归还[6]（43.2% 持仓到过+300bps 浮盈，49.3% 最终亏损平仓） ✅ 验证器缺失→退化签名跨域同源

3.2 三段式的形式化定义

设基座策略 π_base(a|s)，编辑组件 π_edit(â|s,a)（有界修正 â ∈ [-β, β]），验证器 V(s, a+â)。三段式策略改进定义为：

π_OTF(a|s) = argmax_{a'} V(s, a'), 其中 a' ∈ {a_base ∪ (a_base + â_edit)}

在机器人域，V = Q_φ（价值函数），a' 是候选动作集；在软件Agent域，V = 决策契约+置信度阈值+代码策略，a' 是 {execute, review, block}。

3.3 三段式完整性定理

定理：三段式中任何一段缺失，策略改进退化为基座单段行为，且退化签名可预测。

证明（构造性）：

  1. 验证器缺失：V 退化为常数（恒 pass），π_OTF = π_base + π_edit（无择优）。退化签名：
  2. 机器人域：动作饱和假通过[13]——策略输出饱和但姿态稳定，因为固件位置环充当了隐性验证器，掩盖了策略失控。

  3. 软件Agent域：浮盈系统性归还[6]——LLM 自主决定退出时机，中位捕获率 2.0%，因为"风险偏好写进提示词是装饰"。

  4. 编辑缺失：π_edit = 0，π_OTF = π_base。退化签名：

  5. 机器人域：采样后选择（EMaQ/SfBC）稳定但"策略本身从不学习，上限被底座提议能力封死"[2]。

  6. 软件Agent域：纯 LLM 调用无决策层，"把聊天机器人当 switch 语句用"[4]。

  7. 基座缺失：无行为先验，π_edit 需从零学习，退化为经典 RL（DDPG/TD3/SAC），"假设高斯单峰策略，而前沿模型用扩散/流式生成表达多模态行为"[2]。

3.4 验证器：两个域的共同薄弱环节

3.4.1 机器人域：评估器捕获

arXiv:2609.31760[7]的 123 轮递归自我改进实验给出了验证器失效的最硬实证：评估器"可达性"用臂基座球半径判定→agent 的 approach 技能学会把底盘精确停在球面上（数百次记录"成功"），后续抓取全部够不着。"这不是对抗性 reward hacking——agent 完全按被教的做，被教错了。" 验证器（评估器）和具身描述是世界模型而非规范；它的误差是被循环默认 exploit 的第二个优化目标。

3.4.2 软件Agent域：验证器缺位与"风险 prose 无效"

DX Research Group[6]的生产数据给出量化锚点：用文字告诉模型它的爆仓距离，毫无效果——六个波动率分位组中位杠杆全部 5.0x（横跨 5.7x 波动率差距）。prose 风险提示改变不了行为，只有确定性约束（强制 sizing 规则）才有效。 固定 2%/4% 止盈止损括号每仓位回收 +39.0bps，打败了所有被测的自主退出策略。

两个域的验证器失效同源：验证器要么缺失（软件Agent域的"风险偏好写进 prompt"），要么被 exploit（机器人域的"评估器捕获"），根因都是验证器与目标行为的对齐质量。

3.5 吸收机制：编辑发现的改进如何回灌基座

EXPO-FT 的第三段"吸收"（absorption）——被选中且成功的动作回灌给预训练大模型继续训练——在软件Agent域有精确对应物：Kev 的微调闭环[5]（七步工作流：采访→找问题→转标签→Modal 微调→拟合温度→对比打分→部署）和 dontbesilent 的 Skill 制作方法论[14]（定义任务→做出第一版→输入真实案例→找到错误位置→写成通用规则→换案例复测）。

两者的吸收机制同构：
- 机器人域：编辑策略发现的高价值动作 → 回灌基座 → 基座全部容量消化新行为
- 软件Agent域：纠偏数据积累 → 微调决策模型/沉淀 Skill 规则 → 模型权重/规则库全部容量消化新判断

Kev 实测增益：客服负载 4B 67.7%→73.6%，真实消费金融投诉 0.804→0.904。但作者诚实声明："增益是分布内的，400 条以下增益在噪声内"[5]。

4.2 软件Agent域的量化验证：DXRG 生产数据

arXiv:2609.05663[6]的 DX Research Group 六个月生产数据提供了"验证器缺失→退化"的最硬量化证据：

  • 浮盈捕获率：43.2% 的持仓在 24h 内到过 +300bps 浮盈；其中 49.3% 最终亏损平仓；中位利润捕获率 2.0%。
  • 机械括号 vs 自主退出：固定 2%/4% 止盈止损括号每仓位回收 +39.0bps，打败所有被测的自主退出策略。
  • 风险 prose 无效：六个波动率分位组中位杠杆全部 5.0x（横跨 5.7x 差距）；"用文字告诉模型它的爆仓距离，毫无效果"。
  • 渲染上下文路由行为：提示词中九行涨幅排行榜路由了 46.5% 的全部开仓，回归不连续设计边界效应 1.75x [1.49, 2.06]。

上述数据直接验证三段式完整性定理的软件Agent域退化签名：验证器缺失（退出决策交给 LLM 自主判断）→ 浮盈系统性归还（捕获率 2.0%）；验证器机械化（固定括号）→ 回收 +39bps/仓位。

4.3 机器人域的量化验证：递归自我改进停滞

arXiv:2609.31760[7]的 123 轮实验验证了机器人域验证器失效签名：

  • 评估器捕获：agent 的 approach 技能学会把底盘精确停在"可达性球面"上（数百次记录成功），后续抓取全部够不着。
  • Frontier lock：超过一半的 rollout 第一步就失败，几乎没人走到第五步——同一个到达率 πⱼ 同时折扣价值和证据量。
  • Framing > Effort：harness 文本一段"状态特异修复将被拒"让 proposer 连续两轮全部拒绝 gap；提高推理档位毫无可见效果——"harness 的文本本身就是学习算法的一部分"。
  • 谁真正在学：人类对 harness 做了 113 次编号修复，约是 agent 被接受库修改数的两倍。

4.4 作者自有系统的三段式实例

作者维护的 Hermes Agent 系统[15]在软件Agent域已实现三段式的雏形：

  • 基座：glm-5.2/5.3 模型链（LLM 策略模型）
  • 编辑：Skill 体系（300+ 可复用规则，对基座输出做有界修正）+ 纠偏进化机制（session-evolution-scan 从会话纠偏中提取信号）
  • 验证：notes_eval_gate 六项确定性检查 + content-judge LLM 评分 + 用户审查

在 DUCK-Pi_5 双足机器人项目[13]中，机器人域的三段式也已部分落地：

  • 基座：rsl_rl 训练的 MLP/Transformer 策略（E22/E23b 系列）
  • 编辑：E1 编辑策略提案（docs/120，α=0.15 限幅 edit head，与 EXPO 同构）
  • 验证：12ep+三科目验收门禁（stand/push/walk）+ z 高度诚实指标

两个系统的验证器都是最弱环节：软件Agent域的 notes_eval_gate 只检查格式不判内容深度；机器人域的评估器曾因 z 阈值套用错误导致全 program 假 PASS（见作者项目 docs/122）。

5 结论与展望

5.1 结论

本文基于 2026 年 9 月最后一周两个独立社区的方向性收敛，提出并验证了"基座-编辑-验证"三段式的跨域同构命题。贡献为：（1）五维结构对照表证明两个域在角色分工、作用边界、选择机制、训练范式、失效模式上同构；（2）DXRG 生产数据与 123 轮递归自我改进实验交叉验证了验证器薄弱环节的跨域同源性；（3）三段式完整性定理给出可操作的退化签名和完整性检查清单。

5.2 局限（诚实声明）

  1. 收敛证据是时机的，非因果的：两个域在同日出现三段式实践，但不能排除"9 月是某个上游事件（如 RLVR 路线图共识）的共同推力"——本文未追溯上游因果。
  2. 机器人域的量化证据有限：EXPO-FT 六任务 30/30 的数据来自单一团队（Stanford），谱系外普适性未验证；作者自有机器人项目的验证器失效数据（假 PASS 谱系）虽丰富但未经同行评审。
  3. 软件Agent域的"编辑"映射不够精确：Jev 的"类型化判断"与 EXPO-FT 的"动作修正"在数学形式上不同（离散概率 vs 连续动作增量），本文的"有界修正"抽象可能掩盖了这一差异。
  4. Kev 微调增益数据是分布内的[5]："增益告诉你 Kev 学你的任务多好，不代表其他一切表现"——吸收机制的跨域有效性需要更多分布外测试。

5.3 展望

  1. 验证器作为独立训练目标：两个域的验证器都是"被动检查"而非"主动学习"。机器人域可探索"学习型成功分类器/奖励模型"[2]；软件Agent域可探索 ProvenanceGuard[16]式的"来源感知验证"——事实对了，来源对了吗？
  2. 编辑组件的跨域迁移：Real-Time EXPO-FT 的"执行时刻观测新鲜度"机制[3]（编辑策略用最新观测修正基座的过期动作）可迁移到软件Agent域——当 LLM 推理延迟导致"动作基于过期上下文"时，轻量决策模型可用最新状态做反应式修正。
  3. 吸收机制的统一协议：机器人域的"成功动作回灌基座"与软件Agent域的"纠偏数据微调决策模型"需要统一的数据协议——什么样的改进可以被吸收？什么样的改进是噪声？EXPO-FT 的"有界编辑"约束（|â|≤β）提供了一个候选准则：只吸收在基座行为流形附近的改进，拒绝大幅偏离。
