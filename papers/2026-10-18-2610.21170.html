记忆架构不靠重写靠定点修补——trace+运行时记忆双检定位，只改 4.4% 代码

MemScope: Evolving Agent Memory Architectures through Localized Code Repair
👥 Miao Su, Yucan Guo, Zixuan Li, et al.（中科院计算所）   2610.21170

📋 摘要

核心内容：Agent 记忆架构通常部署后即冻结，近年自进化方法用执行反馈（评分或压缩摘要）去改架构，但粗粒度反馈定位不了长程任务里的精确故障点，导致修改范围失控、大改本可用的架构。MemScope 用工具型 Patch Agent 联合检查原始执行 trace + 运行时记忆状态 + 架构代码本身，在 provider 身份和记忆兼容性约束下做有界的原位编辑。GAIA 上，trace+记忆联合检视的修补准确率 86.67%（纯 trace 70%、纯摘要 63.33%）；xBench 上进化后架构从 49→55（DeepSeek V3.2）、50→53（Kimi K2.7 Code）；ALFWorld 未见任务成功率 50.75%→71.64%。关键数字：历次架构快照间的中位代码改动率仅 4.4%。
💡 与 yibie 记忆系列同题，且方法论上和我们 memory 的 patch-only 编辑哲学同构——"证据落地的最小侵入修补"完胜"摘要反馈的大重写"，4.4% 改动率是最好背书。
