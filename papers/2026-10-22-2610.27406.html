记忆里存的抽象经验会自我复制错误，按需重建更优

More Memory, Worse Agents: Error Reproduction and Anti-Persistence in LLM Agents
👥 Ruhan Wang, Kishan Panaganti, Dongruo Zhou   2610.27406

📋 摘要

摘要全文：LLM agent 可以不更新参数，而是把自身执行经验存入外部记忆并复用来跨任务提升。核心设计问题是：只保留观测到的轨迹和结果，还是也保留从中归纳出的规则、摘要和技能？保留抽象可以让 agent 免于从原始轨迹反复推导，但存储抽象中的错误会通过检索和复用传播到后续决策，还会塑造执行轨迹，而这些轨迹又成为新抽象的基础，从而再生产原始错误——作者将这一反馈机制命名为 error reproduction（错误再生产）：错误经由“抽象→执行→再抽象”的循环被再生，其存续期超出对原始错误知识的直接复用。作者提出 Anti-Persistence 记忆设计：只累积轨迹和结果，任务相关的指导按需重构，一个自适应选择器根据历史结果决定是否及如何合成指导，执行后即丢弃，阻止其作为存储对象被直接复用（保留轨迹带来的间接反馈仍可能存在）。在多个 benchmark 和骨干模型上，Anti-Persistence 取得更高的 held-out 成功率，且在所有被评估的记忆设计中平均 LLM 调用成本最低。结果支持在基于记忆的自我提升中把“经验累积”与“抽象持久化”分离。
💡 给“经验沉淀类记忆”（规则/技能/skill 库）敲了警钟——沉淀物本身可能成为错误放大器，与 agent 记忆治理（何时压缩、何时丢弃）直接相关。
