定位 GRPO 训工具调用 Agent 时优势信号跨段污染问题，分段锁定功劳分配，BFCL/τ²-Bench 显著提升

论文二：SLCA-GRPO: Resolving Cross-Segment Credit Misattribution in Tool-Calling RL（解决工具调用 RL 中的跨段功劳错配）
👥 Yan Zhan, Shaobo Liu, Qiunan Liu, et al.   2609.29050

📋 摘要

摘要全文：工具调用 Agent 的输出是异构的，结构化的工具调用与面向用户的自然语言摘要交错出现。这种输出异构性给标准 on-policy RL 带来结构性失效：GRPO 等算法将同质的轨迹级标量优势无差别广播到所有 token，导致摘要生成的梯度噪声泄漏到工具决策 token，造成跨段功劳错配和优化不稳定。论文提出 SLCA-GRPO 框架，核心是分段锁定功劳分配（SLCA）。为在不调用昂贵真实 API 的前提下实现可扩展探索和稳定训练，作者先构建了 Schema 引导的 LLM 模拟器（SGLS）作为训练基础设施。在此基础上，SLCA 在单组 rollout 内按结构段粒度解耦优势估计，无需从中间状态额外采样 rollout。配合分层奖励（HierR），SLCA 将执行优势路由给工具 token、将偏好优势路由给摘要 token，消除每次策略更新中的优势污染（跨段错配的主要通道）。在 7B 底座模型上，SLCA-GRPO 加速收敛，同等训练预算下相对标准 GRPO、ToolPO 和 RLTR 在域内评测提升 +2.53 pp，Berkeley 函数调用榜（BFCL）提升 +1.36 pp，τ²-Bench 提升 +9.15 pp，以更少的工具冗余和成本取得更高准确率。
💡 对“GRPO 一刀切广播优势”这一被忽视的结构性缺陷给出清晰诊断和解法，对做工具调用 Agent RL 训练的人是必读的工程级洞察。
