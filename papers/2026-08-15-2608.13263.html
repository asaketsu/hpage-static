vLLM 内加 token 级虚拟化层，让 KV cache 逐 token 回收

vToken: Token-Level Virtualization for Reclaimable KV Caches
👥 Yuanhang Gao, Xiangrui Yang, Yuanfeng Chen et al.   2608.13263

📋 摘要

LLM 服务面临 KV cache 随序列长度和 batch 增长的内存瓶颈。PagedAttention 用固定大小内存块减少了分配器级碎片，但现有 KV 驱逐算法工作在比块更细的 token 粒度，导致块内碎片、大量已分配 KV 内存无法回收。vToken 是轻量级 token 级虚拟化层，通过 token 表间接寻址维持稳定的逻辑 token 视图，异步重排存活 token 实现物理回收；保留 PagedAttention kernel 与 CUDA Graph 兼容。基于 vLLM 对 H2O/Random/Scissorhands 的评测：每请求保留 KV 块减少 27.2%–72.3%，SLA 约束下吞吐最高提升 1.37 倍，受限 KV 预算下最大并发提升 2 倍，且策略集成代码从 500+ 行降到 50 行以内。
💡 直接可落地的推理部署优化——不改 kernel、不改 CUDA Graph，vLLM 用户近乎零成本接入，长上下文并发翻倍对生产环境价值显著。
