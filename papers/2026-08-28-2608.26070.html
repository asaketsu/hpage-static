推理时丢弃过期中间 token，长思考提速 3 倍且不掉点

Prefix Sliding for efficient test-time scaling
👥 Niklas Muennighoff, Zhengyang Wang, Zeyi Chen, Weijia Shi, Binyuan Hui et al.   2608.26070

📋 摘要

核心内容：测试时扩展（test-time scaling）让模型思考更久以提升性能，但全注意力机制会把整条推理轨迹保留在显存中，长推理任务开销巨大。作者发现大多数中间推理 token 会随推理推进迅速失去重要性。据此提出 Prefix Sliding：只保留前缀（关键指令与工具说明）和最近几千 token 的滑动窗口，其余全部丢弃，从而无论思考多长显存都有上限。无需训练即可让现有模型提速 3 倍且保持性能；结合强化学习训练后，可扩展到超过 10 万 token 的推理轨迹并获得更好效果。消融实验显示其优于对中间 token 做摘要或普通滑动窗口。代码已开源。
💡 直击推理模型长思考的成本痛点，免训练即得 3 倍加速，是 inference-time scaling 落地部署的关键技术；作者 Muennighoff 为该领域知名研究者。
