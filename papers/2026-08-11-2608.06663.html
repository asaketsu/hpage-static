系统性综述长程 LLM Agent 的规划、记忆、执行、训练与评估，梳理 1547 篇论文的核心发现

The Horizon Gap: Planning, Memory, Execution, Training, and Evaluation for Long-Horizon LLM Agents
👥 Mingguang Chen, Licheng Wang, Bo Qu   2608.06663

📋 摘要

前沿语言模型已能在单次前向传播中解决几年前还是研究贡献的推理问题，但在多小时的复杂任务上却频繁失败：忘记之前的决策、将半成品工作标记为完成、或逐渐偏离目标。作者将此现象称为"horizon gap"（水平差距），并系统性综述了 1547 篇 arXiv 论文（2024-2026），通过种子采集+定向补充构建语料库（披露 26.8% 渗透率过滤器）。论文澄清了三个常被混淆的概念：长程（任务属性：所需步数）、长上下文（模型属性：token 容量）、长期记忆（系统属性：跨步/会话持久性）。作者将语料分为六大类，追踪长程任务的全生命周期——规划、记忆、执行、训练、评估、基础/安全——并与"水平信息在何处承载"的轴线（上下文内、任务内但上下文外、跨任务持久化）交叉分析。核心发现：随着水平变长，仅依赖结果的信号越来越缺乏信息量，而领域的应对——无论是过程奖励模型、信用分配还是轨迹级诊断——都在制造更密集的步级信号。论文最后指出了三个开放测量问题：分解模型能力与 harness 能力、管理训练和评估中共享的过程级信号的相关偏差、以及长程可靠性是否能建立通用预测理论。
💡 目前最全面的长程 Agent 综述之一，覆盖完整任务生命周期。对理解"为什么 LLM Agent 在长时间任务上会崩"以及"如何用步级信号训练和评估 Agent"有地图级参考价值，适合作为研究方向选题指南。
