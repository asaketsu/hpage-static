CLI 与 MCP 两条工具集成路线的 14 维系统对比

MCP vs CLI for AI Agents: A Comparative Analysis of Tool Integration Strategies for Autonomous Systems
👥 Arun Malik, Nitish Talasu, Bradley Klemick, et al.   2610.30157

📋 摘要

摘要全文：AI agent 需要接口与外部系统（文件、API、数据库、云服务）交互，当前存在两大竞争范式：CLI（agent 直接执行 shell 命令）与 MCP（结构化 JSON-RPC 协议，提供受治理的强类型工具访问）。本文在 14 个评估维度上做对比分析，辅以实例演示、对照既有合规框架的安全评估、以及经济性建模。结论：CLI 在单用户、纯本地工作流上效率更优；MCP 则满足 CLI 根本无法做到的需求——细粒度访问控制、凭据隔离、结构化审计、多租户治理。论文进一步论证 progressive disclosure 技术已消除 MCP 的历史短板（上下文窗口开销），使其 token 效率可与 CLI 相当，同时保留架构优势。最终建议生产系统采用混合架构。分析引用了学术、政府与工业信源，包括 NSA 正式指南（CSI U/OO/6030316-26）、OWASP 安全标准、以及 BCG 和 Gartner 的经济模型。
💡 与我们 CLI-Anything 分析（能力预检+轨迹快照）正面呼应——论文的混合架构结论（本地 CLI + 治理面 MCP）和 progressive disclosure 消除 token 开销的论断，可直接用于校准我们 cli-hub 路线的适用边界与安全论证。
