无验证器场景下用动态评分量表给 Agent 每步分配细粒度优势

DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training
👥 Shubham Gandhi, Saurabh Goyal, Kiran Kate, et al.（IBM）   2609.04094

📋 摘要

核心内容：RLVR 依赖程序化检查器，但多数长程 Agent 任务没有 ground-truth 成功信号。DRACO 在训练中动态生成 rubric 以跟踪策略能力演进，对完整轨迹评分后将判断闭式地重新分配到对应步骤，在 GRPO 中产生有区分度的逐步优势，无需训练额外的归因模块。在 AppWorld 上比基座模型高 15.9 分、比用稀疏真值奖励的 GRPO 高 5.3 分；在域外 Tau-Bench 上不用前沿 judge 也能超越真值奖励训练。代码已开源（github.com/IBM/draco）。
💡 直击 Agent RL 训练最大痛点（无 verifier 的 credit assignment），IBM 出品、有代码、双 benchmark 验证，做 Agent 训练必读。
