让 Agent 闭环自动设计 PTQ 量化配方，评测从数十 GPU 小时压到分钟级

QDA: Closed-Loop LLM Quantization Design with Agents
👥 Xingyang Li, Tianlang Zhao, Song Han, Ligeng Zhu〔11-17〕   2611.23388

📋 摘要

摘要要点：训练后量化（PTQ）是低成本 serving 的标准路径，但最优配方随模型和精度而变，专家逐模型重设计既耗时又次优。QDA 用 Agent 为每个模型+精度设计配方：评估端用候选模型在从未见过的推理轨迹上与原模型的输出 KL 散度做分钟级打分，再对有希望的长生成复检以捕捉复读循环等失败模式；构建端提供一批互相兼容、可移植到新架构的公开 PTQ 方法库。在四个推理模型上，QDA 以每档 64 GPU 小时的搜索成本，在 W4A16/W4A8/W3A16 平均超过最强公开配方 0.9/1.4/2.2 个百分点；在 320B MoE 的 GLM-5.3-Flash 上做 NVFP4 W4A4，恢复 FP8 精度的 98.3%（最好厂商 checkpoint 只有 96.9%），且所有产出的 checkpoint 在现有 serving kernel 上零推理开销运行。
💡 Song Han 组出品，Agent×量化交叉；在 GLM-5.3-Flash 上拿到 NVFP4 恢复 98.3% 的结果，与你日常在用的 glm-5.3 直接相关，方法库+评测器将开源。
