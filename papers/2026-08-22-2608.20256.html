让推理模型自己决定每题花多少 token 思考，平均省 41% 推理长度

Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation
👥 Gijs Kassenaar, Zhao Yang, Vincent François-Lavet   2608.20256

📋 摘要

Abstract：
用强化学习训练出的推理模型通常采用固定 token 预算，导致简单题过度计算、难题算力不足。本文研究模型能否通过首 token 选择三种模式来自主分配推理努力：NoThink（尽快作答）、Short（简短推理）、Long（深度推理）。该选择在 GRPO 框架内直接学习，无需独立 router，通过精心设计 reward 让每种模式在不同长度下各有价值，并配合每模式 token 上限区分。在 MATH 上训练的 1.5B 蒸馏模型中，三种模式自然涌现、不坍缩；简短模式反而比 Long 更准，证明 router 是按难度分流而非随机。三个 seed 平均：在 MATH500 上精度与基线几乎持平（0.782 vs 0.796），而平均响应长度从 4796 降至 2811 tokens（-41%）。无需再训练即可迁移到其他基准，GSM8K 上最高省 76% token 且精度不降。
💡 直击 inference-time scaling 的核心痛点——自适应计算分配，是 DeepSeek-R1 风格推理模型走向实用的关键一步，工程价值极高。
