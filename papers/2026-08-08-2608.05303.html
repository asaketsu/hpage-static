软硬件协同的边缘 LLM 加速器，首次让 MoE 与投机解码在端侧真正兼容

EdgeXpert: An Edge Device for Memory-Efficient LLM Inference with Mixture-of-Experts and Speculative Decoding
👥 Sangwoo Ha, Hyunwoo Seo, Yurim Jo, Youngjin Moon, Hoi-Jun Yoo   2608.05303

📋 摘要

核心内容：端侧部署 LLM 的核心瓶颈是 FFN 层的外部内存访问（EMA）。投机解码能减少解码阶段数，MoE 能降低单阶段成本，但两者结合存在不兼容问题。EdgeXpert 提出软硬件协同方案：在 prefill 阶段，将路由重构为 prompt 级别的专家复用，用轻量编码器识别重要 token 构建共享专家集，并为次要 token 减少专家预算；在 decode 阶段，利用同深度候选 token 的上下文相似性和互斥性做深度感知的专家合并，只加载显著通道并通过计算校准恢复精度，无需额外内存访问。基于三星 28nm 工艺 800MHz 综合实现，相比已有方案延迟降低最高 56.3%、能耗降低 44.1%，精度几乎无损。
💡 直击边缘推理中 MoE+投机解码的核心矛盾，用软硬件协同在 28nm 老工艺上做到了接近基线精度的极致能效，对 Jetson 类设备有直接参考价值。
