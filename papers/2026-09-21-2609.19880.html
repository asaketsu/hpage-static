熵编码 + drift 机制做 KV Cache 量化，兼顾压缩率与并行解码

D-Quant: Driftable Entropy Coding for KV Cache Quantization
👥 Yi Su, Hong Liu, Guanghua Yu et al.   2609.19880

📋 摘要

KV Cache 随序列长度和 batch 规模线性增长，已成为 LLM 部署的主要瓶颈，量化因有效且易部署而受青睐。但现有方法多为固定位宽量化，位数降低时量化级数指数收缩导致信息损失严重；且 KV 值经旋转归一化后近似正态分布，固定编码对高频中心值和低频尾部值分配相同位数，浪费明显。熵编码可为高频符号分配短码字，但其变长输出不兼容需要规则内存布局的并行 attention kernel。D-Quant 引入 drift 机制，将每个 token 的熵编码表示转换为固定位宽比特流，实现 attention kernel 内的规则内存访问与并行反量化，在压缩率与硬件友好性之间架起桥梁。
💡 与今日 DeepSeek 新文的 FP4 KV Cache 思路互补，解决熵编码“压缩率高但硬件不友好”的老矛盾，工程落地价值大。
