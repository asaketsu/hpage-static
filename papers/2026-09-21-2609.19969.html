552B 参数 MoE 新模型，KV Cache 压至 890 字节/token，支持百万上下文

DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression
👥 DeepSeek-AI（Anyi Xu, B. Li, Bangcai Lin et al.）   2609.19969

📋 摘要

针对长程 Agent 带来的重输入负载，DeepSeek 发布 V4.1-Flash——552B 骨干参数的多模态 MoE 模型，支持最高 100 万 token 上下文。其 Causal Encoder-Decoder（CED）架构在解码时每 token 激活 16B 参数，prefill 阶段仅激活 8B，显著提升 Agent 负载的成本效率。模型结合 CSA2 稀疏注意力中的跨层 KV 复用与 FP4 KV 缓存，将全局 KV Cache（常驻 HBM）压至 890 字节/token，约为 V4-Flash 的 1/4；配合 SWA Bounded Replay 部署优化，持久化 KV Cache（SSD/主机内存）降至 V4-Flash 的约 1/8。模型在 45T token 多模态语料上预训练并完成全面后训练，性能反而超越基线。模型权重已开源。
💡 DeepSeek 官方新旗舰，把 KV Cache 压缩做到了新极限，且直接面向 Agent 长上下文场景开源可用，是本周必读。
