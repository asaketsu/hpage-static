让云端 Agent 自动为本地部署的小模型 Agent 构建"技能包"，使其能力逼近云端大模型

SkillSmith: Enhancing Locally Deployed Agents via Automatic Skill Construction and Evolution
👥 Xinle Jiang, Remy Xie, Ming Tang   2608.08037

📋 摘要

摘要全文：
当前基于 LLM 的 agent 框架（如 OpenClaw）普遍采用云端部署模式，用闭源云 LLM 做骨干，存在泄露用户隐私和重复调用成本的问题。本地 Agent 用用户自控设备上的开源 SLM（小模型）解决了部署顾虑，但任务效果远落后于云端 Agent。作者通过诊断分析发现，本地 Agent 效果不足主要源于骨干模型规模有限导致缺失环境知识（包括环境规则和操作流程）。为非参数化、上下文高效且无需专家编写地补充这类知识，作者提出 SkillSmith——一个云-本地 Agent 协作框架：以 Skill 作为上下文高效的知识载体，从云端 Agent 的任务探索中自动构建 Skill，再用本地 Agent 的执行反馈来演化 Skill，从而增强冻结的本地 Agent。在 AppWorld 和 WorkBench 日常 agent 任务数据集上，自动生成的 Skill 使 Qwen3.6-27B（SLM）本地 Agent 达到接近前沿 LLM 云端 Agent 的任务效果，超过最强的非参数基线，在 AppWorld-Normal 上将每任务平均动作数从 36.1 降到 9.9，且无需重跑 Skill 构建即可泛化到其他 SLM 骨干。
💡 思路与上一篇"技能蒸馏"形成呼应，共同指向一个趋势——把大模型的能力固化成可迁移的技能包喂给小模型，是兼顾隐私、成本与效果的现实路径。
