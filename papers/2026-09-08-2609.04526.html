4-bit 微缩放 LLM 合并 LoRA 不再精度回退，且生命周期稳定

Scale-QLoRA: Code-Invariant Adapter Merging for Native 4-bit Microscaling LLMs
👥 Tung-Ling Li, Jiale Huang, Lee-Chi Wang, et al.   2609.04526

📋 摘要

将 LoRA adapter 合并进 base model 是标准部署实践，可消除运行期 adapter 前向开销。但在原生 4-bit 微缩放 checkpoint（NVFP4、MXFP4）上这一步不再"免费"——合并后的权重必须经过量化器重写回原格式的离散 E2M1 code plane（约占整个 artifact 字节数的 90%），使得部署产物与单一量化约定耦合，生命周期中任何后续 code-touch 操作都可能破坏它。朴素做法更糟：在已对齐网格的 base 上重建最优就是 base，会删除适配效果，最多掉 39 个百分点。Scale-QLoRA 只适配原生的 per-block scale 字段，在部署网格上训练这些 scale，冻结所有 E2M1 code，从而在固定格式、scale grid、block layout、code plane 下，合并是逐位恒等映射，产物 code-invariant。在 4 个模型 4 个任务上，Scale-QLoRA 和 merge-aware QAT-LoRA 都无精度损失，因此两者不做精度排序；区别是 QAT-LoRA 通过量化器重推 code plane，而 Scale-QLoRA 精确保留 code plane。这个差异决定了生命周期成本：nearest-rounding 实现之间差约 1 pp，更极端的规则错配可让权重空间产物降到约 0%。此外保留 code plane 还能去掉训练中的权重空间直通估计器（dense 8B 上每步 3.9× 加速），并支持精确回滚、code-plane 去重和约 125× 的 scale-only 任务切换。
💡 随着 4-bit 微缩放（NVFP4/MXFP4）成为主流部署格式，LoRA 合并从"免费操作"变成陷阱。这篇给出结构性解法，对多任务/多租户量化推理栈有直接参考价值。
