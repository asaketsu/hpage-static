严格对照实验证明：agent 框架（harness）选择对编码任务成功率没有平均优势，别迷信厂商原生搭配

Harness or Model? Isolating the Harness Effect in Agentic Coding with a Contamination-Controlled Private Suite
👥 Mohsen Arjmandi   2609.11987

📋 摘要

agentic coding 系统 = 模型 + harness（工具、提示、控制流）。业界默认“厂商原生 harness 配自家模型更强”，本文用私有、防污染的 256 个任务套件检验这一假设：同一模型分别在 claude-agent-sdk 与 deepagents 下、openai-codex SDK 与 deepagents 下配对对比，共 792/800 次运行由隔离 oracle 评分。结果：两种对比下 harness 均无平均优势（Opus 4.8 差 -1.25pp，GPT-5.5 差 +1.25pp，置信区间均跨零）。但分层后出现显著分化：原生 harness 在 61 个仓库任务上落后 9.0pp，却在 19 个竞赛任务上领先 23.7pp（置换检验 p=0.003）；该划分是事后选择的，需设计性复现。成本上，按原始用量重算，中立 harness 在 Opus 上每解决任务花费 1.3-1.6 倍。作者公开了编排器、评分 oracle 与复析代码，任务保持私有。
💡 给“选 agent 框架”这一日常决策提供了罕见的高质量证据——harness 影响呈任务类型分化而非整体优劣；防污染评测方法学（私有套件+隔离 oracle）本身也值得借鉴。
