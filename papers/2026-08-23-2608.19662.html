把 Agent 重复调用的工具 Schema 缓存起来，KV 内存砍掉九成

ReCache: Efficient KV Cache Reuse and Compression for Tool-Augmented LLM Agents
👥 (今日新发 arXiv，作者信息见原文)   2608.19662

📋 摘要

Agent 型语言模型在多次请求中反复编码相同的工具和技能 Schema，传统 prefix cache 因组合顺序不同无法复用其 KV 状态。ReCache 提出独立缓存资源表示，同时降低推理时计算与内存开销。核心思路是"资源级注意力"——消除跨资源交互、分配资源局部位置，从而生成组合不变的 KV 块；再结合贡献选择的层-KV 头路由，以及结构和语义层面的剪枝保留关键调用字段。在涵盖 7 个公开工具/技能数据集的评测中，资源级注意力与完整调用性能持平（Inv-F1 82.3% vs 82.4%），同时实现 3.655× 的时延加速；完整框架将 KV 张量内存降低 92.43%，注意力计算加速 1.423×。
💡 精准命中 Agent 部署的 KV 爆炸痛点，内存降幅 92% 是工程界最需要的数字，开源可用。
