用小模型投机预执行多步动作链，大幅降低工具型 Agent 延迟

Speculative Macro Commit for Faster Tool-Using Agents
👥 Zeyu Liu, Souvik Kundu, Peter A. Beerel et al.   2609.03236

📋 摘要

工具型 LLM Agent 的耗时不仅在模型推理，还在于串行的“动作-观察”轮次，每次工具调用、环境转移和观察都会拖延后续决策。本文提出 Speculative Macro Commit（SMC），一种双层 Agent 系统的运行时机制：大型权威 actor 模型产出官方轨迹，而更快的投机 drafter 模型在隔离的环境快照上持续预测并执行未来的动作链。SMC 从训练轨迹中挖掘 recurring 多动作骨架存入宏库，运行时用于匹配 drafter 预测的动作链；当 actor 的下一个工具调用与首个 draft 动作吻合时，SMC 将剩余已预执行的 draft 步骤连同观察一并提交到官方轨迹。实验使用 Qwen3.5-27B INT4 作为权威 actor、Qwen3.5-4B 作为投机 drafter，在 τ²-Bench Telecom 子集上保持与串行 Agent 相当的准确率，延迟较 Speculative Actions（SA）基线降低 10.23%，较串行执行降低 18.59%；在 AppWorld 上较 SA 降低 7.7%、较串行执行降低 44.9%（任务完成率略有下降）。代码已开源。
💡 把“投机解码”思想从 token 级扩展到 Agent 多步动作级，是 Agent 推理加速方向的新范式，对构建低延迟生产级 Agent 有直接参考价值。
