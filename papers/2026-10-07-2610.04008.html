首个把 Skill 包「文档修复/脚本修复/行为保持」分开考核的自进化基准，AST 定位修订法提升 21-31%

SkillScriptBench: Benchmarking Self-Evolution of Executable Agent Skill Packages Beyond Markdown
👥 Yuxuan Liu, Haoran Li, Yuhao Zhang, et al.（共13人）   2610.04008

📋 摘要

摘要全文：可执行 Agent Skill 将自然语言指令与脚本打包为 LLM agent 可复用的组件，修订它们要求在修复错误的同时不破坏正确行为。现有基准评估 skill 自进化时没有系统区分文档修复、脚本修复与行为保持。作者提出 SkillScriptBench：350 任务基准，分别评估这三项能力。从 35,000+ 个 GitHub 托管 Skill 根目录的调查中选出 100 个包、构造 150 个修复任务，每个任务将含注入脚本缺陷的包与维护请求、所需行为的可执行检查配对；另有受控赛道含 50 个包的 200 个任务，每个在干净/文档缺陷/脚本缺陷/双重缺陷四种状态下按同一维护请求评估。在四个 LLM 上，同时编辑文档与脚本的方法能修复脚本缺陷，但在文档修复与行为保持上并不稳定优于纯 Markdown 修订。因此提出 AST 引导的 Skill 修订：用抽象语法树与调用关系把维护需求定位到相关代码位置，把脚本编辑限制在这些位置内，并同步更新文档与修订后脚本一致。按模型平均，该修订阶段在 Raw Package 上修复成功率绝对提升 21.9%、CoEvoSkills 上提升 27.7%；三次运行全部解出的任务占比分别提升 20.8% 与 31.5%，修复一致性显著提高。
💡 直接对标 Hermes 式「SKILL.md+脚本」双件套 skill 生态——它把「改文档」和「改脚本」拆成两种独立能力分开打分，AST 定位法是 skill 自维护的可直接借鉴的工程手段。
