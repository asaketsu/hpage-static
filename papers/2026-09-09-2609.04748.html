量化模型 + prefix caching 会让相同请求产出不同答案，4-bit 下 75% 轨迹发生改变

Same Request, Different Answer: Quantization Amplifies Cache-Induced Divergence in LLM Serving
👥 Aditi Patodiya   2609.04748

📋 摘要

Prefix caching（跨请求复用共享前缀的 KV 张量）已在主流开源推理框架中默认开启，被视为透明优化。本文测量了它在可复现性上的代价，发现该代价随权重量化急剧上升：固定模型、解码参数、种子和请求顺序、以 batch size 1 串行执行 80 轮多轮 agent 工具调用任务，开启缓存后在 16-bit 精度下改变了 36.2% 的轨迹，4-bit 下高达 75.0%；关闭缓存则所有配置下重复执行完全 bit 级一致（800 轮中 0 例偏差）。三组实验定位成因：单个服务端 prompt-cache 设置可使轮间偏差移动 37.5 个百分点；执行顺序仅在该设置激活时起作用；恢复缓存状态后 cached 与 recompute 路径各自可复现但仍互不相同。结论是：缓存服务在给定缓存状态下是确定性的，但实践中不可复现，因为该状态既不随请求传递也默认不重置。单轮实验表明分歧会传导到任务结果层面而不改变总体准确率。作者开源了全部测试 harness、日志与分析管线。
💡 量化部署的可复现性隐患鲜有人系统量化，结论（4-bit + 缓存默认开启 = 3/4 轨迹漂移）对所有在生产环境跑量化 agent 的团队都是直接警示。
