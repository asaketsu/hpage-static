用长程反思任务数据训练 LLM Agent 在测试时自我迭代改进

AREX-2: Advancing Self-Improving Agents through Long-Horizon Reflective Tasks
👥 Hongjin Qian, Chaofan Li, Kun Luo, et al.   2609.38288

📋 摘要

摘要核心：AREX-2 旨在提升 LLM Agent 的自我改进能力，即测试时反复迭代优化解法的能力。该能力依赖两个互补要素：反思（产生比当前更好的解法）与长程执行（多轮迭代保持有效）。作者假设这两种能力是领域无关的，因此在有可验证反馈的 ML 与算法编程任务中合成大量长程改进轨迹作为训练数据。基于 Qwen3.8-27B 训练的 Agent 在 MLE-bench Lite 达 81.8、Frontier-CS 达 70.7，并能迁移到深度研究任务（BrowseComp 84.0、HLE 52.6、GAIA 92.2、DeepSearchQA 93.8），且随推理轮数预算增长持续提升。
💡 证明“长程反思数据”是训练自我改进 Agent 的有效路径，且跨领域迁移性极强，是 Agent 自我进化方向的重要进展。
