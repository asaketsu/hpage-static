学会在每步动作前决定“想多想少”，省一半token不掉分

PORA: Learning When More Reasoning Pays Off for LLM Agents
👥 Bo Yan, Qi Zhang, Zhen Tan, et al.   2610.27119

📋 摘要

摘要全文：LLM agent 在多步任务中执行动作并根据反馈修正，但总推理预算有限且要留给后续步骤，因此必须在每个动作前选择长推理还是短推理。长推理可通过预防后续错误改善最终结果，但会占用未来决策所需的预算容量，这带来两个挑战：估计长推理的下游价值，以及判断该价值是否值得消耗剩余预算。作者提出 PORA（Paired Outcome-guided Reasoning Allocation），通过在同一交互状态上对比短/长推理来学习这一决策：训练时从每个选定状态出发分别以短、长推理额度各完成一次任务，比较最终质量和总处理量来估计长推理何时有价值；推理时由一个控制器将该估计与学习到的“剩余预算压力价格”进行权衡，直接选择短或长推理，无需实际运行两种方案。在应用、记忆、代码、零售、数学五类任务上均取得强结果：BFCL memory 上超出现有最强方法 17.4–32.9 个百分点；同一 agent 在代码和数学任务上以减少 50.6% 的 actor token 和 31.2% 的模型请求数，达到或超过“始终长推理”的效果。
💡 把 inference-time scaling 从“越想越好”推进到“按状态定价的推理经济学”，token 节省幅度（50%+）对 agent 成本控制有直接工程价值。
