消融测显著性给 harness 剪枝——大多数 agent harness 高度冗余，剪掉大半不掉点

SHarP: Saliency-based Pruning of Agent Harnesses
👥 Xinyi Gao, Qiucheng Wu, Kaizhi Qian, et al.   2610.04178

📋 摘要

摘要全文：Agent harness 是协调模型调用、工具使用与任务执行的系统，常通过修订指令/工具/工作流迭代精化，复杂度持续上升，其中某些模块可能冗余——token 开销可观却几乎没有性能收益。受神经网络剪枝启发，本文将 harness 剪枝作为平衡任务性能与 token 成本的手段，提出 SHarP：依据每个模块对性能与效率的显著性进行剪枝。做法是先把工具、指令与支撑机制识别为可独立禁用的组件，再通过消融每个模块、相对完整消融集评估其任务性能与 token 成本来估计显著性，对性能贡献最小或开销最大的模块剪除。在多种 harness 上用留出验证集评估得到意外发现：所研究的大多数 harness 高度冗余，即使剪除大部分模块仍能维持相当的性能与效率。该剪枝方法与实证为 agent harness 设计优化提供了新视角。
💡 给「skill/harness 积累后要不要清理」提供了量化方法论——单模块消融+显著性排序，可直接搬进 Hermes 的 skill 审计流程，对 token 成本敏感场景尤其实用。
