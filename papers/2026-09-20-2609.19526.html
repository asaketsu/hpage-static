用 LLM 评审 + 快速树搜索大幅降低自进化 coding agent 的算力成本

Self Improvement via Fast Tree-search (SIFT)
👥 Xinghong Fu, Aravinth Kulanthaivelu, Yutaro Yamada et al.   2609.19526

📋 摘要

摘要核心：Coding agent 可递归修改自身实现形成自我改进闭环，但现有方法依赖反复重跑 benchmark 任务来评估候选改动，耗时且昂贵。SIFT 引入 LLM-as-a-judge 对候选补丁做两两比较，用正则化 Bradley-Terry 模型聚合胜负记录得到强度分数，驱动轻量级解耦树搜索中的 rank-based 父节点采样；昂贵的下游任务评估只保留给最有希望的节点。在完整 Polyglot benchmark 上，SIFT 超越现有 tree-search 自进化框架，且 CPU 小时、墙钟时间和 API 成本均显著更低。
💡 直击 self-improvement loop 的评估瓶颈，judge 信号替代重复评测，是 inference-time scaling + agent 自进化的高价值方向。
