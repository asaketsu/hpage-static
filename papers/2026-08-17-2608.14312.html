把 verifier 奖励转化为逐 seed 的 RL 训练环境合成策略，Agent RL 训练效率大幅提升

Envs-FORGE: Frontier-Optimized Reward-Grounded Environment Synthesis for Agent RL
👥 Xiaojun Wu, Cehao Yang, Honghao Liu et al.   2608.14312

📋 摘要

摘要全文：面向终端 Agent 的强化学习（RL）需要具备可靠奖励和合适难度的可执行训练环境。固定配方（few-shot、Self-Instruct、Evol-Instruct）对每个 seed 施加相同的 prompting 策略，即使当前策略本应受益于更难、更易或不同类型的任务。Envs-FORGE 是一种将 verifier 奖励转化为逐 seed 环境合成动作的 prompting 策略：它估计 seed 通过率，围绕目标学习前沿评估六个 projection-direction 动作，并通过求解逐 seed 混合整数线性规划（MILP）选择最优动作来驱动生成。所选动作会同步改写指令、fixtures、oracle 解、测试和 Docker 环境；只有通过 gold 验证的 bundle 才进入 RL 训练。在 Qwen 3.5 35B 上，Envs-FORGE 使 tb-core 的 Pass@1 相比 Base 提升 9.2 个百分点（40.0% → 49.2%），tb-2.0 提升 6.4 个百分点（23.0% → 29.4%），超过最强固定配方基线 2.4 和 2.1 个百分点；在 SWE-bench Verified 上达到 77.1%（Base 为 73.4%），并在 4B-35B 模型上带来 6.8-9.2 点提升。源代码已开源。
💡 Agent RL 最痛的环境合成问题给出了系统性解法，SWE-bench Verified 77.1% 是硬核结果，对训练 coding agent 直接可用。
