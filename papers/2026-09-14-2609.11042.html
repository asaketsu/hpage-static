122B MoE 模型用 RL 训练真实终端 Agent，长程任务超越 GPT-5.4

T1: Terminal Agent Reinforcement Learning for Long-Horizon Tasks
👥 Junyao Yang, Yucheng Shi, Zhongzhi Li, et al.   2609.11042

📋 摘要

Agent 应用正转向编码和科学发现等长程任务，其中终端（shell）任务尤为重要。作者推出 T1：一个总参数量 122B 的 MoE 模型，通过强化学习训练，在云端沙箱中操作真实 shell，单个任务最多进行 300+ 轮工具调用，奖励来自每个任务自带的验证器（verifier）。训练配方包含三大要点：其一，激进的热启动（warm-start）以稳定 actor-critic 训练，并用按通过验证器绝对数量打分的密集过程奖励；其二，通过 TITO 构造实现稳定优化——在精确采样的 token 标识符上训练并在轮次边界修复漂移，同时进行 rollout 路由回放（R3），即记录每一层 MoE 中采样器的逐 token 专家选择并在训练时回放；其三，训练语料完全分布外：隔离的种子与合成任务和 Terminal-Bench 2.1 不相交，确保提升反映真实的能力迁移而非基准过拟合。TITO 与 R3 将训练-推理对数概率差异从 0.021 降至 0.013。在 Terminal-Bench 2.1 上，后训练管线把基础模型从 43.8% 提升到 T1 的 64.0%；在 Long-Horizon Terminal Bench 上达到 27.9%，超过 GPT-5.4 和 GLM-5.1。
💡 当前 Agent RL 最前沿的完整工程配方（TITO + 路由回放解决 MoE 训练漂移），且在长程终端基准上超越 GPT-5.4，对研究 Agent RL 训练稳定性极具参考价值。
