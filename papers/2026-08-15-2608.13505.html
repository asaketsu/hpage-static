面向科学发现的多模态 Agent 基座模型（397B）

Intern-S2-Preview: Scientific Agentic Foundation Model
👥 Lei Bai, Jiaqi Cao, Chiyu Chen et al.（上海AI实验室，百人团队）   2608.13505

📋 摘要

科学发现日益需要 AI 系统能推理异构模态的科学证据、与科学工具和环境交互、并在长任务中持续推进。Intern-S2-Preview 系列支持多模态科学理解、推理、生成与长程任务。训练管线从科学多模态预训练开始（渲染科学文档、图文交错数据、科学语料），再经统一后训练：SFT、可扩展多任务 RL、黑/白盒 Agent RL、on-policy 蒸馏；配合部分 rollout + off-policy 校正、自适应长度正则、在线投机解码等稳定性技术。架构上 397B 主干扩展了时序建模能力，另设独立的 Memory Decoder 内存增强路径（Intern-MemDec-4B）可在冻结主干上快速科学特化——将 Biology-Instructions 平均分从 56.92 提至 60.32。在科学、多模态、Agent 及通用基准上取得竞争力或领先成绩。
💡 这是“科学 Agent 基座模型”路线的最新旗舰实践，其冻结主干 + 外挂 Memory Decoder 的特化方案，对做垂直领域 Agent 的工程架构有直接参考价值。
