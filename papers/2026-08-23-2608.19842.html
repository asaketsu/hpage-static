单 rollout、共享骨干的 Agent RL 新算法，把 PPO 和 GRPO 都甩在身后

SAPO: Single-Rollout Autoregressive Policy Optimization for Agentic RL
👥 (今日新发 arXiv，作者信息见原文)   2608.19842

📋 摘要

Agent 强化学习已成为大模型后训练的关键阶段。现有 GRPO 等无 critic 方法虽省内存，但仍存在三大局限：缺乏显式价值泛化与有效时序信用分配、长任务优势坍缩、采样预算与性能之间代价高昂。SAPO 提出一个低内存框架，策略与价值函数共享单一自回归骨干，在共享参数下于不同因果边界产生策略与价值预测，并独立优化 PPO 目标与辅助 on-policy SARSA 目标。为稳健估计每一步的贡献，作者进一步引入轨迹级广义优势估计（GAE），结合 λ-return 与 batch norm。在 ALFWorld 和 WebShop 上，使用 Qwen2.5-1.5B/7B 训练，SAPO 较 PPO 平均提升 +15.1pp、较 GRPO 提升 +12.1pp，同时完全省去独立 critic 的内存开销，每次迭代运行时间较 PPO 减少 33.2%。
💡 单 rollout 即超越 PPO/GRPO 是 RLHF 训练效率的重要突破，对 DeepSeek-R1 这类推理模型训练管线具有直接参考价值。
