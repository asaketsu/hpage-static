免外部教师、靠诊断报告回流驱动的 harness agent 自训练闭环

ClawLoop: Self-Improving Agents via Harness-Native Training Loop
👥 Hansi Yang, Linji Hao, Hongyan Hao, et al.   2610.14118

📋 摘要

LLM agent 正走向通用 harness 环境（沙箱内直接操作文件系统与 shell），但现有 harness agent 后训练管线稀少、且多为一次性+依赖教师——由更强的外部模型合成任务和收集轨迹、目标 agent 只训一次、评测结果给人看而不回流，上限被外部模型能力和人类先验锁死。ClawLoop 提出无外部教师、最小先验依赖的自改进框架，三个阶段构成自维持循环：任务合成（两套互补构造例程生成多样化任务池，诊断条件化的难度增长，agent-free + agent-based 双重验证）→ 训练（SFT 和/或 RL）→ 诊断反馈（分析 rollout 行为产出能力分析报告，作为下一轮任务合成的输入）。用 Qwen3.6-27B 做循环模型，在 SkillsBench、Claw-Eval-Live、ClawGym-Bench 上一致提升；迭代出的任务迁移到更小的 Qwen3.5-4B/9B 后各基准仍全面涨分，证明数据质量独立于循环模型。
💡 与我们的自进化基础设施同构度极高——「评测→诊断报告→任务合成」的回流结构，正是 Hermes 进化链缺的那一环（我们的 gate 信号目前只判过/不过，没有能力画像回流）。
