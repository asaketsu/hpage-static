检索会污染置信度投票，改用答案-文档重叠度投票即可修复

Beyond Confidence: Test-Time Scaling for Multi-Turn Search Agents via Retrieval Grounding
👥 Hyunho Kook, Junhyuk So, Tianyu Fu, et al.   2608.24024

📋 摘要

用 token logprob 加权的置信度投票在单轮推理中广泛有效，但论文发现它迁移到多轮搜索 agent 时表现很差。根因是 copy inflation：检索文档拼入上下文后，从中复制的 token 会获得系统性膨胀的 logprob，拉平同一问题内的置信度分布，使加权投票失效。为此提出 Retrieval-Grounded Voting（RGV）：用每个 rollout 的最终答案与其检索到的文档之间的词面重叠度打分，该信号在污染上下文之外计算，不依赖 logprob 也不需要额外 LLM 调用。在 4 个搜索 agent 基准、5 个 LLM 上，RGV 稳定优于置信度投票，准确率最高 +5.4%；在仅 1-2/8 rollout 正确的少数派难题上最高提升 +35%。已被 EMNLP 2026 Findings 接收。
💡 机制诊断干净、修复方案极简（词面重叠即可），所有做 agent 投票 / self-consistency 系统的人都该知道的坑位与解法。
