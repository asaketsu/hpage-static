只给目标、工具和算力，冻结的 LLM 智能体能自己发明学习算法实现自我改进

Do LLM Agents Still Need to Be Told How to Self-Improve?
👥 Shobhita Sundaram, Cansu Sancaktar, Phillip Isola（MIT）   2611.23219

📋 摘要

摘要全文（中译）：
LLM 智能体正日益主导自身的学习，自我改进（self-improvement）方法把模型优化的各个环节委托给模型自己完成。随着模型能力增强，一个基本问题随之而来：越来越强的模型还需要人类告诉它们「如何」自我改进吗？本文研究一种自主范式：只给定基本原语、资源和自我改进的总目标，智能体自行构造自己的自学习算法来执行基于上下文的优化。以游戏为测试环境，一个冻结权重的 LLM 智能体获得计算预算、收集经验与更新文本文档的工具，在没有外部强加训练循环、也接触不到真实世界数据的条件下自由实验。结果发现：足够强的模型在这些条件下确实能自我改进，且其策略与经典认知科学的自我调节学习框架、以及机器学习文献中「自生成课程」的构造相吻合。作者进一步考察学到的文本工件（text artifacts）向外部基准的迁移，观察到在不同游戏时长、游戏机制及 3D 导航任务上均有提升。
💡 MIT Isola 组出品。把「如何自我改进」这个元问题本身交给 agent 设计，其自发涌现的策略竟能与教育学/认知科学理论对齐——对自进化 Agent（含我们自己的 Hermes/LangGPT 迭代体系）有直接借鉴意义。
