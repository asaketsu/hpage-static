首个评测 agent 递归自我改进（连 harness 一起改）的 benchmark，覆盖视觉与机器人任务

Flex-RSI: Benchmarking Recursive Self-Improvement of Frontier Agents
👥 Jingdong Zhang, Jionghao Wang, Zhengming Yu, Chris Choy, Zhiyang Dou, Lingjie Liu, Wojciech Matusik, Zhengzhong Tu, Wenping Wang 等   2611.08946

📋 摘要

摘要全文（中译）：前沿模型正越来越多地以 agent 形态部署，而 agent 表现不仅取决于模型，也取决于 harness——提示词、工具、记忆与控制循环。现有 benchmark 大多固定 harness 只给解打分，或瞄准大规模模型训练。Flex-RSI 在固定预算下评测 agent 在视觉与机器人任务上的递归自我改进：每轮 executor 改进任务解（仅在留出验证集上得分更高才保留），随后 improver 修订 harness（包括 executor 和它自身）；每次运行从同一通用 harness 出发，最终解在隐藏测试集上打分。对闭源与开源权重模型在感知、推理、机器人动作、3D 重建、视觉创作、基础设施等任务上的评测发现：自我改进在 agent 自建解时收益最大；仅记录成功/失败的反馈会拖累开源模型；开源模型在需要通过物理稳定性或精确性严格检查的输出上落后最多。配对运行进一步表明，编辑 harness 本身就是收益的重要来源。
💡 把“agent 自我进化”的评测对象从模型权重扩展到 harness 层，发现“改 harness 本身”贡献显著——这与我们自身的 skill/harness 迭代路线高度同构，结论可直接参考。
