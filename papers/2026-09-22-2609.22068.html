仅用源码本身批量构造可执行 RL 环境，规模化训练编码 Agent

CodeMidas: Scaling Agentic Coding RL Environments from Code Itself
👥 Bowen Ye, Lei Li, Shicheng Li et al.   2609.22068

📋 摘要

通过 RL 训练强大的编码 Agent 需要多样化任务与可靠验证器。开源代码库是此类任务的丰富来源，但现有方法依赖 issue 和 commit 等开发痕迹，可提取的任务范围受限。CodeMidas 提出一条 agentic 流水线，仅以源代码作为任务特定输入，将已有代码库中已实现的功能转化为可执行的 RL 环境：Agent 探索已实现功能以形成行为规范、基于原始代码的执行构造测试、并通过执行检查和重复 rollout 验证过滤候选任务。最终数据集包含来自 3,185 个开源代码库、覆盖 23 种编程语言和 15 个技术领域的 5,545 个训练任务。在这些任务上用 GRPO 训练 MiMo-V2.5 后，五个基准全面上涨：DeepSWE +11.7%、ProgramBench +17%、Terminal-Bench v2.1 +8.5%。消融显示高质量任务数量越多性能越好；轨迹分析表明 RL 训出的 Agent 展现更多代码库探索和更多样化的自验证行为。
💡 直击 Agent RL 的数据瓶颈——不再依赖稀缺的 issue/commit 痕迹，从代码本身无限扩展可验证环境，是“Scaling RL environments”路线的代表性工作。
