推理模型跑 agentic 任务要付 3-6 倍 token 溢价，但这份成本可以跨 episode 摊销成可复用技能

Reason Wide, Not Deep: Amortizing the Reasoning Premium into Distilled Skills
👥 Agamdeep Singh, Srishti Gautam, Priyanshu Gupta 等   2608.07885

📋 摘要

摘要全文：
推理模式的语言模型在多步 agentic 任务上优于非推理模型，但每次推理都要付出 3-6 倍的输出 token 溢价——大部分花在反复推导同领域内重复出现的流程上。作者证明这部分重复成本是可以摊销的：一个编程 agent 分析训练集中少量已有轨迹，编译出紧凑的自然语言技能（skill），注入非推理模型的 system prompt。在四个 agentic benchmark（ALFWorld、tau²-bench 电信与零售、SpreadsheetBench-Verified）上，技能帮助 GPT-5.4-mini 在留出任务上恢复了 55%-100%+ 的推理差距，其中两个 benchmark 甚至直接超过推理模式，同时输出 token 减少 2.7-6 倍、推理 token 为零。值得注意的是推理轨迹并非必需：仅从非推理轨迹蒸馏的技能同样有竞争力。作者用"搜索"视角解读——测试时推理是单 episode 内的深度搜索（每次部署都重付），而语料蒸馏是跨 episode 的广度搜索（只付一次），两者恢复的程序化知识高度重叠，在廉价轨迹上做广度搜索往往是更划算的买卖。
💡 直接挑战"推理模型一定更好"的直觉，用数据证明推理溢价可以靠技能蒸馏摊平，且给出清晰的"深度搜索 vs 广度搜索"理论框架。对做 Agent 成本优化的同学极具实操价值。
