首篇以“终端交互”为统一视角的 agent 综述，提出七维终端能力画像

Terminal Agents: A Survey of AI Agents in Command-Line Environments
👥 Yi Bin, Xiaoyang Yuan, Haoxi Zeng 等（共 12 人）   2608.20485

📋 摘要

LLM agent 越来越多地通过终端行动，但现有综述把终端介导的行为分散在软件工程、工具调用和 computer-use 研究中。本综述将 terminal agent 界定为“以终端命令执行、文本反馈和有状态环境交互为主导行动-观察循环”的系统，并以终端介导执行为组织视角，通过七维终端能力画像打通系统架构、能力获取与评估。综合分析表明：实际行为由模型、界面、harness、运行时和环境共同塑造；可执行轨迹让学习锚定在行动后果、验证与恢复上，而现有评测偏重最终结果，对过程质量、恢复和治理的暴露不均衡。固定条件诊断显示不同 benchmark 家族暴露不同的过程信号，组件归因存在 benchmark 依赖的局限。作者呼吁显式报告系统与运行时条件，并以可重放轨迹支撑过程级证据。
💡 52 页系统梳理，Claude Code / Codex 类 CLI agent 开发者的评估体系与 benchmark 选型直接可用。
