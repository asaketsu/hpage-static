摘要

策略熵正则在 PPO 类算法中被默认为单向"防坍缩"工具，其失效模式与有效域边界缺乏系统刻画。本文基于某双足机器人项目 2026-09-19 至 09-21 期间 11 个训练变体的连续失效谱系，提出策略熵失效的双相结构：在同一任务、同一配方下，熵系数 0.01 导致熵坍缩相（熵 19.85→-1.42 穿零，奖励 -99），相邻系数 0.02 导致熵爆散相（熵 9.9→40.7，奖励 -3473 发散），表明熵正则的可行域可被奖励结构变化压空至不可用。进一步，同配方双架构对照显示，带 GTrXL 式 σ-gate 门控的 Transformer 策略在 MLP 连续两次坍缩/爆散期间保持熵 1.47-1.66 稳定，呈现架构免疫。据此提出四象限判别协议（熵×奖励双指标）并落地为 30 分钟质量守护自动化，在后续 6 个变体上实现全部失败在 2 小时 GPU 内被捕获。本工作将 LLM-RL 社区的熵坍缩理论（离散动作）与机器人连续控制工程实践贯通，证明熵正则失效是双相统一体，其管理需机制化而非超参艺术。

关键词：策略熵；熵坍缩；熵爆散；PPO；双足机器人；σ-gate 门控；训练失效分类学

1 引言

1.1 问题背景

策略熵是 PPO[1] 类策略梯度算法中探索行为的量化指标，熵正则（entropy bonus）自 A3C[2] 时代起即为标准配置。2025-2026 年，LLM 推理强化学习（RLVR）社区对熵坍缩（entropy collapse）给出了系统理论解释：Cui 等[3]证明熵变化由优势函数与中心化对数概率的相关性驱动，高概率动作获正优势必然压熵；Petrenko 等[4]（ICLR 2026）进一步提出 REPO/ADAPO 等机制化熵保持方案，并指出数值精度（BF16 ratio 偏置）是隐藏推手；Shen 等[5]观察到常数系数熵正则会引发"长度爆炸"等过度正则失效。

然而，这条理论线几乎全部建立在离散动作空间（LLM 词表采样）之上。机器人连续控制（高斯策略、tanh 压缩、关节力矩）中，熵正则的双向失效——既有坍缩也有爆散——及其与奖励结构、策略架构的耦合，缺乏第一手实证刻画。工程社区流传的"熵系数调参"经验（如 rsl_rl 默认 0.005-0.01）掩盖了一个未被言明的问题：当任务奖励结构变化时，历史健康值是否依然安全？

1.2 命题与案例背景

本文命题：连续控制策略训练中，熵坍缩与熵爆散是同一熵正则机制的两个对立失效相；系数可行域可被奖励结构变化压空；σ-gate 架构门控在同配方对照中免疫；失效相判别须用熵×奖励双指标而非熵单指标。

案例背景：DUCK-Pi_5 双足机器人项目，rsl_rl PPO + mjlab 仿真，2048 并行环境，双架构（MLP / 64 帧滑窗 Transformer）并行的 W5 终结版配方（同一奖励结构：站立 upright + 速度跟踪 track + 对称约束 + 课程化 cmd 指令）。该案例的独特价值在于其天然对照结构：W5 双架构同配方并发，一次训练事故即构成受控对照实验。

1.3 贡献声明

  1. 双相失效分类学：首次在连续控制任务上实证熵正则的双向失效结构——同任务相邻系数（0.01/0.02）分别触发坍缩相与爆散相，并给出六点采样的相轨迹特征（§3.1）。
  2. 可行域压空现象：提出"熵系数可行域"概念并实证其可被奖励结构变化压空——跨奖励结构搬运历史健康值（docs/81 H1T 的 0.02）在 W5 三修奖励下反向失效（§3.2）。
  3. 架构免疫对照 + 判别协议：同配方双架构对照证明 σ-gate 门控对熵双相失效免疫（TRANS 熵 1.47-1.66 vs MLP 崩溃），并提炼四象限判别矩阵与自动化守护协议，落地为 30 分钟质量守护（§3.3-3.4）。

3 方法与分析

3.1 双相失效的实证轨迹

W5 终结版配方（站立 + 速度跟踪 + 对称三修 + cmd 课程）下，MLP 架构连续两次失效构成双相对照：

坍缩相（W5-MLP，entropy_coef=0.01）——六点均匀采样（docs/86 §20，console 真值）：

iter ~0 ~1000 ~2000 ~3000 ~4000 ~5273（判死）
Loss/entropy 19.85 8.68 1.72 0.32 -0.64 -1.42（穿零）
Mean reward +15 峰值 缓降 下坠 负值 -99 持续下坠 判死即杀

爆散相（W5-MLP2，entropy_coef=0.02）——30 分钟守护首战捕获（docs/86 §21）：

iter 0 ~600 ~1200 1717（判死）
entropy 9.99 缓涨 加速 40.7（4 倍爆涨）
reward 0.85 下行 加速 -3473（发散）

两相的机理统一性：熵正则项 β·E[-H] 在 β 过小时被优势梯度完全主导（坍缩，与 Cui 定理预测一致[3]）；β 过大时熵奖励本身成为可 exploitation 的免费分，策略选择"最大化输出分布方差"而非"最大化任务回报"——在连续动作空间中表现为高频抖动（action_rate 罚同项爆涨 9 倍，-0.44→-3.98），return 分布随之突变，MLP critic 追不上引发 value 爆炸（TRANS4 曾实测 value_loss 0.19→52.7[9]）。两相共享同一条级联链：策略分布突变 → return 分布突变 → critic 失配 → 更新方向错误 → 正反馈死循环。

3.2 可行域压空：跨奖励结构搬运失效

关键对照：W1 配方（简单奖励，无三修）在同一任务族上以 entropy_coef=0.01 健康完训——熵同样衰减到 1.66，但 reward 稳定 20+ 至完训（air_time 0.30）。这说明：

  1. 熵低 ≠ 必崩：熵值本身不是充分判死指标，须与奖励联合判读（W1 熵 1.66 健康 vs W5-MLP 熵 1.72 后崩）；
  2. 系数可行域是奖励结构的函数：H1T 任务（docs/81）的 0.02"验证修复值"搬运到 W5 三修奖励下即成爆散毒药。可行域 W1(0.01∈) ⊃ W5(0.01∉ ∧ 0.02∉)——W5 的对称约束三层叠加（mirror loss 0.5 + env action_symmetry 0.3 + hip_yaw_cm 1.5）压缩了熵正则的安全区间，直至无解。

这一现象解释了工程社区"调熵系数玄学"的来源：不是系数本身玄学，而是可行域随奖励结构漂移，而历史健康值不含奖励结构信息。

3.3 架构免疫：σ-gate 门控对照

W5 双架构同配方并发（唯一差异：MLP 带 mirror loss、TRANS 带 σ-gate 门控[7]）：

架构 熵轨迹 reward 结局
W5-MLP (0.01) 19.85→-1.42 穿零 -99 坍缩判死
W5-MLP2 (0.02) 9.9→40.7 爆涨 -3473 爆散判死
W5-MLP3 (0.01+课程延后) 健康中 2.0→向上 在训
W5-TRANS (0.01+σ-gate) 1.47-1.66 全程稳 +15~18 稳升 免疫

机理：σ-gate 在残差支路乘 sigmoid 门（偏置 -2 起步，sigmoid≈0.12 近恒等），抑制了残差支路输出的突变幅度，从而限制了策略分布的每步锐化/发散速度——恰好切断了 §3.1 所述级联链的第一环（策略分布突变）。F1 烟雾实验（从零训练 1500/2500 iter）进一步确认：value 0.03-0.31 全程稳、熵平滑衰减至 0.47 无穿零，代价是学习速度（air_time 0，与 MLP 同病但机理不同——这是任务设计问题非架构问题，见 docs/86 §16）。

需要诚实指出免疫的边界：σ-gate 免疫的是熵双相失效，不免疫任务设计缺陷（F1 烟雾同样走出趴地解）；且 TRANS 在更早版本（TRANS4/5/6，无 gate）死于 value 爆炸型 farming，免疫来源于门控而非 Transformer 架构本身。

3.4 判别协议：四象限矩阵与守护自动化

从双相结构直接推导运维判据——单指标（熵阈值）不可用，须熵×奖励双指标联合判别：

熵方向 × reward reward 稳/升 reward 跌
熵单边降 正常确定性化（W1：熵 1.66+reward 20+） 坍缩相（W5-MLP：熵穿零+reward -99）→ 杀+升系数或换门控
熵单边涨 温和探索（正常） 爆散相（MLP2：熵 40+reward -3473）→ 杀+降系数或换门控

配套工程协议（已落地为 30 分钟 cron 守护，docs/86 §21-22）：
1. 真值源：console 逐 iter "Mean reward" 行为唯一真值；TensorBoard 目录级读入在多 variant 并发时混流（两个 PID 写同一目录事件文件，曾致误诊）；
2. 相判据：熵<1 且 reward 同跌=坍缩；熵>15 且 reward 跌=爆散（过度正则）；ALERT 即杀不等完训；
3. 决策树：MLP3 若在 iter 4000-6000 再崩→卸 mirror loss 由 env 层 action_symmetry 补位（TRANS 实证）；
4. 独立实验目录：多 variant 并发必须独立 experiment_name，否则 TB 混流。

效果量化：11 变体谱系中，守护上线前的失败平均烧 GPU >5h（TRANS4 崩点 ~8500 iter）才被人工发现；守护上线后 MLP2 在 iter 1717（<2h GPU）被捕获即杀，损失压缩一个数量级。

3.5 局限

  1. 单平台（rsl_rl + mjlab）单任务族（双足站立/行走），双相谱系虽完整但样本量为 11 变体，未做跨任务族统计检验；
  2. 爆散相与 mirror loss 过约束的耦合未被完全分离（W5-MLP 两连崩的主因判定为 mirror×三修×课程联合过约束，熵系数是其表达通道）；
  3. σ-gate 免疫只有同配方对照证据，无消融（gate 偏置、位置、数量）；
  4. 未与 REPO/ADAPO/AEnt 在同任务上对照——这三者是"修好熵"的候选，与本文的"判别熵失效相"正交，对比实验是后续工作。

4 案例验证

本论文全部实证材料取自本周笔记群与项目文档，形成证据闭环：

  • 熵坍缩理论线：笔记《熵保持强化学习与PPO熵坍缩修复》（09-19，arXiv 2603.11682 精读）提供 REPO/ADAPO 理论框架与"it's not the destination, it's the journey"熵轨迹判据；
  • 跨域结构线：笔记《Agentic-RL训练配方全景》（09-14）证实"训练-推理失配、FP32 输出头修熵坍缩"已进入 LLM-RL 工程配方库，佐证熵失效是跨域共性问题；
  • 实战谱系：docs/80-86 七篇事故解剖（H1T 熵坍缩 → TRANS4/5/6 value 爆 → F1 σ-gate 烟雾 → W5-MLP 双相 → MLP3 修复）构成完整失效-修复链；
  • 同代文献面：笔记《Transformer策略训练稳定性》（09-21）扫描证实"熵坍缩+PPO"2026 年命中几乎全部来自 LLM-RL，机器人侧无人以熵动力学为核心贡献——这正是本文填补的空白。

四线独立收敛：熵正则失效需机制化管理，不是超参艺术[3][4][5]，而机器人侧的机制化第一步是失效相的准确判别（本文），第二步才是熵保持算法的移植（REPO/ADAPO/AEnt 在连续控制的适配，后续工作）。

5 结论与展望

本文以 11 变体连续失效谱系为材料，提出并实证了连续控制策略熵失效的双相结构：(1) 坍缩相与爆散相是同一机制的对立表达，同任务相邻系数可分别触发；(2) 熵系数可行域是奖励结构的函数，跨结构搬运历史健康值可致反向失效；(3) σ-gate 门控在同配方对照中对双相失效免疫，免疫源是门控而非 Transformer 本身；(4) 四象限双指标判别协议 + 守护自动化可将失败捕获时间压缩一个数量级。

展望：①将 REPO/ADAPO 式优势函数改造移植到 rsl_rl 连续控制，替代脆弱的系数调参；②爆散相与过约束耦合的分离实验（mirror off 网格）；③σ-gate 消融与蒸馏路线（MLP 冠军教师→TRANS 学生）的结合。局限如 §3.5 所列，结论边界仅限同任务族谱系证据。
