长程工具调用 Agent 的 RL 训练框架 SINKFLEX-RL，集成 GRPO 与 sink-aware FlexAttention，峰值显存直降约 20%

Efficient Reinforcement Learning for Long-Horizon Tool-Use Agentic Tasks
👥 Zelei Cheng, Amritansh Mishra, Sambit Sahu, William Campbell et al.   2608.10357

📋 摘要

摘要全文：
长程工具调用 Agent 需要推理用户目标、领域策略、工具调用、仿真器状态以及延迟可验证奖励。强化学习是此场景的天然契合点，但多轮 on-policy rollout 会产生超长上下文，同时模型特定的注意力层可能需要自定义掩码和习得的 sink 归一化。

作者提出 SINKFLEX-RL，一个用于双控制工具调用环境的模块化 RL 训练系统。该系统整合了：Gymnasium 兼容的环境包装器、VERL 风格的 rollout 数据流、无需独立 value 模型的组相对策略优化（GRPO），以及一条 sink 感知的 FlexAttention 路径——旨在因果掩码和滑动窗口掩码下保留模型特定的 sink 缩放。

在初步的 Tau2Bench 零售任务实验中，验证奖励（mean@1）从训练早期的 0.25 上升到观测窗口后期的 0.44，训练分数和轨迹奖励代理指标也呈上升趋势。在固定配置的内存基准中，优化后的注意力路径将 4096 token 配置的峰值 VRAM 从 28.06GB 降至 22.52GB（降低 19.7%），并在 8192 token 配置中以 25.53GB 运行——而 eager 基线在该配置下直接内存溢出。
💡 工程实用性强，把环境接口、RL 数据流、注意力内核设计三者打通，解决了长程 Agent RL 训练中最实际的显存瓶颈，GRPO + FlexAttention 的组合值得复现。
