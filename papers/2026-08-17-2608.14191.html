用经典变换编码理论做 KV cache 压缩，5.8 倍压缩率下精度几乎无损

KV Cache Compression Through the Lens of Transform Coding
👥 Hannah Laus, Claudio Mayrink Verdun, Hao Wang et al.   2608.14191

📋 摘要

摘要全文：KV cache 存储历史 token 信息，是长上下文推理的主要内存瓶颈。现有量化方法以统一低精度数据类型表示 KV cache，并设计量化方案以最小化 cache 本身的重建误差，但未考虑该误差如何经 attention 机制传播。本文证明：在白噪声量化模型下，期望的 attention 感知失真可分解为 key 和 value 的可加贡献，并可跨 token 和 channel 因子化。基于变换编码和逆注水（reverse water-filling）这些信号处理与率失真理论的经典工具，提出 Attention-Aware Transform Coding（AATC），在校准集上分配比特以最小化 attention 感知失真。在 Llama-3.1-8B-Instruct 和 Qwen-2.5-7B-Instruct 上，经 LongBench、RULER、GSM8K、MMLU-Pro、MATH-500 评测，该方法在约 5.8 倍压缩下实现近无损精度，而所有基线方法至少在某些设置下出现退化。
💡 把 rate-distortion 理论严谨地引入 KV cache 压缩，有可证明的失真分解定理 + 全面基准，5.8x 近无损对长上下文边缘部署是实打实的收益。
