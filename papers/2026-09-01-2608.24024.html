多轮搜索 Agent 上置信度投票失效，用“答案与检索文档的词面重合度”投票反而大涨

Beyond Confidence: Test-Time Scaling for Multi-Turn Search Agents via Retrieval Grounding
👥 Hyunho Kook, Junhyuk So, Tianyu Fu, Haizhong Zheng, Beidi Chen   2608.24024

📋 摘要

摘要要点：基于置信度的投票（用 token log 概率加权聚合并行 rollout）在单轮推理上被广泛研究，但现代 LLM 越来越多地作为多轮搜索 Agent 运行。本文发现置信度投票迁移到多轮场景效果很差，根因是 copy inflation：检索文档拼进上下文后，从文档复制的 token 获得系统性膨胀的 log 概率，拉平了每题内的置信度分布，削弱加权投票。提出的 Retrieval-Grounded Voting（RGV）改用“最终答案与其检索到的文档之间的词面重合度”给每个 rollout 打分，信号在污染上下文之外计算，无需 log 概率也无需额外 LLM 调用。在 4 个搜索 Agent 基准 + 5 个 LLM 上，RGV 一致优于置信度投票，精度最高 +5.4%，少数派正确题（8 个 rollout 中仅 1-2 个对）上 +35%。
💡 诊断出 RAG Agent 自我评估失效的精确机理（copy inflation）并给出零成本解法，对所有做 Agent 采样/投票系统的人是必读的坑位指南。
