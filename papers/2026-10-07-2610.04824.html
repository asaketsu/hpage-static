agent 行为写成确定性程序，FM 只负责改程序——鲁棒性反升，成本降 5-9.5 倍

Agent Behavior as Code: Efficient and Robust LLM Agents with Programmatic Specifications（ABCAgent）
👥 Peng Qi, Chunliang Lyu, Gang Li, et al.   2610.04824

📋 摘要

摘要全文：基于基础模型的 AI agent 面临三大共性挑战：(a) 语义相似的任务间 agent 行为剧烈偏离，错误灾难性传播；(b) FM 调用成本与延迟高，同一任务换输入重现时每次全量重跑；(c) FM 上下文与指令遵循能力有限，制约长上下文管理与复杂计划执行。作者提出 ABCAgent：用符号程序（含神经函数的 Python 代码）在运行时完整刻画 agent 行为，由强 FM agent 编辑该程序获得灵活性——行为不做过早变量绑定，执行确定性。在六个 agent 基准上评估（含两个自建的变体泛化测试），ABCAgent 在 GAIA 与增强 GAIA 上与模型对等的神经 agent 持平，在鲁棒性与长控制流场景显著胜出：GSM-Symbolic 98.3% vs 97.3%（p=0.001）、τ²-bench 电信域 Pass⁴ 71.9% vs 47.4%（p=0.0001）、控制流增强 WorkArena 上每个循环长度写入的正确记录都更多。对参数化任务族效率优势显著：不新写程序即解决 GSM-Symbolic 92.6% 实例与增强 GAIA 变体 20.1%，GSM-Symbolic 延迟降 5.2×、成本降 7.0×，增强 GAIA 成本降 19%，τ²-telecom agent 延迟降 9.5×。
💡 与你 9 月定调的元趋势「工程知识的显式契约化」完全同构——达索/ROSClaw/EBTO 之后，Agent 行为契约化（behavior-as-code）也独立收敛到同一方向，且给出了 5-9.5× 成本数据背书。
