KV 状态块级落盘复用，50M token 流免重算

Real Long-Term Memory for AI: A 50-Million-Token Window That Is Faster and Cheaper Than Recompute
👥 Sietse Schelpe   2610.10845

📋 摘要

摘要全文：LLM 只能用上下文窗口内的文本，且每次发送 prompt 都要重算 KV 状态。本文测试记忆层 galahad-kv（公开包）：将每约 1.6 万 token 块的 KV 状态加密存到本地 NVMe 磁盘，之后按字节精确加载而不重算。在 5000 万 token 真实公开文本上、单张 H100 + vLLM、Gemma 4 12B 与 31B 验证：探测的每个块都从加密存储零重算加载回（100/100，深度覆盖 0 到 50M）。加载比重算快 2.8-4.3 倍、GPU 能耗省 8.8-12.3 倍，且整个 50M token 流中 GPU 显存保持平稳。对数百万 token 前植入的事实提问，12B 模型 100 次答对 82 次、31B 答对 98 次，均未编造答案。限制：这是存储状态复用而非更宽的注意力窗——一次只加载一个块，回答质量取决于模型；写入是一次性成本，存储需 TB 级 NVMe。测试协议专门抵御长上下文基准的常见作弊方式，给出单 GPU 可复现方案。
💡 为“长程记忆=持久 KV 态而非重算”给出迄今最大规模的公开压测数据（能耗/显存/事实召回三维），对 Agent 记忆基础设施选型是硬数据。
