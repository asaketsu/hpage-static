记忆 Agent 的检索/写入/停止三决策统一进一个奖励空间，用过程奖励 RL 端到端优化

All-in-One Memory: Process-Rewarded Reinforcement Learning for Memory Agents
👥 Bingbing Wang, Jingjie Lin, Weiming Qiao, et al.   2610.21147

📋 摘要

摘要要点：LLM 依赖外部记忆处理多轮对话和长文档，但现有方法把检索和记忆构建分开优化，缺少统一评估搜索、写入、停止决策的奖励空间。AiO-Mem 把这些操作建模为共享证据状态上的状态转移，将异构历史编译成可溯源的多视角事件作为公共底座；统一记忆策略在该状态上滚动完整交互轨迹；另训一个轨迹条件的过程奖励模型（证据接地 SFT + 轨迹级 DPO）为轨迹打过程分，聚合为动作平衡的轨迹奖励，再用 PA-DAPO 优化记忆策略。长上下文记忆基准上，答案准确率稳定超过静态记忆系统和 RL 训练的记忆 Agent。
💡 把「记忆操作 = 序列决策 + 过程奖励」的形式化很干净，PA-DAPO 是 DAPO 在 Agent 动作空间上的新变体，对做长程 Agent 训练的配方有直接参考价值。
