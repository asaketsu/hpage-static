免训练在线压缩 agent 历史推理，token 省 25% 奖励反升

When Can Agents Forget Their Reasoning? ICLR for Long-Horizon Agent Context Compression
👥 Mingxuan Wang, Fei Luo, Bo Wang, et al.   2609.29875

📋 摘要

长程 agent 持续累积推理历史，即使早期决策已执行并观测，上下文长度与推理成本仍在增长。与静态 CoT 压缩不同，删除历史推理会改变后续动作与交互轨迹。本文研究何时可以安全遗忘推理，提出 Interaction Aware Compression for Long Horizon Reasoning（ICLR）：一种免训练的在线方法，用冻结代理熵对推理块排序，同时完整保留动作、工具调用与观测。在 260 个 WorkBuddyBench 任务上，ICLR 将平均奖励从 0.699 提升至 0.718，同时输入、输出、缓存读 token 分别下降 25.5%、14.4%、33.3%。消融揭示了“轨迹放大”现象：局部删除推理会通过改变后续交互非线性地改变总计算量。表征探针、激活修补与受控轨迹分析进一步表明：一旦任务相关的派生状态被可靠外化到代码、文件、工具输出或环境反馈中，历史推理就变得可替换。这些结果将 agent 推理刻画为动态工作状态，而非永久的交互历史。
💡 方法零训练成本、即插即用，token 全面下降的同时奖励不降反升，并给出“何时可安全遗忘”的可操作判据（派生状态已外化），对长程 agent 的成本控制极具落地价值。
