发现推理模型会“回访”早期思路 token，据此实现免训练 KV cache 压缩

BeaconKV: Key-Value Cache Compression Guided by Beacon Queries for Efficient Large Reasoning Model Inference
👥 Janghyeon Kim, Minsoo Kim, Kyuhong Shim et al.（ICML 2026，已开源）   2609.04971

📋 摘要

大型推理模型（LRM）依靠长思维链获得强解题能力，但 KV cache 随序列长度线性增长，长推理轨迹常超出 GPU 显存。现有压缩方法依赖近期 query 估计未来 token 重要性，隐含假设其能代表未来注意力模式。本文证明该假设在长程推理中失效：某些解码步会产生“思路回访 token”（TRT），重新关注远处上下文（如推理早期制定的解题计划）。系统分析发现 TRT 对应的 query 在嵌入空间聚成少量相似组，据此提出 BeaconKV——一种免训练压缩方法，为每个全局 query 簇维护紧凑的“信标 query”，在不存储完整 query 历史的前提下预判哪些 KV 会被回访。在四个开源 LRM 和多样推理基准上，BeaconKV 普遍优于现有压缩方法，最高实现 5.8 倍显存压缩，几乎保持全 cache 精度，吞吐提升超 4.3 倍。
💡 对推理模型注意力行为提出了新洞察（TRT 聚类现象），免训练即插即用，已中 ICML 2026 且代码开源，长推理部署可直接受益。
