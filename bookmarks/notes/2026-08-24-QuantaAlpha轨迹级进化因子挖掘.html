内容整理：论文核心内容还原

1. 要解决的三大数据挖掘顽疾

论文对现有 LLM 因子挖掘 Agent（RD-Agent、AlphaAgent 等）的诊断：

  • 脆弱可控性: 迭代精炼由噪声回测反馈驱动，诱发语义漂移（semantic drift），逐渐偏离预期经济机制、滑向伪相关
  • 有限可信度: 依赖瞬态上下文的随机再生成，不显式继承跨迭代的已验证推理链，因子缺谱系、难审计
  • 受限探索: 搜索过度开发初始种子邻域 → 因子拥挤（factor crowding），对更广假设空间系统性覆盖不足

2. 核心抽象：把挖掘运行形式化为轨迹

  • 一次运行 = 一条轨迹 τ = (s₀, a₀, s₁, a₁, …, sₙ)，s₀ 是初始市场上下文，aᵢ 是多 Agent 系统第 i 步动作，sₙ 含回测结果
  • 轨迹奖励 R(τ) = L(f_τ(X), y) − λ·R(f_τ)：预测效用 − 正则项（鼓励简洁+新颖）
  • 优化目标：找轨迹生成机制 π 最大化 E[R(τ)] —— 即进化的是"怎么挖"，而不只是"挖出的因子"

3. 单条轨迹的挖掘流程（多 Agent 分工）

假设生成（idea agent）: 结构化整合三路输入——市场观察、金融理论先验、参数规格（如"10日高低点"），产出可操作的市场机制假设

可控因子构建（factor agent）:
- 不直接生成代码（易碎：语法错误/依赖错配/语义漂移），而是经过算子库 + AST 中间表示
- 假设 h → 结构化语义描述 d（映射到离散算子+实例化窗口阈值）→ 符号表达式 f → AST T(f) → 编译为代码 c；编译失败触发 LLM 修复
- 语义一致性验证: LLM verifier 双向校验 h↔d↔f 对齐 + f↔c 忠实性，不过则重写直到通过或重试预算耗尽
- 复杂度控制: C(f) = α₁·SL(f) + α₂·PC(f) + α₃·log(1+|F_f|)（符号长度+自由参数数+原始特征数）
- 冗余控制: 与已有因子库 Z 做 AST 最大同构子树匹配 S(f)=max s(f,φ)，超限拒绝重写——结构性防因子撞车

回测评估（evaluation agent）: 标准化回测（预测力 IC/ICIR + 收益 ARR/IR + 风控 MDD/CR），并维护评估历史、总结成败因子的系统性规律

4. 进化机制：Mutation + Crossover

多样化规划初始化: 初始化 agent 生成 10 个互补研究方向（信号源价格vs量能 / 时间尺度短vs长 / 机制类型动量vs均值回归vs状态条件触发），扩大初始搜索前沿、防过早收敛

Mutation（变异）:
- 自我反思定位最差决策节点 k（对低终端奖励贡献最大的步骤）
- 只重写 a_k（或短局部段），冻结前缀 s₀…s_k，后续步骤在固定前缀条件下重生成保持轨迹连贯
- 重写可作用于假设层/符号表达式层/代码层，可引入机制级变化（改时间尺度、加状态条件）

Crossover（交叉）:
- 按轨迹奖励选父代集合，识别持续贡献高累计奖励的片段（假设模板/构建模式/修复动作），重组为单一连贯子代
- 显式继承已验证决策 → 可信谱系（lineage），模仿人类"取长补短"

5. 关键实验结果（CSI 300，2022-2025 四年测试期）

GPT-5.2 驱动的对比（IC / ARR / MDD）:

  • RD-Agent: 0.0531 / 9.91% / 14.82%
  • AlphaAgent: 0.0966 / 15.54% / 12.89%
  • QuantaAlpha: 0.1501 / 27.75% / 7.98%
  • 相对 RD-Agent：IC +0.0970、ARR +17.84pp、MDD −6.84pp；相对 AlphaAgent：IC +0.0535、ARR +12.21pp、MDD −4.91pp
  • 跨底座一致（Qwen3-235B/Deepseek-V3.2/Gemini-3/Claude-4.5 全部领先），证明增益非模型特定
  • 深度学习最强基线 TRA 仅 IC 0.0421 / ARR 6.81%——被全面碾压

消融（各拆一个组件）:
- 去 Mutation：IC 掉 0.0292（最大跌幅）、ARR 掉 9.81pp → 变异是有效探索与轨迹修复的主驱动
- 去 Planning：IC 微降但 ARR 掉 7.78pp、MDD 升 2.73pp → 多样化初始化主要稳住策略层表现
- 去 Crossover：较小但一致的退化 → 负责继承已验证模式、提升效率与稳定性

跨市场迁移: CSI 300 挖出的因子直接用于 CSI 500 / S&P 500，4 年累计超额分别 160% / 137% —— 分布漂移下强鲁棒性的证据

6. 工程配置（附录 B 摘录）

  • 进化：5 轮迭代，每轮 Mutation→Crossover 交替；每假设生成 3 个因子表达式
  • 因子硬约束：符号长度 ≤250 字符、基础特征 ≤6、自由参数比 <50%
  • 下游模型 LightGBM；组合构建 TopkDropout（topk=50，每期换 5 只，等权）
  • 交易成本：买 0.05% / 卖 0.15%（含印花税）；次日开盘价成交；涨跌停阈值 9.5%
  • 算子库六类：时序（TS_MEAN/TS_RANK/TS_CORR 等 18 个）、横截面（RANK/ZSCORE 等）、数学、技术（SMA/MACD/RSI/REGBETA）、逻辑、辅助

7. 案例研究（附录 C）

因子 Institutional_Momentum_Score_20D 的 Crossover 诞生记:
- Parent 1 假设：识别散户投机驱动的"脆弱动量"
- Parent 2 假设：识别机构活动支撑的"可持续动量"
- LLM 不是平均两家的因子表达式，而是合成统一的新假设（捕捉真正新颖的市场动力学），再走完整构建+回测流程

归纳总结：核心发现提炼

  1. 轨迹是比因子更优的进化单元: 直接进化因子表达式会陷入噪声驱动的语义漂移；把"假设→构建→评估"整条链作为遗传对象，变异定位到具体失误步骤、交叉继承已验证片段，才同时获得可控性、可信谱系和探索广度
  2. 防拥挤必须做结构级度量: AST 最大同构子树相似度 + 复杂度三元正则（长度/参数/特征），比收益相关性去重更能拦住"换皮因子"
  3. Mutation > Crossover > Planning 的贡献序: 消融数据明确——针对性修复（变异）贡献最大，重组继承次之，多样化初始化主要稳住回撤
  4. 中间表示是语义一致性的锚: 假设 h ↔ 语义描述 d ↔ 符号表达式 f ↔ 代码 c 四层链路 + LLM verifier，把"自由生成"变成"锚定编译"，这是所有 Agentic 系统对抗语义漂移的通用解
  5. 跨市场正迁移是鲁棒性硬证据: A 股挖的因子零适配直接跑美股还有 137% 四年超额，说明进化学到的是机制而非市场特定套路

趋势判断：方向与影响

  • "自进化 Agent × 量化"从 2025 的多 Agent 协作范式，收敛到 2026 的轨迹级进化范式: FactorMiner、AlphaAgentEvo、QuantaAlpha 三个月内密集出现，方法关键词从 debate/memory 转向 mutation/crossover/lineage——与 AlphaEvolve → CSE（可控自进化）一脉相承
  • 可解释性成为硬通货: 论文反复强调 lineage 可审计、AST 透明、显式假设——监管趋严（尤其 A 股程序化交易新规）下，"能讲清楚因子从哪来"与"因子赚钱"同等重要
  • LLM 底座差距被框架放大而非抹平: 同框架下 GPT-5.2 vs Qwen3-235B 的 IC 差 0.025，说明进化框架对强底座有杠杆效应——框架红利与模型红利叠加
  • 对个人量化的启示: TopkDropout+次日开盘+真实费率的回测协议已经是社区标准；下一步差异化在"经验复用层"——谁能把每次回测失败变成可继承的轨迹片段，谁的迭代速度就快一个数量级

指南分析：可操作清单

  1. 想复现论文水平: 底座选最强可用模型（本机语境=智谱 GLM 系列），框架增益对底座有杠杆；5 轮 Mutation→Crossover 交替、每假设 3 表达式是论文验证过的甜点配置
  2. 因子硬约束照抄: ≤250 字符、≤6 特征、自由参数比 <50%——简洁性正则贡献了防过拟合的大头，代价为零
  3. 回测协议对齐再比较: 与任何因子论文对比前，先核对成交价（次日开盘）、费率（0.05%/0.15%）、涨跌停处理（9.5% 阈值）三项，口径不一致的对比无意义
  4. 进化学 Agent 的通用配方: 冻结前缀+局部重写（Mutation）解决"越改越乱"；继承已验证片段（Crossover）解决"重复造轮子"；多样化初始化解决"集体撞车"——三件套可迁移到任何迭代优化型 Agent（含本机 skill 进化）
  5. 迁移测试是照妖镜: 本地有效的因子，先在相邻市场/相邻指数零适配跑一遍，正迁移才可信——这是比样本外测试更狠的鲁棒性检验
