为什么选这个第一项目

第一个项目不要做机械臂、无人机或智能小车。更适合新手的是一台 USB 供电的桌面环境信息终端：

  • ESP32-S3 开发板
  • 温湿度传感器
  • 一块小型显示屏
  • 一个旋钮或几个按键
  • 通过 Wi-Fi 获取时间或天气
  • 最后为它设计 PCB 和 3D 打印外壳

为什么选它：可以练到输入、显示、传感器、联网、PCB、焊接和结构设计，同时避开市电、锂电池、大电流电机和射频天线等高风险问题。

六步实战路线（总周期 6~10 周）

第一步：补最少量的电子基础（1~2 周）

学什么：电压、电流、电阻、功率、欧姆定律、串并联、分压、上拉和下拉、LED 限流、电容去耦，以及二极管、三极管和 MOSFET 的基本用途。

同时练习：面包板、烙铁和万用表（至少会测电压、电阻和通断）。

学习资料：
- 📺 洋桃电子《极速入门数模电路》(B站)：中文零基础入门
- 📖 All About Circuits 免费电子学教材（allaboutcircuits.com）：按需查阅
- 📄 SparkFun 万用表教程（PDF）

✅ 完成标准：能在面包板上搭出 LED、按键和简单三极管电路，并用万用表排查连接错误。

第二步：学会使用 ESP32（2 周）

练习顺序（严格按此序）：
1. 点亮 LED
2. 读取按键
3. 使用 PWM 调光
4. 读取 I²C 传感器
5. 驱动 SPI 显示屏
6. 连接 Wi-Fi，请求一个 API

学习资料：
- Arduino Learn（docs.arduino.cc/learn）：GPIO、PWM、I²C 和基本程序结构
- 乐鑫 Arduino-ESP32 官方入门（docs.espressif.com）
- DFRobot ESP32 系列教程（wiki.dfrobot.com）

✅ 完成标准：开发板可以同时读取传感器、刷新屏幕、响应按键并联网。

第三步：做出面包板原型（1 周）

把此前练过的功能组合起来，做出桌面环境信息终端的面包板版本。先确认所有模块可以稳定工作，再开始画 PCB。

⚠️ 关键工程经验：固件中尽量少用长时间的 delay()，改用时间戳和状态管理，确保设备连续运行数小时不会卡死。

✅ 完成标准：所有目标功能都已经在模块连接状态下得到验证。

第四步：设计第一块 PCB（2~3 周）

工具选择：在国内打样选嘉立创 EDA；如果更看重开源和长期迁移能力，选 KiCad。选一套即可，不要同时学两套。

学习资料：
- 嘉立创 EDA 专业版快速入门（prodocs.lceda.cn）
- 嘉立创 EDA 官方视频教程（视频页）
- KiCad 9 官方入门教程（docs.kicad.org）
- Phil's Lab（YouTube）：PCB 和嵌入式项目实战

⚠️ 关键经验：第一块 PCB 不要直接使用 ESP32 裸芯片。更稳妥的做法是设计一块开发板底板，把传感器、显示屏、按键和连接器整合到板上。

下单前检查清单：元器件型号、封装尺寸、连接器方向、电源脚、去耦电容、安装孔、ERC 和 DRC。

✅ 完成标准：得到一块可以生产、焊接和调试的 PCB。

第五步：焊接和调试首板（1 周）

首板固定上电顺序（严格按此序）：
1. 不通电检查短路、虚焊和器件方向
2. 检查电源对地电阻
3. 上电后测量 5V 和 3.3V 电源轨
4. 确认主控可以下载程序
5. 验证按键和串口
6. 逐个启用传感器、屏幕和网络

⚠️ 核心原则：每次只增加一个变量，不要在所有模块同时启动时排查整机故障。

✅ 完成标准：PCB 可以独立运行面包板原型的全部功能。

第六步：设计外壳（1~2 周）

使用 Onshape CAD Basics（教育版）学习草图、尺寸约束、拉伸、倒角、壳体和装配。

设计重点：PCB 安装孔、螺丝柱、USB 和屏幕开孔、壁厚、打印公差、内部走线空间、装配顺序。

3D 打印问题查 Teaching Tech（teachingtechyt.github.io）。

✅ 完成标准：PCB 能装入外壳，所有接口可用，别人拿到设备后可以直接体验。

第一轮采购清单

物品 备注
ESP32-S3 开发板 主控
面包板 + 杜邦线 原型验证
常用阻容 LED 限流/去耦

❌ 暂时不买：示波器、3D 打印机。先完成第一遍闭环再考虑。

完整闭环目标

面包板功能可用
  → 固件稳定运行
  → PCB 完成并打样
  → 首板成功上电
  → 外壳可以装配
  → 别人可以直接体验 Demo

对零基础开发者来说，最重要的不是一开始学得足够全面，而是先完整做出第一件东西。

结合最新研究与技术变化

1. 与 ESP32 嵌入式开发方向的关联

这篇文章的学习路线与你的 embedded-firmware-dev Skill 和 esp32-unit-test-mock-setup 高度互补。关键差异：本文强调"从面包板到 PCB 到外壳的完整闭环"，而 Hermes 的 ESP32 Skill 更偏底层固件（FreeRTOS/ESP-IDF）。两者结合 = 从原型到产品的全栈路径。

2. 与 ESP32-FluidBox 项目的关联

ESP32-FluidBox（ESP32-S3 上跑 3D 粒子模拟+AMOLED 渲染）是本文"第二步"的极端版本——它把 ESP32 的双核分工、DMA 双缓冲渲染推到了性能极限。但 FluidBox 跳过了 PCB 设计和外壳，而本文的闭环包含了这两步。

3. 与 OttoClaw 项目的关联

OttoClaw（ESP32-S3 AI 人形机器人）正是本文建议"第一轮不做"的机械臂类型。本文的判断是对的：先做简单闭环建立信心，再做复杂项目。

4. 与 dual-mcu-robot-architecture 的关联

本文的 ESP32-S3 单芯片方案适合入门。等你走完 6 步闭环，下一步可以考虑双 MCU 架构（ESP32 + STM32 分工），进入更复杂的机器人控制领域。

学习进化借鉴点

洞察 可借鉴到 说明

delay() → 状态管理 固件设计 避免长时间阻塞，确保连续运行不卡死
闭环思维 目标设定 不是"学会硬件"而是"做出一件完整的可展示 Demo"

趋势判断

  1. AI 辅助学习路线设计——这篇文章明确标注 "Made with AI"，Codex 为零基础开发者生成了完整的学习路线。AI 在教育领域的价值不仅是答疑，而是路线规划。
  2. ESP32-S3 成为零基础入门标配——价格低、USB 供电、Arduino 生态、Wi-Fi+BLE 一应俱全，正在取代传统的 STM32 入门板。
  3. 国内 PCB 打样链路成熟——嘉立创 EDA + 打样一站式，从设计到收板只需几天，大幅降低了硬件 DIY 门槛。
  4. 软件开发者跨界硬件——随着 AI 辅助工具普及，越来越多的软件开发者开始涉足硬件 DIY，形成"软硬兼施"的新趋势。
  5. 闭环优先——"先完整做出第一件东西"的方法论正在成为共识，取代传统的"先学完理论再实践"。
