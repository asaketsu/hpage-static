### 1.1 市场现状（截至2026年8月）

2026国产AI芯片已过"对标英伟达先进算力"阶段，开始从"能用"走向"好用"：

| 亮点 | 数据 |
|------|------|
| 华为昇腾910C | FP16约800T，通用算力达H200的60-70%；950披露支持FP4 |
| 寒武纪思元690 | FP16破700T，196GB HBM3显存超H200 |
| 阿里平头哥真武M890 | 144GB显存/800GB/s互联，可128卡拧成一台计算机，出货已超56万片 |

**核心论断**：**选型最大的坑不是参数，是生态**。代码迁移几个月、算子库缺东少西才是真实差距。

### 1.3 三阵营象限图（技术开放度 × CUDA兼容性）

**右上「兼容迁移派」**（CUDA兼容度高 + 技术开放度高）：海光、摩尔线程、沐曦、壁仞

- CUDA代码改几行就跑，迁移成本最低
- 海光唯一AMD CDNA授权路线（HIP源码级兼容，算子覆盖99%+）
- 摩尔线程MUSA宣称100%兼容，PyTorch全量算子支持
- **缺点**：生态跟随英伟达节奏，架构自主性弱

**右下「自主生态派」**（不兼容CUDA + 技术开放度高）：华为昇腾、阿里平头哥

- 建全栈自研闭环：昇腾=达芬奇+CANN(2025开源)+MindSpore；平头哥=真武+倚天CPU+ICN Switch+阿里云
- 万卡集群最成熟的是昇腾，信创政务首选
- 平头哥靠"芯云模一体"打入政企金融，上升势头猛
- **适合**：全新从零项目，长期自主可控

**左下「专用封闭派」**（低开放性 + 低兼容性）：寒武纪、昆仑芯

- AI专用芯片，推理能效比极强
- 思元690字节部署>10万张，昆仑芯深度绑定飞桨
- **缺点**：生态封闭、无通用图形能力
- **适合**：纯推理集群 + 自家框架深度绑定

### 1.4 出货格局：一超多强

| 梯队 | 厂商 | 预期出货 | 份额 |
|------|------|----------|------|
| **断层第一** | 华为昇腾 | 130万张+ | ~30%(单一品牌),摩根预测62% |
| **黑马第二** | 阿里平头哥 | 60万张 | 真武首次大批量外供(电信/浦发等400+客户) |
| **缠斗第三** | 寒武纪/海光/昆仑芯 | 各20-25万张 | 第二梯队 |

**总结**：昇腾一超、平头哥黑马、多强缠斗。国产算力从"备胎"正式走向"主角"。

### 1.5 三个快速决策建议

1. **存量CUDA代码多** → 兼容派（海光/摩尔线程/沐曦），几天迁移跑通
2. **全新项目+极致算力/信创** → 昇腾（生态最完整/集群最成熟）或平头哥（云上协同性价比高）
3. **纯推理服务+成本敏感** → 寒武纪/昆仑芯（推理吞吐和能效比舒适区）

**金句**：国产GPU选型，选的是生态不是参数。参数差距可以用集群堆出来，生态差距只能靠时间熬出来。

### 2.2 使用性评估

**很强**：作为选型入门地图极好——三阵营象限图直观理解生态差距 vs 参数差距；三个决策建议可直接抄。

**需注意的数据点**：
- 算力均为"厂商公布峰值"，非实测吞吐——实际训练吞吐通常只有峰值的30-50%
- "摩尔线程100%兼容CUDA"是宣传口径，社区有争议（部分算子需适配）
- "海光唯一AMD授权"——AMD对CDNA授权的持续性和范围未说明
- 出货数据综合"多家机构口径"，具体来源未列

### 2.3 指导性意见

- **我们局域网的A100怎么选位置？**——8×A100目前性价比最优（生态成熟+算子完备+文档丰富），短期无需替换。但如果团队以存量CUDA业务为主且追求自主可控，海光DCU是最平滑迁移路径
- **LAN-GPU-Farm扩展方向**：如果未来要扩容A100以外的卡做负载均衡，兼容派（海光/摩尔线程）可以无缝接入现有CUDA管线；自主派需要重写算子层
- **昇腾生态趋势最强**：CANN全面开源+万卡集群经验→2027-2028可能是最佳替代窗口期
- **平头哥值得关注**：真武M890+倚天CPU+ICN Switch构成硬件级的"垂直整合"（类似Apple M系列策略），在"芯云模一体"赛道独特
- **寒武纪/昆仑芯适合专机专用**：如果纯推理服务（如每天固定时间做文献摘要+模型调用），这两家的推理能效比优势可以直接变现为电费节省
- **避免的坑**：不要只看FP16/FLOPS数字——实际价值取决于你的LLM推理/微调需要的精度（BF16/FP8/INT8）、通信带宽（NVLink/IB）、以及算子覆盖度

### 2.4 案例可寻

- 寒武纪思元690被字节部署超10万张——大规模AI推理的国产方案实证
- 平头哥真武系列出货56万片+超六成卖给体系外客户——证明国产算力已能独立商业交付
- 昇腾910C通用算力达H200的60-70%——国产卡的硬指标已经不在同一个数量级了

### 2.5 使用方法借鉴

```
选型决策树：
├─ 存量CUDA代码？
│   ├─ 是 → 兼容派：海光(HIP最全)/摩尔线程(MUSA最激进)
│   └─ 否 ↓
├─ 信创/政务合规要求？
│   ├─ 是 → 昇腾(CANN开源+万卡集群)
│   └─ 否 ↓
├─ 云端优先还是本地？
│   ├─ 云 → 平头哥(芯云模一体)
│   └─ 本地 ↓
├─ 纯推理 or 训练+推理？
│   ├─ 纯推理 → 寒武纪/昆仑芯(能效比)
│   └─ 训练+推理 → 昇腾 或 继续用A100(生态最优)
```

## 三、查询拓展

1. **A100与国产卡的衔接时序**：当前A100仍然是生态王者，但2027年后国产卡（特别是昇腾950、平头哥真武二代）可能成为高性价比替代。保持关注CANN/MindSpore的生态成熟度
2. **海光HIP兼容性验证**：如果考虑迁移，先拿一个中等规模CUDA项目（比如我们的a100-training-playbook的vram_calc.py）在DCU上编译验证，确认算子覆盖率再决定
3. **国产智算中心投资趋势**：摩根士丹利预测昇腾2026年份额62%——这意味着国产AI基础设施正在形成"准寡头"格局，选择哪家等于押注哪家生态
4. **FP8/FP4量化加速**：文中提到昇腾950支持FP4——这是边缘端部署的关键技术（Qwen3.8-27B量化后可压缩到极低显存），与我们的edge LLM研究相关

## 五、趋势判断

1. **国产GPU市占率60%临界点已过**——从"备胎"到"主角"的分水岭在2026年已跨过，2027-2028将进入真正的生态建设深水区
2. **"全栈自研"路线胜出概率更大**——昇腾/CANN/MindSpore+平头哥/真武/倚天/ICN都是"硬件+软件+云"一体化打法，比单纯卖卡的摩尔线程更抗周期
3. **兼容派是过渡期最优解，但天花板可见**——跟随英伟达生态意味着永远追不上其原生优化速度，最终仍需面对"自主性妥协"问题
4. **AI推理市场的国产化最快**——推理对算子的宽容度高于训练，寒武纪/昆仑芯已在推理领域跑通规模化部署
5. **FP8/FP4量化将成为国产卡突围抓手**——小模型边缘部署需求激增时，国产卡在特定精度上的创新可能弯道超车

## 六、归纳总结

**一句话**：2026国产GPU三阵营分明——兼容派(海光/摩尔线程/沐曦/壁仞)CUDA迁移零痛苦；自主派(昇腾/平头哥)全栈自研建生态；专用派(寒武纪/昆仑芯)推理能效无敌；选型不是选FLOPS而是选生态，参数可以堆，生态只能熬。

**结构记忆**：
- 三阵营：兼容(改代码就行) / 自主(全栈自建) / 专用(AI推理专精)
- 出货格局：昇腾一超(130万+/30%+)、平头哥黑马(60万)、多强缠斗(20-25万)
- 三决策：存量CUDA→兼容派；新项/信创→昇腾；纯推理→寒武纪/昆仑芯
- 一个真相：参数差距=集群可堆，生态差距=时间壁垒
