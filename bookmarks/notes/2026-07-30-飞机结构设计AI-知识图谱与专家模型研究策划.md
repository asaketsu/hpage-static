# 飞机结构设计中 AI 应用：知识图谱与专家模型研究策划

> **类型**: 原创研究策划（Research Proposal）
> **日期**: 2026-07-30
> **标签**: `aircraft-design` `knowledge-graph` `expert-model` `AI` `结构设计` `知识工程` `foundation-model`

---

## 摘要

本策划提出一套将**知识图谱（KG）**和**专家模型（Expert Model）**引入飞机结构设计全流程的研究方案。核心思路是：**知识图谱解决"知识在哪、怎么关联"的问题，专家模型解决"知识怎么用、怎么推理"的问题，二者通过"图谱增强的检索-生成-验证"闭环耦合。** 研究分为四大板块（本体构建、数据汇聚、专家模型、集成验证），覆盖从概念设计到适航验证的完整链条，最终交付可部署的 AI 辅助结构设计原型系统。

---

## 一、研究背景与问题定义

### 1.1 行业痛点

飞机结构设计是高度知识密集、规范驱动、多学科耦合的工程活动，当前面临四大 AI 落地瓶颈：

| 痛点 | 表现 | 根因 |
|------|------|------|
| **知识碎片化** | 设计手册、适航条款、材料数据库、仿真报告分散在不同系统 | 缺乏统一的知识表示和关联体系 |
| **隐性知识难提取** | 老专家的选材直觉、铺层经验、开口补强方案无法形式化 | 经验型知识未结构化，随人员流失而消亡 |
| **AI 模型缺乏工程约束** | 通用 LLM 不理解 CCAR-25/FAR-25 适航条款、材料许用值边界 | 缺少领域本体注入和约束推理 |
| **设计-分析-验证脱节** | CAD 建模→FEA 分析→疲劳试验各环节知识不回传 | 数据流单向，无反馈闭环 |

### 1.2 研究目标

| 目标 | 描述 | 衡量指标 |
|------|------|---------|
| **G1** | 构建飞机结构设计领域知识图谱 | 覆盖 5+ 子系统、10万+ 实体、适航条款全量映射 |
| **G2** | 训练结构设计专家模型 | 在选材推荐、铺层设计、开口补强任务上准确率 >85% |
| **G3** | 实现图谱增强的 AI 辅助设计原型 | 设计周期缩短 ≥20%，返工率降低 ≥30% |
| **G4** | 建立可追溯的适航合规验证机制 | 条款→设计决策→证据链 100% 可溯源 |

### 1.3 核心科学问题

> **如何将飞机结构设计中的多源异构知识（规范条文、工程经验、物理模型、仿真数据）统一表示为知识图谱，并驱动专家模型在满足适航约束的前提下进行可解释的设计推理？**

## 二、知识图谱研究内容

### 2.1 领域本体设计（Ontology Design）

本体是知识图谱的骨架，定义"有哪些概念、概念间有什么关系"。

#### 顶层本体架构

```
AircraftStructuralDesign-Ontology (ASD-O)
├── 设计对象层 (Design Artifact)
│   ├── 机体结构: 机身 / 机翼 / 尾翼 / 起落架 / 发动机挂架
│   ├── 结构元件: 长桁 / 蒙皮 / 翼梁 / 肋 / 框 / 接头
│   └── 细节特征: 开口 / 加强区 / 连接件 / 过渡区
│
├── 设计知识层 (Design Knowledge)
│   ├── 材料知识: 铝合金 / 钛合金 / 复合材料 / 钢
│   ├── 工艺知识: 机加 / 钣金 / 复材铺层 / 增材制造 / 焊接
│   ├── 分析方法: 静强度 / 疲劳 / 损伤容限 / 气弹 / 声疲劳
│   └── 设计准则: 剩余强度 / 检测周期 / 安全余量 / 模型系数
│
├── 规范约束层 (Regulatory Constraints)
│   ├── 适航条款: CCAR-25 / FAR-25 / CS-25
│   │   └── 子条款: §25.305 (强度) / §25.571 (疲劳) / §25.631 (冲击) ...
│   ├── 材料规范: AMS / GB / HB / Q/6S
│   └── 设计手册: MMPDS / MIL-HDBK-17 / 公司内部手册
│
├── 工程经验层 (Engineering Heuristics)
│   ├── 选材经验: "主承力结构优先选 7000 系铝合金或复合材料"
│   ├── 铺层经验: "±45° 铺层比例不低于 10% 以保证面内剪切"
│   ├── 开口补强: "开口区应力集中系数 Kt 与形状参数的关系"
│   └── 公差分配: "复合材料配合面公差比金属宽 0.1-0.2mm"
│
└── 生命周期层 (Lifecycle Data)
    ├── 服役数据: 载荷谱 / 裂纹扩展记录 / 维修记录
    └── 试验数据: 静力试验 / 疲劳试验 / 声疲劳试验
```

#### 关系类型定义

| 关系 | 含义 | 示例 |
|------|------|------|
| `hasComponent` | 结构组成关系 | 机翼 → hasComponent → 翼梁 |
| `madeOf` | 材料关系 | 蒙皮 → madeOf → CFRP-T800 |
| `governedBy` | 适航约束关系 | 疲劳分析 → governedBy → §25.571 |
| `analyzedBy` | 分析方法关系 | 接头 → analyzedBy → 应力集中分析 |
| `requiresProcess` | 工艺约束 | 复材蒙皮 → requiresProcess → 热压罐固化 |
| `hasExperienceRule` | 经验规则关联 | 开口区 → hasExperienceRule → Kt补偿 |
| `hasAllowable` | 许用值关系 | 2024-T3 → hasAllowable → σ_y=324MPa |
| `hasFailureMode` | 失效模式 | 长桁失稳 → hasFailureMode → 屈曲 |
| `validatedBy` | 验证关系 | 设计方案 → validatedBy → 疲劳试验 |
| `conflictsWith` | 约束冲突 | 轻量化 → conflictsWith → 制造工艺约束 |

### 2.2 知识抽取与图谱构建

#### 数据源与抽取策略

| 数据源类型 | 具体来源 | 知识形态 | 抽取方法 |
|-----------|---------|---------|---------|
| **适航规范** | CCAR-25 / FAR-25 / CS-25 全文 | 结构化条款 + 数值约束 | 条款解析 + 正则/NER |
| **材料数据库** | MMPDS / CMH-17 / Key-to-Steel | 属性-值表格 | 表格抽取 + 本体映射 |
| **设计手册** | 公司内部设计手册 / MIL-HDBK | 半结构化文档 | LLM 辅助抽取 + 人工校验 |
| **历史设计案例** | 成熟型号的设计报告 | 非结构化工程文档 | 信息抽取 + 案例推理 |
| **FEA 仿真库** | Patran/Nastran/Abaqus 模型与结果 | 数值数据 + 元数据 | 模型文件解析 + 结果提取 |
| **试验数据库** | 静力/疲劳/损伤容限试验报告 | 表格 + 曲线图 | OCR + 表格识别 + 数值化 |
| **工程经验** | 专家访谈 / 技术评审纪要 | 口头/文本经验 | 结构化访谈 + LLM 转录 |
| **服役数据** | 舙空公司维修记录 / 载荷谱 | 时序数据 + 事件日志 | 事件抽取 + 时序分析 |

#### 构建流水线

```
┌─ 数据汇聚层 ──────────────────────────────────────┐
│ PDF/Word/Excel → 文档解析 → 清洗 → 标准化          │
│ FEA 模型 → 特征提取 → 数值化                        │
│ 试验数据 → 统一格式 → 标准化                        │
└────────────────────┬──────────────────────────────┘
                     ▼
┌─ 知识抽取层 ──────────────────────────────────────┐
│ 实体抽取 (NER): 材料/结构/条款/参数                 │
│ 关系抽取 (RE): is-a / madeOf / governedBy          │
│ 属性抽取: 许用值 / 系数 / 范围                      │
│ 约束抽取: "σ ≤ 0.67 × Ftu" 类数值约束              │
└────────────────────┬──────────────────────────────┘
                     ▼
┌─ 知识融合层 ──────────────────────────────────────飞机
│ 实体对齐: "2024-T3" = "Al2024-T3" = "AA2024-T3"   │
│ 冲突消解: 不同来源许用值差异                         │
│ 质量评估: 完整性 / 一致性 / 时效性                   │
└回写: 增量更新到图数据库 (Neo4j / NebulaGraph)      │
└────────────────────┬──────────────────────────────┘
                     ▼
┌─ 知识服务层 ──────────────────────────────────────┐
│ 图谱查询 (Cypher / SPARQL / GraphQL)              │
│ 语义检索 (图谱增强 RAG)                             │
│ 推理服务 (规则推理 + 图神经网络)                    │
│ 可视化 (子图浏览 / 路径溯源)                        │
└───────────────────────────────────────────────────┘
```

### 2.3 知识推理

| 推理类型 | 方法 | 应用场景 |
|---------|------|---------|
| **规则推理** | SWRL / Datalog 规则 | "若结构属于主承力件 AND 材料为复材 → 需进行损伤容限分析" |
| **本体推理** | 描述逻辑推理机 (Pellet/HermiT) | 检查本体一致性、发现隐含 subclass |
| **图神经网络** | R-GCN / CompGCN / GraphSAGE | 链接预测：发现新材料-结构潜在适用关系 |
| **图嵌入** | TransE / RotatE | 知识补全：补全图谱中缺失的关系 |
| **约束传播** | CSP 求解器 | 适航约束传播：验证设计参数是否满足所有适用条款 |

## 三、专家模型研究内容

### 3.1 专家模型架构

专家模型 ≠ 通用大模型。专家模型是在通用基座之上，注入领域知识图谱和物理约束的**领域增强模型**。

│              飞机结构设计专家模型架构                    │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌─ 用户交互层 ──────────────────────────────────┐   │
│  │  自然语言设计需求 / 约束输入 / CAD 上下文       │   │
│  └──────────────────┬───────────────────────────┘   │
│                     ▼                                 │
│  ┌─ 知识检索层 (KG-RAG) ────────────────────────┐   │

### 3.2 MoE 专家分工

| 专家 | 核心任务 | 输入 | 输出 | 约束 |
|------|---------|------|------|------|
| **选材推理** | 推荐结构材料与规格 | 载荷环境/功能需求/成本约束 | 材料牌号/热处理/许用值 | MMPDS 数据库对齐 |

| **连接设计** | 紧固件选型与排列 | 载荷/板厚/材料 | 紧固件规格/间距/边距 | 挤压/剪切/疲劳 |

### 3.3 训练数据构建

| 数据类型 | 来源 | 规模目标 | 构建方式 |
|---------|------|---------|---------|
| **结构设计指令微调数据** | 历史设计报告 + 人工标注 | 10万+ QA 对 | 专家编写 + LLM 辅助 + 人工审核 |
| **适航条款问答对** | CCAR-25/FAR-25 条款 | 2万+ QA 对 | 条款拆解 + 自动生成 + 专家审核 |
| **FEA-知识对齐数据** | 仿真模型 + 工程判断 | 5万+ 样本 | 仿真结果→设计知识映射 |
| **多轮设计对话数据** | 专家访谈录音转写 | 5000+ 轮 | 结构化访谈 + 多轮对话构建 |
| **偏好对齐数据 (DPO)** | 专家评审打分 | 1万+ 对 | 同一问题的多个方案 + 专家排序 |

### 3.4 训练策略

```
阶段 0: 基座选择
├── 候选: Qwen3-72B / DeepSeek-V4 / GLM-5
├── 选择标准: 中文能力强 + 工程推理能力 + 开源可部署
└── 推理成本与质量的平衡

阶段 1: 领域持续预训练 (CPT)
├── 语料: 设计手册 + 适航规范 + 材料数据库 + 论文
├── 规模: 50-100B tokens
└── 目标: 注入领域基础知识

阶段 2: 有监督微调 (SFT)
├── 数据: 10万+ 领域 QA 对
├── 格式: 指令 + 知识图谱上下文 → 专家级回答
└── 目标: 学会利用知识图谱上下文进行推理

阶段 3: 偏好对齐 (DPO/GRPO)
├── 数据: 专家偏好数据
├── 目标: 对齐工程判断标准 (安全余量优先/适航优先)
└── 关键: 安全相关回答的偏好权重更高

阶段 4: MoE 专家训练
├── 各专家独立 SFT + 路由器训练
├── 路由依据: 任务类型 + 知识图谱中的实体类型
└── 优势: 不同子领域用不同专家, 避免知识干扰

阶段 5: RAG 增强 + 约束验证集成
├── 实时检索知识图谱补充上下文
├── 生成后约束验证 (物理/适航)
├── 不通过 → 反思修正 → 重新生成
└── 目标: 保证输出的工程可执行性
```

### 3.5 知识图谱 × 专家模型耦合机制

这是本研究的核心创新点——KG 和专家模型不是独立的两块，而是**深度耦合**的：

| 耦合方式 | 描述 | 实现 |
|---------|------|------|
| **KG → 模型 (检索增强)** | 模型推理前从图谱检索相关知识注入 prompt | KG-RAG pipeline |
| **模型 → KG (知识回写)** | 模型生成的新设计经验写回图谱 | 人工审核后增量更新 |
| **KG → 模型 (约束注入)** | 图谱中的适航约束作为模型输出的硬约束 | 约束求解器 + 模型生成 |
| **模型 → KG (链接预测)** | 模型预测图谱中缺失的关系 | GNN 链接预测 → 人工确认 |
| **KG → 模型 (可解释性)** | 图谱路径作为模型推理的可追溯依据 | 推理链 = 图谱路径 |

```
耦合闭环:

用户设计需求
    │
    ▼
┌─ KG 检索 ──→ 检索相关条款/材料/经验/案例
│                  │
│                  ▼
│             ┌─ 专家模型推理 ──→ 生成设计方案
│             │                      │
│             │                      ▼
│             │              ┌─ 约束验证 ──→ 通过?
│             │              │                ├─ 是 → 输出 + 推理链
│             │              │                └─ 否 → 反思 → 回到模型推理
│             │              │
│             │              ▼
│             │         知识回写 (新经验写入图谱)
│             │              │
└─────────────┴──────────────┘
                   ↑
              图谱持续增长
```

## 四、重点应用场景

### 4.1 场景一：智能选材推荐

```
输入: "机翼下壁板, 承受拉伸疲劳载荷, 需满足 §25.571, 目标减重 15%"

KG 检索路径:
  机翼下壁板 → madeOf → [2024-T3, 7075-T6, CFRP-T800, Al-Li 2099]
    → 2024-T3: hasAllowable(σ_y=324MPa), hasFatigueProp(优良), weight(基准)
    → 7075-T6: hasAllowable(σ_y=503MPa), hasFatigueProp(较差, 对疲劳敏感)
    → CFRP-T800: hasAllowable(高), weight(轻40%), hasProcess(需热压罐)
    → Al-Li 2099: hasAllowable(σ_y=480MPa), weight(轻8%), hasFatigueProp(优良)

  §25.571 → requires → 疲劳/损伤容限分析
    → CFRP 需额外进行冲击损伤容限分析
    → 7075-T6 疲劳性能不满足优先推荐

专家模型推理:
  → 综合载荷/疲劳/减重/工艺/成本
  → 推荐: Al-Li 2099-T8 (综合最优) 或 CFRP-T800 (极致减重)
  → 输出: 推理依据 + 适用条款 + 置信度 + 后续验证清单
```

### 4.2 场景二：复合材料铺层方案生成

```
输入: 翼盒上壁板几何 + 压缩载荷工况 + §25.305 强度要求

KG 检索:
  翼盒上壁板 → analyzedBy → 压缩屈曲分析
    → governedBy → §25.305(b) 屈曲安全余量 ≥ 0
    → hasExperienceRule → 铺层准则:
       • 0° 铺层: 承受轴向压缩, 比例 30-40%
       • ±45° 铺层: 承受剪切, 比例 ≥10% 每方向
       • 90° 铺层: 防止基体开裂, 比例 ≥8%
       • 表面 ±45°: 抗冲击

专家模型输出:
  [45/0/-45/90/0/45/-45/0/90/0/-45/45]s  (24层对称铺层)
  → 各角度比例: 0°=41.7%, ±45°=33.3%, 90°=16.7%
  → 屈曲 MS = 0.15 (代理模型预估)
  → 需进一步详细 FEA 验证
  → 适用条款: §25.305, §25.305(c) 变形
```

## 六、技术风险与缓解措施

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| **R1: 数据保密性** — 航空设计数据涉密，无法用公有云训练 | 🔴 高 | 私有化部署全栈 (本地 GPU 集群 + 开源模型) |
| **R2: 知识图谱质量** — 抽取准确率不足影响下游任务 | 🟡 中 | 多轮人工审核 + 主动学习 + 专家反馈闭环 |
| **R3: 模型幻觉** — 专家模型生成不安全的设计建议 | 🔴 高 | 约束验证层 + 安全余量强制检查 + 人工确认 |
| **R4: 适航条款变更** — 条款更新导致知识图谱过期 | 🟡 中 | 条款变更监测 + 增量更新管道 |
| **R5: 工程师接受度** — 工程师不信任 AI 建议 | 🟡 中 | 可解释性优先 + 从辅助决策开始 (非自动决策) |
| **R6: 计算资源** — 大模型训练 + KG 存储成本高 | 🟢 低 | MoE 路由减少推理成本 + 图谱分区存储 |
