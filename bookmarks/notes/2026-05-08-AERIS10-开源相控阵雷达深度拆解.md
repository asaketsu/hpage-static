## 摘要

AERIS-10（又名 PLFM_RADAR）是一个完全开源的 10.5 GHz 脉冲线性调频（PLFM）相控阵雷达系统，由 NawfalMotii79 于 2026 年 5 月发布。提供两个版本：AERIS-10N（3km 贴片天线）和 AERIS-10E（20km 缝隙波导 + GaN 功放）。项目包含完整的 KiCad 原理图/Gerber/BOM、Xilinx Artix-7 FPGA Verilog RTL（含形式验证）、STM32 固件、Python GUI，以及 30+ 芯片数据手册。总计约 99K 行代码，是迄今为止最完整的开源相控阵雷达参考实现。

## 核心内容

### 硬件架构：五板分离的模块化设计

项目采用五板分离架构：电源管理板、频率合成板、主信号处理板、功放板（仅 Extended 版）、天线阵列。核心是 Analog Devices 的射频链：AD9523-1 低抖动时钟 → ADF4382×2 频率合成 → DAC 生成 LFM Chirp → LTC5552 混频器上下变频 → ADAR1000×4 控制 16 阵元相位 → ADTR1107×16 收发放大。Extended 版额外用 QPA2962 GaN 功放将每通道功率推到 10W，实现 20km 探测。

### FPGA 信号处理：从天线到目标的完整流水线

XC7A50T Artix-7 上实现了完整的雷达信号处理链：
1. **波形生成** — DAC 生成 LFM Chirp（线性调频脉冲）
2. **接收链** — ADC → I/Q 基带下变频 → CIC 4x 抽取 → FIR 滤波
3. **脉冲压缩** — 匹配滤波（FIR 实现），提升距离分辨率
4. **Doppler 处理** — FFT 提取目标径向速度
5. **MTI** — 动目标显示，抑制静止杂波
6. **CFAR** — 恒虚警率检测，自适应阈值发现目标

特别值得注意的是**混合 AGC（自动增益控制）**——跨层 FPGA/STM32/GUI 闭环：FPGA 做快速粗调，STM32 做中速精调，GUI 做慢速监督。这种跨层设计在开源项目中极罕见。

### STM32 固件：系统管理的中枢神经

STM32F746 承担系统管理角色：上电序列控制、AD9523-1/ADF4382/ADAR1000 配置、16 通道 PA 偏置闭环校准（ADS7830 ADC 采样 Idq → DAC5578 调 Vg）、GPS（UM982）/IMU（GY-85）/气压计（BMP180）集成、步进电机控制（360° 机械扫描）、热管理（8 路热敏电阻监测 + 风扇控制）。

### 跨层测试：工程化的亮点

项目包含 Python 跨层 contract tests（`9_Firmware/tests/cross_layer/`），验证 FPGA↔MCU↔GUI 的系统不变量。FPGA 侧还有 SymbiYosys 形式验证（`.sby` 文件），覆盖 CDC（跨时钟域）、Doppler 处理器、模式控制器等关键模块。这在开源硬件项目中是极高的工程水准。

### Python GUI：从 Tkinter 到 PyQt6 的演进

GUI 有多个版本并行：V5（Tkinter 基础）、V6（增强版，含地图集成）、V65 Tk（优化版）、V7（PyQt6 重写，模块化架构：models/hardware/workers/processing/dashboard/map_widget 分离）。V7 版本的架构最成熟，支持数据回放（replay.py）和软件 FPGA 模拟（software_fpga.py）。

## 🔍 借鉴点

- **跨层 Contract Testing 模式** → 可用于任何嵌入式系统，Python 脚本验证 FPGA 寄存器映射与 MCU 驱动的一致性。参考 `contract_parser.py` 和 `adar1000_vm_reference.py` 的设计
- **FPGA 信号处理模块库** → CIC 抽取器、FIR 滤波、FFT 引擎、CFAR 检测器的 Verilog 实现可直接复用或改造，适用于任何 SDR/雷达项目
- **ADAR1000/ADF4382 驱动** → Analog Devices 相控阵核心芯片的 C 库，含完整的初始化序列和相位校准算法
- **混合 AGC 架构** → FPGA 快速 + MCU 中速 + GUI 慢速的三层增益控制模式，可推广到任何需要动态范围管理的射频系统
- **形式验证流程** → SymbiYosys .sby 文件覆盖 CDC、Doppler、Mode Controller，是 FPGA 开源项目的最佳实践范本
- **PCB 分层策略** — 6 层板（RO4350B + FR4 混压），阻抗控制 0.102mm 介质厚度，可为微波 PCB 设计提供参考

## 💡 启发

- **开源硬件的"完整度壁垒"已被打破** — 从原理图到 FPGA bitstream 到 GUI 的全链路开源，意味着小团队也能做出军用级别的雷达系统。这种"全栈开源"模式将成为硬件创业的新标准
- **跨层测试 > 单层测试** — 大多数嵌入式项目只在 MCU 或 FPGA 层面做测试，但真正出 bug 的地方是层间接口。AERIS-10 的 Python contract tests 提供了一个可推广的框架
- **混合 AGC 是个精妙设计** — 不同时间尺度的控制环分工明确，这种分层控制思想可以推广到任何复杂的闭环系统（机器人控制、电源管理等）
- **GaN 功放的开源化** — QPA2962 10W GaN MMIC 的开源应用，意味着射频前端的门槛在快速降低

## 🔮 预判

- **开源雷达生态将爆发** — AERIS-10 证明了"从零到雷达"可以用开源组件完成。预计 12-18 个月内会出现更多频段（24GHz/77GHz/94GHz）的开源雷达项目
- **相控阵成本将降至消费级** — ADAR1000 等芯片的价格在持续下降，3-5 年内可能出现千元级别的消费级相控阵雷达（无人机避障、汽车辅助驾驶）
- **FPGA + AI 混合处理将成为标配** — AERIS-10 的 FPGA 做传统信号处理，未来会在 FPGA 侧加入轻量级 AI 推理（目标分类、杂波抑制），形成"信号处理 + AI 推理"双引擎
- **Cross-layer testing 框架将独立成工具** — 这种 FPGA↔MCU↔GUI 的 contract test 模式足够通用，可能被提取为独立的嵌入式测试框架
