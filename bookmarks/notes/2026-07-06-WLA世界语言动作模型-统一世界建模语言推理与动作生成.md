## 一、内容详细整理

### 1.1 背景问题：WAM（世界-动作模型）的三大局限

世界-动作模型（World-Action Model, WAM）是当前具身智能的重要方向，将**世界建模与动作预测结合**——机器人不仅根据当前观测生成控制动作，还能预测未来状态或画面，在行动前预演可能结果。

但 WAM 存在三大局限：

- **细节重建负担**：图像预测需要重建大量与任务无关的细节（背景、纹理、光照），对生成动作帮助有限，却增加学习负担
- **推理延迟**：如果推理阶段仍需显式生成图像/视频，引入额外延迟，影响机器人实时闭环控制
- **语义信息不足**：许多 WAM 主要依赖像素级视觉预测，难以充分表达任务意图、因果关系和长期规划

> 核心矛盾：**像素级预测 ≠ 任务理解**。机器人不需要"想象出未来画面"，它需要理解"未来会发生什么关键变化"。

### 1.2 WLA 的核心方案：双表征统一框架

上海交大 DENG Lab 提出世界-语言-动作模型（World-Language-Action Model, WLA），将**世界建模、语言推理与机器人动作生成**统一到同一个框架中。

WLA 对未来状态的预测不只停留在"生成未来画面"，而是同时建模**两类关键信息**：

**文本意图（粗粒度）**：
- 用自然语言描述未来状态和任务目标
- 为机器人提供简洁、可解释的语义表示
- 过滤与决策无关的视觉细节
- 支持目标分解、记忆组织、逻辑推理和长期规划

**物理动态（细粒度）**：
- 刻画动作对环境状态的影响
- 描述物体位姿、接触关系、运动趋势等细粒度变化
- 连接高层任务意图与底层动作控制
- 让机器人理解"这样做会带来什么结果"

### 1.3 架构设计：自回归 Transformer + VLM 初始化

**不同于基于双向 DiT 的 WAM**，WLA 采用：
- **自回归 Transformer 骨干网络**
- **预训练视觉-语言模型（VLM）初始化**

这一设计使模型天然继承 VLM 的语言理解、序列生成和上下文管理能力，不再局限于像素级预测。

#### 1.3.1 文本意图：子任务预测 + 记忆缓冲区

在长时程任务中，语言指令通常只给出最终目标，不告诉机器人每一步怎么做。WLA 的解决方案：

- 将高层意图表示为**文本子任务**
- 模型预测未来动作窗口对应的**子任务序列**
- 维护**记忆缓冲区**记录已完成步骤
- 推理流程：自回归生成当前子任务 → 基于子任务生成动作 → 执行后写入记忆 → 作为后续决策上下文

> 这使 WLA 不再是"看一帧、做一步"，而是能持续判断任务进度：哪些步骤已完成、当前应做什么、接下来如何推进。

#### 1.3.2 物理动态：世界专家 + meta-queries

为使自回归主干具备物理动态建模能力，WLA 引入：
- **世界专家（World Expert）**：专门模块
- **一组 meta-queries**：追加到输入序列之后

工作原理：
- meta-queries 通过因果注意力聚合上下文信息 → 形成环境变化的紧凑表征
- 训练时世界专家以当前视觉状态 + meta-queries 隐藏表示为条件，预测未来视觉状态
- 隐藏表示被约束为**潜在动作表征**——不重建低层细节，集中编码核心物理动态
- 这些潜在表征也作为条件输入，引导**动作专家**生成可执行动作

**推理优化关键**：推理时**关闭世界专家**，直接生成动作。世界建模信号已在训练阶段通过共享主干和 meta-queries 注入动作生成过程，推理时无需"先想象、再执行"。

> 经系统级优化后，WLA 单次推理延迟降至 **40ms**，胜任动态场景实时控制。

### 1.4 实验结果：全面验证

#### 仿真基准

- **RoboTwin 2.0 和 LIBERO**：WLA-0（仅激活 2B 参数，未进行具身预训练）取得极具竞争力的结果
- **RMBench**（评估长程记忆、任务规划、错误恢复）：
  - WLA-0：**56.5%** 平均成功率
  - 次优 Mem-0：28.5%（WLA 几乎是它的两倍）
  - WAM 基线 Fast-WAM：13.3%
  - VLA 基线：5.5%
- **消融实验**：移除子任务预测损失后，成功率骤降至 17.3% → **语言推理对长程任务关键**

#### 真机实验

- WLA-0 从零开始训练，性能仍优于两个预训练基线和 Motus
- 能泛化至**分布外物体与场景**
- 动态 Dispose Trash 任务中成功率最高
- Motus 因推理延迟高，无法及时跟踪旋转垃圾桶导致失败
- **WLA-0 推理延迟仅为 Motus 的 1/40**

#### 跨具身迁移：从无标注视频学习新任务

RoboTwin 50 个任务分为 45 seen + 5 unseen，四组对比：

- **Seen-Action baseline**：仅 seen 任务动作监督 → Clean/Rand. = 13.0/11.6
- **+Seen Video**：加入 seen 视频监督 → 11.8/12.6（几乎无收益）
- **+Unseen Same-Emb. Video**：加入 unseen 同本体视频 → **34.4/30.0**
- **+Unseen Cross-Emb. Video**：加入 unseen 跨本体视频 → **28.8/27.4**

> 以 Beat Block Hammer 为例，baseline 几乎完全失败，而 unseen 视频监督使模型学会抓取锤子并尝试敲击——**展现出跨本体迁移潜力**。

## 二、查询拓展

### 2.1 WAM（World-Action Model）vs VLA（Vision-Language-Action）

WAM 是 VLA 的演进方向。VLA（如 RT-2、π0、Octo）接收图像+语言指令直接输出动作，不显式建模"未来世界状态"。WAM 在此基础上增加世界模型——预测动作执行后的环境变化，使机器人具备"预演"能力。但 WAM 的像素级预测引入了延迟和语义不足。WLA 的贡献正是在 WAM 框架中引入语言层，解决了语义和延迟问题。

### 2.2 DiT（Diffusion Transformer）双向 vs 自回归

许多 WAM 使用基于 DiT（Diffusion Transformer）的双向架构生成未来帧——所有 token 同时去噪，适合图像生成但不天然支持序列推理。WLA 选择自回归 Transformer（类似 GPT/LLaMA），逐 token 生成，天然支持子任务序列预测、记忆管理和长程推理。这也是 WLA 能继承 VLM 语言能力的架构基础。

### 2.3 RMBench — 长程记忆基准

RMBench 专门评估机器人在长时程任务中的记忆、规划和错误恢复能力。传统 VLA/WAM 在此基准上表现差（5.5%-13.3%），因为它们缺乏"记住已做步骤"的机制。WLA 的子任务记忆缓冲区直接针对此痛点，56.5% 的成绩说明语言推理 + 记忆是长程任务的解法。

### 2.4 Motus — 被对比的 WAM 基线

Motus 在本文中作为真机对比的 WAM 基线，因推理延迟高在动态任务中失败。这与 UniLab 笔记中提到的 Motrix（清华 AIR 自研仿真器）不同——此处的 Motus 是一个 WAM 模型，而非仿真器。同名但不同物，需区分。

### 2.5 Sim-to-Real 与分布外泛化

WLA-0 从零训练（无具身预训练）却能在真机上超越预训练基线，且泛化到分布外物体/场景，这在 sim-to-real 领域是重要信号。说明语言推理提供的语义抽象有助于跨域泛化——文本意图不依赖特定视觉纹理，比像素级表征更鲁棒。

## 三、归纳总结

### 3.1 WAM → WLA 的范式跃迁

```
         WAM（世界-动作）              WLA（世界-语言-动作）
──────────────────────────────────────────────────────────
预测目标   像素级未来画面              文本意图 + 物理动态
架构       双向 DiT                   自回归 Transformer + VLM
语义       弱（像素）                  强（语言）
延迟       高（需生成图像）            低（40ms，关闭世界专家）
长程规划   无（看一帧做一步）          有（子任务+记忆缓冲区）
可解释性   低（黑箱像素）              高（文本子任务可读）
──────────────────────────────────────────────────────────
```

### 3.2 WLA 的双表征设计哲学

```
┌──────────────────────────────────────────────────┐
│              WLA 双表征统一框架                    │
├──────────────────────────────────────────────────┤
│                                                  │
│  文本意图（粗粒度）    ←→    物理动态（细粒度）   │
│  · 自然语言描述               · 物体位姿变化      │
│  · 任务目标                   · 接触关系          │
│  · 子任务序列                 · 运动趋势          │
│  · 可解释、可推理             · 连接意图与控制    │
│         ↕                            ↕           │
│    记忆缓冲区                   世界专家           │
│  （记录已完成步骤）          （meta-queries聚合）  │
│         ↕                            ↕           │
│              动作专家（生成可执行动作）            │
│                                                  │
│  训练时：世界专家注入物理先验                     │
│  推理时：关闭世界专家，40ms 直出动作              │
└──────────────────────────────────────────────────┘
```

### 3.3 性能层级：RMBench 成功率对比

- WLA-0：**56.5%**（本文）
- Mem-0：28.5%（次优，WLA 的 2 倍差距）
- Fast-WAM：13.3%
- VLA 基线：5.5%
- WLA 消融（无子任务预测）：17.3%（骤降 → 证明语言推理是核心）

> 56.5% vs 5.5%（VLA），**10 倍差距**。这不是渐进改进，是范式级差异——长程任务中"记忆+规划"的价值碾压纯反应式 VLA。

## 四、趋势判断

### 趋势1：WLA 将取代 WAM 成为具身智能主流框架

依据：WLA 在 RMBench 上以 10 倍优势碾压 VLA、4 倍优势碾压 WAM 基线，且推理延迟仅 40ms（实时控制级）。语言推理带来的可解释性、长程规划、记忆能力是 VLA/WAM 架构性无法提供的。2026-2027 年预计大量团队从 VLA/WAM 转向 WLA 类架构。

### 趋势2：自回归架构将主导机器人策略模型

依据：WLA 用自回归 Transformer + VLM 初始化，而非 WAM 常用的双向 DiT。自回归天然支持序列推理、子任务生成、记忆管理——这些是长程任务的核心能力。这与 LLM 领域 GPT 类自回归碾压 BERT 类双向的趋势一致。机器人策略模型正在重演 LLM 的架构演化路径。

### 趋势3：跨具身迁移将依赖语言抽象而非像素对齐

依据：WLA 跨具身实验显示，unseen 跨本体视频仍达 28.8% 成功率，接近同本体的 34.4%。这说明语言层提供的任务理解（"抓锤子敲目标"）可以跨机器人形态迁移，而像素级 WAM 无法做到。未来"一个模型控制多种机器人"的路径大概率是语言统一接口 + 物理动态分别适配。

### 趋势4：世界模型将从"生成器"退化为"训练信号"

依据：WLA 推理时关闭世界专家——世界建模只在训练时注入物理先验，推理时直接出动作。这预示着一个重要趋势：世界模型的价值不在于"运行时生成未来画面"，而在于"训练时教会策略网络理解物理"。运行时的想象是昂贵的奢侈品，训练时的想象是廉价的教师。

## 七、行动启示

- **框架选型**：新机器人项目如果涉及长时程操作任务，WLA 架构优于纯 VLA/WAM，语言推理+记忆是关键差异化能力
- **延迟红线**：WLA 的 40ms 推理延迟是动态实时控制的标杆，评估任何策略模型时以此为基准
- **数据策略**：WLA 展示了从无标注跨本体视频学习的能力，这意味着 YouTube 等海量人类操作视频可成为机器人训练数据源，大幅降低采集成本
- **开源跟进**：代码和模型权重已开源（GitHub + HuggingFace），可直接在 RoboTwin/LIBERO 上复现实验
- **记忆模块升级**：WLA 的记忆缓冲区是简单序列，可考虑引入 Agent 记忆架构的成熟方案（情景检索、遗忘、巩固）提升长程任务表现
- **跨具身方向**：WLA 的跨本体迁移（28.8%）预示"一个大脑多种身体"的可能性，关注其跨具身迁移的后续工作
