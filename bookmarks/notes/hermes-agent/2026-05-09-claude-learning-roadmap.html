摘要

鸟哥分享了一份 Claude 分级学习指南，源自 Ruben Hassid 的 substack 系列文章。按学习时间分为4个等级，从基础到专家。内容覆盖 Claude 基础使用、团队协作、设计、代码、API开发等场景。

4级学习路线

第1级：基础入门（24分钟）

  • Claude 傻瓜指南：从零到入门
  • Claude 设置：环境配置
  • 链接：
  • https://ruben.substack.com/p/claude-for-dummies
  • https://ruben.substack.com/p/claude

第2级：实战工作流（1小时）

6个实战方向：
1. Claude 协作 — 个人效率提升
2. Claude 团队版 — 团队协作
3. Claude 设计 — 从设计到出图
4. 协作+项目 — Claude 作为远程员工
5. Claude 幻灯片 — AI 做 PPT
6. Claude 技能 — 隐藏功能解锁
- 链接：
- https://ruben.substack.com/p/claude-coworking
- https://ruben.substack.com/p/claude-for-teams
- https://ruben.substack.com/p/claude-design
- https://ruben.substack.com/p/claude-coworking-and-projects
- https://ruben.substack.com/p/powerpoint
- https://ruben.substack.com/p/claude-skills

第3级：专业技巧（3.5小时）

5个进阶主题：
1. 避免奉承 — 让 AI 说实话而非拍马屁
2. Claude Code — 写代码、改 bug
3. Claude 101 — 官方培训课
4. 突破限制 — 打破输出天花板
5. 停止瞎提示 — 精准 prompt 技巧
- 链接：
- https://ruben.substack.com/p/i-love-to-be-a-sycophant
- https://ruben.substack.com/p/claude-code
- https://anthropic.skilljar.com/claude-101
- https://ruben.substack.com/p/how-to-stop-claudes-limit
- https://ruben.substack.com/p/stop-prompting

第4级：专家模式（8小时）

2个硬核方向：
1. Claude 电脑 — 桌面操控（Computer Use）
2. Claude API — 二次开发
- 链接：
- https://ruben.substack.com/p/claude-computer-use
- https://anthropic.skilljar.com/claude-with-the-api

关键建议

  • 不要一口气看完，逐级学习
  • 每学一级立即用到工作中，用熟了再学下一级
  • 核心思路：学完就练，练完就用于实际工作

我的评估

这篇内容本质上是对 Ruben Hassid 的 substack 系列文章的中文转述和推广。作为 Claude 学习路线图的索引有一定参考价值，但内容深度有限，主要价值在于整理好的链接列表。

对我们而言：我们已经在用 Claude Code + Skills 体系做深度开发，第3-4级的内容更相关，第1-2级太基础。值得关注的点：
- Claude Skills 的隐藏功能（我们的 SKILL.md 体系已覆盖并超越）
- 避免 sycophancy 的技巧（可借鉴到 prompt 设计中）
- Computer Use 桌面操控（我们已有 CDP 方案）
