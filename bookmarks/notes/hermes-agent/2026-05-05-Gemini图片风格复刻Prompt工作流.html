摘要

作者分享了一套用 Gemini 辅助生成高质量图片 prompt 的工作流：先给 Gemini 充分的背景知识（如 Google 提示工程白皮书），让它做需求分析，最后输出一个通用的分析模板，保存为 Gem（Gemini 的自定义角色），之后每次只需上传图片就能自动生成针对不同模型优化的 prompt。核心是一份8维度图片分析法：主体动作、场景环境、构图、艺术风格、光照、色彩、氛围情绪、技术细节，并针对 Midjourney、Stable Diffusion、DALL-E 3 三个模型分别给出不同的输出格式。

核心内容

工作流三步走

第一步是知识注入。先把 Google 提示工程白皮书等权威文档喂给 Gemini，让它充分吸收背景知识。同时把具体需求告诉它，比如"我要做图片风格复刻"。

第二步是模板生成。Gemini 基于吸收的知识和需求，生成一个结构化的分析模板。这个模板定义了分析的维度、输出的格式。

第三步是固化复用。把模板保存为 Gem（Gemini 的自定义角色），之后每次只需上传参考图，Gem 就会按照模板指引自动分析并生成 prompt，无需重复解释需求。

8维度图片分析法

主体与动作：识别画面中的核心对象、外观、姿态、互动关系和数量。

场景与环境：背景设定、时间、天气等环境要素。

构图：视点角度（鸟瞰/平视/特写）、取景景别（全身/半身/远景）、布局规则（三分法/对称/黄金分割）、空间深度。

艺术媒介与风格：媒介类型（照片/油画/水彩/3D渲染）、整体风格（写实/印象派/赛博朋克/梵高风）、技法特征（笔触/厚涂/平滑渲染）。

光照：光源类型、方向、质量感、时间和阴影特征。

色彩调色板与色调：主色、色调倾向、对比度与和谐度、整体明暗。

氛围与情绪：画面传达的整体感觉。

技术细节：相机镜头效果、宽高比、分辨率清晰度。

三模型差异化输出

Midjourney 侧重简洁诗意的描述性短语，逗号分隔，可带参数如 --ar --style --s。

Stable Diffusion 侧重详细关键词短语，用括号 () 加权，必须生成 negative_prompt。

DALL-E 3 侧重流畅的自然语言描述，像讲故事一样整合各元素。

🔍 借鉴点

8维度分析法 → 可直接整合到 google-ai-image-cdp skill 中，生成图前先用此框架分析参考图，输出高质量 prompt
Gem 固化复用模式 → Hermes 的 skill 本质就是"固化复用"，思路一致。可以在 Gemini 里创建一个专属的"图像分析 Gem"角色
多模型差异化输出 → 提醒我们在生成 prompt 时考虑目标模型的偏好，不能一刀切
知识注入先行 → 先给 AI 背景知识再做任务，这个模式在 Hermes 的 skill 体系中也适用（references/ 目录就是这个思路）

💡 启发

"知识注入 → 模板生成 → 固化复用"这个三步模式不限于图片 prompt，可以泛化到任何需要 AI 反复执行同类任务的场景。本质上就是把一次性的"教会 AI"变成可复用的"角色"。Hermes 的 skill 体系、Gemini 的 Gem、ChatGPT 的 Custom Instructions 都是同一思路的不同实现。

对于我们自己的生图 skill，可以在分析参考图时自动调用这个 8 维度框架，生成结构化的描述后再转成目标模型的 prompt 格式，这样质量会比随便写一句话好很多。

🔮 预判

图片 prompt 工程会越来越模板化，未来可能发展为"拖拽式 prompt 构建器"——每个维度一个滑块或选择器。但在当前阶段，结构化分析模板仍然是最实用的方案，因为 AI 对自然语言描述的理解还不足以完全替代精心设计的 prompt。
