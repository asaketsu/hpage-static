# Voicebox — 开源语音合成工作室 > 本地化部署版本，基于 jamiepine/voicebox (21.9k ⭐) ## 🎙️ 功能 语音克隆 — 上传音频样本，克隆任意声音 文本转语音 — 支持多引擎 (Qwen3-TTS / Kokoro / Chatterbox / Hume) 音频效果 — 内置效果器 (均衡、压缩、混响等) 本地运行 — 所有推理在本地完成，隐私安全 Web UI — 现代化 React 前端，支持中文 ## 🚀 快速启动 ### 方式一：Docker (推荐) bash chmod +x start.sh ./start.sh docker 访问 http://localhost:17493 ### 方式二：本地运行 bash ./start.sh local 前端: http://localhost:5173 API: http://localho
