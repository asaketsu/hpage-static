一、四款材料的完整技术档案

1.1 6061-T6｜6系通用铝（Al-Mg-Si）

项目 数据
抗拉强度 310 MPa
延伸率 12%
强化机制 热处理强化（Mg₂Si 析出相，β''/β' 亚稳相）
焊接性 T6 状态基本不可焊，需回 O 态退火后再焊；焊后不可恢复 T6
耐蚀性 良好，可阳极氧化
加工性 四款中最好（刀具寿命长、表面质量优）
温度上限 约 200°C（T6 状态）

公众号定位："机械圈的万能通用铝"，综合平衡能力最强——这是四款材料里唯一在强度/焊接（退火态）/耐蚀/加工四项都不拉胯的，所以成为行业万金油。

注意一个常被忽略的事实：6061 的强化相是 Mg₂Si，焊接时 Mg₂Si 溶解 → 热影响区（HAZ）软化。这就是"焊接机架锁定 6061 或 5052"的技术根源——不是 6061 焊得好，而是它的焊接后果（HAZ 软化）在四款里最可控。

1.2 7075-T6 / T651 / T7351｜7系超高强铝（Al-Zn-Mg-Cu）

项目 T6 T651 T7351
抗拉强度 572 MPa 572 MPa 505 MPa
屈服强度 503 MPa 503 MPa 455 MPa
抗应力腐蚀开裂（SCC） 最敏感 中等 最优秀
强化机制 淬火+时效，η'/η（MgZn₂）相 淬火+时效+拉伸释放应力 淬火+受控过时效
焊接性 不可焊（Zn 5.5% 导致热裂纹） 不可焊 不可焊
典型应用 航空次承力、赛用结构件 航空主要承力结构 航空关键承力件（要求抗 SCC）

三个时效状态是理解 7075 的关键（公众号只提"7075-T6/T7351"而未展开差异）：

  • T6：最强，但晶界连续分布 → 晶间腐蚀路径最短 → SCC 敏感性最差。实测数据（机械科学研究期刊）：NaCl 溶液中 T6 晶间腐蚀深度 58 μm。
  • T651："51"表示淬火后拉伸处理释放残余应力（消除 50% 残余应力）→ 缓解残余应力诱发的 SCC，但强度不变。
  • T7351：受控过时效，牺牲约 12% 强度，换来自腐蚀电位更高、阻抗值更大 → 抗 SCC 最优。T7351 是航空关键件的标配。

结论：写"7075"而不写状态，等于没写。T6 和 T7351 的抗 SCC 能力是数量级差异，选错状态在海洋/近海航空场景就是失效。

1.3 2A12-T4（旧牌号 LY12）｜2系硬铝（Al-Cu-Mg）

项目 数据
抗拉强度 约 415 MPa
强化机制 热处理强化（Cu 为固溶强化主元素 + S' 相）
焊接性 不可焊（Cu 含量高，热裂纹敏感）
疲劳性能 疲劳比（疲劳强度/抗拉强度）显著高于 7075
温度性能 约 150°C 保持强度（外网源：b2bwiki 明确标注）
典型应用 交变载荷件、航空次承力结构、高强工装

这是本笔记最关键的纠偏点（详见第五章）：公众号说"强度介于 6061 与 7075 之间"，按室温抗拉强度是对的（310 < 415 < 572），但这个定位忽略了 2A12 的两大独家优势：
1. 耐热：150°C 保持强度——6061-T6 约 200°C 上限但强度衰减快，7075 在 150°C 以上强度急剧下降
2. 缺口敏感性低：2xxx 系（2A12/2024/2219）对应力集中不敏感，7xxx 系对缺口极敏感——这是 2A12 在高周疲劳工况性价比更高的真正原因，不是"静态疲劳强度更高"

1.4 5052-H32｜5系防锈铝（Al-Mg）

项目 数据
抗拉强度 约 220-245 MPa（H32 状态）
屈服强度 约 165 MPa
延伸率 ≥12%
强化机制 不可热处理强化，纯冷加工硬化（H32 表示双向冷轧 + 稳定化退火）
焊接性 四款中最好（Mg 4-5% 低裂纹敏感性，MIG/TIG 均可）
耐蚀性 四款中最好，耐海水腐蚀（外网源：5052-H32 "常见铝合金中耐海水腐蚀最好"）
成形性 四款中最好（折弯/深冲/拉伸）
温度上限 不可用于高温（冷加工硬化会回复）

5 系的核心逻辑：不靠淬火时效，靠冷加工积累位错密度提升强度。这决定了它的两个极端——成形性无敌，但高温下强度会回复消失。

三、选型决策树（公众号逻辑的完整还原 + 补充）

公众号给出的优先级链：

使用环境 ＞ 是否焊接 ＞ 加工工艺 ＞ 强度需求 ＞ 成本 ＞ 表面处理

这个顺序非常对——强度是最后的筛选条件，不是第一筛。还原为决策树：

开始
│
├─ Q1: 使用环境是否有腐蚀风险（盐雾/高湿/户外/近海）？
│   ├─ 是 → 排除 7075、2A12（裸用必失效）
│   │        ├─ 需要钣金/高耐蚀 → 5052-H32
│   │        └─ 需要结构强度 → 6061-T6（+阳极氧化+喷涂封闭）
│   │        └─ 必须高强且必承受盐雾 → 7075-T7351 + 全套喷涂防护
│   └─ 否（室内干燥）→ 进入 Q2
│
├─ Q2: 需要熔焊（TIG/MIG）？
│   ├─ 是 → 排除 7075、2A12（热裂纹报废）
│   │        ├─ 钣金件 → 5052-H32
│   │        └─ 结构件 → 6061（用 O 态材料焊，焊后不再热处理）
│   └─ 否（螺栓/铆接/胶接）→ 进入 Q3
│
├─ Q3: 加工方式？
│   ├─ CNC 铣车 → 6061-T6（加工性最好，成本最低）
│   ├─ 折弯/冲压/拉伸 → 5052-H32（成形性最好）
│   │        └─ 若必须用 6061 → O 态折弯，然后重新做 T6 热处理
│   └─ 型材 → 6061（型材机加工件首选）
│
├─ Q4: 载荷类型？
│   ├─ 静态/稳态 → 追求强度 → 7075-T651（或 T7351 若抗 SCC 要求）
│   ├─ **交变疲劳** → **2A12-T4**（疲劳比高，缺口不敏感）
│   │        └─ 若载荷同时要求高强 → 7075-T7351（强度+抗SCC，但疲劳比不如 2A12）
│   └─ 中等载荷 + 成本敏感 → 6061-T6
│
└─ Q5: 温度工况？
    ├─ ≤50°C → 任意
    ├─ 50-150°C → **2A12-T4**（唯一选项）
    └─ >150°C → 四款均不适用，需高温合金或钛合金

四、四个高频踩坑的技术机理（公众号未展开的部分）

坑 1：户外裸用 7075 → 点蚀 + 应力腐蚀开裂

机理：7075 的 Zn（约 5.5%）+ Cu 组合是 SCC 的"化学引信"。晶界上富集 Cu 和 η'（MgZn₂）相，晶界成为电化学腐蚀的优先路径。盐雾环境下几个月即出现点蚀，点蚀坑成为应力集中源 → 裂纹萌生 → 沿晶扩展。

实测数据：7075-T6 在 NaCl 溶液中晶间腐蚀深度 58 μm（机械科学研究期刊）。阳极氧化只是减缓，不是免疫——公众号说"即便阳极氧化，长期盐雾仍需要喷涂封闭"是对的。

正确做法：
1. 首选 6061 或 5052
2. 必须用高强铝 → 7075-T7351（过时效，牺牲 12% 强度换抗 SCC）
3. 阳极氧化 + 喷涂封闭（氟碳漆/环氧），且要检查涂层有无针孔

坑 2：焊接机架用 7075 → 热裂纹报废

机理：7075 的 Zn 含量高，凝固温度区间宽（低熔点共晶相凝固温度差约 40-60°C），凝固末期固相率不足时，液态金属沿晶界流动受阻 → 结晶裂纹（热裂纹）。这是冶金学层面的不可修复问题，不是工艺参数能解决的。

外网核实（焊接学报）：7075 作为填充材料对 6061 进行高组配焊接时"焊接接头硬度确有提升，但在焊接过程中产生了热裂纹"——即使作为填充材料也不行。

唯一例外：7075 可以钎焊（钎料填充焊缝而非熔焊母材）或胶接。但常规机架设计直接锁定 6061（O 态）或 5052。

坑 3：钣金折弯用 6061-T6 → 折弯处开裂

机理：T6 状态的 Mg₂Si 强化相使材料硬而脆，折弯时的应变梯度导致开裂。

关键工程细节（公众号提到了但没展开）：6061-O 态可以折弯，折弯后必须重新做 T6 热处理（固溶 + 时效）。这个"退火→成形→再热处理"工艺链有成本代价（多两道工序）和质量风险（时效工艺控制不好会强度不达标）。

如果零件需要大批量折弯成形，5052 是正确选择——它不需要热处理，冷加工本身就是强化机制。

坑 4：交变疲劳件一味用 7075 → 寿命不如 2A12

机理：这是本笔记最需要说清的一点（公众号表述有误导，见第五章）。

  • 7075 的静态抗拉强度 572 MPa，是 2A12 的 1.38 倍
  • 但 7075 的疲劳强度（10⁷ 次循环）约 310 MPa，2A12 约 245 MPa
  • 疲劳比（疲劳强度/抗拉强度）：7075 = 310/572 = 54%，2A12 = 245/415 = 59%
  • 更重要的是缺口敏感性：7075 对应力集中极敏感，2A12 相对钝感

结论：在交变疲劳工况下，2A12 的单位重量疲劳寿命往往优于 7075——尤其在存在孔洞、圆角、装配间隙等应力集中源时。这就是"2A12 性价比更高"的准确含义：不是绝对疲劳强度高，而是疲劳性能相对静态强度的"性价比"高。

五、对公众号的三处诚实修正（有数据支撑）

修正 1：2A12 的强度定位不完整

公众号表述："2A12-T4，强度介于 6061 与 7075 之间，很多人容易忽略它的价值。"

这个表述按室温抗拉强度是对的（310 < 415 < 572），但"容易忽略的价值"表述得太保守。2A12 的真实定位应该是"50-150°C 温区的唯一主力"：
- 外网源（b2bwiki）明确标注"推荐 2A12-T4（150°C 下强度）"
- 6061-T6 在 200°C 以上强度急剧衰减，7075 在 150°C 以上同样衰减
- 这意味着发动机舱周边、涡轮增压旁、刹车系统周边等 100-150°C 温区，2A12 是四款材料里唯一的选择

公众号把它定位成"交变疲劳 + 耐热"的备选，容易让工程师在温区工况下漏选它。

修正 2：疲劳优势的表述容易误导

公众号表述："7075 静态强度高，但抗疲劳不如 2A12，交变工况 2A12 性价比更高。"

这个表述方向对，但"抗疲劳不如"的字面理解会误导。准确说法是：

指标 7075-T6 2A12-T4 谁优
抗拉强度（静态） 572 MPa 415 MPa 7075 胜 38%
疲劳强度（10⁷ 循环） 约 310 MPa 约 245 MPa 7075 胜 27%
疲劳比 54% 59% 2A12 胜
缺口敏感性 极高 相对钝感 2A12 胜
单位重量疲劳寿命（有应力集中时） 低 高 2A12 胜

准确表述："2A12 的疲劳比更高、缺口敏感性更低——在存在应力集中的交变载荷工况，2A12 的疲劳寿命性价比优于 7075。"公众号的"抗疲劳不如"如果理解为绝对疲劳强度，是错的（7075 更高）；如果理解为疲劳寿命性价比，是对的。

修正 3：5052 的耐海水优势需要更精确的界定

公众号表述："优先 5052"用于海边/盐雾环境。

这个建议正确但需要限定：5052 的耐海水优势在无应力状态下成立。如果 5052 处于残余应力或循环应力状态（如焊接后的结构件），它同样会发生 SCC——只是比 7075/2A12 慢得多。5052 的耐蚀性不改变"焊接后残留应力"这一基本事实，需要退火或振动时效释放残余应力。

六、一个公众号完全没提但极其重要的知识点

6.1 "材质状态"是必须写进图纸的独立字段

公众号结尾强调"除牌号，一定要写清材料状态"，这是全篇最有价值的提醒。展开说明：

同牌号不同状态的性能差异可以到 40%：
- 6061-O vs 6061-T6：抗拉 145 MPa vs 310 MPa（差 114%）
- 7075-T6 vs 7075-T7351：抗拉 572 vs 505 MPa（差 12%），但抗 SCC 是数量级差异
- 5052-O vs 5052-H32：抗拉 145 vs 235 MPa（差 62%）

工程实践规范：
1. 图纸材料栏写 6061-T6 而非 6061
2. 采购合同必须指定状态，并要求供应商提供该状态的材料质保书（MTS）
3. 焊接件标注 6061-O（焊后不热处理）——避免供应商误按 T6 供货

失效根因：很多零件失效不是牌号选错，而是采购时未指定状态，供应商按默认状态供货（通常是 O 态或 F 态）。这是隐蔽成本最高的选型失误。

6.2 T651 的"51"到底是什么

7075-T651 中的"51"是ASTM A210 状态代号：
- 51 = 淬火 + 拉伸消除 50% 残余应力 + 自然时效
- 目的：消除淬火过程产生的残余应力（残余应力是诱发 SCC 的重要因素之一）
- 效果：抗 SCC 性能优于纯 T6，但强度不变

这是航空业的常规做法——T651 是航空 7075 承力件的标准状态，比 T6 贵一点但可靠性大幅提升。公众号只写"7075-T6/T7351"略过了 T651 这个中间状态。

6.3 一个容易被忽略的温度边界

四款材料中只有 2A12 能在 150°C 保持强度。这个边界意味着：
- 发动机舱周边结构件：只有 2A12
- 涡轮增压管道附件：只有 2A12（或钛合金/高温合金）
- 刹车卡钳支架（温度可达 100-150°C）：只有 2A12
- 无人机电池仓周边（锂电池温度可达 60-80°C）：四款均可，但需验证长期热稳定性

公众号把 2A12 描述为"有一定温度的工况"，这个模糊表述容易让人低估它的重要性。

七、与增材制造的关联（跨笔记连接）

本笔记与《2026-09-09 万套级军用无人机押注增材制造》的 AEVEX×Divergent 产业逻辑直接相关：

传统工艺 AM 增材 材料选型影响
需要铸造/锻造毛坯 → 焊接 → 机加工 直接打印成品 焊接性约束消失（不需要焊了）
需要 5052 做钣金成形 直接打印复杂拓扑 成形性约束消失
受限于材料供货状态 打印后需热处理 状态约束变复杂（打印态 vs 热处理态性能不同）
应力腐蚀敏感（7075） 打印缺陷成为新的裂纹源 耐蚀性约束更严格

关键洞察：AM 时代，6061 和 7075 的相对地位会改变——因为 6061 的焊接优势（在 AM 中消失）不再是决定因素，而 7075 的高强度优势被进一步放大。但 SCC 问题在 AM 中更严重（打印缺陷提供裂纹路径），T7351 的过时效处理对 AM 件的价值可能高于传统件。

八、快速选型口诀（公众号版 + 增强）

公众号版：

通用结构、需要焊接、机加工、兼顾外观 → 6061-T6
极致高强轻量化、无焊接、室内干燥 → 7075-T7351
交变疲劳、耐热、高强铆接件、控成本 → 2A12-T4
钣金折弯冲压、焊接、潮湿耐蚀环境 → 5052-H32

增强版（加入温度维度和状态约束）：

50-150°C 温区、发动机舱、涡轮增压旁 → 2A12-T4（唯一）
交变疲劳 + 有应力集中（孔/圆角/间隙） → 2A12-T4（疲劳比高，缺口钝感）
极端高强度 + 无焊接 + 干燥环境 + 不抗 SCC → 7075-T651
极端高强度 + 必须抗应力腐蚀（海洋/航空关键件） → 7075-T7351
需要熔焊的结构件 → 6061-O（焊后不热处理）
需要熔焊的钣金件 → 5052-H32
大批量钣金/深冲/拉伸 → 5052-H32
CNC 精度件 + 成本敏感 → 6061-T6
必须标材质状态：图纸写 6061-T6 而非 6061，采购合同必须指定

九、局限性

  1. 公众号的优点/短板部分被图片替代——本笔记的技术数据来自外网核实，不是公众号原文
  2. 具体性能数据是"典型值"，实际受板材厚度、加工工艺、供应商工艺水平影响。工程设计必须以材料质保书（MTS）为准——公众号也明确说了这一点
  3. 本笔记覆盖 4 款材料，不覆盖：2024（航空传统 2xxx 主力，与 2A12 同系但 Cu 含量更高）、7050（7xxx 系新一代替代）、2219（2xxx 耐热型）、AlSi10Mg（AM 专用铝合金）等
  4. 温度边界数据（150°C）来自单一外网源（b2bwiki），未做多源交叉验证，实际工程请以材料数据手册为准
  5. 疲劳强度数据（7075 约 310 MPa、2A12 约 245 MPa）是 10⁷ 循环的常规值，实际疲劳寿命强烈依赖应力比 R、载荷谱、表面状态、环境腐蚀
