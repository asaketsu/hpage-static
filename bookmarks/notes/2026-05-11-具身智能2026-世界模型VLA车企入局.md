# 具身智能 2026: 世界模型 + VLA + 车企入局三浪叠加

**来源**: 36Kr, 新华网, 水清木华, 知乎  
**日期**: 2026-05-11  
**类型**: 机器人/具身智能

## 摘要

2026年是具身智能从"0到1"商业化闭环验证的关键年。三大趋势叠加：①世界模型让机器人获得"想象未来"能力；②VLA模型实现跨平台通用；③车企大规模入局解决数据稀缺和成本问题。中国处于全球第一梯队，人形机器人即将迈入十万台级量产。

## 关键要点

### 1. 世界模型：从"模仿"到"推演"
- **WorldVLA**(阿里)、**WAM**(英伟达)、**GE-1**(智元机器人)、**UnifoLM-WMA-0**(宇树科技) 等世界模型密集发布
- 核心能力：预测动作后果 → "脑内推演" → 主动决策
- 解决三大痛点：
  - **数据瓶颈**: 作为"数据生成器"产出高保真合成训练数据
  - **泛化能力**: 因果推理 + 物理直觉 → 处理未见过的场景
  - **大小脑协同**: 高层认知(世界模型) + 底层控制(VLA) 协同进化

### 2. VLA 跨平台应用
- 英伟达 **GR00T N1.6**: "一次训练、多机适配"，支持人形/机械臂/AGV/医疗/科研
- 星动纪元 **ERA-42**: 同一模型适配灵巧手/轮式/双足人形
- **核心突破**: 打破"每款机器人需专属算法"的传统模式

### 3. 车企入局：数据+供应链双重优势
- 特斯拉、小米、广汽、小鹏、比亚迪等 11 家车企布局
- 供应链重合度超50%（电池/电机/传感器/域控制器）
- 自动驾驶技术栈（BEV感知/端到端决策）直接迁移至机器人
- **小米 Xiaomi-Robotics-0**: 2026年2月开源，MoE架构，复用自动驾驶感知/决策技术
- **广汽 GoMate Mini**: 2027年规模化量产，安防场景首发

### 4. 开源趋势加速
- 开源模型汇总（截至2026年3月）：包括宇树 UnifoLM-WMA-0、小米 Xiaomi-Robotics-0 等
- "巨头搭台、百家唱戏"格局形成
- 正向飞轮：开源→生态→数据→更强模型

### 5. 中国政策体系
- 2025年具身智能首次写入《政府工作报告》
- "十五五"规划列为六大未来产业之一
- 北京/上海/深圳等城市密集出台专项政策
- 全国机器人训练场近30个

## 个人分析

具身智能是2026年最值得关注的AI赛道之一，原因：
1. **技术拐点明确**: VLA+世界模型的结合解决了此前"只会模仿不会思考"的根本问题
2. **中国优势突出**: 政策+制造+场景三重优势，成本和场景密度全球领先
3. **车企入局催化**: 不是简单的"车企造机器人"，而是自动驾驶→机器人的技术迁移路径
4. **对Hermes生态意义**: 具身智能的Agent架构（感知-决策-执行闭环）与Hermes的skill+event架构高度类似
