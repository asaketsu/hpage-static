内容整理

三条核心变化线

  1. 国产模型全面超越 Whisper：FireRedASR 和 Qwen3-ASR 在中文精度上已把 Whisper-Large-v3 甩开几个身位
  2. 非自回归（NAR）架构成为主流：SenseVoice 和 Paraformer 推理速度比 Whisper 快 10-30 倍
  3. ASR 不再只是转文字：情感识别、音频事件检测、说话人分离、语种识别成为标配

代码示例（SenseVoice-Small）

pip install funasr

from funasr import AutoModel
from funasr.utils.postprocess_utils import rich_transcription_postprocess

model = AutoModel(
    model="FunAudioLLM/SenseVoiceSmall",
    vad_model="fsmn-vad",
    device="cuda:0"
)
result = model.generate(input="meeting_recording.wav")
text = rich_transcription_postprocess(result[0]["text"])
print(text)
# 输出: [中性] 欢迎大家来体验达摩院推出的语音识别模型

查询拓展

  • CER（字错率）：ASR 核心评价指标，计算识别结果与正确文本之间的字符级编辑距离，越低越好
  • 非自回归（NAR）架构：不同于传统自回归模型逐 token 生成，NAR 模型一次性输出全部结果，速度极快但通常精度略低。代表：SenseVoice、Paraformer
  • VAD（语音活动检测）：从音频流中检测有语音的片段，ASR 前端必备模块。FunASR 的 fsmn-vad 是常用方案
  • 流式 ASR：边录边转，不等整句结束就输出识别结果。自回归模型天然支持，NAR 模型需要特殊设计

归纳总结

2026 年中文 ASR 格局已变：FireRedASR v2 称霸精度，SenseVoice-Small 统治速度和功能，FunASR 工具链称王生态。Whisper 在中文场景已无优势。选型逻辑应从"哪个最好"转向"哪个最适合我的场景"——有 GPU 追精度选 FireRedASR，无 GPU 追速度选 SenseVoice，不确定就从 FunASR 开始。

趋势判断

  1. NAR 架构成主流：非自回归模型在中文 ASR 场景的推理速度优势已不可逆
  2. 多模态融合：ASR + 情感 + 事件检测的一体化输出将成为标配
  3. 端侧 ASR 成熟：234M 参数即可 CPU 实时，端侧部署门槛持续降低
  4. 工具链竞争白热化：模型层差距缩小后，部署工具链（FunASR / sherpa-onnx）成为差异化竞争点

关联分析

  • 与 tts-backend-adapter 关联：ASR 选型逻辑与 TTS 引擎适配器模式一致——按场景选模型，策略模式无缝切换
  • 与 voice-assistant-service-stack 关联：本文 ASR 模型选型直接决定语音助手前端的识别质量和延迟
  • 与 Jetson 边缘部署关联：SenseVoice-Small 234M 在 Jetson Orin 上可 GPU 实时（170x），是端侧 ASR 最优解
  • 与 Hermes STT 降级链关联：当前 Hermes 语音链路用 faster-whisper small，可考虑切换到 SenseVoice-Small 获得更好中文精度+情感识别
