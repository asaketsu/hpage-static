一、领域定调：记忆是「下半场」的核心变量

arXiv 2602.06052《A Survey of Agent Memory in the Second Half》（Wei-Chieh Huang + 59 位作者，横跨 UIUC/UW-Madison/Salesforce/Meta/Google 等 60 家机构，TMLR 2026 Survey Certification）的立论：AI 研究重心正从「模型创新与基准分数」转向「问题定义与真实世界严格评估」。agentic coding / deep research / computer use 等长时程、动态、用户依赖场景里，LLM Agent 面临 context explosion，必须持续积累-管理-选择性复用信息——2025 年一年涌出数百篇记忆论文，记忆从被动存储升级为 Agent 自进化的基底（substrate）：

  • 短期记忆把关哪些经验在执行中被感知和抽象；
  • 长期记忆把经验固化为可复用的知识与技能；
  • 两者构成 Agent 从自身经验改进的闭环。

二、综述的三维统一框架

维度 划分 对应 Hermes 现状
记忆基底 substrate 内部参数状态 vs 外部检索增强存储 MEMORY.md（外存）+ Skills（外存可执行）
认知机制 mechanism 感官/工作/情景/语义/程序性 五类 会话上下文（工作）+ session DB（情景）+ MEMORY §条目（语义）+ SKILL.md（程序性）——五类俱全
记忆主体 subject 用户中心个性化 vs Agent 中心经验 USER PROFILE / MEMORY 两文件分离，正好踩在这个分类上

综述关键判断：记忆管理本身正在变成可训练能力——RL 学习的上下文策展（context curation）、决策时经验固化（decision-time consolidation）、可移植可共享的 Agent skills 生态。Hermes 的 skill_manage + curator 机制已在这个方向上，但缺「记忆操作的学习策略」层（哪些记忆何时写入/淘汰仍靠规则）。

三、Mem0 2026 生产数据：基准与架构演进

3.1 三大基准成为标准

  • LoCoMo：1,540 题，多会话对话记忆（单跳/多跳/开放域/时序）。
  • LongMemEval：500 题，六类（用户/助手/偏好召回、知识更新、时序推理、跨会话）。
  • BEAM：1M/10M token 规模，10 类任务——无法靠扩上下文窗口解决，最贴近生产。
  • 新秀 DolphinBench：600 任务，长对话+真实工具调用+可测任务结果。

Mem0 新算法成绩：LoCoMo 92.5 / LongMemEval 94.4 / BEAM(1M) 64.1 / BEAM(10M) 48.6，平均 ~6,900 tokens/查询（对比 2025 全上下文 ~26,000 tokens/对话）。增益最大的两类：时序推理 +29.6 分、多跳推理 +23.1 分——正是「事实随时间积累、变化、互相关联」的真实用户历史特征。

3.2 两个架构变化（可抄）

  1. 单遍 ADD-only 抽取：把 Agent 生成的事实（确认、建议）当作与用户陈述平等的一级公民存储——之前的管线只存用户说的，丢了 Agent 侧的一半覆盖面。
  2. 多信号检索：语义相似度 + BM25 关键词 + 实体匹配三路并行打分归一融合，任一单信号都被融合分击败。配套改动：外部图数据库（Neo4j）被替换为内置实体链接——add() 时抽实体存平行集合 {collection}_entities，检索时查询实体命中给相关记忆加分。代价是放弃了可遍历的图接口。

3.3 竞品对比（第三方口径）

Mem0 92.5 / Zep 80.32@189ms / Letta 74.0（其自研主张简单文件存储有竞争力）/ OpenAI Memory 52.9。

3.4 生态规模

21 框架集成（LangChain/LangGraph/LlamaIndex/CrewAI/AutoGen/OpenAI Agents SDK 等）+ 20 向量库；语音是增长最快场景（ElevenLabs/LiveKit/Pipecat——语音会话用户无法回滚找回上下文，记忆缺失的摩擦即时可见）。

3.5 三个最难开放问题

跨会话身份（同一用户多线程/多平台识别）、大规模时序抽象、记忆陈旧化（staleness）。

四、前沿衍生工作（Awesome-Self-Evolving-Agents 甄选）

  • MemSkill (arXiv'26)：学习并进化记忆技能本身——记忆操作元学习。
  • MemRL (arXiv'26)：情景记忆上的运行时强化学习，Agent 自进化新路径。
  • A-Mem (NeurIPS'25)：Agent 式记忆组织。
  • Memgen (ICLR'26)：生成式潜在记忆编织。
  • GLoW (2026)：双尺度文本世界记忆（全局高价值发现前沿 + 局部优势反思）驱动 Go-Explore，比 RL 基线少 100-800 倍真实环境交互——对真机样本昂贵的 DUCK 场景极具启发。

五、对 Hermes 的四条镜鉴

  1. hybrid-search skill 的三信号融合（semantic+keyword+entity）与 Mem0 2026 生产结论独立收敛——方向正确，但缺「融合分归一化」细节，值得对齐其开源 memory-benchmarks 仓库的实现。
  2. MEMORY.md 已 98% 满 = 典型 staleness + 时序抽象缺失。§条目是纯追加式语义记忆，没有遗忘曲线/置信衰减/版本标注（哪条已被后续判决推翻——E28 假 PASS 教训正是靠人工对拍才发现）。处方：给 §条目加状态标（active/superseded/dead）+ 周度 memory-consolidation cron 里加「被引用但已判死条目」扫描。
  3. ADD-only 抽取对 Hermes 的映射：session-evolution-scan 只扫用户纠偏，不扫「Agent 自己验证成功的结论」——后者同样是可固化经验（如 v7 IMU 分读修复这种自证有效的事实）。
  4. GLoW 的经验前沿思想：把「已验证有效的修复配方」组织成全局前沿（高价值发现）而非散在 error-case-library，检索时先打前沿再打细节——error-case-library 目前是平的，缺价值分层。

七、指南分析（怎么用这批材料）

  • 记忆系统选型/重构：直接抄 Mem0 双架构变化（ADD-only 平等抽取+三信号融合归一）与开源 memory-benchmarks 的评测框架，LoCoMo/LongMemEval 双基准跑分再谈架构优劣。
  • 给用户讲解：一句话版「2026 年记忆系统=多信号检索（不迷信单一向量）+把 Agent 自己验证过的事实平等入库+记忆管理本身可学习；纯追加式记忆必然遭遇陈旧化」。
  • 避坑速查：①单一向量检索已被三信号融合全面击败，新项目禁单押 embedding；②图数据库接口与实体链接是取舍关系（部署成本 vs 可遍历性）；③~6,900 tokens/查询是生产可行线，26,000 tokens 级系统不可部署。

八、拓展应用推荐

  1. MEMORY 陈旧化治理（最直接）：给 MEMORY.md §条目加状态标（active/superseded/dead），memory-consolidation 周扫「被引用但已判死」条目——E28 假 PASS 靠人工对拍才发现的教训制度化为自动扫描。
  2. hybrid-search skill 对齐 Mem0 开源实现：补三信号融合归一化细节（语义+BM25+实体匹配打分归一），对照 memory-benchmarks 仓库校准。
  3. session-evolution-scan 扩容：从「只扫用户纠偏」扩为「Agent 自证有效结论」也入候选（ADD-only 平等抽取原则）——v7 IMU 分读修复这类自验证事实目前不进进化候选。
  4. error-case-library 价值分层：借 GLoW 双尺度思想，把「已验证有效配方」提升为全局前沿层，检索先打前沿再打细节。
  5. 周论文候选：「信用分配的同构性：RL 奖励路由 × 记忆检索路由」——两篇今日笔记的交叉命题，查重后可写。

九、趋势判断

  1. 记忆从组件升级为自进化基底：短期记忆管感知抽象、长期记忆管经验固化，自进化=两者闭环——2026 综述的统一叙事，Skill 生态（可移植共享）是其生产形态。
  2. 基准成熟倒逼架构收敛：LoCoMo/LongMemEval/BEAM 三基准+DolphinBench 使记忆架构第一次可横向比较，头部方案差距（92.5 vs 52.9）证明架构选择影响大于模型选择。
  3. 时序推理与多跳是决胜局：Mem0 最大增益（+29.6/+23.1）恰在事实随时间变化的场景——陈旧化检测与知识更新将从附加功能变为核心能力。
  4. 语音 Agent 是记忆的最强拉动场景：用户无法回滚语音上下文，记忆缺失摩擦即时可见——ElevenLabs/LiveKit/Pipecat 集成增速佐证。
  5. 运行时学习（MemRL 类）与情景记忆结合：不改权重、在记忆上做 RL 的自进化路径，与 Hermes 的 evolver/sensor-grid 方向独立收敛。

九、查询拓展

  • Awesome-Agent-Memory：综述配套仓库，60 机构联合维护。
  • MemSkill (arXiv'26)：记忆技能元学习——「学习如何记忆」的可训练化。
  • A-Mem (NeurIPS'25)：Agent 式记忆组织，主动式而非被动存取。
  • Zep (arXiv 2501.13956)：时序知识图架构的对手路线，80.32@189ms 的延迟-精度权衡样本。
  • hybrid-search skill（本地已有）：三信号融合的 Hermes 实现，可对照 Mem0 开源版校准归一化细节。

十、内容整理（归纳总结与关联分析）

归纳总结：2026 记忆领域共识公式=多信号检索（语义+BM25+实体三路并行融合）+Agent 侧事实平等入库（ADD-only）+记忆管理可训练化（RL 策展/决策时固化/技能生态）。基准侧 LoCoMo(1540题)/LongMemEval(500题)/BEAM(1M-10M token) 成为标准，BEAM 证明扩上下文窗口不可解。开放难题三件套：跨会话身份、大规模时序抽象、记忆陈旧化——全部指向「纯追加式记忆」的系统性软肋。

关联分析：综述三维框架（基底/机制/主体）映射到 Hermes 现状发现五类认知机制俱全但缺「记忆操作学习层」；Mem0 的实体链接增强检索与本地 hybrid-search skill 独立收敛，验证方向正确；MEMORY.md 98% 满载是陈旧化难题的活例（§条目纯追加、无状态标注，E28 假 PASS 靠人工对拍才发现已判死）。GLoW 的双尺度经验前沿（全局高价值发现+局部优势反思）与 DUCK 的 error-case-library 平铺结构形成对照——缺价值分层。与 [[2026-10-06-步态条件奖励路由-多姿态单策略RL]] 的共同命题：信用分配——RL 里是 reward mask 路由梯度，记忆里是检索信号路由注意力，结构同构。
