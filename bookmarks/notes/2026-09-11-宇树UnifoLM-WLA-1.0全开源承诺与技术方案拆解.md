## 二、三层架构拆解（技术方案的核心价值）

### 2.1 架构总览

```
第一层：具身推理 UnifoLM-ER-1（Qwen3-VL-4B 底座）
  ↓ 提供：场景理解/空间关系/多视角推理
第二层：未来动态区域预测（VQ-VAE 压缩 + mask token）
  ↓ 提供：交互会改变哪里的预测信号
第三层：动作生成（RVQ 动作 token + MMDiT 动作专家）
  → 输出：连续控制动作
```

### 2.2 每层机制白话拆解

| 层 | 机制 | 白话 |
|----|------|------|
| **具身推理 ER** | Qwen3-VL-4B + 500 万样本（点预测/检测/多图推理/2D 轨迹/3D 检测/空间问答） | 不只认出"盘子"，还要知道盘子在哪、手该从哪接近、多视角怎么对齐——感知底座 |
| **变化预测** | 相邻帧光流找变化区域 → VQ-VAE 压成离散 token → 预测"下一步哪些区域会变" | **不生成整个未来画面，只盯"动作会改变哪里"**——手靠近杯子，变化区域跟着杯子走 |
| **动作学习** | 统一动作空间拆三块（末端位姿/末端关节/下肢关节）→ RVQ 残差量化成离散 token → 与变化 mask token 在 VLM 中对齐（UnifoLM-ER-Flow）→ MMDiT 动作专家输出连续动作 | "一个模型多任务"不是 64 个技能塞一个文件，是共享"感知→变化→动作"链路 |

### 2.3 与 BeyondMimic 的架构对照

| 维度 | BeyondMimic（09-10 笔记） | UnifoLM-WLA |
|------|--------------------------|-------------|
| 范式 | 两阶段蒸馏：VLA 教师 → 扩散学生 | 三层串联：VLM → 变化预测 → 动作专家 |
| 动作表示 | 扩散去噪 | RVQ 离散 token → MMDiT 连续输出 |
| 任务 | 特技跟踪（单一技能族） | 通用 64 任务（桌面+全身） |
| 数据 | 仿真+MoCap | ~2500h 真机 |
| **共同点** | **都在"理解→预测→行动"链路上做文章**；都把动作生成与场景理解分层 | 同左 |

**收敛信号**：两条完全不同的路线（蒸馏 vs 串联）都选择了"分层架构 + 共享感知表征"——这是本周机器人主题簇（BeyondMimic/UnifoLM/RIG-Hover LQR）的第三个独立收敛：**通用性来自共享中间表征，不来自任务堆叠**。

## 四、未回答的工程问题（决定开源价值的关键）

文章列出的六个待验证问题（资源上线后逐项核）：

1. 动作 tokenizer 的码本如何训练？
2. 不同机器人本体如何映射到统一动作空间？
3. ~2500 小时数据的任务分布？
4. 64 项真机评测每项跑了多少次？
5. **推理延迟能否满足闭环控制？**（与我们 TTFT/延迟主题直接相关——6B 模型 onboard 推理的实时性是硬门槛）
6. 换场景/物体/末端执行器后的成功率？

1. **文章本身质量高**：不替官方补 WLA 全称（"官网没有给出，本文不替宇树补定义"——克制）、标注 2x Speed、给失效条件——科普文中罕见的诚实样本
