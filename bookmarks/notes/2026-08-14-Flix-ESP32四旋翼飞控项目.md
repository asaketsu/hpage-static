## 核心结论

**Flix 是一套基于 ESP32 的开源四旋翼项目，飞控固件采用 Arduino 风格，主循环约 1000Hz，涵盖 IMU 读取、姿态估计、级联 PID、电机混控、MAVLink 遥测和失控保护。三条学习路径：裸板验证（最低成本）→ Gazebo 仿真（无硬件）→ 真机组装试飞（完整硬件）。**

## 项目定位

```
成品无人机负责飞，Flix 负责把"为什么能飞"摊开给你看。
```

- **适合**：想拆开飞控学明白的人，动手调试飞控全过程
- **不适合**：想买台开箱即飞的航拍机（有一定门槛：焊 MOSFET、检查电机方向、校准 IMU、处理锂电池）

## 三条学习路径（不先买齐零件）

| 路径 | 成本 | 内容 | 适合 |
|------|------|------|------|
| **裸板验证** | 一块裸 ESP32 | 烧录后出现 `flix` Wi-Fi，命令行 + QGroundControl 基础连接测试 | 验证编译/USB/无线 |
| **Gazebo 仿真** | 免费（Ubuntu 20.04） | 理解飞行模式、摇杆输入、参数变化 | 无硬件先试 |
| **完整硬件** | ~1 套零件 | 先拆桨检查，USB 驱动/编译/Wi-Fi/IMU/电机分开排错 | 动手组装 |

## 硬件清单

| 类型 | 器件 | 说明 |
|------|------|------|
| 主控 | ESP32（WEMOS D1 MINI）或 ESP32-S3 | 板载 Wi-Fi + BLE |
| IMU | GY-91（MPU9250）/ ICM-20948 / MPU-6050 | SPI 或 I2C 接口 |
| 电机 | 4 通道 3.7V 无刷/有刷 | 轴径需匹配桨孔 |
| 驱动 | 4× MOSFET | 每路配下拉电阻 |
| 机架 | 3D 打印（官方 STL/STEP） | 0.2mm 层高 0.4mm 线宽 100% 填充 |
| 遥控 | 手机 / USB 手柄 / SBUS 接收机 | QGroundControl 控制 |
| 工具 | 电烙铁/焊锡/助焊剂/万用表/螺丝刀 | |

## 详细教程（11 步）

### 第一步：下载源码
```bash
git clone https://github.com/okalachev/flix.git
cd flix
# 锁定验证提交
git checkout d64bf24c6d1b18e7b9ef7093c395ac176568118c
```

### 第二步：配置 Arduino IDE
- Arduino Core `3.3.10` + `FlixPeriph` + `MAVLink 2.0.25`
- 板型 `WEMOS D1 MINI ESP32`，打开 `flix/flix.ino`
- `Tools → Core Debug Level → Error`
- `USB CDC on Boot → Enabled`
- 命令行：`make` / `make upload` / `make upload monitor`
- ESP32-S3：`make BOARD=esp32:esp32:esp32s3:DebugLevel=error,FlashSize=4M,CDCOnBoot=cdc upload`

### 第三步：裸板验证
- 串口 115200，输入 `help` 看命令列表
- 搜到 `flix` Wi-Fi（默认密码 `flixwifi`）
- 修改默认 SSID/密码：`ap my-flix-ssid mypassword123` + `p WIFI_MODE 1`（重启生效）

### 第四步：打印/焊接
- 官方机架 STL/STEP，0.2mm 层高 / 0.4mm 线宽 / 100% 填充
- ESP32 Mini 与 IMU 用 SPI 接线
- **电机 GPIO：后左12 / 后右13 / 前右14 / 前左15**，每路 MOSFET 配下拉电阻
- 电机位置/转向/桨型以当前 `motors.svg` 为准

### 第五步：选 IMU 型号（`flix/imu.ino`）
```cpp
MPU9250 imu(SPI);     // 默认 GY-91
ICM20948 imu(SPI);    // 改 ICM-20948
MPU6050 imu(Wire);    // 改 MPU-6050（I2C）
```

### 第六步：连接 QGroundControl
- `Vehicle Setup → Analyze Tools → MAVLink Console`
- 连不上检查防火墙/VPN

### 第七步：IMU 朝向 + 校准
- 三个参数：`IMU_ROT_ROLL/PITCH/YAW`，默认 `0, 0, 1.571`
- 控制台运行 `ca`，依次保持各姿态 8 秒

### 第八步：拆桨检查 IMU
- 控制台 `imu`：`status: OK`，采样率 ~1000Hz，静止 `landed=1`

### 第九步：电池测四电机（无桨状态）
- `mfr`/`mfl`/`mrl`/`mrr` = 前右/前左/后左/后右
- 位置或方向不对先修接线，别用软件硬顶

### 第十步：配置遥控
- 手机：启用 `Virtual Joystick` + 关 `Auto-Center Throttle`，降 `CTL_TILT_MAX` 应对灵敏
- USB 手柄：`Vehicle Setup → Joystick` 校准
- SBUS：`p RC_RX_PIN 4` + `rc` + `cr`

### 第十一步：低高度首飞
- 左摇杆油门+偏航，右摇杆俯仰+横滚
- 右下角解锁，左下角上锁
- `STAB` 稳定姿态（会漂移），`RAW` 测试用，`AUTO` 有推力指令自动解锁

## Gazebo 仿真（无硬件）

- Ubuntu 20.04 + Gazebo 11 + CMake + SDL2，按 `gazebo/README.md` 构建
- Python 侧 `pip install pyflix`：

```python
from pyflix import Flix
flix = Flix()
print(flix.connected)        # 连接状态
print(flix.attitude_euler)   # 姿态
print(flix.voltage)          # 电压
flix.set_mode("AUTO")
flix.set_attitude([0.1, 0.2, 0.3], 0.6)  # 姿态+推力
flix.set_attitude([0, 0, 0], 0)          # 归零
```

## 关键限制

| 限制 | 说明 |
|------|------|
| `set_position`/`set_velocity` 不可用 | 目录中不存在（无位置控制） |
| `delay()` 相关可能有问题 | 循环依赖 |
| 真机执行 AUTO 前 | 先确认失控保护/遥控接管/场地安全 |
| 无线命令行入口 | `Vehicle Setup → Analyze Tools → MAVLink Console` |
| Settings 是 Apache-2.0 | `LICENSE`/`COPYING` |
