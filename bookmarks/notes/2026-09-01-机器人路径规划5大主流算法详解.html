一、内容详细整理

核心问题定位

原文开篇即纠正一个常见误解：机器人导航的核心问题并不是"单纯抵达目标"，而是——在拥挤环境、复杂障碍物和难以预先穷尽的突发变化中，持续做出安全、可执行的移动决策。

文章沿着"如何解决不同环境难题"这条主线，将常见路径规划范式重组为五条技术路线：

路线 核心问题 代表算法 强项 失效条件
① 图搜索 有完整地图时如何找路 Dijkstra / A / Hybrid A 全局连通性保证 依赖预建地图；高维网格爆炸
② 采样方法 空间维度太高如何快速穿越 RRT / RRT* / PRM 高维构型空间可行解 狭窄通道概率极低；路径锯齿
③ 人工势场 突发障碍如何瞬间反应 APF 及变体 计算量小、近场快速避障 局部极小值（U 型陷阱）
④ 最优控制 动作逼近物理极限如何踩稳 MPC 显式写入扭矩/摩擦等物理约束 依赖模型质量与快速求解器
⑤ 强化学习/AI 环境规则无法穷举如何靠直觉 DRL / LLM 分层 非结构化场景习得避障反应 Sim2Real 差距；决策难解释
— 分层协同 — 上述组合 工程主流路线 —

① 图搜索：先切碎环境，再搜索连通

思路：把连续物理环境"切碎"成离散网格或节点图，然后搜索算法在节点中寻找连通路径。前提是地图较准确、代价定义明确。

  • Dijkstra：按起点到各节点累计代价依次扩展。边权非负时保证最短路径，但访问节点多（均匀扩张）。
  • A*：加入启发式函数——已走代价 + 到终点距离预估，优先检查靠近目标的区域，减少不必要搜索。前提：启发函数与实际代价匹配。
  • Hybrid A*（自主泊车案例）：车位狭窄 + 阿克曼转向几何约束 → 传统 A* 折线无法直接行驶。改进：扩张状态时就把车辆朝向和最大转向角纳入，得到满足运动学条件的粗路径，再交底层控制拟合平滑。

失效模式：
1. 高度依赖预建地图——执行中遇未建模突发障碍，缺乏对未来状态的预测 → 频繁停顿或规划失败
2. 高自由度机械臂三维避障 → 网格数量爆炸 → 实时性不满足（维度灾难）

② 采样方法：高维空间里随机"撒点"

思路：不死磕精确网格，在状态空间随机/伪随机采样 + 碰撞检测，把安全点连成路径。

  • RRT（快速探索随机树）：以起点为根，随机采样向外长"枝干"直到触及终点，是高维运动规划的常用工具。
  • 典型场景：7 自由度机械臂底盘机器人从杂乱桌面抓水杯——构型空间维度极高，网格搜索直接失效；用 RRT/PRM 在关节空间采样 + 碰撞检测。
  • 近期改进方向：目标偏置采样、受限空间采样（减少无方向扩张）+ 候选路径平滑处理。

失效模式：
1. 狭窄通道问题——必须穿过门缝/密集间隙时，随机采样命中概率极低 → 规划超时
2. 随机性导致每次路径不同、常呈锯齿折线 → 部署必须额外串联平滑模块
3. 面对快速移动的动态障碍物，重规划实时性难保证

③ 人工势场：近场本能反应

思路：借鉴电磁场概念——目标点产生"引力"，障碍物产生"斥力"，机器人沿合力方向（势能下降方向）"滑"向目标。

  • 典型用法：服务机器人应对突然闯入的行人——全局规划无法每瞬间重算，APF 作为底层反应式避障。雷达/相机检测到靠近障碍时，根据相对位置与速度调整斥力项，改变航向或减速让行。
  • 优点：数学直观、计算量小、适合快速更新的近场避障；势场方向信息便于转成底盘速度/转向参考。

失效模式：
1. 局部极小值——U 型障碍内部或引力斥力恰好抵消时陷入停滞/原地打转
2. 目标点紧贴墙壁时，强斥力把机器人推开 → 永远无法抵达终点

工程定位：实际系统常将 APF 放在全局路径之后，作近场修正或局部避障一环。

④ 最优控制：物理极限下每步踩稳

思路：路径规划 = 带约束的最优化数学问题。MPC（模型预测控制）是典型代表。

  • MPC 工作机制：在有限时间窗口内预测系统状态 → 解带约束优化问题 → 只执行当前最优动作的第一步 → 下一周期根据新状态滚动更新。
  • 四足机器人高动态控制是常见路线：腿足机器人需持续决定落点、关节力矩与机身姿态；研究者在跑道、草地、人工草坪、实验室等多种地面与扰动条件下验证控制框架。
  • 价值：电机扭矩、摩擦条件等约束显式写入优化问题，轨迹贴近动力学可行范围。

失效模式：依赖模型质量与快速求解器——面对未建模接触、传感误差或算力不足时性能明显下降。

⑤ 强化学习与 AI：规则无法穷举时靠直觉

思路：DRL 让智能体在仿真或真实环境中通过奖励信号学习策略，直接把激光雷达/相机观测映射为速度或转向动作。

  • 适用：传统建模难以覆盖的非结构化场景，如移动机器人在拥挤室内学习局部脱困策略。
  • 落地门槛：① Sim2Real 差距——仿真有效策略在真实环境性能下降；② 神经网络决策难解释，验证与安全评估困难。

更稳妥的工程路线（原文明确观点）：不是完全用神经网络替代规划器，而是分层——LLM 负责高层语义理解。例："去书房拿杯子"指令 → 感知算法在地图上锚定家具/物品位置（空间语义锚点）→ LLM 拆解为子目标 → 底层导航模块依然调用传统搜索与控制算法规避物理障碍。

分层协同：工程主流结论

原文结尾的核心论断——五条路线解决的是不同问题：图搜索提供全局连通性，采样方法解决高维可行性，APF 处理近场快速反应，最优控制保证物理约束下的动态稳定，AI 方法补充感知与语义决策。

实际具身智能系统中往往配合使用：先用 A*（低分辨率）确认门的位置 → 再用 RRT 在门附近精细化采样 → 底层始终开着 APF 防撞 → MPC 负责执行微调。

与其寻找一套能解决所有路径规划问题的完美算法，不如回到更实际的问题：在给定任务、算力和安全边界下，什么算法组合最可靠？

查询拓展

  • A* 启发函数可采纳性（admissible）与一致性（consistent）：原文提到"启发函数与实际代价匹配"是 A 效率前提，可深挖 h(n) ≤ h(n) 的数学保证与违反时的路径次优
  • RRT* 渐近最优性：原文图 4 出现 RRT*，其 rewiring 机制如何把"可行"变"最优"
  • 狭窄通道问题的专门解法：如 Bridge Test 采样、Gaussian 采样、多树 RRT-Connect 等
  • MPC 求解器选型：QP（OSQP）、SQP、iLQR 在腿足控制实时性上的对比
  • Hybrid A* 原始论文（Dolgov et al., Stanford，DARPA Urban Challenge 背景）的运动学 primitive 设计
  • DWA/TEB：文章未提但属于局部规划器生态（ROS nav2 默认栈），与 APF 定位重叠可对比

归纳总结

  1. 五流派 = 五个不同的"信息假设"：图搜索假设有全图、采样假设无图但高维、APF 假设只需近场、MPC 假设模型可写、RL 假设规则不可穷举但奖励可定义。选型本质是问"我手里有什么信息"。
  2. 每个流派都有明确的失效条件，且互为补集：图搜索怕未知+高维、采样怕窄通道、APF 怕局部极小、MPC 怕模型误差、RL 怕 Sim2Real——这正是分层架构成立的逻辑基础。
  3. 工程主流不是选一个，而是分层组合：全局（A*）→ 区域精细化（RRT）→ 近场防撞（APF）→ 执行（MPC）→ 语义（LLM），各管一段。
  4. 原文立场鲜明反对"万能算法"叙事：正确的问题是"给定任务、算力和安全边界下的最优组合"，而非"最先进的单一算法"。

二、趋势判断

  1. 分层架构是当前工程主流，短期不会变：纯端到端（观测→动作）在安全验证与可解释性上仍不过关，LLM 做语义层 + 传统算法做几何/动力学层的分工将持续。高飞团队课程体系（搜索/采样/动力学/MPC）本身即印证教学界仍以经典方法为骨架。
  2. "门缝测试"将成为具身智能的标尺场景之一：原文用"仅比自身宽 5 厘米的门"统一检验五类算法，这类极端狭窄场景天然区分算法能力边界，预计会更多出现在 benchmark 设计中。
  3. RL 与经典方法的融合点在"局部策略"：DRL 不替代全局规划，而是学习"拥挤室内脱困"这类传统建模难覆盖的局部反应——与 APF 的反应式定位形成新旧对照。
  4. 约束显式化（MPC 路线）与数据驱动（RL 路线）的双线并进：四足/人形高动态平台爆发（宇树等）持续给 MPC 输送场景，同时 Sim2Real 研究持续缩小 RL 落地差距，两线在中层（局部规划器）交汇竞争。

指南分析

适用场景判定表（从原文提炼，可直接用于选型）：

你的情况 首选路线 理由
有准确地图、低自由度（2D 底盘） A* / Dijkstra 全局最优+连通性保证，算力便宜
泊车等运动学约束场景 Hybrid A* 朝向+转向角纳入搜索状态
高自由度机械臂、无栅格地图 RRT / PRM 关节空间采样避开维度灾难
动态行人密集的近场避障 APF（作局部层） 计算快，但需防局部极小
四足/人形高动态、需力矩约束 MPC 物理约束显式入优化
非结构化、规则难穷举 DRL（局部策略） 从交互学反应，注意 Sim2Real
语义指令 → 导航任务 LLM 高层 + 传统底层 拆解子目标，底层保持可靠

实施要点：
1. 先问"手里有什么信息"（全图？模型？奖励？），再选流派——信息假设错配是选型失败的第一原因
2. 任何单一算法都不该裸奔部署：RRT 后接平滑、APF 前置全局路径、RL 前置安全层
3. 算力预算纳入选型变量：MPC 对求解器延迟敏感，嵌入式平台（如 Pi 5）上需实测 QP 求解时间
