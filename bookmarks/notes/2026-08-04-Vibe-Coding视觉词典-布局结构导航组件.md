## 核心问题

> 很多人让 AI 做网页时只会说："帮我做一个高级、简洁、有设计感的网站。"

问题在于，"高级""简洁""有设计感"都不是明确的网页结构。AI 不知道内容应该怎么排，也不知道用户应该怎么浏览和操作。

### 网页四层拆解

一个完整网页可以先拆成四层：

1. **布局 Layout** — 页面上的东西怎么排
2. **页面结构 Page Structure** — 内容按什么顺序出现
3. **导航 Navigation** — 我在哪里、还能去哪里
4. **组件 Components** — 点击、输入、展开、关闭如何发生

每个词条只保留三部分：**概念说明 → 适用场景 → 可直接复制给 AI 的提示词**。

## 第一章：页面布局 Layout

> 决定内容如何占据屏幕：整齐排列、错落排列、左右分屏，还是由大小不同的模块组成。

### 1. 卡片式布局 Card-based Layout

把内容拆成一张张独立卡片，每张卡片承载一个项目、一篇文章、一项服务。卡片之间边界清楚，浏览速度快，也是 **AI 最容易稳定实现**的布局之一。

**适用**：作品集、博客列表、功能介绍、工具导航、商品列表、个人主页

### 2. 瀑布流 Masonry Layout

卡片宽度大致一致但高度不统一，内容像瀑布一样自然错落。不强迫每一行严格对齐，特别适合不同尺寸的图片。

**适用**：AI 生图作品集、摄影集、灵感墙、案例封面、视觉型博客

### 3. 便当盒布局 Bento Grid

用大小不同的矩形模块组成页面。最大区域展示核心内容，小模块放技能、文章、联系方式。**依靠尺寸差异建立视觉优先级。**

**适用**：个人主页、产品首页、SaaS 首页、创作者网站、AI 工具展示页

### 4. 分屏布局 Split-screen Layout

页面分成左右两部分，常见是左边文字、右边视觉，或一边固定、另一边滚动。信息和视觉同时成为主角。

**适用**：个人首页、产品介绍、登录页、创意作品集、对比页面

### 5. CSS 网格布局 CSS Grid Layout

按明确的行和列组织页面，适合处理二维关系。不同模块占据不同列宽，构建规则或非对称的复杂页面。

**适用**：复杂首页、杂志排版、Dashboard、非对称作品集、响应式模块

### 6. 弹性布局 Flexbox

让一组元素沿一个主要方向排列，最适合处理一行或一列中的对齐、间距和顺序。

> **Punk 网站顶部导航使用 Flexbox**：左侧 Logo，右侧导航 + 主题切换；`justify-content: space-between` + `align-items: center`；小屏幕隐藏文字导航并显示 Hamburger Menu。

**适用**：顶部导航、工具栏、按钮组、标签、头像与文字组合、卡片内部

### 7. 侧边栏布局 Sidebar Layout

页面一侧长期保留一条栏，另一侧显示主要内容。侧边栏可承载个人信息、分类、目录、筛选器。

**适用**：博客、文档站、后台、作品归档、设置页

### 8. 仪表盘布局 Dashboard Layout

由侧边导航、顶部工具栏、统计卡片、图表、表格和最近活动构成，强调信息密度与任务效率。

**适用**：个人内容后台、项目管理、数据产品、CMS、AI 工具控制台

### 9. 响应式布局 Responsive Layout

同一个网页根据屏幕尺寸重新排列，而不是把桌面页面整体缩小。桌面、平板和手机应有不同的布局状态。

**适用**：几乎所有公开网页

### 10. 全出血布局 Full-bleed Layout

图片、视频或颜色区域一直延伸到屏幕边缘，不受普通内容容器限制。常用于制造沉浸式首屏或章节过渡。

**适用**：品牌首页、作品开场、摄影网站、产品发布页、沉浸式故事

## 第二章：页面结构 Page Structure

> 决定用户先看到什么、接着看到什么，以及一个页面如何讲完一件事。

### 11. 单页网站 Single-page Website

所有主要内容放在同一页面中，通过滚动或锚点导航浏览 Hero → About → Projects → Writing → Contact。

**适用**：个人名片、轻量作品集、活动页、早期产品介绍

### 12. 多页网站 Multi-page Website

不同内容拥有独立页面和网址（首页、作品列表、项目详情、关于、文章、联系），更适合长期扩展。

**适用**：成熟作品集、博客、企业官网、内容站、项目较多的网站

### 13. 落地页 Landing Page

围绕一个明确目标组织页面，用户被引导完成注册、购买、预约、下载。**每一部分都服务于同一个行动。**

**适用**：AI 产品、课程、活动、Newsletter、个人服务、作品发布

### 14. 案例研究页 Case Study Page

不仅展示最终效果，还讲清：背景 → 问题 → 过程 → 关键决策 → 方案 → 结果 → 复盘。

**适用**：设计师作品集、开发者项目、产品项目、品牌案例、求职作品集

### 15. 首屏 Hero Section

用户打开页面最先看到的区域，负责快速回答：**你是谁、你做什么、为什么值得继续看、下一步该点哪里。**

**适用**：几乎所有首页和 Landing Page

### 16. 功能网格 Feature Grid

用 3-6 个并列模块介绍能力、服务或功能，每个模块通常包含图标、标题和短说明。

**适用**：能力介绍、产品功能、服务清单、优势展示

### 17. 固定叙事区 Sticky Storytelling

一侧内容固定，另一侧随滚动依次出现不同阶段，让复杂过程像讲故事一样被阅读。

**适用**：产品故事、项目过程、时间线、复杂功能解释、品牌叙事

### 18. 时间线 Timeline

用一条线和多个节点按时间顺序展示经历、版本、里程碑。

**适用**：职业经历、项目里程碑、产品版本、公司历史、学习路径

### 19. 常见问题 FAQ Section

常见问题集中放在页面末段，通过折叠面板展开答案。

**适用**：服务说明、产品定价、课程、合作流程

### 20. 页脚 Footer

页面最底部的收尾区域：站点导航、社交链接、联系方式、版权、订阅入口。

**适用**：所有完整网站

## 第三章：导航与切换 Navigation

> 决定用户怎样在页面和内容之间移动：我在哪里、我还能去哪里、点击后会发生什么。

### 21. 固定导航 Sticky Navbar

页面向下滚动时顶部导航仍然可见。

**适用**：长页面、单页网站、文档、Landing Page、作品集

### 22. 汉堡菜单 Hamburger Menu

手机端右上角三条横线按钮，点击后展开或滑出完整导航。

**适用**：移动网站、小屏界面、极简导航

### 23. 面包屑 Breadcrumb

页面顶部显示层级路径，如"首页 › 作品 › AI 工具 › 项目详情"。

**适用**：多层级网站、电商、博客、文档、项目详情页

### 24. 锚点跳转 Anchor Link

点击导航后不打开新页面，而是移动到当前页面中的指定区块。

**适用**：单页网站、长文章、Landing Page、文档目录

### 25. 标签切换 Tabs

多个标签共用同一块内容区域，一次只显示一个视图。

**适用**：内容分类、数据视图、设置、作品分类

### 26. 侧边导航 Sidebar Navigation

主要导航长期放在左侧或右侧，适合入口较多、层级较深的系统。

**适用**：后台、文档、设置页、复杂工具

### 27. 超级菜单 Mega Menu

点击主导航后展开一个面积较大的多列菜单，可同时展示分类、子页面和精选内容。

**适用**：内容很多的网站、产品矩阵、资源中心

### 28. 底部导航 Bottom Navigation

手机屏幕底部长期显示 3-5 个最重要的入口。

**适用**：移动 Web App、Dashboard、内容工具、创作工具

### 29. 分页 Pagination

把长列表拆成多个固定页面，用户通过页码或上/下一页切换。

**适用**：博客归档、搜索结果、后台表格、作品列表

### 30. 返回顶部 Back to Top

页面滚动到一定距离后右下角出现返回顶部按钮。

**适用**：长文章、长作品页、文档、长列表

## 第四章：常用组件 UI Components

> 组件是页面中的局部交互单元：点击、输入、展开、关闭和反馈应该如何发生。

### 31. 模态框 Modal

覆盖在当前页面之上的对话框，背景被遮罩，用户需先处理或关闭才能回到页面。

**适用**：联系表单、确认操作、登录、快速预览、必须立即处理的任务

### 32. 抽屉 Drawer

从屏幕左侧、右侧或底部滑出的面板，展示导航、筛选、设置或详情。

**适用**：移动导航、筛选、设置、详情预览、购物车、通知中心

### 33. 手风琴 Accordion

多组标题纵向排列，点击标题后展开或收起对应内容。

**适用**：FAQ、移动菜单、筛选器、课程目录、分组说明

### 34. 气泡提示 Tooltip

鼠标悬停或键盘聚焦到图标时，旁边出现一小块简短说明。只适合补充短信息。

**适用**：图标解释、术语补充、按钮名称、图表数据说明

### 35. 轻提示 Toast

完成操作后在页面角落短暂出现的状态消息，**不会像 Modal 一样中断用户**。

**适用**：保存、复制、发布、删除、网络状态和轻量操作反馈

### 36. 轮播图 Carousel

在有限空间中轮流展示多个项目，通常带有左右箭头、圆点指示和序号。

**适用**：精选项目、客户评价、产品截图、活动 Banner

### 37. 图片灯箱 Lightbox

点击缩略图后在遮罩层上放大显示原图，支持关闭、切换和查看标题。

**适用**：摄影、AI 作品、插画、项目截图、视觉作品集

### 38. 表单 Form

由输入框、标签、选择器、复选框和提交按钮组成。

**适用**：联系、订阅、登录、搜索、预约、设置

### 39. 命令面板 Command Palette

按下快捷键后弹出的快速搜索与操作面板，用户可通过键盘跳转页面或执行命令。

**适用**：开发者工具、文档站、复杂个人网站、Dashboard、效率工具

### 40. 悬浮操作按钮 Floating Action Button (FAB)

固定在界面角落的主要操作按钮，不随内容滚走，通常代表新增、创建或快速联系。

**适用**：Dashboard、移动工具、创作应用、快速联系、主要新增操作

## 使用方法

### 给 AI 的精确提示词公式

```
布局：[从 1-10 中选] + 页面结构：[从 11-20 中选]
导航：[从 21-30 中选] + 组件：[从 31-40 中选]
```

**反面**：帮我做一个高级、简洁、有设计感的网站

**正面**：
> 用 Bento Grid 布局，Single-page 结构。顶部 Sticky Navbar + Hamburger Menu（移动端），锚点跳转。首屏 Hero Section 用 Full-bleed 背景。作品用 Masonry 瀑布流展示，点击弹 Lightbox。联系方式用 Modal 表单，页脚放社交链接。

## 关键洞察

> **"高级""简洁""有设计感"是审美判断，不是结构描述。** AI 需要的是具体的布局名称、页面类型、导航模式和组件清单——这些才是可以执行的指令。

> 这套词典本质上是一套**从模糊审美到精确结构的翻译系统**——和 WorkBuddy 六字段指令法、FDE 面试追问五层是同一个底层逻辑：**模糊的需求一定产生模糊的结果。**
