一句话总纲

Q、K、V 是同一个输入向量经三次不同线性变换派生出的三个角色——"提问者"（Wq 投影到关注方向）、"被检索者"（Wk 投影到被匹配方向）、"内容提供者"（Wv 投影到传递方向）；注意力五步（派生→点积打分→√dk 缩放→softmax→加权聚合 V）用 3 token × 2 维可完整手算，本文所有数字已代码复现验证一致。

一、直觉层：检索类比

把 Self-Attention 想成句子里词语间的互相"检索"（以「天气 真 好」中「真」为例）：

角色 类比 「真」的例子
Query（问） 每个词带着一个问题 「真」想问：句子里有没有"能被我修饰"的词？
Key（标签） 每个词挂着标签 好=「形容词·可被修饰」
Value（内容） 每个词备着实际内容 无论谁检索，我能贡献的信息

关键认知：Q、K、V 都从同一个输入向量 x 派生——同一个 token 同时扮演三种角色（提问的同时也被提问，也提供内容）。

为什么三个矩阵而非一个：若 Q=K=V=x，"提问、匹配、传递内容"三种角色未解耦，表达能力明显受限。Wq/Wk/Wv 的作用是把 x 分别投影到三个方向——角色解耦是注意力表达力的来源。

二、派生层：从 token 到 Q/K/V

token_id → W_e（查表）→ x        ← 词嵌入矩阵 [V×d]，本质是查找表
x → x·Wq → Q    ← 提问方向
x → x·Wk → K    ← 被检索方向
x → x·Wv → V    ← 内容方向

Wq/Wk/Wv 是三个独立 2×2 矩阵（训练学到）。文中示例设定：

x_天气=[0.9,0.1]（名词高）  x_真=[0.2,0.8]（修饰高）  x_好=[0.1,0.9]（可被修饰高）
第 1 维=名词程度，第 2 维=修饰/可被修饰程度（略去位置编码）

三、五步手算全记录（「真」的注意力）

Step 1：派生 Q/K/V（矩阵乘法）

Q_真 = [0.2,0.8]·Wq = [0.26, 0.70]
K_天气=[0.55,0.27]  K_真=[0.20,0.76]  K_好=[0.15,0.83]
V_天气=[0.58,0.25]  V_真=[0.44,0.60]  V_好=[0.42,0.65]

Step 2：点积打分（Q·K 衡量方向相近）

Q_真·K_天气 = 0.26×0.55 + 0.70×0.27 = 0.332
Q_真·K_真   = 0.26×0.20 + 0.70×0.76 = 0.584
Q_真·K_好   = 0.26×0.15 + 0.70×0.83 = 0.620  ← 最高（"真""好"第二维都大）

Step 3：√dk 缩放（降温，防 softmax 饱和）

dk=2，√2≈1.41
天气: 0.332/1.41=0.235   真: 0.584/1.41=0.414   好: 0.620/1.41=0.440

为什么要缩放：高维点积是 dk 个数相加，方差随维度增大；softmax 对大数敏感——分数偏大→最高项≈1 其余≈0→梯度变小训练不稳。除以 √dk 让"谁大谁小"不变但数值温和，softmax 不过早变成"几乎只看一个词"。

Step 4：softmax 归一化（和=1 的权重）

e^0.235≈1.265  e^0.414≈1.513  e^0.440≈1.553   总和=4.331
天气: 29.2%   真: 34.9%   好: 35.9%  ← 最高，符合"真好"修饰直觉

Step 5：加权聚合 V（不是选一个词，是加权融合）

Output_真 = 0.292×V_天气 + 0.349×V_真 + 0.359×V_好
第1维: 0.169+0.154+0.151 = 0.474
第2维: 0.073+0.209+0.233 = 0.515
Output_真 = [0.474, 0.515]

x_真 从 [0.2, 0.8] 变成 [0.474, 0.515]——它依然代表"真"，但已"知道"自己和"好"关系最密切。

四、输出层：从 Attention 到预测词

token_id → W_e → x → Wq/Wk/Wv → Q/K/V → Attention → Output
       → ×N 层（残差+LN+FFN，GPT-2=12 层，GPT-3=96 层）→ 最终 Output
       → ×W_eᵀ（lm_head，通常复用 W_e 转置）→ logits → softmax → 概率 → 输出词
  • GPT（生成）：取最后位置 token 的最终 Output → lm_head → 预测下一词；训练时加 Causal Mask 防看未来
  • BERT（理解）：取 [CLS] 或各 token 的最终 Output → 接分类器

五、完整公式卡

Attention(Q, K, V) = softmax( Q·Kᵀ / √dk ) · V

多头：把 Q/K/V 拆多个"头"并行算再拼接——不同子空间同时捕捉不同语言关系。

六、查询拓展：三个易混点 + 一个实验

6.1 易混点辨析

易混点 澄清
"注意力权重最高的词=模型输出那个词"？ ❌ attention 只帮当前位置形成上下文表示；最终输出词取决于后续多层加工+输出投影
"Attention 后 token 合并了"？ ❌ 每个 token 各自独立计算 Output，互不合并（n 个 token 进 n 个出）
"缩放改变了谁更相关"？ ❌ 只降温不改变排序；dk=2 时效果微弱，高维时才关键

6.2 因果掩码实验（本项目 demo.py 实测）

对同一例子加 causal mask（token 只能看自己及之前）：

Token 权重分布 观察
天气 只能看自己 out=[0.48, 0.50]（退化为自投影）
真 看 天气+真 weights=[0, 0.494, 0.506]
好 看 天气+真+好 weights=[0, 0, 1.0]（无未来可看时=纯自投影）

这正是 GPT 训练"不作弊"的机制——每层每步的未来信息都被遮死。

七、归纳总结

一次 Self-Attention = 同源三角色 × 五步流水线

同源：一个 x → Wq/Wk/Wv 三投影 → Q(问)/K(标签)/V(内容)
五步：派生 → 点积(方向相近度) → √dk(降温) → softmax(权重) → 加权聚合V(融合)
产出：每个 token 的新表示——"知道自己和谁最相关"
后续：×N 层精炼 → lm_head 反嵌入 → 预测词
