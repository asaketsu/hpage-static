Hermes Agent Self-Evolution 引擎深度分析

源仓库：NousResearch/hermes-agent-self-evolution（3.6k ⭐，MIT 许可）
本地克隆：/home/jc/uclaw/project/hermes-agent-self-evolution/

1. 核心发现

这是一个文本优化管道，不是模型训练。 它通过 DSPy + GEPA 自动突变、评估、筛选 Hermes 的 SKILL.md 文件，使 Agent 的技能指令越来越精准。

三大引擎

引擎 优化目标 许可 状态
DSPy + GEPA Skills、Prompts、Tool Descriptions MIT ✅ Phase 1 已实现
Darwinian Evolver Python 源码 AGPL v3 ⚠️ 仅 CLI 调用
DSPy MIPROv2 Few-shot Examples MIT ✅ 备用优化器

关键优势：GEPA

  • ICLR 2026 Oral 论文，集成在 DSPy 中
  • 读取执行轨迹理解为什么失败（不只是"失败了"）
  • 仅需 3 个样本即可开始优化
  • 每次优化运行成本仅 $2-10

2. 五阶段进化路线图

Phase 目标 周期 风险 jbot 适用性

P2 Tool Description 优化 2-3周 低 ⭐⭐⭐⭐ 高价值

3. 进化闭环架构

SessionDB（真实对话历史）
    │
    ▼
评估数据集构建器
    ├── 合成生成（强模型读 Skill → 生成测试用例）
    ├── 会话挖掘（从历史对话提取成功/失败案例）
    └── 手工金标集（JSONL 格式）
    │
    ▼
DSPy Module 包装（SKILL.md → 可优化参数）
    │
    ▼
GEPA 优化器 ◄── 执行轨迹（batch_runner 产出）
    │
    ▼
候选变体 → 约束验证 → 最佳变体 → PR → 人工审核

4. 约束护栏（5 道门禁）

  1. 完整测试套件 — pytest tests/ -q 必须 100% 通过
  2. 尺寸限制 — Skill ≤ 15KB，Tool 描述 ≤ 500 字符
  3. 缓存兼容 — 不允许会话中途热切换
  4. 语义保持 — 不能漂移到无关功能
  5. PR 审核 — 禁止直接 commit，必须人工合并

5. jbot 落地适配分析

当前 jbot 差距

维度 hermes-agent 官方 jbot 现状 Gap
Skill 数量 118 内置 418 自建 无 Gap，反而领先
进化引擎 GEPA 已集成 无 🔴 核心缺失
SessionDB FTS5 全文检索 有 FTS5 ✅ 已有
评估数据集 自动生成 + 挖掘 无 🔴 需建设
batch_runner 并行评估 无 🟡 可用 subagent 替代
benchmark gate TBLite/YC-Bench 无 🟡 可用自建测试用例替代

落地路线（推荐 P1 起步）

Phase 1：Skill 自动进化（2-3 天可跑通）

  1. 安装 dspy>=3.0.0 + gepa 到 jbot venv
  2. 选择 2-3 个高频 Skill 作为首批目标：
  3. feishu-card-table（使用频率最高）
  4. systematic-debugging（质量可量化）
  5. note-dual-format（输出可程序化验证）
  6. 从 SessionDB 挖掘历史对话，构建评估数据集
  7. 运行 GEPA 优化，产出改进版 Skill

成本评估

  • 每次优化运行：$2-10（API 调用费）
  • jbot 当前主力模型 zai/glm-5.1 可作为 eval_model
  • optimizer_model 需要更强的模型（如 sensenova 或 OpenRouter）

6. 对 jbot 已有自进化机制的增强

jbot 现有机制 hermes-agent-self-evolution 增强
SOUL.md 自省规则 GEPA 自动优化自省触发条件
错误模式 → Skill 创建 GEPA 自动优化已有 Skill 文本
Curator 7 天淘汰 进化版 Skill 自动 A/B 测试
memory 级经验沉淀 SessionDB 挖掘 + 评估数据集积累

7. 立即可执行的行动项

  1. 安装依赖：pip install dspy gepa openai
  2. 创建评估数据集目录：~/.hermes/evolution/datasets/
  3. 选 3 个 Skill 做 POC：用合成数据跑一次 GEPA 优化
  4. 验证改进效果：对比优化前后的 Skill 在相同任务上的表现

8. 风险与缓解

风险 缓解措施
zai/glm-5.1 并发=1 限制优化速度 用 sensenova/openrouter 作为优化器模型
418 个 Skill 全量优化成本高 按使用频率排序，优先优化 Top 20
优化后 Skill 可能丢失个性化 语义保持约束 + 人工审核 PR
NFS I/O 不稳定影响评估 评估运行在本地 /tmp 执行

结论： hermes-agent-self-evolution 是目前对 jbot 进化能力提升最大的外部工具。P1（Skill 进化）可直接落地，成本可控（$2-10/次），风险极低（约束护栏完善）。建议立即启动 POC。
