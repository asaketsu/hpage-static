## 执行摘要

> **核心结论**：航空结构强度垂域模型的技术主线已经收敛为**"AI for PDEs 五条路线 + 预训练科学模型"**，其中清华 2026 年提出的 PFEM（预训练有限元：物理信息神经算子热启动经典求解器）代表"预训练模型+经典数值求解器"融合范式，最契合适航对**确定性与可追溯性**的刚性要求。工业侧 Siemens Simcenter Physics AI（FNO 已集成进 STAR-CCM+ Design Manager 2602 版）证明商业化拐点已到。**研判：3 年内可落地的是"代理模型加速设计迭代 + 知识工程沉淀"，5-10 年方向是"预训练结构力学大模型"；纯端到端 AI 出强度结论用于适航取证在可见期内不可行，也不应作为目标。**
> **方法层增补**：第六章补齐代理模型四代谱系（Kriging→多保真→ROM→神经算子）与 SHM 方法栈（传感→Lamb 波损伤识别→寿命评估），并以 SHM×代理模型×数字孪生残差闭环作为垂域模型的服役期支柱。

## 一、需求侧：结构强度专业的真实痛点

| 痛点 | 现状量化 | AI 切入点 |
|------|---------|----------|
| **全机有限元求解耗时** | detailed FE 模型千万自由度级，单工况非线性求解小时-天级 | 代理模型毫秒-秒级预判 |
| **设计迭代次数** | 打样-校核循环数十轮，每轮等求解 | 实时代价反馈进入设计环 |
| **多工况/多约束扫描** | 包线全覆盖（限制载荷×1.5→极限载荷、疲劳谱、颤振）组合爆炸 | 神经算子零样本泛化到新工况 |
| **知识流失** | 强度校核经验（钉载分配/开口补强/接头细节）存于老工程师 | 知识工程（本机白皮书已论证） |
| **适航文档链** | 分析报告-模型-试验对应关系追踪成本高 | 数字主线+RAG |

**关键判断**：痛点分两层——**算得快**（代理模型域）与**判得准**（知识/经验域）。当前最成熟的 AI 落地点在第一层，第二层是垂域模型真正的护城河（呼应萨顿"经验才是分水岭"）。

## 二、技术供给侧：AI for PDEs 五条路线

> 主要依据：清华刘应华团队《Artificial intelligence for partial differential equations in computational mechanics: A review》（Applied Mechanics Reviews, 2026）——该综述是本方向最系统的中文团队英文综述，归纳了三类范式；本报告补充几何深度学习与 LLM 知识层，扩展为五条。

### 路线 1：PINN 物理信息神经网络

**原理**：控制方程、边界条件、初始条件写入损失函数，网络在物理约束下逼近 PDE 解。

**结构强度适用性**：
- ✅ 无网格、无需标注数据、天然处理反问题（从应变测点反演载荷/材料参数）
- ✅ 已有航空实证：前起落架 drag strut 近实时应力预测（Engineering Applications of AI, 2025/2026 在刊）
- ❌ 训练难（损失项冲突/病态）、复杂几何边界处理弱、逐问题重训

**定位**：**反演类任务**（载荷识别、材料参数标定、传感器数据同化）的首选，正问题大规模求解非其强项。

### 路线 2：DEM 深度能量法

**原理**：基于变分原理/最小势能原理构造能量泛函做损失。

**结构强度适用性**：
- ✅ **弹性力学、断裂力学等有能量结构的问题天然契合**——结构强度正是此类
- ✅ 应力对称性、平衡方程弱满足比 PINN 硬约束更稳
- ✅ 子域化改进（CENN 等）已解决复杂几何/非均质问题
- ❌ 需要问题的变分形式（阻尼/非保守系统需扩展）

**定位**：固体力学正问题的**理论最优雅路线**，与有限元数学同源（都是变分框架），对强度专业最"可解释"。

### 路线 3：神经算子（FNO / DeepONet / PINO）

**原理**：学习"输入函数→解函数"的算子映射，而非单个解。

**结构强度适用性**：
- ✅ **一次训练、一族问题**：新载荷工况/边界条件零样本推理
- ✅ 工业已落地：Siemens Simcenter **Physics AI 集成 FNO 进 STAR-CCM+ Design Manager（2602 版）**——设计空间探索的官方加速器
- ✅ 物理信息变体 PINO 减数据需求：航空复合材料固化工艺优化已有案例（EAAI 2024-2026 在刊）
- ❌ FNO 矩形域假设（几何不规则需 Geo-FNO 变体）、高频响应频谱偏差（Helmholtz 类问题需多尺度改进）

**定位**：**设计空间扫描/多工况扫描**的主力——把"一次算一个"变成"一次学一族"。

### 路线 4：PFEM 预训练有限元（清华 2026，重点）

> Wang Y., ..., Liu Y. "Pretrain finite element method: A pretraining and warm-start framework for PDEs via physics-informed neural operators." *Journal of the Mechanics and Physics of Solids*, 2026.

**原理**：物理信息神经算子做**预训练**，为**经典有限元求解器提供热启动**（初始场/网格参数化）。

**范式意义**：
```
通用 LLM 范式：预训练模型 + 下游微调
PFEM 范式：    预训练物理模型 + 经典数值求解器热启动
```
- AI 不替代求解器，而是**加速其收敛**——保守路径，保真度仍由经典 FEM 兜底
- 与"预训练-微调"的科学基础模型浪潮同构（气象 GraphCast→航空结构的对应物）

**定位**：**最契合适航语境的融合路线**——确定性由 FEM 保证，AI 只做加速，责任边界清晰。

### 路线 5：几何深度学习 + LLM 知识层（补充）

- **几何深度学习/图网络**：直接在 CAD/网格拓扑上学习（本机《超越求解器-几何深度学习重塑CAE》08-15 笔记已详述）——处理真实飞机几何（不规则/装配体）的必经之路
- **LLM 知识层**：强度校核经验、适航条款（CCAR 25.303/25.305/25.307）、历史分析报告的结构化检索与推理——本机《飞机结构智能体框架》（08-19）与《知识库白皮书》（08-20）已论证

**五路线总览**：

| 路线 | 一句话定位 | 成熟度（结构强度域） |
|------|-----------|---------------------|
| PINN | 反演/数据同化 | TRL 4-5（论文级→工程试点） |
| DEM | 变分类正问题 | TRL 3-4（理论成熟，工程少） |
| 神经算子 FNO/PINO | 设计空间扫描 | **TRL 6-7（已进商业 CAE）** |
| PFEM | 求解器热启动 | TRL 3-4（2026 新提出） |
| 几何 DL + LLM 层 | 几何直连 + 知识推理 | TRL 3-5 |

## 四、航空特有约束：适航与确定性

### 4.1 安全关键系统对随机性的排斥

> AIAA AVIATION Forum 2026 新设 AI in Aerospace Applications 工作组的定性（Gregory Roth, AFRL）："软件是配方，实例化一个模型，是确定性的……流行 AI（如 LLM）依赖随机近似，但在安全关键环境，这字面意义上'飞不起来'（won't fly—literally）。"

### 4.2 适航语境下的 AI 应用边界（研判）

| 用途 | 可取证性 | 判定 |
|------|---------|------|
| 概念设计快速权衡 | 不进取证链 | ✅ 无约束 |
| 优化迭代中的代理模型预筛 | 最终方案仍过认证求解器 | ✅ **推荐主路径** |
| 强度报告自动起草（LLM） | 报告需工程师签署负责 | ✅ 辅助（知识工程） |
| 反问题载荷识别（试验支持） | 试验数据分析，非交付物 | ✅ |
| **端到端 AI 出强度结论** | 无法满足 CCAR 25.307 分析方法可追溯要求 | ❌ **可见期内不可行** |

**核心论点**：适航要求的不是"AI 很准"，而是"**结论可复现、方法可追溯、责任可归属**"。这正是 PFEM"AI 加速+求解器兜底"路线优于端到端路线的**制度性理由**，不仅是技术理由。

## 五、综合研判

### 5.1 成熟度-价值矩阵

```
价值 ↑
高  │  设计空间扫描(神经算子)      预训练结构大模型(PFEM演进)
    │  ●已商业可用                 ○5-10年方向
    │
中  │  知识工程/RAG报告链          反演/数字孪生(PINN)
    │  ●本机已论证                 ○工程试点中
    │
低  │  端到端AI出强度结论
    │  ✕适航不可行，不应作为目标
    └────────────────────────────────→ 成熟度
      低         中         高
```

### 5.2 分阶段落地路线图（指导性结论）

**阶段一（0-1 年，确定性收益）**：
1. **代理模型加速设计迭代**：用 FNO/几何 DL 建典型部件（接头/开口/壁板）的载荷-应力代理，扫描速度 100-1000×——最终方案回归认证求解器校核
2. **知识工程底座**：强度校核经验+适航条款+历史报告进 RAG（本机白皮书方案）——LLM 层不碰物理结论，只做检索与文档链

**阶段二（1-3 年，跟随学术前沿）**：
3. **PFEM 类热启动试点**：跟踪清华团队开源进展，在内部 FEM 流程（NASTRAN/ABAQUS/自研）上试神经算子提供初始场
4. **试验数据反演**：PINN 做静力/疲劳试验的载荷识别与参数标定——不进交付链但提试验效率

**阶段三（3-10 年，范式级）**：
5. **预训练结构力学基础模型**：跨机型/跨部件的"结构 GPT"——输入几何+工况+约束，输出全场预判+置信度
6. **与数字主线融合**：设计-强度-试验-服役数据闭环反哺（本机数字主线笔记的 AI 增强版）

### 5.3 选型决策树（单问题判定）

```
该问题需要可取证结论？
├─ 是 → 必须经典求解器交付；AI 只能做加速（选 PFEM 思路）或前置筛选（代理模型）
└─ 否（探索/试验/内部迭代）
   ├─ 是反问题（从测点反推载荷/参数）？ → PINN
   ├─ 是设计空间扫描（同族几何×多工况）？ → 神经算子 FNO/PINO
   ├─ 有清晰变分结构（弹性/断裂能量）？ → DEM
   └─ 是知识/经验类问题？ → LLM+RAG（知识工程）
```

### 5.4 风险清单（诚实声明）

1. **泛化边界未经适航级验证**：代理模型在训练分布外的静默失效是最大风险——必须保留分布内检测（OOD detection）与求解器复核
2. **数据资产是前提**：没有结构化的历史分析数据库，垂域模型无从训练——知识工程必须先行（这与 08-23 企业知识工程笔记结论一致）
3. **人才断层**：既懂结构强度又懂算子学习的人极少——团队建设比模型选型更瓶颈
4. **学术过热风险**：AI for PDEs 论文增速远超工业验证速度，选型应以商业落地证据（TRL）为准绳而非论文数量

## 六、方法层深化：代理模型谱系与结构健康监测（SHM）

> **定位**：第二章五条路线回答"用什么"；本章回答两条主线的方法地基——**代理模型**（"算得快"的完整谱系，衔接路线 3/4）与**结构健康监测 SHM**（"测得准"的感知前端，把垂域模型从设计期延伸到服役期）。二者与数字孪生闭环融合，构成本报告研判的服役期支柱。

### 6.1 代理模型四代演进谱系

代理模型（Surrogate Model）是高保真有限元/CFD 仿真的快速替身：高保真仿真单次求解耗时数小时至数天，无法支撑设计空间扫描与数字孪生的秒级闭环；代理模型以毫秒~秒级推理替代逐次仿真。**第一~三代是工业界已验证的存量资产，第四代（神经算子）即本报告路线 3——五条路线中 TRL 最高的正是这条谱系的最新一代。**

**第一代：经典统计代理（1990s-2010s）**

- **Kriging / 高斯过程回归（GPR）**：航空多学科优化（MDO）的标准工具。核心优势是**小样本建模**（几十~几百个仿真点即可）与**原生不确定性量化**（预测方差即置信区间）。典型应用：气动系数拟合、结构应力近似
- **响应面法（RSM）**：多项式拟合，简单快速但精度有限，已逐步被 Kriging 取代

**第二代：多保真度融合（2010s）**

- **Co-Kriging（协同克里金）**：将少量高保真样本（CFD / 详细 FEA）与大量低保真样本（面元法 / 粗网格）融合建模，用相关性参数 ρ 联结两级响应。ICAS 2012 机翼机身优化实证：Co-Kriging 以更小的高保真样本量达到优于单保真 Kriging 的气动系数预测精度，显著降低优化总成本
- **变体**：分层 Kriging（Hierarchical Kriging）、多保真尺度法
- **多保真度的核心思想**：低保真模型提供趋势，高保真模型校正精度，高保真样本量可压到个位数~十位数。对飞机结构的直接启示：**全机粗模型（低保真）+ 关键部位详细模型（高保真）+ 实测数据（最高保真）的三层体系**，是兼顾覆盖面与精度的工程架构。2025-2026 的演进方向是**动态多保真**（SC-DT：保真度层级随结构状态演化切换，Computers in Industry, 2026）与**时序多保真**（DT-SHM：不同时间粒度的代理协同，J. Industrial Information Integration, 2025-07）

**第三代：降阶模型 ROM（2015-）**

- **POD（本征正交分解）**：对高维物理场（应力/温度/位移）提取本征模态，把十万~百万自由度问题投影到几十维低维空间
- **POD-GPR 非侵入式仿真器**（arXiv:2607.16447）：POD 降维 + GPR 回归系数映射，用于碳-碳飞机刹车盘峰值热-力场预测，完成 **surrogate-to-code 认证级验证**（误差量化 + 验证框架）——公开文献中认证成熟度最高的 ROM 路线
- **侵入式 vs 非侵入式**：侵入式 ROM 需要改写求解器源码；非侵入式（POD-GPR / POD-NN）只调用黑箱仿真结果，工程落地门槛低得多——这是 POD-GPR 能走向认证的原因之一，也与本报告路线 4（PFEM"预训练+经典求解器"）的融合逻辑同构

**第四代：神经算子（2020-）**——详见本报告第二章路线 3

- **DeepONet**（Lu et al., 2020）：branch 网（编码输入函数：载荷谱/边界条件）+ trunk 网（编码输出查询坐标）双架构，内积输出预测。理论基础是**算子的万能逼近定理**——学的不是离散数据点的函数，而是"函数到函数"的映射（任意载荷历程 → 任意位置应力响应），泛化能力本质上优于传统代理
- **Kobayashi et al.**（Nature Scientific Reports 14:2101, 2024，91+ 引用）：验证 DeepONet 作为数字孪生实时推理引擎的可行性（核能系统场景，毫秒级推理替代小时级仿真）
- **FNO（傅里叶神经算子）、PI-DeepONet（物理信息约束）**：频域全局感受野 / 物理约束嵌入，是 2025-2026 结构预测方向的主流变体

### 6.2 面向 SHM 的时序代理（2025-2026 新方向）

代理模型最新演进是**从"稳态场预测"转向"时序状态预测"**，直接服务数字孪生-SHM：

- **多保真时序代理 DT-SHM**（Journal of Industrial Information Integration, 2025-07）：以时序多保真代理模型为核心构建数字孪生虚拟模型，实现物理结构实时状态重构与预测（悬浮结构案例验证）
- **SC-DT 时空协同数字孪生**（Computers in Industry, 2026）：动态多保真度模型 + 时空协同策略，解决监测数据在"空间覆盖稀疏"与"时间演化"上的双重失配
- **轻量多保真孪生**（ASME J. Mech. Des., 2022，起重机臂案例）：多保真代理（MFS）构建轻量孪生，在监测精度与实时性之间取得工程平衡——方法论可直接迁移到飞机结构关键件

### 6.3 代理模型关键机制与工程约束

| 机制 | 作用 | 方法载体 |
|------|------|----------|
| 不确定性量化（UQ） | 输出"预测值 ± 置信区间"，认证前提 | GPR 预测方差、深度集成、贝叶斯神经网络 |
| 主动学习采样 | 按不确定性自适应加点，降低高保真样本成本 | EI（期望改进）准则 |
| 在线/增量更新 | 新监测数据到达时局部重训练，支撑残差闭环 | 增量 GPR、迁移学习微调 |
| 误差上界与验证 | 认证级交付物：可证明的误差边界 | surrogate-to-code 验证框架（arXiv:2607.16447） |

**工程红线**：

- **外推风险**：代理模型在训练域外（超出已见载荷/工况范围）的预测不可信且无警告——必须搭配域判定器或保守回退到高保真仿真。这与第五章风险清单第 1 条（OOD 检测+求解器复核）互为印证
- **训练数据成本**：高保真样本每个都是数小时仿真，样本量与精度的权衡是多保真方法存在的根本原因
- **维度灾难**：全机级 FEA 百万自由度，纯 Kriging 无法直接建模——必须先降维（POD）或换算子学习（DeepONet）

### 6.4 结构健康监测（SHM）方法层 — 垂域模型的"感知输入前端"

> **定位**：SHM 负责回答"结构现在什么状态"，为孪生模型提供实测输入与残差校准基准。方法栈分四层：**传感层 → 特征提取 → 损伤识别 → 状态评估**。国内该层算法研究力量最强（国防科大、北航、西工大在 Lamb 波/复材损伤识别方向论文量大质高），但与孪生闭环的工程集成仍是短板。

#### 6.4.1 传感层：航空场景主流传感器

- **FBG 光纤光栅**：分布式应变测量，重量轻、抗电磁干扰、可埋入复合材料铺层，是复材机翼监测首选（MDPI Sensors 2025 航空 ML-SHM 综述 25(19):6136）
- **PZT 压电片**：既可主动激励 Lamb 波（损伤成像），又可被动监听声发射（AE）——主动 + 被动双模态融合是趋势（Nasrollahi et al., 2018）
- **MEMS 加速度计**：全局模态特征，适合结构级异常筛查
- **工程约束**：重量/空间/可靠性限制 → 机载传感器数量有限 → **数据稀疏 + 噪声是 SHM 的先天条件**，一切算法必须在此前提下设计

#### 6.4.2 损伤识别层：以 Lamb 波为主线的方法演进

Lamb 波是板类结构（蒙皮/加筋壁板/复材层压板）损伤监测的物理载体。其物理基础：Lamb 波是板状结构中的导波，存在对称（S0）与反对称（A0）模态，具有频散特性（不同频率传播速度不同）。损伤识别利用三个物理效应：**散射**（损伤处反射/散射波）、**模态转换**（S0↔A0，指示厚度方向不连续）、**传播速度/衰减变化**（刚度退化）——这些物理效应决定了信号特征（飞行时间/幅值/频谱）与损伤类型（裂纹/分层/脱粘）的对应关系。

**物理信号处理路线（2006-2015）**：

- **时间反转法**：利用波动方程时间可逆性聚焦损伤散射信号（Poddar 2011 金属板；Bijudas 2013 加筋板）
- **匹配追踪 + 机器学习**：Lamb 波信号稀疏分解后提特征分类（Sushant & Mira 2014）
- **数值增强机器学习**（Sbarufatti 2014）：用仿真数据增广实测训练集——"仿真补充实测"思想的早期代表，正是今天多保真/数字孪生思路的前身
- **Bayesian 稀疏重构**：从健康/损伤信号峰值与峰时变化重构损伤因子，实现 CFRP 疲劳损伤定位与尺寸可视化（Duan 等）
- **多路径概率成像**：PZT 阵列多路径波程偏差 → 损伤概率场成像（CFRP 试件验证：健康结构波路径不变，损伤结构路径偏转）

**深度学习路线（2016-2024）**：

- 光纤传感 + 深度学习 SHM 系统（Jayawickrema et al. 2022，249+ 引用）：CNN / LSTM / 自编码器做损伤诊断与预后决策
- 核心挑战：结构一生绝大部分时间处于健康状态 → **损伤样本极度稀缺 → 类别不平衡严重**

**少样本与生成式路线（2025-2026 前沿）**：

- **Lamb 波特征增强 + 不平衡少样本学习 + 交互式迁移**（SHM2025 会议，Yuan Huang / Xinlin Qing 等）：直接面向"损伤样本稀缺"痛点的数字孪生损伤监测系统
- **去噪扩散概率模型（DDPM）合成 SHM 数据集**（Bazrafshan et al., SHM2025）：生成式 AI 补充稀有损伤工况样本
- **高分辨率超声成像**（Huang / Lanza di Scalea, SHM2025）：鲁棒数据驱动匹配场处理，用于加筋复材板

#### 6.4.3 状态评估与预测层衔接

- 损伤识别输出（位置/尺寸/类型 + 置信度）→ 送入裂纹扩展模型 → RUL 预测
- **多裂纹 link-up 问题**（Drexel 大学 2025 框架）：预测机身搭接壁板相邻铆钉孔多条疲劳裂纹相互作用与贯通——相邻裂纹在数千次飞行中相互生长、连接成长裂纹，贯通后剩余强度骤降，是损伤容限评估的关键场景
- 该层与本报告路线 1（PINN 反演/数据同化）直接衔接：实测数据同化进物理模型正是 PINN 的定位场景

#### 6.4.4 SHM 方法的瓶颈与认证约束

- **环境变异**：温度/载荷变化引起 Lamb 波特征漂移，与损伤信号混叠——需温度补偿或环境-损伤解耦算法
- **基准数据缺失**：缺少飞机结构级公开基准（对比：发动机 PHM 有 NASA CMAPSS），模型横向对比与复现困难
- **认证路径**：EASA/FAA 目前仅部分接受 SHM 数据作为维修依据，SHM 结果作为定检替代仍需逐案批准——这决定 SHM→孪生→决策链的落地节奏（2026 传感器部署 → 2027-2028 单机寿命预测 → 2029+ 机队级），与第四章适航约束的判定完全同构

### 6.5 三方法融合框架 — SHM × 代理模型 × 数字孪生的闭环

> **融合逻辑**：SHM 解决"感知与输入"（结构实测状态），代理模型解决"实时计算"（秒级状态预测），数字孪生解决"闭环与决策"（残差校准 → 寿命更新 → 维修行动）。三者缺一即退化为传统离线分析。

```
┌──────────────────────────────────────────────────────────────────┐
│              物理飞机（尾翼 / 机翼 / 机身关键件）                   │
│    FBG光纤应变 ──┐   PZT-Lamb波 ──┐   飞行参数(载荷谱) ──┐       │
└──────────────────┼────────────────┼──────────────────────┼───────┘
                   ▼                ▼                      ▼
┌──────────────────────────────────────────────────────────────────┐
│ ① SHM 感知层：多参数飞行实测 + Lamb波损伤识别（6.4 节）            │
├──────────────────────────────────────────────────────────────────┤
│ ② 代理模型层：POD-GPR / DeepONet 实时推断应力与损伤场（6.1-6.3）  │
├──────────────────────────────────────────────────────────────────┤
│ ③ 孪生闭环层：实测 — 校准 — 残差反馈 — 模型修正                   │
│    残差 = 实测 − 孪生预测 → 更新裂纹长度 / 材料退化参数            │
├──────────────────────────────────────────────────────────────────┤
│ ④ 决策层：单机寿命动态预测 → 机群维修规划（NSGA-II）               │
└──────────────────────────────────────────────────────────────────┘
```

**国内工程验证（航空学报 2025 年"飞行器数字孪生技术专刊"，46 卷 19 期）**——三处关键证据：

- **残差驱动闭环的严格理论化**（卓然、闫楚良《飞机结构数字孪生的关键一环：多参数飞行实测》，532375）：针对建模假设偏差、输入信息不确定、模型响应失配三大难题，提出**"实测—校准—残差反馈—模型修正"动态闭环**，系统证明残差反馈闭环的**理论收敛性**，给出**误差上界的严格定量分析方法**，并建立多维度、可量化的模型自进化评价指标体系；以某型飞机尾翼完成工程验证，复杂工况下模型预测误差有效降低，疲劳寿命预测准确性与鲁棒性提升——这是"残差驱动参数更新"机制的国内最强工程背书，与路线 4（PFEM"AI 加速+求解器兜底"）形成设计期/服役期两端的同构呼应
- **飞参-载荷-寿命孪生链路**（航空学报 10.7527/S1000-6893.2025.32382）：飞行参数 → 结构关键部位载荷 → 实时寿命预测 → 智能运维的完整方法链
- **机群寿命精细化管理**（顾宇轩等，沈阳飞机设计研究所 + 大连理工，531290）：以单机实时健康状态为输入，建立维修计划规划模型（目标：维修资源利用率 + 机群保有率；约束：各机剩余寿命 / 同时维修能力）与飞行训练规划模型（目标：关键部位寿命损耗均衡），用非支配排序遗传算法（NSGA-II）求解——**决策层的国内系统化成果**

**融合框架的三点技术判断**：

- ①②③④ 全链贯通的前提是**每层都有不确定性量化**：传感器噪声 → 代理预测方差 → 残差统计特性 → 决策风险度量，任一环缺失都会让"可认证"退化为"看起来能用"
- 残差闭环（③）是三者融合的**枢纽**——它把 SHM 的实测信息持续注入代理模型与孪生参数，是实现"单机定制化"的机制载体
- 机群层（④）是价值兑现点：单机预测 → 机队维修资源优化，经济价值比单机预测高一个数量级

## 七、查询拓展：与通用 LLM 垂域化的边界辨析

**"航空垂域模型"≠"航空垂直 LLM"**：

| 维度 | 垂直 LLM（知识层） | 垂域科学模型（物理层） |
|------|-------------------|----------------------|
| 学习目标 | 文本规律（条款/报告/经验） | PDE 解算子/物理场 |
| 骨干 | Transformer | PINN/神经算子/DEM |
| 输出 | 文本/结论引用 | 场量/载荷/应力 |
| 适航路径 | 辅助文档链 | 加速+复核 |
| 典型 | 条款问答 RAG | Simcenter Physics AI |

真正的"航空垂域模型在结构强度方向"= **物理层为主（五路线）+ 知识层为辅（LLM）** 的双层架构。只做 LLM 是不够的，只做物理层是缺经验的。
