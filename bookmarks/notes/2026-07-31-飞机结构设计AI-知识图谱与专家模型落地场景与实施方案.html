二、场景一：智能选材推荐系统

2.1 痛点诊断

飞机结构选材是一个多目标约束优化问题，涉及强度、疲劳、损伤容限、腐蚀、重量、成本、制造工艺、供应链等 10+ 维度。当前痛点：

  • 信息孤岛：材料性能数据散落在 MMPDS、CMH-17、企业内部数据库、供应商 datasheet 中，格式不统一
  • 经验依赖：资深工程师凭经验快速锁定候选材料，年轻工程师需翻阅大量手册，耗时数天
  • 遗漏风险：非标材料或新材料（如新型铝合金、增材制造粉末）容易被忽略
  • 权衡困难：重量-成本-制造-性能的权衡缺乏系统化工具，常凭直觉拍板

2.2 知识图谱如何介入

构建 材料知识子图（Material-KG），将材料从"数据库条目"升级为"可推理的知识节点"：

Material-KG 子图结构
├── 材料实体层
│   ├── 铝合金: 2024-T3 / 7075-T6 / 7050-T7451 / 2099-T8 ...
│   ├── 钛合金: Ti-6Al-4V / Ti-5553 / Ti-6242 ...
│   ├── 复合材料: CFRP-T800 / CFRP-IM7 / GLARE ...
│   ├── 钢: 300M / 15-5PH / 17-4PH ...
│   └── 新材料: Scalmalloy® (AM) / Al-Li 2099 ...
│
├── 性能属性层
│   ├── 力学: Ftu / Fty / E / ν / KIc / σ疲劳极限
│   ├── 物理: ρ / α / k / Cp
│   ├── 腐蚀: SCC敏感度 / 电位 / 腐蚀速率
│   └── 工艺: 可焊性 / 可锻性 / AM适配度
│
├── 应用关系层
│   ├── usedIn: 材料→型号部件 (如 2024-T3 → usedIn → 机身蒙皮)
│   ├── alternativeFor: 替代关系 (如 2099-T8 → alternativeFor → 2024-T3)
│   ├── conflictsWith: 冲突关系 (如 7075-T6 → conflictsWith → 海洋环境腐蚀)
│   └── qualifiedFor: 合格认证 (材料→规范条款)
│
└── 经验规则层
    ├── "主承力框优先 7050-T7451 锻件（厚截面断裂韧性好）"
    ├── "机身蒙皮优先 2024-T3（疲劳性能优）或 2524-T3（损伤容限更好）"
    ├── "高温区(>150°C)选钛合金或不锈钢"
    └── "复合材料结构需匹配增韧树脂体系"

知识图谱的核心价值：不只是查询材料属性，而是能推理——给定一个载荷环境（"机身下部蒙皮，服役温度 -55°C~+70°C，承受增压循环载荷，需检测周期 ≥5000 飞行小时"），KG 能沿图谱路径推理出候选材料集合及排序。

2.3 专家模型如何推理

选材专家模型（Material Expert）的推理流程：

输入: 结构位置 / 载荷环境 / 约束条件 / 历史偏好
  │
  ▼
Step 1: 需求分解 → 提取关键约束维度
  │  例: {载荷类型: 静力+疲劳, 温度: -55~70°C, 
  │       腐蚀: 海洋环境, 重量敏感度: 高, 成本敏感度: 中}
  │
  ▼
Step 2: KG-RAG 检索 → 从 Material-KG 检索候选材料
  │  Cypher: MATCH (m:Material)-[:usedIn]->(p:Part {type:'fuselage_skin'})
  │          WHERE m.Ftu > 400 AND m.rho < 2.8
  │          RETURN m ORDER BY m.fatigue_strength DESC
  │
  ▼
Step 3: 多目标排序 → 用 AHP/TOPSIS 加权排序
  │  权重: 轻量化(0.3) + 疲劳(0.25) + 损伤容限(0.2) + 成本(0.15) + 制造(0.1)
  │
  ▼
Step 4: 约束验证 → 逐条校验适航/工艺/供应链约束
  │  例: 候选1: 2524-T3 → ✅ 合格 / 候选2: 2099-T8 → ⚠️ 缺AM认证
  │
  ▼
Step 5: 生成推荐报告
  → Top-3 材料牌号 + 各维度评分 + 推理依据 + 适用条款引用
  → 可追溯链: 决策→KG路径→数据来源→MMPDS页码

2.4 落地实施路线（四阶段）

阶段一（1-3 月）：数据底座建设

  • 结构化材料数据库：将 MMPDS、CMH-17、企业内部材料数据库导入 Neo4j，建立材料实体和属性节点
  • 经验规则结构化：从设计手册中提取 200+ 条选材经验规则，编码为 KG 中的 hasExperienceRule 边
  • 交付物：可视化材料知识图谱（可按材料牌号/部件/工艺查询），覆盖 ≥500 种航空金属材料 + ≥50 种复合材料体系

阶段二（3-6 月）：选材专家模型 v1

  • 基于通用 LLM（如 Qwen3-72B）+ KG-RAG，构建选材问答系统
  • 训练数据：从历史设计报告中提取 5000+ 选材决策案例
  • 交付物：输入载荷环境描述，输出 Top-3 候选材料 + 推理依据

阶段三（6-12 月）：与 CAD/PLM 集成

  • 在 CATIA/PLM 系统中嵌入选材建议插件：工程师选中部件 → 自动推送材料候选
  • CAD 材料属性自动回填到 FEA 前处理（避免手动输入错误）
  • 交付物：CAD-KG 联动的选材推荐原型

阶段四（12-18 月）：闭环学习

  • 收集工程师的采纳/拒绝反馈，持续优化推荐排序
  • 新材料认证后自动入图，推荐系统自动更新
  • 交付物：自进化的选材推荐系统 v2

2.5 关键技术栈

  • 图数据库: Neo4j / NebulaGraph（存储 Material-KG）
  • 知识抽取: LLM-assisted NER/RE（从 MMPDS PDF 和设计手册中自动抽取）
  • 专家模型: Qwen3-72B + LoRA 微调（选材指令数据）
  • 多目标决策: AHP / TOPSIS / Pareto 前沿可视化
  • 集成: CATIA CAA/RADE 二次开发（CAD 插件）
  • 验证: 与资深工程师的盲测对比，Top-3 召回率 ≥90%

2.6 度量指标

  • 推荐准确率: Top-3 候选中包含工程师最终选择的比率 ≥90%
  • 选材周期: 从平均 3-5 天 → 目标 <4 小时
  • 知识覆盖: ≥500 种材料、≥200 条经验规则、≥50 个型号部件映射
  • 可追溯性: 每个推荐 100% 可溯源到 MMPDS/手册的具体页码

2.7 风险与缓解

  • 数据质量风险: MMPDS 数据版本不一致 → 建立版本管理和数据溯源机制
  • 新材料覆盖不足: 新材料（如 AM 粉末）性能数据匮乏 → 标记 confidence=low，提示需补充试验
  • 过度依赖风险: 工程师完全依赖 AI 推荐 → 系统只提供候选，最终决策由工程师确认

三、场景二：开口补强智能设计

3.1 痛点诊断

飞机结构中存在大量开口——舱门、检查口、管路穿孔、紧固件孔等。开口破坏了结构传力路径，产生应力集中（Kt），是疲劳裂纹的高发区域。

  • Kt 计算依赖经验公式或查表：Peterson's 应力集中系数手册覆盖有限，非标准形状需 FEA
  • 补强方案迭代多轮：每次改补强 → 重做 FEA → 周期长
  • 多参数耦合：开口形状/尺寸/位置/载荷方向/板厚/材料/补强形式，组合爆炸

3.2 知识图谱如何介入

构建 开口补强知识子图（Cutout-KG）：

Cutout-KG 子图结构
├── 开口类型实体
│   ├── 形状: 圆形 / 椭圆 / 矩形(圆角) / 多连通
│   ├── 功能: 检查口 / 舱门 / 管路孔 / 紧固件孔 / 电缆穿孔
│   └── 位置: 蒙皮 / 腹板 / 翼梁缘条 / 长桁
│
├── Kt 经验知识库
│   ├── Peterson 公式族: Kt = f(形状参数 d/D, r/D, 载荷方向)
│   ├── 有限元修正系数: 不同 Re/D 下的修正曲线
│   └── 多开口干涉: 相邻开口的应力叠加规则
│
├── 补强方案库
│   ├── 补强形式: 加强板 / 补强环 / 增厚 / 镶套
│   ├── 补强参数: 补强板厚度比 t'/t, 补强范围 W/d
│   └── 工艺约束: 补强件连接方式(铆接/胶接/焊接/AM一体)
│
└── 历史案例库
    ├── 成功案例: 某型号检查口补强方案 → 验证结果
    ├── 失效案例: 开口处疲劳裂纹 → 根因分析 → 改进措施
    └── 经验阈值: "矩形开口圆角半径 r ≥ 5mm 且 r/d ≥ 0.1"

3.3 专家模型如何推理

开口补强专家模型（Cutout Expert）的核心能力是快速生成补强方案初稿并预测 Kt 降低效果：

输入: 开口形状/尺寸/位置/载荷工况/材料
  │
  ▼
Step 1: Kt 快速估算（AI 代理模型）
  │  输入开口参数 → AI 代理模型(训练于 FEA 数据) → 输出 Kt_base
  │  响应时间 <1s（vs FEA 单次分析 30-60min）
  │
  ▼
Step 2: 补强方案生成
  │  KG 检索: 类似开口的历史补强方案
  │  约束推理: 材料/工艺/空间约束 → 可行补强形式集合
  │  生成: 2-3 个候选补强方案(补强板尺寸/形式/连接方式)
  │
  ▼
Step 3: 补强后 Kt 预测
  │  AI 代理模型预测每个方案的补强后 Kt_reinforced
  │  评估: Kt 降低率 / 重量增加 / 工艺复杂度
  │
  ▼
Step 4: 方案排序与推荐
  → 推荐最优方案 + 补强后应力分布云图(代理模型预测)
  → 自动生成 FEA 验证模型（供工程师确认）

核心创新：用 AI 代理模型（Surrogate Model） 替代部分 FEA 计算，将"改补强 → 重做 FEA"的迭代从数小时缩短到秒级。代理模型训练数据来自历史 FEA 模型库，覆盖率越高，精度越好。

3.4 落地实施路线

阶段一（1-3 月）：Kt 知识库 + 代理模型训练

  • 从历史 FEA 模型库中提取 ≥2000 个开口分析案例，训练 Kt 代理模型（CNN/Graph Neural Network）
  • 整理 Peterson 公式 + 企业内部经验曲线，编码到 Cutout-KG
  • 交付物：输入开口参数 → 1s 内输出 Kt 估算值 + 置信度

阶段二（3-6 月）：补强方案生成器

  • 构建补强案例库（≥500 案例），关联到 Cutout-KG
  • 开发补强方案生成器：给定开口+约束 → 输出 Top-3 补强方案
  • 交付物：方案推荐 + 代理模型预测的应力分布

阶段三（6-12 月）：与 CATIA 集成

  • CATIA 中选开口特征 → 自动推送补强方案
  • 一键生成 FEA 验证模型（Patran/Nastran 批处理）
  • 交付物：CAD-FEA-KG 三向联动的开口补强设计工具

阶段四（12-18 月）：闭环验证

  • 收集补强方案的实际 FEA 验证结果 → 持续训练代理模型
  • 累积失效案例 → 更新经验规则
  • 交付物：精度持续提升的自进化系统

3.5 关键技术栈

  • 代理模型: CNN / Graph Neural Network（几何→应力映射）
  • FEA 数据管线: Patran session 文件解析 → 参数化提取 → 训练数据集
  • 补强方案检索: Case-Based Reasoning (CBR) + KG 检索
  • CATIA 集成: CAA/RADE API + Knowledge Advisor

3.6 度量指标

  • Kt 代理模型精度: 平均误差 ≤5%（vs FEA 真值）
  • 补强方案初稿命中率: Top-3 候选中包含最终方案的比率 ≥85%
  • 迭代周期: 从 3-5 轮 FEA 迭代 → 1 轮代理模型筛选 + 1 轮 FEA 确认
  • 设计时间: 从 1-2 周 → 目标 <2 天

四、场景三：复合材料铺层智能优化

4.1 疲点诊断

复合材料（CFRP/GFRP）铺层设计是高度复杂的工程问题：

  • 设计变量多：铺层序、角度、厚度、区域递减、材料选择
  • 约束复杂：CMH-17 准则、面内/面外耦合、冲击损伤容限(BVID)、分层、湿热效应
  • AI 优化空间大：传统设计靠经验确定铺层百分比，AI 可探索更大设计空间
  • 验证成本高：每改一版铺层 → 需做层合板分析 → 甚至需试验验证

4.2 知识图谱如何介入

构建 铺层知识子图（Laminate-KG）：

Laminate-KG 子图结构
├── 铺层规则层
│   ├── 对称性约束: 对称铺层 / 反对称铺层
│   ├── 均衡性约束: ±θ 配对 / 铺层百分比下限
│   ├── 分散性约束: 同向连续层数 ≤4 / ±45° 间隔
│   └── 区域过渡: 铺层递减规则 / 过渡区设计
│
├── 性能映射层
│   ├── 铺层 → 刚度矩阵 [ABD] → 面内/弯曲性能
│   ├── 铺层 → 开孔拉伸/压缩 (OHT/OHC)
│   ├── 铺层 → 冲击后压缩 (CAI)
│   └── 铺层 → 分层韧性 (GIC/GIIC)
│
├── CMH-17 准则层
│   ├── 准则条文 → 铺层约束映射
│   ├── 许用值数据库 (B-basis / A-basis)
│   └── 环境折减系数 (湿热/冷干)
│
└── 历史铺层案例库
    ├── 翼面蒙皮典型铺层: [45/0/-45/90]s 比例
    ├── 机身蒙皮典型铺层: 偏 0° 主承力方向
    └── 夹层结构面板: 面板薄 / 芯子高密度

4.3 专家模型如何推理

铺层专家模型（Laminate Expert）的能力分两层：约束满足和多目标优化：

输入: 几何形状 / 载荷工况 / 约束条件 / 目标(轻量化/刚度)
  │
  ▼
Layer 1: 约束满足层（Constraint Satisfaction）
  │  从 Laminate-KG 加载适用约束集
  │  ├── CMH-17 规则: ±45° ≥ 10%, 0° ≥ 10%, 90° ≥ 10%
  │  ├── 工艺约束: 最薄铺层 0.125mm, 总厚 ≤ 10mm
  │  └── 经验约束: "外表面 ±45° 抗冲击"
  │
  ▼
Layer 2: 多目标优化层
  │  方法: 遗传算法 / Bayesian Optimization
  │  目标: min(重量) s.t. 刚度/强度/CAI/损伤容限约束
  │  KG 增强: 用历史铺层案例作为初始种群 → 加速收敛
  │
  ▼
Layer 3: 验证与推荐
  → Pareto 前沿 → 推荐折中方案
  → 自动生成经典层合板理论分析(CLPT)报告
  → 标记需 FEA 验证的关键区域

4.4 落地实施路线

阶段一（1-3 月）：规则库 + 案例库

  • 将 CMH-17 铺层设计准则编码为可执行约束（JSON 规则集）
  • 从历史铺层设计中提取 ≥300 个案例，关联到 Laminate-KG

阶段二（3-6 月）：铺层优化引擎

  • 集成 KG-RAG：优化时自动检索类似工况的历史铺层
  • 交付物：输入工况 → 输出 Pareto 最优铺层方案集

  • 交付物：CAD → AI 优化 → FEA 验证一体化管线

  • 收集 FEA 验证结果 → 持续优化性能预测代理模型

  • 交付物：自进化铺层优化系统

4.5 关键技术栈

  • 优化算法: NSGA-II / Bayesian Optimization (BoTorch)
  • 层合板分析: 经典层合板理论 (CLPT) + 一阶剪切理论 (FSDT)

  • 优化时间: 从 1-2 周 → <4 小时
  • 设计空间覆盖: AI 探索的铺层方案数 vs 人工 → 1000x+

五、场景四：疲劳与损伤容限智能评估

5.1 痛点诊断

疲劳和损伤容限（Damage Tolerance, DT）分析是飞机结构详细设计阶段最耗时的工作：

  • 载荷谱处理复杂：全机疲劳载荷谱可能包含数百万个载荷峰谷
  • 裂纹扩展建模：需逐个载荷循环积分裂纹扩展方程（如 Paris 公式 / Walker 方程）
  • 多部位损伤(MSD)/广域损伤(WFD)：复杂交互的裂纹群分析
  • 计算量巨大：单条关键裂纹的全寿命分析可能需数小时

5.2 知识图谱如何介入

构建 疲劳/DT 知识子图（Fatigue-KG）：

Fatigue-KG 子图结构
├── 材料疲劳数据层
│   ├── S-N 曲线数据库: 按材料/热处理/应力比/环境分类
│   ├── 裂纹扩展曲线: da/dN-ΔK 数据 (Paris区/门槛区/断裂区)
│   ├── 断裂韧度: KIC / Kc / KISCC
│   └── 疲劳极限: 光滑/缺口试件，不同 R 比下
│
├── 分析方法层
│   ├── 名义应力法: S-N + Miner 累积损伤
│   ├── 局部应变法: ε-N + Neuber 修正
│   ├── 裂纹扩展: Paris/Walker/Forman 方程 + β修正
│   └── 概率方法: Weibull 分布 / 可靠度分析
│
├── 适航条款映射
│   ├── §25.571(a): 疲劳评估要求 → 方法选择决策树
│   ├── §25.571(b): 损伤容限 → 裂纹扩展+剩余强度
│   ├── §25.571(c): 疲劳(安全寿命) → S-N 方法
│   └── §25.571(e): 广域损伤 → MSD/WFD 分析
│
└── 历史分析案例库
    ├── 关键部位: 翼根接头 / 机身环框 / 舱门角 / 紧固件孔
    ├── 典型寿命曲线: 不同细节类型的疲劳寿命分布
    └── 修正经验: 孔冷作/喷丸/干涉配合的疲劳增益系数

5.3 专家模型如何推理

疲劳/DT 专家模型（Fatigue Expert）的核心能力是自动化分析决策和寿命快速预测：

输入: 结构细节 / 材料 / 载荷谱 / 目标寿命

  │  判断: 该部位是疲劳临界还是 DT 临界？

  │

  │  从 KG 获取材料 S-N 曲线 / da/dN 方程参数 / KIC
  │  从载荷谱库匹配标准谱(TWIST/TRAN)或用户谱

  │  方法1: 传统逐循环积分（精确但慢）

5.4 落地实施路线

阶段一（1-3 月）：材料疲劳数据库 + 条款决策树

六、场景五：适航条款智能合规校核

6.1 痛点诊断

适航合规校核是飞机结构设计中最规范密集的环节：

  • 条款数量庞大：CCAR-25 部结构相关条款 ≥150 条，每条可能有数十条子条款
  • 条款交叉引用：一条设计决策可能涉及 5-10 条适航条款的交叉校验
  • 条款解读不一致：不同工程师对同一条款的理解可能不同
  • 合规报告冗长：每条条款需要"条款要求 → 设计措施 → 验证证据 → 结论"的完整证据链

6.2 知识图谱如何介入

构建 适航知识子图（Regulatory-KG）——这是整个体系中最结构化的部分，因为适航条款本身就是高度结构化的文本：

Regulatory-KG 子图结构
├── 条款实体层
│   ├── CCAR-25 部
│   │   ├── §25.305 强度和变形 → {要求, 验证方法, 符合性证据}
│   │   ├── §25.307 结构验证 → {要求, 试验, 分析}
│   │   ├── §25.571 结构疲劳 → {a疲劳, b损伤容限, c安全寿命, e广域}
│   │   ├── §25.631 冲击损伤 → {要求, 离散源, 鸟撞, 剩余强度}
│   │   └── ... ≥150 条
│   ├── FAR-25 / CS-25 差异条款映射
│   └── 咨询通告(AC) / 适航指令(AD) 关联
│
├── 合规证据层
│   ├── 分析证据: FEA报告号 / 疲劳分析报告号
│   ├── 试验证据: 静力试验 / 疲劳试验 / 鸟撞试验
│   ├── 类似性证据: 参考已取证型号的类似设计
│   └── 构型声明: 设计定义文件版本
│
├── 条款关系层
│   ├── dependsOn: §25.571 → dependsOn → §25.305 (先满足强度)
│   ├── conflictsWith: §25.305(轻量化) ↔ §25.571(损伤容限余量)
│   ├── alternativeTo: §25.571(b) ↔ §25.571(c) (DT vs 安全寿命)
│   └── requiresEvidence: 条款 → 证据类型要求
│
└── 历史合规案例
    ├── 已取证型号的条款符合性矩阵 (TC/STC 数据)
    └── 审定过程中的不符合项及纠正措施

6.3 专家模型如何推理

适航专家模型（Airworthiness Expert）的核心能力是自动条款识别和合规证据链生成：

输入: 设计参数 / 分析结果 / 结构构型
  │
  ▼

  │  例: "机翼主承力结构 → governedBy → §25.305 + §25.571 + §25.631"

  │  对每条适用条款，从 KG 提取:

  │

  │  约束求解: 遍历所有适用条款 → 检查是否满足

8.2 Knowledge Graph in Engineering Design

近年来 KG 在工程设计领域的研究集中在：
- 材料信息学(Material Informatics)：JMP、Materials Project 等平台已建立材料知识图谱
- CAD-KG 融合：Dassault Systèmes 探索 3DEXPERIENCE 平台的知识管理
- 适航知识图谱：民航局与高校合作的适航法规知识图谱项目

8.3 Surrogate Model / AI代理模型

FEA 代理模型是当前结构优化领域的前沿：
- SkrGAN（Sketch-Rule GAN）用于几何参数化
- Physics-Informed Neural Network (PINN) 将物理约束嵌入神经网络
- Graph Neural Network 用于非结构网格的应力场预测

8.4 MoE 在工程领域

Mixture-of-Experts 架构在工程设计领域的应用刚起步。DeepSeek-V3、Mixtral 等通用 MoE 模型的成功为领域 MoE 提供了参考。关键挑战是专家分工粒度——太粗（如只分"结构/材料"）效果有限，太细（如每个条款一个专家）训练数据不足。

9.2 落地成功三要素

  1. 数据先行：没有结构化数据库，知识图谱就是空壳。第一个 6 个月的重心应是数据汇聚和结构化，而非算法创新
  2. 工程师在环：AI 系统必须是"副驾驶"而非"自动驾驶"——推荐候选、加速计算、检查合规，但最终决策由工程师做出
  3. 增量价值：每个阶段必须有可量化的交付物和 ROI 证明，避免"大项目"心态

十、趋势判断

趋势1：从"单点 AI"到"系统级 AI"

判断：当前的 AI 结构设计工具多为单点解决方案（如独立的拓扑优化软件、独立的疲劳分析工具），未来 3-5 年将向系统级集成发展——一个统一的 AI 平台串联选材→设计→分析→验证→适航全过程。本文提出的 5 场景统一架构即这一趋势的体现。

依据：Dassault Systèmes 的 3DEXPERIENCE、Siemens 的 Xcelerator 平台已在向这个方向整合，但 AI 深度集成仍在早期。

趋势2：知识图谱成为航空工程"数字底座"

判断：适航局方推动的"数字适航"(Digital Airworthiness) 趋势下，知识图谱将作为设计知识的唯一事实来源(Single Source of Truth)，所有设计决策、分析结果、试验数据、合规证据都必须挂载在 KG 上，实现 100% 可追溯。

依据：FAA 的 Digital Information Program、EASA 的 AI Roadmap 2.0 均明确提出数字化的适航验证方向。

趋势3：代理模型替代部分 FEA

判断：FEA 代理模型的精度持续提升（PINN/GNN 的进展），在 3-5 年内，详细设计阶段 50%+ 的迭代分析将由代理模型完成，FEA 仅用于最终验证。这将极大压缩设计迭代周期。

依据：NVIDIA Modulus、ANSYS Discovery AI 已有商业化产品，MIT/Stanford 的学术工作证明了 GNN 应力场预测的可行性。

趋势4：适航 AI 审查员的出现

判断：在合规校核场景中，AI 将从"辅助生成报告"演进为主动审查员——在设计阶段就预警合规风险。这需要适航局方的认可和标准化的 AI 审查流程。预计 5-10 年内首批"AI 辅助适航审查"指南将出台。

依据：EASA AI Concept Paper 已讨论 AI 在适航中的角色，FAA 的 AI Roadmap 预留了相关接口。
