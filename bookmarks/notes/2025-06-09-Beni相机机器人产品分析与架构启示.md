## 二、核心功能矩阵

### 2.1 拍摄能力
- **4K@30fps** / **3K@60fps** / **1080p@100fps**
- 多角度构图：后方跟随 / 侧方跟随 / 环绕拍摄
- 自动曝光、自动对焦、电子防抖（EIS）

### 2.2 运动能力
- **最高速度**：17.9 mph（约 29 km/h）
- **越障高度**：10 英寸（约 25 cm）
- **全地形适应**：草地、碎石、台阶、坡道
- **续航**：约 1.5 小时，可更换电池

### 2.3 智能功能
- **自动跟随（Auto-Follow）**：基于视觉的目标检测 + 预测性路径规划
- **自动剪辑（Auto-Edit）**：用户选择片段 → AI 输出 highlights
- **世界模型控制**：基于强化学习的端到端运动控制（官方确认）
- **FPV 探索模式**：第一视角远程遥控

### 2.4 互动体验
- **Motion Controller**：实体手柄，控制移动/跳跃/拍照
- **Game Mode**：双人 tug-of-war 互动游戏
- **个性化配件**：耳朵、帽子、贴纸、3D 打印扩展
- **情感设计**：名字"Beni" + 可爱外观 = Sidekick 叙事

## 四、设计启发（4 条核心洞察）

1. **AI 硬件从"谁被替代"开始** — Beni 替代的是跟拍摄影师 + 剪辑师 + 玩伴三位一体
2. **机器人需要角色感** — 耳朵/帽子/名字让 Sidekick 叙事成立，用户产生情感连接
3. **动态示例比参数更有说服力** — GIF 演示（跳台阶/跟滑板/手柄控制）比任何参数表都强
4. **AI 时代硬件趋势 = 工作流硬件** — 感知→决策→创作→互动→情感 完整链路闭环

## 五、5 大风险点

| # | 风险维度 | 具体风险 | 缓解策略 |
|---|---------|---------|---------|
| 1 | 视觉跟随 | 逆光/遮挡/多人/宠物乱跑 | 多传感器融合 + 预测模型 |
| 2 | 安全边界 | 越障时家庭/儿童场景安全 | 安全包围圈 + 碰撞检测 + 急停 |
| 3 | 续航 | 1.5 小时对于户外拍摄偏短 | 可更换电池 + 快充 |
| 4 | 自动剪辑 | 模板拼接 vs 智能剪辑质量 | 云端 AI + 用户反馈循环 |
| 5 | 交付风险 | Kickstarter 全链路集成难度 | 模块化设计 + 充分测试 |

## 六、第二篇文章补充信息（妙动创始人澄清）

- Beni 与人形机器人共享底层技术栈（运动控制 + 世界模型）
- 采用强化学习训练的运动策略，非传统规则引擎
- 海外众筹首发策略：验证 PMF + 建立品牌认知
- 世界模型（World Model）用于端到端运动控制决策
- 后续计划扩展产品线（暗示人形机器人消费版）

## 七、对我们的架构设计启示

### 7.1 必选模块（MVP）
1. **视觉目标检测与跟踪** — YOLOv8/RT-DETR + ByteTrack
2. **路径规划与避障** — 融合 2D/3D 感知的局部规划器
3. **运动控制** — 差速驱动模型 + PID 闭环
4. **视频采集与流传输** — RTSP/WebRTC 低延迟传输
5. **移动端遥控 App** — 蓝牙/WiFi 直连 + FPV

### 7.2 增强模块（V2）
1. **世界模型 + RL 策略** — 端到端运动控制
2. **自动剪辑引擎** — 关键帧提取 + 智能拼接
3. **个性化外观系统** — 可更换外壳/配件
4. **多人互动模式** — 竞技/合作游戏模式

### 7.3 技术选型建议
| 模块 | 推荐方案 | 备选方案 |
|------|---------|---------|
| 边缘计算 | Jetson Orin Nano | RK3588 |
| 相机 | IMX586 (4K) | IMX477 |
| 跟踪算法 | RT-DETR + ByteTrack | YOLOv8 + BoT-SORT |
| 运动控制 | ROS2 Control | MicroROS |
| RL 训练 | Isaac Gym / MuJoCo | NVIDIA Isaac Sim |
| 通信 | WiFi 6 + BLE 5.0 | 4G LTE (远程) |
| App | Flutter (跨平台) | React Native |
