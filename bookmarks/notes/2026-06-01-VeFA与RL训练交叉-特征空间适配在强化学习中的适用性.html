VeFA 与 RL 训练交叉分析：特征空间适配在强化学习中的适用性（2026-06-01）

夜学深度笔记 | 从侵入维度消除策略（VeFA/HiP-LoRA/KeepLoRA）出发，分析特征空间适配方法能否承载 RL advantage 信号。覆盖 Hybrid-LoRA（RLVR 后训练实证）、LoFT（优化器对齐）、LOFT（正交 PEFT 统一框架）、LoRATRF（特征增强）的最新研究，建立 VeFA→RL 适用性的完整论证链。
日期：2026-06-01

一、核心发现

1. VeFA 的 RL 适用性核心矛盾：逐元素缩放 vs advantage 信号

VeFA（arXiv 2510.19155）的核心机制是 W_eff = diag(v) · W₀，其中 v 是逐特征缩放向量。这种设计天然避免了侵入维度（有效权重矩阵的列空间是 W₀ 列空间的子集），但在 RL 场景面临根本挑战：

数学分析：GRPO 的 advantage 信号 A(x,y) 是一个标量，但它需要通过策略梯度 ∇θ log π(y|x) · A(x,y) 传播到参数空间。LoRA 的低秩矩阵 ΔW = BA 可以学习新的方向来编码这种梯度信号。而 VeFA 的 diag(v) 只能做各向异性的幅度调整——它不能旋转 W₀ 的任何奇异向量。

Schulman 信息论论证的启示：RL 每轮仅需 O(1) bits 信息，远低于 LoRA rank-1 的参数容量（3M 参数 = 数百万 bits）。这意味着 VeFA 的表达能力限制在 RL 场景中可能不是瓶颈——关键不在于能学多少信息，而在于以什么形式学。

推断：VeFA 在 RL 中可能优于 SFT 场景，因为 RL 的信号更稀疏、更简单（标量 advantage vs 逐 token 梯度）。但 VeFA 的分布鲁棒性优势在 RL reward hacking 场景中可能特别有价值。

2. Hybrid-LoRA 实证：RLVR 后训练中 LoRA 的系统性不足（arXiv 2605.18822, May 2026）

这是目前最直接研究 LoRA 在 GRPO/GSPO 后训练中表现的工作，提供了关键实验数据：

核心发现：
- LoRA 在 RLVR 后训练中存在系统性性能差距：纯 LoRA 在 Math-500 上比 FullFT 低 5-8 个点
- 10% FFT 模块即匹配全参微调：仅对 10% 参数量最大的模块做全参微调，其余用 LoRA，性能接近 FullFT
- 模块分配模式：FFT 模块集中在后层 Attention（q/k/v/o），FFN 层（gate/up/down）LoRA 即足够
- 在 Qwen-2.5 1.5B/3B/7B 三个规模上验证，Hybrid-LoRA 平均优于最佳基线 4.36%

Hybrid-Score 评分机制：
- 短期 LoRA probing 阶段（500 步）
- 对每个模块计算梯度加权的敏感度：s = (1/r) ||e ⊙ g||₁
- 综合 μ（均值）· σ（方差）得到最终分数
- 低分模块 → 不适合 LoRA → 分配 FFT

关键数据点（Qwen-2.5 1.5B, GRPO）：
- FullFT: Math-500 80.6, AIME-24 40.0, MMLU-Pro 55.6
- LoRA (AdaLoRA): Math-500 75.3, AIME-24 32.0, MMLU-Pro 50.5
- Hybrid-LoRA (10% FFT): Math-500 80.2, AIME-24 38.0, MMLU-Pro 54.9
- 可训练参数：FullFT 1544M vs Hybrid-LoRA 105M（93% 减少）

3. LoFT：优化器对齐消除 LoRA-FullFT 差距（arXiv 2505.21289）

LoFT（Low-rank Adaptation That Behaves Like Full Fine-Tuning）从优化器动态角度解决 LoRA 性能差距：

核心创新：不仅学习低秩权重更新，还将优化器的动量和方差（Adam 的 m 和 v）投影到同一低秩子空间。这使低秩更新的轨迹与全参微调的轨迹对齐。

消除超参数：LoFT 不需要调节 LoRA 的缩放因子 α，因为优化器动态已经被正确建模。

与 VeFA 的关系：LoFT 追求与 FullFT 的行为等价（间接避免侵入维度），而 VeFA 从数学结构上保证不产生侵入维度。两者思路互补：LoFT 适用于需要 FullFT 级别表达能力的场景，VeFA 适用于需要强分布鲁棒性的场景。

4. LOFT 正交 PEFT 统一框架（arXiv 2605.11872）

LOFT（Low-Rank Orthogonal Fine-Tuning）从正交变换角度统一了多种 PEFT 方法：

核心洞见：正交 PEFT 的两个独立设计选择常被混淆——(1) 适配发生在哪个子空间；(2) 在该子空间内应用什么变换。LOFT 将正交适配视为「乘法子空间旋转」，统一了 coordinate/butterfly/Householder/principal-subspace 四种变体。

任务感知支持选择：一阶分析表明，有价值的适配支持应由下游训练信号决定。梯度信息指导的子空间选择在相同参数/内存/计算预算下改善效率-性能权衡。

VeFA 的定位：VeFA 的 diag(v)·W₀ 可被视为一种退化的正交适配（只调幅度不调方向），LOFT 框架可以将其纳入统一视角。

5. LoRATRF：特征增强型 LoRA（arXiv 2412.09827）

LoRATRF（Low-Rank Adaptation with Task-Relevant Feature Enhancement）从特征层面增强 LoRA：

核心思路：设计任务感知过滤器，从隐藏表示中选择性提取对目标任务有价值的知识。在参数减少 33.71% 的同时优于 SOTA 低秩方法。

与 VeFA 的互补性：VeFA 在特征空间做逐元素缩放，LoRATRF 在特征空间做选择性过滤。两者都操作特征而非权重，但 VeFA 是无参数化的幅度调整，LoRATRF 是有参数化的特征选择。

二、技术原理解析

2.1 VeFA 在 RL 中的适用性论证链

Step 1：RL 信号的信息量分析

Schulman 的信息论论证：每轮 GRPO 训练产生 O(1) bits 信息（一个标量 advantage）。而 VeFA 的 diag(v) 对 d 维权重有 d 个自由度。即使 d = 4096（Llama-3.1-8B hidden_size），信息容量也远超 RL 需求。

Step 2：VeFA 的梯度流动分析

GRPO 策略梯度：∇_v L = E[∇_v log π(y|x) · A(x,y)]

其中 π(y|x) = softmax(W_eff · h(x)) = softmax(diag(v) · W₀ · h(x))

∇_v log π = (∂ log π / ∂ W_eff) · (∂ W_eff / ∂ v) = (∂ log π / ∂ W_eff) · diag(W₀ · h(x))

关键观察：∂ W_eff / ∂ v = diag(W₀ · h(x))，这是一个 d 维向量。advantage 信号通过这个向量传播到 v 的每个分量。因为 diag(v) 只影响 W₀ 各列的幅度，梯度信号会被 W₀ 的结构所调制——强特征方向获得更强的梯度，弱特征方向获得更弱的梯度。

Step 3：与 LoRA 的梯度对比

LoRA 的梯度路径：∇_{A,B} L = (∂ log π / ∂ W) · h(x)^T (for B) 和 x^T · (∂ log π / ∂ W) (for A)

LoRA 可以学习新方向（A 和 B 的列空间可以超出 W₀），而 VeFA 被限制在 W₀ 的列空间内。但在 RL 场景中，Schulman 证明 rank-1 LoRA 即可匹配 FullFT，说明 RL 不需要新方向——只需调整已有方向的幅度。这正是 VeFA 擅长的。

2.2 Hybrid-LoRA 的启示：哪些模块 VeFA 可能失败

Hybrid-LoRA 的模块分配分析揭示了一个关键模式：
- Attention 层（特别是后层 q/k/v/o）：需要全参更新，LoRA 表达能力不足
- FFN 层（gate/up/down）：LoRA 足够，因为 FFN 本质是知识存储/检索

推论：VeFA 可能适用于 FFN 层（知识存储的幅度调整），但可能不适用于后层 Attention（需要方向性变化来建模新的注意力模式）。

理想组合方案：VeFA 适配 FFN 层 + Hybrid-LoRA 方式处理 Attention 层 → 既获得 VeFA 的分布鲁棒性，又保证 Attention 层的表达能力。

2.3 从侵入维度角度的统一分析

方法 操作空间 侵入维度 RL 适用性 分布鲁棒性

四、Actionable Insights

  1. VeFA + FFN 的 RL 训练方案：基于 Hybrid-LoRA 发现 FFN 层 LoRA 足够，可尝试 VeFA 适配 FFN 层 + 标准 LoRA 适配 Attention 层的混合方案。这样在 FFN 层获得数学保证的分布鲁棒性，同时保持 Attention 层的表达能力。

  2. Hermes 自进化的遗忘防护：VeFA 的无侵入维度保证在持续学习场景中特别有价值。Hermes 的 skill 学习如果涉及 adapter 更新，VeFA 可以防止累积遗忘，同时保持足够的 RL 信号学习能力。

  3. RL reward hacking 防御：VeFA 的强分布鲁棒性可能天然缓解 reward hacking——因为 VeFA 不能学习新的方向，只能调整已有特征的权重，所以 reward hacking 需要的「捷径方向」可能被结构性阻止。

  4. Hybrid-Score 评分用于 VeFA 选择：可以借鉴 Hybrid-LoRA 的 probing + scoring 策略来决定哪些模块用 VeFA、哪些用 LoRA/FFT，而非全局统一使用。

  5. VeFA 与 FP8-RL 的天然兼容：VeFA 的逐元素缩放 v 在 FP8 下量化误差可能更可控（因为是对角操作，不涉及矩阵乘法的误差累积）。这值得在 veRL 框架中实验验证。
