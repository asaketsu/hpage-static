## 二、星动纪元 XHAND1Pro 产品发布

### 2.1 产品定位

**"大脑手"——AI 定义硬件**

从具身大脑的训练需求出发，反向定义灵巧手的机械架构、传感排布和控制底层。

### 2.2 核心参数

| 维度 | 参数 | 说明 |
|------|------|------|
| **自由度** | 21 DOF 全直驱 | 侧掌独立自由度，提升小拇指对指精度 |
| **触觉感知** | 18 个分布式触觉传感器 | 覆盖指尖、指腹、掌心，X/Y/Z 三维力感知 |
| **精度** | 关节背隙 < ±0.25mm | 双编码器动态补偿齿轮背隙与传动空程 |
| **重复定位精度** | ±0.1mm | 高一致性动作复现 |
| **力控带宽** | 4kHz 电流环 | 高精度力控算法开发 |
| **开合频率** | > 5 次/秒 | 快速抓放、高频控制、强化学习 |
| **抓握范围** | 最大展开 135°，包络直径 > 160mm | 覆盖更多尺寸和形态 |
| **供电** | 24V-72V 宽压 | 工业级供电范围 |
| **通讯** | RS-485 / EtherCAT / CANFD | 多协议兼容 |
| **软件** | Ubuntu + SDK + C/Python + ROS1/ROS2 | x86/ARM 双架构 |

### 2.3 关键升级

| 升级点 | 意义 |
|--------|------|
| **全掌触觉** | 不只是"是否接触"，而是"接触位置、力度、物体状态" |
| **全直驱结构** | 力控响应与执行一致性，高保真物理交互数据 |
| **侧掌独立自由度** | 提升小拇指对指精度和整手抓握能力 |
| **遥操作支持** | VR 头显、动捕、外骨骼手套 + 自研高精度操作件 |

## 四、核心洞察

### 4.1 AI 定义硬件

如果一只手无法稳定复现动作，模型就很难判断任务失败来自算法还是硬件误差。

- 触觉反馈不完整 → 模型只能拿到部分接触信息
- 力控响应迟滞 → 真实物理交互数据被传动噪声扭曲

**"大脑手"的核心：让灵巧手成为具身大脑进化链路的一部分**

### 4.2 数据闭环

```
真实任务 → 灵巧手采集数据 → 具身大脑训练 → 策略下发 → 真实任务
    ↑                                                        │
    └──────────────── 数据回流 ──────────────────────────────┘
```

### 4.3 自由度 ≠ 全部

| 维度 | 重要性 | 说明 |
|------|--------|------|
| 自由度 | 基础 | 决定操作空间覆盖范围 |
| 精度 | 关键 | 决定数据可重复性 |
| 触觉 | 核心 | 决定物理交互质量 |
| 力控 | 保障 | 决定操作稳定性 |
| 开发适配 | 门槛 | 决定接入效率 |
