一、核心发现

1. DoRA 归一化在量化基座上的数值不稳定性是真实存在的风险

DoRA 的核心操作是对更新后的方向矩阵做列归一化：V' = (W₀ + BA) / ||W₀ + BA||_c，然后用可训练的幅度向量 m 重缩放。当 W₀ 是量化权重（NF4/FP8）时：

  • 量化误差注入归一化：W₀ 的量化误差（NF4 ~0.3-0.5 相对误差）直接进入归一化的分母。对于某些列，量化后 ||col||_2 可能接近 0 或异常大，导致归一化结果不稳定
  • 梯度路径变长：DoRA 的梯度需要穿过归一化操作 → 比标准 LoRA 多一次 Jacobian 计算。RL 场景中梯度本身就不稳定（advantage 估计方差高），额外的不稳定来源可能被放大
  • 实测证据：NVIDIA 的 QDoRA 实践表明，在 4-bit 量化基座上 DoRA 可以工作，但需要特别处理归一化步骤（使用 FP32 做归一化计算，即使权重是 4-bit），否则训练会出现 NaN

2. 三种替代方案可绕过 DoRA 的归一化问题

EDoRA（arXiv 2501.12067） — 用 SVD 替代归一化：
- 将预训练权重 W₀ 做 SVD 分解：W₀ = UΣVᵀ
- 冻结 A 和 B 矩阵（来自 SVD 的高秩分量），只训练中间的可学习矩阵
- 30x 更少参数达到 DoRA 的效果
- 关键优势：完全不需要归一化操作，不存在量化基座上的数值稳定性问题
- 在 GLUE 基准上与 DoRA 和 LoRA 竞争或超越

MAP（arXiv 2505.23094） — 两个标量系数：
- 将权重视为高维向量，严格分解为方向和幅度
- 引入两个标量系数 λ_base 和 λ_update，独立缩放基向量和新方向
- 比 DoRA 更简洁：不需要逐列归一化，只需两个全局标量
- 低精度下更友好：标量运算在任意精度下都稳定

Dual LoRA（arXiv 2512.03402，AMD） — ReLU + sign：
- 将 LoRA 矩阵分为幅度组（ReLU 控制"是否更新"和"多大幅度"）和方向组（sign 函数控制"向前还是向后"）
- 无需归一化，使用简单的 ReLU 和 sign 函数
- 天然适合量化场景：ReLU 和 sign 在低精度下仍然定义良好
- 在 NLU 和常识推理任务上一致超越 LoRA 及其 SOTA 变体

3. FP8-RL 验证了统一低精度训练的可行性，但未探索方向-幅度分解

FP8-RL（arXiv 2601.18150） — InfiXAI/Ant Group/SGLang/Miles 联合工作：
- 在 veRL 生态中实现端到端 FP8 RL 训练
- 三个关键组件：(i) blockwise FP8 W8A8 rollout，(ii) FP8 KV cache + per-step QKV scale 重校准，(iii) importance sampling rollout correction（TIS/MIS）
- Dense（Qwen3-8B）和 MoE（Qwen3-30B-A3B）模型上验证
- 44% rollout 加速，学习行为与 BF16 基线相当
- 关键缺失：仅用标准 LoRA 做 RL 适配，未测试 DoRA/EDoRA/MAP 等方向-幅度分解方法

统一 FP8 消除 train-inference mismatch（LMSYS Blog 2025-11）：
- 发现 MoE 模型越大，BF16 训练 + FP8 rollout 的 train-inference 不一致越严重
- 解决方案：训练和 rollout 都用 FP8（统一精度），消除不一致
- 启示：DoRA + 量化 RL 的理想方案应该是"统一低精度"，而非混合精度

4. RL 梯度特性使 DoRA 的幅度分量可能比 SFT 中更关键

Imbalanced Gradients in RL Post-Training（EACL 2026，Meta AI）：
- 多任务 RL 后训练中，不同任务的梯度量级差异巨大（跨任务梯度冲突）
- 梯度量级与学习收益相关性被验证：大梯度任务获得更多增益
- 与 DoRA 的交互：DoRA 的幅度向量 m 本质上是层级的"缩放器"。在 RL 场景中，如果某些层的梯度被 advantage 信号大幅放大，DoRA 的 m 向量可以通过独立调整每列的幅度来吸收部分梯度方差
- 理论上，DoRA 的幅度分量在 RL 中扮演"自适应 gradient clipper"的角色 — 这可能是它在 RL 场景的潜在优势

5. CoA-LoRA：量化配置感知的 LoRA 动态调整

CoA-LoRA（arXiv 2509.25214）：
- 核心问题：不同层的量化配置（per-layer bit-width）不同时，LoRA 适配器如何动态调整？
- 方案：轻量映射网络，将每层的量化配置映射到紧凑的低秩调整
- 配置集搜索基于 Pareto 高斯过程，优化训练配置集
- 启示：如果 DoRA + 量化 RL 要实现，需要类似 CoA-LoRA 的机制来处理不同层量化精度对方向-幅度分解的影响

二、技术原理解析

2.1 DoRA 归一化的数学风险分析

DoRA 的前向传播：

W' = m · (W₀ + BA) / ||W₀ + BA||_c

其中 ||·||_c 是逐列 L2 范数。梯度：

∂L/∂m = ∂L/∂W' · (W₀ + BA) / ||W₀ + BA||_c     # 幅度梯度
∂L/∂B = (m/||V||_c) · ∂L/∂W' · Aᵀ - m·V/||V||_c³ · (∂L/∂W')ᵀ · V · Aᵀ  # 方向梯度（含归一化项）

当 W₀ 是量化权重时：
- W₀ = Quantize(W₀_full) = W₀_full + ε_q
- ε_q 对 NF4 约 0.3-0.5 相对误差
- ||W₀ + BA + ε_q||_c 的稳定性取决于量化误差与 BA 更新的相对大小
- RL 早期训练中 BA 很小（初始化接近零），||W₀ + ε_q||_c ≈ ||W₀||_c + ε_q 的影响更大
- 结论：RL 训练初期（BA 小）DoRA 最不稳定，中后期（BA 大）量化噪声被稀释

四、Actionable Insights

  1. Hermes Agent 的 LoRA Skill 可更新：如果未来做 LoRA 微调任务，优先推荐 EDoRA 或 MAP 而非原始 DoRA，特别是在量化基座上
