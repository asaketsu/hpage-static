## 摘要

Three.js 是一个跨浏览器的 JavaScript 3D 图形库，由 Ricardo Cabello（Mr.doob）于 2010 年创建，当前版本 184（2026-04-16）。它基于 WebGL（底层图形 API）封装了场景、灯光、阴影、材质、纹理、3D 数学等复杂概念，让开发者无需手写底层 WebGL 代码就能在网页中创建 3D 内容。本文从架构原理、核心对象、安装使用、代码实战到高级特性全面拆解。

## 一、Three.js 是什么

Three.js 是 WebGL 的高层封装库。WebGL 是非常底层的 API——只能画点、线、三角形，做任何有用的事都需要大量代码。Three.js 在 WebGL 之上提供了：

- 场景管理（Scene Graph）
- 相机系统（Camera）
- 灯光与阴影（Lights & Shadows）
- 材质系统（Materials）
- 纹理管理（Textures）
- 3D 数学库（矩阵、四元数、向量）
- 动画系统（Keyframe、骨骼、IK）
- 后处理管线（Bloom、DOF、SSAO）
- 模型导入导出（glTF、OBJ、USDZ）
- VR/AR 支持（WebXR）

## 二、核心架构：Three.js 应用的五大对象

Three.js 应用的核心结构可以概括为：**Renderer 渲染器 + Scene 场景 + Camera 相机 + Mesh 网格 + Lights 灯光**。

```
                ┌──────────────┐
                │   Renderer   │ ← 主对象，接收 Scene + Camera，渲染到 Canvas
                │(WebGLRenderer)│
                └──────┬───────┘
                       │
           ┌───────────┼───────────┐
           ▼           ▼           ▼
     ┌──────────┐ ┌─────────┐ ┌────────┐
     │  Scene   │ │ Camera  │ │ Lights │
     │(场景根节点)│ │(相机)   │ │(灯光)  │
     └────┬─────┘ └─────────┘ └────────┘
          │
    ┌─────┼─────┐
    ▼     ▼     ▼
 ┌─────┐┌─────┐┌──────┐
 │Mesh ││Mesh ││Group │
 │(网格)││(网格)││(分组) │
 └──┬──┘└──┬──┘└──────┘
    │       │
 ┌──┴──┐ ┌─┴───┐
 │Geom │ │Geom │
 │etry  │ │etry │
 └─────┘ └─────┘
 ┌─────┐ ┌─────┐
 │Mate │ │Mate │
 │rial │ │rial │
 └─────┘ └─────┘
```

### 2.1 Renderer（渲染器）

Renderer 是 Three.js 的核心对象。它接收 Scene 和 Camera，将 3D 场景中相机视锥体内的部分渲染为 2D 图像到 Canvas。

```javascript
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setAnimationLoop(animate);
document.body.appendChild(renderer.domElement);
```

关键配置：
- `antialias` — 抗锯齿
- `alpha` — 透明背景
- `setSize(width, height)` — 设置渲染分辨率
- `setPixelRatio(window.devicePixelRatio)` — 适配高分屏
- `setAnimationLoop(callback)` — 替代 requestAnimationFrame 的渲染循环

### 2.2 Scene（场景）

Scene 是场景图的根节点，定义了 3D 世界的容器。所有 Mesh、Light、Group 都添加到 Scene 中。

```javascript
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x000000);  // 背景色
scene.fog = new THREE.Fog(0x000000, 10, 50);   // 雾效
```

### 2.3 Camera（相机）

Camera 决定了"从哪个角度看场景"。最常用的是 PerspectiveCamera（透视相机）。

```javascript
const camera = new THREE.PerspectiveCamera(
    75,                                     // fov: 视场角（度）
    window.innerWidth / window.innerHeight, // aspect: 宽高比
    0.1,                                    // near: 近裁剪面
    1000                                    // far: 远裁剪面
);
camera.position.z = 5;  // 相机后移5个单位
```

相机四参数决定了**视锥体（Frustum）**——一个截头锥体，只有在这个范围内的物体才会被渲染。

| 参数 | 说明 | 典型值 |
|------|------|--------|
| fov | 视场角，越大看得越广 | 45-90° |
| aspect | 宽高比 | innerWidth/innerHeight |
| near | 近裁剪面距离 | 0.1 |
| far | 远裁剪面距离 | 100-10000 |

还有一种 OrthographicCamera（正交相机），没有近大远小的透视效果，常用于 2D 游戏或工程制图。

### 2.4 Mesh（网格）= Geometry + Material

Mesh 是场景中可见的 3D 物体，由 Geometry（几何体）和 Material（材质）组成。

```javascript
const geometry = new THREE.BoxGeometry(1, 1, 1);           // 1x1x1 的立方体
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 }); // 绿色材质
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

**Geometry（几何体）**定义顶点数据——形状。内置几何体：

| 几何体 | 类名 | 说明 |
|--------|------|------|
| 立方体 | BoxGeometry | 长/宽/高可调 |
| 球体 | SphereGeometry | 半径、经纬分割数 |
| 平面 | PlaneGeometry | 宽/高 |
| 圆柱体 | CylinderGeometry | 顶/底半径、高度 |
| 圆环 | TorusGeometry | 环半径、管半径 |
| 文字 | TextGeometry | 需加载字体 |

**Material（材质）**定义表面属性——看起来什么样。材质层级：

```
Material（基类）
├── MeshBasicMaterial — 不受光照影响，最简单最快
├── MeshLambertMaterial — 顶点级光照计算
├── MeshPhongMaterial — 像素级光照 + 高光
├── MeshStandardMaterial — PBR 物理渲染（金属度+粗糙度）
├── MeshPhysicalMaterial — PBR + 透射/清漆等高级属性
├── MeshToonMaterial — 卡通渲染（阶梯式着色）
└── ShaderMaterial / RawShaderMaterial — 自定义 GLSL 着色器
```

**性能原则**：不需要光照用 Basic，不需要高光用 Lambert，需要真实感用 Standard/Physical。

### 2.5 Lights（灯光）

灯光照亮场景中的物体（MeshBasicMaterial 除外）。

| 灯光 | 类名 | 说明 |
|------|------|------|
| 环境光 | AmbientLight | 均匀照亮所有物体，无方向 |
| 平行光 | DirectionalLight | 模拟太阳光，平行光线 |
| 点光源 | PointLight | 从一个点向四周发光（灯泡） |
| 聚光灯 | SpotLight | 锥形光束（手电筒） |
| 半球光 | HemisphereLight | 天空色 + 地面色 |
| 矩形光 | RectAreaLight | 矩形面光源（柔光箱） |

```javascript
const light = new THREE.DirectionalLight(0xffffff, 1);
light.position.set(5, 5, 5);
scene.add(light);
```

## 四、完整实战：旋转立方体

```javascript
import * as THREE from 'three';

// 1. 创建场景
const scene = new THREE.Scene();

// 2. 创建相机
const camera = new THREE.PerspectiveCamera(75, innerWidth/innerHeight, 0.1, 1000);
camera.position.z = 5;

// 3. 创建几何体 + 材质 → 网格
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 4. 创建渲染器
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 5. 渲染循环
function animate(time) {
    cube.rotation.x = time / 2000;
    cube.rotation.y = time / 1000;
    renderer.render(scene, camera);
}
renderer.setAnimationLoop(animate);
```

五步流程：**Scene → Camera → Mesh(Geometry+Material) → Renderer → Animation Loop**

## 五、场景图（Scene Graph）

Three.js 使用树形结构管理 3D 对象，父子关系决定了位置和朝向的继承：

```javascript
const car = new THREE.Group();
const body = new THREE.Mesh(bodyGeo, bodyMat);
const wheel1 = new THREE.Mesh(wheelGeo, wheelMat);
wheel1.position.set(-1, -0.5, 1);

car.add(body);
car.add(wheel1);
scene.add(car);

// 移动 car → wheel1 自动跟着动
car.position.x = 5;
```

**关键**：子节点的 position/rotation/scale 是相对于父节点的。

## 六、Controls（控制器）

Three.js 提供了丰富的交互控制器（在 addons 中）：

| 控制器 | 说明 |
|--------|------|
| OrbitControls | 围绕目标旋转/缩放/平移（最常用） |
| DragControls | 拖拽物体 |
| TransformControls | 平移/旋转/缩放变换手柄 |
| PointerLockControls | FPS 风格鼠标锁定 |
| FlyControls | 自由飞行 |
| TrackballControls | 轨迹球旋转 |

```javascript
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
const controls = new OrbitControls(camera, renderer.domElement);
controls.target.set(0, 5, 0);
controls.update();
```

## 七、高级特性

### 7.1 PBR 物理渲染

```javascript
const material = new THREE.MeshStandardMaterial({
    color: 0xff0000,
    metalness: 0.8,    // 金属度 0-1
    roughness: 0.2,    // 粗糙度 0-1
});
```

### 7.2 后处理（Post-Processing）

```javascript
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));
composer.addPass(new UnrealBloomPass(new THREE.Vector2(innerWidth, innerHeight), 1.5, 0.4, 0.85));
```

支持效果：Bloom（辉光）/ DOF（景深）/ SSAO（环境遮蔽）/ FXAA（抗锯齿）/ Motion Blur / Outline 等。

### 7.3 实例化渲染（Instancing）

一次绘制数千个相同物体：

```javascript
const mesh = new THREE.InstancedMesh(geometry, material, count);
// 设置每个实例的变换矩阵
const matrix = new THREE.Matrix4();
mesh.setMatrixAt(i, matrix);
```

### 7.4 模型加载

```javascript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
const loader = new GLTFLoader();
loader.load('model.glb', (gltf) => {
    scene.add(gltf.scene);
});
```

支持格式：glTF（推荐）/ OBJ / FBX / USDZ / STL / PLY

### 7.5 WebGPU 渲染器（实验性）

```javascript
import { WebGPURenderer } from 'three/addons/renderers/WebGPURenderer.js';
const renderer = new WebGPURenderer();
```

WebGPU 是 WebGL 的下一代替代，提供更好的性能和计算着色器支持。

## 八、性能优化要点

| 优化手段 | 说明 |
|---------|------|
| 使用最简单的材质 | 不需要光照就用 BasicMaterial |
| InstancedMesh | 大量相同物体用实例化 |
| LOD（Level of Detail） | 远处用低精度几何体 |
| 纹理压缩 | 使用 KTX2 格式 |
| 视锥体裁剪 | Three.js 自动执行 |
| 合批（Merge） | 静态物体合并为单个几何体 |
| 对象池 | 复用对象避免 GC |
| setPixelRatio | 不要超过 2，2x 已经很清晰 |

## 九、能力边界

- Three.js 不是游戏引擎——没有内置物理、碰撞、UI 系统
- 学习曲线中等——需要理解 3D 图形学基础概念
- 大型场景需要手动优化——不会自动管理性能
- WebGPU 渲染器仍为实验性
- 移动端性能受限——需要降级策略
- 不支持服务端渲染（SSR）
