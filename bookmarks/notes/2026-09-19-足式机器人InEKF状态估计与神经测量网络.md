## 内容整理：核心问题

足式机器人控制依赖机体姿态/速度/位置的准确估计，但纯本体感知（IMU + 关节编码器）方案面临三重困境：
1. 传统 EKF 假设足端非滑动接触，软地/打滑时残差污染滤波器
2. 学习法（IoNet/RoNIN 类）直接从 IMU 回归位姿，黑箱难标定、误差无界累积
3. 混合法需要真机数据采集——足式机器人数据采集极贵

## 内容整理：方法详解

### 核心架构：NMN（GRU-MLP）作为 IEKF 的测量模型

- **NMN 输入**：m_t = [ã_t, ω̃_t, q̃_t, q̇̃_t, q_des_{t-1}]（加速度+角速度+关节角+关节速度+上步目标）
- **NMN 输出**：ĉ_t（足端接触概率）+ v̂_t^b（机体线速度，body frame）
- 两者作为 IEKF 校正步的**观测**注入，而非直接输出状态——网络只做测量，滤波器管融合
- 关键设计：v̂_t^b = R_t^T·v_t + w^NN 构造成**右不变观测形式**（Y = X⁻¹b + V），保持 Lie 群结构 → InEKF 的对数线性误差动力学优势不被破坏

### IEKF 状态空间（SE_{N+2}(3) Lie 群）

X_t = [R, v, p, d]（旋转/速度/位置/世界系接触点位置），系统动力学由 IMU 预积分驱动，接触点静止约束 d_t 的速度噪声建模打滑。Kalman 更新用 log-linear 一阶近似：X⁺ = exp(K·Π·X̄·Y)·X̄

### 训练管线：纯仿真数据 + sim2real 三件套

- 数据：Raisim 仿真，400 env × 400 步/迭代，4kHz 仿真/500Hz 估计器；地形 U(0.2,1.4) 山丘+台阶+楼梯，摩擦 U(0.4,1.2)，1% 概率强制打滑（摩擦 U(0.3,0.4)）
- 损失：L = L_BCE(接触) + L_L1(速度) + λ·L_smooth，λ=50；**平滑损失（CAPS 启发）惩罚速度输出的一阶+二阶差分**——只加在 v̂ 上（接触本质离散）
- sim2real 三技术：early stopping（200 iter 后过拟合仿真器）、domain randomization、平滑正则
- 反直觉发现：**机器人模型足够准时，DR 反而降低速度预测精度**（消融证明）

## 关键实验结果

- 四地形（平地/碎石/软地/打滑）Vicon 真值验证：NMN+IEKF 位置漂移显著低于模型基线（InEKF 硬接触假设）
- 学习到的线速度测量模型是**滤波器无关**的——可移植到 EKF/UKF/因子图等其他估计器
- 消融：平滑损失+early stopping 是 sim2real 迁移的主力；DR 在准确模型下是负资产
- 估计器 500Hz 实时运行，与 4kHz 仿真解耦

## 查询拓展

- InEKF 理论线：Barrau & Bonnabel 2017（group affine → log-linear 误差动力学）；Hartley RSS 2018（Cassie 双足验证 InEKF > QEKF）；Lin 2021（学习接触检测替代物理传感器）
- 打滑处理线：Kim 2021 动态接触事件（速度阈值改协方差）；Teng 2021 滑动环境速度更新
- 双 IMU 视角：DUCK 骨盆+头部双 IMU 可互为冗余校验——头部 IMU 6° 静态俯仰偏置可用 InEKF 的 bias 增广在线估计，不需静态标定
- 与 RL 策略的关系：论文故意让估计器与控制器观测解耦（policy 用原始 IMU roll-pitch，不用估计状态）——避免估计误差反馈进控制回路形成耦合失稳

## 归纳总结

1. "网络做测量、滤波器做融合"是学习×模型混合的正确切面——保留可解释性/协方差语义，网络只补模型盲区（接触/打滑/软地）
2. 右不变观测形式是融合神经测量的结构门禁：不满足 Lie 群形式的学习输出无法进 InEKF
3. 纯仿真训练可行，但靠 early stopping + 平滑正则而非无脑 DR；模型准时 DR 是负资产
4. 平滑损失（一阶+二阶差分正则）是廉价高效的 sim2real 桥——对时序回归网络通用
5. 估计器与控制器观测解耦，避免估计误差进入控制回路

## 趋势判断

- 足式机器人状态估计的主流路线已从"纯模型"（EKF 硬接触假设）迁移到"模型骨架+神经测量"，KAIST/ETH/UMich 系全线跟进
- 双 IMU/多 IMU 冗余（机身+腿部 IMU）是新增长点——DogLegs 等工作把 IMU 下放到腿上直接测接触振动
- 500Hz 轻量 GRU 在 Jetson 级边缘算力完全可跑——DUCK 的 Pi5 部署无算力障碍
- InEKF 的 Lie 群状态空间正在成为足式估计器的标准底座（等价于视觉 SLAM 的 SE(3) 底座地位）

## 拓展应用推荐

**对 DUCK-Pi_5（直击今晨双 IMU 轴向定案）**：
- P0：头部 IMU 0x6B 的 6° 静态俯仰偏置——按本文 bias 增广思路，在 robotd 的 IMU 读取层加**在线偏置估计**（静止窗均值 + 缓慢更新的一阶低通），替代一次性静态标定；比手标更稳（温漂/安装应力自适应）
- P1：足端接触概率 ĉ_t 可从现有数据免费获得——DUCK 关节编码器 + IMU 数据已有，训一个迷你 NMN（GRU-128）输出接触概率，喂给步态调试/跌倒检测，不需要改控制
- P2：骨盆+头部双 IMU 互验——两颗 IMU 的 grav 向量在静止时应一致（差 = 头颈相对姿态），可做实时健康检查（一颗漂了立刻发现），比单 IMU 盲飞强
- P2：位置/速度全状态估计暂缓——当前 obs 用原始 IMU + 关节角已够训练收敛，等真机行走时再上 InEKF

**对 Hermes Agent**：
- "网络做测量、滤波器做融合"是 Agent 混合架构的通用切面：LLM 做特征提取、确定性层做融合决策——与 deterministic-guardrails skill 的哲学同构
- 平滑损失思路可用于时序信号回归类 skill（传感器去噪/指标平滑）

**对量化交易**：
- early stopping + 平滑正则 > 无脑 DR 的结论映射到因子训练：因子正则化（IC 平滑约束）优于盲目数据增强
- InEKF 的协方差语义 = 仓位不确定性管理：状态估计置信度低时降杠杆，与风控引擎同构

## 指南分析：落地步骤清单

DUCK 头部 IMU 在线偏置估计（P0，Pi5 侧 robotd 补丁）：
1. 在 robotd IMU 读取循环中维护 bias 向量 b（初值 = 今晨静态窗均值 (-0.107,-0.064,1.0)g）
2. 静止检测：|ω| < 0.02 rad/s 持续 >0.5s 判静止，静止窗内 grav 均值以 α=0.01 指数更新 b
3. 输出 grav_corrected = grav_raw - (b - b_ideal)，b_ideal=(0,0,-1)
4. 验证门禁：静止时 grav_corrected 三轴偏差 <0.02g；前倾 30° 动作后回正，grav_x 回到 0±0.05
5. 坑点：更新只在静止窗做，运动中冻结 b（否则重力分量被吃进 bias）；双 IMU 各自独立维护
