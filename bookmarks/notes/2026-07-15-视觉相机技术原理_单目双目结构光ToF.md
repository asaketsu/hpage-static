# 视觉相机技术原理深度解析：单目、双目、结构光、ToF 优劣与适用场景

## 核心结论

四大视觉方案不存在绝对优劣，只存在场景适配区别。高阶方案采用多类视觉设备互补 + 激光雷达融合 + BEV统一空间建模。

---

## 一、单目RGB（2D）

| 维度 | 内容 |
|------|------|
| **成像原理** | 小孔成像，CMOS接收反射光，3D场景投影为2D像素 |
| **深度获取** | 无原生深度，靠AI模型+纹理尺寸/遮挡关系/地面几何先验推理 |
| **优势** | 成本极低、体积小、标定简单、分辨率上限高、语义识别强 |
| **缺陷** | 弱纹理区域失效、尺度混淆、远距离误差大 |
| **定位** | 自动驾驶主力感知设备，需搭配BEV模型或激光雷达补深度 |
| **场景** | 前视主摄、侧方补盲、环视泊车、纯视觉SLAM |

---

## 二、双目立体视觉（2.5D）

| 维度 | 内容 |
|------|------|
| **成像原理** | 人眼视差原理，两台同步相机+固定基线，三角几何直接算深度 |
| **核心逻辑** | 视差越大→物体越近；视差越小→物体越远 |
| **优势** | 物理测距可信度高、输出稠密深度图、被动方案无光源干扰、室内外通用 |
| **缺陷** | 低纹理场景失效、算力消耗高、标定维护要求严苛（震动/热变形影响基线） |
| **定位** | 户外纯视觉高精度方案 |
| **场景** | 室外巡检机器人、无人机、NAV2室内小车辅助定位 |

---

## 三、结构光相机（3D·主动式）

| 维度 | 内容 |
|------|------|
| **成像原理** | 主动投射编码光斑/条纹→接触物体形变→接收相机采集畸变图案→三角测距 |
| **本质** | 主动制造人工纹理，纯白无纹理环境也能工作 |
| **优势** | 无光环境稳定、无纹理场景可行、毫米级近距离精度、细节丰富 |
| **缺陷** | **太阳光下完全失效**（红外杂光覆盖编码光斑）、测距短、成本高、体积大 |
| **定位** | 室内高精度专用 |
| **场景** | 人形机器人机械臂抓取、三维扫描重建、人脸识别门禁 |

---

## 四、ToF飞行时间相机（3D·主动式）

| 维度 | 内容 |
|------|------|
| **成像原理** | 高频调制红外光→反射→记录时间差/相位差→光速换算距离 |
| **优势** | 帧率高、算力需求低、无光稳定、成本低于结构光 |
| **缺陷** | 深度分辨率低（仅轮廓）、远距离精度衰减、多机红外串扰、户外强光削弱 |
| **定位** | 低成本近距离动态测距 |
| **场景** | 扫地机器人、仓储AGV避障、人体感应 |

## 横向对比矩阵

| | 单目RGB | 双目 | 结构光 | ToF |
|---|---|---|---|---|
| **测距方式** | AI推理 | 三角几何 | 三角测距 | 光时差 |
| **是否主动光源** | ❌ 被动 | ❌ 被动 | ✅ 主动 | ✅ 主动 |
| **室内** | ✅ | ✅ | ✅ 最佳 | ✅ |
| **户外** | ✅ | ✅ 最佳 | ❌ | ⚠️ 受限 |
| **无光环境** | ❌ | ❌ | ✅ | ✅ |
| **无纹理场景** | ❌ | ❌ | ✅ | ✅ |
| **精度** | 低(AI) | 中 | 毫米级 | 低 |

## 最终选型逻辑

- **语义识别 + 量产 + 长期稳定** → 单目RGB + BEV大模型
- **户外 + 纯视觉物理深度** → 双目视觉
- **室内 + 毫米级高精度抓取/建模** → 结构光
- **算力有限 + 近距离快速避障** → ToF
- **高阶方案** → 多类视觉互补 + 激光雷达融合 + BEV统一空间建模

## 关联思考

- 与机器人视觉系统选型直接相关（参见 ~/uclaw/project/two-wheel-legged-robot/）
- 双目方案对STM32+Pixracer平台算力有要求，需评估嵌入式可行性
- 结构光适合机械臂抓取环节，ToF适合近距离避障
- 后续可研究BEV模型架构（Occupancy Network / BEVFusion等）
