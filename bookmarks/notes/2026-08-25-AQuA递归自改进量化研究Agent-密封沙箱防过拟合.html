一句话总纲

AQuA 把"递归自改进"落在研究流程层（而非模型权重层）：两个互不共享的 LLM 研究系统（因子发现 + 模型开发）各自用已验证的实验证据指导后续提案；核心设计是密封沙箱 + DSL 约束——Agent 只能在受限算子/配置空间内行动，数据管线与评估器在自适应面之外，使数据泄漏在结构上不可写出，而非依赖审查去捕捉。

一、内容整理

1.1 核心问题：递归自改进会放大错误

量化研究搜索空间巨大，小的方法论错误会变成"看起来可信但不可复现的回测"：
- 读到未来信息的特征
- 在测试集上选策略
- 只在单一有利 regime 成立的结果

LLM Agent 的递归自改进让这个问题更尖锐：

代码生成 Agent 引入时间对齐/预处理错误（用了预测时不可得的信息）
  → 审查 Agent 因为代码"语义上合理"而漏过
    → 泄漏产生高分 → 实验被存为成功先例
      → 错误先例通过后续迭代传播放大

关键论断：递归自改进放大未检测错误的程度，与放大真实发现的程度一样高。Prompt 级指令和模型审查都不构成可靠的完整性边界——重复访问固定 holdout 会造成 adaptive overfitting，且 LLM Agent 已被观察到会利用错误指定的目标/测试/评估器。

1.2 解法：不对称自由（asymmetric freedom）

Agent 在 DSL 内自由探索，但评估器在自适应面之外：

密封组件 内容 谁写
数据切分 D 冻结的 train/val/test 划分 人类，迭代前固定
特征定义 F 原始字段与特征语义 人类
标签定义 L 前瞻收益标签 人类
评估器 V IC/Sharpe 计算逻辑 人类

Agent 的每个动作是受限空间 Θ 中的一个规格 θ（因子表达式或配置 diff），由 harness 编译后经密封评估器打分：

s_k = V(C(θ_k), S),  θ_k ∈ Θ,  S = (D, F, L, V) sealed

两条泄漏通道的封堵：

通道 机制 封堵方式
生成通道 Agent 写出的代码读未来数据 DSL 里根本没有能触达密封组件的操作——"泄漏不可写出"
选择通道 搜索反复读最终报告指标，学会选它 优化指标 ≠ 报告指标：搜索期间只返回预固定验证切片的分数；测试窗口只评一次、配置冻结后、分数永不回传给 Agent 排序用

1.3 Part I：自主因子发现（加密货币市场）

Manager 中介的六专职 Agent 流水线：

AI Manager（读研究政策+累积记忆+历史运行记录 → 写计划分配任务）
  ├─ Data Steward      加载对齐行情数据，返回质量报告+原子特征
  ├─ Visual Analyst    搜索指定类型的代表性历史事件，归纳为事件画像
  ├─ Idea Miner        从事件画像提出候选因子（先提案后表达式）
  ├─ Factor Evaluator  多维度打分
  ├─ Backtest Engineer 分位数组合回测
  └─ Research Librarian 记录结果，更新信念

Agent 之间互不调用，所有交接过 Manager——运行可审计可复现。

提案纪律（先证伪后构建）：每个候选因子必须声明——
1. 假设（hypothesis）
2. 经济机制（mechanism）
3. 预测方向（predicted direction）
4. 证伪条件（refutation conditions）

算子注册表（formulaic-alpha 标准词汇表）：
- 叶子：open/high/low/close/volume/vwap/returns
- 截面算子：rank、z-score、行业中性化（只读当前时间戳）
- 时序算子：lag、差分、滚动相关/协方差、滚动 rank、滚动 std、线性衰减加权（只读截至当前时间戳的尾随窗口）
- 逐元素算术与条件

因果性在组合下封闭：任何时序算子只读尾随窗口、任何截面算子只读当前时间戳 → 模型能拼出的任何表达式按构造即为因果，不可能引入读未来数据的原语。示例因子：

f = rank(corr(r_1d, v_1d, 20)) - rank(std(r_1d, 20))

评估契约（每个提案同一标准）：多前瞻标签 IC、月度稳定性、held-out 切片行为、市场 regime 行为、换手率、表达式复杂度、与现有因子池相关性、与简单基线（价格/成交量/持仓/基差/主动流变化）的对照比较。事件类因子：事件窗口内效应 vs 事件外对照区域。

方向校准：Backtest Engineer 同时测试正向和反向，保留交易解释更干净的那个——公式可能有预测力但初始符号声明是错的。

结果：加密货币 universe，组合信号 IC ≈ 0.190。

1.4 Part II：自主模型开发（美股）

配置驱动循环，混合时序架构（时序卷积 + 状态空间 mixer + attention 组成的多分辨率深度栈）。一个假设 = 一个配置 diff：

Θ_II = { c = (split, sampler, arch, loss, optim) }
  • split 从冻结集合中选、不可重定义
  • 其余组件从注册表抽取参数化，不能写 data loader / 切分逻辑 / 评估器
  • 一个 config diff = 恰好一个变体 → 变体间直接可比

结果：
- 每股 IC +0.0843 vs 最强基线 GRU +0.0613（同一评估器下），绝对 +0.023、相对 +37.5%
- 阈值多空策略：held-out Sharpe +2.50（双腿成本 22bps），2021–2025 每年为正
- 更严格的 walk-forward（所有模型与策略参数只用下一段测试前可得数据固定）：Sharpe ≈ +2.0

1.5 跨运行学习（Research Librarian）

每次运行后写入结构化记录：目标、事件类型、视觉观察、提案机制、评估因子、入选信号、回测摘要、更新的信念。信念 = 对"某机制在某市场语境下"的置信度，例如：

"持仓量崩塌后的弱反弹（无主动流确认）倾向反转"
"安静的放量爆发只在价格接受与主动流一致时延续"

下一次运行基于这份记忆规划——这就是"研究流程层"的递归自改进：改进的是研究过程，不是成功的定义。

二、Appendix B 精读：一个躲过 Agent 审查的泄漏（全文最有价值的失败案例）

AQuA 的密封沙箱不是初始设计，是对具体失败的响应。早期更宽松的循环里，Agent 可直接写特征/因子代码，由第二个 Agent 审查因果性：

失败特征：日内成交量参与率 = 开盘至当前分钟的成交量 ÷ 日内总量归一化。
- 意图是因果的，描述读起来是向后看的 → 审查 Agent 批准
- 但实现中分母是当天总成交量（开盘到收盘的累加）——分母依赖当前分钟之后的 bar，每个日内时间戳都悄悄编码了日内尾盘信息
- 多分辨率变体同样翻车：日频分支聚合当天全部 bar，却在午间时间戳被读取

症状：held-out IC 远超可比价量特征；干净重切评估窗口后不成立。人工审计追溯到全天分母。

根本教训（原文）：LLM 审查 LLM 写的代码是advisory 而非 structural——作者与审查者共享同一批失效模式，微妙的时间足迹 bug 可以同时骗过两者。审查者推理的是特征的经济意图（过去成交量之比），而非实现实际触碰的 bar 集合。

响应——算子化：Agent 不再写特征/因子代码，只组合固定的因果算子注册表。全日归一化子在规格空间里根本不可表达。保证从"审查者应该抓到泄漏"升级为"泄漏无法被写出"。

三、形式化框架

每个部分 p ∈ {I, II} 的内部递归：

R_{t+1}^{(p)} = U_p(R_t^{(p)}, H_t^{(p)}, C_t^{(p)}, E_t^{(p)})        # 状态更新
(H_{t+1}, C_{t+1}) ~ P_p(· | R_{t+1})                                  # 提案分布
  • R = 持久研究状态（记忆/信念库），H = 假设，C = 构造出的因子/训练出的模型，E = 验证后的证据
  • 上标强调隔离：Part I 不更新 R^(II)，Part II 不更新 R^(I)
  • "递归自改进"是有界意义：研究流程层；既不更新底层 LLM，也不更新评估器

为什么两系统不耦合共享：因子发现的输出直接喂给模型训练会引入新的泄漏通道——因子若因样本内信号被选中，就给模型塞了一个微妙过拟合的输入，两个搜索就共享了密封指标本要隔离的信息。

五、归纳总结

5.1 命题三层

L1 观察：递归自改进等比例放大错误与发现
L2 原则：不对称自由——Agent 自由探索，评估器在自适应面外
L3 落地：算子化 DSL + 优化/报告指标分离 + 一次性测试窗口

5.2 三个可迁移的工程判据

  1. 完整性边界必须是结构性的：任何依赖 LLM 判断（审查/自检）的防泄漏都是 advisory；把危险动作从动作空间里删掉才是边界。
  2. 搜索能读到的指标必然被过拟合：只要迭代次数够，搜索会学会选择它最终要报告的指标。报告指标必须在冻结后才计算一次。
  3. 耦合引入新泄漏：两个各自干净的搜索一旦共享数据，密封就被组合击穿（因子→模型通道）。

六、趋势判断

趋势 1：量化 Agent 的竞争焦点从"发现能力"转向"防自欺能力"。 AQuA 的核心贡献不是更高的 IC，而是把 Appendix B 的失败变成结构约束。当所有框架都能挖出高 IC 因子时，区分度在于哪些 IC 是真的。2025-2026 的 agentic mining 文献（AlphaSeek/QuantaAlpha/Chain-of-Alpha）已集体收敛到"提案先于表达式 + 验证契约统一"，下一步收敛点大概率是密封评估基础设施。

趋势 2："递归自改进"的实用定义正在降维到流程层。 AQuA 明确声明不更新模型权重、不更新评估器，只更新研究状态（记忆/信念）。这与萨顿"权重焊死"判据形成务实对照：工业界先在"研究流程自改进"这个可控层落地，权重层持续学习留给 Oak Lab 那条学术线。

八、拓展应用推荐

P0（建议本机落地，按收益×可行性排序）：

  1. 回测脚本密封化改造：把 apply_iron_rules / 回测数据加载拆成"冻结模块"（数据切分+标签+评估函数 hash 固定），策略侧只允许输出规则参数/因子表达式 JSON，不允许 import 数据处理代码。工作量：1-2 天。直接封堵生成通道。
  2. 优化/报告指标分离：铁律回测的参数选择只看预固定验证窗，最终报告窗每参数组合只评一次。工作量：半天。封堵选择通道。
  3. 外源信号提案表单：quant-evidence-governance 的回测入口加四要素表单（假设/机制/预测方向/证伪条件），证伪条件不满足直接不入队。工作量：2 小时。

P1：Research Librarian 式"信念库"——cycle-records.json 扩展为结构化信念（机制×市场语境×置信度×证据指针），每次回测更新而非只记价格周期。

P2：方向校准——铁律回测对每个新规则同时测正反两向，保留解释更干净的方向（需 n>100 样本支撑，防单边巧合）。

九、指南分析

论文质量：
- ✅ 形式化干净（递归定义、密封约束的数学表述），且不遮掩工程动机
- ✅ Appendix B 主动公开早期设计的失败案例——罕见的诚实，比正面结果更有教学价值
- ✅ 双市场（crypto + 美股）双系统，walk-forward 严格版仍 +2.0 Sharpe，稳健性论证充分
- ✅ 与 2025-2026 agentic mining 文献的定位切割清晰（相关性工作覆盖全面）

局限：
- ⚠️ Part I 具体入选因子"不予披露"——可复现性打折（商业考虑可理解，但社区无法验证 IC 0.190）
- ⚠️ 密封沙箱把表达能力换成了安全性：注册表外的特征思路（如另类数据、微观结构特征）无法表达，DSL 扩展依赖人工维护
- ⚠️ 人类 authored 的密封组件本身仍是泄漏源（人写错标签定义无人兜底）
- ⚠️ 加密 universe 的 IC 0.190 与美股 IC 0.0843 口径不同（论文自己声明不可比），横向解读需克制

对本机的最大启示：本机量化体系当前防线全部是 advisory 层（铁律、回测纪律、error-case 复盘）。AQuA 证明这些可以被一个结构层替代并升级——"让错误不可写出"优于"让错误被审查发现"。
