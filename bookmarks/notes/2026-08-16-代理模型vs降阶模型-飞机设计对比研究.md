## 一、核心内容：两种"加速器"的本质区别（完整还原）

### 1.1 一句话定义

- **代理模型（Surrogate Model）**：完全抛开物理方程，从 I/O 数据学习"输入参数 → 输出指标"的黑盒映射（Kriging/RBF/ANN/XGBoost/DeepONet/FNO）
- **降阶模型（ROM）**：保留物理结构，把高维状态空间压缩到低维子空间（POD 基 + Galerkin 投影/插值/DMD/算子推断），在子空间里解物理

**本质区别**：代理学"答案"，ROM 学"方程的降维投影"。前者自由度高无物理约束，后者保物理结构但受子空间表达力限制。

### 1.2 检索到的硬数字对比（实例锚点）

| 维度 | 代理模型 | 降阶模型 | 实例来源 |
|------|----------|----------|----------|
| 典型加速比 | 10²-10⁴× | 10²-10³× | PoliMi FNO/DeepONet 3055×-10656×；UT Austin OpInf 气弹 100-1000× |
| 精度（场级） | MLP 类 0.08-0.5%；神经算子 0.09-2.9% | POD 类精度与代理相当 | METU：POD-RBF ROM 与 RBF 代理精度"几乎同级" |
| 构建成本 | 纯数据拟合，快 | 含 POD 分解+模态选择，略慢 | METU：ROM 构建流程更长 |
| 推理速度 | DeepONet 4ms/次（3D 换热 10656×） | POD-RBF 只对低维系数插值，**推理更便宜** | METU：POD-RBF ROM 推理成本低于 RBF 代理 |
| 物理一致性 | 无（纯数据） | 有（Galerkin 投影保结构） | DLR 论文系列 |
| 非线性/激波 | 神经算子可拟合但需多尺度技巧 | POD 线性基抓不住变激波位置（需更多模态） | DLR 硕士论文：跨声速需显著更多 POD 模态 |
| 外推能力 | Kriging 外推弱；DeepONet 泛化强 | POD 插值在训练域外失效 | Zimmermann & Görtz：POD+Kriging 跨声速外推翻车 |
| 可解释性 | 弱 | 强（模态=流动结构） | ROM 模态有物理含义 |
| 典型用途 | MDO 总体参数优化、设计空间探索 | 非定常气动力、颤振、载荷谱、实时仿真

### 1.3 速度的公平比较（本笔记核算）

同一个物理问题（NACA 翼型绕流），两种路线的"总成本"：

```
代理：500 CFD 快照 × 1h = 500h 离线 + 训练 2h + 在线推理 4ms
ROM ：500 CFD 快照 × 1h = 500h 离线 + POD 分解 0.5h + 在线推理 1-10ms
```

**结论**：离线成本几乎相同（都吃快照），差异在在线——ROM 推理略便宜（低维系数插值），代理更灵活（任意参数查询）。真正的分水岭是**用途**不是速度。

### 1.4 各自的杀手级场景（实例矩阵）

| 场景 | 赢家 | 实例 |
|------|------|------|
| MDO 总体参数优化（设计向量→航程/重量） | **代理** | STS 运载火箭概念设计（RSM+Kriging，气/推/弹道/质量多学科） |
| 翼型/机翼构型优化（几何→流场） | **神经算子代理** | DeepONet 翼型优化（ScienceDirect 2024）：精度足够+CFD 级加速 |
| 颤振速度预测（非定常气动力） | **ROM** | ICAS 2024：ERA 误差 5%、DMD 误差 0.6% vs CFD 基准 |
| 跨声速全包线非定常载荷 | **ROM**（吃力） | DLR：ROM 库+插值覆盖全包线含激波/分离，替代 DLM |
| 设计空间 10⁵ 点遍历 | **代理** | MDPI Aerospace 11(8):607：ANN 气动数据集生成 |
| 实时仿真/数字孪生在线运行 | **ROM** | OpInf 气弹：训练后 flutter 预测 100×，可在线耦合 |
| 热防护/传热（不规则网格） | **DeepONet** | PoliMi 3D 楔形件：DeepONet 10656× vs FNO 4438× |

### 1.5 学术界的最新共识（2024-2026）

- **"不是竞争是互补"**（Medium digital thread 文章/多论文）：物理可信度要求高→ROM；参数泛化要求高→代理
- **神经算子（DeepONet/FNO）正在模糊边界**：算子学习既有代理的数据驱动性、又有"解算子"的物理泛化性——POD 是它的线性特例（自编码器视角）
- **混合路线兴起**：ROM 提特征 + 代理学映射（POD+Kriging/POD+RBF/POD+神经网络）——DLR、Zimmermann & Görtz 主推
 POD+插值跨声速外推翻车
- **多保真融合**：低保真 VLM 大样本 + 高保真 CFD 小样本（Co-Kriging/迁移学习）——数据性价比最优解

## 二、五要素展开

### 2.1 功能清单

| 功能 | 代理模型 | ROM |
|------|----------|-----|
| 参数→标量指标（CL/CD/航程） | ✅ 主场 | ⚠️ 需先投影再插值 |
| 参数→全流场 | 神经算子 ✅ | ✅ 主场（POD 模态重构） |
| 非定常时间演化 | ⚠️ 需时间序列版本 | ✅ 主场（DMD/Galerkin/OpInf） |
| 物理守恒约束 | ❌ 无 | ✅ Galerkin 保结构 |
| 不确定性量化 UQ | ✅ Kriging 自带方差 | ⚠️ 需扩展 |
| 优化中的自适应加点 | ✅ EGO/expected improvement | ❌ 无天然机制 |
| 可解释性 | ❌ 黑盒 | ✅ 模态有物理含义 |
| 网格无关性 | ✅（参数级）/ 神经算子 ✅ | ❌ 绑定快照网格 |

### 2.2 使用性评估

- **代理最顺手**：设计向量维度 <50、输出为标量/少维、需 UQ 或自适应加点的优化场景；工程门槛低（sklearn/GPy/PyTorch 就够）
- **ROM 最顺手**：非定常、时间历程、颤振/气弹耦合、需要物理一致性的认证场景；门槛高（需懂 POD/Galerkin/快照采集策略）
- **都不顺手**：训练域外外推、强非线性分叉（颤振边界附近）、多物理场强耦合且数据稀缺

### 2.3 指导性意见

1. **选型决策树**：输出标量→Kriging/ANN 代理；输出流场→POD-ROM 或神经算子；非定常→DMD/OpInf ROM；需 UQ→Kriging；需认证级物理一致性→intrusive ROM
2. **不要二选一**：混合路线（ROM 降维 + 代理/插值学系数映射）常常最优——POD+Kriging 是 DLR 工程化标配
3. **跨声速小心**：激波位置随参数跳跃，POD 线性基 + 插值代理都会翻车（Zimmermann & Görtz 实证）——需加密快照或上非线性降维（Isomap/自编码器）
4. **A100 在哪里**：神经算子训练（FNO/DeepONet 10⁴-10⁵ 样本）才是 8 卡的用武之地；POD 是 SVD，CPU 就够
5. **验证铁律**：任何代理/ROM 上线前，保留 20% 快照做盲测 + 报告训练域内/外分开的误差（外推误差才是翻车点）

### 2.4 演示与案例可寻

- **PoliMi 对比表（最硬的横向数字）**：FNN vs DeepONet vs FNO 同题竞技——2D/3D 换热：DeepONet 精度 0.09-0.098% 且 3055×-10656×，FNO 参数多 2 个量级、精度 2.877%/0.651%——DeepONet 是精度-成本最优
- **ICAS 2024 颤振**：DMD 误差 0.6% vs ERA 5.0%，两者都用极少量 CFD 运行
- **STS 火箭 MDO**：RSM+Kriging 组合代理横跨气动/推进/弹道/质量五学科
- **本机 aero-surrogate-pipeline**：MLP 代理两级闭环，+689% vs 随机盲选、VLM 调用 4000× 削减——代理路线的最小完整实例

### 2.5 使用方法借鉴（选型速查）

```
问题类型判定：
├─ 标量输出优化 → Kriging（带 UQ）或 ANN；加点用 EGO
├─ 流场预测     → POD-ROM（小数据）或 DeepONet（大数据）
├─ 非定常/颤振  → DMD（频域特征）/ OpInf（无需 FOM 源码）
├─ 全包线插值   → ROM 库 + 参数插值（DLR 模式）
└─ 混合最优     → POD 降维 + 代理学系数（工程性价比之王）
```

A100 工作量分配：CFD 快照生成（CPU 集群）→ POD（单卡甚至 CPU）→ 神经算子训练（8 卡）→ 在线推理（单卡/批量）

## 三、查询拓展

1. **POD 与自编码器的数学等价**：POD = 线性自编码器最优解（Baldi & Hornik 1989）——神经算子可视为"可学习的非线性 POD"——两条路线在深度学习里统一
2. **OpInf 的独特价值**：Operator Inference 不需要原始 CFD 源码（非侵入式）也能学到保结构低维模型——黑盒商业求解器（ Fluent/CFX）用户的唯一 ROM 入口
3. **DMD 与颤振物理**：DMD 特征值实部即流动稳定性增长率——气弹分析直接读出颤振速度，这是代理模型给不了的物理洞察
4. **Kriging 的方差免费赠品**：同一网络同时输出预测+不确定度，代理优化（EGO）的核心机制——ROM 无对应物
5. **认证视角**：EASA/FAA 认证语境下"intrusive ROM"更受信（方程可追溯），代理模型需要附加误差界证明——与 Lean 笔记的形式化误差界闭环

**信息架构**：定义区分（学答案 vs 学方程投影）→ 硬数字对比表 → 速度公平核算（离线同贵、在线 ROM 略便宜、分水岭在用途）→ 场景赢家矩阵 → 最新共识（互补/神经算子模糊边界/混合路线）→ 五要素 → 选型决策树。

**本笔记增量判断**：
- 速度之争是伪命题——两者离线都吃 CFD 快照，在线都是毫秒级；**真正的分水岭是输出类型（标量 vs 场）和时间性（定常 vs 非定常）**
- 神经算子是"统一论"候选者——但 FNO 参数量过大（25M vs DeepONet 4K）的工程缺点检索中反复出现
- POD+插值的跨声速外推翻车是两条路线共同的软肋（数据分布问题，不是模型问题）

## 五、趋势判断

1. **神经算子 2-3 年内吃掉传统代理的场级任务**：DeepONet/FNO 在精度-速度-泛化三角上全面占优（PoliMi 实测），传统 Kriging 会退守标量+UQ 利基
2. **ROM 在认证场景守住基本盘**：物理可追溯性是代理给不了的，EASA/FAA 语境下 Galerkin ROM 仍是气弹认证主力
3. **混合路线是工程主流**：POD 降维+神经代理学系数，兼得物理结构与数据灵活性——DLR/Airbus 已经这么用
4. **GPU 农场价值重估**：CFD 快照生成（CPU）才是总成本大头，A100 应该优先投给神经算子训练和在线推理服务化
5. **降维+代理的组合会标准化**：类似 modred/EZyRB 这类开源管线成熟后，"选型"问题会退化为"配置"问题

## 六、归纳总结

**一句话**：代理模型学"参数→答案"的黑盒映射（快、灵活、无物理保证），ROM 学"方程的降维投影"（物理一致、可解释、推理略便宜）——速度差异是伪命题，选型分水岭在输出类型与时间性；神经算子正在模糊两者边界，混合路线（POD+神经代理）是工程性价比之王。

**结构记忆**：
- 两个本质：学答案 vs 学投影
- 三个分水岭：标量 vs 场 / 定常 vs 邞定常 / 优化探索 vs 认证一致性
- 四个实例锚点：DeepONet 10656× / DMD 颤振 0.6% / POD+Kriging 跨声速翻车 / STS 火箭 MDO
- 一个趋势：神经算子统一论 + 认证场景 ROM 守擂
