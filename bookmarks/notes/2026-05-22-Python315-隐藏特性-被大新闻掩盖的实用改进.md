## 摘要

Python 3.15.0b1 已进入 feature freeze，lazy imports 和 tachyon profiler 等大特性备受关注。但 Jamie Chang 的文章揭示了多个同样重要却未被广泛报道的改进：asyncio TaskGroup 优雅取消、ContextDecorator 对 async/generator 的完整支持、以及多个实用的小改进。这些特性将显著改善 Python 在 Agent 系统、异步编程和日常开发中的体验。

## 核心内容

### 1. Asyncio TaskGroup.cancel()

Python 3.15 之前，优雅地取消 TaskGroup 需要自定义异常 + contextlib.suppress 的组合：

```python
class Interrupt(Exception): ...
with suppress(Interrupt):
    async with asyncio.TaskGroup() as tg:
        tg.create_task(run())
        if await wait_for_signal():
            raise Interrupt()  # 不优雅
```

3.15 新增 `tg.cancel()` 直接取消，无需异常：

```python
async with asyncio.TaskGroup() as tg:
    tg.create_task(run())
    if await wait_for_signal():
        tg.cancel()  # 干净利落
```

### 2. ContextDecorator 修复 async/generator 问题

3.15 之前，用 context manager 做装饰器时，async 函数和生成器会立即返回而不执行完整生命周期。3.15 修复了这个问题，现在 `@duration` 装饰器可以正确包装 async/generator 函数：

```python
@duration('async workload')
async def async_workload():  # 3.15 前不工作，现在工作
    ...

@duration('generator workload')
def workload():  # 3.15 前不工作，现在工作
    while True:
        yield
```

这意味着 context manager 现在是创建装饰器的最佳方式——比手写装饰器更安全、更清晰。

## 关键概念

**Structured Concurrency**：结构化并发范式，TaskGroup 是其 Python 实现——所有子任务的生命周期被限制在 async with 块内

**ContextDecorator**：Python 标准库提供的混入类，使 context manager 可以同时用作装饰器和 with 语句

**Lazy Imports (PEP 690)**：3.15 的头条特性，延迟模块加载直到首次使用，大幅提升启动速度

**Tachyon Profiler**：3.15 的另一个头条特性，低开销的持续性能分析器
