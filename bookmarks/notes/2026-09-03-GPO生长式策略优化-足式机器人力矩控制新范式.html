GPO 生长式策略优化：四足/六足力矩控制的新范式

内容整理

核心命题：优化机制层面的创新，而非又一层 pipeline 补丁

GPO（Growing Policy Optimization，arXiv:2601.20668）针对的是足式机器人 RL 的一个被长期忽视的事实：绝大多数现有方法改训练管线（奖励塑形/课程学习/专家示教/动作裁剪），但从不改优化机制本身。PPO 隐含假设动作空间在全程固定，导致早期探索方差过大、优化地形崎岖——策略还没学会可靠的小幅控制就被淹没在全幅动作空间里。

GPO 的解法极简：引入时变动作变换，把策略输出的固定范围映射到"随训练进程逐步扩张的可执行动作范围"。早期限制有效动作空间（梯度估计更稳、优化更易导航），后期逐步解锁全部控制权限。数学上证明该变换保持 PPO 更新规则的结构（目标函数和 clipping 机制经变量替换后不变），梯度失真有界且随训练消失——早期收敛更快，渐近性能不低于固定动作空间 PPO。

机制细节

1. 增长函数 βt 直接乘在命令上（不是乘在动作上）

这是对 DUCK-Pi_5 站桩问题最有迁移价值的一条。GPO 的奖励追踪项写作：

r_tracking,x = φ(vx − vx_cmd · βt)      权重 10dt
r_tracking,y = φ(vy − vy_cmd · βt)      权重 5dt
r_tracking,yaw = φ(ω_yaw − ω_cmd · βt)   权重 5dt
r_tracking,height = φ(hb − h_cmd · βt)   权重 7dt

命令 v_cmd 先乘以 βt∈(0,1] 再进奖励——训练初期命令被压小（任务天然简单），随 βt→1 逐步恢复全额命令。这与"早期收紧 torque 限制、后期放宽"的工程直觉同构，但被整合进了学习公式本体。

2. Gompertz 增长曲线胜出（四种生长函数对比）

生长函数 βt 形式 参数 表现
无增长 (PPO) 1 – 收敛显著最慢，难任务上尤其差
线性 clip(kt, 0, 1) k=1/3000 最差：动态不稳定或过早饱和
Sigmoid (1+exp(−k(t−t0)))⁻¹ k=−2.3e−3, t0=3000 比线性稳但收敛慢、终值低
Gompertz e^(−e^(−k(t−t0))) k=3e−5, t0=24000 双任务一致最优

关键洞察是非对称增长：Gompertz 初期斜率小（强限制动作空间→先学小幅可靠控制），后期加速扩张（恢复控制权限→跳出局部最优）。Sigmoid 恰好相反（先快后慢），所以逊于 Gompertz——增长曲线的"形状"本身就是超参。

3. 力矩级控制 + 无步态先验，行为完全涌现

GPO 验证场景是比 DUCK-Pi_5 的位置控制更难的力矩控制（直接暴露接触丰富动力学给策略，无底层舵机稳定环兜底）。观测向量 o_t = [w, g, q, q̇, v_cmd, τ, ζt]，含力矩反馈和疲劳状态 ζt（SATA 式：ζt = (ζt−1 + |τ|·dt)·0.95）。不施加任何显式步态先验（相位同步/预定义落足表/腿使用约束都没有）——步态行为完全从"任务追踪 + 共享正则项"中涌现。正则项包括：|roll| 惩罚、vz² 惩罚、关节限位惩罚、疲劳×力矩惩罚（权重仅 −0.05dt）、关节加速度 q̈² 惩罚（权重 −1e−6dt）。

4. 六足的"退化支撑分配"诊断

六足任务揭示一个新失败模式：无步态结构激励时，策略可能收敛到退化支撑分配（degenerate support allocation）——推进和支撑过度集中在部分腿，其余腿闲置。评估因此引入支撑分布合理性指标。对多腿平台的奖励设计有直接参考意义。

同期工作：Agent 驱动的自主 RL 研究实录（arXiv:2603.27416）

第二篇是方法论互补的案例研究：Claude（经 OpenCode 环境）在 Isaac Lab 上对 DHAV1 12-DoF 四足执行了 14 波/70+ 实验的迭代策略改进，人类只给高层指令。从 Wave 1 平均奖励 ~7 进化到 Wave 12 exp063：速度误差 0.263、97% episode 存活率、2000 迭代完成，跨 3 种 GPU 独立复现 5 次。

对站桩问题直接可迁移的发现（Agent 从参考实现移植的 4 个奖励项）：对角步态奖励、air-time 方差正则、关节镜像对称、feet-contact-without-command shaping（有脚接触但无命令时塑形——正是"零命令抑制站桩"的奖励版本！）。收敛配置：降低步态强制强度 + 加强稳定性惩罚 + 提高 airtime 方差正则 → 速度追踪反而更好。

其他工程发现：地形含 boxes/stairs 类原件会触发 PhysX 死锁（隔离地形族+换平滑地形混合后才有可靠长跑）；Isaac Sim 启动期 eager import 引导问题需修；挂死实验直接杀掉换班（不等待自愈）。

查询拓展

  • GPO 的 βt 乘在命令上的做法，与 microduck 官方 rel_forward_envs 的 clamp(|vx|≥0.3) 是同一问题的两种解：前者"命令从零长到全额"，后者"命令永不为零"。两者能否叠加（βt 增长 + 下限 clamp）？值得在 W2 重训中做对照实验
  • Gompertz 参数 (k=3e−5, t0=24000) 对应多少训练步？按 dt=0.02s 换算 t0≈24000 步时 βt≈0.37，需结合 microduck 9k iter 的训练预算重新标定
  • 疲劳建模 ζt 对 3025 无刷舵机（额定 1.5A/堵转 4.4A）的热管理有直接类比价值——连续大力矩输出降额
  • Agent 驱动 RL 研究与 Hermes 的 auto-dream/evolver 架构同构：都是"观察→假设→干预→执行→分诊"五段循环，其 wave-based 实验档案管理方式值得借鉴
  • 六足退化支撑分配 → 双足/腿混合平台的支撑分布评估指标如何设计

归纳总结

  1. GPO 把"动作空间课程"从工程直觉升格为学习公式：时变变换保持 PPO 结构不变 + 梯度失真有界消失，是"改优化机制"而非"改管线"的第一批系统工作。Gompertz 非对称增长（先慢后快）优于线性与 Sigmoid。
  2. 命令缩放是站桩问题的另一条正道：βt 直接乘 v_cmd 进奖励追踪项，与 feet_air_time 加无指令基础项、cmd clamp 三者构成三选一（或组合）的解空间。
  3. 力矩级控制 + 零步态先验 + 行为涌现在四足/六足上验证可行，正则项设计（疲劳/限位/加速度）是涌现质量的隐性决定者。
  4. Agent 自主 RL 研究已能承担大部分迭代负担：14 波 70+ 实验、跨 GPU 复现、工程分诊（死锁隔离/挂死处置/参考代码移植）全部由 Agent 完成，人类仅掌舵方向。其移植的 airtime 方差正则 + contact-without-command shaping 正中 DUCK-Pi_5 站桩要害。

趋势判断

  • "改优化器"正在成为足式 RL 的下一个掘金点：奖励塑形/课程/示教的红利已薄，GPO 证明了动作空间维度的时间调度可以同时改善早期收敛和渐近性能，预计 2026 下半年会涌现更多 time-varying formulation（观测空间/命令空间的生长课程）。
  • Agent-driven research 从 ML 领域外溢到机器人 RL：AutoResearch→AI Scientist→机器人 RL 的路径已打通，"failure-prone 工程环境 + 部分人类掌舵"是当前甜点位。与 Hermes 的 evolver/experience-bank 架构哲学一致。
  • Air-time 方差正则取代固定步态强制正在成为主流：强制步态先验换取稳定性但牺牲速度追踪，方差正则让步态自由涌现但抑制单腿垄断——与 GPO 的零先验哲学同流。

指南分析

对 DUCK-Pi_5 W2 重训的可执行建议（按改动成本排序）：

  1. 零成本：eval 指标中加"支撑分布合理性"（各腿 contact time 方差）——检测鸭子的退化站桩是否本质是支撑分配退化
