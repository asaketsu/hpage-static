归纳总结

一篇标准的 AI 通识培训长文（2w+字），走"大模型通识 → 提示词 → Agent → 上手实操"四段式课程结构。深度定位是入门科普，但作为经过市场验证（付费内训5轮迭代）的企业培训教材样本，其框架化表达方式有参考价值。三个核心判断：

核心命题 表述 点评
AI软件本质 AI软件 = 大模型（心）+ 产品界面（皮） 手机/芯片类比的通俗版，帮助小白看穿"套壳软件"
Agent本质 Agent = 执行架构 + AI大脑；"工具决定能做什么，大脑决定做得多好" 一句话统一了 Claude Code/Codex/OpenClaw/WorkBuddy 的产品谱系
提示词趋势 提示词工程没死，在民主化+分层进化；范式从"一次写完美"转向"对话式共创" 与推理模型（DeepSeek R1）出现后"提示词已死"论断的对冲观点

最有个人特色的方法论是「升维提问，逐级降维」：不会写提示词时，先问 AI 一个更高维度的问题（"我做XX没头绪，帮我整理做这件事的框架"），拿到框架后结合实际逐级细化，最后沉淀为自己的通用提示词模板。

内容整理：四部分课程结构

第一部分：大模型通识（11节）

  • AIGC 为何火：区别于人脸识别/推荐算法/AlphaGo，AIGC"会说人话"，AI 第一次进入普通人生活；五种生成形态（文生文/文生图/文生视频/图生图/图生视频），新手从文生文起步（门槛最低/场景最多/免费工具最多）
  • 大模型的"大"三维度：数据量大（知识广度）、计算资源大（教育成本，数千GPU数月）、参数量大（脑容量）——用"幼儿园到博士"类比
  • 工作原理：图书管理员比喻——不"思考"而是统计文字组合规律（文字接龙/按概率选答案）；四个特点：跨书联想、语气模仿、错误陷阱（谣言高频=被当事实）、不懂自己在说什么（人类是最终质检员）
  • 优势 vs 局限：优势=信息处理/知识覆盖/内容生成；局限=幻觉、时效性、偏见放大、多步推理漏洞（洗车店50米开车还是走路案例）、深层含义理解、上下文长度
  • 三种优化手段对比：提示词（所有人/低门槛）、微调（技术团队/高门槛，"为什么微调不全调"=先通才再专才的教育类比）、RAG（活字典，解决知识过期+私有数据）
  • 选型五指标：是否需要梯子、价格、速度、上下文长度（作者认为最重要）、应用领域；"上下文容量≠长上下文处理能力"的区分值得记住；建议定期让AI总结已达成的结论防丢失
  • 测试方法论：积累自己的测试用例，新模型用自己的高频场景实测，"用渣男心态持多个模型，为每个场景匹配最优工具"
  • 国外模型三种用法：官网（$20/月起，Claude封号严）、国内套壳（按月买勿按年）、国外套壳（选大平台）

第二部分：提示词工程（8节）

  • 基本公式：高质量提示词 = 清晰的指令 + 必要的上下文
  • 六技巧：Task明确任务 / Context补充背景 / Examples给例子（作者最推荐） / Persona设定角色 / Format规定格式 / Tone调整语气——一切策略为最终效果服务，不必全用
  • 方法论「升维提问，逐级降维」四步：①升维提问求框架 → ②降维细化构建提示词 → ③持续优化 → ④人肉总结通用框架（作者强调第④步自己抽象而非让AI总结，理解更深）
  • 模板一句话：我要做一件XX事情，但是我没有头绪，你能帮我整理下做这个事情的框架么？
  • 用AI写提示词两招：直接口喷（"我要做XXX，帮我写一个提示词"）+ 让AI模仿（粘贴好提示词照葫芦画瓢）
  • 学习路径：先模仿（WayToAGI提示词库/小七姐提示词图书馆/向阳乔木）再实践

第三部分：什么是Agent（6节）

  • 定义锚点：与普通AI对话的区别在于"最后一步"——普通AI帮你整理好资料你自己填Excel，Agent在授权范围内完成最后操作
  • 为什么工具这么多：产品形态被验证后厂商迅速跟进（飞书/钉钉/企微类比）；2025 Claude Code/Codex CLI 起 → 桌面/网页 → 2026 OpenClaw 走红带动聊天软件远程指挥智能体（文中点名 OpenClaw、QClaw、WorkBuddy、Codex、Claude Code、hermes）
  • 认识智能体三维框架：谁开发的 / 什么产品形态（对话式/桌面GUI/CLI/即时通讯入口，分类不互斥）/ 主要完成什么任务（通用办公/编程/行业垂直）
  • 底层逻辑：所有智能体=同一套结构"执行架构+AI大脑"，差异只在执行架构能力边界+所接模型
  • 选型不看聪明看交付：能否真完成任务/结果准确度/时间与额度成本/平台支持/权限与数据安全
  • 普通人学习路线四阶段：表达需求 → GUI智能体完成真实任务 → 理解执行过程（规划/调工具/读文件/处理错误）→ 按需深入（Skills/MCP/远程定时）

第四部分：WorkBuddy实操

  • 选 WorkBuddy 因门槛最低+免费额度，会它可无缝迁移到 Codex 等
  • 上手三要点：选工作空间（产出物固定目录）/ 权限用"允许完全访问"（默认权限每步都要点批准）/ 模型选择决定效果（价格倍率≈能力梯度的粗暴判断；作者日常 DeepSeek V4.1 flash，设计网页用 Kimi K3）
  • 示例：宠物猫高端烘焙粮市场调研 → Excel 表格落地

结语三观点

AI是工具不是魔法；提示词本质是把需求讲清楚；智能体当下并不智能但已能解决实际问题。金句："AI是学不会的，是用会的。"

  1. 智能体产品"百花齐放→形态收敛"：作者观察到"名字不同但解决相同问题"（类飞书/钉钉/企微格局），判断未来按场景分化（办公/编程/垂直行业），而非一家独大——与我们看到的 Agent 入口战争（CLI→GUI→聊天软件）一致

  3. 提示词民主化不可逆：模型越强，"把话讲清楚"的门槛越低，专业提示词技巧向两个方向迁移：①沉淀为系统提示词/skill（工程侧）②退化为自然对话（用户侧）。中间态的"提示词教程"市场会萎缩，作者自己也把方法论从模板转向"对话式拆解"
  4. 企业AI内训是一个真实市场：8000元/小时的定价能成立，说明传统企业付费意愿集中在"认知扫盲+场景落地"层；这类内容的商品化（长文免费公开做获客）本身是 AI 自媒体的获客范式
  5. 普通人学习曲线压扁：从"学提示词技巧"到"会用一个GUI智能体"的路径已被压缩到2小时，竞争焦点从"会用AI"转向"有测试用例/有场景判断力"
