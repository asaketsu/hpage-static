## 一、内容详细整理（底稿骨架全录 + 提示词照录）

### 1.1 核心命题：为什么 AI 设计总是平庸

> **模型没有任何不同，差别在于你能不能把它的极限榨出来。绝大多数人看到的，不过是 AI 创造力的冰山一角——顶多 1%。**

**机制解释**（底稿最硬的一段）：

- LLM 本质是"下一个 Token 预测器"：每步推算概率最优解
- RLHF 层层对齐后 → 模型被调教成迎合大众、四平八稳的"好好先生"
- 设计抉择时**总下意识选最不得罪人的平庸解** → 产出 = "多方扯皮妥协后的平庸委员会产物"
- 顶尖设计始于感知、终于共鸣，敢于打破陈规——**与大模型追求"最可预测、最保险"的本性背道而驰**

### 1.2 三阶段工作流总纲（借鉴设计界双钻模型 Double Diamond）

| 阶段 | 目标 | 技法 |
|------|------|------|
| **探索 Discover** | 跳出平庸预设，铺开多种方向 | ① 种子字符串随机熵 ② 大胆提示词+三步发散法 |
| **确立 Define** | 逼 AI 挣脱路径依赖，铸造设计灵魂 | ③ 设计挑刺官双智能体 ④ 图像生成 ⑤ 视频模型动效 |
| **交付 Deliver** | 大刀阔斧剔除杂音，雕琢高级质感 | ⑥ 克制做减法 |

### 1.3 技法 ①：注入随机"种子字符串"（String Seed of Thought）

**问题**：4 个独立 Claude 实例同一提示词 → 同一副面孔（紫青渐变+左文右图+三段式）；口头催"放开点、完全随机"不管用——**大模型不具备真正随机能力，只是在挑"听起来像随机"的高概率词元**。

**解法**（Sakana AI 的 String Seed of Thought）：引入**模型外部的随机熵**——先让 AI 用 Shell 生成一串真随机字符串，作为设计灵感锚点。

**进阶提示词（照录）**：

> 1. 先用 Shell 脚本生成一串冗长且完全随机的字母数字字符串。
> 2. 将这串字符作为唯一灵感源，推导出你的核心视觉方向（调色板、版式编排、字体规范）。深入挖掘数字组合、字符结构。
> 3. 调动全部审美判断，转化为高水准视觉落地页。
> 注意：不要在最终设计中展示这串字符，它只是灵感引信。

**效果**：视觉风貌瞬间拉开，每版独一无二。

### 1.4 技法 ②：提示词足够大胆 + 三步发散法

**大胆提示词范例**（照录三个方向）：
- 像素艺术风格："每个内容区块像一帧定格的游戏画面，但保有完整落地页交互"
- 2.5D 等轴测虚拟城市："核心功能化作城市街区或标志性建筑"
- 激进非对称："冲突感字体与撞色+让人略带不安的大面积负空间，打破所有排版常规"

**三步发散法**（照录）：

| 步 | 提示词 | 要点 |
|----|--------|------|
| 1 | "尽可能多地列出设计概念，每个只用一句高维度简述。**重在广度，严禁展开细节**" | 抽象铺开海量脑洞 |
| 2 | 挑中心动方向，代入直觉反馈（"机械触感实体按键/避开卡通廉价感/克制而硬核/灰渐变太死板要材质肌理"） | 人的审美焊进方向 |
| 3 | "整理出精炼利落的提示词，让开发智能体直接构建第一版 POC" | **AI 反向生成执行提示词** |

**关键论断**：

> 把 AI 生成的平庸点子不经思考直接扔回给 AI，你永远只能得到大众流水线产品。**当你把个人的独特审美牢牢焊进设计方向时，产出的作品就烙上了非你莫属的印记。**

> 如果你心里突然闪过"这怎么可能行得通"，恭喜你，你找对方向了。**把没能成功的提示词存好，等更强的新模型面世时再跑一次——那是检验大模型能力进阶的最佳试金石。**

### 1.5 技法 ③：设计挑刺官（Design Critic）双智能体闭环

**问题**：智能体无法客观看待自己——会辩护自己的决策，难跳出微观视野。

**解法**：双智能体协同——干活的代码智能体 + 独立"设计挑刺官"：
- 挑刺官**不看代码、不关心实现心血**，只看渲染截图，用最挑剔眼光评判
- **经济账**：挑刺官用最贵模型（Fable 5）只把关出谋；跑腿交给低成本模型——**整个迭代 Fable 消耗 Token 不足 10%，直接让 Fable 重写成本至少翻倍**

**挑刺官提示词（照录核心）**：

> - 截取当前界面完整渲染图
> - **在完全独立、全新的上下文（Fresh Context）中唤醒挑刺官，仅输入截图，严禁输入代码细节、实现逻辑或先前修改历史**
> - 挑刺官提炼视觉风格，设想顶级设计工作室如何驾驭，尖锐指出与大师级水准的最大差距
> - 10 分制打分。**及格线 9 分，但严禁在挑刺官提示词中泄露及格线**
> - 系统提示词准则：整体构图高维审视+像素级苛求 / 警惕"AI 味"套路从严扣分 / 意见一针见血杜绝空话 / **态度大胆鲜明，严禁推崇平庸安全牌**

**四条搭建细节（照录）**：
1. **评估基准越客观效果越惊艳**
2. **善用情绪板（Moodboard）**：投喂心仪截图但严警告"只是审美基准，绝不能像素级抄袭"
3. **牢牢设死止损条件**：防代码智能体陷入反复取悦挑刺官的死循环空耗 Token——先跑 1-2 轮看收敛趋势再放开上限
4. **各司其职**：挑刺官选大模型（参数量决定审美底蕴），干活的选性价比主力但不能太弱（否则理解不了挑刺意图）

### 1.6 技法 ④：引入图像生成，褪去纯代码"穷酸气"

- 代码智能体**极度偏爱原生 CSS**，从不主动画图——硬拼渐变/几何形状/低质图案 = **AI 网页最具辨识度的廉价标记**
- 解法：给 API 密钥调 OpenAI/Gemini 生图 + 着色器（Shaders）或轻量 3D 搭配
- 底稿强调：密钥仅在本地调用，**严禁写入代码或产品交付物**

### 1.7 技法 ⑤：视频模型充当"动效魔术师"（两大杀手级玩法）

**玩法一：物理质感微动效**
- 核心：生成纯色背景循环短视频 → 色度键控/视频抠图（Video Matting）抽离背景 → 得到可任意悬浮嵌入 UI 的通透动画
- 高级技巧：**以当前页面背景色为底渲染玻璃视频（折射色直接烘焙进去），再抠图**——折射效果以假乱真
- 效果："纯 CSS 或 Canvas 无论如何调不出的高级质感——焦散光斑、折射变形、物理动力学解算"

**玩法二：滚动交互转场（最被低估）**
- 前沿视频模型的**关键帧插值（Keyframe Interpolation）**：给两张不同状态渲染图 → 无中生有算出丝滑过渡帧
- **转场与滚动/滑动手势逐帧绑定（Scrubbing）**——"手眼合一"，贴合滚轮阻尼
- 流程：生图首帧 → 视频渲染状态 1→2 → 末帧为母版推演下一段 → 与滚动进度逐帧绑定
- 底稿实例：行李箱"悬浮→坠落弹开→收纳物归位"三状态，一句提示词完成
- 推荐平台：fal.ai 聚合中转（智能体自主挑模型），模型如 Seedance 2.5

### 1.8 技法 ⑥：克制做减法（交付阶段核心）

**问题**：**AI 天生喜欢贪婪地做加法，却极少主动做减法**——"画蛇添足"是辨别 AI 设计最管用的标志（过度解释文字/莫名装饰色块/无交互意义的悬浮元素）。

**案例照录**：卡路里 App 收尾阶段 80% 精力花在"删东西"：
- 删：廉价粉色光晕、文本高亮装饰、冗余标签无意义留白、自以为是的自定义组件
- 保留：以纯图片为核心的网格布局、iOS 原生组件规范

**关键论断**：

> **当下的所有 AI 大模型，单凭自己是绝无可能主动做出这种取舍的。** 切记，AI 骨子里厌恶冒险，而"大动干戈删代码、做减法"恰恰是高风险的事。**这把手术刀必须由你亲自递到它手上。**
>
> 屏幕上留下的越少，传递出的力量反而越充沛。

## 三、归纳总结

1. **平庸的根源是机制不是模型**：Token 预测+RLHF 对齐 → "好好先生"——**换更贵的模型不解决平庸，打碎惯性才解决**（与"堆参数"思维形成对照）
2. **随机熵必须从模型外部注入**：模型无真随机，只会挑"听起来随机"的高概率词元——Shell 生成种子字符串是**切断训练预设路径依赖**的最小方案
3. **双智能体 = 执行/评判分离**：挑刺官在 Fresh Context 只看截图不看代码——**避免自我辩护+跳出微观视野**；经济账是"贵模型当大脑、便宜模型当手脚"（Fable Token 占比 <10%）
4. **三步发散法的关键是人**：AI 铺广度、人给直觉、AI 反向生成执行提示词——**"把个人审美焊进方向"是与流水线产品的分水岭**
5. **图像/视频生成是"去 AI 味"的武器**：纯 CSS 渐变拼贴=AI 廉价标记；生图+着色器+视频抠像是质感分水岭
6. **滚动 Scrubbing 是视频模型最被低估的用法**：关键帧插值→过渡帧与滚动进度逐帧绑定——交互设计的新范式
7. **减法只能人来递刀**：AI 厌恶风险，删代码是高风险动作——**收尾阶段 80% 精力在删**，"留下的越少，力量越充沛"
8. **失败提示词是试金石**：存好翻车的提示词，新模型发布时重跑——**用固定提示词测量模型能力进阶**

## 四、趋势判断

1. **"设计智能体编排"会成为新兴岗位技能**：单模型直出 → 多智能体分工（发散者/挑刺官/动效师/裁剪师）——设计工作流正在 Agent 化
2. **随机熵注入会成为标配技巧**：SSoT 类方法将从"高手秘技"进入通用提示词工具链（类似 temperature 的外部等价物）
3. **视频模型进入 UI 交互主战场**：从"生成广告片"到"物理转场+Scrubbing 绑定"——视频模型与前端工程的融合是 2026-2027 的明确方向
4. **Fresh Context 评估会成为质量门禁范式**：独立上下文+截图输入+评分门槛——与我们的执行/评判分离原则完全同构
5. **"AI 味"检测会催生反向产业**：挑刺官的"警惕 AI 套路从严扣分"预演了未来的 AI 设计质检标准
