零、结论先行

BeyondMimic 的核心贡献是把"模仿动作"和"解决任务"拆成两个解耦阶段：第一阶段用统一 RL 配方批量学技能（不管任务），第二阶段蒸馏进潜在状态-动作扩散模型（不管任务），任务逻辑全部推迟到测试时用可微代价函数引入——零样本解锁航点导航/遥操作/动作补全/避障，Unitree G1 真机全验证。

对我们最重要的三个点：
1. 范式级启发："训练任务无关 + 测试时任务注入" 与我们熟悉的 verifier 思想同构（No Free Checker 笔记的下一跳：verifier 可以在测试时才写）
2. microduck 直接可抄的五个工程细节：锚点中心跟踪、无历史观测、自适应采样、适度域随机化（过度随机化让动作保守僵硬——这与我们的经验相悖需重验证）、Rot6D 表示
3. 延迟敏感度红线：5ms 通信延迟即失败——对 asa 演示的 50Hz 控制环路是直接警示

一、问题与四条既有路线的底层矛盾（忠实还原）

路线 优势 逃不开的矛盾
基于模型的分层控制 物理可解释 牺牲自然度（膝盖持续弯曲/质心高度固定）；多接触特技规划难写；sim-real 鸿沟大
任务定制 RL（DeepMimic 流派） 特技自然 每个新技能单独调参；本质是轨迹回放——输入必须是完整参考序列，零散指令无法响应，未见任务束手无策
VAE 多任务运动先验 支持技能组合 依赖目标条件标注；隐式目标（避障）输出抖动/物理不合理
分层规划+跟踪器解耦 模块化 规划-控制器失配：上层轨迹不满足动力学，下层执行崩坏，分开训练难对齐

BeyondMimic 的回答：跟踪 RL（解决质量与敏捷）+ 状态-动作扩散（解决组合与泛化）在同一模型内规划+控制，规避失配。

二、第一阶段：可扩展 RL 运动跟踪（五项设计精读）

不是 DeepMimic 复刻——是一套 MDP 配方同一组超参训所有动作，无需每特技调参。

设计 内容 为什么重要
锚点中心相对跟踪 不强制全局位姿对齐，以躯干为锚点只约束各连杆相对姿态，允许全局合理漂移 保留动作风格同时提升对扰动/sim-real 差异的鲁棒性——与 microduck 零位标定思想同源：绝对对齐是脆弱的
极简统一奖励 跟踪主项 + 关节限位/动作平滑/自碰撞三项轻正则 无手工启发式堆叠 → 降低调参负担（我们 t2048 五版本收敛的经验：奖励越简越稳）
无历史观测 不堆叠长时间历史 减少过拟合仿真特有时序模式，提升真机迁移——与"堆历史帧提升表现"的直觉相反，消融证实
自适应采样 失败片段采样概率自动提高 长参考动作内部难度不均（侧手翻的腾空 vs 助跑），解决长序列难收敛
适度域随机化 仅地面摩擦/关节零位/躯干惯量有限随机 + 精确电机 armature 建模 "过度域随机化反而让动作保守僵硬"——对我们地形课程扩展的警示：随机化不是越多越好

数据与结果：2.5 小时动捕数据仿真训练，21 个代表性片段零样本部署 G1（单腿站立/腾空侧手翻/旋踢/连续特技/舞蹈/倒地起立）。官方口径 30 个 clip（alphaXiv 摘要），微信文 21 个——以 arXiv 30 为准。

三、第二阶段：潜在状态-动作扩散模型（核心机制）

为什么需要：RL 教师策略的本质局限 = 需要完整参考运动输入。摇杆速度/航点/零散关键帧都不是完整轨迹——无法直接用。

数据不是动捕而是教师轨迹：把第一阶段所有 RL 教师跑出的状态-动作轨迹作为数据集（DAgger 蒸馏）。

两步训练：
1. 条件 VAE 压缩状态-动作序列进平滑潜空间
2. 潜轨迹上训 Transformer 去噪器 → 潜在状态-动作扩散模型

关键设计——联合建模状态+动作（区别于多数动作扩散只输出关节动作）：模型隐式学习动作带来的状态演化，自带预测能力，天然适配预测控制闭环。不是先生成完整离线轨迹再交跟踪器——去噪输出的当前步动作直接下发硬件，滚动时域闭环。

分类器引导（Classifier Guidance）= 任务注入机制：
- 训练全程看不到任何任务（导航/避障/遥操作全无）
- 部署时为新任务手写简单可微代价函数，在扩散去噪迭代中把代价梯度加进潜变量更新
- 航点导航→位置代价；遥操作→速度代价；避障→SDF 符号距离场排斥代价；运动补全→关键帧硬约束
- 代价直接相加 = 复合任务（一边去航点一边避障）

四、三类零样本能力 + 实验数字（核实）

能力 表现 核实
命令条件运动 摇杆/航点下自主在行走/慢跑/奔跑间切换（切换样本训练中稀少=涌现行为）；真机 50m+ 连续奔跑；推撞后恢复 ✅ arXiv 确认
运动补全 稀疏关键帧间生成平滑过渡（行走中插侧手翻关键姿态），完成后自动切回；速度/关键帧模式无缝切换 ✅
代价组合避障 训练从未见过障碍物样本，SDF 代价叠加航点代价即可绕行 ✅
拟人度用户调研 77 人二选一：70.8% 认为 BeyondMimic 更拟人；跑步场景 84.7% ⚠️ 微信转述数字，arXiv 有用户研究章节
高动态特技 室外泥土/落叶/不平地面 180° 侧手翻、连续旋踢、360° 翻转踢；骨盆角速度 15.7 rad/s ≈ 运动员量级；多次连续 C 罗跳（基线多只能单次） ✅ arXiv 确认高动态动作清单
定量 速度跟踪误差：行走 12.14% / 奔跑 13.65% ⚠️ 转述数字

消融四结论（对我们最有工程价值）：
1. Rot6D 连续旋转表示显著优于四元数/轴角（跟踪误差）
2. 增大观测历史反而损害 sim-to-real（与直觉相反，正文设计章呼应）
3. 5ms 通信延迟即失败——低延迟 C++ 部署栈是真机跑通前提（500Hz 状态估计：广义动量观测器+卡尔曼滤波，无外部动捕）
4. armature 精确建模对实机迁移关键

五、批判性审视

  1. "零样本"的精确边界：零样本的是任务适配（不重训网络），但需要手写可微代价函数——这不是零成本。SDF 避障需要外部感知提供障碍物位置（见局限 3），代价函数的引导权重还要调。"零样本"更多是"零重训练"
  2. 教师上限 = 学生上限：扩散模型不能凭空造出 RL 教师学不会的技能（原文自己承认）——两阶段范式把泛化上限锁死在第一阶段。类比：我们的 golden set 门禁质量上限 = 我写笔记的质量上限（No Free Checker 同构）
  3. 0.64s 预测时域：只适合局部反应式控制，长时序规划（多房间导航/长程任务）不在射程内——标题的"versatile"有限定
  4. 瞬态不稳 + 引导权重手调：运动模式切换起始/结束易踉跄；权重不当去噪不稳定——"精细动作控制效果有限"（原文自认）。这两个短板说明引导扩散还不是生产级即插即用
  5. 无视觉端到端：本体感知 only（IMU/关节状态），避障靠外部输入——与 VLA 主线（Astra/Dyna-2 笔记）的感知路线完全不同，是"控制层专精"而非"感知-控制一体"。两者是互补层级不是竞争
  6. 领域映射：训练-测试解耦 = 适航的"型号设计-任务适配"同构（飞机平台不管具体航线任务，任务装订在运营层）；引导代价 = 任务装订参数。这个范式对 CDTDS 的启示：平台层固化能力（不必任务无关但要泛化），任务层测试时注入

六、microduck 对照（可执行吸收清单）

BeyondMimic 做法 我们现状 行动
锚点中心相对跟踪 零位 2048+STAND 绝对标定 观察项：奖励里相对姿态约束 vs 绝对位姿的鲁棒性对比（真机扰动场景）
无历史观测（消融支持） obs 是否堆历史待查（61 维 velstand 布局） 可验证：如堆了历史，消融一版短历史对比 sim-to-real
自适应采样（失败片段加权） 未用 候选：地形课程扩展时失败地形加权采样
适度域随机化 + 精确 armature XML 质量 1604.6g 已实测重训 印证：真机 1831g vs XML +14.1% 的质量差正是"精确物理参数比暴力随机化重要"的实证
5ms 延迟红线 asa 演示 50Hz 环路 警示：我们的控制延迟预算要显式测量，C++ 部署栈是方向
两阶段蒸馏（教师→扩散） 单阶段 RL 远期：microduck 技能库规模化后的组合层候选
Rot6D 表示 待查当前姿态表示 小改动大收益的典型，值得查

风险提示：直接照抄有陷阱——G1 是 20+ DoF 全身人形，microduck 是双足小平台；"无历史观测"结论依赖其仿真时序模式，需在我们栈内验证而非默认成立（铁律：单次 2-env = 假确定性，对照须 ≥3seed）。

"不恰当增大观测历史长度，反而损害 sim-to-real 迁移性能。"
