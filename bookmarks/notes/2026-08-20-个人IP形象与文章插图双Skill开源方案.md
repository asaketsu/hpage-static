# 个人 IP 形象与文章插图双 Skill 开源方案（X/推文笔记）

## 一、核心概念（内容整理）

**背景**：金尘马的文章插图（本人卡通形象，黄黑绿热带套装+墨镜）有辨识度，多篇 10 万+阅读。他把工作流拆成两个开源 Skill。

**架构 = 两步分离**：

| 步骤 | Skill | 解决的问题 |
|------|-------|-----------|
| ① 固定人物 | jinchenma-ip-builder | 「画的是谁」——三视图 + 人物设定 |
| ② 统一画风 | jinchenma-ip-article-illustrations | 「图长什么样、人物做什么」——画风规则 + 文章理解 |

**关键设计**：两部分**分开**——三视图统一人物形象，画风规则统一视觉语言；文章主题再怎么变，场景动作跟着内容调整，人物始终一致。

### 第一个 Skill：IP 形象制作

1. 选一张轮廓清晰、能代表自己的照片
2. 告诉 AI 哪些特征要保留（发型/脸部/服装/配件）
3. 生成**正面、侧面、背面三视图**——补出单张照片看不到的角度（转身/行走/背对读者时 AI 有统一参考，不临时猜测）
4. 补全信息缺口：原照片没拍到脚 → 按热带风格配拖鞋，全身形象完整
5. 调整头身比例、卡通化程度；**设定不用复杂，抓最有辨识度的几项**（他的墨镜+热带套装）——特征稳定，小瑕疵大家照样认得出

### 第二个 Skill：IP 插图制作

1. **画风提炼**：找自己喜欢的参考图给 AI 观察，总结构图/色彩/线条/留白/氛围的共同点；自问喜欢的是什么（干净白底？克制颜色？人物与物件不合常理的关系？）
2. **叠加个人要求**：画面可抽象、同一人物可在一图重复出现、整体简洁元素少、保留暗喻隐喻
3. **迭代定稿**（画风不是一次提炼定稿）：生成真实文章配图→继续调→**每调出满意版本就把有效做法写回风格规则**——几轮后"个人审美变成可复用的画面语言"
4. 最终风格：16:9 横版、纯白背景、大面积留白、低饱和彩色漫画、少量物件、"第一眼看懂关系，再注意到不合理却对应观点的细节"
5. **人物融入的关键**：先让 AI 想清楚这张图表达什么→给人物安排具体动作（观察/触发/承受/改变那个超现实关系）；一图多人物时每个形象都要有具体作用
6. **从文章出发**：AI 先读全文再决定哪些观点值得变成图；每图只表达一个意思；优先配核心观点/内容转折/抽象难懂处；同主题几段合一张图——**图片数量跟信息密度走**

## 二、技术要点（指南分析）

### 2.1 安装 Prompt 照录（Agent 安装 Skill 的范本）

```text
请帮我安装这个仓库中的两个 Agent Skills：
https://github.com/jinchenma94/jinchenma-ip-skills

请根据我当前使用的客户端自行确定正确的 Skills 安装位置并完成安装。只安装仓库中的两个 Skill。安装完成后确认两个 Skill 可以使用。
```

### 2.2 使用 Prompt 照录

```text
# 建 IP（配照片发送）
使用 jinchenma-ip-builder。请根据这张照片为我创建 <你的名字> 个人 IP，保持人物的五官、发型、服装和配件特征一致。

# 生成插图
使用 jinchenma-ip-article-illustrations。请导入刚刚创建的 <你的名字>，然后完整读取这篇文章并直接生成配图：
<文章地址或正文>
```

输出包含：每张图的用途、保存路径、建议插入位置。

### 2.3 方法论拆解（可迁移的三层结构）

| 层 | 内容 | 类比 |
|----|------|------|
| 身份层（不变） | 三视图 + 特征清单 | 类似 Brand Profile——"我是谁" |
| 风格层（慢变） | 画风规则（白底/低饱和/超现实/留白） | 类似笔记 HTML 模板——"长什么样" |
| 内容层（每篇变） | 观点→画面隐喻映射 + 人物动作 | 每篇笔记本身 |

**风格规则的迭代回路**：生成→调→满意→**写回规则**——这正是"个人审美工程化"的闭环，与 humanize 五维评分的"评分写进交付报告"同构。

## 三、复现验证（归纳总结）

- 仓库 github.com/jinchenma94/jinchenma-ip-skills 开源可用，安装 Prompt 设计为客户端自适应（"根据当前客户端确定安装位置"）
- 效果证据：作者自述多篇 10 万+阅读文章使用此工作流；45.6K 浏览 + 545 赞 + 293 转发，传播力强
- 画风目前仅一种（作者自带超现实风格），后续承诺更新风格模板——单一风格是该方案当前边界
- 本机未实测安装（生图链路本机已有：free-image-generation / wan2.7-image / chatgpt-image 等，见 3.3 对比）

## 四、可学到的点（Hermes 借鉴）

1. **Skill 的市场形态正在成熟**：两个 skill 一个 GitHub 仓库 + 一段安装 prompt = 即插即用产品。本机 skill 生态（Hermes skills/）完全兼容此模式——lark-skill-maker 已在做同类封装
2. **三视图=身份的完备参考系**：只给正面照，AI 画背面全靠猜——**完备参考系是"一致性"的工程前提**。同理：brand.md 管文风一致性，三视图管形象一致性，都是"把不变的东西显式固化"
3. **风格规则写回回路**：与 evolver（错误→规则沉淀）、content-templates（五维评分写回）完全同构——**凡是"调完满意的就把做法固化"的结构都值得复用**
4. **"每图只表达一个意思"+信息密度决定配图数**：可直接用于笔记封面/配图策略（covers 目前是模板生成，未来可按核心观点生成概念图）
5. **安装 prompt 的客户端自适应措辞**：不指定路径、让 Agent 自查安装位置——跨客户端（Claude Code/Hermes/Cursor）通用的分发设计

## 五、趋势判断（拓展应用）

1. **个人 IP skill 会成为创作者标配**：从"头像一致性"到"全内容视觉资产化"，开源模板降低门槛后，IP 插图会像 markdown 模板一样普及
2. **Skill 分发渠道 = GitHub + 一段 prompt**：比插件市场更轻，Agent 客户端自适应安装是关键创新——预计各 Agent 框架会跟进"skill install"标准命令
3. **风格模板会走向多选**：单一风格→风格库（作者已预告），对应本机 museum-infochart-gen（专业版式）/zine-poster-prompt-compiler（Zine 风）的模板化路线
4. **与生图链路的整合点**：本机 free-image-generation（Google CDP→ChatGPT→SenseNova 降级链）可作为该 skill 的执行后端，三视图+画风规则作为 prompt 前端
