# ES 量化模型 RL 训练前沿：无梯度进化策略如何绕过量化-RL 交互困境（2026-06-03）

> 夜学深度笔记 | 深入分析 Evolution Strategies（ES）在量化模型上的 RL 训练可行性。覆盖 QES（Quantized ES, arXiv 2602.03120）直接在量化空间微调、EGGROLL（arXiv 2511.16652）低秩扰动百倍加速、EA4LLM（arXiv 2510.10603）无梯度预训练、QuZO（EMNLP 2025）量化零阶优化、ES 遗忘分析（arXiv 2605.30148），建立"无梯度+量化"的方法谱系与实用评估。
> 日期：2026-06-03

## 一、核心发现

### 1. QES：首次在量化空间直接全参数微调（Cognizant AI Lab, arXiv 2602.03120, Feb 2026）

**这是"量化模型能否再训练"这一核心问题的突破性回答**：

核心创新：
- **Accumulated Error Feedback（累积误差反馈）**：ES 在离散量化空间中加高斯扰动时，大多数扰动被量化截断为零（因为量化步长 > 噪声幅度）。QES 引入误差反馈机制，将每步被截断的噪声累积起来，累积到足够大时跨过量化步长，从而在离散空间中实现近似连续的搜索
- **Stateless Seed Replay（无状态种子回放）**：传统 ES 需要存储 N 份完整参数副本（population），QES 用随机种子代替参数副本存储。只要知道种子和随机数生成器状态，就能重建任意扰动版本。内存从 O(N×|θ|) 降到 O(|θ|) + O(N)（N 个种子）

关键结果：
- **INT4/GPTQ 量化模型上直接微调**：在 Llama-1.5B/3B 的 INT8 和 INT4 量化版本上验证
- QES 的噪声步长 σ 配置：INT4 上 σ=0.005，INT8 上 σ=0.001（量化精度越低，需要更大的搜索步长）
- **显著超越 Zeroth-Order（ZO）方法**：在算术推理任务上 QES >> MeZO/One-Point Estimator
- **内存 = 推理级别**：如果能跑推理，就能跑 QES 微调。这是量化模型训练的终极实用性指标

**核心洞察**：ES 天然绕过了量化-RL 交互问题的根本原因 — 量化使参数空间离散化、不可微分，传统 RL（GRPO/PPO）的反向传播在量化参数上梯度消失或严重偏差。ES 完全不需要梯度，只需要 forward pass + 标量 reward 信号。

### 2. EGGROLL：低秩扰动让 ES 在 GPU 上百倍加速（Oxford/FAIR/McGill, arXiv 2511.16652, Nov 2025）

**解决了 ES 扩展到十亿参数的核心瓶颈 — 算术强度**：

核心问题：朴素 ES 需要对参数 θ 加 N 个随机扰动矩阵 E∈R^{m×n}，然后做 N 次 forward pass。在 GPU 上，E 的矩阵乘法算术强度极低（大量随机内存访问），远低于正常推理。

EGGROLL 的解决方案：
- 将每个扰动 E 分解为低秩形式：E = AB^T，其中 A∈R^{m×r}, B∈R^{n×r}，r ≪ min(m,n)
- 辅助存储从 mn 降到 r(m+n)（如 4096×4096 层，r=1 时从 16M 降到 8K）
- Forward pass 的扰动计算从 O(mn) 降到 O(r(m+n))
- **N 个低秩扰动的平均仍然是高秩更新**（关键理论结果），不牺牲表达能力

关键数据：
- **训练速度提升 100x**（在十亿参数模型 + 大 population 规模下）
- **达到纯推理吞吐的 91%**（即 ES 训练几乎不比推理慢）
- Population size 可扩展到 **1,048,576**（百万级 worker 并行）
- **在 Countdown 和 GSM8K 上超越 GRPO**（使用 RWKV 语言模型）
- 成功在 **int8 整数数据类型**上从头预训练非线性 RNN 语言模型

**与 LoRA 的数学联系**：EGGROLL 的 E=AB^T 结构与 LoRA 的 ΔW=BA 完全同构，但目的相反 — LoRA 是找到最优低秩更新，EGGROLL 是用低秩近似高秩随机扰动以加速计算。

### 3. EA4LLM：首次证明 ES 可以从预训练阶段开始优化 LLM（arXiv 2510.10603, Oct 2025）

**挑战"梯度是训练神经网络的唯一途径"这一根本假设**：

- 在 0.5B 到 32B 模型上验证 ES 全参数预训练可行性
- 继承了 Cognizant ES 的 reward 计算方式（从 GRPO 适配）
- 从预训练（而非仅后训练）开始，完全无梯度
- 对比梯度方法，在特定任务上 ES 预训练模型质量接近

**意义**：如果 ES 能从预训练开始工作，那么量化模型从一开始就不需要高精度权重 — 整个训练管线可以在低精度空间完成。

### 4. ES 遗忘是可逆的"性能漂移"而非灾难性遗忘（arXiv 2605.30148, May 2026）

**纠正了 ES 会导致严重遗忘的悲观结论**：

- 之前的论文（arXiv 2601.20861）报告 ES 微调导致前任务遗忘
- 新论文的发现：
  1. ES 遗忘是"性能漂移"（performance drift），训练过程中前任务性能经常自动恢复
  2. 这不是 ES 独有的问题 — RL 方法（GRPO/PPO）同样有此现象
  3. **Freezing 策略**（冻结底层）可以大幅缓解 ES 遗忘
- 结论：ES 是持续学习（continual learning）的有前途方案

**对量化模型的启示**：如果 ES + 量化 + 持续学习联合使用，冻结底层量化权重 + ES 微调顶层，可能同时解决遗忘和精度问题。

### 5. QuZO：量化零阶优化的工程化实践（EMNLP 2025, UCSB/Amazon）

**比 QES 更早的量化+零阶联合工作**：

- 在 4-bit 和 8-bit 量化 LLM 上做 forward-pass-only 微调
- LLaMA-7B 4-bit 上：QuZO 在 SST-2 达到 91.62%（vs One-Point Estimator 89.96%）
- 作为推理引擎的插件实现，与量化推理管线无缝集成
- 与 QES 的区别：QuZO 是 MeZO 风格的零阶优化（单点/两点估计器），QES 是 ES 风格（population-based）

## 二、技术原理解析

### 2.1 为什么 ES 天然绕过量化-RL 交互问题

**量化-RL 交互的三层困境**（来自之前学习 [[2026-05-29-NVFP4-vs-FP8在MoE-RL训练中的精确对比-精度域与训练范式的抉择]]）：

1. **梯度消失/偏差**：量化后参数不可微，straight-through estimator (STE) 引入偏差
2. **Off-policy 失配**：训练用 BF16，rollout 用 FP8/INT4，策略分布不一致（Jet-RL 发现的致命问题）
3. **量化噪声×RL 方差叠加**：两种噪声源互相放大

**ES 如何逐一解决**：

| 困境 | 传统 RL | ES |
|------|---------|-----|
| 梯度消失/偏差 | 需要 STE 近似，偏差累积 | 完全不需要梯度，forward pass 即可 |
| Off-policy 失配 | 训练/推理精度不同导致分布偏移 | QES 直接在量化空间操作，训练=推理精度 |
| 噪声叠加 | 量化噪声 + RL 梯度方差 | ES 的噪声就是搜索机制本身，QeRL 发现量化噪声增强探索 |

### 2.2 QES 的 Accumulated Error Feedback 数学

朴素量化 ES 的问题：
```
θ' = Quantize(θ + σ·ε),  ε ~ N(0, I)
```
当 σ·ε < 量化步长 Δq 时，Quantize(θ + σ·ε) = Quantize(θ)，扰动完全消失。

QES 的解决：
```
e_t = e_{t-1} + σ·ε_t  (累积残余噪声)
θ'_t = Quantize(θ + e_t)
e_t = e_t - (θ'_t - θ)  (减去实际量化后的变化，保留残余)
```

这类似于 SGD 中动量的角色 — 将多次小幅变化累积为一次有效更新。

### 2.3 EGGROLL 的低秩扰动理论

传统 ES 更新：
```
θ_{t+1} = θ_t + (1/N) Σᵢ fᵢ · εᵢ,  εᵢ ∈ R^d
```
其中 fᵢ 是第 i 个个体的适应度（reward）。

EGGROLL 的关键观察：**N 个低秩扰动的加权平均是高秩的**。

设 εᵢ = AᵢBᵢ^T（rank-r），则：
```
Δθ = (1/N) Σᵢ fᵢ · AᵢBᵢ^T
```
当 N >> r 时，Δθ 的有效秩接近 min(N·r, d)，远大于单个扰动的 rank-r。

**理论保证**：在 rank-1 扰动（r=1）+ population N=1024 的设置下，有效更新秩可达到数百，足够表达复杂的参数更新方向。

### 2.4 无梯度方法的精度需求分析

**不同量化格式对 ES 的影响**：

| 格式 | 参数步长 | ES 噪声 σ 需求 | 难度 |
|------|---------|---------------|------|
| BF16 | ~2^-8 | 标准（~0.02） | 最易 |
| FP8 (E4M3) | ~2^-3 | 中等（~0.005） | 中等 |
| INT8 | ~1/256 | 较大（~0.001） | 较难 |
| INT4/GPTQ | ~1/16 | 大（~0.005） | 需 QES error feedback |
| NVFP4 | ~1/8 (块缩放) | 最大 | 未知（QES 未验证） |

**关键发现**：量化步长越大，ES 需要越大的 σ 来"跨过"量化边界，但大 σ 导致搜索粗糙。QES 的误差反馈机制正好解决这个问题 — 用小 σ 多步累积代替大 σ 单步跳跃。

## 四、Actionable Insights

### 4.1 短期可落地
1. **量化 Hermes 模型的 ES 微调**：如果用 INT4/GPTQ 量化后的模型做推理，QES 允许在不增加内存的情况下继续微调。对端侧部署场景有直接价值
2. **ES + QeRL 联合实验可行性确认**：ES 的无梯度特性 + QeRL 的 NVFP4 量化噪声增强探索，理论上是互补的。ES 绕过梯度问题，QeRL 的 NVFP4 噪声提供探索多样性

### 4.2 中期方向
3. **MoE + ES 直接在量化空间 RL**：之前 05-28 分析的 MoE-QLoRA-RL 三维叠加困境，ES 可以消除"量化噪声×RL 方差"这个维度。只需要在每个 expert 的量化参数上加扰动，forward pass 获得标量 reward
4. **EGGROLL + MoE-Sieve**：MoE-Sieve 的"热专家"筛选与 EGGROLL 的低秩扰动结合 — 只对热专家加扰动，冷专家保持不动，减少 population 内存

### 4.3 开放问题
5. **ES 在 NVFP4 上的表现未知**：QES 验证了 INT4/INT8，但 NVFP4 的块缩放结构（2-bit 元素 + 6-bit 块缩放因子）对 ES 扰动的影响未研究。块缩放因子是共享的，扰动个别元素的效果可能被缩放因子"稀释"
6. **ES 的 Population 规模 vs 量化精度 trade-off**：低精度模型上 ES 可能需要更大的 population 来补偿搜索粗糙度
