一、核心结论（TL;DR）

# 结论 硬证据
1 FNO 直接做大规模时空代理已撞墙：参数量 O(10⁸~10⁹)、依赖矩形域 FFT、时间维度固定 SPE 级油藏（10⁶ 网格）FNO 需 226M 参数（Witte 2023 CCS 案例）；819k 网格需 2×RTX 3090 Ti；428k 网格需 8×A100
2 Hybrid DeepONet（FNO branch + 轻量 trunk）把误差降一个数量级：空间结构交给 FNO branch，时间/查询坐标交给仅 5K~21K 参数的 KAN/MLP trunk SPE10 Model 2：DeepONet(FNO+MLP) 相对误差 2.65e-2 vs vanilla DeepONet(MLP) 1.38e-1（↓80.8%），MSE 1.25e-3 vs 3.33e-2（↓96.2%）
3 MLP 与 KAN 单层在表示能力上数学等价（该文 Appendix A 证明），选型应看工程性质（参数增长、可解释性）而非"KAN 更强"的直觉 KAN 参数量随宽度二次增长；文中 Darcy 实验里 FNO+KAN 与 FNO+MLP 误差几乎打平（2.83e-2 vs 2.65e-2）
4 时间维度是神经算子通用短板：DeepONet/FNO 在空间函数空间泛化优秀，但未在训练中显式见过的时刻上外推能力弱 TNO（Sci Rep 2025）专文解决：加 temporal-branch + Markov 假设 + teacher forcing + temporal bundling 四件套
5 混合架构的代价结构极度不对称：FNO branch 贡献 20.5M/20.55M = 99.9% 参数，trunk 换 KAN 还是 MLP 只动 0.03% 参数 DeepONet(FNO+KAN) 总参 20,552,392，其中 KAN trunk 仅 21,760；DeepONet(FNO+MLP) 中 MLP trunk 仅 5,410

一句话：2025-2026 神经算子的主旋律不再是"发明新 NO"，而是解耦——把空间归纳偏置（FNO 的谱卷积）、时间动力学（Markov/temporal branch）、查询坐标（trunk）拆给各自最擅长的子网络，再用 DeepONet 的内积结构拼回来。

二、问题背景：为什么"纯 FNO / 纯 DeepONet"不够用

2.1 两大基础架构回顾（公式照录）

DeepONet（Lu et al. 2021，基于算子万能逼近定理）：branch 网络吃输入函数的传感器采样 v = {v(ω₁),...,v(ωₘ)} 映射为潜在向量 b(v)∈ℝʳ；trunk 网络吃查询坐标 ξ 映射为 t(ξ)∈ℝʳ；输出为二者内积：

G(v)(ξ) = Σₖ₌₁ʳ bₖ(v)·tₖ(ξ)

FNO（Li et al. 2021）：把积分算子核参数化在傅里叶域，每层为：

z_{n+1}(ω) = σ( F⁻¹(R·F(z_n))(ω) + W·z_n(ω) )

其中 F 为 FFT，R 是只作用于低频模的可学习线性算子（高频截断兼作低通滤波）。全局卷积在频域变成逐元素乘法，长程依赖捕获效率远超 CNN。

2.2 FNO 三大工程痛点（因果链）

痛点 机理 后果 文中实证
参数/显存爆炸 频域模数 × 通道宽 × 层数，随分辨率和维数超线性增长 10⁶ 网格级油藏需 O(10⁸~10⁹) 参数 Witte 2023：2M 网格 CCS 模型 226M 参数；chandra2024：428k 网格用 8×A100
矩形域假设 FFT 要求 box-bounded/周期几何 不规则域+复杂边界（真实油藏构型）失效 需 Domain-Agnostic FNO / GINO 等补丁
时间维度僵硬 时间被当作固定维度张量轴，或走自回归 rollout 无法外推训练时间窗之外；rollout 步长/长度强敏感（mccabe2023 稳定性分析） Diab & Al Kobaisi (TNO) 全文主题

2.3 DeepONet 的相对优势与短板

  • 优势：branch/trunk 模块化天然支持嵌入互补组件（FNO/KAN/MLP）；传感器点输入对不规则几何更宽容。
  • 短板：纯 MLP/KAN branch 提取空间相关结构效率低；vanilla 版在强非均质（渗透率跨 6 个数量级）场中误差大。

三、Hybrid DeepONet：空间-时间解耦架构（arXiv 2511.02962）

3.1 核心设计

架构规则：base 模型为 DeepONet；branch 网络 = FNO / KAN / MLP（编码空间结构）；trunk 网络 = KAN / MLP（编码时间域/查询坐标）。空间学习与时间学习在 branch/trunk 中被显式解耦。

实现栈：NVIDIA PhysicsNeMo（内置 DeepONet/FNO/MLP）+ 自研 KAN（基于 pykan 与 efficient-kan 改写，继承 PhysicsNeMo 基类合入）。损失函数为标准 MSE（式 8），训练硬件单卡 H100 94GB。

3.2 关键实验数据

实验 1：2D 稳态 Darcy 流（240×240，渗透率从高斯过程 k(x)~N(0,(−Δ+9I)⁻²) 采样，1500 训练/300 测试，500 epochs Adam）：

  • 结论：FNO+KAN 与 FNO+MLP 逐点绝对误差、∞-范数误差、相对 2-范数误差均最小，混合配置显著优于纯 KAN / 纯 MLP DeepONet。

实验 2：SPE10 Model 2（3D，1,122,000 网格，水驱黑油模型，OPM Flow 全隐式有限体积模拟器生成数据）——核心结果表：

架构 MSE 相对 2-范数误差 对比 vanilla 误差降幅
DeepONet (FNO+MLP) 1.25×10⁻³ 2.65×10⁻² ↓80.8%
DeepONet (FNO+KAN) 1.43×10⁻³ 2.83×10⁻² ↓79.5%
DeepONet (KAN) 2.09×10⁻² 1.09×10⁻¹ ↓20.3%
DeepONet (MLP)（vanilla 基线） 3.33×10⁻² 1.38×10⁻¹ —

参数量分解（说明混合收益来自哪里）：

混合方案 组件 参数量 占比
DeepONet (FNO+KAN) Branch: FNO（lifting 2,432 + FNO blocks 20,500,800 + projection 27,400） 20,530,632 99.89%
Trunk: KAN（2 层×16 宽，spline order 2） 21,760 0.11%
DeepONet (FNO+MLP) Branch: FNO 同上 20,530,632 99.97%
Trunk: MLP（2 层×32） 5,410 0.03%

洞察：trunk 只需要描述"时间/坐标如何调制空间特征"，任务本质低维，5K 参数足矣。真正的容量瓶颈在空间编码器——这正是 FNO 的强项。与其说这是"FNO+KAN 融合"，不如说是"把 FNO 塞进 DeepONet 的 branch 槽位，用内积结构替代 FNO 昂贵的时间轴张量"。

3.3 MLP 与 KAN 的数学等价性（Appendix A）

单层 MLP：f_mlp(ω) = Σᵢ₌₁ᵐ aᵢ·σ(Σⱼ wᵢⱼωⱼ + dᵢ)
单层 KAN：f_kan(ω) = Σᵢ₌₁²ⁿ⁺¹ ψᵢ(Σⱼ φᵢⱼ(ωⱼ))

文中证明：适当参数化下二者可表示同一函数类，可互相任意逼近。工程差异才是选型依据：

维度 MLP KAN
激活位置 节点固定激活函数 边上可学习激活（样条/RBF）
参数增长 随宽度线性 随宽度二次增长（wu2025 PoKAN 指出）
可解释性 弱 较强（样条可视化）
本文实测 trunk 首选（参数更省） 与 MLP 误差打平，未显胜出

3.4 时序相关 PDE 的四件套训练策略

该文与 TNO 共同引用的时序处理工具箱（对做 SHM/疲劳载荷时序代理直接可借鉴）：

  1. Markov 假设：下一状态只依赖当前状态（+输入函数），把长时序切成逐步转移。
  2. Teacher forcing：训练时用真值而非预测值作下一步输入，抑制误差累积。
  3. Temporal bundling：一次预测多个未来时间步，降低 rollout 次数。
  4. 条件化灵活性：输出可条件于当前态或历史多态。

四、TNO：Temporal Neural Operator（Sci Rep 2025）

同一作者团队（Diab & Al Kobaisi，KAUST）的前置工作，专攻时间维度：

  • 问题：DeepONet/FNO 空间函数空间映射泛化好，但对训练中未显式见过的时刻，时间外推精度差——因为时间动力学没进训练目标。
  • 方案：在 DeepONet 框架中引入 temporal-branch，综合多个 NO 的最佳设计 + 上述四件套训练策略。
  • 验证：多组基准 + 消融证明——长程时间外推能力、对误差累积的鲁棒性、分辨率不变性（discretization invariance：低分辨率训练→高分辨率零样本推理）、多输入函数灵活性。
  • 工程意义：与 08-25 笔记 6.2 节"面向 SHM 的时序代理（多保真时序 DT-SHM / SC-DT 时空协同）"互为印证——时序代理是 2025-2026 神经算子落地的主攻方向。

其他时序 NO 支线（文中引证）：Ti-DeepONet（可学习时间积分）、随机初始化自回归模型集成（Khurjekar 2025，用 ensemble 换稳定性）、U-DeepONet（U-Net 增强，地质碳封存）。

五、方法谱系定位：对 08-25 四代谱系的增量更新

08-25 笔记 6.1 节谱系：Kriging → Co-Kriging 多保真 → POD-GPR 非侵入式 ROM → DeepONet 神经算子。本文补充第五层动向：

阶段 代表方法 核心瓶颈 突破方向（2025-26）
第四代（神经算子单架构） FNO / DeepONet vanilla FNO 参数爆炸+矩形域；DeepONet 空间结构提取弱 —
第五代（混合/解耦架构） Hybrid DeepONet（FNO+KAN/MLP）、TNO、Fourier-MIONet、U-DeepONet、嵌套 FNO-DeepONet 治理"哪个子网络管哪个物理维度"的组合爆炸 空间→FNO、时间→Markov/temporal-branch、坐标→轻量 trunk 的职责解耦成为共识模式

航空结构场景映射（延续 08-25 笔记 5.2 决策框架）：

  • 若做气动载荷时空场代理（机翼压力场随迎角/马赫数演化）：Hybrid DeepONet 模式（FNO branch 编码空间流场 + 轻量 trunk 编码 (t, 展向位置)）参数效率比纯 FNO 3D 时序张量低 1-2 个数量级。
  • 若做结构健康监测时序代理（应变场时间演化）：TNO 四件套（Markov + teacher forcing + bundling + 条件化）是训练配方级参考，重点防 rollout 误差累积。
  • 认证红线不变：任何 NO 外推超出训练分布（新工况/损伤模式）时，仍需 ROM 的严格误差界或残差闭环校验兜底——NO 本身不提供误差证书。

六、可执行要点（Actionable）

  1. 选型速查：空间复杂+时间简单 → FNO branch + MLP trunk（参数最省）；需要时间外推 → TNO 式 temporal-branch + Markov 训练；域不规则 → 考虑 GINO/Domain-Agnostic FNO 或 DeepONet 传感器输入。
  2. 复现栈：NVIDIA PhysicsNeMo（DeepONet/FNO/MLP 内置）+ efficient-kan；基准 SPE10 数据集公开（Christie 2001）；Darcy 基准在 PhysicsNeMo examples/cfd/darcy_transolv 直接可得。
  3. KAN 使用警示：宽度二次参数增长，高维输入（如 10⁶ 网格展平）直接喂 KAN 会爆内存——KAN 只适合低维坐标/调制器角色（trunk），不适合当空间编码器（branch）。
  4. 与多保真体系组合：Hybrid NO 可作为 Co-Kriging 体系中的低保真快速求解器（"低保真给趋势"），高保真 CFD 校准仍走传统链路——对应 08-25 笔记三层体系。
