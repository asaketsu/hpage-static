摘要

通达信发布 v7.73 正式版支持量化模拟交易，通过 tdxquant 库（tqcenter.py）提供 Python 接口。文章封装了完整交易流程：初始化连接→查询资产/持仓/委托→买卖下单/撤单→获取实时行情。核心价值在于提供了一个可直接运行的 A 股模拟交易框架。

核心内容

1. 环境要求

  • 通达信客户端：金融终端（量化模拟）V7.73 或 专业研究版V7.73
  • ⚠️ 普通金融终端 V7.73 不含量化功能，V7.72 的 tq 策略也被移除
  • 需要手机号登录模拟交易账户
  • 依赖：tqcenter.py + TPythClient.dll（通达信安装目录下）

2. tdxquant API 接口清单

功能 API 说明
初始化 tq.initialize(path) 连接通达信目录
获取账户 tq.stock_account(account, account_type) stock/FUTURE/CREDIT
查询资产 tq.query_stock_asset(account_id) 资金总额/可用/冻结
查询持仓 tq.query_stock_positions(account_id) 返回持仓列表
查询委托 tq.query_stock_orders(account_id, stock_code) 当日委托
实时行情 tq.get_market_snapshot(stock_code) 五档买卖盘
股票信息 tq.get_stock_info(stock_code) 名称等基础信息
买入 tq.order_stock(account_id, stock_code, STOCK_BUY, ...) 限价/市价
卖出 tq.order_stock(account_id, stock_code, STOCK_SELL, ...) 限价/市价
撤单 tq.cancel_order_stock(account_id, order_id, stock_code) 撤销未成交委托
关闭 tq.close() 断开连接

3. 价格类型常量

price_type 含义
0 指定价格（限价）
1 市价
2 涨停价
3 跌停价

4. 委托状态码

状态码 含义
0 无效单
1 未成交
2 部分成交
3 全部成交
4 部分撤单
5 全部撤单

5. 股票代码格式

通达信使用 代码.市场 格式，如 300308.SZ（深圳）、600519.SH（上海）。

借鉴点（可执行）

  1. 交易接口封装模式：文章把 tqcenter.py 的原生 API 封装为清晰的函数（init/query/order），我们的 quant-trading skill 可以借鉴加入通达信交易通道
  2. 模拟交易流程：初始化→获取账户→查询→下单→撤单，这是标准量化交易流程，可做通用抽象层
  3. 安全转类型函数 _f()/_i()：通达信返回值类型不确定（str/int/None），统一转类型是实用模式
  4. 股票代码格式差异：我们 quant-trading 用 sz000823，通达信用 000823.SZ，需要映射层

启发（超越原文）

  1. 通达信 vs 开源方案的定位：通达信提供完整的本地交易通道（DLL），比开源方案（easytrader 等）更稳定，但绑定 Windows 平台——Linux Agent 不能直接用
  2. 模拟→实盘的差距：模拟交易不涉及滑点、资金限制、风控，实盘化需要额外封装风控层（我们的 risk_engine.py 正好对应）
  3. DLL 依赖意味着跨平台难：未来如果要集成到 Hermes Agent，需要考虑用 Windows 中继或 Wine 方案

预判

  • 趋势：通达信开放 Python 交易接口是券商终端的普遍趋势，未来更多终端会跟进
  • 行动：基于此封装通用交易抽象层，支持多通道（通达信/同花顺/开源），不绑定单一平台
  • 风险：tdxquant 为非正式开源库，接口可能随版本变动；DLL 仅支持 Windows
