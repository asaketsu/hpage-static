1.4 本篇的四个结构增量

  1. 安全+评估合并成域且位置靠后（11/13）：作者 CISO 出身，把 Hallucinations & Benchmarking、Prompt Injection & Data Leakage、Guardrails & Testing 打包——中文版是 Evals（06）与安全（07）分开且居中。两图一致证明：安全与评估已是 2026 路线图一级公民，不再是附注。
  2. "微调 vs RAG"作为显式学习条目（09 域第三项）：把技术选型决策本身当知识教——这是 2026 年才成熟的写法（2023 路线图只教"怎么微调"，不教"什么时候不微调"）。
  3. Cost Optimization 进入基础阶段（07）：成本意识从"高级优化话题"下沉到 API 使用基础课。
  4. 四项目终局（Chatbot → RAG → Agent → Production System）：难度严格递进——对话 → 检索增强 → 工具自治 → 生产化运维，最后一级"Deploy a Production-Ready AI System"把前 12 阶段全部收口。

二、查询拓展

2.1 为什么本篇不含"上下文工程（Context Engineering）"而中文版有

中文版 02 域明确列了"上下文工程"，本篇 07 只写 Prompt Design & Structured Outputs——这是"从零派"路线图的典型取舍：上下文工程（对话历史管理/预算化检索/工具输出修剪）是 2025-2026 才成型的方法论名词，新人路径还来不及吸收；而"转型派"地图已把它当核心域。侧证：roadmap.sh 的 AI Engineer 路线 2026 版也尚未单列 context engineering，只在 prompt 区带过。

2.2 MCP（Model Context Protocol）已成路线图标配名词

两图（10-19 英文版"10 Agents 域 MCP & Human Approval"、9 月中文版"05 域 MCP + A2A"）都把 MCP 列为一级知识点，间隔 6 周的两张独立编选路线图同列 MCP——MCP 从"新协议"变成"基础设施常识"的拐点已过。与之对照，A2A 互操作只在中文版出现，说明 A2A 尚处早期观察期。

2.3 "从零派"路线的隐性成本：13 阶段过长

本篇从 Python 学到生产部署，按每阶段 1-2 个月保守估算需要 18-24 个月。英文圈高赞评论的主流质疑也在此——2026 年的实际市场行情是"用 AI 加速学 AI"：跳过经典 ML 的手工实现（04），直接从 LLM API + 框架层切入，遇到瓶颈再回补数学。两条路径的争论本身就是 2026 年 AI 教育的最大分歧点。

三、归纳总结

3.1 一句话定性

这不是一张新知识地图，而是"从零到生产"的市场需求快照——13 阶段的每个名词在 9 月篇和 roadmap.sh 都能找到，增量全在结构：通用工程基础（01-05，占 38%）+ LLM 应用栈（06-11，占 46%）+ 生产化收口（12-13，占 15%）。

3.2 路线图三分法（本篇与 9 月篇对照后可提炼的框架）

路线图类型 代表 覆盖 适用
从零派（学习路径） 本篇 Dhanush N 编程/数学/ML/DL/LLM/生产 转行者、学生
转型派（知识地图） 9 月 @NFTCPS 中文版、roadmap.sh LLM 应用栈横向全域 在职工程师

三派的共同骨架收敛于：LLM 基础 → Prompt/RAG → Agents → 评估+安全 → 生产化——这五段式是 2026 年社区共识的最大公约数。

3.3 作者方法论：树形结构 + 递进项目收口

可复用的编选结构：树形总览（可收藏性）→ 每节点 3 子项（记忆友好）→ 项目梯度收口（可执行性）→ 金句定调（传播性）。"Save this roadmap / Learn one concept at a time / Build projects as you go" 三连是标准收藏钩子。

四、趋势判断

4.1 33 倍热度差的信号：市场主力仍是"入门者"而非"转型者"

同为路线图，从零派（152K 浏览）对转型派（4.5K 浏览）的热度差说明：2026 年 10 月 AI 工程师赛道的流量基本盘是想入行的人，不是已入行想升级的人。对内容创作者：入门路径内容仍是流量洼地；对招聘方：初级候选人供给将在 12-18 个月后激增，"会调 API"的差异化价值继续贬值，安全（11）与生产化（12）能力成为筛分项。

4.2 安全域的位置迁移：从"附注"到"一级阶段"再到"合并学科"

2024 路线图安全是脚注 → 2026 上半年独立成域 → 本篇（CISO 作者）把 Security+Evaluation 合并为一个阶段——合并不是降权，而是"可靠性工程"（Reliability Engineering）成为统摄学科的征兆：幻觉治理、注入防御、护栏、基准测试本质上都在回答同一个问题"系统在对抗条件下还可靠吗"。

4.3 预测：六个月内"微调 vs RAG 决策"会升级为"多模型路由决策"

本篇 09 域把"Fine-Tuning vs RAG"当静态选择题教。但 2026 年模型经济学的主战场已在移动：包月/按量混合、多供应商 fallback、任务分级路由（简单查询走便宜模型）——决策框架正从"二选一"变成"n 选 k 的动态编排"。学这张图的人六个月后需要补的第一课大概率是模型路由。
