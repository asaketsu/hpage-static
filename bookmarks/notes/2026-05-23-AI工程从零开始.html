AI Engineering from Scratch — 从零到生产的 AI 工程全景课程

📅 2026-05-23 | 🔗 GitHub 仓库 | ⭐ 11.8k stars | 🍴 2.3k forks

一句话

435 节课、20 个阶段、~320 小时，从线性代数到自主 Agent 集群，每节课都产出可复用工具。Python / TypeScript / Rust / Julia，MIT 开源。

核心理念

传统 AI 教材 本课程
碎片化：论文+博客+demo 线性递进：数学 → 机器学习 → 深度学习 → Agent
学完只会调 API 从原始数学推导开始，Backprop/Tokenizer/Attention 全手写
5 分钟视频 + 复制粘贴 读题→推导→编码→测试→产出工具，无捷径
学完没产出 每节课交付可复用制品：prompt / skill / agent / MCP server

"You don't just learn AI. You build it. End-to-end. By hand."

课节结构

每个课节遵循统一目录和六拍循环：

phases/<NN>-<phase-name>/<NN>-<lesson-name>/
├── code/       # 可运行实现（Python/TypeScript/Rust/Julia）
├── docs/
│   └── en.md   # 课程叙事
└── outputs/    # 产出制品：prompt / skill / agent / MCP server

六拍循环：
1. Read — 理解问题
2. Derive — 数学推导
3. Build — 从零手写代码
4. Use — 用生产库跑同一功能（理解框架在做什么）
5. Test — 验证正确性
6. Ship — 保留可复用制品

亮点设计

Phase 14 示例：Agent Loop（~120 行纯 Python，零依赖）

def run(query, tools):
    history = [user(query)]
    for step in range(MAX_STEPS):
        msg = llm(history)
        if msg.tool_calls:
            for call in msg.tool_calls:
                result = tools[call.name](**call.args)
                history.append(tool_result(call.id, result))
            continue
        return msg.content
    raise StepLimitExceeded
