## 一、内容整理

### 0. 为什么解剖 OpenVLA

不是因为它最强（π0.5、GR00T N1.7 基准数字更好），而是**开放链路最完整的 7B VLA**：架构、权重、训练代码、微调脚本、数据配方全部可本地检查。本篇是系列地基，后续 PointVLA（点云注入）与动作生成篇均以它为基线。

### 1. 基座：Prismatic VLM（纠正以讹传讹）

| 流传说法 | 事实 |
|---|---|
| "丰田研究院的模型" | Stanford 的 Karamcheti/Nair/Balakrishna 牵头，Percy Liang、Dorsa Sadigh 参与；2024-02 挂 arXiv，代码托管在 TRI-ML GitHub——TRI 是合作方+托管方，不是"丰田造了 VLM" |

**双视觉编码器**（为看图问答设计，非为机器人设计，OpenVLA 直接拿来用）：
- **SigLIP 管语义**：物体是什么、怎么跟语言对齐
- **DINOv2 管几何**：透视、遮挡、相对位置、姿态
- 两路特征 concat → 两层 MLP projector → 对齐到 Llama 2 7B 的 4096 维

网络拓扑没动、没新增模块，只做一件事：在这个 VLM 之上**全量微调**让它输出机器人动作。

### 2. 一张图怎么变成 7 个动作 Token

**输入**：224×224 第三人称 RGB 图像 × 1 + 自然语言指令 × 1。**没有**深度相机、关节角度、臂长、本体状态。

**链路**：图像 → SigLIP+DINOv2 双编码 → concat → MLP projector → 视觉 token + 文本 token → Llama 2 7B → LM Head 输出。

**关键设计——借词表离散化动作**：
- 预测 7 维动作（3 平移 + 3 旋转 + 1 夹爪），不接独立回归头，**复用 Llama 的 LM Head**
- 每维连续动作离散化为 256 bin：bin 边界取训练数据该维的**第 1-99 百分位**（沿用 RT-2 做法，防离群点稀释精度），区间外压边界 bin
- Llama tokenizer 只预留 100 个 special token 不够用 → **覆盖词表末尾 256 个最低频 token**
- 7 维 = 7 个 token 自回归逐个吐，损失只在这 7 个动作 token 上算交叉熵
- 推理时 token id 查表还原 bin → 反归一化成浮点数（无可学习参数）
- 路线来源：Google RT-2；训练数据：97 万条 Open X-Embodiment

### 3. 借词表的三笔代价

| 代价 | 具体表现 |
|---|---|
| **速度** | 7 token 串行 = 7 次自回归解码。RTX 4090 bfloat16 约 6Hz；A5000 非量化 1.2Hz、4-bit 量化约 3Hz。"1-2Hz"是低端卡数字。BridgeData V2 采 5Hz 勉强跟；ALOHA 跑 50Hz 的双臂平台原版进不了场 |
| **量化误差** | 每维仅 256 档，交叉熵把相邻 bin 当完全无关类别——不知道 bin 3 与 bin 4 比 bin 3 与 bin 200 更接近，精细操作硬伤 |
| **表示冲突（潜在）** | 动作类别与自然语言共用词表和 LM Head，两种输出目标结构上无隔离——是设计风险，非已证明的语言能力损伤 |

**工程边界（本体参数缺失）**：原版无本体参数输入口——臂长、连杆、关节限位、最大速度、夹爪行程一个都喂不进去。真正的问题不是"0.02 米随臂长变"（物理上恒为 2cm），而是**同一个归一化动作值在不同数据集对应不同物理位移/坐标系/控制周期**——推理时必须用 `unnorm_key` 指定按哪套统计量反归一化。

### 4. OFT：原团队的四处手术（arXiv:2502.19645）

**先纠正误传**：OFT 不是社区 fork——作者 Moo Jin Kim、Chelsea Finn、Percy Liang 全部来自 Stanford 原团队，2025-02 挂 arXiv。OFT = Optimized Fine-Tuning，**本质是微调配方不是新模型**。

| # | 手术 | 内容 |
|---|---|---|
| 1 | 连续动作头 | 取 Llama 解码器最后一层 hidden state → 独立 MLP action head 直接回归连续动作，损失 L1，256 动作 token 退役 |
| 2 | 并行解码 | 动作段把因果 mask 换成双向注意力，一次性预测整段动作 |
| 3 | 动作分块 | 一次预测未来 K 步（LIBERO K=8，ALOHA 真机 K=25），整块动作一次前向出 |
| 4 | FiLM 调制（可选） | 语言特征调制动作头中间层，带 FiLM 叫 OFT+，主要用在 ALOHA |

**数字**：LIBERO 四套件平均成功率 76.5% → **97.1%**；吞吐提高 **26 倍**、延迟降至 1/3（项目页区间 25-50 倍）；OFT+ 在 ALOHA 真机以 **25Hz** 控制双臂（14 维动作，三路图像+本体状态输入）。注意：原版 4090 的 6Hz 与 OFT+ 25Hz 硬件/输入/动作块设定不同，不能当严格四倍加速实验。

**L1 vs diffusion 的边界**：论文明确没声称 L1 普适优于扩散——多峰动作分布下 L1 易收敛到"中位数"模态。结论只是"高容量骨干+微调设定下简单 L1 出人意料有效"。**别读成"扩散已死"**。

### 5. 搬到自己的机械臂上

- **LoRA 路线（轻）**：`--lora_rank 32`，单张 A100 跑 BridgeData V2 微调；LoRA 不改 7 维输出格式，调整的是图像特征→动作数值映射，**用数据把本体差异隐式学进去**（不是把臂长填进配置）
- **全量微调（重）**：8×A100 完整节点 + Prismatic 兼容 checkpoint
- **示教数据量**：官方无统一下限，任务跨度/采集质量/本体差异都会改变答案；铁律是**标签必须遵守正确的动作坐标系和归一化约定**——搞错后面全白忙
- **安全边界**：模型输出的 Δ **不能裸发给电机**——限位、速度裁剪、加速度约束、急停、碰撞检测由底层控制器/驱动/ROS 节点执行，不在 VLA 内部。"底层配置里写了臂长"≠"模型知道臂长"

### 6. 许可证与定位

- 代码 MIT；**权重继承 Meta Llama Community License**——商业使用需遵守 Meta 协议，"代码 MIT"≠无许可边界
- 透明 ≠ 最强：视觉骨干 2024 初水平、动作端是"借词表"阶段性方案、单目 RGB 无显式几何、本体状态缺失。π0（PaliGemma 3B + 300M 动作专家，flow matching，动作块 H=50，最高 50Hz）代表另一条架构思路
- 核心价值：**每个设计选择的来路看得见、每笔代价算得清、可本地复现然后改它**——能被拆开的标本比又一个 benchmark 数字有用

## 二、查询拓展

1. **256-bin 离散化 vs 连续回归 vs diffusion head**：三种动作表示的精度-速度-多模态三角权衡，各在什么任务分布下占优？
2. **双编码器 SigLIP+DINOv2 的后续演化**：GR00T N1.7/π0.5 的视觉栈是否仍沿用双骨干？语义-几何解耦是否被验证为最优？
3. **`unnorm_key` 陷阱的泛化**：多数据集混合训练时归一化统计量冲突的系统性解法（按 embodiment 分组统计？）
4. **动作分块 K 值选择**：K=8（LIBERO）vs K=25（ALOHA）背后的控制频率-任务时域匹配逻辑
5. **PointVLA 篇预告**：点云注入 RGB 驱动 VLA 的接口设计——深度信息在哪一层融合最有效？

| 维度 | 要点 |
|---|---|

| 适配铁律 | LoRA rank32 单 A100 可跑；标签坐标系/归一化约定错则全废；模型输出必须过底层安全控制器 |

## 四、趋势判断

1. **"借词表"路线已完成历史使命**：RT-2 开创、OpenVLA 固化为开源基线、OFT 亲手退役它——动作输出走向独立连续头（L1/diffusion/flow matching），LM 词表只管语言。2026 新模型不会再走词表离散化
2. **并行解码+动作分块成为 VLA 标配**：OFT 的 26 倍吞吐提升证明自回归串行是部署瓶颈的核心——后续 π0 的 flow matching（H=50 一步生成）与 GR00T 的扩散头都在解决同一问题：**把动作生成从"逐 token"变成"整块一次出"**
3. **本体状态输入从缺失到标配**：原版 OpenVLA 无本体输入是最大工程短板，OFT+ 补上（三路图像+本体状态）——2026 的新 VLA（GR00T N1.7 等）全部显式包含本体 proprioception
4. **"透明基线"的战略价值上升**：行业充满"端到端大模型表现优异"PPT 的背景下，可拆解可复现的开源样本（OpenVLA/π0 开源版）是研究者的公共基础设施——**透明本身成为竞争力**
5. **边缘部署推动量化研究**：A5000 4-bit 量化 3Hz vs 4090 bf16 6Hz 的现实，让 VLA 量化（Jetson 类边缘平台）成为独立研究方向（与我们 jetson-orin 部署线交叉）
