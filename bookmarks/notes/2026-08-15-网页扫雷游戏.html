一、内容整理

1.1 需求与交付物

用户要求生成一个网页扫雷游戏，页面要漂亮，并保存为笔记。交付物为三件套：

  • 游戏本体：2026-08-15-网页扫雷游戏-游戏.html，单文件 19KB，零外部依赖（无 CDN、无图片、无字体请求），浏览器直接打开即玩
  • 本笔记：MD + HTML 双格式，记录实现方案与技术要点
  • 线上地址：GitHub Pages 自动部署，约 1-2 分钟后可通过 hpage.top 访问

1.2 玩法规则（经典扫雷 + 现代化改良）

  • 目标：翻开所有非雷格子即胜利；踩到雷立即失败
  • 数字含义：格子上数字表示其周围 8 格中的地雷总数
  • 三档难度：
  • 初级 9×9，10 雷
  • 中级 16×16，40 雷
  • 高级 30×16（宽 30 高 16），99 雷
  • 首点必安全（改良）：第一次点击的格子及其周围 8 格保证无雷——布雷延迟到首击时执行，避开首点及其邻域后再随机布雷。这消除了经典 Windows 扫雷"第一步就可能踩雷"的挫败感
  • 数字和弦（Chord）：已翻开的数字格上，若周围旗数恰好等于数字，双击/连点该格可一次性翻开周围所有未插旗格子——高手速开的核心操作
  • 插旗：右键循环插旗；移动端长按 420ms 插旗并震动反馈
  • 计时与雷数：LED 风格数码管显示剩余雷数（雷数减旗数，可为负显示 -xx）与用时（上限 999 秒）
  • 最佳纪录：按难度分别存 localStorage（ms-best-<难度>），破纪录时横幅提示"新纪录"

1.3 视觉设计

  • 配色：暖米色纸感底（#f2eee6）+ 蜂蜜橙强调色（#c2670a），浅色系，拒绝纯黑纯白
  • 格子：拟物立体感——未翻开格子带内阴影（上亮下暗）模拟凸起，翻开后变平面浅色；波浪式翻开带缩放动画，按 BFS 波次逐层延迟 22ms，呈现"涟漪扩散"效果
  • 笑脸按钮：4 态 SVG 表情（普通/惊讶/胜利墨镜/失败 X 眼），按下棋盘时变惊讶，点击重开一局——复刻 Windows 经典交互记忆点
  • 数字八色：1 蓝 2 绿 3 红 4 深蓝 5 棕 6 青 7 黑灰 8 灰，沿用微软 30 年配色惯例，老玩家零学习成本
  • 地雷与旗子：内联 SVG symbol 绘制（辐射爪 + 高光圆 / 三角旗 + 底座），失败时展示所有雷并用红框标出爆炸点、错误插旗处打红叉

BFS 波浪展开：翻开空白格（n=0）时，广度优先扩散翻开连通的空白区及其数字边界；每个格子记录所处的波次 wave，动画延迟 wave × 22ms，形成从点击处向外的涟漪视觉。用 seen 哈希防止重复入队，O(N) 复杂度。

和弦判定：数字格上触发时，统计周围旗数，等于数字才批量 openCell 未旗未开格；若其中有雷则直接判负（忠于经典规则的惩罚）。

事件绑定采用事件委托：整个棋盘只挂一个 click/dblclick/contextmenu 监听，通过 closest('.cell') 定位目标格，30×16=480 格也只有 3 个监听器。

二、查询拓展

2.1 首点安全的两种流派

一是"首击后布雷"（本作方案）：点击时才确定雷区，可自由排除任意安全区；二是"平移重排"：预布雷后若首击是雷，则把雷"搬运"到远处并重算数字。前者实现简单、语义清晰，是 Google 扫雷等现代实现的 mainstream 方案。

2.2 和弦（Chording）的历史

双击速开最早是 Windows 3.1 扫雷的双键同按操作，后来简化为双击或同时按左右键。它是扫雷竞技（世界纪录 1 秒内完成初级）的核心技巧：高手平均每秒可完成 8+ 次有效和弦。本作用"单击已开数字格"触发，对触屏用户更友好。

2.3 单文件零依赖架构

"HTML 的不合理有效性"是 2025-2026 前端圈的一个重要趋势（见关联笔记）：单个 HTML 文件 + 原生 JS 能覆盖大量中小工具场景，无需构建链、无需 npm、双击即用、天然离线。扫雷这类状态简单、渲染轻量的游戏正是最佳载体之一。

三、归纳总结

3.1 实现要点清单

  • 状态与 DOM 分离：S.grid[i] 持有逻辑状态，el 引用 DOM，逻辑函数只改状态再统一刷视图
  • CSS 变量 --cell 驱动格子尺寸：难度切换 + 窗口 resize 只需改一个变量，Grid 布局自动重排
  • 动画用 animation-delay: var(--d) + backwards 填充，避免延迟期间闪现终态
  • 移动端适配：touch-action:manipulation 消除 300ms 点击延迟，长按定时器在 touchmove 时取消防止误触
  • 无障碍：role=grid/gridcell、aria-label、aria-live 结果横幅自动播报

3.2 质量规范遵循（html-quality-standards）

  • 8px 基线网格：间距/圆角均为 8 体系；CJK 优先字体栈；暖色浅底非纯黑纯白
  • 移动端 viewport + 媒体查询降级；语义化 header/main/section/footer
  • 无 AI 味装饰：无渐变文字、无药丸堆砌、无 em-dash 文案、一页一强调色（蜂蜜橙）

四、趋势判断

  • 单文件 HTML 工具将持续走热：AI 生成代码的天然交付单元就是单文件，"发个 HTML 就能用"的分发方式在即时通讯场景（飞书/微信传文件即传播）优势明显
  • 经典游戏是前端教学的常青载体：扫雷/贪吃蛇/2048 覆盖了矩阵状态、BFS/DFS、事件系统、动画调度等通用模式，一人通关即掌握前端基础闭环
  • localStorage 本地纪录是轻量持久化的甜点位：无后端、无账号、无隐私顾虑，适合所有离线小游戏
