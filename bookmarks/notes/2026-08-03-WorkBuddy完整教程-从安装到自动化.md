## 核心观点

> **没有要求，它只能猜。而猜的时候一定挑最省事的。**

装完 WorkBuddy 的第一个星期，作者把上个月的报销单甩给它打了四个字"帮我整理"——结果金额含税不含税混着、时间格式一半"七月"一半"07-01"、疑似重复的发票被直接跳过。

教训：**你要把它当成你的牛马，你要管它，它才能给你挤奶。**

---

## WorkBuddy 是什么

腾讯云 2026 年 3 月上线的 AI 办公助手，装在自己电脑上，能翻文件、做表格、写文档、连邮箱发邮件。相比 Claude Code 和 Codex，没有门槛，安装即用。

## 第1章 安装与第一个活

### 安装四注意

| # | 注意事项 |
|---|---------|
| 1 | 只从官网下，第三方安装包别碰 |
| 2 | C 盘剩不到 10G 的，改安装路径到别的盘 |
| 3 | 安装路径和文件夹都**别用中文名** |
| 4 | 安装时关掉 360 等杀毒软件，免得模块被当病毒杀 |

### 免费额度

- 免费体验版：每月 **500 积分**
- 注册新人额外积分（约 2000）
- Hy3 模型 8 月 5 日前限时免费无限用

### 第一个活怎么派

1. 新建文件夹如 `D:\试一下`，**把文件复制一份**丢进去（是复制，别搬原件）
2. WorkBuddy 左上角新建任务 → 选择工作空间 → 打开本地文件夹 → 指到该目录
3. 默认权限别动（它删文件/跑命令前会先弹窗问你）
4. 输入框右下 Auto 是模型选择，先别管，自动按难度派活

**示范指令**：
> 把 D:\试一下 里的 Word 文档全部转成 PDF，按"日期-文件名"重命名，原文件别删别改，转完告诉我一共几份

> 跟你交代一个新来的人一模一样：指哪打哪，你没说的，它就自己擅自做主了。

### 适合 / 不适合的活

| 适合 | 不适合 |
|------|--------|
| ✅ 规则明确、你自己心里有标准的重复活 | ❌ 创意的活（起名、写文案 → 规整正确却无趣） |
| ✅ Word→PDF 转换、批量重命名、发票整理 | ❌ 要拿捏分寸的活（催款邮件 → 该软软不下来，该硬硬不起来） |

## 第2章 三种模式

输入框加号菜单 → 模式 → 三个选项：

| 模式 | 行为 | 适用场景 | 口诀 |
|------|------|---------|------|
| **默认** | 直接上手干：读文件、改文件、生成文档/表格/PPT、跑命令 | 日常派活 | 动手的事默认干 |
| **计划 Plan** | 先列出几步方案给你确认，你点头再继续 | 复杂任务，新手必守 | 动脑的事先开计划 |
| **仅问答 Ask** | 一个文件都不碰，只给你文字结果 | 写文案、查资料、翻译，省积分 | 只说不做 |

### 权限

- **默认权限**（推荐新手）：删文件、跑命令前弹窗提示，安全度高
- **完全访问**：不问了，自己觉得该删就删——**先用默认权限跑十来趟**，摸清哪些判断靠谱再考虑放开
- 放开完全访问也别在放着合同、财务、客户资料的文件夹里放

## 第3章 工作空间与目录

### 三个防事故习惯

1. **一项目一空间** — 不同客户、项目、选题别混在一个文件夹里
2. **处理副本** — 尤其是表格、合同、图片库、客户资料，让它处理副本再决定迁移
3. **留过程材料** — 至少留原材料、过程稿、公开稿、图片、发布记录和复盘

### 推荐目录结构

```
D:\我的个人工作台
├─ 00-收件箱        暂时不知道放哪的先丢这儿
├─ 01-我的资料      你的身份、目标用户、风格、工作规则
├─ 02-进行中项目
├─ 03-内容生产
├─ 04-日常办公
├─ 05-交付成果
└─ 06-归档
```

### 任务 vs 项目

- **任务**：干一次就完的活
- **项目**：要干几个月的活，有「指令」栏可填通用规矩（以后这个项目里每建一个任务自动带着）
- 五个现成模板：产品需求全流程、市场调研与竞品分析、团队知识库、项目交付、Bug 跟踪测试验收

## 第4章 积分与省钱

### 模型选择

| 模型 | 倍数 | 说明 |
|------|------|------|
| Auto（自动） | 1x | 按任务难易自动派活 |
| DeepSeek / GLM / Kimi / MiniMax | 0.57x 等 | 名后倍数 = 积分消耗 |
| Hy3 | 限时免费 | 8月5日前无限用 |

> 真正烧掉的是 token，积分只是便于理解的单位。一次公众号运营方案 auto 消耗约 60 积分。

### 省积分 6 条

1. 方向没定就让它动手，**最耗** → 需求方向永远是第一位
2. 简单问题用"仅问答"模式，省积分也省得它动文件
3. 选对模型（倍数低的更省）
4. 一个对话只做一件事（不串味也省积分）
5. 充分利用项目指令栏和记忆功能（减少重复沟通）
6. 别囤积分，有大把就用

### 价格（2026年7月起）

| 档位 | 月费 | 实得积分 |
|------|------|---------|
| 体验版 | 免费 | 500/月 |
| 标准版 | ¥99 | 4000（2000基础+2000加赠） |
| 高级版 | ¥199 | 9000（4000+5000） |
| 旗舰版 | ¥999 | 50000（20000+30000） |

连续包月 7 折，年付再叠 8 折。**三条隐藏规则**：积分有有效期、不累积到下月、加赠积分有时限。

## 第5章 六字段指令法（核心精华）

> 你给的活越模糊，它交付的就越离谱。

### 官方公式 vs 六字段拆解

官方：**做什么 + 有什么 + 怎么样**（太粗）

拆解成六个字段：

| 字段 | 含义 | 报销发票示例 |
|------|------|-------------|
| **输入** | 材料在哪 | QQ邮箱里所有带发票附件的邮件，只取上个月的 |
| **目标** | 要什么成品 | 每张发票的开票日期和金额，整理成 Excel |
| **边界** | 什么不能碰 | 原始邮件和附件不要删不要改，金额统一按含税填，判断不了的单独列"待确认" |
| **过程** | 大概什么步骤 | 先下载附件到财务文件夹，再逐张读取，最后汇总 |
| **输出** | 做完放哪 | 存到财务专用文件夹，文件名带月份 |
| **验收** | 怎么算做好了 | 张数跟邮件数对得上，金额合计能加回去，待确认的单独列出来 |

> 六行，九十秒写完。

### 漏掉某个字段的后果

| 你漏了哪个 | 它就自己决定 |
|-----------|------------|
| 输入 | 自己翻文件夹，翻到哪些算哪些 |
| 目标 | 按最省事的方式理解你要什么 |
| 边界 | 顺手把原文件也改了 |
| 过程 | 跳过核对，直接给你结论 |
| 输出 | 存在一个你等会儿找不到的地方 |
| 验收 | 告诉你做完了，你没法反驳 |

> **这不只是 WorkBuddy 的问题。** 管理学家管这个叫**权责缺口**：执行权交出去了，验收权没跟上。权力出得去，责任回不来。

### 验收标准三句话（可直接复制）

```
验收标准：
首页每个数我要能从原始表里一步步加回来；
同比环比用同一套算法；
每个结论后面注明是从哪张表哪一列看出来的；
证据不够的写待核实，别替我推测。
```

### 自检技巧

> 它交完活，你在同一个对话里问"有没有问题"，它大概率说没问题——因为它顺着自己的思路又看了一遍，**等于自己给自己判卷**。

正确做法：**新开一个任务**，扔给它三样东西——原始材料、它做的成品、你的三句验收标准，让它当个刚来的人挑毛病。

### 10 条能直接抄的指令模板

1. **批量 Word→PDF**：转换 + 重命名 + 原文件不动 + 报告数量
2. **文档摘要**：提炼结论 + 页码引用 + 待核实标注
3. **会议录音转纪要**：转文字 + 议题/责任人/截止日期 + 争议标注
4. **Excel 汇总**：合并 + 按部门算环比 + 柱状图 + 总额对账
5. **数据去重**：按手机号去重 + 保留最后更新 + 清洗记录
6. **周报生成**：三页 + 商务风 + 图表 + 每结论标台账来源
7. **PPT 制作**：5 页科技风 + 数据引用报告 + 配图写备注
8. **文件归档**：按类型分类 + 快捷方式别动 + 待归类
9. **重复照片清理**：找重复 + 保留最新 + 先列清单等你点头
10. **自动化日报**：每天 9 点读数据 + 生成日报 + 企业微信发送

### 三个立竿见影的加分动作

1. **设定角色**：比如你是一位在投行干了10年的财务分析师，按最高标准分析这份财报
2. **给范例**：把你满意的范例甩过去说"照这个来"，比描述半天都管用
3. **一事一对话**：别在一个对话里又写周报又做PPT还查竞品，会串味也更费积分

## 第6章 规矩写在哪（四个层级）

| 你要说的话 | 怎么写进去 | 管到哪儿 |
|-----------|-----------|---------|
| 这次任务的具体要求 | 指令里说（六字段） | 说完就完，下个任务不带 |
| 这个项目通用的规矩 | 新建项目时填指令栏 | 这个项目里每个任务自动带着 |
| 你个人的老毛病（简体中文、字数、不许套引号） | 对话里说一句"记住：xxx"，它自动存进记忆 | 换哪个项目都跟着你 |
| 项目干到哪儿了、上次结论 | 它自动记，你也能打开文件补 | 只在这个空间，方便跨会话接着干 |

## 第8章 定时任务

设定后在特定时间自动执行任务。关键原则：**先手动跑通确认无误，再设自动化**。

## 第9章 六字段自测和七天练法

### 自测

拿一个你最近干过的活，按六字段写出来。哪一行你写不清楚，就是下次它会出问题的地方。

### 七天练法

| 天 | 任务 |
|----|------|
| Day 1 | 装好 + 建目录 + 跑通第一个活 |
| Day 2-3 | 每天至少派 3 个任务，养成六字段习惯 |
| Day 4 | 开始用项目指令栏固化规矩 |
| Day 5 | 试一次"计划模式"做复杂任务 |
| Day 6 | 把满意的结果存为范例，下次"照这个来" |
| Day 7 | 设一个定时任务，体验自动化 |

## 关键洞察

> **管理 AI 和管理人的底层逻辑是一样的。** 权责缺口、验收标准、工作空间管理——这些概念在管理学里存在了几十年，现在原封不动地搬到了 AI 办公场景。

> 没有要求，它只能猜。而猜的时候一定挑最省事的。

> 四十分钟（反复返工） vs 九十秒（一次写对六字段）。**你算另一笔账**。
