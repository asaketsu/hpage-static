## 摘要

泛函分析的基本元素不是数字，而是**完整的函数**。为了用代数方法研究函数，数学家构建了一条严密的概念继承链：**线性空间 → 度量空间 → 赋范空间 → 内积空间（希尔伯特空间）**，每一层都比上一层更"富饶"。

---

## 四层概念阶梯

```
线性空间（最贫瘠：只有加法和数乘）
  │  + 度量 d(x,y)  → 定义"距离"
  ▼
度量空间（有相对位置）
  │  + 范数 ‖x‖    → 定义"大小/长度"
  ▼
赋范空间（有绝对大小）
  │  + 内积 ⟨x,y⟩  → 定义"角度/正交"
  ▼
内积空间 = 希尔伯特空间（最富饶：投影、坐标、傅里叶）
```

---

## ① 空间（Space）：万物的容器

| 要素 | 初等数学 | 泛函分析 |
|------|---------|---------|
| 基本元素 | 实数（一维）/坐标（二维） | **完整的函数**（如 f(x)、g(x)） |
| 加法 | 数值相加 | 函数相加 f+g |
| 数乘 | 标量乘法 | λf(x) |

核心：**一个函数就是空间里的一个"点"（向量）**。

## ② 度量（Metric）：如何定义"距离"

记作 d(x,y)，需满足三个公理：

| 公理 | 含义 |
|------|------|
| 非负性 | d(x,y) ≥ 0，且 d(x,x)=0 |
| 对称性 | d(x,y) = d(y,x) |
| 三角不等式 | d(x,z) ≤ d(x,y) + d(y,z) |

→ 升级为**度量空间**，可讨论极限和连续性。

## ③ 范数（Norm）：如何定义"大小"

记作 ‖x‖，理解为"该点到原点的度量"。

> 有了范数，度量自动诞生：**d(x,y) = ‖x - y‖**

→ 升级为**赋范线性空间**。函数的 L² 范数 = 平方积分的平方根 = 信号的**能量**。

## ④ 内积（Inner Product）：如何定义"角度"与"正交"

记作 ⟨x,y⟩，是比范数更严苛的结构。

> 有了内积，范数自动诞生：**‖x‖ = √⟨x,x⟩**

在函数空间中：⟨f,g⟩ = ∫f(x)g(x)dx

**核心威力**：如果 ⟨f,g⟩ = 0，则 f 与 g **正交（垂直）**。

### 傅里叶变换的本质

正弦波和余弦波在内积意义下互相垂直 → 可以把任何复杂函数投影到正交三角函数"坐标轴"上，如同三维空间分解为 x/y/z。

→ 完备的内积空间 = **希尔伯特空间**（Hilbert Space），量子力学和现代泛函分析的终极舞台。
