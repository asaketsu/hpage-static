📋 完整升级流程

Phase 1: 系统升级 (JetPack 6.22 → 7.2)

  • 通过 NVIDIA SDK Manager 执行升级
  • 升级前备份数据，确保充足存储空间（约 15GB）

Phase 2: 编译 llama.cpp 推理框架

⚠️ Ollama 官方预编译不支持 sm_87（Orin 架构），只能 CPU 推理。

sudo apt install -y build-essential cmake git libcurl4-openssl-dev
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
cmake -B build -DGGML_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=87
cmake --build build --config Release -j$(nproc)
echo 'export PATH="$HOME/llama.cpp/build/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
llama-server --version
  • 编译时间：约 20 分钟 | 占用空间：< 2GB

Phase 3: 下载模型

推荐 Nemotron-Nano-8B-v1-Q4_K_M（unsloth GGUF 格式）

wget -c https://hf-mirror.com/unsloth/Llama-3.1-Nemotron-Nano-8B-v1-GGUF/resolve/main/Llama-3.1-Nemotron-Nano-8B-v1-Q4_K_M.gguf

Phase 4: 启动推理服务

llama-server -m Llama-3.1-Nemotron-Nano-8B-v1-Q4_K_M.gguf \
    --host 0.0.0.0 --port 8081 --mlock \
    -t 8 -c 8192 --jinja --flash-attn on \
    --cache-type-k q8_0 --cache-type-v q8_0 \
    --temp 0.7 --top-p 0.85 --top-k 50 \
    --repeat-last-n 64 --repeat-penalty 1.15

⚠️ 端口 8081（非默认 8080，NemoClaw OpenShell 占用）。启动后保持运行。

Phase 5: 安装 NemoClaw

git clone --depth 1 --single-branch https://github.com/NVIDIA/NemoClaw.git
cd NemoClaw && chmod +x install.sh
NEMOCLAW_AGENT=hermes sudo ./install.sh

配置环节填写：
| 配置项 | 值 |
|--------|-----|
| Choose [1] | 3 |
| OpenAI-compatible base URL | http://0.0.0.0:8081/v1 |
| API key | 任意非空字符串 |
| Resource Profiles | 1)（新手推荐） |

⚠️ 务必关闭系统 proxy 代理！沙箱镜像 2.8GB 下载可能需要数小时。

Phase 6: 验证安装

nemoclaw --version
nemoclaw agent status
nemoclaw chat "你好，请介绍一下你自己"

⚠️ 关键注意事项

问题 解决方案
Ollama 不支持 sm_87 使用 llama.cpp 源码编译
国内网络下载失败 使用 hf-mirror.com 镜像站；从 GitHub 代码仓克隆
端口冲突 llama-server 用 8081，NemoClaw 用 8080
proxy 代理干扰 安装 NemoClaw 配置前务必关闭 proxy
模型格式不兼容 必须使用 GGUF 格式（unsloth 提供）
