# 太秀了，我把自己蒸馏成了 Skill！已开源
> 来源：程序员鱼皮 @yupi996 (X Article)
> 链接：https://x.com/i/article/2042839472174407680
> 博客：https://www.cnblogs.com/yupi/p/19851437
> 日期：2026-04-11

## 核心内容

GitHub 上掀起「蒸馏人」热潮：同事.skill、前任.skill、女娲.skill、老板.skill、自己.skill……把人封装成 AI 技能包。

鱼皮把自己蒸馏成了 `yupi-skill` 并开源。流程五步：
1. **收集原料** — 简历、文章、聊天记录、工作文档、别人评价 → `references/`
2. **生成画像** — AI 分析素材提炼性格、风格、专业能力
3. **AI 追问** — 补充细节和盲区
4. **补充能力** — 加专业技能和知识库
5. **开始蒸馏** — 生成 `SKILL.md`

全程不需要写代码，用 Claude Opus 完成。

## 关键项目

| 项目 | Star | 说明 |
|------|------|------|
| 同事.skill | ~11.1k | 复刻同事工作能力+人格，双层架构 |
| 女娲.skill | ~4.3k | 蒸馏名人认知框架（乔布斯/芒格/费曼等） |
| 自己.skill | ~1.4k | 数字永生 |
| 反蒸馏.skill | ~1.4k | 防止被蒸馏，生成清洗版 |
| 前任.skill | ~732 | 情感记忆存档 |
| 老板.skill | ~106 | 打工人整活 |

## 隐私与伦理

- 澎湃新闻报道：法律争议集中在隐私权与个人信息保护
- 职务文档蒸馏有一定合理性，但私人聊天记录等涉及人身权
- 反蒸馏.skill 的存在说明博弈已经白热化

## 我的思考

这个风潮本质是 "知识蒸馏" 在 AI Agent 领域的应用。值得关注的方向：
- Skill 标准化（SKILL.md 格式）正在成为 AI 编程工具的通用接口
- 从工具类 Skill 到人格类 Skill，AI Agent 的能力边界在扩展
- 隐私法规需要跟上，技术进步无法阻止但利益分配可以由制度塑造
