## 一、CoorDex：让人形机器人边走边抓

**论文**：arXiv 2606.23680 | 项目页：https://skevinci.github.io/coordex/

### 问题

传统人形 loco-manipulation 是「停-抓-走」模式：
- 走到物体前 → 停下来 → 操作 → 继续走
- 而且通常只有低自由度（开合式）夹爪

### CoorDex 方案

三阶段训练管线：

```
阶段1: 特权运动跟踪教师（Whole-body + Dexterous hand）
  ↓ 仿真环境中用特权信息训练身体和手的运动跟踪
阶段2: 本体感知条件隐式先验蒸馏
  ↓ 将教师策略蒸馏为仅依赖本体感知的隐式先验
阶段3: 协调隐式残差强化学习
  ↓ 冻结先验作为动作空间，用残差RL学习协调控制
```

**关键创新**：
- **隐式先验接口**：身体和手各有一个先验，通过共享任务上下文 + 独立残差头部组合
- 消融实验证明：纯关节空间PPO、纯关节空间手控制、单体隐式预测**全部失败**
- 只有隐式先验接口 + 协调残差结构能让高维接触密集型操作可训练

**实机验证**（Unitree G1 + 20-DoF WUJI灵巧手）：
- 移动中抓瓶子和搬运
- 边走边开冰箱门
- 移动中立方体抓取和翻转

### 对我们项目的启示

用户刚创建了 LeRobot Humanoid 和 ToddlerBot 项目。CoorDex 的三阶段管线（教师→蒸馏→残差RL）可直接应用于：
- LeRobot Humanoid 的 sim-to-real 迁移
- 从简单行走扩展到移动操作

## 二、HoloAgent-0：统一具身Agent框架

**论文**：arXiv 2606.23565

### 核心架构：三层耦合

```
┌─────────────────────────────────────────┐
│         Embodied AgentOS               │
│  语言指令 → 可执行技能图 → 调度 → 监控  │
│  运行时反馈 → 澄清/重规划              │
├─────────────────────────────────────────┤
│         3D Spatial Memory              │
│  物理世界锚定（空间记忆层）             │
├─────────────────────────────────────────┤
│         Embodied Skills                │
│  异构机器人模型和控制器统一接口         │
└─────────────────────────────────────────┘
```

**与 Hermes Agent 的类比**：
- Embodied AgentOS ≈ Hermes 的 Gateway + Skill 执行循环
- 3D Spatial Memory ≈ Hermes 的知识图谱 + 上下文工程
- Embodied Skills ≈ Hermes 的 Skills 系统

**关键设计**：
- **AgentOS 将语言指令转化为技能图**：自动分解任务、调度资源、监控执行
- **运行时反馈触发澄清或重规划**：不只是执行失败就报错，而是主动重新理解任务
- **跨机器人协调**：多机器人协同工作

**评价**：这是将 LLM Agent 的「推理-工具-反馈」循环从数字世界扩展到物理世界的完整框架，与用户之前研究的 UAVClaw 三层架构（认知层+MCP连接层+VLA执行层）高度互补。

## 三、dVLA-RL：离散扩散VLA的强化学习

**论文**：arXiv 2606.23623

### 突破点

之前 VLA（视觉-语言-动作）模型主要有两类：
1. **连续动作**：扩散/流过程建模
2. **离散动作**：自回归生成或并行解码

dVLA-RL 首次将**强化学习**应用于离散扩散VLA：
- 核心挑战：dVLA 最终动作的边际概率不可计算
- 解决方案：将去噪过程建模为 MDP，学习目标是生成路径的联合概率
- **轨迹级目标**：天然适应可变去噪步数

**性能**：
- **LIBERO 基准：99.7% 成功率**
- RoboTwin 2.0：比 SFT 基线提升 30.6%
- 与 World-Action Model 基线竞争

### 技术价值

统一步调度方法：针对不同任务复杂度定制去噪步数，同时最大化成功率和计算效率。这对边缘部署（如 Jetson 平台）意义重大——简单任务用少步去噪，复杂任务用多步去噪。

## 四、KEMO：事件驱动关键帧记忆

**论文**：arXiv 2606.23589

### 解决什么问题

长时序机器人操作的核心难题：
- 相似观察可能出现在不同执行阶段
- 正确动作取决于之前完成了什么
- 现有方法要么保留密集历史（需要压缩），要么只看最近帧（丢失早期关键事件）

### KEMO 方案

**事件驱动的选择性关键帧保留**：

1. **事件检测**：结合机器人运动学 + 视觉过滤，检测任务相关的状态变化事件
2. **关键帧编码**：将选中关键帧编码为紧凑的时序记忆 token
3. **融合集成**：通过交叉注意力 + 门控残差融合，将记忆 token 与当前视觉特征整合
4. **损失对齐**：关键转换点附近赋予更高训练权重

**性能提升**（对比 π₀.₅ 无记忆基线）：
- 任务成功率：**+23.6%**
- 阶段完成率：**+34.1%**
- 测试范围：真实世界双臂操作任务，2-6个子任务，830-2846执行步

### 与 Agent 记忆系统的关联

KEMO 的「事件驱动选择性记忆」思路与 Hermes 的记忆精炼系统异曲同工：
- 都面临：信息过载 vs 关键信息保留的矛盾
- KEMO 用运动学+视觉检测事件 → Hermes 用会话启发式触发精炼
- KEMO 的门控残差融合 → 可借鉴到 Agent 记忆的上下文融合中

## 五、技术趋势总结

1. **从「停-走」到「连续操作」**：CoorDex 证明人形机器人可以边走边做精细操作，这是从实验室走向实用的关键一步

2. **VLA + RL 成为标配**：dVLA-RL 将 SFT 和 RL 统一在离散扩散框架下，99.7% 成功率表明纯模仿学习的天花板正在被打破

3. **空间记忆成为标配**：HoloAgent-0 和 KEMO 都强调记忆系统的重要性——没有有效的记忆，长时序任务无法完成

4. **模块化 > 单体模型**：CoorDex 的消融实验反复证明，模块化设计（先验+残差、身体+手分离）比端到端训练更有效

5. **边缘适配性**：dVLA-RL 的可变去烟步数调度，直接面向资源受限场景，这与 Jetson 边缘部署需求高度契合
