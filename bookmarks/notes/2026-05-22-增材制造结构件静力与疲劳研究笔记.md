# 增材制造结构件静力与疲劳特性研究笔记

> 电弧增材（WAAM）与铺粉增材（PBF）结构件力学行为系统性研究框架

---

## 一、研究背景与核心差异

### 1.1 两种工艺的本质差异

| 维度 | WAAM（电弧增材） | PBF（铺粉增材） |
|------|-----------------|----------------|
| 能量源 | 电弧（GMAW/GTAW/PAW） | 激光/电子束 |
| 材料利用率 | ~90%+（丝材） | ~60-70%（粉末回收） |
| 沉积速率 | 1-10 kg/h（高） | 0.1-1 kg/h（低） |
| 典型尺寸 | 大型结构件（>1m） | 中小件（<500mm） |
| 成本 | 低（适合工程结构） | 高（适合精密件） |
| 典型材料 | 钢、钛合金、铝合金 | 钛合金、高温合金、钢 |

### 1.2 为什么静力/疲劳研究对结构件至关重要

- **静力性能**：决定承载能力上限，是结构设计的起点
- **疲劳性能**：决定服役寿命，是航空/航天/船舶结构件的核心考核指标
- **增材件 vs 锻件**：疲劳性能通常是锻件的 30-70%，是产业化最大瓶颈

## 二、静力特性研究要点

### 2.1 关键性能指标

| 指标 | 定义 | 关注点 |
|------|------|--------|
| 抗拉强度（UTS） | 拉伸曲线峰值应力 | 与锻件对比（通常 90-105%） |
| 屈服强度（YS） | 0.2% 偏移屈服 | 各向异性差异 |
| 延伸率（EL） | 断裂伸长率 | 增材件通常低于锻件（~5-15% vs ~15-30%） |
| 弹性模量（E） | 应力-应变线性段斜率 | 各向异性（Z 向通常偏低） |
| 断裂韧性（KIC） | 抵抗裂纹扩展能力 | 受缺陷分布强烈影响 |
| 硬度（HV） | 局部抗变形能力 | 层间硬度波动 |

### 2.2 各向异性（Anisotropy）—— 核心关注点

**现象**：增材件在 X/Y（水平面）和 Z（构建方向）方向的静力性能差异显著。

**原因**：
- **晶粒取向**：Z 向生长柱状晶 → Z 向强度通常较低
- **热历史差异**：Z 向经历更多热循环 → 微观组织不同
- **缺陷分布**：Z 向缺陷（未熔合、气孔）沿层间排列 → 成为薄弱面

**典型数据（Ti-6Al-4V）**：
| 方向 | UTS (MPa) | YS (MPa) | EL (%) |
|------|-----------|----------|--------|
| X/Y（水平） | 950-1050 | 850-950 | 12-18 |
| Z（竖直） | 880-980 | 800-900 | 8-14 |

### 2.3 微观组织对静力的影响

| 组织特征 | 对静力的影响 | 控制手段 |
|----------|-------------|----------|
| 晶粒尺寸 | 细晶强化（Hall-Petch） | 调整热输入、添加形核剂 |
| 相组成 | α/β 比例决定强度/塑性平衡 | 热处理调控 |
| 织构 | 择优取向影响各向异性 | 扫描策略优化 |
| 残余应力 | 降低有效承载能力 | 预热、热处理 |

## 三、疲劳特性研究要点

### 3.1 疲劳性能的核心问题

**核心矛盾**：增材件疲劳性能显著低于同材料锻件，差距可达 50-70%。

**根本原因**：缺陷 + 表面质量 + 残余应力

### 3.2 缺陷类型及其对疲劳的影响

| 缺陷类型 | 成因 | 对疲劳的影响 | 检测方法 |
|----------|------|-------------|----------|
| **气孔** | 气体卷入、保护不良 | 疲劳裂纹萌生点，尤其高周疲劳 | CT、X 射线 |
| **未熔合** | 热输入不足、扫描间距过大 | 最严重缺陷，相当于预制裂纹 | CT、超声 |
| **球化** | 熔池不稳定 | 局部应力集中 | 金相、CT |
| **夹杂物** | 粉末污染、保护气不足 | 疲劳源 | 金相、SEM |
| **层间缺陷** | 层间氧化、未熔合 | Z 向疲劳最薄弱环节 | CT、超声 |

**缺陷尺寸效应**：
- 疲劳裂纹萌生寿命 ∝ 1/√a（a = 缺陷尺寸）
- 临界缺陷尺寸：通常 50-100 μm 以上显著影响疲劳
- 高周疲劳（HCF）：对微小缺陷（10-50 μm）敏感
- 低周疲劳（LCF）：对大缺陷和塑性应变敏感

### 3.3 表面质量对疲劳的影响

| 因素 | 影响机制 | 量化影响 |
|------|----------|----------|
| 表面粗糙度（Ra） | 应力集中 → 疲劳裂纹萌生 | Ra 从 5μm→20μm，疲劳寿命下降 30-50% |
| 台阶效应（阶梯状表面） | 几何应力集中 | 尤其影响 Z 向疲劳 |
| 未熔粉末附着 | 局部应力集中 | 铝合金最严重 |

**改善手段**：
- 机械打磨（Ra 降至 1-2 μm）
- 化学抛光
- 喷丸（引入残余压应力）
- 车削/铣削（Z 向外表面）

### 3.4 残余应力对疲劳的影响

| 应力类型 | 分布特征 | 对疲劳的影响 |
|----------|----------|-------------|
| 拉应力 | 表面/近表面 | 促进裂纹萌生和扩展 |
| 压应力 | 内部 | 延缓裂纹扩展 |
| 残余应力梯度 | 沿 Z 向变化 | 影响疲劳裂纹路径 |

**测量方法**：XRD、中子衍射、钻孔法

### 3.5 疲劳裂纹扩展（FCG）

| 阶段 | 特征 | 影响因素 |
|------|------|----------|
| 萌生（Initiation） | 缺陷/表面粗糙处 | 表面质量、缺陷尺寸 |
| 早期扩展 | 沿晶/穿晶混合 | 微观组织、织构 |
| 稳定扩展（Paris 区） | d a/d N = C(ΔK)^m | 材料本质属性 |
| 快速扩展 | 失稳断裂 | 断裂韧性 KIC |

**增材件 vs 锻件**：
- Paris 区参数 C 通常更大（裂纹扩展更快）
- 织构导致 FCG 各向异性（Z 向裂纹扩展更快）

## 四、WAAM 与 PBF 的对比研究

### 4.1 静力性能对比

| 材料 | 工艺 | UTS vs 锻件 | 各向异性程度 | 备注 |
|------|------|-------------|-------------|------|
| Ti-6Al-4V | WAAM | 95-100% | 中等 | 热输入大，晶粒粗 |
| Ti-6Al-4V | PBF-LB | 95-105% | 高 | 快速冷却，针状 α' |
| 316L 钢 | WAAM | 90-100% | 低 | 晶粒较细 |
| 316L 钢 | PBF-LB | 95-105% | 中等 | 细晶强化明显 |
| AlSi10Mg | PBF-LB | 90-100% | 中等 | 共晶组织 |

### 4.2 疲劳性能对比

| 工艺 | 疲劳性能 vs 锻件 | 主要瓶颈 |
|------|-----------------|----------|
| WAAM | 50-70% | 未熔合 + 气孔 + 表面粗糙 |
| PBF-LB | 40-60% | 气孔 + 表面粗糙（阶梯效应） |
| PBF-EB | 60-80% | 气孔（EB 真空环境，缺陷较少） |

## 五、后处理对性能的影响

### 5.1 热处理

| 处理类型 | 目的 | 对静力的影响 | 对疲劳的影响 |
|----------|------|-------------|-------------|
| 去应力退火 | 消除残余应力 | 强度略降（5-10%） | 改善（消除拉应力） |
| 固溶+时效 | 析出强化 | 强度提升 | 可能降低（粗化组织） |
| 热等静压（HIP） | 消除内部缺陷 | 基本不变 | **显著提升（30-100%）** |
| 循环热处理 | 细化组织 | 强度提升 | 改善 |

### 5.2 表面处理

| 方法 | 适用工艺 | 疲劳改善效果 |
|------|----------|-------------|
| 机械打磨 | WAAM（大尺寸） | 20-40% |
| 车削/铣削 | WAAM（外表面） | 30-50% |
| 喷丸 | WAAM + PBF | 20-50%（引入压应力） |
| 化学抛光 | PBF（复杂内腔） | 15-30% |
| 激光抛光 | PBF（外表面） | 20-40% |

### 5.3 综合后处理效果

**最佳组合**（Ti-6Al-4V）：
```
HIP (920°C, 2h, 100MPa) → 去应力退火 → 表面喷丸
疲劳寿命提升：~100-200%（接近锻件水平）
```

## 六、疲劳设计准则

### 6.1 基于缺陷的疲劳评估

**Murakami 模型**：
$$\sigma_w = \frac{C(HV+120)}{(\sqrt{area})^{1/6}}$$

- $\sigma_w$：疲劳极限
- $HV$：维氏硬度
- $\sqrt{area}$：缺陷投影面积平方根
- $C$：材料常数（旋转弯曲 = 1.43）

**应用**：用 CT 检测缺陷尺寸 → 预测疲劳极限

### 6.2 安全系数建议

| 应用场景 | 静力安全系数 | 疲劳安全系数 |
|----------|-------------|-------------|
| 航空结构件 | 1.5 | 2.0-3.0 |
| 航天结构件 | 1.5 | 2.5-4.0 |
| 船舶结构件 | 1.3-1.5 | 1.5-2.0 |
| 一般工程 | 1.25 | 1.5-2.0 |

### 6.3 疲劳寿命预测流程

```
1. CT 扫描 → 提取缺陷尺寸分布
2. 表面粗糙度测量 → Ra、 Rz
3. 残余应力测量 → XRD
4. 选择疲劳模型（Murakami / 断裂力学 / 应变寿命）
5. 考虑各向异性修正
6. 输出 S-N 曲线 / 寿命预测
```

## 七、关键研究空白与前沿方向

### 7.1 尚未充分研究的问题

| 方向 | 问题 | 意义 |
|------|------|------|
| 多轴疲劳 | 增材件在复杂载荷下的疲劳行为 | 实际结构件多为多轴载荷 |
| 腐蚀疲劳 | 海洋/化工环境中的疲劳 | 船舶/海洋工程应用 |
| 高温疲劳 | 高温服役条件下的疲劳 | 航空发动机部件 |
| 尺寸效应 | 大尺寸 WAAM 件 vs 小试样的疲劳差异 | 工程放大问题 |
| 在线监测 | 制造过程中缺陷的实时检测与调控 | 质量控制 |

### 7.2 新兴研究方向

- **机器学习辅助疲劳预测**：用制造参数 + 微观组织 → 预测疲劳性能
- **拓扑优化 + 增材制造**：在疲劳约束下进行结构优化
- **混合制造（减材+增材）**：关键受力面用传统工艺，非关键用增材
- **原位热处理**：制造过程中实时控制微观组织
