VLA 的 Action Head：为什么有的机器人动作丝滑，有的却一顿一顿？

来源: 微信公众号 - 现实智能
作者: 现实智能
日期: 2026-07-31
标签: VLA Action-Head Diffusion-Policy Flow-Matching π0 机器人 动作生成

核心结论

VLA 模型中，VLM 决定机器人是否理解任务，Action Head 决定机器人能不能把任务做好。动作不丝滑的根因不在视觉或语言理解，而在 Action Head 的技术路线选择。四种主流路线各有优劣：ACT 实时性好、Diffusion Policy 多样性强、Flow Matching 兼顾连续与灵巧、动作 Token 训练统一——不存在唯一最好的方案。

一、问题本质：机器人不能像 LLM 那样逐字生成

LLM 文本生成 机器人动作生成
一个 Token 接一个 Token，用户可以等 机械臂 50Hz 运行，每 20ms 需更新一次动作
延迟可接受 模型每次只生成一个动作点 → 延迟、停顿、轨迹不连续

解法：Action Chunking（动作块）

一次生成未来一段动作序列，而非只预测下一步：

传统: 逐点生成
  a_t → 执行 → 观察 → a_{t+1} → 执行 → 观察 → ...
  问题: 每步都要推理, 延迟大, 轨迹不连续

Action Chunking: 一次生成一段
  (a_t, a_{t+1}, a_{t+2}, ... a_{t+H}) → 执行前几步 → 重新观察 → 重新预测
  优势: 减少重复推理, 相邻动作连贯
  代价: 动作块越长 → 对环境变化响应越慢

真实系统通常采用滚动执行（Receding Horizon）：预测一段，执行一小段，再根据最新观察重新预测。

二、四种 Action Head 技术路线

路线 1：ACT（Action Chunking Transformer）

维度 说明
核心 Action Chunking + 滚动执行
动作表示 连续值回归
优势 实时性好，适合需要快速闭环的任务
劣势 普通回归面对多模态分布（多种抓法）会取平均，生成错误轨迹

路线 2：Diffusion Policy（扩散策略）

维度 说明
核心 从随机噪声出发，经多次去噪，逐步生成一整段合理轨迹
动机 同一个杯子可以从左抓也可以从右抓——普通回归会取平均生成"两边都不像"的轨迹
优势 轨迹平滑、表达能力强，适合处理多种可能性（不同抓取方向/操作顺序/接触策略/柔性物体）
劣势 需要多轮去噪，推理速度可能难以满足高频控制

路线 3：Flow Matching（π₀ 的选择）

维度 说明
核心 同样从噪声出发，但不反复去噪，而是学习连续"速度场"，引导噪声流向合理轨迹
代表 Physical Intelligence 的 π₀
架构 VLM Backbone（理解图像/语言/任务）+ Action Expert（根据机器人状态生成连续动作）
优势 兼顾连续生成与灵巧操作，适合高频、连续、多解的机器人操作
分工 VLM 负责"思考"，Action Expert 负责"控制身体"

路线 4：动作 Token（离散化）

维度 说明
核心 把连续动作压缩成离散 Token，让 Transformer 统一处理
早期方法 每个关节动作划分为离散区间 → 易损失精度，长序列产生大量 Token
PI FAST 先压缩整段动作，再编码成更紧凑的 Token 序列 → 显著缩短序列，提高训练效率
OpenVLA-OFT 连续动作 + Action Chunking + 并行解码 → LIBERO 成功率从 76.5% 提升到 97.1%，吞吐量提升约 26 倍
优势 更容易与 Transformer 统一训练
劣势 自回归 Token 逐个生成，真机推理速度未必优于 Flow Matching

四、选型决策：没有唯一最好的 Action Head

工程平衡的六个指标

指标 说明
动作精度 位置/力矩的准确度
轨迹平滑性 动作连贯无卡顿
推理速度 满足控制频率需求
多样性 处理多种合理解的能力
训练成本 数据量和计算量
部署复杂度 工程实现难度

按场景选型

场景 最在意 推荐路线
高速分拣 节拍（速度） ACT / OpenVLA-OFT
柔性物体操作 动作分布（多样性） Diffusion Policy
精密装配 控制精度 Flow Matching / ACT
动态场景 反馈速度 ACT（快速闭环）
灵巧操作 多解+连续 Flow Matching (π₀)
统一训练 与 LLM 对齐 动作 Token (FAST)

五、关键概念速查

术语 说明
Action Head VLA 中把语义信息转化为连续实时控制指令的模块
Action Chunking 一次预测一段动作序列而非逐步，减少重复推理
滚动执行 预测一段→执行一小段→重新观察→重新预测
Diffusion Policy 从噪声去噪生成动作轨迹，处理多模态分布
Flow Matching 学习连续速度场引导噪声流向合理轨迹
Action Expert π₀ 中与 VLM Backbone 分工的动作生成模块
FAST Physical Intelligence 的动作压缩 Token 方案
OpenVLA-OFT 连续动作+Chunking+并行解码，吞吐量提升 26 倍
