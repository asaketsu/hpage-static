电子书下载宝库 (ebook-treasure-chest)

GitHub: https://github.com/jbiaojerry/ebook-treasure-chest
在线搜索: https://jbiaojerry.github.io/ebook-treasure-chest/

简介

11.2k star | 1.6k Fork | 更新至 2026-01

汇聚各类电子书下载链接的开源仓库，涵盖帆书app(原樊登读书)、微信读书、京东读书、喜马拉雅等读书app的大部分电子书。

核心特点

特性 说明
格式 epub / mobi / azw3 三种格式
分类 经典文学、经管励志、终身学习、职场创业、技术手册等
搜索 GitHub Pages 实时搜索，支持多关键词
来源 帆书、微信读书、京东读书、喜马拉雅等

使用方式

  1. 在线搜索（推荐）：访问 GitHub Pages 页面，输入书名/作者/分类关键词即时搜索
  2. 浏览分类：仓库 md/ 目录按分类存放书籍 Markdown 文件
  3. 批量下载：Clone 整个仓库获取全部链接

分类目录

  • 经典文学
  • 经管励志
  • 终身学习
  • 职场创业
  • 技术手册
  • 其他

技术实现

  • scripts/ — 自动同步脚本
  • .github/ — GitHub Actions 自动更新工作流
  • docs/ — GitHub Pages 搜索页面
  • md/ — 按分类的书籍 Markdown 文件
