一、内容详细整理

1.1 底稿命题：积木与大厦的正确关系

千问底稿给出四节框架：MLP 分析 / Transformer 分析 / 核心区别与联系 / 应用场景对比。最有价值的一句判断：

MLP 是构建复杂神经网络的"基础积木"，擅长静态特征的非线性映射；而 Transformer 则是专为序列数据设计的"高级架构"，通过自注意力机制和内置的 MLP 组件，实现了对复杂上下文和长距离依赖的高效建模。

本笔记以底稿四节为骨架，向下挖数学原理，向上补演进路径。

1.2 MLP 数学原理：从线性不可分到通用逼近

基本运算（单隐藏层）：

$$h = \sigma(W_1 x + b_1), \quad y = W_2 h + b_2$$

  • $x \in \mathbb{R}^d$，$W_1 \in \mathbb{R}^{m \times d}$，$\sigma$ 逐元素非线性
  • 若无 $\sigma$：$y = W_2 W_1 x + (W_2 b_1 + b_2) = W'x + b'$——任意深度坍缩为单层线性变换，非线性是深度的意义所在

通用逼近定理（UAT）三阶段：

定理 年份 内容 证明工具
Cybenko 1989 单隐层 + sigmoid 型激活可逼近紧集上任意连续函数 泛函分析（Hahn-Banach）
Hornik 1989 多层前馈网络可逼近任意 Borel 可测函数 Stone-Weierstrass 定理
Leshno et al. 1993 激活函数条件放宽为非多项式即可 —

深度分离（Depth Separation）——UAT 没说的部分：
- UAT 说"宽度足够就能逼近"——但没说效率
- 深度 $L$ 层、每层 $n$ 神经元的 ReLU 网络可表示分段线性函数的线性区域数最多 $O\left(\binom{n}{d}^L\right)$——指数级于深度
- 单层只有 $O(n)$ 个区域
- 结论：深度对某些函数类是指数级参数高效的——UAT 保证"能"，深度分离解释"省"
- 局限性（教材诚实条款）：UAT 不保证泛化、不保证训练能找到好的解——存在性定理 ≠ 可达性定理

MLP 的两个结构性缺陷（底稿+扩展）：
1. 无序列归纳偏置：把序列当固定长度向量，元素顺序被打乱后 $W_1$ 的每一列无法区分——置换等变但非顺序感知
2. 参数量随输入维度膨胀：图像直接展平 → $d = H \times W \times C$，第一层参数爆炸——CNN 用局部权值共享、Transformer 用 token 化绕开，纯 MLP 直接硬吃

1.3 Transformer 数学原理：注意力作为可微检索

缩放点积注意力：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

  • $Q = XW^Q$，$K = XW^K$，$V = XW^V$——同一输入三份投影
  • $\frac{1}{\sqrt{d_k}}$ 的作用：$d_k$ 维点积的方差随维度线性增长，不缩放则 softmax 进入饱和区、梯度消失
  • 本质：可微的软性键值检索——$QK^\top$ 算相关度，softmax 归一化成权重，对 $V$ 加权求和

多头注意力：

$$\text{MultiHead}(X) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O, \quad \text{head}_i = \text{Attention}(XW_i^Q, XW_i^K, XW_i^V)$$

  • $h$ 组独立子空间投影——不同头看不同关系（句法/共指/位置）
  • 总计算量与单头 $d_{model}$ 相当（每头 $d_k = d_{model}/h$）

Transformer 层 = 注意力 + MLP 的交替（底稿"包含关系"的数学形态）：

$$X' = X + \text{MHA}(\text{LN}(X)); \quad X'' = X' + \text{FFN}(\text{LN}(X'))$$

$$\text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2 \quad \text{（原版，两层 MLP）}$$

分工（底稿原话+深化）：
- 自注意力负责"收集/融合"上下文——token 间的信息搬运（通信算子）
- FFN/MLP 负责"非线性变换/特征提取"——每个 token 独立加工（计算算子）
- 这就是"MLP 是 Transformer 核心组件"的精确含义：Transformer = 通信（attention）与计算（MLP）的交替堆叠

复杂度对照（序列长 $n$、维度 $d$）：

架构 计算复杂度 参数量 说明
MLP（逐 token） $O(d^2)$ 每 token $O(d^2)$ 与序列长度无关
自注意力 $O(n^2 d)$ $O(d^2)$ 序列平方项
MLP-Mixer token-mixing $O(n^2)$（隐层 $O(n)$ 时） $O(n^2)$ 固定 权重不随输入变
卷积（核 $k$） $O(k \cdot n \cdot d^2)$ $O(k d^2)$ 局部性

1.4 核心区别：固定权重 vs 数据依赖权重（比底稿更深一层）

底稿列了四条区别（序列处理/并行效率/参数共享/包含关系），全部成立，但可以统一到一个更深的轴上：

维度 MLP 自注意力
token 间权重 固定（训练后冻结） 动态（每个输入现算 $QK^\top$）
权重生成 $W \in \mathbb{R}^{n \times n}$ 学习参数 $A = \text{softmax}(QK^\top/\sqrt{d_k})$ 数据函数
感受野 固定（全连接=一跳） 动态任意（O(1) 路径长度）
插值能力 不能外推到新长度（$W$ 尺寸锁死） 天然可变长
等变性 对输入维置换不等变 置换等变（需位置编码打破对称）

一句话：MLP 的混合矩阵是学的，注意力的混合矩阵是算的。MLP-Mixer 把"学的混合"推到视觉 SOTA 附近，证明了静态混合的上限；注意力的胜利在于混合规则可以逐样本适配——这正是检索/上下文学习需要的性质。

参数共享的精确表述：自注意力对序列中所有 token 应用同一组 $W^Q, W^K, W^V$——跨位置共享；MLP 若逐 token 应用（如 FFN），同样跨位置共享；差别在 token 维度的混合上：FFN 不做 token 间混合，token-mixing MLP 做但权重固定，attention 做且权重动态。

1.5 演进路径一：视觉 MLP 复兴（2021，"注意力必要吗"之问）

MLP-Mixer（Tolstikhin et al., NeurIPS 2021，Google）：
- 两类层交替：token-mixing MLP（沿 patch 维全连接+转置）+ channel-mixing MLP（沿通道维）
- 每层 $\text{LN} \to \text{MLP}_1(\text{token 维}) \to \text{LN} \to \text{MLP}_2(\text{channel 维})$ + 残差
- 论文命题：卷积和注意力都充分但都不必要——纯 MLP 达到 76.4%（Mixer-B/16，ImageNet Top-1，59M 参数）
- 关键结论：在大数据（JFT-300M 预训练）下 Mixer 逼近 ViT；小数据下差——静态权重的代价是数据饥渴

gMLP（Liu et al. 2021，"Pay Attention to MLPs"）：
- 门控机制 + Spatial Gating Unit（SGU）：$\text{SGU}(X) = f(X) \odot g(W X + b)$（$\odot$ 逐元素乘）
- 79.6%（gMLP-S，20M）——在翻译任务上接近 Transformer，但作者自己指出长距离依赖上仍逊于注意力

ResMLP（Touvron et al. 2021，Meta）：
- 残差设计 + 交叉残差连接（每 token 的输出加回所有 token 输入的线性组合）
- ResMLP-B24 达 81.0%（116M）——纯 MLP 的视觉最好成绩档

后续分叉：ViP/Vision Permutator（轴向置换混合）/ S2-MLP（空间位移）/ As-MLP（轴向位移）/ CycleMLP（稠密预测）/ DynaMixer（动态生成混合矩阵——向注意力靠拢）/ FNet（傅里叶变换混合 token，完全无参数混合）

谱系总结表（含参数与 ImageNet 成绩）：

模型 年份 参数 FLOPs Top-1 token-mixing 机制
Mixer-B/16 2021.5 59M 12.7G 76.4 固定 MLP（转置全连接）
ResMLP-S24 2021.5 30M 6.0G 79.4 固定 MLP+交叉残差
ResMLP-B24 2021 116M 23.0G 81.0 同上
gMLP-S 2021.5 20M 4.5G 79.6 空间门控（SGU）
gMLP-B 2021 73M 15.8G 81.6 同上
ViP-Small/14 2021 30M 6.9G 80.7 轴向线性投影
ViT-B/16（对照） 2020 86M 17.5G 77.9→84+ 动态注意力

视觉 MLP 复兴的启示与局限：
- 启示：归纳偏置越少 + 数据越多 = 上限越高（与 ViT 同一逻辑）；架构简化有工程价值（无 attention 的二次开销）
- 局限：静态权重在变长/动态任务（语言）上始终差一口气——gMLP 论文自己承认；2022 后视觉 MLP 谱系热度回落，主力遗产被吸收进"去注意力化"研究线

1.6 演进路径二：FFN 内部演进（MLP 作为组件的自我升级）

底稿说"FFN 本质上就是 MLP"——但 2017→2026 这九年间 FFN 自身经历了三级跳：

第一跳：ReLU → GLU 家族（SwiGLU）
- 原版：$\text{FFN}(x) = \max(0, xW_1)W_2$
- SwiGLU（Shazeer 2020）：$\text{FFN}(x) = (\text{Swish}(xW_1) \odot xW_3)W_2$——门控线性单元，三矩阵
- LLaMA/PaLM/Qwen/Mistral/DeepSeek 全部采用——"2017 年到现在 Transformer 主结构上变化最大的一处"
- 诚实注脚：Shazeer 原文承认没有清晰理论解释为什么更好（"divine benevolence"）——工程上稳定有效，理论上未解

第二跳：FFN 是键值记忆（理论视角）
- Geva et al. 2021：FFN 的 $W_1$ 行向量 = key，$W_2$ 列向量 = value——每个中间神经元是一个 (key, value) 记忆槽
- 这一视角解释三件事：①为什么 SwiGLU（门控=更好的检索匹配）②为什么 MoE 有效（多个小字典比一个大字典检索省）③为什么 FFN 量化难（key 有明星神经元长尾分布，INT8 覆盖不住）

第三跳：MoE——把 FFN 切成专家（参数与算力解耦）

$$y = \sum_{i \in \text{TopK}} g_i \cdot \text{Expert}_i(x)$$

  • 路由器（线性层+softmax）每 token 只激活 K 个专家（K=1~2 常见）
  • 核心价值：容量（总参数）与成本（激活参数）解耦——Mixtral 8x7B 总参 47B/激活 13B，性能超 Llama2-70B（激活参数是其 5 倍+）
  • DeepSeek-V3：细粒度专家+共享专家+极致工程（671B 总参/37B 激活）
  • MoEfication 路线：训好的稠密 FFN 可事后切分成 MoE（激活稀疏性发现——FFN 本来就只强烈激活少数神经元，与人脑稀疏激活同构）

演进逻辑链：ReLU FFN → SwiGLU（更好）→ 键值记忆理论（解释）→ MoE（扩展）——"MLP 组件"不是静止的积木，是持续进化的器官。

1.7 演进路径三：注意力自身的 MLP 化/线性化（两个学派的合流）

痛点：$O(n^2)$ 的注意力在长上下文（>128K）不可持续——KV Cache 随上下文线性膨胀。

线性注意力学派（把 softmax 去掉换可分解核）：
- Performer/cosFormer/FLASH：$\text{softmax}(QK^\top)V \approx \phi(Q)(\phi(K)^\top V)$——右结合先算 $K^\top V$（$d \times d$），复杂度 $O(nd^2)$
- RWKV（2023→RWKV-7 2025）：WKV 机制=线性注意力近似，并行训练（类 Transformer）+ 常数状态推理（类 RNN）；社区小但在嵌入式（手机/Pi）部署领先
- RetNet（2023）：retention 机制，微软提出的"Transformer 继任者"

SSM 学派（状态空间模型）：
- Mamba（Gu & Dao 2023.12）：选择性状态空间——参数随输入变化（把 LTI 打破），线性复杂度 $O(n)$，百万 token 序列（基因/音频）优势
- Mamba-2（2024）：State Space Duality 理论——选择性 SSM 与注意力是对偶表示；rank-1 状态矩阵的 Mamba 层等价于线性注意力
- 混合架构成主流：Jamba（AI21）/Zamba——Mamba 块 + 少量注意力层 + MLP，两头兼顾

合流的数学表述：注意力 $A = \text{softmax}(QK^\top)$ 与 SSM 的状态递推 $h_t = \bar{A}h_{t-1} + \bar{B}x_t$ 在 SSD 框架下是同一算子的两种分解（序列形式 vs 递归形式）——Transformer 与"后 Transformer"不是替代而是同一连续谱的两个端点（完全数据依赖 ↔ 完全固定递推）。

关键数据锚点（Mamba-360 综述的 PPL 对照）：

类型 模型 PPL(val)↓ 参数
注意力 Transformer 24.40 44.65M
注意力 cosFormer 26.53 44.65M
MLP gMLP 28.08 47.83M
MLP Syn(D) 31.31 46.75M

语言建模上注意力 > 线性注意力 > 纯 MLP 的梯度依然清晰（小模型时代数据；大模型+大数据下差距缩小但次序未反转）。

1.8 应用场景全景（底稿第四节扩展）

场景 更优选择 原因
表格数据/分类回归 MLP 静态特征非线性映射，无序列结构
CNN 分类头 MLP 全局特征聚合
RL 策略网络（小 obs/动作空间） MLP 低延迟推理，算力约束
边缘控制（如机器人步态） MLP ONNX 部署轻量，延迟确定
大语言模型/长上下文 Transformer（+线性注意力混合） 上下文学习/检索需要动态权重
视觉基础模型 ViT 系 大数据下动态混合上限高
超长序列（基因/音频/Agent 记忆） Mamba/RWKV $O(n)$ 与常数状态
巨容量知识存储 MoE Transformer 参数算力解耦

选型判断式：任务需要逐样本变化的关系结构（检索/组合泛化/上下文学习）→ 动态混合（注意力）；任务的关系结构固定且可预学习（图像局部性/表格独立性）→ 静态混合（MLP/卷积）足够且更省。

三、归纳总结

  1. "积木与大厦"是底稿最准确的判断：MLP 是静态非线性映射的通用积木；Transformer 用注意力（通信）+ MLP（计算）交替堆叠出序列智能——包含关系不是装饰性的，是架构分工的本体
  2. UAT 三定理保证"能"，深度分离解释"省"，泛化理论管"学得到"：单隐层够宽即可逼近（Cybenko/Hornik），但深度指数级省参数（$O(\binom{n}{d}^L)$ 线性区域），而训练可达性是另一回事——三个层次不可混淆
  3. 固定权重 vs 数据依赖权重是 MLP 与注意力的本质分界：MLP 的混合矩阵是学的（训练后冻结），注意力的混合矩阵是算的（逐样本生成）——置换等变性/变长外推/感受野动态性全部由此派生
  4. 视觉 MLP 复兴证明了静态混合的上限，也暴露了天花板：MLP-Mixer/ResMLP/gMLP 在大数据下逼近 ViT，但语言建模 PPL 梯度（Transformer 24.4 < gMLP 28.1）说明逐样本自适应的关系结构在语言里不可省
  5. FFN 九年三级跳说明"MLP 组件"在进化：ReLU→SwiGLU（工程胜利但理论未解）→键值记忆理论（解释三件事）→MoE（参数算力解耦，Mixtral/DeepSeek-V3 成主流范式）——看 Transformer 演进史，一半在看 MLP 演进史
  6. Mamba-2 的 SSD 对偶把"学派之争"变成"同一算子的两种分解"：注意力（序列形式）与 SSM（递归形式）对偶；rank-1 Mamba ≡ 线性注意力——后 Transformer 时代不是替代而是谱系展开
  7. 混合架构是当前收敛点：Jamba/Zamba = Mamba 块+注意力层+MLP——三种混合算子（动态线性递推/动态全局/静态非线性）按任务比例配比
  8. 选型判断式一句话：需要逐样本变化的关系结构→注意力；结构固定可预学→MLP/卷积；超长序列→线性递推；巨知识容量→MoE
  9. MLP 的持久优势在边缘与控制：低延迟/确定性/ONNX 友好——DUCK-Pi_5 策略网络用 MLP 不用 Transformer 正是复杂度与任务的匹配
  10. 底稿的一句话在 2026 年依然成立且更深刻：MLP 擅长静态特征的非线性映射，Transformer 通过内置 MLP+自注意力实现对复杂上下文的高效建模——九年了，两个构件谁也没淘汰谁，分工反而更清晰

四、趋势判断

  1. "注意力 vs MLP"的二元叙事正在被"混合算子配比"取代：2026 前沿模型（DeepSeek-V3/Jamba2 等）全是 Mamba+Attention+MoE-MLP 的组合——架构设计从选边站变成配比优化
  2. MoE 成为容量扩展的默认路径：稠密模型在前沿榜单上绝迹——"参数算力解耦"从技巧变成范式；MoEfication（稠密切 MoE）会成为存量模型升级的标准手术
  3. 线性注意力的实用化临界点在 Agent 长记忆：Agent 需要 100 万+ token 的对话/工具历史——KV Cache 线性膨胀不可承受，常数状态模型（Mamba/RWKV）成为 Agent 基础设施的候选底座
  4. SwiGLU 之谜会被理论补上："不知道为什么但有效"的状态不会持续——键值记忆视角+检索理论的结合可能在 2027 年给出解释
  5. 视觉 MLP 谱系沉寂但遗产长存：token-mixing 思想活在 HyperMixing（线性注意力里的 TM-MLP）等混合设计中——失败路线的组件被胜利路线吸收
  6. MLP 在端侧复兴：RWKV.cpp/手机 Pi 部署——当推理成本压到极致，常数状态+纯 MLP 块的模型是电池友好解
  7. "架构研究"的重心从 token 混合移向系统级：单层算子的边际创新递减，组合创新（并行策略/KV 管理/专家路由）成为主战场——与 KVCache 十二技笔记的系统工程视角合流

五、关联分析

关联对象：KVCache 优化十二技 / DeepLoop 循环 Transformer / TurboVLA 实时账 / DUCK-Pi_5 策略网络 / c-xor-nn 六版演进项目

  1. 与 KVCache 十二技笔记（姊妹篇）：本笔记讲"架构为什么长这样"，十二技讲"架构的账怎么省"——公式归因三分法（架构类/引擎类/只省读不省存）中的架构类正是本笔记演进路径三的展开（MQA/GQA/线性注意力都是注意力的变体）；两篇构成"原理→优化"完整链
  2. 与 DeepLoop 循环 Transformer 对照：DeepLoop 把"生成新 token"换成"循环重访已有 token"——与 RWKV/Mamba 的"常数状态递推"是同一焦虑（上下文二次成本）的两个解（改用法 vs 改架构）；访问对齐系数是循环侧的理论工具，SSD 对偶是架构侧的理论工具
  3. 与 TurboVLA 的架构选型互证：TurboVLA 0.2B 轻策略 32Hz 高频出动作——正是"MLP 持久优势在边缘与控制"的 VLA 版落地；语言理解（动态权重需求）前移到特征融合层，控制回路只留轻 MLP——§1.8 选型判断式的机器人实例
  4. 与 DUCK-Pi_5 策略网络：小鸭用 MLP 策略（非 Transformer）——obs/动作空间小、关系结构固定（步态动力学可预学）、Pi5 边缘延迟约束——三条全中 §1.8 的 MLP 判据；GigaBrain 借鉴判定中"不吸收 Transformer 架构"的决策在本文找到理论根据：任务复杂度与架构复杂度匹配
  5. 与 c-xor-nn 六版演进对照：XOR 项目是"MLP 数学原理"的 C 语言手搓版——sigmoid 收敛慢→换激活、MSE→交叉熵雅可比消解、Softmax 多分类——与本笔记 §1.2 的数学层完全对应；六版演进=个人尺度重演了 §1.6 的 FFN 演进逻辑
  6. 与 Karpathy 五级阶梯：五级阶梯从 LLM 到 Graph 的工程化进路中，每一级的基础算子仍是 Transformer+MLP——架构演进（本笔记）是纵向时间轴，五级阶梯是纵向之上的横向系统化
  7. 对自有量化体系的映射：因子挖掘用 MLP（表格数据判据）/ 大模型 API 调用用 Transformer 服务（长文本判据）——选型判断式直接适用
