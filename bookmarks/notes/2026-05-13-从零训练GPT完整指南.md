## 摘要

这是一个从零构建现代 LLM 的交互式教科书，12 章 3900+ 行，教你用纯 PyTorch 手写 LLaMA 3 风格的 GPT 模型。涵盖 BPE 分词、RoPE 位置编码、RMSNorm 归一化、SwiGLU 激活、多头注意力、完整训练管线和推理引擎。每一行代码都带 WHAT+WHY 双重注释，用 5 岁小孩能懂的类比引入概念，再用真实数字推演验证。适合有 Python 基础但零 ML 经验的开发者，CPU 即可跑通 Tiny 配置（17M 参数），GPU 可跑 GPT-2 Scale（151M 参数）。

## 核心内容

### 第 0 章：全局概览

GPT 本质是「下一词预测器」——读了海量文本后，根据上文猜下一个词。现代 GPT 架构的演进路线：GPT-2(2019) → GPT-3(2020) → LLaMA/Mistral/Qwen(2023-2025)。本项目教的是 **LLaMA 3 风格**——公开文档中最先进的架构。

### 第 1 章：环境搭建

依赖仅 6 个包：torch、tiktoken、datasets、numpy、matplotlib、jupyter。支持 CPU 和 GPU，推荐用 venv 隔离环境。

### 第 2 章：BPE 分词

BPE（Byte Pair Encoding）将文本拆分为子词单元。例如 "unbelievably" → "un" + "believ" + "ably"。GPT-2/3/4 都用这个算法，能处理任何文本包括未见过的词和 emoji。vocab_size=50257（GPT-2 标准）。

### 第 3 章：词嵌入

将 token ID 映射为 d_model 维向量。经典例子：king − man + woman ≈ queen。embedding 矩阵是模型可学习参数，训练过程中词向量空间会逐渐捕捉语义关系。

### 第 4 章：RoPE 旋转位置编码

LLaMA 用旋转矩阵编码位置信息，而非 GPT-2 的可学习位置向量。核心思想：通过旋转向量，使 token 间的内积自然包含相对位置信息。θ=10000 是旋转基础频率，每个维度对偶旋转。

### 第 5 章：注意力机制（核心，713 行）

这是全书最关键的章节。自注意力的本质：每个词对序列中所有词计算「关注度权重」，生成该词的新表示 = 所有序列词的加权混合。

8 步计算流程：
1. 输入 X 经 Q/K/V 线性投影得到 Query/Key/Value
2. RoPE 旋转编码注入位置信息
3. Q·K^T 计算注意力分数
4. 除以 √d_k 防止梯度消失（方差归一化）
5. 应用因果 mask（下三角矩阵，禁止看到未来词）
6. Softmax 归一化为概率分布
7. 加权求和 Value
8. 输出投影回 d_model 维

### 第 6 章：Transformer Block

一个完整 Block = Pre-Norm + Multi-Head Attention + 残差连接 + Pre-Norm + SwiGLU FFN + 残差连接。Pre-Norm 比 Post-Norm 训练更稳定（梯度直通高速公路）。RMSNorm 比 LayerNorm 快 15%（不需要均值中心化）。SwiGLU = SiLU(W1·x) ⊙ W2·x 再经 W3 投影，三个权重矩阵的门控机制。

### 第 7 章：完整 GPT 模型

Token Embedding → Dropout → N 个 Transformer Block → Final RMSNorm → LM Head（logits）。151M 参数模型：12 层、768 维、12 头。Weight Tying（embedding 和 LM head 共享权重）省 30% 参数。初始化用 Normal(0, 0.02)，是 GPT 家族标准。

参数量精确计算：
- Token Embedding: 50,257 × 768 = 38.6M
- 每个 Block: 9.4M（Attention 2.4M + SwiGLU 7.1M + RMSNorm 1.5K）
- 12 个 Block: 113.3M
- 总计: ~151.9M（Weight Tying 省了 LM Head 的 38.6M）

### 第 8 章：训练管线

- **损失函数**：交叉熵（-log(P(正确词))），衡量预测与真实的差距
- **优化器**：AdamW（解耦权重衰减），betas=(0.9, 0.95)
- **学习率调度**：Cosine Warmup（先线性升温再余弦衰减）
- **混合精度**：bfloat16 前向+反向，float32 权重更新，2x 速度半内存
- **梯度累积**：小 batch 模拟大 batch（每 N 步更新一次）
- **梯度裁剪**：max_norm=1.0 防止梯度爆炸

### 第 9 章：推理引擎

- **Temperature**：控制随机性（0=确定性，1=正常，>1=更随机）
- **Top-K**：只从概率最高的 K 个词中采样
- **Top-P（Nucleus Sampling）**：只从累积概率达到 P 的词中采样
- **KV Cache**：缓存已计算的 Key/Value，避免重复计算，推理速度提升 100x+

### 第 10-11 章：完整脚本 + 术语表

main.py 437 行自包含脚本。术语表包含架构溯源表（每种技术的来源模型）和参数拆解。

| 组件 | 代码行数 | 核心原理 | 替代的旧方案 |

## 能力边界

- **是教学项目，非生产级**：没有分布式训练、数据并行、模型并行
- **无 RLHF/DPO**：只教预训练，不涉及对齐
- **数据集小**：WikiText-103 仅 5000 篇，真实训练需万亿 token
- **无 Flash Attention / KV Cache 实现**：代码中 generate() 是朴素的逐 token 重计算
- **无 GQA / MQA**：标准 Multi-Head Attention，每头独立 QKV

## 最佳实践

- 先跑通 Tiny 配置确认环境正常，再切大模型
- Ch5 注意力章节至少读 2 遍，这是理解 Transformer 的关键
- 用 Jupyter notebook 交互式学习，比纯读 MD 效果好
