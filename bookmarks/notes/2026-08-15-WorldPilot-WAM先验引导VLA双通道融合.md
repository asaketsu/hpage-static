## 一、内容整理：核心问题与全文脉络

VLA 模型继承 VLM 骨干的语义接地（semantic grounding），在分布内操作任务表现合格。但这个接地建立在**静态图文对**上，而操作是连续、富接触的过程——预训练无法提供"场景在动作下如何演化"的模型：

| VLA 有什么（VLM 继承） | VLA 缺什么（WAM 补充） |
|---|---|
| 图文对齐的语义表征 | 动作条件下的场景演化预测 |
| 指令跟随、任务级泛化 | 接触动力学的内部表征 |
| 静态场景理解 | 轨迹级动作假设（动作→效果的前向模型） |

后果实证：一旦视角、几何、接触容差偏离训练分布，VLA 成功率崩塌（论文实机 OOD 掉 25-50 个百分点）。

视频预训练是天然互补：动作条件场景演化在视频中**构造性存在**，Cosmos Policy / mimic-video / DreamZero 等 WAM 习得的动力学表征可跨本体、跨视觉条件迁移。

## 二、方法：双通道先验路由

"把两个模型并排放一起"不够——关键在**提取什么信号、以什么形式承载、注入 VLA 哪一层**。World Pilot 的回答是两条互补通路：

```
                    ┌─ Latent Steering ─→ 感知层：场景演化 latent 经残差交叉注意力注入 VLM 隐状态
WAM（冻结）─ 先验 ─┤
                    └─ Action Steering ─→ 生成层：预期轨迹作为运动先验（单 token）喂给动作生成器
```

### 2.1 Latent Steering（隐状态转向）

- 从 WAM 提取 **scene-evolution latent**（不解码成未来图像！），通过**残差交叉注意力更新**注入 VLM 感知层隐状态
- 关键设计决策：**路由 latent 而非解码的未来帧**——像素内容携带动作无关细节（纹理/光照/背景/生成伪影），会稀释 latent 直接编码的动力学结构
- 提供的能力：时空动力学预期（spatiotemporal dynamics anticipation）

### 2.2 Action Steering（动作转向）

- WAM 输出的**预期轨迹**（粗动作假设）作为 motion prior 供给动作生成器
- 形式：**单轨迹级先验 token**（消融验证这是最优形式，见下）
- 两个先验来自 WAM 共享编码器的联合训练，结构上天然对齐

### 2.3 训练细节（工程要点）

- **WAM 全程冻结**，梯度只更新 VLA 侧参数（VLM 骨干、动力学编码器、交叉注意力、动作编码器、flow-matching 生成器）
- WAM 当作外部先验模型 → 其前向输出**可预计算缓存**，排除在训练内循环外
- 动作生成用 clean-action 参数化的 flow-matching（等价于速度空间重加权目标），监督目标恒等于专家 chunk，WAM 先验只走条件路径，无需额外先验损失
- 损失：L = E[w(τ)·‖Â−A*‖²]，w(τ)=1/(1−τ)²
- 推理时 VLA 和 WAM 都在线跑，训练/推理先验形状一致，融合行为直接迁移

## 三、核心实验数据

### 3.1 仿真主结果（LIBERO-Plus zero-shot OOD）

| 方法 | Total 成功率 |
|---|---|
| ABot-M0（baseline） | 80.5% |
| + Latent Steering only | 83.7% (+3.2) |
| + Action Steering only | 83.1% (+2.6) |
| **双通道（World Pilot）** | **84.7%（SOTA）** |

结论：两类先验贡献互补信号，超出 VLM 语义表征的信息容量。

### 3.2 最有信息量的消融（三连）

**① 世界先验在 action 后训练之前就已存在**：用纯视频预训练的 Cosmos-Predict（无 action 后训练）+ 仅 Latent Steering：

| Benchmark | ABot-M0 | +Cosmos-Predict latent | 增益 |
|---|---|---|---|
| LIBERO-Plus | 80.5 | 82.6 | +2.1 |
| RoboCasa | — | 62.7 | +8.7 |
| RoboTwin2.0 (clean) | — | 85.3 | +4.1 |

Cosmos-Predict 的预训练数据（VLM 打标的驾驶/操作/人类活动/导航/物理动力学视频）让 scene-evolution latent 在任何 action 适配之前就编码了可迁移动力学结构。Cosmos Policy（action 后训练版）进一步锐化到 83.7%（+1.1），但**先验本身免费存在**。

**② latent 注入 > 解码未来图像**：

| 先验形式 | Total |
|---|---|
| 1/3/5-step latent（不同去噪深度） | 84.5-84.7%（彼此差 0.2pt，稳定） |
| 完全解码的未来图像 | 83.5%（-1.2） |

latent 对去噪深度鲁棒（依赖状态转移线索而非像素级真实感）；解码引入视觉伪影、稀释动力学结构。

**③ 单 token 轨迹先验最强**：

| 动作先验形式 | Total |
|---|---|
| 单轨迹级 token | **84.7%** |
| per-step 编码 tokens | 83.6% |
| flow-matching 初始化自先验 | — |
| 原始轨迹直接当先验 | 83.0% |

单 token 保留先验的"提示"性质，per-step/原始形式把生成钉死在噪声轨迹上，反而限制生成器。

### 3.3 实机：OOD 鲁棒性是最大卖点

平台：同一机械臂 + RGB 输入，对比 π0.5 / ABot-M0 / Cosmos Policy。每任务 1 个 ID 设置 + 2 个 OOD 变体（改外观/几何/可变形状态/位姿），每设置 20 试。每任务 100 条 ID 遥操作示教、matched 优化器下微调 10k 步。

| 方法 | 堆块 ID/色/高 | 折巾 ID/向/新巾 | 果盘 ID/新果/布局 | 盖盖 ID/新物/盖姿 |
|---|---|---|---|---|
| π0.5 | 40/15/0 | 55/25/10 | 35/10/5 | 40/15/5 |
| ABot-M0 | 60/25/10 | 50/20/5 | 65/30/15 | 65/30/15 |
| Cosmos Policy | 65/30/15 | 45/15/10 | 70/35/20 | 60/25/10 |
| **World Pilot** | **70/55/50** | **85/75/70** | **90/75/70** | **80/70/65** |

- **全部 12 个任务设置格第一**
- **World Pilot 的 ID→OOD 掉幅 ≤20pt，baseline 掉 25-50pt**——这是论文的核心卖点：WAM 先验把"OOD 崩塌"压成"OOD 衰减"
- 最严苛的容器盖对齐（需盖沿对齐+完全闭合）：World Pilot ID 80 → OOD 70/65，而 baseline 掉到 10-15

## 四、局限与作者自省（论文原文）

1. **继承 WAM 覆盖度**：测试场景落在 WAM 视频预训练分布外时，双先验都退化、增益缩小
2. **改进不均衡**：LIBERO-Plus 的 Language/Robot/Layout 轴上 World Pilot 落后；实机 OOD 相对 ID 仍掉 10-20pt——先验**减少但未消除** OOD 效应
3. **模块化的代价**：WAM-VLA 只通过动作损失耦合（换来组件可互换：换更强世界模型/换 VLA 骨干都行），但放弃联合训练的先验-策略深度共适应
4. **每步多一次 WAM 前向** → 不适合高频反应控制
5. 后续方向：不确定性感知的先验门控（处理 WAM 覆盖下降）、WAM-VLA 联合共调、先验蒸馏/自适应查询降低逐步开销

## 五、关联分析：对既有认知的增量（与 [[2026-08-14-WAM与VLA分界判据解析]] 的衔接）

| 前篇结论 | 本篇增量证据 |
|---|---|
| WAM=动力学预测、VLA=语义执行，分工明确 | 分工之上存在**单向供血**：WAM latent → VLA 感知层 + WAM 轨迹 → 生成层，融合比并列强（+4.2pt） |
| 视频预训练是世界知识的来源 | Cosmos-Predict 纯视频预训练即有效（+2.1~+8.7），action 后训练只是锐化（+1.1）——"世界先验免费存在" |
| — | **latent > 解码图像**（-1.2pt）：伪影污染动力学信号，验证了 latent space 传递的优越性 |
| — | **先验形式讲究**：单 token > per-step > 原始轨迹——先验是提示不是锚 |

## 六、工程借鉴（可迁移的模式）

1. **冻结专家+可缓存前向**：把大模型当外部先验源，前向预计算缓存排除训练循环——VLA 微调成本 ≈ 原 VLA
2. **残差交叉注意力注入**：外部信号进 Transformer 的低侵入方式（不改主干结构，残差更新保底不劣化）
3. **单 token 先验**：外部信息进生成器的最轻形式，避免约束过强钉死生成
4. **OOD 掉幅作为核心指标**：不只比 ID 成功率，ID→OOD 掉幅（本篇 ≤20 vs baseline 25-50）更能反映鲁棒性本质——评估 VLA 时应双指标并报

## 七、查询拓展：值得跟进的后续线索

- **Cosmos-Predict / Cosmos Policy**（NVIDIA）：本文的世界先验来源——其预训练数据构成与 latent 接口细节
- **V-JEPA 2**（Meta）：非生成式 latent 动力学路线，与 Cosmos（生成式）的先验质量对比
- **ABot-M0**：baseline VLA 的架构细节，理解 +4.2pt 增益的起点
- **不确定性感知先验门控**：作者留的三个后续方向之一——WAM 覆盖度下降时自动衰减先验权重
- **查询方向**：残差交叉注意力注入在 LLM Agent 记忆系统中的对应物（外部知识→隐状态的低侵入融合）

## 六、趋势判断

1. **"WAM 供血 VLA"正在成为具身智能的主融合范式**：World Pilot（latent+轨迹双通道）、Cosmos Policy（WAM 直接出策略）、V-JEPA 2 系（latent 动力学）殊途同归——2026 下半年的竞争焦点从"谁的 VLA 更大"转向"谁的世界先验注入得更聪明"
2. **latent space 传递确立为默认接口**：解码像素→再编码的路线被证伪（-1.2pt），未来跨模型知识迁移会更多走 latent 直连（与 LLM 生态的 KV-cache/adapter 复用同构）
3. **纯视频预训练的"免费先验"红利还在释放**：Cosmos-Predict 未做 action 后训练就 +2.1~+8.7——海量无标注视频的动力学结构迁移是当前性价比最高的能力来源
4. **瓶颈转移**：注入机制（本篇解决）之后，下一瓶颈是 WAM 覆盖度（OOD 场景先验退化）与逐步前向开销——不确定性门控和先验蒸馏是明确的下一步赛道

## 八、归纳总结

World Pilot 用一个干净的实验体系回答了"WAM 与 VLA 如何融合"：**不并排、不联合训练，而是双通道单向供血**——场景演化 latent 经残差交叉注意力进感知层、预期轨迹以单 token 进生成层，WAM 冻结、先验可缓存。三组消融（纯视频先验已有效 / latent 优于解码图像 / 单 token 优于逐帧形式）把设计空间的关键分叉全部钉死，实机 12 格全胜 + OOD 掉幅 ≤20pt 是最有说服力的交付。局限同样清晰：增益受 WAM 覆盖度约束、每步多一次前向限制高频控制、联合共调尚未探索。一句话：**融合的收益是真实的，代价是可控的，接口是 latent 的**——这是对 [[2026-08-14-WAM与VLA分界判据解析]] 分界判据的实证补全。
