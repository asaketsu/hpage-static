# GEN-1.5：具身基础模型的一次示范革命（内容整理与趋势分析）

## 一句话核心

给机器人看 3–12 秒的单次示范，塞进 30 秒上下文窗口，它就能立刻执行这个新任务——**全程零梯度更新、零微调、零训练**。这是官方所知第一个在规模化预训练下**涌现**出物理技能 one-shot 学习能力的模型。

## 内容整理

### 1. 关键数据一览

| 指标 | 数值 | 含义 |
|------|------|------|
| One-shot in-context 成功率 | **59%**（±10%） | 零梯度，仅 3–12 秒单次示范 |
| Few-shot 微调成功率 | **83%**（±9%） | 5 分钟数据 + **10 步**梯度下降 |
| 极端 1 步梯度设定 | **66.5%** | 1 分钟数据采样，开箱即用无调参 |
| 10 步后权重变化 | **<0.15%** | 微调=重组已有知识，非学新表征 |
| 传统机器人微调 | 数万步梯度（高出几个数量级） | 对比基线 |
| 上下文窗口 | 30 秒 | 剩余部分装滚动实时观测 |
| 动作输出频率 | 100 Hz | 多模态输入（视频/语言/本体感受） |
| 预训练时长 | 超过 8 个月，跨 3 个训练阶段 | 持续未见瓶颈 |

### 2. 模型能力清单（六大涌现能力）

1. **One-shot in-context 学习**：单个 3–12 秒示范 → 立刻执行，零训练。官方命名为「**physical prompting（物理提示）**」——语言模型 in-context learning 的具身对应物。
2. **组合泛化**：两段互不相干的示范拼进上下文 → 模型自动串成连续技能，自生成中间动作（重新定位/再抓取/错误恢复）。
3. **零样本 sim-to-real**：纯仿真录的示范可直接提示真机——且预训练数据**一帧仿真都没有**。
4. **人到机器人模仿**：人用自己的手在摄像头前演示 → 机器人用自己的手复现（跨形态鸿沟）。
5. **极少梯度适应**：1–10 步梯度 + 1–5 分钟数据即可微调到新任务（约 10–50 次示范）。
6. **即兴工具使用**：只用刷子微调过的模型，拿到**香蕉会当刷子用**，拿到**簸箕直接铲方块倒碗里**——完全另一套接触序列，零语言引导。

### 3. 官方 GPT-3 类比的完整因果链

```
语言模型侧                          具身模型侧
─────────────                      ─────────────
GPT-3 (2020)                       GEN-1.5 (2026)
one-shot prompting ≈45% 准确率      one-shot physical prompting 59% 成功率
few-shot (100例) ≈65%              few-shot (50示范+10步梯度) 83%
        │                                  │
        └──→ 「不训练就能干新活」成为基础模型的标志能力 ←──┘
```

**为什么能力会涌现？** 官方明确：没有为 in-context learning 做任何专门设计——无架构改动、无元学习内外循环、无辅助损失函数。两个假说：
- 物理观测/动作分布可能具备与语言类似的「突发性（burstiness）」和 **Zipf 结构**（Chan et al. 2022 认为这是 LLM ICL 涌现的数据分布前提）
- 物理劳动天然含重复循环，模型学会了检测并延续模式（同 LLM 处理一般序列）

**反直觉细节**：预训练采样的是随机截取的连续片段，从未见过「示范打包进上下文」这种时间不连续跳变——但物理提示依然工作。

### 4. 发展脉络（Generalist 自家三代）

| 代际 | 时间 | 里程碑 |
|------|------|--------|
| GEN-0 | 9 个月前 | 开始看到可预测的 **scaling law** |
| GEN-1 | 5 个月前 | 后训练可达 99%+ 任务精通；即兴智能初现 |
| GEN-1.5 | 2026-08 | one-shot 零梯度学习涌现 |

微调步数的下降轨迹：**上百步 → 几十步 → 1 分钟数据 1 步梯度 → 0 步（纯上下文）**。团队原话：「我们还看不到这条曲线在哪里收敛到渐近线。」

### 5. 即兴发挥的五个实证案例

| 案例 | 微调内容 | 涌现行为 |
|------|----------|----------|
| 香蕉当刷子 | 只用刷子扫方块 | 拿香蕉执行同样动作 |
| 簸箕新策略 | 同上 | 铲起+倒进碗里（全新接触序列） |
| 障碍物处理 | 只学放方块入碗 | 自行移开盖在碗上的纸，事后还会盖回去 |
| 干扰物清除 | — | 乐高粘指尖 → 用另一只手移除 |
| 双手协同 | 训练只用一只手 | 自发改用双手转罐盖 |
| 整理倾向 | 只学「方块放碗」 | 按颜色/类别给方块分类 |

**规律**：即兴行为随微调梯度步数**减少**而**增强**——轻度适应的模型更贴近预训练先验，可调用更宽的行为库。

## 可学到的点

1. **「physical prompting」是范式级命名**：把 LLM 的 prompt engineering 思想平移到物理世界——示范即提示，上下文即记忆。以后评估任何具身模型，第一问应该是「它支不支持 in-context 示范」。
2. **预训练阈值论**：越过某个预训练规模阈值后，任务适应成本趋近于零——「用极小算力提醒模型一件它本就快要会的事」。这对数据引擎投入的优先级判断是根本性依据。
3. **微调步数是新度量**：从「成功率」到「学会新任务最少需要几步梯度」，评估维度正在切换。10 步梯度 + 权重变化 <0.15% 的表述方式值得借鉴。
4. **即兴=预训练先验的暴露**：微调越轻，即兴越强。这对「微调 vs 纯提示」的工程选型有直接指导意义——重微调会覆盖掉泛化能力。
5. **示范采集可以用仿真替代**：sim-to-real 零样本意味着部分任务不再需要物理采集示范数据，仿真器内部任何手段（脚本策略/RL/遥操作仿真机）皆可。

## 归纳总结

GEN-1.5 的真正贡献不是 59% 这个数字，而是证明了**「one-shot 物理学习」可以从纯预训练中涌现**，不需要元学习等专门机制。它把机器人学习的问题从「如何训练一个新任务」改写为「如何提示一个通用底座」。三条主线收敛于同一结论：

- **数据侧**：8 个月连续预训练、纯真实物理经验（零仿真帧），动作预测误差持续下降无饱和迹象；
- **能力侧**：适应成本单调下降（万步→10步→1步→0步）；
- **应用侧**：与机器人协作的门槛从「专家编程数月」压缩为「任何人做给它看 3 秒」。

局限也明确：任务简单、时程短、one-shot 成功率仅中等、in-context 技能比微调版更脆弱。这是「GPT-3 时刻」而非「GPT-4 时刻」——标志能力出现，离实用还有代差。

## 趋势判断

| 判断 | 依据 | 置信度 |
|------|------|--------|
| 具身模型竞争焦点将从「任务成功率」转向「适应成本」 | 官方全篇以梯度步数/数据分钟数为叙事主轴 | 高 |
| 示范数据生态（录制工具/提示库/组合界面）将成为新赛道 | 「物理提示词工程」拖拽界面已出现，组合提示可拼长时程行为 | 高 |
| scaling law 在物理领域继续成立，数据引擎>算法 tricks | 三代模型连续复利，所有指标同向 | 中高 |
| sim-to-real 论述将被改写 | 预训练零仿真帧却可被仿真 rollout 提示——仿真从「训练工具」变「提示工具」 | 中 |
| 人形/机械手竞争白热化下，「可提示性」(promptability) 或成采购指标 | 官方愿景「任何人都能教机器人」直指部署门槛 | 中 |

**对量化/Agent 领域的横向启示**：LLM Agent 生态已经历同样路径（prompt engineering → few-shot → 微调死亡论）。GEN-1.5 证明这条路在物理世界同样成立——**通用底座+轻适应**压倒**任务专用模型**的剧本正在重演。

## 拓展应用

- **dual-MCU 机器人架构**：ESP32/STM32 端侧无法跑 GEN 级模型，但「物理提示」思想可用——预录制示范序列作为参考轨迹，端侧做闭环纠偏，云端周期性重规划。
- ** servo-arm-control / 6-DOF 机械臂**：传统逆解+轨迹规划管线可对照「即兴纠错」案例（移障碍/双手协同）反思——固定管线在扰动场景的脆弱性正是这类基础模型的切入点。
- **教学示教（zero-g teaching）对照**：Generalist 引用了 1954 Unimate 示教专利与 1970 MIT Copy Demo——70 年后「示教」从物理引导（拖拽手臂）进化为感知提示（视频进上下文），本质都是「做给你看」，但知识载体从关节空间升级到了多模态表示空间。
- **Agent 系统设计**：30 秒上下文 + 100Hz 输出的架构，对 Hermes 这类多模态 Agent 的「记忆-行动」分层有直接参考——滚动观测窗口管理值得借鉴。
