一、内容整理

1.1 项目定位（第一决策：难度分级先拍板）

  • Level A 族内插值：同一拓扑族（某系列支架/接头），参数变化（厚度、孔径、圆角 R、载荷）→ 成熟，一期目标
  • Level B 轻拓扑变体：孔数量/位置增减、筋条布置变化 → 已有文献验证（arXiv 2606.08287 任意孔洞几何 MGN），二期目标
  • Level C 任意新构型零样本：学术前沿，不做

工程红线：训练域外外推不可信且无警告——必须配域判定器 + 保守回退 Abaqus，直接写入架构不可裁剪。

1.2 四条技术路线（组合拳）

  1. B0 标量响应面（GPR/GBDT）：参数+载荷 → 峰值应力，1 周可交付，作为深度学习对照组；Kriging 原生不确定性量化
  2. R1 U-Net 场预测：SDF+载荷向量场+BC mask 多通道图像 → 逐像素 von Mises 云图，双头输出（场+峰值标量），2D 精度极高（文献 von Mises 平均误差 0.5~0.9%）
  3. R2 MeshGraphNets（主力）：网格节点+边特征 → 节点级应力六分量 → 物理推导 von Mises；天然适配非结构网格、3D 可扩展
  4. R3 神经算子（DeepONet/FNO/GINO）：泛化理论最优但门槛高，技术储备

推荐节奏：B0（第 1 周验证需求）→ R1（4~6 周 MVP）→ R2（8~12 周主力）→ R3 储备。

1.3 五阶段实施

Phase 0 数据管道（2 周）——存量 ODB 是最大资产：
- odbAccess 提取节点坐标 + ELEMENT_NODAL 外插平均应力六分量 + 单元连接关系
- 统一 HDF5 格式：nodes/conn/S6/vM/load/bc_mask/params/meta
- 无量纲化铁律：σ/E、F/(E·L²)、几何按特征长度归一
- 两个零成本增强王牌（线性弹性专属）：①叠加原理 σ∝F——每几何只算单位载荷工况，训练时随机线性组合生成无穷载荷样本；②对称镜像翻倍

Phase 1 MVP（4~6 周）：B0 基线 + U-Net 打样 2D 典型件族（接头/耳片/支架类）

Phase 2 GNN 3D（8~12 周）：Encode-Process-Decode 10~15 步 message passing，固定网格拓扑起步

Phase 3 UQ+域回退（4 周）：Deep Ensemble（5 模型）std 作置信度；域判定（参数空间 KDE/马氏距离）+ 三级分级置信（直接采用/人工复核/强制回退）

Phase 4 工具化（4 周）：ONNX → Streamlit 工具或 Abaqus CAE 插件，单次评估 ≤10s，预测记录挂件号/构型基线

1.4 量化验收门禁（M2）

  • 峰值 von Mises 误差 ≤5%（相对 Abaqus 真值，测试集逐样本）
  • 全场相对 L2 误差 ≤8%（族内插值）
  • 峰值位置偏差 ≤2 个单元尺寸
  • 危险侧偏差（预测<真值）：样本占比 ≤5% 且单样本 ≤3%
  • 推理加速比 ≥1000×
  • train/test 必须按参数空间分块留出，禁随机分割（相邻参数样本过近=虚高精度，本领域最常见假 PASS）

二、查询拓展

2.1 MeshGraphNets

DeepMind Pfaff et al. ICLR 2021 提出，Encode-Process-Decode 架构：网格节点携带物理状态，边携带相对几何，经 N 步 message passing 后解码出节点输出。原为瞬态动力学设计，Nature Sci. Reports 2024 已验证其在 time-independent 静力问题（含线弹性固体）上的有效性——本项目正是这个场景。几何泛化的关键经验：用相对特征（相对位移/方向）而非绝对坐标，避免模型记忆位置。

2.2 代理模型四代谱系（领域知识库已蒸馏）

Gen1 Kriging/GPR（小样本+原生 UQ）→ Gen2 Co-Kriging 多保真（高低保真样本联结）→ Gen3 POD 降阶+POD-GPR 非侵入式仿真器（认证成熟度最高的 ROM 路线）→ Gen4 神经算子 DeepONet/FNO（学"函数到函数"映射，泛化本质更优）。本项目 B0=Gen1、R2=图神经网络变体、R3=Gen4。

2.3 ED-324/ARP6983 适航窗口

SAE G-34/EUROCAE WG-114 联合标准，Draft 7（2025-08）完成公开咨询，W 形开发生命周期。首版范围=离线监督 ML——代理模型+数据驱动路线恰在其内；EASA AI Concept Paper Issue 2 的 Level 1（人类增强/AI 增强、人工担责）是本项目自限定位，证据包按其骨架预留接口=低成本适航对齐。

三、归纳总结

3.1 总体架构（两步走）

存量 ODB ──odbAccess──▶ HDF5 数据湖（无量纲化）
                            │
              ┌─────────────┼──────────────┐
              ▼             ▼              ▼
        B0 GBDT/GPR    R1 U-Net(2D)    R2 MeshGraphNets(3D)
        峰值标量        全场云图 MVP     全场主力
              └─────────────┼──────────────┘
                            ▼
                 Deep Ensemble UQ + 域判定器
                            │
              std<阈值→采用  中间→复核  域外/超阈→回退 Abaqus
                            ▼
                 ONNX → Streamlit/CAE 插件（≤10s/次）

3.2 方法论核心

  • 数据先行：M0 门禁（≥100 样本提取成功+完整率 100%）不过不进模型层
  • 物理一致：预测应力六分量再推导 von Mises，优于直接回归标量
  • 安全分层：UQ+域回退是不可裁剪的安全层，"可信才答，不可信闭嘴"
  • 对照纪律：B0 标量基线先行，确认全场云图的增量价值成立再投入深度学习

四、趋势判断

趋势1：FEA 代理从标量响应面走向全场预测

依据：2024-2026 文献主流已从 RSM/Kriging 标量代理转向 GNN/U-Net 场代理；caeassistant 2025 生态综述显示 Abaqus+ML 工程实例集中爆发。

趋势2：适航体系正在给"离线监督 ML"开窗

依据：ED-324/ARP6983 首版范围明确限定离线监督学习；EASA NPA 2025-07 推进航空 AI 可信性规范。窗口期内对齐证据包结构的代理模型项目，合规成本最低。

趋势3：GNN 将成为非结构网格场景的默认选择

依据：MeshGraphNets 衍生工作（任意孔洞几何泛化、3D FEM 应力预测开源实现）密集出现；HF 社区选型共识已把 MeshGraphNet 列为 unstructured mesh 首选 baseline。

趋势4：数据增强与不确定性量化是工程落地分水岭

依据：纯精度竞赛已饱和（误差<1% 屡见），危险侧偏差控制、域外回退、UQ 有效性成为航空等高可靠场景的真正门槛。

五、关联分析

5.1 与气动代理项目的关联

~/uclaw/project/aero-surrogate-pipeline/（OpenVSP→MLP/FNO→优化闭环）与本项目方法论同构：参数化造数→代理训练→加速迭代闭环。训练基础设施（AutoDL 启动模板、DDP 经验）可直接复用；差异在本项目输出是场而非标量向量，需 GNN/U-Net 而非 MLP。

5.2 与航空结构数字孪生研究线的关联

本课题是 2026-10-20 飞机结构设计融入AI科研需求与使用流程策划 与 2026-10-22 面向人工智能的航空结构智能体设计关键技术研究 研究线的第一个可落地子课题：代理层成果可直接进数字孪生残差闭环（实测−预测→参数更新），UQ 层呼应"每层都有 UQ 才可认证"的知识库结论。

六、金句摘录

「偏保守可容忍，偏危险不可接受」——危险侧偏差门禁的设计哲学：ML 预测偏危险侧（低估应力）是适航语境的硬红线。

「训练域外外推不可信且无警告」——领域知识库工程红线，域判定器+保守回退因此不可裁剪。

「先盘点再生成」——存量 ODB 是最大资产，M0 数据管道是一切前提。

七、行动启示

  • 用户提供存量 ODB 件族类型/数量/网格密度分布 → 定 Level A/B 分界与 DOE 方案
  • scripts/extract_odb.py 提取脚本骨架（Abaqus Python 2.7 + odbAccess）
  • scripts/hdf5_schema.py 统一数据格式落盘
  • B0 基线第 1 周出数，作为深度学习对照组
  • 论文孵化对接周计划：载荷叠加增强+危险侧门禁+适航对齐=现成差异化卖点

八、拓展应用推荐

  • 疲劳危险部位筛选：全场应力秒级预测 → 快速定位峰值/应力集中区，替代首轮 Abaqus 粗筛
  • 拓扑优化内循环：优化迭代中用代理替代 FEA 评估，数千候选→top-N 再 Abaqus 复核
  • 损伤容限分析：预测应力场导出峰值位置作为初始裂纹假设位置，加速 IDD 编制
  • 多保真层级：本项目代理作低保真层，与 Co-Kriging 结合降低高保真样本需求（Gen2 思路）
  • 数字孪生实时引擎：代理层直接复用至 SHM 残差闭环（KB 融合闭环框架）

九、指南分析

  • 分级定位先拍板：Level A/B/C 三级定位决定数据规模、路线选择与成功率预期——策划同类项目时"先把泛化边界说清楚"比选模型更重要
  • 量化门禁方法论：每个里程碑必须带数值+口径的出口门禁（如"峰值 ≤5%，测试集逐样本"），只给框架不给数字=不合格
  • 对照纪律：先用最便宜的基线（GBDT 1 周）验证深度学习的增量价值，避免"为了深度学习而深度学习"
  • 反例警示：随机分割数据=虚高精度假 PASS；无量纲化缺失=跨样本不可比；这两个反例都写进了 PLAN 坑表
