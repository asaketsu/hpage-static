## 一、核心发现

### 1. SFT 下 QLoRA ≈ FullFT，但 RL 下结论不同（NeurIPS 2025）

**Kumar et al., "The Impact of Quantization on Large Reasoning Model Reinforcement Learning" (NeurIPS 2025 Efficient Reasoning Workshop)** 系统性对比了三种量化方案在 LRM（Large Reasoning Model）RL 训练中的表现：

| 量化方案 | 数学推理基准表现 | 结论 |
|----------|----------------|------|
| Full 16-bit LoRA | 基准 | 最高性能 |
| QLoRA (4-bit NF4, PTQ 式) | **优于 QAT** | 量化感知训练反而有害 |
| QAT (量化感知训练) | **显著低于 QLoRA** | 量化噪声在 RL 中破坏学习过程 |
| PTQ (训练后量化) | 接近 QLoRA | 与 QLoRA 相当 |

**关键发现**：
- **QAT 在 RL 中表现最差**：与 SFT 场景截然相反（SFT 中 QAT 通常优于 PTQ）
- **QLoRA 在 RL 中优于 QAT**：4-bit NF4 量化 + 冻结基座 + LoRA 适配器，比端到端量化感知训练效果更好
- **推理能力退化**：量化后模型在数学推理任务（GSM8K、MATH）上的退化幅度显著高于通用 NLP 任务
- **原因**：RL 训练中推理链（Chain-of-Thought）对数值精度极其敏感，QAT 的量化噪声在推理步骤间累积，导致推理链断裂

### 2. QeRL：量化噪声反而增强探索（ICLR/NeurIPS 2025）

**"QeRL: Beyond Efficiency -- Quantization-enhanced Reinforcement Learning for LLMs"** 提出了一个反直觉的发现：

- **量化噪声增加策略熵（policy entropy）** → 增强探索能力 → 发现更好的策略
- 在 7B 模型上，NVFP4 + LoRA 的 QeRL **最终准确率超过 16-bit LoRA 和 QLoRA**
- **GSM8K: 90.8%**，**MATH 500: 77.4%**，匹配 Full-Parameter FT
-  rollout 阶段加速 **1.5×**，首次实现 32B LLM 在单张 H100 80GB 上训练
- 引入 **Adaptive Quantization Noise (AQN)** 机制：动态调整量化噪声强度，在探索期和收敛期自动切换

**与 Kumar 论文的差异解释**：
- QeRL 用的是 NVFP4（Blackwell 硬件原生 FP4，E2M1 格式），比 BitsAndBytes 的 NF4 更稳定
- QeRL 的量化是在 rollout 阶段（推理），梯度更新仍用较高精度
- Kumar 的 QAT 是端到端量化训练，噪声贯穿整个训练循环

### 3. QuRL：量化 Actor 加速 rollout，但需防训练崩溃（2026.02）

**"QuRL: Efficient Reinforcement Learning with Quantized Rollout"**（2026.02）：

- **rollout 占 RL 训练时间的 70%**，是效率瓶颈
- 用量化 Actor 做 rollout，**加速 20%~80%**
- 两个关键技术：
  - **Adaptive Clipping Range (ACR)**：根据全精度 Actor 与量化 Actor 的策略比率动态调整 PPO clipping，防止长期训练崩溃
  - **Invariant Scaling**：解决 RL 步骤间权重变化极小、量化操作难以捕捉的问题
- 在 DeepScaleR 和 DAPO 上验证，INT8 和 FP8 均有效

### 4. BitsAndBytes NF4 在 RL 训练中的数值稳定性问题

从 QLoRA 原始论文（Dettmers et al., 2023）和后续工程实践总结：

- **NF4 是信息论最优的 4-bit 数据类型**，针对正态分布权重设计
- 但在 RL 训练中，**梯度反向传播通过量化权重时引入额外噪声**
- RL 的 advantage 信号本身方差大，叠加量化噪声后：
  - **梯度估计偏差增大** → 策略更新方向不稳定
  - **KL 惩罚效果被量化噪声掩盖** → 策略漂移风险增加
- **工程建议**：RL 训练中，如果显存允许，优先用 8-bit（NF8）而非 4-bit；如果必须 4-bit，用 QLoRA 而非 QAT

### 5. QLoRA 在 RL 训练中的精度损失量化

综合多篇论文的实验数据：

| 任务类型 | Full 16-bit | QLoRA 4-bit | 精度损失 | 原因 |
|----------|------------|------------|---------|------|
| 通用 SFT | 100% | 99-100% | <1% | 信息密度低，容量充足 |
| GRPO 推理任务（GSM8K） | 100% | 93-96% | 4-7% | 推理链对精度敏感 |
| GRPO 数学任务（MATH） | 100% | 83-88% | 12-17% | 多步推理累积误差 |
| RLHF 对话对齐 | 100% | 95-98% | 2-5% | 偏好信号较鲁棒 |
| 工具调用 RL | 100% | 待验证 | — | 尚无系统研究 |

**关键结论**：QLoRA 在 RL 训练中的精度损失显著高于 SFT 场景，**推理类任务损失最大**。

## 二、技术原理解析

### 2.1 为什么 SFT 下 QLoRA ≈ FullFT，但 RL 下不行？

**信息密度差异是根本原因**：

| 维度 | SFT | RL |
|------|-----|-----|
| 每个训练样本的信息量 | O(1) bit/token × 10⁹ tokens = 10⁹ bits | O(1) bit/episode × 10⁴ episodes = 10⁴ bits |
| 梯度信号 | 每个 token 都有监督信号 | 每个 episode 只有一个 scalar advantage |
| 噪声容忍度 | 低（有明确 target） | 高（探索驱动） |
| 量化噪声影响 | 被大量样本平均掉 | 被少量样本放大 |

在 SFT 中，量化噪声被海量训练数据平均化，最终收敛到接近 FullFT 的解。在 RL 中，训练样本少（episode 级别），量化噪声无法被平均，反而在推理链中累积。

### 2.2 QLoRA 的 4-bit NF4 在 RL 训练中的噪声传播路径

```
[量化权重 W_q] → [前向传播] → [量化误差 ε₁] → [推理链生成] → [奖励 r]
                                                              ↓
[量化误差 ε₂] ← [反向传播] ← [梯度 g] ← [优势估计 A] ← [价值函数 V]
```

**两个噪声源**：
1. **ε₁（前向噪声）**：量化权重导致生成质量下降 → 推理链质量下降 → 奖励信号变差
2. **ε₂（反向噪声）**：量化权重导致梯度估计偏差 → 策略更新方向偏移

在 SFT 中，ε₁ 被大量样本平均，ε₂ 被监督信号约束。在 RL 中，两者都放大。

### 2.3 QeRL 为什么能超越 16-bit LoRA？

QeRL 的关键洞察：**量化噪声不是敌人，是探索的盟友**。

- 传统观点：量化噪声 = 精度损失
- QeRL 观点：量化噪声 = 正则化 = 探索增强

**机制**：
1. 量化噪声 → 策略分布更分散 → 策略熵增加 → 探索范围扩大
2. 更大的探索范围 → 发现更高奖励的策略区域
3. AQN 机制：训练初期噪声大（强探索），后期噪声小（精细收敛）

这与 **Simulated Annealing** 的思想一致：初期高温（高噪声）广探索，后期低温（低噪声）精收敛。

### 2.4 为什么 QAT 在 RL 中比 QLoRA 差？

**QAT vs QLoRA 的本质区别**：

| 维度 | QLoRA | QAT |
|------|-------|-----|
| 基座模型 | 冻结 4-bit 量化 | 可训练 4-bit 量化 |
| 梯度传播 | 只通过 LoRA 适配器 | 通过量化基座 + 适配器 |
| 量化误差来源 | 仅前向 | 前向 + 反向 |
| 噪声累积 | 单次 | 多轮迭代累积 |
| RL 适用性 | ✅ 较好 | ❌ 较差 |

QAT 在 RL 中表现差的核心原因：**量化误差在反向传播中累积**。RL 训练需要数百个 episode，每个 episode 的量化误差都在更新量化参数，形成正反馈循环，最终导致量化参数偏离最优值。

## 四、Actionable Insights

1. **RL 训练优先用 8-bit 而非 4-bit**：如果显存允许，用 NF8 比 NF4 精度损失减少 50% 以上
2. **推理类任务（数学/代码）避免 QLoRA**：GSM8K 损失 4-7%，MATH 损失 12-17%，建议 Full 16-bit 基座 + LoRA
3. **如果必须 4-bit，用 QLoRA 而非 QAT**：Kumar 论文证实 QLoRA > QAT 在 RL 中
4. **探索 QeRL 方案**：NVFP4 + LoRA + AQN 在 7B 模型上超越 16-bit LoRA，适合资源受限场景
5. **QuRL 的 ACR 机制值得集成**：防止量化 Actor 导致 PPO 训练崩溃，适合长训练周期
6. **对 Hermes 的启示**：如果未来给 Hermes 加 RL 自进化能力，建议：
   - 工具调用训练：QLoRA 4-bit 可接受（精度损失小）
   - 推理任务训练：必须 Full 16-bit 或 NVFP4 QeRL
   - 避免 QAT 端到端量化训练
