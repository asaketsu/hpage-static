## 摘要

扩散模型（Diffusion Model）是当前生成式 AI 领域的主流范式。其核心思想源于热力学扩散过程：通过"逐步加噪→逐步去噪"的双向过程，从纯噪声中生成高质量样本。2020 年 DDPM 论文标志现代扩散模型诞生，此后 Latent Diffusion（Stable Diffusion）、DALL·E、Sora 等产品彻底改变了图像/视频生成领域。

本研究从六大维度展开：核心原理、数学基础、架构演进、关键里程碑、应用场景、实践使用方法。

## 一、核心原理：前向加噪 × 反向去噪

扩散模型的核心是一个优雅的双向过程：

### 1.1 前向过程（Forward Process / 加噪）

一个**固定的马尔可夫链**，在 T 个时间步内逐步向数据添加高斯噪声，直到原始图像变成纯噪声。

单步转移公式：
```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t) · x_{t-1}, β_t · I)
```

- β_t 是第 t 步的噪声方差（noise schedule），通常从 0.0001 线性/余弦增长到 0.02
- 每一步只加一点点噪声，T 通常取 1000

**关键洞察：封闭形式采样**
令 α_t = 1 - β_t，ᾱ_t = ∏(α_s)，可以**直接从 x_0 采样任意时间步 x_t**，无需迭代：
```
q(x_t | x_0) = N(x_t; √ᾱ_t · x_0, (1-ᾱ_t) · I)
```
这意味着训练时可以随机采样任意 t，极大提高效率。

### 1.2 反向过程（Reverse Process / 去噪）

训练一个**神经网络**（通常是 U-Net）来逆转加噪过程：给定 x_t 和时间步 t，预测噪声 ε。

去噪均值：
```
μ_θ(x_t, t) = (1/√α_t) · (x_t - β_t/√(1-ᾱ_t) · ε_θ(x_t, t))
```

**设计选择：预测噪声 ε 而非直接预测 x_0**
这是 DDPM 的关键洞察——预测噪声比预测原图在实践中效果更好，且简化了损失函数。

### 1.3 训练目标

简化的 MSE 损失：
```
L_simple = E_{t, x_0, ε} [ ||ε - ε_θ(√ᾱ_t · x_0 + √(1-ᾱ_t) · ε, t)||² ]
```

训练过程极其简洁：
1. 采样真实图像 x_0
2. 采样随机噪声 ε
3. 采样随机时间步 t
4. 计算加噪后的 x_t
5. 让网络预测噪声 ε_θ(x_t, t)
6. 计算与真实噪声的 MSE 损失

### 1.4 生成流程（推理）

1. 从纯噪声 x_T ~ N(0, I) 开始
2. 从 t=T 到 t=1，迭代应用去噪步骤
3. 每步减去预测的噪声
4. 最终得到清晰图像 x_0

**层次化学习**：不同时间步强迫模型学习不同层次特征——高噪声时捕捉宏观结构（轮廓、构图），低噪声时关注细节（纹理、色彩）。

## 二、架构演进与核心组件

### 2.1 U-Net — 去噪骨干网络

U-Net 最初为医学图像分割设计，因"U"形结构得名。它天然适合去噪任务：

- **编码器**：逐层降采样，捕捉带噪输入的上下文，识别"哪些是信号、哪些是噪声"
- **解码器**：逐层上采样，借助跳跃连接（skip connections）提供的早期特征，重建清晰版本
- **时间嵌入**：通过正弦位置编码 + MLP，将时间步 t 注入每一层，让网络知道"现在噪声有多重"
- **交叉注意力层**：接收文本/条件信息，实现条件生成

**架构演进时间线：**
```
2020: U-Net (DDPM)           — CNN 骨干，组归一化，时间嵌入
2022: U-Net + Attention (SD) — 加入交叉注意力，支持文本条件
2023: DiT (Diffusion Transformer) — 纯 Transformer 骨干
2024: MM-DiT (SD3/FLUX)     — 多模态 DiT，融合文本+图像 patch
```

### 2.2 变分自编码器（VAE）— 潜空间压缩

**问题**：像素空间直接操作高分辨率图像（如 512×512×3 = 786,432 维）计算成本巨大

**解决**：Latent Diffusion Model（LDM）= VAE + Diffusion

```
编码阶段：图像(512×512×3) → VAE编码器 → 潜空间(64×64×4)
扩散过程：在潜空间做前向/反向扩散（维度降低 48 倍！）
解码阶段：潜空间(64×64×4) → VAE解码器 → 图像(512×512×3)
```

**Stable Diffusion 就是 LDM**。这是它能在消费级 GPU 上运行的核心原因。

### 2.3 文本编码器（CLIP Text Encoder）

将用户输入的文本提示（prompt）转换为模型能理解的向量表示：

- CLIP（Controgeneous Language-Image Pre-training）的文本编码器
- 将文本映射到与图像共享的语义空间
- SD1.5 用 CLIP ViT-L/14，SDXL 用双文本编码器（CLIP ViT-L + OpenCLIP ViT-bigG）
- SD3/FLUX 进一步加入 T5-XXL 编码器处理长文本

### 2.4 完整工作流（以 Stable Diffusion 为例）

```
用户输入 prompt："一只可爱的猫咪"
        │
        ▼
   CLIP Text Encoder → text embeddings (77×768)
        │
        ▼
   采样纯噪声 z_T ~ N(0, I)  在潜空间(64×64×4)
        │
        ▼
   U-Net 迭代去噪（20-50步）
   每步：z_t + text embedding → 预测噪声 → z_{t-1}
        │
        ▼
   VAE Decoder → 最终图像 (512×512×3)
```

## 三、发展历程与三大流派

### 3.1 三大理论流派 → SDE 统一框架

| 流派 | 核心思想 | 代表论文 | 时间 |
|------|---------|---------|------|
| **NCSN（Score-Based）** | 学习数据分布的梯度（score function），用 Langevin dynamics 采样 | Song & Ermon, 2019 | 2019 |
| **DDPM** | 离散马尔可夫链的前向加噪/反向去噪，训练噪声预测网络 | Ho et al., 2020 | 2020 |
| **SDE 框架** | 用随机微分方程统一前两种方法——本质上是同一随机过程的不同离散化 | Song et al., 2021 | 2021 |

**SDE 统一洞察**：
- DDPM = 离散化 SDE（方差保持，VP-SDE）
- NCSN = 离散化 SDE（方差爆炸，VE-SDE）
- 概率流 ODE（确定性采样）= DDIM 的理论基础

### 3.2 关键里程碑

| 年份 | 事件 | 影响 |
|------|------|------|
| 2015 | Sohl-Dickstein 提出扩散模型原始思想 | 奠基，但未引起广泛关注 |
| 2019 | NCSN（Score-based） | 首次将分数匹配与多尺度噪声结合 |
| 2020 | DDPM（Ho et al.） | 现代扩散模型里程碑，CIFAR-10 首超 GAN |
| 2021 | SDE 统一框架 | 理论统一；CLIP 引导生成 |
| 2021 | DALL·E（OpenAI） | 首个大规模文生图产品 |
| 2022 | Latent Diffusion / Stable Diffusion | 潜空间扩散，消费级 GPU 可运行，**开源引爆** |
| 2022 | DALL·E 2 + Imagen | 大公司入场 |
| 2022 | eDiff-I（NVIDIA） | 专家噪声集成 |
| 2023 | ControlNet | 结构化条件控制（边缘/深度/姿态），精细可控生成 |
| 2023 | DiT（Peebles & Xie） | Transformer 骨干替代 U-Net |
| 2024 | Sora（OpenAI） | 扩散+Transformer 视频生成 |
| 2024 | SD3 / FLUX.1 | MM-DiT 架构，多模态融合 |
| 2024 | Consistency Models | 单步/少步生成，速度突破 |
| 2025-26 | 持续演进 | 蒸馏加速、视频/3D、边缘部署 |

### 3.3 与其他生成模型对比

| 特性 | Diffusion | GAN | VAE | Flow-based |
|------|-----------|-----|-----|------------|
| 训练稳定性 | 高 | 低（模式崩溃） | 高 | 中 |
| 生成质量 | 极高 | 高但易有伪影 | 较模糊 | 高 |
| 多样性 | 好 | 差（模式崩溃） | 好 | 好 |
| 采样速度 | 慢（迭代） | 快（单步） | 快 | 快 |
| 理论基础 | 似然/分数匹配 | 博弈论 | 变分推断 | 可逆变换 |
| 可控性 | 强（CFG/ControlNet） | 弱 | 中 | 中 |
| 逆问题求解 | 无需额外训练 | 需特定训练 | 不太直接 | 可用 |

**当前趋势**：研究界倾向 Diffusion（质量+多样性），GAN 仍有速度优势，实践中常结合使用（如 GAN 蒸馏加速 Diffusion）。

## 四、关键技术与控制方法

### 4.1 无分类器引导（Classifier-Free Guidance, CFG）

**解决的问题**：无条件生成 → 条件生成，如何让输出更贴合 prompt？

**原理**：
- 模型同时学习条件分布 ε_θ(x_t, c) 和无条件分布 ε_θ(x_t, ∅)
- 推理时放大"条件信号"：
```
ε_guided = ε_uncond + s · (ε_cond - ε_uncond)
```
- s 是引导强度（guidance scale），通常 7-12

**意义**：无需额外训练分类器，极大提升文本-图像一致性。是文生图的关键突破。

### 4.2 ControlNet — 结构化条件控制

**解决的问题**：纯文本控制太粗糙，如何用边缘图/深度图/姿态图精准控制生成？

**原理**：
- 在 U-Net 的每个 block 上挂接一个"零卷积"分支
- 分支输入：结构化条件（Canny 边缘/深度图/OpenPose 姿态等）
- 训练时只训练 ControlNet 分支，冻结原始 U-Net
- 推理时可组合多个 ControlNet

**意义**：从"生成器"变成"创作工具"，精细可控。

### 4.3 快速采样技术

原始 DDPM 需要 1000 步采样 → 太慢。演进：

| 方法 | 步数 | 原理 |
|------|------|------|
| DDIM | 20-50 | 确定性采样，跳步 |
| DPM-Solver | 10-20 | ODE 数值求解器 |
| DPM-Solver++ | 10-15 | 改进版 |
| UniPC | 5-10 | 统一预测-校正 |
| Consistency Models | 1-4 | 蒸馏为单步生成 |
| LCM（Latent Consistency） | 2-8 | 一致性蒸馏 |

### 4.4 LoRA / 微调方法

| 方法 | 可训练参数 | 用途 |
|------|-----------|------|
| 全量微调 | 100% | 风格/领域适配 |
| LoRA | ~1% | 人物/风格/概念注入 |
| Textual Inversion | 极少 | 新概念（几个 token） |
| IP-Adapter | 适配器 | 图像作为条件（图生图） |

```python
from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=torch.float16
).to("cuda")

image = pipe("a cute cat sitting on a windowsill, golden hour").images[0]
image.save("output.png")
```

### 6.2 Prompt 工程技巧

结构化 prompt：
```
[主体], [场景/环境], [光照/氛围], [风格/艺术家], [质量词]
```

示例：
```
正面 prompt:  "a cyberpunk cityscape, neon lights reflecting on wet streets,
               rain, cinematic lighting, by Greg Rutkowski, masterpiece, best quality"
负面 prompt:  "blurry, low quality, deformed, ugly, watermark"
```

关键参数：
- **Steps**（采样步数）：20-50（越多越精细但越慢）
- **CFG Scale**（引导强度）：7-12（越高越贴合 prompt，过高会过饱和）
- **Sampler**：DPM++ 2M Karras（推荐）或 Euler a
- **Seed**：固定种子保证可复现

### 6.5 进阶：从零训练 DDPM

```python
# 简化的 DDPM 训练循环
import torch
import torch.nn as nn

model = UNet()  # 去噪网络
optimizer = torch.optim.Adam(model.parameters(), lr=2e-4)

for x_0 in dataloader:  # 真实图像
    t = torch.randint(0, T, (x_0.shape[0],))  # 随机时间步
    noise = torch.randn_like(x_0)             # 随机噪声
    
    # 前向加噪（封闭形式，一步到位）
    x_t = sqrt_alpha_bar[t] * x_0 + sqrt_one_minus_alpha_bar[t] * noise
    
    # 预测噪声
    pred_noise = model(x_t, t)
    
    # 简化损失
    loss = nn.functional.mse_loss(pred_noise, noise)
    loss.backward()
    optimizer.step()
```

## 七、发展趋势与挑战

### 当前挑战
- **速度瓶颈**：迭代采样是根本性开销，Consistency Models 是方向
- **可控性**：从粗粒度文本 → 细粒度空间/结构/时序控制
- **一致性**：视频生成的时序一致性、多视角一致性
- **成本**：训练成本（SD3 训练费数百万美元）、推理成本

### 前沿方向
- **DiT 架构**：Transformer 替代 U-Net，更好的扩展性
- **一致性模型**：单步生成，接近 GAN 速度
- **视频/3D/4D**：时空扩散模型
- **多模态融合**：文本+图像+音频+3D 统一生成
- **边缘部署**：量化、蒸馏、TinyML 适配
- **物理 AI**：扩散模型用于物理仿真、机器人控制
