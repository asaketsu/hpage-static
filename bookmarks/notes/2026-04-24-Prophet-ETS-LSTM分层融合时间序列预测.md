## 摘要

文章提出「**分解-重建**」思路做时间序列预测：用 Prophet 抓低频趋势+多季节性，用 ETS 做中频平滑+短期外推，用 LSTM 学高频非线性残差。三者加性融合得到最终预测。用 5 年合成数据（含趋势、周/年季节性、假日尖峰、结构渐变）做完整实战演示。

## 核心内容

### 1. 分层建模思想

| 频段 | 比喻 | 方法 | 负责什么 |
|------|------|------|---------|
| 低频 | 低音鼓 | Prophet | 长期趋势 + 多季节性（周/年） + 节假日 |
| 中频 | 节奏 | ETS | 短期平滑 + 局部趋势外推 |
| 高频 | 即兴演奏 | LSTM | 非线性残差、突变、相位漂移 |

### 2. 数学模型

**分解**：`y(t) = T(t) + S_week(t) + S_year(t) + ε(t)`

**Prophet**：`y(t) = g(t) + s(t) + h(t) + ε(t)` — 分段线性/逻辑增长趋势 + 傅里叶季节项 + 节假日效应

**ETS(A,Ad,A)**（含阻尼趋势）：
- 水平：`l_t = α(y_t - s_{t-m}) + (1-α)(l_{t-1} + φb_{t-1})`
- 趋势：`b_t = β(l_t - l_{t-1}) + (1-β)φb_{t-1}`
- 季节：`s_t = γ(y_t - l_t) + (1-γ)s_{t-m}`

**融合**：`ŷ_hybrid = ŷ_prophet + ŷ_ets + ŷ_lstm(resid)`

### 3. 实战流程

1. **生成/准备数据**：5年天粒度，含线性趋势（后期放缓）+ 周季节 + 年季节 + 25个随机假日尖峰 + 渐增噪声
2. **拆分**：前4年训练 → 半年验证 → 半年测试
3. **Prophet 建模**：weekly + yearly seasonality，additive 模式
4. **ETS 建模**：加性 + 阻尼趋势 + 周季节(7)
5. **计算残差**：`resid = y_train - ŷ_prophet_train - ŷ_ets_train`
6. **LSTM 训练**：28天窗口 → 预测下1天残差，2层LSTM(hidden=64)，Adam lr=1e-3，30 epochs
7. **滚动预测**：用训练残差末尾28天作为上下文，逐步滚动预测验证+测试期残差
8. **融合**：三模型预测加性叠加

### 4. 分析工具

- **频谱分析**（periodogram）：确认数据在 1/7 和 1/365 频率有显著能量峰
- **ACF/PACF**：验证残差中仍有相关结构，说明 LSTM 有用武之地
- **误差分布**（KDE）：对比三种模型误差的集中度和长尾

### 5. 评估指标

MAE、RMSE、MAPE 三指标，文章结论：Hybrid 在尖峰和复杂波段更贴近真实值。

### 6. 增强策略

- 权重学习（堆叠）：用线性层/softmax 学习模型权重
- 多特征 LSTM：加入日历特征（周几、月份）、移动平均、滚动标准差
- 节假日明确加入 Prophet
- 异常检测 + 局部再训练（Regime shift）
- 置信区间 + 风险控制

## 借鉴点（可执行）

1. **分解-重建思路适用于我们的量化系统**：Kronos 引擎目前用 5 因子概率模型，可以借鉴「先确定性分解 → 再残差建模」的思路增强预测
2. **LSTM 残差学习可直接用于 A 股**：在 quant-trading 的 kronos_engine.py 基础上，加一层 LSTM 学残差
3. **滚动预测模式**：28天窗口滑动是实用模式，可用于我们的回测引擎
4. **频谱分析**：periodogram 验证周期性，这是数据分析的好习惯，加到 quant_tool.py

## 启发（超越原文）

1. **「分频处理」是时间序列的核心智慧**：不做一把梭，按频段分配最适合的工具——这和信号处理中的滤波器组思想一致
2. **残差 = 信息的金矿**：确定性模型（Prophet+ETS）解释不了的残差，往往藏着最有价值的非线性模式。类比：好的 AI Agent 系统也是先处理规则性任务，把「残差」（异常/边缘case）交给更智能的模块
3. **加性融合优于堆叠的场合**：当各模型负责不同频段时，加性比加权堆叠更稳定——因为不抢同一结构

## 预判

- **趋势**：混合模型在金融时序预测中会成为标配，单一模型（纯 LSTM 或纯 Transformer）难以覆盖所有频段
- **行动**：基于此文章形成项目 `~/uclaw/project/hybrid-timeseries/`，实现完整可运行的混合预测框架，并集成到 quant-trading skill
- **风险**：合成数据和真实 A 股数据差距大（停牌、涨跌停、政策突变），需要额外处理
