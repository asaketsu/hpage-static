# 蒸馏+量化+RL 三联流水线：LLM 后训练范式统一与 Reward-Density 原则

> 2026-05-19 夜学 | 深度 L3 | 前沿研究综合

---

## ① 核心发现

### 1. Sparse-to-Dense Reward Principle（arXiv 2605.12483，Princeton）

这篇论文提出了 **reward-density principle**（奖励密度原则），从根本上重新思考了稀缺标注数据的分配策略：

**核心洞察**：稀疏的序列级奖励（如数学题对/错）应该用于有能力探索的大模型（教师），而密集的 token 级教师奖励应该用于压缩行为到小模型（学生）。

**三阶段流水线**：
- **Stage 1（Teacher-Side Discovery）**：在大型教师模型上用稀疏奖励 RL（如 GRPO）做行为发现
- **Stage 2（Dense Bridge）**：通过两阶段密集蒸馏将教师行为迁移到学生
  - 2a: Forward-KL warmup（教师 rollouts 上）
  - 2b: On-Policy Distillation（学生 rollouts 上）
- **Stage 3（Student-Side Sparse RL）**：仅在此后才对学生做稀疏 RL

**关键数据**：
- 固定 Qwen3-1.7B 部署规模：RL-improved 8B teacher → dense bridge → student = **79.3% MATH**，超过 direct GRPO on student 的 76.5%（+2.8pp）
- Forward-KL warmup + OPD 的组合在 MATH 上始终最强
- 操作原则：**永远不要把稀缺标注数据浪费在准备最不充分的策略上**

### 2. RLAD — RL-Aware Distillation（arXiv 2602.22495）

提出 **Trust Region Ratio Distillation（TRRD）**，将蒸馏与 RL 后训练统一：

**关键创新**：
- 用 PPO/GRPO 风格的 likelihood-ratio 目标替代传统的 teacher-student KL 正则项
- 锚定到 teacher-old-policy mixture，实现 advantage-aware、trust-region-bounded 的蒸馏
- **选择性模仿**：学生只在有利于 RL 目标时才跟随教师

**效果**：在多个逻辑推理和数学 benchmark 上，RLAD 一致优于 offline distillation、标准 GRPO 和 KL-based on-policy distillation

### 3. On-Policy Distillation 统一框架综述（arXiv 2604.00626，Tencent）

首个 OPD（On-Policy Distillation）综合 survey，提出统一理论框架：

**三维度设计空间**：
1. **Feedback Signal**：logit-based（白盒概率）、outcome-based（结果奖励）、self-play（自我对弈）
2. **Teacher Access**：white-box（完整 logits）、black-box（仅输出）、teacher-free（自蒸馏）
3. **Loss Granularity**：token-level、sequence-level、hybrid

**核心理论**：将 OPD 形式化为 **f-divergence minimization** over student-sampled trajectories，建立了 OPD 与 KL-constrained RL 的理论联系。

**关键失败模式**：
- 分布偏移（compounding error）
- 教师覆盖不足
- 负迁移（negative transfer）
- 训练不稳定

### 4. DenseGRPO — 稀疏到密集奖励（ICLR 2026）

将 sparse-to-dense 思想应用到 Flow Matching 模型对齐：

**核心方法**：
- 预测 step-wise reward gain 作为每个去噪步骤的密集奖励
- 基于 ODE 方法在中间清洁图像上应用奖励模型
- 揭示了 GRPO 中统一探索设置与时间变化噪声强度的不匹配问题
- 提出自适应噪声强度 ψ(t) 校准

**意义**：sparse-to-dense 不仅适用于 LLM 文本推理，也适用于生成式模型的 RL 对齐

### 5. DeepSeek-R1 蒸馏范式验证了 Pipeline 的有效性

DeepSeek-R1 的训练流程本身就是三联流水线的工业级验证：
- **Stage 1**：DeepSeek-V3-Base 上大规模 GRPO RL（发现推理能力）
- **Stage 2**：蒸馏到 6 个 Dense 模型（1.5B/7B/8B/14B/32B/70B）
- 蒸馏效果：小模型蒸馏 > 小模型独立 RL（证明了教师 RL 发现 + 蒸馏迁移的优越性）

## ② 技术原理解析

### 2.1 Reward-Density Principle 数学基础

传统做法是在部署模型上直接 GRPO：

```
J_GRPO(θ) = E[{τ_k} ~ π_θ_old] [
  1/K Σ_k 1/|o_k| Σ_t [ρ̂_k,t(θ) Â_k - β D_KL(π_θ || π_ref)]
]
```

其中 Â_k = (r_k - E[r_k]) / std[r_k]，是序列级的稀疏优势。

**问题**：小模型探索能力有限，稀疏奖励的梯度信号太弱。

**Sparse-to-Dense 方案**的 dense bridge 用 token 级密集信号：

```
L_dense_bridge = E_{y~π_S(·|x)} [
  Σ_t D_f(π_T(·|x,y_{<t}) || π_S(·|x,y_{<t}))
]
```

其中 D_f 是 f-divergence（通常是 Forward KL），π_T 是教师，π_S 是学生。

### 2.2 RLAD 的 TRRD 机制

传统 on-policy 蒸馏目标：
```
L_OPD = -E_{y~π_S} [Σ_t log π_T(y_t|x, y_{<t})]
```

RLAD 的 TRRD 替换为：
```
L_TRRD = E_{y~π_S} [Σ_t min(ρ̃_t(θ) · A_t, clip(ρ̃_t(θ), 1-ε, 1+ε) · A_t)]
```

其中 ρ̃_t(θ) = π_θ(y_t|x,y_{<t}) / (α·π_T(y_t|x,y_{<t}) + (1-α)·π_old(y_t|x,y_{<t}))

这是一个混合参考策略（teacher + old policy），使得蒸馏信号与 RL advantage 联动：
- 当教师方向与 RL 目标一致时，模仿强度大
- 当不一致时，trust region 限制防止负迁移

### 2.3 OPD 与 RL 的理论等价性

Survey 的核心理论贡献：On-Policy Distillation 可以等价于 KL-constrained policy optimization。

对于 KL-regularized 目标：
```
max_π E_{y~π}[r(y)] - β·D_KL(π || π_ref)
```

最优策略为：
```
π*(y|x) ∝ π_ref(y|x) · exp(r(y)/β)
```

当 π_ref = π_T（教师）时，上述 KL-constrained RL 等价于用教师作为参考策略的 distillation + RL 联合优化。

### 2.4 三联流水线的最优顺序

综合多篇论文的实验证据：

| 策略 | MATH (1.7B) | 计算成本 | 推荐场景 |
|------|-------------|---------|---------|
| Direct GRPO on student | 76.5% | 低 | 资源极度受限 |
| Teacher RL → Distill | 79.3% | 中 | 标准场景 |
| Teacher RL → Dense Bridge → Student RL | ~80%+ | 高 | 最佳效果 |
| RLAD (unified) | comparable | 中-高 | 需要 RL+KD 联合 |

**关键发现**：先蒸馏再 RL > 先 RL 再蒸馏。因为蒸馏提供了更好的初始化，后续 RL 可以在更高起点上探索。

## ④ Actionable Insights

### 4.1 Hermes Agent 自训练 Pipeline
现有的 Hermes self-improvement loop（evolver skill）可以借鉴 sparse-to-dense 原则：
- 用大模型（如 DeepSeek-V3）做 RL discovery
- 通过 OPD 蒸馏到小模型（如 Qwen3-1.7B）
- 小模型作为日常 Agent 运行

### 4.2 量化部署路径优化
当前量化部署（05-07 学习）的流程：SFT → 量化 → QAD 恢复
优化为：大模型 RL → 蒸馏到目标大小 → 量化 → QAD → 部署（多一个蒸馏阶段，但效果更好）

### 4.3 Multi-Teacher KD + GRPO
OpenReview 上发现 Multi-Teacher KD Augmented GRPO（MTKD-GRPO）论文，将多教师蒸馏直接嵌入 GRPO 目标：
```
J'(θ) = L_GRPO(θ) - β·D_KL(π_θ||π_ref) + λ·Σ_i w_i(s)·D_H(π_Ti||π_θ)
```
可用于 Hermes 的多模型经验融合。

### 4.4 RLKD（AAAI 2026）推理结构蒸馏
RLKD 用 RL 蒸馏推理链的隐式多分支结构（Generative Structure Reward Model），而非单纯模仿输出。比 standard KD 更适合推理任务的迁移。
