微信公众号文章抓取完全指南

猫仔实际使用的公众号文章提取方案，从原理到实操。

一、为什么公众号文章这么难抓？

微信公众号 (mp.weixin.qq.com) 有三层反爬机制：

用户请求 → 微信服务器
              ├── 1. User-Agent 检测 → 非微信浏览器直接拦截
              ├── 2. 验证码弹窗 → 频繁访问触发滑块/点选验证
              └── 3. 动态渲染 → 正文靠 JS 加载，静态抓取拿不到
常规方法 结果 原因
curl / requests ❌ 空内容或验证码 UA 检测 + JS 渲染
web_extract (Jina/Firecrawl) ❌ 被拦截 走的正常抓取通道
browser 自动化 ❌ 弹验证码 频繁访问触发人机验证
搜索引擎缓存 ❌ 大概率无缓存 微信屏蔽了搜索引擎索引
手动复制粘贴 ✅ 但低效 依赖人工

结论：需要一个"中间人"来绕过微信的反爬检测。

二、Tavily Extract API — 核心方案

2.1 Tavily 是什么

Tavily 是专为 AI Agent 设计的搜索和提取 API，其 Extract 端点能在服务端渲染页面、绕过反爬机制、返回结构化内容。

2.2 为什么它能绕过微信

你的服务器 → Tavily 服务器（云端 IP 池 + 浏览器集群）→ 微信服务器
                                     ↑
                        这里有：代理轮换、UA 伪装、验证码自动处理

Tavily 的服务端：
- 维护大量代理 IP，每个请求换 IP
- 模拟真实浏览器环境（完整 Chrome 渲染）
- 自带验证码处理能力
- 返回干净的 Markdown 正文

2.3 API 详情

项目 说明
端点 https://api.tavily.com/extract
方法 POST
认证 API Key 放在请求体 JSON 中
并发 一次最多 5 个 URL
响应时间 7-15 秒/篇
返回格式 JSON，正文在 raw_content 字段（Markdown）
免费额度 有限（具体看套餐），不要批量滥用

2.4 申请 API Key

  1. 访问 https://tavily.com 注册账号
  2. 进入 Dashboard → API Keys
  3. 创建 Key，复制
  4. 存入 ~/.hermes/.env：
TAVILY_API_KEY=tvly-xxxxxxxxxxxxxxxxxx

三、完整抓取代码

3.1 单篇文章抓取

import json
from hermes_tools import terminal

def extract_wechat_article(url: str) -> dict:
    """抓取微信公众号文章，返回 {title, content, length}"""

    # Step 1: 从 .env 读取 API Key 并调用 Tavily
    result = terminal(f'''curl -s -X POST "https://api.tavily.com/extract" \
      -H "Content-Type: application/json" \
      -d '{{"urls": ["{url}"], "api_key": "'$(grep TAVILY_API_KEY ~/.hermes/.env | cut -d= -f2)'"}}'
    ''', timeout=30)

    # Step 2: 解析响应
    data = json.loads(result["output"])

    if not data.get("results") or len(data["results"]) == 0:
        raise Exception(f"抓取失败: {data}")

    article = data["results"][0]

    # Step 3: 提取字段
    content = article.get("raw_content", "")  # Markdown 正文
    title = article.get("title", "")          # 可能为 null

    # title 经常返回 null，从正文第一行提取
    if not title and content.startswith("# "):
        title = content.split("\n")[0].replace("# ", "").strip()

    return {
        "title": title,
        "content": content,
        "length": len(content)
    }


# 使用示例
article = extract_wechat_article("https://mp.weixin.qq.com/s/Ny_TEIIzryV16DbrUQzp8g")
print(f"标题: {article['title']}")
print(f"字数: {article['length']}")
print(article['content'][:500])

3.2 批量抓取（最多 5 篇）

def extract_wechat_batch(urls: list) -> list:
    """批量抓取，一次最多 5 篇"""

    if len(urls) > 5:
        raise Exception("单次最多 5 个 URL")

    url_json = json.dumps(urls)

    result = terminal(f'''curl -s -X POST "https://api.tavily.com/extract" \
      -H "Content-Type: application/json" \
      -d '{{"urls": {url_json}, "api_key": "'$(grep TAVILY_API_KEY ~/.hermes/.env | cut -d= -f2)'"}}'
    ''', timeout=60)

    data = json.loads(result["output"])
    articles = []

    for item in data.get("results", []):
        content = item.get("raw_content", "")
        title = item.get("title", "")
        if not title and content.startswith("# "):
            title = content.split("\n")[0].replace("# ", "").strip()
        articles.append({"title": title, "content": content, "url": item.get("url", "")})

    return articles

五、内容清洗

raw_content 末尾通常包含以下垃圾文本，需要清洗：

预览时标签不可点

Scan to Follow

继续滑动看下一个

{公众号名}

[Got It](javascript:;)

Scan with Weixin to use this Mini Program

[Cancel](javascript:void(0)) [Allow](javascript:void(0))

微信扫一扫可打开此内容，使用完整服务

: ， ， ， .   Video Mini Program Like ，轻点两下取消赞 Wow ...

清洗脚本

import re

def clean_wechat_content(raw: str) -> str:
    """清洗微信文章尾部垃圾文本"""

    # 常见垃圾文本的起始标记（按出现顺序，取最早的那个截断）
    trash_markers = [
        "预览时标签不可点",
        "Scan to Follow",
        "继续滑动看下一个",
        "Scan with Weixin",
        "微信扫一扫可打开",
        "[Got It]",
        "[Cancel](javascript:",
    ]

    cut_pos = len(raw)
    for marker in trash_markers:
        pos = raw.find(marker)
        if pos > 0 and pos < cut_pos:
            cut_pos = pos

    content = raw[:cut_pos].rstrip()

    # 去除末尾 --- 分隔线
    content = re.sub(r'\n---\s*$', '', content)

    return content

八、局限性与替代方案

当前方案局限

局限 影响 解决方案
图片无法获取 图片类文章体验差 browser 截图或手动保存
API 有配额 批量抓取受限 控制频率，优先抓高价值文章
title 经常为 null 需额外提取 从正文 # 标题 行提取
视频/音频不返回 多媒体内容丢失 无解，需原文查看
部分删除文章失败 已被作者删除 无法恢复
