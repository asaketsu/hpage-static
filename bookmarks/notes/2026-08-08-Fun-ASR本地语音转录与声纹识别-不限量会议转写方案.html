一句话定义

基于 Fun-ASR 的本地不限量语音转录方案——语音转文本 + 说话人分离（speaker diarization）+ 声纹识别自动标注发言人 + 大模型文本整理。声纹库越用越精准，形成正向循环。完全本地运行，替代飞书妙记的分钟限制。

完整原文核心内容

转录流程 Pipeline

1. 启动电脑录音
      ↓
2. Fun-ASR 转录文本（区分说话人 speaker 0, speaker 1...）
      ↓
3. 大模型文本整理：
   - 按对话主题聚合 + 对话轮次呈现
   - 还原对话真实信息
   - 生成 Final 文稿 + 摘要
      ↓
4. 说话人映射表（spk_id ↔ display_name）
   - 声纹识别自动建议 suggested_name + 匹配度 score
   - 人工确认/修正
   - 回灌声纹库（越用越准）

成熟期

多场景语料交叉标注后，系统对音色特征越来越熟悉，不同会议中都能稳定识别，score 基本达到 0.7-0.8。

结合最新研究与技术变化

1. 与 LuxTTS 的关联

LuxTTS（Jetson 上的语音克隆）和 Fun-ASR 的声纹识别是同一技术栈的两个方向——LuxTTS 从文本到语音（合成），Fun-ASR 从语音到文本+身份（识别）。两者的声纹特征提取技术是互通的。

2. 与 Whisper Skill 的关联

Hermes 有 whisper Skill（OpenAI 语音识别），但 Whisper 只做语音转文本，不做说话人分离和声纹识别。Fun-ASR 在中文场景下更强（专门优化中文识别），且自带说话人分离+声纹库。

3. 与本地 AI 七层堆栈的关联

Fun-ASR 对应七层堆栈中的：
- 模型层：语音识别模型（ASR + 说话人分离 + 声纹识别）
- 记忆层：声纹库（可累积可审计的成长性记忆）
- 工作流层：录音→转录→整理→标注→回灌的闭环

4. 与数字人口播 Rachel Skill 的关联

Rachel 用 MiniMax 做声音克隆（voice clone），Fun-ASR 做声纹识别（voice identification）。一个是"从声纹特征生成语音"，另一个是"从语音提取声纹特征匹配身份"。

5. 与 Hermes STT 的关联

Hermes 的 STT 目前用 faster-whisper 做语音转文本。Fun-ASR 可以作为升级方案——增加说话人分离和声纹识别，让 Hermes 处理多人对话场景时知道"谁在说什么"。

趋势判断

  1. 本地语音转录正在替代云端服务——不限量+隐私+声纹成长性是核心优势
  2. 声纹识别从"极贵极难"变为"人人可用"——开源 + AI 普惠让技术平权
  3. 声纹库的成长性是核心壁垒——越用越准形成正向循环，类似个人知识库的复利效应
  4. 说话人身份是语音转录的关键信息——"不知道谁在说话，转写再准有什么用"
  5. Fun-ASR 在中文 ASR 领域的竞争力——专门优化中文，且自带说话人分离+声纹
