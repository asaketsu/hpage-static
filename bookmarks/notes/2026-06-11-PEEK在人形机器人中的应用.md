# PEEK 在人形机器人中的应用：材料选型与工程实践

> PEEK（聚醚醚酮）在人形机器人中的定位：不是"塑料版钢材"，而是在小型、耐磨、低噪音、需要绝缘或轻量化的关键位置，提供比普通塑料更能扛工况、又比金属更轻的工程选择。

---

## 一、PEEK 材料概览

**全称**：polyether ether ketone（聚醚醚酮），高性能热塑性工程塑料（特种/超级工程塑料）

| 参数 | 值 |
|------|-----|
| 熔点 | ~340℃ |
| 长期使用温度 | 250~260℃ |
| 密度 | ~1.3 g/cm³（远低于金属） |
| 特性 | 耐磨、耐化学腐蚀、尺寸稳定、电绝缘、机械强度好 |

### 牌号分类

| 牌号类型 | 增强方向 |
|---------|---------|
| 未增强 PEEK | 基准性能 |
| 玻纤增强 PEEK | 刚度 + 尺寸稳定性 |
| 碳纤维增强 PEEK | 强度 + 刚度 + 耐磨性 |
| 耐磨改性 PEEK | 降低摩擦系数 |
| 导电改性 PEEK | 改善静电问题 |

> 选型先看零件载荷、工作温度、摩擦条件、绝缘要求、批量一致性和整机成本，而不是先看材料档次。

---

## 二、机器人为什么需要塑料件（而非全金属）

### 金属过量的三大问题

| 问题 | 连锁反应 |
|------|---------|
| **重量** | 增重 → 关节扭矩需求↑ → 电池续航↓ → 整机惯量↑ → 控制难度↑ |
| **摩擦噪音** | 金属间接触对润滑、表面处理、装配精度要求高；做不好 → 磨损、异响、精度漂移 |
| **绝缘** | 电池、驱动器、控制板、编码器、传感器、线束需要电气隔离 |

**关键洞察**：手腕、灵巧手、小型执行器中，几克/几十克的差异会被多关节结构放大。末端减重收益 > 躯干同等减重。

## 三、PEEK 在人形机器人中的候选位置

### 3.1 关节模组内的小型辅助件

| 位置 | 适用性 |
|------|--------|
| 低/中载荷的小型齿轮、轴套、衬套、滑动摩擦件 | ✅ PEEK 适用 |
| **高载荷关节（髋、膝、踝、肩）核心承载传动件** | ❌ 不能直接替代金属 |

> PEEK 在关节模组中更常见的位置是小型辅助件，而不是高载荷核心承载件。

### 3.2 灵巧手里的小型传动件

手指内部：小型关节、连杆、腱绳、滑轮、齿轮、传感器、线束、结构支撑件

**PEEK 可用于**：部分小齿轮、滑轮、轴套、线缆导向件、绝缘支撑件

**影响**：手指动作顺滑程度、噪音、维护周期

### 3.3 轴承保持架、垫片、隔套等内部小件

单个看简单，但影响长期稳定运行：
- 选材不当 → 磨损加快 → 间隙变大 → 噪音增加 → 定位精度下降

**验证清单**：接触材料、表面粗糙度、载荷、速度、润滑条件、温度、粉尘环境

### 3.4 电气绝缘件和传感器周边结构

**PEEK 可用于**：绝缘支架、连接器结构件、线束固定件、传感器安装座、电子模块周边支撑件

同时承担机械支撑 + 电气安全。

## 四、PEEK 解决的五大工程问题

| 问题 | 工程影响 |
|------|---------|
| **轻量化** | 降低关节负担、电机/减速器规格、提升续航 |
| **耐磨** | 齿轮啮合、轴套旋转、导向件滑动等长期运行 |
| **低噪音** | 服务机器人进入办公/商场/医院/家庭的必要指标 |
| **绝缘** | 连接器、支架、传感器周边的电气隔离 |
| **尺寸稳定** | 吸水率低，防止间隙、噪音、定位误差、传感器读数漂移 |

> 耐磨不能只看材料名称。接触材料、表面粗糙度、载荷、速度、润滑方式、温度和粉尘环境都会改变结果。材料参数表只能给初筛依据，进入样机前还要做真实工况测试。

---

## 五、成本结构三层分析

| 成本层 | 内容 |
|--------|------|
| **原材料** | 解决高温、高磨损、耐腐蚀、高可靠性、轻量化、精密应用，成本远高于常见工程塑料 |
| **加工工艺** | 熔点高 → 注塑、挤出、机加工、热处理、模具设计、成型收缩控制、结晶度控制均更复杂 |
| **改性与验证** | 改性改变加工窗口、良率和检测要求；进入机器人后需做载荷、寿命、温升、噪音、装配一致性、环境适应性验证 |

> PEEK 属于非常昂贵的一类高性能工程塑料，适合在关键位置少量使用，而不是大面积堆料。

## 六、三大使用约束

### 约束 1：成本

若尼龙、PPS、POM、铝合金等常规材料已满足要求，PEEK 增加的费用难以摊回。

### 约束 2：承载限制

PEEK 不是"塑料版钢材"：
- 主承力结构、高冲击位置、高载荷传动部位 → 金属材料和复合材料更稳
- 髋/膝/踝关节核心承载件需经强度、刚度、疲劳和寿命验证

### 约束 3：长期蠕变风险

长期预紧、振动、温升、交变载荷下形状和间隙可能变化——问题往往在几百/几千小时运行后慢慢出现。

### 加工与装配挑战

- 能打样 ≠ 能量产
- 精密小齿轮、薄壁结构件、复杂异形件对尺寸精度和批量一致性要求高
- 材料、结构设计、加工工艺、系统验证任一环不稳定 → 装配间隙、传动噪音、寿命问题

## 七、机器人材料体系分工

| 部位 | 材料选择 |
|------|---------|
| 主承力结构 | 铝合金、钢、钛合金、镁合金、碳纤维复合材料 |
| 高载荷传动件 | 高强度金属 + 成熟热处理工艺 |
| 灵巧手/小型关节 | 轻量化、耐磨、低摩擦、低噪音材料（PEEK 等） |
| 电气系统 | 绝缘、阻燃、耐热、尺寸稳定材料 |
| 外壳/覆盖件 | 重量、质感、耐冲击、成本平衡 |

### 内部小件的隐性影响

| 小件选错 | 连锁后果 |
|----------|---------|
| 轴套选错 | 磨损加快 |
| 导向件设计不好 | 线缆寿命下降 |
| 绝缘支架不可靠 | 电气风险 |
| 小齿轮噪音大 | 整机体验差 |
| 材料加工不稳定 | 批量装配一致性差 |

> 机器人从"能动起来"走到"能长期稳定工作"，材料工程的重要性明显上升。几千小时静音运行、反复启停、跌倒冲击、温升、灰尘和维护不足条件下的稳定性会占更大权重。

## 八、工程选材核心原则

> **用对位置，它可以帮助机器人减重、耐磨、降噪、绝缘和提升稳定性；用错位置，它只是昂贵但没有必要的堆料。工程选材看匹配程度，材料越贵并不等于方案越好。**

### 选材决策流程

```
1. 明确零件工况：载荷、温度、摩擦、绝缘、精度、批量
2. 先筛常规材料：尼龙/POM/PPS/铝合金是否够用？
3. 不够 → 考虑 PEEK（哪种牌号？）
4. 样件测试 → 真实工况验证
5. 小批试产 → 加工一致性验证
6. 定型 → 锁定材料批次和工艺参数
```
