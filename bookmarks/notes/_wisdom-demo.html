人文哲思 · Wisdom Theme

配色与字体

正文使用 EB Garamond + Crimson Pro + Noto Serif SC 三层衬线组合。紫藤色系从深紫 #7c5cbf 渐变到淡紫 #b892d6。

引用文字使用 Playfair Display 大号引号装饰，背景渐变填充，斜体排版。这是一个有书卷气的引用块。

装饰层次

三级标题带圆点标记

  • h1 渐变文字 + 双层装饰线 + EB Garamond 字体
  • h2 左侧发光竖条 + 底部渐隐线
  • h3 左侧圆点标记
  • blockquote 悬浮卡片 + 装饰引号
  • code 药丸胶囊样式
  • strong 渐变文字
  • hr 菱形居中装饰
  • ul 自定义圆点带发光
