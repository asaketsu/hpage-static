SSGM — 进化型 Agent 记忆的治理框架

来源：Governing Evolving Memory in LLM Agents: Risks, Mechanisms, and the Stability and Safety Governed Memory (SSGM) Framework (arXiv:2603.11768, 2026-03)
定位：概念性治理架构。核心主张：记忆进化必须与记忆治理解耦——无治理的自进化记忆错误是累积且持久的（静态 RAG 的错误只影响单次检索，进化记忆的错误会复利）。

生成日期 2026-10-04

核心发现

1. 进化记忆的三接口失效环

自进化记忆引入了静态 RAG 没有的反馈回路，错误在三个接口累积：

输入摄取（中毒）→ 记忆固化（漂移）→ 记忆检索（幻觉）→ 反哺输入…

2. 记忆漂移不是一种病，是三种

漂移类型 机制 典型症状
语义漂移 迭代摘要的有损压缩 "喜欢微辣"经反复重写→"爱吃变态辣"——轻度偏好被逐级强化成具体违规
过程漂移 次优工作流被强化固化 学会绕远路的 API 调用方式后固化进程序记忆，堵死未来优化
目标漂移 交互偏差累积致对齐偏移 长期角色扮演偏离原始指令

漂移的形式化：D(m_t, L) = 1 − cos(φ(m_t), φ(L))，当前记忆与不可变原始账本 L 的嵌入距离。用不可变账本锚定可变记忆的失真上界。

3. 记忆管理 = POMDP，可用 RL 优化

把 add/update/delete/retrieve 形式化为原子动作空间，以长期任务回报为目标优化记忆策略（Memory-R1 用 PPO，MemAgent 用 GRPO 处理长期收益稀疏）。核心权衡：一次高成本写入若大幅改善未来检索，仍是优的。

4. SSGM 四设计原则

  1. 固化前校验（Write Validation Gate）：记忆增量必须过真值维护系统（TMS）——检索既有核心事实做 NLI 矛盾检查，矛盾即拒绝，阻断幻觉级联
  2. 时间与溯源接地（Read Filtering Gate）：读取时双重过滤——密码学溯源（防对抗注入）+ Weibull 认知衰减函数（低于动态相关性阈值的旧记忆剪枝，不进上下文）
  3. 访问域限定检索：ACL 防跨会话/跨用户泄漏；多智能体全连接拓扑最大化泄漏面
  4. 可逆调和：可变活跃图 + 不可变情景账本双基底——周期性调和把失真锚回真值

5. Weibull 衰减优于指数衰减

R(t) = exp(−(t/λ)^k)，形状参数 k 可表达"早期快衰/延迟遗忘"两种域特征，比单指数更通用。SSGM 中相关性低于阈值 τ 的记忆项被剪枝或归档。

对 Hermes 记忆系统的对照诊断

SSGM 风险 Hermes 现状 评估
语义漂移（迭代摘要失真） MEMORY.md 已 99% 满，反复压缩重写 § 条目 高风险——每次精练都是有损压缩，§ 条目越压越短正是漂移温床
过程漂移（次优工作流固化） skill 体系有 skill-review/健康度分层 中风险，已有部分治理
记忆中毒（指令注入入库） skill-vetter/skill-ab-testing 存在 中风险，写入侧无 NLI 校验
时间性过时 § 条目无时间衰减，09 月条目与 10 月条目同权 中风险——旧实验结论（已判死的 PASS 记录）可能被再次引用
检索延迟/索引膨胀 session DB FTS5 + memorygraph 低风险

具体改进建议（按 ROI 排序）：

  1. 不可变原始账本：MEMORY.md 的 § 条目压缩时，原始事实同步落一份到不可变归档（如 yearly-ledger.md），漂移可用余弦距离审计——治"引用历史 PASS 前忘核对是否已判死"的旧病
  2. § 条目加时效标注：每条 § 头部加 (MMDD) 已有，但缺"已被判死/已被取代"状态位——被新实验推翻的结论应标记而非删除，防止旧结论复活
  3. 写入侧 NLI 矛盾检查：memory-write skill 增加"与既有核心条目矛盾→拒绝并报告"步骤，替代无条件写入
  4. Weibull 衰减用于 memorygraph：get_related_memories 检索时按 R(t) 加权，旧实验数据自动降权
