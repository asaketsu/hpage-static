一句话总纲

sim2real 差距的主导项是执行器动力学建模误差——用"固定基座 chirp 激振 + CMA-ES 参数辨识 + 物理单位能量奖励"替代大范围 domain randomization，仅 4 项 reward、约 49 个可解释参数，即可在 13 台足式机器人上零样本迁移，ANYmal 全程运输成本（CoT）降低 32%。

一、内容整理

1.1 问题定位：为什么仿真策略上真机就拉胯

论文开篇直指两个行业痛点：

痛点 现状 后果
执行器建模粗糙 电机电气损耗/机械损耗常不被建模 sim2real 差距大，直接吃续航和负载
奖励函数膨胀 主流控制器 10+ 个手调 reward 项（Lee 2020 / Miki 2022 / Rudin 2022） 调参靠专家直觉，观察真机偏差→反复改 reward 的无结构循环

关键因果链：建模误差↑ → sim2real gap↑ → 被迫堆 reward 项/堆 randomization → reward 与物理效率脱钩 → 真机效率差。

1.2 PACE 三阶段管线

① 数据采集（真机）          ② 仿真器对齐               ③ 策略训练与部署
固定基座 + chirp 激振   →   CMA-ES 进化参数辨识    →   盲 locomotion RL
20-60s/序列，无接触         4096 并行环境              zero-shot 上机
关节位置指令级回放           encoder-only 数据          PPO + 四项 reward

①固定基座激振采集（Section 2.1 精髓）：
- chirp 信号从最低频扫到最高频，施加在关节位置目标层，由 PD 控制器跟踪——真机与仿真器被同一条参考轨迹驱动，而非自由动态演化，彻底消除相位漂移累积，让直接轨迹匹配成为适定问题
- 采样率 400Hz~10kHz；对称腿同步指令抵消净基座力（ANYmal/Minimal 两个对称面，Tytan 一个）
- 无任何接触（含腿间）：站立相中基座惯量比腿/传动惯量高 1-2 个数量级，空中数据才能隔离腿/传动动力学
- 激励带宽目标：f_policy/2（Nyquist）；达不到则至少覆盖控制器运动最高频率的 2 倍（1 m/s 行走 ≈ 1Hz → 激励 ≥2Hz；ANYmal 结构限 2Hz，Tytan/Minimal 可到 10Hz）
- PD 增益故意取低：增益抬高闭环极点频率 → 超出可激振带宽 → 辨识质量反而下降（实测高增益无改善）

②CMA-ES 参数辨识（Section 2.2）：
- 参数向量极简且物理可解释：p = [Ia（每关节电枢惯量）, d（黏性阻尼）, τf（库仑摩擦）, q̃b（关节偏置）, Td（全局指令延迟）] ∈ R^(4n+1)，约 49 维
- 闭环单关节模型：Ia·q̈ + d·q̇ = sat(Pτ(q̂−q+q̃b) − Dτ·q̇ + τcomp) + τf
- 损失 = 时间平均关节位置 MSE；4096 并行环境同时回放同一指令轨迹，CMA-ES 在种群上优化
- 固件补偿（cogging 补偿/摩擦观测器等）不显式建模——其净效应被拟合参数隐式吸收；电流环/转矩环按单位增益近似（带宽远超激励频段）
- 饱和不作为自由参数：用厂商规格+安全限界作为已知确定性非线性，在仿真与真机同样强制施加
- 选 CMA-ES 的理由：目标非凸、含摩擦/饱和/延迟等非光滑效应、无需对整个硬件匹配仿真管线求梯度

③四项 reward 训练（Section 2.3.3）：

项 角色
速度跟踪 任务性能
能量消耗（物理单位 J） 物理效率——PMSM 第一性原理损耗（电气+机械）
碰撞避免 结构安全
落足速度 防冲击步态

能量项以焦耳为单位是点睛之笔：避免任意 reward 缩放，同一系数可跨机器人形态复用无需重调——这是"减少 robot-specific 调参"主张的物理根基。

二、查询拓展：对 DUCK-Pi_5 的直接适用性

背景对照：我方训练环境按官方 1604.6g 标定，真机装配 1181g（差 26%+），BOM 为 STS3025 无刷舵机 ×8（12V，额定 1.5A/堵转 4.4A）。这正是 PACE 要解决的"动态参数不匹配"问题。

PACE 方法 DUCK-Pi_5 可操作映射 成本
固定基座 chirp 激振 鸭身夹持固定，腿悬空，8 关节位置指令扫频回放，log 编码器反馈 低：只需一个夹具 + 现有 servo 驱动代码
CMA-ES 辨识 p=[Ia,d,τf,q̃b,Td] 在 MuJoCo 里回放同指令，cmaes pip 包 4096 并行环境拟合（Jetson 上 CPU 辨识可跑，样本量小） 低：辨识一次，数分钟级
关节偏置 q̃b 舵机装配公差/编码器零位偏移的显式建模—— ducks 组装误差真实存在 直接可用
指令延迟 Td UART 总线 15 舵机 50Hz 轮询延迟 + 舵机内部环延迟，可整体辨识 直接可用
能量 reward（J 单位） STS3025 铜损 I²R + 机械损耗写入 reward，替代纯 torque² 惩罚 中：需从规格书提取相电阻
低 PD 增益辨识 舵机内部 PD 不可改——退化为辨识等效闭环极点，同样可行 注意点

边界诚实声明：STS3025 是带内部控制环的串行总线舵机（位置指令接口），非裸 PMSM+FOC——不能照搬电流环单位增益假设，应把"舵机内部固件+控制环"整体当作黑箱传动，在位置指令→位置响应层面做端到端辨识（PACE 的 joint-space end-to-end 抽象恰好支持这种用法，q̃b 和 Td 就是为此设计的吸收项）。

与现有引擎的关系：duck_engine_v5 已有顺序队列+双口径评测；辨识模块可作为第 0 阶段插入（train 前先 align），产出 identified_params.json 注入 MuJoCo model。

三、归纳总结

  1. Sim2real 的第一性答案是对齐而非鲁棒：domain randomization 是"让策略对一切参数鲁棒"，系统辨识是"让仿真器就是真机"——后者样本效率高且 reward 不必为鲁棒性付性能税。
  2. 数据采集协议决定辨识上限：位置指令级回放（开环参考）> 闭环策略 rollout——前者消除漂移让 MSE 适定，后者误差复利必须用 Wasserstein 等分布距离补救。
  3. 奖励的物理单位化是跨形态迁移的钥匙：能量写进 Joule，系数不随机器人变；torque² 这类无量纲代理项每换一台机器人都要重调。
  4. 不建模一切，只建模可观测的主导项：固件补偿、电流环、饱和全部不当自由参数——要么按单位增益近似，要么按已知限界强制施加。49 维可解释参数胜过大而全的辨识空间。
  5. PD 增益低不是妥协而是设计：辨识与训练用同一套低增益，让主导动力学落在可激振频段内。

四、趋势判断

Sim2real 正从"随机化艺术"走向"辨识工程"：2022-2024 主流是 domain randomization + teacher-student 蒸馏（Rudin/Lee/Miki 一系），2025-2026 出现三条并行的新路线——CMA-ES 系统辨识（本文/Sobanbabu）、残差动力学学习（Fey 2025 无力矩传感执行器网络）、LLM 引导奖励搜索（DrEureka/Eureka 一系）。判据：当论文开始比较"谁用的真实数据更少、参数更可解释、跨平台更多"时，领域已从 demo 竞赛进入工程化阶段。10+ 附加机器人零调参复用同一系数，是工程成熟的标志。

对低成本自研机器人（如 DUCK-Pi_5 这类百元级舵机平台）：辨识路线的性价比远高于 randomization 路线——随机化要求训练时穷举参数分布（GPU 时长成本），辨识只要一次数分钟的真机激振。

六、拓展应用推荐

  1. DUCK-Pi_5 真机标定阶段（最高优先）：装配完成后（用户负责硬件），写 identify_duck.py——夹具固定 + chirp 回放 8 关节 × 20s + CMA-ES 拟合 MuJoCo 参数，产出与官方 URDF 的 diff 报告，再决定微调还是重训。这与用户"真机有差异，没必要一次训完"的 3000 档策略兼容。
  2. 舵机健康监测副产品：q̃b 漂移和 τf 增大是齿轮磨损早期信号——定期重跑激振，参数漂移即维保告警。
  3. 能量 reward 改造：从 STS3025 规格书提取相电阻/空载电流，把现有 torque² 项升级为 J 单位电气+机械损耗，为续航优化（1181g 整机 2S 锂电）铺路。
