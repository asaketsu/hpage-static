## 摘要

农业机器人田间落地时，**摄像头/激光雷达一启动，RTK/北斗定位立刻跳点漂移**——这不是单点故障，是整机系统沦为**高强度电磁干扰发射体**，自噪声淹没了 -130~-160dBm 的卫星信号。

---

## 一、核心问题：系统级电磁坍塌

| 信号 | 强度 | 说明 |
|------|------|------|
| GNSS 卫星信号 | **-130 ~ -160 dBm** | 自然界极弱信号，极易被覆盖 |
| 摄像头 SoC/SerDes | 毫瓦~瓦级 | 高速链路辐射 |
| 激光雷达驱动 | 毫瓦~瓦级 | 电机驱动 + 高速回传 |

**能量级差：整整 10 亿倍**。农机的 GPS 不是被外界干扰，而是**机器自身把卫星信号"抹平"了**。

---

## 二、三大田间故障案例

### 案例 1：果园割草机器人「间歇性失明」

- **现象**：同步开启视觉+激光雷达 3 秒内，RTK 跳变 1-3 米；关闭即恢复
- **排查**：算法/天线/基站/换模块 → 两周无进展
- **根因**：SerDes 高速链路共模泄漏，辐射频谱精准覆盖 GPS L1 频段

### 案例 2：喷药机器人「原地漂移鬼畜」

- **现象**：预设直线→S 型轨迹；RTK 满格但坐标乱跳；激光点云抖动
- **根因**：激光雷达+摄像头共用 POC 同轴供电，DCDC 纹波噪声→辐射天线→污染 GNSS 前端低噪放

### 案例 3：坡地履带车「周期性失控」

- **现象**：GPS 信号/卫星数正常，但周期性漂移、航向失控、点云大面积噪点
- **根因**：PCB 地平面割裂，激光雷达电机驱动大电流→超大环路→高强度低频 EMI

## 三、四大隐形干扰链路

```
┌──────────────────────────────────────────────────────┐
│              系统性电磁塌缩闭环                         │
├──────────────────────────────────────────────────────┤
│  ① SerDes 高速链路                                    │
│     1.5GHz 辐射频谱 → 覆盖 GPS L1/北斗 B1              │
│     共模泄漏 → 自家摄像头/雷达噪声叠加在卫星信号里       │
│                                                       │
│  ② POC 同轴供电链路                                   │
│     DCDC 纹波 + 激光雷达电流波动 → 同轴线变辐射天线     │
│     近距离持续性辐射 GNSS 模块                          │
│                                                       │
│  ③ 激光雷达电机驱动                                    │
│     换向尖峰 + 开关噪声 → 电源线/金属支架耦合           │
│     干扰 GNSS 低频接收 + 污染雷达回波                   │
│                                                       │
│  ④ 地回流路径（最隐蔽）                                │
│     PCB 地平面割裂 + 屏蔽壳接地不良                    │
│     电流环路面积越大 → 辐射强度指数暴涨                  │
│     实验室静态隐形 → 田间全负载爆发                      │
└──────────────────────────────────────────────────────┘
```

## 四、农机 vs 汽车：电磁环境更恶劣

| 维度 | 汽车 | 农机 |
|------|------|------|
| 设计预算 | 高，完整 EMC 体系 | 低，无专项预算 |
| 噪声器件 | 相对封闭 | 电机+液压泵+执行器+激光雷达 |
| 信号接收 | 金属车身屏蔽 | **全开放无屏蔽** |
| 环境 | 标准化道路 | 复杂地形+植被+土壤湿度变化 |

**结论：农机是移动机器人中电磁环境最恶劣的品类。**

---

## 五、根治方案：三层架构重构

### 第一层：电磁架构重构（先让机器"安静"）

- 视觉/激光雷达 SerDes 链路 → **独立共模扼流 + 双层屏蔽**
- 拆分 POC 供电 → **独立供电支路 + LC 隔离**
- 激光雷达电机 → **吸收回路 + 磁珠滤波**
- GNSS 模块 → **独立干净电源域**（与雷达/视觉完全隔离）
- PCB 接地 → **地平面完整连续化 + 多点低阻抗接地**

### 第二层：传感器架构重构（颠覆 GNSS 主导航）

| 传感器 | 新角色 | 说明 |
|--------|--------|------|
| GNSS | 全局粗定位锚点 | 仅提供地理坐标基准 |
| 视觉+激光雷达 | 短周期高精度相对定位 | 实时障碍物感知 |
| IMU+轮速里程计 | 连续运动状态维持 | 填补 GNSS 中断空白 |
| 地形约束模型 | 长期定位纠偏 | 适配复杂田间地形 |

### 第三层：控制逻辑重构（抗失效智能机制）

- **GNSS 实时质量评分** → 动态调整融合权重
- **EMI 电磁干扰状态机** → 实时检测整机噪声异常
- **传感器故障降级策略** → 干扰超标时降频/分时启闭/安全停机

---

## 六、核心结论

> **先有电磁安静，才有算法智能。**
>
> 在一个自噪声失控的系统里：
> - 算法越强 → 误判越快
> - 传感器越多（相机+激光雷达） → 干扰越严重
> - 算力越高、雷达线束越多 → 电磁越复杂
>
> **农业机器人的竞争，从来不是 AI/算法的竞争，而是系统工程与工业可靠性的竞争。**
>
> **不是卫星信号变弱了，是你的机器，把自己活成了干扰源。**
