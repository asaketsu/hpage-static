无臂双足机器人跌倒自恢复 FTSR：力引导约束强化学习

#机器人 #强化学习 #DUCK #跌倒恢复

出处/来源：arXiv 2606.14270v1（IEEE RA-L 录用，北京理工大学，2026-05-14 接收）。项目页 https://2350575870.github.io/force-guided.github.io/

生成日期 2026-10-05

核心问题

无臂双足（轮腿）机器人跌倒后如何仅靠腿部执行器自主起身——没有手臂支撑、没有多余腿协同，纯奖励优化极易收敛到"死点"（dead points，局部最优的无效姿态）。首个在真实无臂双足轮式机器人上实现多随机姿态+多地形跌倒恢复的工作。直接对应当前 DUCK E29 的失败模式：趴姿起身 z 到位但 qy 残留（躯干侧翻），起身过程中 yaw/侧向翻正能力不足。

内容整理

1. 核心机制一：力引导 = 可优化约束，非课程衰减

传统方法（HoST 等）用"外部助力课程"：前期给上托力，按固定日程衰减。问题：衰减时机与策略能力脱钩——策略还没学会站立，力先撤了，训练崩塌进死点。

FTSR 的做法是把外力/外力矩写进 CMDP（约束马尔可夫决策过程）的约束项，用 CPO（Constrained Policy Optimization）求解：

  • 外力公式：F = (1 − e^(−μ(h_cmd − h))) · sat0,1 · F_max·n
  • μ 为高度系数，h_cmd 目标质心高度，h 当前质心高度——机器人越矮，外力越大；高度逼近目标，力自动指数消失
  • n = [0,0,1]ᵀ 纯竖直上托
  • 外力矩：T = 同样的高度/时间系数 × T_max·log(R_tag·R⁻¹)（SO(3) 对数映射，把当前姿态拉向目标欧拉角）
  • 关键改造：不用 CPO 原版二次规划求解，用罚函数法把约束折进混合优势函数 Ā = A − Σβᵢ(J_Cᵢ + 约束优势项)，仍用 PPO 优化，di 随训练推向 0——目标是让外力依赖趋零，约束本身成为"可优化的退场机制"

2. 核心机制二：高度渐进式阶段奖励（batch 统计自动切换）

不按固定时长切阶段，按全 batch 智能体高度统计切换：

  • 阶段1 上身竖立 r^u：重力投影惩罚为主，目标高度 h1_cmd。激活条件=起步
  • 阶段2 站起 r^s：当 |S1| > 2/3·N（高度超 h1_cmd 的智能体占 2/3）才激活。腿部关节收回初始站立位附近，目标高度升到 h2_cmd
  • 阶段3 行走 r^w：当 |S2| > 2/3·N 激活。恢复正常行走命令跟踪，防起身后半途而废

3. 奖励表关键项（对 DUCK 最有借鉴价值的原文数值）

  • Termin. 趴地超10s终止罚：阶段1 -200 / 阶段2 -100 / 阶段3 -500（防"躺着吃灰"）
  • Leg bias 对称罚 ‖q_left − q_right‖₂：阶段1 权重 -2.0（防左右腿不对称起身——正是 E29 qy 残留的对症项）
  • Orient. ‖g_xy‖₂：阶段1 -2.6 → 阶段2 -2.8 → 阶段3 -10.0（越后越严）
  • Leg-usage 奖：轮/脚接触力 f 接近总重 M 时 +4.0（鼓励真正承重而非蹭地）
  • No fly 罚（双腿/轮同时离地）：阶段1 -2.0
  • Base height 跟踪：exp(−8.3‖h − h_cmd‖²) 权重 4.0/6.0/5.0
  • Act. rate 罚 -0.06/-0.02/-0.08；DOF pos 偏离标称 -0.06/-0.1/-0.12（与 DUCK 现役配方同族）

4. 师生架构

  • Teacher 编码器吃特权信息（接触力、真实基高、全状态）；Student 编码器只吃 H 步本体感觉历史（34 维观测：角速度/重力投影/命令/关节位置速度/上步动作），MSE 蒸馏对齐
  • Actor MLP [512,256,128]——与 DUCK 现役 61→512→256→128 完全同构，迁移阻力低
  • Critic 额外吃 188 维含高度图+基高的特权状态

5. 实验结果

  • 真机（无臂双足轮式）：草地/坡道/楼梯各 5/5，总体 15/15 起身成功
  • 从多随机初始姿态恢复；恢复后保持完整运动能力
  • 框架直接迁移到高自由度人形，验证泛化性

查询拓展

  • HoST（arXiv 2502.12152）：人形机器人起身策略，多类奖励+助力课程——FTSR 的直接前驱，FTSR 指出其课程衰减会撞死点
  • FRASA（arXiv 2410.08655）：端到端人形跌倒恢复+站起 RL agent
  • UCL 学习复杂运动技能工作：跌倒恢复三阶段分类法（self-righting → standing up → stabilization），与 FTSR 阶段奖励划分一致
  • Learning to Recover（arXiv 2506.05516）：episode 级动态奖励整形，前期广探索后期精收敛——与"课程 vs 约束"之争同主题
  • Robust Recovery Controller（Lee/Hwangbo/Hutter 1901.07517）：四足恢复经典基线

归纳总结

  1. 约束式助力 > 课程式助力：把外力写成与高度误差指数耦合的可优化约束，让"撤力"由策略能力自然驱动，而非人工日程——死点问题的根因是衰减与能力脱钩
  2. 阶段切换用 batch 统计而非固定时长：2/3 智能体过阈才切阶段，天然抗群体进度不均
  3. 对称罚是侧翻翻正的有效信号：Leg bias 在竖立期权重最大（-2.0），与 Orient 罚配合压住 roll/qy 残留
  4. 趴地终止罚防"假健康"：与 DUCK "z 高度是唯一诚实指标"铁律同构——不给躺平策略任何生存空间
  5. 师生蒸馏 + 纯本体感觉部署：与 DUCK 部署链（无真值 IMU-only）完全对齐

趋势判断

  • 跌倒恢复正在从"人形/四足专用"下沉到"低自由度无臂平台"——执行器越少，训练技巧（约束/课程/奖励结构）的边际价值越大
  • 约束式 RL（CMDP/CPO/罚函数化）在足式机器人落地场景中替代简单课程的趋势明显，2026 年多篇工作收敛于此
  • 对 DUCK 线：E29 失败（qy 残留）的下一版变体（E30）若引入 ①leg-bias 对称罚加权到竖立期 ②力引导约束替代/叠加现有 crouch 罚 ③batch 高度统计阶段切换，理论上是对症配方

关联

  • DUCK E29（qy 残留失败）：Leg bias -2.0 + Orient -2.6 的竖立期组合是文献级对症项；E30 variant 设计的直接输入
  • DUCK 五段式起身 skill：FTSR 的"上身竖立→站起→稳定"三阶段与五段式（压髋→锁位→协同上站→终伸→踝回中）物理过程同构——RL 版可以吸收 skill 里的阶段目标高度定义（h1=趴姿翻身位, h2=蹲位 0.046, h3=站位 0.082）
  • Hermes/软件侧：无直接关联，但"约束随能力自动退场"的设计模式对自进化系统有隐喻（护栏应随能力证伪而松弛，非固定时间表）

拓展应用推荐

  1. P0｜E30 变体配方输入：在下一版趴姿起身变体中加入 leg-bias 对称罚（竖立期权重从 0 → -2.0 量级起步）+ 趴地终止罚（-100~-200），直接治 E29 的 qy 残留。工作量=reward 函数两行+权重表
  2. P1｜力引导约束试点：若 E30 对称罚仍不达标，上 CMDP 罚函数版力引导（MuJoCo 里给 trunk 加高度耦合外力，混合优势折进 PPO loss）——工作量约 1-2 天，是"治本"级改造
  3. P2｜batch 统计阶段切换：把现有固定 iter 课程（push 0.05→0.6 爬坡）改为 2/3 智能体过阈自动切换，抗"群体进度不均导致的早切/晚切"
  4. P3｜HoST/FRASA 对照精读：若 E30 立项，先读 HoST 的助力课程细节做负面对照
