一句话结论

扩散策略的 RL 微调增益并非扩散特有（Gaussian policy + PPO 同样涨）；真正可白嫖的是 ADEPT 的难度加权环境采样思想——不改网络、不加训练成本，只改地形课程的数据分布，就能提升泛化与收敛速度。

1. DPPO 综述硬数据（84 项研究的证据地图）

1.1 综述骨架

  • 四条检索路径 → 178 条记录 → 162 去重候选 → 84 项研究入图
  • 层级规则分类：41 项直接奖励驱动（reward-driven）+ 32 项邻近机器人研究 + 8 项替代生成器 + 3 项非机器人
  • 五轴分类法：初始化/数据、交互机制、优化对象、信用分配、生成器类型

1.2 关键实测（D4RL 1.1 Hopper 基准，固定终点评估协议）

最重要的一句话：Gaussian 策略在 PPO 后同样提升——增益不是扩散专属的。这对我们的重训选型是直接证据：MLP+PPO 主线（MODEL_VERSIONS 真值里的既定路线）不需要因为"扩散策略更潮"而动摇。

1.3 综述里的代表性路线（与我们相关的两条）

  • TMRL：扩散策略先用 context-smoothed BC 预训练，再在线 RL 微调（O2O），真机操作任务验证——"预训练保留探索结构、微调榨任务回报"的两段式。
  • Adaptive DP Nav：模仿预训练的视觉扩散导航策略 + RL 微调，零样本迁移到四足真机。

2. ADEPT：扩散模型生成训练环境（公式级拆解）

2.1 核心思想

环境生成器与策略共同进化：用 DDPM 的初始噪声优化，生成"当前策略刚好学得动"的环境。冻结扩散模型权重（保证生成环境贴合真实分布），只优化初始噪声——不需要 classifier-free guidance 的全步扰动，也不需要微调扩散模型。

2.2 三个可直接复刻的机制

① 难度加权插值（生成"跳一跳够得着"的环境）

对数据集子集 Λ̄ 中每个环境 e^i 加噪到第 k 步得到潜变量 e_k^i，按策略改进权重加权平均：

e'_k = Σ w(e^i,π)·e_k^i / Σ w(e^m,π)
w(e,π) = exp{ -(s(e,π) - s̄)² / σ² }
  • s(e,π) = 环境难度代理，用导航/行走成功率（比 TD-error、regret 更便宜且够用）
  • 权重惩罚"太容易"和"太难"两端的偏离，σ 是温度
  • 新环境 = 从加权融合的潜变量做反向扩散

② 多样性自适应（防训练后期躺平）

  • 对数据集每张高程图做 PCA，前几个主成分的方差 → 数据集多样性代理 Λ_var
  • 反向扩散起始步 k = K·(1 - Λ_var)：数据越多样 k 越小（生成越接近已有环境，精修难度）；数据越单一 k 越大（越接近纯噪声，生成全新地形）

③ 环境选择器

不用确定性 argmax，按权重采样 + UCB（Upper Confidence Bound）偏好——兼顾利用与探索。

2.3 环境表示与真机部署

  • 两层地图 e∈R^{2×W×H}：裸地形高程 + 植被冠层布局。不用 SDF/多边形网格（越野细节需要精细空间分辨率，计算太贵）。生成后由程序化生成补细节（coarse-to-fine）。
  • 感知域处理：不搞复杂手工深度噪声模型，只随机化单个红外噪声模型参数（立体匹配模拟）——简单可控且够真实。
  • 部署链：特权教师策略（ADEPT 环境训练）→ teacher-student 蒸馏 + 物理/感知域随机化 → 学生策略零样本上真机（轮式机器人越野验证，优于程序化生成与自然环境训练）。

3. 对 DUCK-Pi_5 的落地分析（四分判定式）

判定 内容 动作
已满足 MLP+PPO 主线（v4 重训指南 docs/45）：综述证明 Gaussian+PPO 增益与扩散持平，无需换扩散策略网络 关闭，不动
新增主线候选 难度加权地形重采样：现有 microduck 地形库（mujoco-scene-design 的 hfield/bin 体系）按 episode 成功率做加权采样——w(e,π) 公式可直接抄，success rate 平方惩罚，σ 可调 重训时实装，零额外训练成本，只改数据采样逻辑
增强阶段（带触发） PCA 多样性代理 + 起始步调度：当地形库固定、训练后期回报平台化时再引入；程序化地形参数化空间有限是已知痛点 触发条件：重训中观察到回报平台 + 地形过拟合（训练地形好、新地形差）
明确不做 训练一个 DDPM 来生成地形：鸭子是小足式机器人非越野导航，地形复杂度需求有限，扩散模型训练成本不成比例；且本机 Jetson 禁跑重型训练 给理由关闭

一句话给重训：重训仍走 MLP+PPO 主线；把"地形按成功率加权重采样"写进重训配置（约 20 行采样逻辑），这是 ADEPT 摘出来最便宜的一块肉。
