## 核心结论

PyTorch 是全球最主流的深度学习研究框架，两大核心能力：**GPU 加速张量计算 + 基于 tape 的自动微分（autograd）**。以"Python First + 动态计算图"哲学击败了 TensorFlow 的静态图范式，成为学术研究和原型开发的事实标准。10 万+ Star，几乎所有主流 LLM（Llama/Qwen/DeepSeek/GLM）都基于 PyTorch 构建。

---

## 一、两大核心能力

| 能力 | 说明 |
|------|------|
| **GPU 加速张量计算** | 类 NumPy 的 Tensor，无缝 CPU/GPU 切换，GPU 加速幅度巨大 |
| **基于 Tape 的自动微分** | 反向模式自动微分（reverse-mode autodiff），动态构建计算图，随时修改网络行为零开销 |

### 动态 vs 静态计算图

| 维度 | PyTorch（动态图） | TensorFlow 1.x（静态图） |
|------|-------------------|------------------------|
| **图构建** | 运行时动态构建（define-by-run） | 先定义后执行（define-then-run） |
| **调试** | ✅ Python 原生调试器直接用 | ❌ 需特殊工具 |
| **灵活性** | ✅ 任意修改网络行为，零开销 | ❌ 改结构需重建图 |
| **直觉** | ✅ 线性思维，所见即所得 | 复杂 |
| **结果** | 🏆 学术界/原型事实标准 | TF 2.x 转向动态图（Keras） |

> "PyTorch is not a Python binding into a monolithic C++ framework. It is built to be deeply integrated into Python."

## 二、核心组件

| 组件 | 说明 |
|------|------|
| **`torch`** | Tensor 库（类 NumPy），强 GPU 支持 |
| **`torch.autograd`** | 基于 tape 的自动微分，支持所有可微 Tensor 操作 |
| **`torch.nn`** | 神经网络库，与 autograd 深度集成 |
| **`torch.jit`** | TorchScript 编译栈，创建可序列化、可优化的模型 |
| **`torch.multiprocessing`** | Python 多进程 + Tensor 跨进程内存共享 |
| **`torch.utils`** | DataLoader 等工具 |

### 典型用途

1. **NumPy 替代品**：用 GPU 加速科学计算
2. **深度学习研究平台**：最大灵活性和速度

## 三、设计哲学

| 原则 | 说明 |
|------|------|
| **Python First** | 不是 C++ 框架的 Python 绑定，而是深度融入 Python 生态 |
| **动态计算图** | define-by-run，所见即所得 |
| **命令式体验** | 直观、线性思维、易用 |
| **快速且精简** | 最小内存开销，高性能 |
| **无痛扩展** | 复用 NumPy/SciPy/Cython/Numba |

## 五、安装

### GPU 版本（CUDA）

```bash
# 通用安装（自动匹配 CUDA）
pip install torch

# 指定 CUDA 版本（如 CUDA 12.4）
pip install torch --index-url https://download.pytorch.org/whl/cu124

# CPU-only
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### NVIDIA Jetson 平台

Jetson 平台（包括 AGX Orin/Orin Nano）有专门的安装指南，因为 JetPack 自带特定版本 CUDA，需要匹配的 PyTorch wheel。详见 [PyTorch Jetson 指南](https://forums.developer.nvidia.com/t/pytorch-for-jetson/)。

### 从源码编译

```bash
git clone --recursive https://github.com/pytorch/pytorch.git
cd pytorch

# macOS/Linux
pip install -r requirements.txt
python setup.py install

# 带特定 CUDA 版本
export CMAKE_PREFIX_PATH="$(python3 -c 'import torch.utils.cpp_extension; print(torch.utils.cpp_extension.CMAKE_PREFIX_PATH)')"
```

### Docker

```bash
# 预构建镜像
docker pull pytorch/pytorch:latest

# 自定义构建
docker build -t my-pytorch .
```

## 六、快速上手

```python
import torch
import torch.nn as nn

# 1. Tensor 基本操作
x = torch.randn(3, 4)           # 随机张量
y = x.cuda()                     # 移到 GPU
z = x @ x.T                      # 矩阵乘法

# 2. 自动微分
x = torch.randn(3, requires_grad=True)
y = (x ** 2).sum()
y.backward()                     # 自动求导
print(x.grad)                    # dy/dx = 2x

# 3. 神经网络
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(784, 10)

    def forward(self, x):
        return self.fc(x)

model = SimpleNet()
if torch.cuda.is_available():
    model = model.cuda()

# 4. torch.compile 加速 (PyTorch 2.x)
model = torch.compile(model)     # 一行代码加速

# 5. 训练循环
```

## 七、PyTorch 2.x / torch.compile

PyTorch 2.0+ 引入了 `torch.compile`，这是近年来最重要的更新：

```python
# 一行代码，无需修改任何模型代码
```

## 九、与 TensorFlow 的历史对比

| 维度 | PyTorch | TensorFlow |
|------|---------|------------|
| **起源** | Meta FAIR (2016) | Google Brain (2015) |
| **初始范式** | 动态图 (define-by-run) | 静态图 (define-then-run) |
| **学术采用** | 🏆 2020 年后学术主导 | 2018 年前主导 |
| **工业采用** | 广泛 | 广泛（Google 生态内） |
| **易用性** | ✅ Pythonic | TF 2.x 改善（Keras） |
| **部署** | TorchServe / ExecuTorch | TF Serving / TF Lite |
| **动态图** | 原生 | TF 2.x 引入 eager execution |
| **2026 地位** | 🏆 研究主导 | 工业 + Google 生态 |

> 关键转折点：2019-2020 年，学术界大规模从 TF 迁移到 PyTorch，主因是动态图的调试便利性和 Pythonic 设计。
