内容整理

1. HumanUP（arXiv 2502.12152）：人形机器人真实世界爬起策略

核心结论：首个真人形（Unitree G1）真实世界爬起演示。关键论断——爬起任务与运动控制有三个本质差异，导致 locomotion 的成功经验不能直接搬：

差异点 locomotion 爬起任务
接触模式 周期性左右交替，相位耦合有效 非周期，接触序列本身需要被探索出来
接触部位 仅脚部 全身多部位（躯干、膝、臂都可能借力）
奖励密度 速度跟踪几十步内可反馈 大量部位先"负进度"（躯干先趴几秒才能起）

两阶段训练架构：
- Stage I 发现策略 f：只给任务奖励+软对称奖励，完全不带部署约束（不平滑、不限力矩速度），专门用于在稀疏奖励下发现可行爬起轨迹。5B 仿真步。
- Stage II 可部署策略 π：模仿 Stage I 轨迹的 8× 减速版，配合强控制正则（平滑、限速限矩）+ 域随机化，仅 20K 步。跟踪奖励 r_tracking = r_tracking_DoF + r_tracking_body（头部高度/重力投影）。
- 课程双向推进：任务上"难到易"（先解决任务再谈部署），Sim2Real 上"易到难"（简化碰撞网格→完整碰撞网格；标准躺姿→随机躺姿；弱正则→强正则）。
- 任务分解：prone（俯卧）不直接起，分解为"翻身→仰卧→起立"两策略分别训练。
- 软对称奖励（鼓励但不强制双边对称动作）继承硬对称的样本效率又保留 DoF 自由度。
- 工程：IsaacGym，4096 并行环境，单卡 RTX 4090/L40S；真机验证雪地、草地、斜坡、湿滑平面。

2. ED 动态奖励整形（arXiv 2506.05516）：轮腿机器人跌倒恢复

核心公式（Episode-based Dynamic Reward Shaping）：

ed = (a·t/T)^k,  a = T/2, k = 3,  t ∈ [0,T]
r_t = ed·R_task(s_t,a_t) + cw·R_behavior
cw = cw^β  (课程权重, β=0.968 指数衰减, 初始 0.3)
  • 机制：episode 前段 ed≈0 → 姿态偏差几乎不受罚 → 机器人自由探索翻滚/甩身等反直觉动作；后段 ed→1 → 逐步收紧到精确目标姿态。每步奖励乘 ed 因子，替代"终点悬赏"式稀疏奖励。
  • 成效数字：KYON 平台成功率 99.1%、Go2-W 平台 97.8%（2048 随机初始态测试），比固定奖励基线 +2.7pp；轮腿协同省关节力矩 15.8%/26.2%。
  • 基线失败模式（与 DUCK v6 高度同构）：基线因关节角偏差惩罚压制了前腿动作，只试图用后腿调 base height，陷入局部最优——正是"深蹲位 dense 项停付"的镜像案例。
  • 跌倒初态生成法：随机 base 朝向+关节角，力矩清零，从 1.1m 高度自由落体 2 秒确保完全瘫倒——比手工枚举躺姿覆盖广得多。episode 固定 5s（50Hz），仅超时终止不提前终止（与我们 fell_over 500 放闸同理）。
  • 非对称 actor-critic：critic 拿特权信息（碰撞状态+VTG），actor 只拿带噪本体感觉历史；关节速度/base 速度噪声加大。

3. FR-Net（arXiv 2509.11504）：质量-接触预测器辅助四足恢复

  • Mass-Contact Predictor：从有限本体感觉估计机器人质量分布+接触状态（critic 侧特权学习），部署时无需地形数据，解决"趴着看不见地形"的部分可观测问题。
  • 奖励设计专门抑制陡峭地形上的危险翻滚行为；Go2 真机 10 个挑战场景验证，仿真跨平台（Go2/Spot/Lite3）+ G1 人形迁移成功。
  • 局限：只估计碰撞状态，不估计精确接触位置（缝隙地形仍弱）。

归纳总结

三篇论文收敛出跌倒恢复的三条通用规律：

  1. 稀疏奖励是第一敌人，解法全是"分阶段/动态化"：HumanUP 用"先发现后部署"两阶段，ED 用 episode 内时间动态因子 ed(t)，FR-Net 用特权 critic 提供价值信号。共同本质：允许早期大偏差、逐步收紧，防止姿态惩罚杀死探索。
  2. 跌倒初态要用物理生成而非枚举：自由落体法（随机朝向+零力矩+1.1m 落体 2s）是标准做法，天然覆盖任意躺姿分布。
  3. 爬起≠运动控制，不能沿用 locomotion 的正则直觉：接触全身化、非周期、先负后正的进度曲线——locomotion 式的平滑/对称/相位约束都要放松或改为软约束。

趋势判断

  • 跌倒恢复正从"平面特例"走向"任意地形+任意姿态"：2024 前的工作多限平面（Lee 2019、Smith reset 策略），2025 起 FR-Net 陡楼梯/悬臂梁、HumanUP 雪地斜坡成为标配验证集。
  • 特权学习+质量/接触估计成为部分可观测的标准解，纯本体感觉+历史编码器是部署侧主流。
  • 人形机器人爬起从仿真走向真机（HumanUP 是首个真人形真机演示），鸭子这类低成本平台完全可以跟进同套配方——小平台复现前沿范式是论文计划的可选切口。

指南分析

对 v7 prone 爬起立项的可执行建议（按优先级）：

  1. P0——奖励结构改造：现有 com_upward/recovery 悬赏改为 ed=(0.5·t/T)^3 × R_task，T 取 episode 长度（当前 12-13 步起步会随放闸变长，T 用固定 5s=250 步）。行为罚项乘课程权重 cw（0.3 起指数衰减）。
  2. P1——初态生成换血：prone ramp 从"配置枚举"改为"零力矩自由落体"，落体高度按鸭质心离地 ~0.14m 取 1.5-2×（论文 1.1m 对 ~0.6m 高的四足），2s 静置。
  3. P2——两阶段拆分预案：直起失败再拆"翻身+起立"，Stage II 轨迹减速倍率按舵机速度档实测调。
  4. 门禁沿用 09-13 铁律：指标判读先读源码定义，成功判定用 tilt<25°+z>0.09 与 b2_4750 基线同期对照。
