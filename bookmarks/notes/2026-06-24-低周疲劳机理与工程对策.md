## 摘要

低周疲劳（Low Cycle Fatigue, LCF）是材料在接近屈服极限的高应力作用下，仅经过较少循环次数（通常 < 10⁴ 次）即发生断裂的现象。与高周疲劳"弹回原样"的弹性变形不同，低周疲劳的核心特征是**塑性变形的不可逆累积**——每一次循环都在"掏空"材料，最终导致裂纹萌生→扩展→突然脆断的三步失效。本文以涡轮叶片、燃气轮机轮盘、发动机气缸盖为典型案例，并给出工程师的三大对策：应变-寿命曲线（ε-N）、圆角过渡设计、以及弹塑性容限设计。

---

## 一、低周疲劳的定义与核心特征

低周疲劳是指材料在承受**接近自身屈服极限的高应力**作用下，仅经过**较少的循环次数**就发生断裂的现象。

三个关键词：**高应力、少次数、塑性变形**。

| 对比维度 | 低周疲劳 (LCF) | 高周疲劳 (HCF) |
|---------|---------------|---------------|
| **应力水平** | 接近/超过屈服强度 | 远低于屈服强度 |
| **循环次数** | < 10⁴ 次（甚至 < 10³） | > 10⁵～10⁷ 次 |
| **变形性质** | 塑性变形（不可恢复） | 弹性变形（可恢复） |
| **寿命评估** | 应变-寿命（ε-N）曲线 | 应力-寿命（S-N）曲线 |
| **控制变量** | 应变幅 Δε | 应力幅 Δσ |
| **通俗比喻** | 口香糖——捏扁回不去 | 弹簧——每次弹回原样 |

> **一句话区分**：高周疲劳是"温水煮青蛙"，低周疲劳是"拳拳到肉"。

---

## 二、三步失效机制（"三步杀人术"）

低周疲劳导致的断裂从来不是一刀毙命，而是经典的三步曲：

### 2.1 第一步：裂纹萌生（埋下种子）

裂纹往往在**应力最集中的位置**最先出现：
- 尖锐的转角 / 台阶
- 焊接气孔、夹渣
- 表面划痕、加工刀痕
- 截面突变处

一条肉眼不可见的微观小裂纹在此萌生，成为失效的"种子"。

### 2.2 第二步：裂纹扩展（慢慢长大）

每一次循环加载，裂纹尖端都经历剧烈的"拉-压"塑性变形：

```
循环加载方向
    ↓↑ ↓↑ ↓↑ ↓↑
 ┌──┐ ┌──┐ ┌──┐
 │  │ │  │ │  │ ← 裂纹尖端塑性区
 └──┘ └──┘ └──┘
─────────────────→ 裂纹扩展方向
  +1μm  +1μm  +1μm
```

每一次循环裂纹推进约一微米量级，日积月累，裂纹越长，尖端应力集中越严重，扩展速率也越快——这是一个**正反馈加速过程**。

### 2.3 第三步：突然断裂（瞬间崩盘）

当剩余完好截面积再也无法承受下一次循环载荷时：

> "咔嚓"一声，**整体脆断**——没有任何预告。

这是低周疲劳最危险的特性：失效前的征兆极短，往往来不及采取任何措施。

## 三、工程中的低周疲劳典型案例

### 3.1 航空发动机涡轮叶片

涡轮叶片同时承受多重极端载荷：

| 载荷来源 | 类型 | 特征 |
|---------|------|------|
| 高速旋转 | 离心载荷 | 巨大、持续 |
| 燃气冲击 | 振动载荷 | 高频交变 |
| 温度梯度 | 热应变 | 周期性（起飞-巡航-降落循环） |
| 燃气硫化物 | 腐蚀 | 加速裂纹萌生 |

此外，叶片的枞树形榫头/榫槽连接等几何不规则部位是天然的应力集中区。**起飞-降落循环中温度剧烈变化产生的热应力**往往使局部超过屈服强度，发生塑性变形，导致低周疲劳损伤。

### 3.2 燃气轮机叶片-轮盘

频繁启停过程中的交变载荷使叶片-轮盘连接处可能发生低周疲劳失效。每次启停 = 一次完整的热-力循环。

### 3.3 发动机气缸盖

发动机台架试验表明：**交变类耐久试验比恒定工况试验更容易导致缸盖开裂**。根因是温度周期变化产生大热应力，局部超过屈服强度 → 塑性变形 → 低周疲劳开裂。

> **共性规律**：凡是经历"启停循环 / 变工况服役"的高温承力部件，都是低周疲劳的高风险对象。

## 四、工程师的三大对策

### 4.1 放弃"应力"，拥抱"应变"

传统高周疲劳使用 **应力-寿命（S-N）曲线**，以应力幅 Δσ 作为控制变量。但低周疲劳由塑性应变主导，S-N 曲线无法正确描述。

| 方法 | 控制变量 | 适用疲劳类型 | 代表曲线 |
|------|---------|-------------|---------|
| 应力法 | Δσ（应力幅） | 高周疲劳 HCF | S-N 曲线（Wöhler） |
| 应变法 | Δε（应变幅） | 低周疲劳 LCF | ε-N 曲线（Coffin-Manson） |

**Coffin-Manson 公式**的核心：

```
Δε_p / 2 = ε'_f · (2N_f)^c

其中：
  Δε_p  = 塑性应变幅
  ε'_f  = 疲劳延性系数
  2N_f  = 反复次数至失效
  c     = 疲劳延性指数（通常 -0.5 ~ -0.7）
```

用形变量来评估剩余寿命，而不是用力的大小。

### 4.2 设计"圆角"，杜绝"尖角"

应力集中在**直角/尖角**处急剧放大（理论应力集中系数 Kt → ∞）。

| 设计特征 | 应力集中 Kt | 疲劳寿命影响 |
|---------|------------|-------------|
| 尖锐直角（R=0） | 极高（→∞） | 寿命极短 |
| 小圆角过渡（R 小） | 高 | 寿命缩短数倍 |
| 大圆角过渡（R 大） | 低 | **寿命翻数倍** |
| 流线型过渡 | 最低 | 最优 |

把所有直角改成**平滑圆角过渡**，疲劳寿命可翻数倍。这是成本最低、收益最大的抗疲劳设计手段。

### 4.3 允许"局部投降"——弹塑性容限设计

传统弹性设计强求零件永远"硬邦邦"，应力不超过屈服。但低周疲劳场景下，更聪明的策略是：

> **允许零部件在局部进入弹塑性状态**——让一部分材料先"屈服"吸收能量，从而保护整体结构不发生灾难性断裂。

这就是**"以柔克刚"**的设计哲学，核心思想包括：
- **应力重分布**：局部屈服后应力峰值被"削平"，载荷转移到周围弹性区
- **能量吸收**：塑性变形吸收循环能量，减缓裂纹扩展
- **损伤容限**：预设允许的裂纹尺寸，在检测周期内确保安全

## 五、低周疲劳 vs 高周疲劳——完整对比总表

| 维度 | 低周疲劳 LCF | 高周疲劳 HCF |
|------|-------------|-------------|
| 应力水平 | ≥ 屈服强度 | < 屈服强度 |
| 循环次数 | < 10⁴ | > 10⁵ |
| 变形 | 塑性为主 | 弹性为主 |
| 评估曲线 | ε-N（Coffin-Manson） | S-N（Wöhler / Basquin） |
| 主导学科 | 弹塑性力学 | 线弹性断裂力学 |
| 裂纹扩展 | 快（μm/cycle → mm/cycle） | 慢（nm/cycle） |
| 典型场景 | 涡轮叶片启停、压力容器加卸载 | 弹簧、轴承、齿轮 |
| 预警时间 | 极短（突然脆断） | 较长（渐进退化） |
| 设计策略 | 弹塑性容限 + 应变控制 | 无限寿命 / 损伤容限 |

## 💡 启发

- 低周疲劳的"三步曲"模型本质上是一个**正反馈加速过程**：裂纹→应力集中→更快扩展→更大裂纹。这与软件系统的"技术债务雪球"惊人相似——小问题不修，加速恶化，最终"脆断"
- "放弃应力拥抱应变"的思路转换，对应工程方法论中的"换控制变量"思维：当当前框架无法解释现象时，不是修补旧框架，而是换一个根本不同的度量维度
