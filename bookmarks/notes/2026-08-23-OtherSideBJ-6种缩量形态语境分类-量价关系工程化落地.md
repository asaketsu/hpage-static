## 一、逐条对照自有铁律体系 + 本地回测

### 第 1 条：长期下跌后缩量上涨 = 反弹，观望

> 股价长期跌，年线向下，股价压在年线下。跌了一大段后反弹但成交量明显缩小——"跌累了喘口气"，反弹结束继续跌。

**自有体系对照**：铁律⑧（暴跌选股：大跌后筛选龙头）——⑧是"系统性暴跌后选率先反弹的龙头"，这条是"长期阴跌后的缩量反弹，最好观望"。两者不冲突，但本机体系缺"长期阴跌反弹不追"的明确规则。

**本地回测**（30 股备选池，200 日窗，代理定义：60 日线向下+收盘在60日线下+日涨幅>1%+量比<0.8）：

| 指标 | 数值 |
|------|------|
| n | 52 |
| 胜率 | 36.5% |
| 均值 | -0.36% |
| **中位** | **-1.83%** |

**判定：✅ 采纳**——中位-1.83% 表明超半数样本继续下跌，观望是正确策略。可作为铁律⑧的细化/限制（⑧的"暴跌选龙头"应排除"长期阴跌后的缩量反弹"语境）。

### 第 2 条：上涨高位缩量大跌 = 预警，再次冲高易见顶

> 高位缩量大跌，不一定是"跌得不够狠"，反而可能是顶部警报。后面再次冲高然后继续大跌，形成顶部结构。

**自有体系对照**：铁律⑰（天量长上影防假突破）+ ⑯（翻倍位不追）——但⑰关注"天量"，这条关注"缩量大跌"。本机无"高位缩量大跌→预警"规则。

**判定：✅ 吸收**——新信号维度。可在评分体系的 warning 层加"高位缩量大跌"标记（当前有"缩量"警告但无"高位+缩量大跌"组合标记）。

### 第 3 条：持续大涨后缩量上涨 = 风险，小心见顶

> 连续大涨后继续涨，但成交量缩、阳线变小、长上影——上涨动力衰减，强弩之末。

**自有体系对照**：铁律④（赚10%跑一半）+ ⑮（破MA10离场）——④是盈亏口径，⑮是均线口径，缺"量价背离型见顶"信号。

**本地回测**（30 股备选池，代理定义：5日涨幅>15%+量比<0.7+当日涨幅<前日）：

| 指标 | 数值 |
|------|------|
| n | 10 |
| 胜率 | 60.0% |
| 均值 | +6.53% |
| 中位 | +5.26% |

**⚠️ 证伪（对本池）**：连板/动量池中缩量上涨=锁仓缩量加速（与#6原理同构），不是见顶信号。本池 60% 继续上涨，均值+6.53%。**E13 语境门教训重现**——同一形态在动量池 vs 普通池含义完全不同。文章结论可能适用于普通股，但对本机连板池不适用。**不吸收为本池规则**，但保留为"普通股/非动量场景"的观察信号。已在铁律⑬(缩量洗盘/放量跑路)中覆盖。

### 第 4 条：上升调整后缩量下跌 = 吸筹，短期上涨

> 强势股上涨过程中短暂回调，但跌的时候缩量——市场认可原趋势，砸盘人不多。回调后很快重新启动。

**自有体系对照**：铁律⑱（回踩二次买点：突破后缩量回踩不破平台再介入）——**高度同构**。

**判定：✅ 已覆盖**——⑱ 已包含"上升趋势中回调缩量=吸筹/蓄力"的判断。本条的"涨时放量跌时缩量=健康"可作为⑱的补充描述。

### 第 5 条：底部反转后缩量上涨 = 机会，大胆进场

> 底部反转确认后，股价温和上涨但成交量仍缩量——上涨初期愿意卖的人少，等加速才放量。

**自有体系对照**：⑱（回踩二次买点：底部反转突破→等缩量回踩→介入）。本条是"反转确认后缩量上涨直接进，不等回踩"——**时序差异**：⑱等回踩更保守，本条更激进。

**判定：✅ 部分吸收**——可作为⑱的"激进版"补充：在底部反转确认（均线多头/双底突破）时，如果缩量上涨，可直接介入，不等回踩。与"收益优先模式"倾向一致（不等回踩=少错失入场机会）。

### 第 6 条：长期下跌后缩量下跌 = 诱空，不要乱割肉

> 跌幅接近 50% 后，成交量缩到地量——恐慌性抛售接近尾声。再跌就割肉，可能割完反弹就来了。

**自有体系对照**：铁律③（亏5%闭眼割）——硬止损，与这条"长期暴跌后缩量跌不割肉"不冲突：③是个人盈亏阈值，这条是"趋势末期的极端超卖判断"。

**本地回测**（30 股备选池，代理定义：60日跌幅>30%+量比<0.5）：

| 指标 | 数值 |
|------|------|
| n | 12 |
| 胜率 | 66.7% |
| 均值 | +4.92% |
| 中位 | +3.47% |

**判定：✅ 采纳为铁律③的豁免检查**——亏5%触发止损时，加一道"是否处于长期暴跌末期的地量状态"检查。如果是，可多观察1天（不等同于取消止损，只是把执行从"立即"改为"次日开盘确认"）。

## 二、关键教训汇总

### 语境门教训（E13 第三次复现）

#3 在连板池的数据与文章结论相反（大涨后缩量上涨=60%继续涨+6.53%均值），因为：

- **动量池**：缩量上涨 = 锁仓加速（存量多头锁仓，抛压轻）
- **普通池**：缩量上涨 = 动能衰减（无新增资金接力）

**方法论固化**：任何单维度量价规则放到本机体系前，必须先用 `detect_regime()` 判断当前股票是 momentum（连板/题材/主升浪）还是 reversion（震荡/阴跌/底部）——同一形态在两种 regime 下含义相反。

### 铁律⑬（缩量洗盘/放量跑路）的细化

当前铁律⑬只有一句话。本课可细化为：

| 语境 | 缩量含义 | 放量含义 |
|------|----------|----------|
| 上升趋势中回调 | 洗盘/吸筹（健康的） | 出货/撤退（危险的） |
| 长期阴跌中反弹 | 动能不足（反弹结束） | 反转信号（有利的） |
| 持续大涨后 | 加速/锁仓（动量股） / 见顶（普通股） | 高潮/出货（危险的） |
| 高位 | 预警（见顶前兆） | 天量见顶（危险的） |
| 低位/底部 | 筑底/地量（好信号） | 吸筹（有利的） |
