核心发现

1. MCP 概览

  • 定位: 开放协议，实现 LLM 应用与外部数据源/工具的无缝集成
  • 类比: "AI 应用的 USB-C 接口"
  • GitHub: 47.2k followers, 42 repositories, 29 contributors

2. 2026 年重要更新

时间 更新 内容
2026-04 维护团队扩展 Clare Liguori 加入核心维护组，Den Delimarsky 加入作为联合负责人
2026-03 工具注释作为风险词汇 5 个独立 SEP 提案，增强工具行为描述（只读/破坏性/幂等/外部访问）
2026-03 MCP Extensions 允许在基础协议之上添加自定义 UI、认证流程、领域特定约定
2026-? MCP Registry (预览) 官方集中式元数据仓库，支持 Anthropic/GitHub/Microsoft/PulseMCP

3. 生态系统支持

客户端支持:
- Claude / ChatGPT
- VS Code / Cursor
- MCPJam
- 更多 (see: modelcontextprotocol.io/clients)

SDK 语言覆盖:
- TypeScript, Python, Java, Kotlin
- C#, Go, PHP, Ruby, Rust, Swift

4. Registry 架构

Package Registries (npm/PyPI/Docker Hub)
         ↓ 存储代码包
MCP Registry (元数据层)
         ↓ 指向包 + 安装说明
Downstream Aggregators (客户端/工具)

关键特性:
- DNS 验证命名空间管理
- REST API 供客户端发现服务器
- 标准化 server.json 格式
- 安全扫描 + 反垃圾机制

5. 对 Agent 系统的意义

维度 价值
互操作性 一次构建，多处集成
扩展性 Extensions 支持领域定制
安全性 工具注释提供风险词汇
发现性 Registry 提供统一发现入口
