一句话定义

mise（发音 /meez ahn plahs/，源自法语"准备就绪"）— 用一个 mise.toml 文件管理项目的开发工具版本 + 环境变量 + 任务，让每台机器获得相同的开发环境。

内容整理

核心理念：Everything in its place, before you code

mise en place（法语）：烹饪前收集和整理所有食材和工具的过程。

mise 把这个理念用在开发环境上——在写代码之前，把工具、环境变量、任务都准备好。

三大功能

1. Dev Tools — 开发工具版本管理

能力 说明
版本安装 1000+ 工具，一个配置文件
自动切换 进入项目目录自动切换到指定版本
版本锁定 在 mise.toml 中 pin 版本
跨平台 Linux / macOS / Windows / WSL

支持的工具包括：node, python, ruby, go, rust, java, deno, bun, terraform, kubectl, zig, swift, php, elixir 等 1000+。

2. Environments — 环境变量管理

  • 从 mise.toml 加载项目特定环境变量
  • 支持 .env 文件
  • 支持 shell 命令动态生成变量
  • 进入目录自动激活

3. Tasks — 任务管理

  • 定义 build / test / lint / deploy 命令
  • 任务与所需的工具和环境变量绑定在一起
  • 用 mise run <task> 执行

mise.toml 配置示例

[tools]
node = "24"
python = "3.13"

[env]
_.file = ".env.local"

[tasks.test]
run = "pytest"

四步快速上手

# 1. 安装 mise
curl https://mise.run | sh

# 2. 验证版本
mise --version
# 2026.7.0 linux-x64

# 3. 安装工具
mise use node@24 python@3.13

# 4. 使用
node --version          # v24.18.0
mise env -s bash        # 输出环境变量
mise run test           # 执行任务

mise vs 竞品

特性 mise nvm/pyenv/asdf direnv make/just
工具版本管理 ✅ 1000+ ✅（每个语言一个工具） ❌ ❌
环境变量 ✅ ❌ ✅ ❌
任务运行器 ✅ ❌ ❌ ✅
单一配置文件 ✅ mise.toml 分散 .envrc Makefile/justfile
语言 Rust（快） Bash/Python Go C/Go
速度 快（Rust） 慢（Shell 脚本） 中 中

mise 的核心优势：三合一——把 nvm/pyenv/asdf（版本管理）+ direnv（环境变量）+ make/just（任务）合并为一个工具，一个配置文件。

归纳总结

mise 是开发环境管理领域的"瑞士军刀"——用 Rust 编写、31.9K Stars，把三个最常见的需求（版本管理、环境变量、任务）合并到一个 CLI 和一个 mise.toml 文件中。

它的价值主张很简洁：把 mise.toml 提交到仓库，任何人 clone 后运行 mise install 就获得完全一致的开发环境。不需要 README 里写"请先安装 nvm，然后 pyenv，然后…，然后记得 direnv allow"。

对多语言项目（Node + Python + Go 混合）特别有价值——以前需要 nvm + pyenv + goenv 三个工具，现在一个 mise 全搞定。

趋势判断

  • 开发环境即代码（Dev Environment as Code） 成为标配——mise.toml / .tool-versions / flake.nix / devcontainer.json 各路线竞争，mise 的 TOML 最简洁
  • Rust 重写 CLI 工具浪潮：mise(Rust) 替代 asdf(Bash)、ripgrep(Rust) 替代 grep、fd(Rust) 替代 find、bat(Rust) 替代 cat——Rust 的零启动开销让 CLI 工具速度跨代提升
  • 多语言项目增多：全栈项目（Node + Python + Go + Rust）的普及让单一版本管理工具的需求更迫切
  • CI/CD 标准化：mise 在 CI 中使用可以保证本地和 CI 环境一致，减少"在我机器上能跑"的问题

关联分析

  • 与 Hermes Agent 的关联：Hermes 运行在 Jetson Orin Nano 上，用 Python venv 管理依赖。mise 可以管理 Python 版本本身（mise use python@3.12），替代 pyenv，让 Hermes 的 Python 环境版本管理更可靠
  • 与用户多语言开发的关联：用户同时使用 Python（Hermes/LuxTTS）、Rust（dynibo）、Node.js（homepage/md2html）、C++（QtScrcpy/嵌入式），mise 是天然的多语言版本管理工具
  • 与 python-env-isolation Skill 的关联：用户有 python-env-isolation（venv 隔离与依赖安装防污染）Skill，mise 可以管理 Python 解释器版本本身，与 venv 形成互补——mise 管 Python 版本，venv 管包
  • 与 Jetson 平台的关联：Jetson 是 ARM64，部分工具需要特殊编译。mise 可以简化 Jetson 上的多版本工具管理
