核心要点

技巧1：二阶系统阶跃响应

  • stepinfo(sys) 一键获取上升时间/调节时间/超调量/峰值时间
  • 关键参数：ζ=0.4, ωn=5 rad/s 的示范系统

技巧2：PID调参三步法

  • 保守→标准→激进参数对比法
  • pidtune() 自动调参 + pidTuner 交互式工具
  • feedback(C*G, 1) 构建闭环系统

技巧3：Bode图频域分析

  • margin() 计算增益裕度(Gm)和相位裕度(Pm)
  • Gm>1 && Pm>0 → 系统稳定
  • semilogx 手动绘制更精细的Bode图

技巧4：根轨迹+Nyquist

  • rlocus(G) 根轨迹 → 参数K对极点的影响
  • nyquist(G) → 绕(-1,j0)圈数判稳定性
  • rlocfind() 交互式选极点

技巧5：状态空间

  • 质量弹簧阻尼系统：A=[0 1; -k/m -c/m]
  • ctrb(A,B) 可控性 + obsv(A,C) 可观测性
  • place() / acker() 极点配置

Simulink进阶

  • 代码化建模：new_system → add_block → add_line
  • 工具箱：Linear Analysis / Control System Designer / Frequency Response Estimator
  • slbuild() 生成C代码 → 部署到树莓派等硬件
