Anime.js — 轻量级 JavaScript 动画引擎

GitHub: https://github.com/juliangarnier/anime
⭐ 68,253 | 语言: JavaScript | License: MIT

概述

Anime.js 是一个快速、多功能、轻量级的 JavaScript 动画库，提供简洁而强大的 API。支持 CSS 属性、SVG、DOM 属性和 JavaScript 对象的动画。

核心特性

  • 轻量 — 核心极小，无依赖
  • 多目标 — 同时操作 CSS 属性、SVG、DOM 属性、JS 对象
  • 时间线控制 — 链式动画编排，精确控制时序
  • 缓动函数 — 内置丰富缓动曲线 + 自定义贝塞尔曲线
  • 关键帧 — 支持多关键帧动画
  • SVG 路径动画 — 沿 SVG 路径运动
  • 交错动画 — stagger() 批量元素依次延迟

v4 版本亮点

  • 完全重写，性能大幅提升
  • 新的时间线 API（更直观的链式调用）
  • 更好的 SVG 动画支持
  • 改进的 stagger 和 keyframe 系统
  • 支持 Web Animations API 兼容

快速上手

// 基础动画
anime({
  targets: '.box',
  translateX: 250,
  rotate: '1turn',
  backgroundColor: '#FF6B6B',
  duration: 800,
  easing: 'easeInOutQuad'
});

// 时间线
const tl = anime.timeline({
  easing: 'easeOutExpo',
  duration: 750
});

tl.add({ targets: '.box1', translateX: 250 })
  .add({ targets: '.box2', translateX: 250 }, '-=600')
  .add({ targets: '.box3', translateX: 250 }, '-=600');

// 交错动画
anime({
  targets: '.grid-item',
  scale: [{ value: 0.1, easing: 'easeOutSine', duration: 500 }, { value: 1, easing: 'easeInOutQuad', duration: 1200 }],
  delay: anime.stagger(200, { grid: [14, 5], from: 'center' }),
  loop: true
});

适用场景

场景 说明
UI 微交互 按钮、卡片、弹窗过渡动画
数据可视化 图表动画、数据过渡
SVG 动画 路径描绘、形状变换
粒子效果 结合 Canvas 的粒子系统
加载动画 进度条、骨架屏、品牌动画
滚动动画 配合 IntersectionObserver

库 大小 上手难度 适用场景
