一、内容整理

0. 核心问题与方案

长时程科研自动化的致命痛点：跑了一半才发现方向错了——传统 agent 流水线只能一条道走到黑（或在错误状态上继续叠加计算）。

ScienceFlow 的解法：把长时程研究拆成带可执行状态的存档段（archived segments）——随时能回到有效分支、及时止损，让 AI 科研人员真正学会"反悔"。

1. 两大机制

① ESTRA 机制（段落续接决策）
- 决定下一段从 live state（当前活跃状态）还是 archived state（历史存档状态）继续
- 本质：给执行流加了"分支点"——发现当前路径无效时，不必从头开始，回到最近的有效存档段续跑

② evidence-aware controller（证据感知控制器）
- 按预算和已验证进展分配算力
- 有证据支撑的方向多给算力，无进展的分支止损——资源分配跟随验证状态而非预设计划

3. 与传统 agent 循环的差异

传统 agent 流水线 ScienceFlow

三、归纳总结

维度 要点
一句话 给长时程科研 agent 加"存档点+读档"能力——ESTRA 选续接状态，evidence-aware 控制器按验证进展分算力
解决的痛点 方向错误时的沉没成本——从"一条道走到黑"到"回到有效分支止损"
机制本质 执行流的分支化（archived/live 双态）+ 资源分配的证据化（预算跟着已验证进展走）
成绩 MLE-bench Any-Medal 70.22%，数学优化/科学建模领先
适用人群 搭长时程 Agent（科研/工程自动化）的开发者

四、趋势判断

  1. "可反悔性"成为长时程 agent 的核心设计指标：线性流水线在小时/天级任务上必然积累错误——存档+回退机制会从论文特性变成 agent 框架标配（类似游戏存档点设计）
  2. 算力分配从预设计划转向证据驱动：evidence-aware 是"预算跟随验证"的范式——与强化学习中的探索/利用平衡同源，会扩散到所有 agent 编排层
  3. 科研自动化赛道从"能跑通"进入"能止损"阶段：MLE-bench 分数竞赛之后，下一个竞争维度是错误恢复与资源效率
  4. 状态管理语义向 git 靠拢：可执行状态存档=commit，分支回退=checkout——agent 基础设施会吸收版本控制的成熟语义
  5. AI for Science 工具链分层加速：上层（假设生成）+ 中层（实验编排）+ 底层（状态/恢复/预算）——ScienceFlow 属于底层的"运行时"创新

六、拓展应用推荐

① 本仓可落地（直接借鉴）
- 长任务的存档段机制：delegate_task 的复杂子任务可引入"每完成一个可验证里程碑就存档"（进度快照+验证证据）——失败恢复时回到最近有效段而非全重跑
- cron 任务的证据感知调度：监控类 cron（如 stock-alert）已按时间触发，可加"进展感知"——连续 N 次无新信号则降频，检测到异常立即升频（预算跟随验证）
- 经验池的分支回退：exchange-protocol 的 JSONL 经验池追加"反悔记录"——某经验被证伪时标记 archived 而非删除，后续 agent 检索时可避开但保留追溯

② 架构设计模式（搭长时程 agent 时用）
| 需求 | 借鉴 ScienceFlow |
|---|---|
| 任务可能几小时/几天 | 拆带可执行状态的存档段 |
| 方向可能中途证伪 | ESTRA 双态续接（live/archived） |
| 算力/API 有预算 | evidence-aware controller 按验证进展分配 |
| 需要人审 | 回退到 archived 段时通知人工确认 |

③ 延伸阅读路径

七、指南分析

什么时候需要 ScienceFlow 式设计（自查清单）

症状 说明
任务跑 30 分钟以上 线性流水线错误累积风险高，需要存档段
中途结论可能被后续证据推翻 需要 live/archived 双态（如实验科学、多假设研究）
API/算力有明确预算 需要 evidence-aware 分配（无进展分支止损）
失败重跑代价大 存档段可增量恢复，避免全量重跑

不需要的场景：短任务（<10 分钟）、单向确定性流程（编译/部署）、无预算约束的探索——传统循环足够，加机制反而复杂化。

三步落地法
1. 定义存档点：什么状态算"可执行快照"（代码+环境+数据+中间结论）
2. 定义切换判据：什么证据触发"回到存档"（损失不降/假设证伪/预算阈值）
3. 定义预算策略：已验证进展如何映射到算力分配（多证据多算力，零证据止损）

避坑
- 存档段不是越多越好——每段都有序列化开销，粒度按"可验证里程碑"定
- evidence-aware ≠ 只看结果分数——要区分"暂时无进展"和"方向错误"（前者继续，后者回退）
- 别忽略论文口径：70.22% 是 Any-Medal 口径，与固定模型的对照分不可直接比
