## 摘要

RoboParty（萝博头）由 21 岁创始人黄熠于 2025 年 2 月创立，获小米战投/Galbot/MPCi 1000 万美元种子轮。仅用 120 天（2025年4-8月）完成从零到跑步的双足人形机器人原型机 ROBOTO ORIGIN，2026 年 1 月全栈开源。1.25m/34kg/23DOF，跑步速度 3m/s。硬件可完全通过淘宝采购+嘉立创打板 DIY 组装。GPLv3 协议。

## 核心内容

### 1. 机器人参数

| 参数 | 数值 |
|------|------|

### 2. 全栈开源架构（8个子仓库）

| 子仓库 | 职责 | 关键技术 |
|--------|------|----------|
| `rpo_hardware` | 机械结构+CAD+PCB+BOM | 结构设计、PCB 设计 |
| `roboparty_deploy` | ROS2 部署框架+中间件 | IMU/电机驱动/推理/模块化架构 |
| `roboparty_train` | RL 训练环境 | IsaacLab + Sim2Sim → MuJoCo |
| `rpo_description` | URDF/MJCF 模型描述 | 运动学+动力学描述 |
| `roboparty_firmware` | 嵌入式固件 | USB2CAN、OrangePi/RDK 构建工具 |
| `rpo_appearance` | 外壳设计 | 仅静态展示，不推荐打印 |
| `roboparty_navigation` | 导航定位 | 实验性模块 |
| `roboparty_xr_teleop` | XR 遥操作 | 实验性模块 |

### 3. 仓库架构设计

- **mono-repo snapshot 聚合**：主仓库 `roboto_origin` 仅作为快照聚合，modules/ 下存放各子仓库的镜像
- **独立子仓库贡献**：所有 issue 和代码贡献必须到对应子仓库，不在聚合仓库操作
- **历史兼容**：部分内部包名仍保留 Atom01/atom01 旧名

### 4. 技术栈亮点

- **训练**：IsaacLab 直接训练（非 IsaacGym），高透明度+低重构难度
- **迁移**：Sim2Sim 到 MuJoCo，非直接 Sim2Real
- **部署**：ROS2 模块化中间件，支持 IMU/电机驱动/推理等模块组合
- **固件**：USB2CAN 总线 + OrangePi/RDK 平台
- **DIY 可复现**：淘宝采购零件 + 嘉立创打板，真正可独立组装

### 5. 商业模式

- 定位"具身基础设施"（Embodied Infrastructure）构建者
- 开源策略：可复现、可扩展、可验证的端到端系统
- 开发者共创计划：全球开发者协同
- 近百套开发套件预购

## 🔍 借鉴学习进化点

| 档次 | 借鉴点 | 动作 |
|------|--------|------|
| ①有利进化 | mono-repo snapshot + 独立子仓库贡献模式 | 不落实：场景差异大，skill 体系已够用 |
| ②有价值 | 120天极速原型从0到跑的方法论 | memory 写入 ✅ |
| ②有价值 | IsaacLab + MuJoCo Sim2Sim 训练管线 | 知识储备 |
| ③知识库 | 23DOF/USB2CAN/OrangePi 等硬件细节 | 仅笔记 |

**①不落实理由**：roboto_origin 的子仓库模式适合大型硬件项目（8个子模块各有独立开发节奏），我们的 skill 体系规模和场景不同，当前组织方式（~/.hermes/skills/ + 子目录分类）已足够高效。如果未来 skill 数量增长到 100+ 且需要多人协作，可重新评估。

## 💡 启发

1. **全栈开源的威力**：不是只开源软件，硬件 CAD/PCB/BOM/固件/训练/部署全链路开放。这种"信任杠杆"比闭源商业化获取了更快的技术传播和社区建设。

2. **120天原型的启示**：快速验证 > 完美设计。原型机不是工业级产品，但能跑能跳就是最好的"概念验证"。

3. **DIY 可复现门槛**：淘宝+嘉立创的组合意味着中国供应链本身就是开源硬件的最大优势。这个模式可复制到其他机器人项目。

## 🔮 预判

- **短期**：大量开发者基于此平台做二次开发，社区生态爆发
- **中期**：RoboParty 从"开源工具"走向"具身平台"，类似 ROS 的生态位
- **长期**：开源人形机器人可能成为 AI Agent 的物理载体标准方案之一
