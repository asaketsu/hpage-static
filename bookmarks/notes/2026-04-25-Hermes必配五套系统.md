# 装完 Hermes 一定要配置的五套系统

> 2026-04-25 · 周六 | 标签：Hermes 配置优化 记忆系统 Token 管理 自进化
> 来源：墨与端（AI小2）· 微信公众号 | 实用指数 ★★★★☆

## 核心观点

Hermes 装完只是裸机状态，回答像刚入职的新人——礼貌但空洞。真正的满配版需要五套系统：人格、记忆、网页抓取、搜索兜底、Token 管控。外加一个自进化加分项。

## 五套系统

### 1. 人格系统 — SOUL.md + 角色模板

默认没有"性格"，通过 SOUL.md 给它人格和专业方向。推荐 `agency-agents-zh`（211 个中文角色模板），从小红书写手到政务助手全覆盖。

### 2. 记忆系统 — 换掉"金鱼脑"

自带 MEMORY.md 只有 2000 字上限且选择性记忆。换成 **Hindsight**：自动提取实体/事实/关系，无字符上限，知识是网状结构。`hermes memory setup` → 选 hindsight，免费额度够用。

### 3. 网页抓取四件套

- **Jina Reader** — 单页抓取
- **Crawl4AI** — 批量深度抓取，研究神器
- **Scrapling** — 专克反爬虫
- **CamoFox** — 隐身浏览器，绕高级防护

### 4. 搜索 + 文档处理

- **Tavily** — AI 专用搜索，月 1000 次免费
- **DuckDuckGo** — 零成本兜底
- **Pandoc** — 万能格式转换
- **Marker** — PDF 转 Markdown 增强版

### 5. Token 管控三件套

- **Tokscale** — 实时全局 Token 消耗，TUI 可视化
- **hermes-hudui** — 按模型/组件/会话拆解成本，Web 面板
- **RTK（Rust Token Killer）** — 压缩终端输出，省 60-90% Token

### 加分项：自进化

`hermes-agent-self-evolution` — 遗传算法自动优化提示词和行为脚本，让 AI 自己优化自己。

## 深度思考

文章隐含了一个**六层 Agent 架构模型**：

1. **身份层**（SOUL.md）— 我是谁
2. **记忆层**（Hindsight）— 我记得什么
3. **感知层**（抓取四件套）— 我能获取什么
4. **推理层**（搜索+文档）— 我怎么处理
5. **经济层**（Token 管控）— 成本可控吗
6. **进化层**（Self-evolution）— 能自我优化吗

这是任何 Agent 系统的最小完备集。猫仔前四层和第六层已完善，**第五层经济层最值得补**——Tokscale 实时监控 + RTK 输出压缩，对每天 19 个 cron 的系统，可降低 30-50% 推理成本。

> "裸装 Hermes 和满配 Hermes，是两种完全不同的工具"——工具本身只是骨骼，配置和优化才是灵魂。但部分推荐工具有推广嫌疑，选型应以自身架构需求为准。
