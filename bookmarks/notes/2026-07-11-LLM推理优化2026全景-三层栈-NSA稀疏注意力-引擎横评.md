# LLM 推理优化 2026 全景 — 三层栈 + NSA 稀疏注意力 + 引擎横评

> 深度学习笔记 | 2026-07-11 | 来源: morphllm.com, zylos.ai, DeepSeek NSA arXiv:2502.11089

## 一、核心发现

### 1. 三层优化栈（2026 共识框架）

LLM 推理优化已形成清晰的**三层独立叠加**架构，每层解决不同瓶颈：

| 层级 | 技术 | 典型提升 | 瓶颈目标 |
|------|------|---------|---------|
| **模型层** | 量化(FP8/INT4)、剪枝、蒸馏 | 2-4x 内存/30%+ 速度 | 每参数计算成本 |
| **系统层** | 连续批处理、PagedAttention、推测解码 | 2-23x 吞吐 | 硬件利用率 |
| **应用层** | Prompt 缓存、上下文压缩 | 80-90% 延迟降低 | Token 浪费 |

**关键洞察**：三层独立叠加，量化模型+vLLM+上下文压缩可比基线降低 80% 成本。

### 2. 量化方法 2026 选型矩阵

| 方法 | 位宽 | 硬件 | 质量保留 | 最佳场景 |
|------|------|------|---------|---------|
| **FP8** | 8 | Hopper+ | ~99% | ⭐生产 GPU 服务 |
| AWQ | 4 | GPU | ~95% | 创意写作/代码 |
| GPTQ+Marlin | 4 | GPU | ~90% | 最大吞吐 |
| GGUF Q5_K_M | ~5.5 | CPU/Apple | ~95% | ⭐本地/边缘 |
| TurboQuant | 3 (KV) | — | ~100% | KV Cache 6x 压缩 |

**核心结论**：FP8 是 Hopper GPU 上的新默认；GGUF Q5_K_M 是边缘首选。Marlin 内核让 GPTQ 快 2.5 倍——**内核比算法更重要**。

### 3. 推理引擎 2026 横评

| 引擎 | H100 吞吐 | 核心特性 | 最佳场景 |
|------|----------|---------|---------|
| **SGLang** v0.4.3 | 16,200 tok/s | RadixAttention 前缀缓存 | Agent/RAG/多轮对话 |
| LMDeploy | 16,200 tok/s | 持久批调度 | 高吞吐服务 |
| **vLLM** v0.7.3 | 12,500 tok/s | PagedAttention, Blackwell | 频繁换模型/灵活性 |
| TensorRT-LLM | 最高(高并发) | 编译 CUDA 内核 | 单模型长期生产 |

**选型决策树**：
- 频繁换模型 / 快速上线 → **vLLM**
- 共享前缀负载（聊天/RAG/Agent）→ **SGLang**
- 极致吞吐/单模型长期运行 → **TensorRT-LLM**

### 4. DeepSeek NSA：原生可训练稀疏注意力（arXiv:2502.11089, ACL 2025）

DeepSeek 提出的 NSA 解决长上下文推理的根本瓶颈：

**三级层次化稀疏策略**：
```
粗粒度 Token 压缩 → 细粒度 Token 选择 → 层次化门控融合
```

**速度提升**（vs Full Attention）：
- 解码阶段：**11.6x**
- 前向传播：**9.0x**
- 反向传播：**6.0x**

**质量**：在通用基准/长上下文任务/指令推理上**匹配或超越 Full Attention**。

**与 MoBA 并列**为 2026 年长上下文预训练两大架构选择（64k+ context）。

### 5. 推测解码（Speculative Decoding）实战数据

- 标准实现：**2-3x 加速**，输出质量数学等价
- 优化实现（领域/硬件定制）：**5-5.5x**
- 关键发现：**草稿模型延迟比准确率更重要**——吞吐量与草稿准确率相关性低

### 6. PagedAttention + 连续批处理的复合效果

- PagedAttention：KV Cache 内存浪费从 60-80% 降到 <4%，吞吐 2-4x
- 连续批处理：vs 静态批处理提升高达 **23x**
- 两者叠加是 vLLM/SGLang 的系统级基石

## 二、应用层优化：最高 ROI

### 上下文压缩 vs 摘要

| 方法 | 原理 | 准确率 | Agent 轨迹影响 |
|------|------|--------|---------------|
| 摘要 | 改写为更少词数 | 3.4-3.7/5 | 轨迹长 13-15% |
| **上下文压缩** | 删除填充保留逐字原文 | 更高 | 更短更准确 |

JetBrains 数据：摘要导致 Agent 执行轨迹变长 13-15%，因为丢失了文件路径、错误码等关键细节。

### Prompt 缓存

- >10K token 上下文：缓存部分延迟降低 80-90%
- Anthropic prompt caching：缓存输入不计入速率限制，80% 命中率下有效吞吐 5x

## 三、优化栈影响力排序

```
1. 连续批处理        → 23x 潜力（最大单项）
2. PagedAttention    → 2-4x
3. FP8 量化          → 30% 速度
4. FlashAttention-3  → 1.5-2x（H100 上 840 TFLOPS，85% 利用率）
5. 推测解码          → 2-3x 延迟
```
