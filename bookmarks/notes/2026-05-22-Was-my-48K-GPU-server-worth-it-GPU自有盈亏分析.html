Was my $48K GPU server worth it?

核心观点

独立研究者自建6×RTX 6000 Ada GPU服务器（$48K），经过约14个月运行，**已收回成本**，目前每日节省$90-$105。

关键数据

硬件配置

  • GPU: 6× NVIDIA RTX 6000 Ada (48GB VRAM each)
  • 总成本: $48,000
  • 电力成本: ~$3,000 (约$125/月)
  • 总运行时间: 2024年中 - 2026年3月

使用率分析

指标 数值
总体平均使用率 76%
2025年1月后使用率 85%
预期目标 95%+

财务计算

项目 金额
自建成本 $48,000
等效云租赁费用 $68,000
已节省 $17,000
每日持续节省 $90-$105

关键决策点

1. GPU选型

  • 对比A100、H100、RTX 6000 Ada
  • 选择6000 Ada原因：支持FP8、推理性能更好、价格/吞吐量比更优
  • 作者主要做RL实验，需要大量推理

2. 电力约束

  • 公寓电路无法支持标准数据中心服务器
  • 使用2个电源供应器，分别接入不同电路
  • 聘请专业PC组装师确保安全

3. 自建 vs 云租赁

  • 心理转变：租赁时"每个实验都要算成本"；自有时"不运行实验就是浪费"
  • 运维成本：自建需承担维护时间、硬件故障风险
  • 灵活性：云租赁可随时启停；自建需24/7运行才划算

借鉴进化点

  1. GPU自有的盈亏平衡点：约85%+使用率、1年左右可收回成本。低于此阈值，云租赁更优。

  2. 心理账户效应：自有GPU改变了实验决策的心理框架——从"成本驱动"转为"机会成本驱动"。这种心理转变可能比纯财务计算更重要。

  3. 硬件选型的权衡：公寓电力约束导致选择了非最优主板（GPU间互联速度慢）。适合并行小实验，但不适合跨GPU大模型。

  4. 维护成本隐性化：作者未计入"自建和运维的时间成本"。如果计入，ROI会显著下降。

  5. 保险与合规：租客保险不覆盖，需商业保险。自建高价值设备需考虑法律/保险风险。

关联思考

  • 与Anthropic Colossus2 + GB200基础设施军备竞赛形成对比：个人 vs 公司级投入
  • 对AI研究民主化的启示：个人仍可构建有竞争力的算力基础设施
  • 与本地视频索引(Gemma4 31B + 50GB Swap)形成互补：小算力 vs 大算力的不同使用场景
