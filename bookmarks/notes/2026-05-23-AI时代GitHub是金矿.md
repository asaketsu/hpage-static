## 核心观点

GitHub 早已不只是代码仓库，对普通人来说是：**有 Star 数的小红书 + 不被算法操控的兴趣雷达 + 不会删帖的免费知识库 + 全球极客公开的工作笔记本**。

> 💡 普通人在小红书上学技巧，聪明人在 GitHub 上抄作业。

---

## 一、GitHub 的本质：公开工作台

GitHub 是全世界最聪明的人把工作过程公开放出来的地方。不只是代码，还有教程、资料、清单、模板、工具、踩坑记录、问题争论。

**与中文平台的区别**：

| 平台 | 内容特点 |
|------|----------|
| 小红书/公众号 | 「成品分享」，信息密度低 |
| GitHub | 「工作现场」，信息密度高 |
| 公众号 | 删了就没了 |
| GitHub | 几万人 Star 的仓库，五年后还在 |
| 中文平台 | 算法推送 |
| GitHub | 真实工作痕迹：提交记录、纠错、讨论 |

**普通人用 GitHub 只需三件事**：**读 README、用 Star、Follow 人**——都不需要写代码。

## 三、挖宝路径二：看人，不只是看项目

**进阶玩法**：追踪具体的人。每个 GitHub 用户有公开主页，显示 Star 了什么、Follow 了谁、贡献了什么。

**没有滤镜、没有算法的兴趣雷达**。

### 具体用法

1. 看到好项目 → 点进作者主页
2. 看 ta Star 的列表（认可的同类项目）
3. 看 ta Follow 的人（认可的同行）
4. 顺藤摸瓜，构建优质资源链

> 💡 别只 Star 项目，要 Follow 真人。算法推荐越来越窄，Follow 真人越来越宽。

## 四、用 GitHub 做 5 件非程序员的正经事

### 1. GitHub Pages 免费搭网站

- 免费、简单、无需服务器
- 绑定域名、免费 HTTPS、现成主题插件
- **用途**：个人博客、在线简历、设计师作品集、数字身份证

### 2. Git 版本管理：告别「最终版_真的最终版_v3.docx」

- 任何文件每次修改都有记录
- 随时回滚到任意版本
- 协作改稿每处修改一清二楚
- 不需要写代码，有 GUI 工具可用

### 3. 学英语 + 沉浸式学习领域知识

- README 英文句式简单、词汇有限，比新闻好读
- 一个领域核心词汇反复出现，自然记住
- 看 issue 讨论区学地道英文表达

### 4. 学生党福利：GitHub Student Developer Pack

**国内最值得领**：

- **JetBrains 全家桶免费** — 年费数百美元，学信网可验证
- **GitHub Copilot 免费** — AI 写代码助手

**可用但有门槛**：

- 免费域名（.me/.tech）— 国外托管没问题，国内需 ICP 备案
- AWS / Azure 云服务额度 — 国内访问慢
