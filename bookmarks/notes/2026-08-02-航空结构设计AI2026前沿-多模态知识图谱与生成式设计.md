2025-2026 年航空结构设计 AI 领域出现**三大范式转变**，直接验证并推进了我们 7 月底的研究策划方向：

## 二、VaLiK：免标注多模态知识图谱构建（ICCV 2025）

### 2.1 解决什么问题

传统 MMKG（多模态知识图谱）构建面临两大瓶颈：

| 瓶颈 | 描述 | 传统方案 |
|------|------|---------|
| **标注成本** | 缺乏大规模细粒度实体-图像语料 | 人工标注图像描述 |
| **浅层关系** | 视觉关系检测器只能识别空间关系（"在…上面"），无法提取语义关系 | 预定义标签分类器 |

### 2.2 VaLiK 核心方法

**三步流水线**（全部免标注）：

```
图片输入
   ↓
Step 1: VLM 级联（Chain-of-Experts）
   ↓  将图像特征对齐到文本描述
图像描述文本（含图像特有信息）
   ↓
Step 2: 跨模态相似度验证
   ↓  量化语义一致性，过滤噪声
净化后的文本描述
   ↓
Step 3: LLM 符号化结构化
   ↓  组织成 MMKG
多模态知识图谱
```

### 2.3 关键技术创新

**跨模态相似度重校准机制**：
- VLM 在跨模态推理时会通过幻觉属性引入虚假关系噪声
- VaLiK 通过语义一致性量化，策略性过滤不一致信息
- 保留有效语义对应，丢弃幻觉关联

**存储效率突破**：
- 比传统 MMKG 构建方法**显著减少存储开销**
- 同时保持**直接的实体-图像链接能力**
- 即使压缩图结构后，实体到图像的直接链接仍然可用

### 2.4 实验结果

| 任务 | 数据集 | 结果 |
|------|--------|------|
| 多模态分类 | CrisisMMD | 超越 SOTA |
| 多模态问答 | ScienceQA | 超越 SOTA |
| 存储效率 | — | 显著优于传统 MMKG |

### 2.5 对航空结构设计的启示

**直接可用于我们的 KG 构建方案**：

1. **FEM 结果图 → 文本 → KG**：用 VLM 将有限元分析结果图（应力云图、变形图）转化为文本描述，再结构化为 KG
2. **试验件照片 → 缺陷描述 → KG**：免标注构建试验件损伤知识图谱
3. **适航条款图示 → 条款文本 → KG**：将适航规章中的图示自动转化为结构化约束

## 三、KG-FM：LLM 构建百万级领域知识图谱（Nature 2025）

### 3.1 规模与成果

**框架材料（MOFs/COFs/HOFs）知识图谱**——LLM 自动构建的最大领域 KG：

| 指标 | 数值 |
|------|------|
| 分析文献数 | **10 万+篇** |
| 节点数 | **253 万** |
| 关系数 | **401 万** |
| 存储 | Neo4j 5.12.0 |
| QA 准确率 | **91.67%**（Qwen2-KG） |
| 被引 | 64 次（发表不到 1 年） |

### 3.2 构建流程

```
100,000+ 文献
       ↓
  LLM 信息抽取
       ↓
  实体/关系/属性
       ↓
  Neo4j 图数据库
       ↓
  KG-RAG（知识图谱增强检索）
       ↓
  Qwen2-KG（增强 LLM）
       ↓
  91.67% 准确率问答 + 来源引用
```

### 3.3 KG-LLM 增强的关键发现

| 技术 | 效果 |
|------|------|
| **KG 注入 CoT 推理** | 显著提升推理质量（材料筛选任务） |
| **事实来源引用** | 精确回答 + 可追溯来源 |
| **RAG 实时更新** | 无需重训 LLM 即可更新知识 |

### 3.4 对航空结构设计 KG 的直接借鉴

KG-FM 证明了 LLM 构建大规模领域 KG 的可行性。**直接迁移路径**：

| KG-FM 框架材料 | 航空结构设计 |
|---------------|-------------|
| 10 万篇材料论文 | 适航规章 + 设计手册 + FEM 报告 + 试验报告 |
| 合成/性质/应用实体 | 材料/结构/载荷/失效模式实体 |
| Qwen2-KG 材料 QA | Aero-KG 结构设计 QA |
| Neo4j 存储 | Neo4j 存储（完全复用） |
| 91.67% 准确率 | 预期 85-90%（航空领域更复杂） |

## 四、生成式设计 2026：从拓扑优化到几何基础模型

### 4.1 范式演进

```
第一代：拓扑优化（1990s-2020s）
  数学优化 + FEM 迭代 → 渐进式材料分布
  局限：只在现有设计空间内优化

第二代：生成式 AI 设计（2020s）
  GAN/Diffusion 生成新设计
  局限：训练数据限制创新空间

第三代：几何基础模型（2025-2026）
  大规模 3D 形状预训练 → 发现人类未曾设想的设计
  突破：跨领域几何知识迁移
```

### 4.2 PhysicsX LGM-Aero：大型几何模型

| 指标 | 数值 |
|------|------|
| 参数量 | 100M（≈ GPT-1 规模） |
| 训练数据 | **2500 万多样 3D 形状** |
| 部署 | 已用于真实客户挑战 |
| 表现 | 超越当前 SOTA 工程流程 |

**核心洞察**：
> "只在传统飞机上训练的生成模型无法产生双翼机，但几何基础模型可以，因为它见过数百万种几何形状。"

**意义**：最大的性能提升往往来自**完全重新设计零件**，而非微调现有设计的几个方面。

## 五、Agentic 气动设计框架（HKUST + U Michigan 2025）

### 5.1 核心创新

首个将 **LLM 作为多学科设计优化（MDO）的编排器**的研究：

```
用户自然语言需求
       ↓
  Gemini 2.0 Flash（成本效益 + 免费 API）
       ↓
  Agentic Workflow（多步推理 + 工具调用）
       ↓
  翼型/机翼气动优化
```

### 5.2 关键设计选择

| 选择 | 理由 |
|------|------|
| **Gemini 而非 GPT/Llama** | 成本效益 + 免费 API，适合开放研究 |
| **Gemini 2.0 Flash** | 优于更复杂版本（速度/成本权衡） |
| **Digital Twin 范式** | 虚拟模型必须"fit-for-purpose"，而非精美复制 |

### 5.3 对飞机结构设计的启示

将 LLM 从"知识查询"扩展到"**设计编排**"：
- 结构设计不是单点优化，而是多学科权衡
- LLM 天然适合编排多步设计流程
- 可与我们的 KG 结合：KG 提供约束知识，LLM 编排设计流程
