一、内容整理

0. 核心命题

"换信息源就是换信息选择权" — 算法推送让你别无选择，newsletter 定向获取保护注意力
效率主张：一天只精读 3 篇，拿到 100 篇的知识量——3 篇进脑子，97 篇进知识库

1. 第一步：更换到低能量信息源（附完整清单）

信息源筛选逻辑：一年时间从 100+ 个源筛出高质量源，按职业分类对号入座。

碎片化 vs newsletter 对比：
- 碎片短信息不产生深刻记忆（测试：回忆 20 分钟前刷过的高价值推文——大概率已忘）
- 算法直接推送 = 别无选择只能阅读；newsletter = 定向获取，保护注意力

2. Newsletter 整理三步法（Gmail/网易邮箱大师）

  1. 让 MailAgent 找出你订了哪些：读最近三个月邮件，把 AI newsletter 发件人地址全揪出来
  2. 生成 Gmail 过滤器规则：多地址 OR 合并，过滤器只建一次
  3. 建标签 + 过滤器：标签"ai newsletter"，动作勾应用标签 + 跳过收件箱（第二个必须勾——newsletter 不进收件箱直接进文件夹），弹窗"同时应用到当前匹配的会话"也勾上

3. 低能量阅读法：一天 3 篇，100 篇的知识量

四步法：
1. Agent 汇总清单：让 MailAgent 把上百封 newsletter 总结成一张清单（一条一行），原来翻 51 封邮件 → 现在看一屏
2. 把主流观点全划掉：主流观点日常已被反复喂过（社媒、群聊、其他 newsletter 都写过），再读增量为零。只挑非主流的：别人没说的角度、跟共识拧着的判断、没见过的数据
3. 一天挑 3 篇精读：如"AI 泡沫风险"这种跟主流反着的
4. 剩下 97 篇不读但存：不值得读 ≠ 不值得存。让 MailAgent 把文章地址列出，全部编译进知识库

知识库技术选型：Karpathy 的 LLM Wiki——Agent 把每篇文章的概念、主张、开放问题拆成卡片，新卡片与已有卡片连接，日积月累成一张活的知识网络。

4. 低能量输出法：不从零开始写

  1. 把知识库 index 丢给 AI：index 登记所有知识页面的标题和摘要。AI 分级检索（先读 index 定位 → 再读具体页面），token 省。进阶：写进 Claude Code 的 CLAUDE.md——"需要了解我的时候，去读这个目录下的 Wiki"。这一步 AI 输出 60 分
  2. 卡住的地方直接问作者（最值钱的一步）：想不透"作者为什么敢这么说"，答案只在作者脑子里。newsletter 作者的邮箱就在邮件里，点回复即可——推文评论他大概率看不到，认真的邮件大概率会回。英文邮件交给 Mail Agent（写信/润色/翻译三动作 + 记忆系统记你的身份和语气）。有原作者解答和背书，阅读量翻倍
  3. 写完自己润稿：AI 会记错会编，凡具体数字、人名、时间、引述一律回原文核。润色把文章拉到 80 分

5. 全流程一句话总结

newsletter 进专属文件夹 → 3 篇进脑子，97 篇进知识库 → 知识库反喂输出 → 卡住回信问作者

工具链：网易邮箱 + 邮箱大师客户端 + Mail Agent（软广属性，方法论通用）

二、查询拓展

  1. Gary Marcus 唱反调的价值边界：持续反向观点在什么条件下失效（如他长期看空 LLM 的论点哪些被证伪）？
  2. LLM Wiki vs Obsidian/RAG：Karpathy 方案的卡片-连接模型与传统双链笔记、向量 RAG 的检索质量差异
  3. "主流观点增量为零"的判定标准：如何程序化判定一条信息是否已在个人知识网络中（去重阈值怎么定）？
  4. 问作者的回复率数据：newsletter 作者对读者邮件的真实回复率分布（大 V vs 小作者）
  5. 51 封 → 1 屏的压缩损失：Agent 总结清单时丢掉的非主流观点如何兜底（作者承认流程里第 3 步漏编号，原文只有四步法却写成"四步"实列三步+处理流程）

三、归纳总结

维度 要点
核心思想 注意力是稀缺资源，信息选择权 > 信息量；"低能量"= 用最小认知开销维持高质量输入输出
输入侧 100+ 源 → 14 个精选 newsletter（按职业分三类），Gmail 过滤器自动化归档
处理侧 Agent 汇总成清单 → 划掉主流观点 → 挑 3 篇非主流精读 → 97 篇编译进 LLM Wiki
输出侧 知识库 index 喂 AI 起草 → 问作者补认知盲区 → 人工核数字润语气
可复制性 方法论工具无关（网易邮箱可换成任何带 AI 的邮件客户端）；核心是流程不是工具

四、趋势判断

  1. 邮件 Newsletter 正在成为 AI 时代的"反算法避难所"：创作者绕开平台算法直达订阅者，读者夺回选择权——与 RSS 复兴同构，X/公众号的算法疲劳在加速这个迁移
  2. "97 篇进知识库"代表阅读的资产化转向：从"读过"到"存进可检索的知识网络"，LLM Wiki 类方案让未精读内容也产生长尾价值——这是 RAG 个人化的先声
  3. 问作者环节暴露 AI 的天花板：作者明说"这些问题 AI 答不了，答案只在作者脑子里"——人际网络仍是最高价值信息源，AI 降低的是接触人际网络的门槛（英文邮件代写）
  4. Mail Agent 软文标志着邮箱厂商把 AI 当增量入口：方法论是真，案例是广告——判断内容时注意"通用流程"与"特定工具"的分离
