一、内容详细整理

1.1 四大方案速查

  • 单目 RGB（2D）：小孔成像，CMOS 采集环境光投影为 2D 像素平面。深度靠 AI 模型估算
  • 双目立体（2.5D）：模仿人眼视差，两台同步相机 + 固定基线，三角几何直接计算物理深度
  • 结构光（3D）：主动投射编码光斑/条纹，采集形变图案，三角测距解算三维外形
  • ToF 飞行时间（3D）：发射高频调制红外光，记录往返时间差/相位差，直接换算距离

1.2 单目 RGB 相机

原理：小孔成像模型 → 三维场景压缩为二维像素平面，丢失深度维度

优势：结构最简单成本最低；分辨率上限高纹理细腻；标定简单稳定性高；常规光照通用性强

缺陷：无原生深度（靠 AI 推算）；弱纹理区域深度失效；尺度混淆（近处小物体 vs 远处大物体）；无法独立完成高精度避障

场景：自动驾驶前视主摄、纯视觉 SLAM、标识识别；搭配 BEV 深度模型或激光雷达弥补

1.3 双目立体相机

原理：两台参数一致的相机固定基线间距，同步拍摄同一帧，算法匹配左右画面像素坐标计算视差，三角几何直接换算深度

视差越大 → 物体越近；视差越小 → 物体越远

优势：物理计算生成深度（可信度高于 AI 估算）；输出稠密深度图；被动视觉（无需主动光源）；户外鲁棒性好

缺陷：高度依赖环境纹理（纯白墙面/大雾失效）；算力消耗偏高（立体校正+逐像素匹配+视差优化）；标定维护严苛（震动/热变形/松动 → 基线漂移）

场景：室外巡检机器人、无人机、NAV2 室内小车辅助定位

1.4 结构光相机

原理：主动投射编码光斑/条纹/网格 → 光线接触物体表面形变 → 接收相机采集畸变图案 → 三角测距解算深度

本质："主动制造人工纹理"，即使纯白无纹理环境也能提供可匹配特征点

优势：黑暗环境稳定工作；无纹理场景正常工作；近距离精度毫米级；深度图细节丰富

缺陷：太阳光下完全失效（自然红外光冲刷编码光斑）；有效距离短；成本/体积高于双目

场景：仅适配室内 — 人形机器人机械臂抓取、三维扫描、人脸识别门禁

1.5 ToF 飞行时间相机

原理：发射高频调制红外光 → 光线接触物体折返 → 芯片记录时间差/相位差 → 结合光速换算距离

优势：帧率高响应快（高速动态避障）；算力需求低（无需像素匹配）；黑暗环境稳定；硬件简化成本低于结构光

缺陷：深度图分辨率低（仅大致轮廓）；远距离精度衰减明显；多台设备近距离红外串扰；户外强光红外信号被抵消

场景：扫地机器人/AGV 近距离避障、低算力嵌入式设备、人体感应

1.6 工程选型逻辑

  • 侧重语义识别 + 大规模量产 + 长期稳定 → 单目 RGB + BEV
  • 户外场景 + 需要纯视觉原生物理深度 → 双目
  • 室内场景 + 毫米级精度抓取/建模 → 结构光
  • 硬件算力有限 + 近距离快速测距 → ToF

二、查询拓展

2.1 BEV（Bird's Eye View）深度估计

单目相机无原生深度，BEV（鸟瞰图）方案通过 Transformer 将多摄像头 2D 图像特征转换到 3D 鸟瞰空间统一表示。BEVFormer / BEVDepth / Sparse4D 等模型通过注意力机制学习 2D→3D 的几何映射，使单目/多目系统能输出深度估计。但本质仍是"基于大数据的统计拟合"，远距离精度不如物理测量。

2.2 结构光编码方案

结构光编码分两类：(1) 空间编码（如 De Bruijn 序列、M-array）—— 单帧投射编码图案，适合动态场景；(2) 时间编码（如 Gray Code、Phase Shift）—— 多帧投射不同图案，精度更高但不适合动态物体。Kinect V1 使用 Light Coding（散斑结构光），RealSense D435 使用 IR Stereo（红外立体+主动投射器）。

2.3 ToF 的间接式（iToF）与直接式（dToF）

  • iToF（Indirect）：测相位差，连续调制光，适合中近距离（0.1-5m），分辨率较高。iPhone Face ID / RealSense L515 使用
  • dToF（Direct）：直接测光子飞行时间（SPAD 阵列），适合远距离（>100m），抗干扰强。iPhone LiDAR / 车载激光雷达使用

四、趋势判断

  • 多传感器融合是终极方案：高端方案不单独依赖某一种视觉，而是单目+激光雷达+ToF/结构光融合，BEV 框架统一空间建模
  • dToF 下沉：iPhone LiDAR 推动 SPAD 阵列成本下降，未来扫地机器人/AR 眼镜可能标配 dToF
  • AI 弥补物理缺陷：单目 BEV 深度模型持续进化，弱纹理/远距离精度差距在缩小

五、关联分析
