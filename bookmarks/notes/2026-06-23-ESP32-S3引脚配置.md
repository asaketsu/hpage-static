# ESP32-S3 引脚配置入门指南

> 来源：微信公众号文章  
> 项目地址：https://github.com/atomic14/esp32-s3-pinouts  
> 日期：2026-06-23

## 核心观点
ESP32-S3 引脚丰富但配置复杂，初学者需了解引脚功能分类和特殊引脚限制，避免冲突和毛刺问题。

## 引脚分类

| 类型 | 说明 |
|------|------|
| **电源引脚** | GND、VCC、EN，为芯片提供电源 |
| **GPIO 引脚** | 通用输入输出，支持数字IO、PWM、I2C、SPI等 |
| **UART 引脚** | 串口通信，连接串口调试器 |
| **USB 引脚** | USB连接，下载程序或与电脑通信 |
| **其他引脚** | JTAG、ADC、电源管理引脚等 |

## 特殊引脚注意事项

| 引脚 | 用途 | 注意事项 |
|------|------|----------|
| **GPIO0 / GPIO46** | 启动模式控制 | 开发过程中避免直接使用 |
| **GPIO35 / 36 / 37** | PSRAM（带PSRAM模块的板子） | 不可用于其他功能 |
| **GPIO39 / 40 / 41 / 42** | JTAG | 默认可安全使用，需JTAG时需配置eFuses |
| **GPIO43 / 44** | UART0（默认） | 可配置为其他功能 |

## 使用要点

1. **引脚冲突**：多个功能共用同一引脚时需避免冲突（如GPIO35作为SPI则不能同时作为JTAG）
2. **电源毛刺**：部分引脚上电时存在毛刺，需注意避免影响程序运行
3. **查阅数据手册**：使用前仔细阅读ESP32-S3数据手册，了解每个引脚的功能和限制
