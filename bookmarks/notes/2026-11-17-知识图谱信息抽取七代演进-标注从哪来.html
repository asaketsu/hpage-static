内容整理：七代方法谱系

任务定义——信息抽取的五个组成部分

  1. 找实体（NER）
  2. 定关系（RE）
  3. 识别事件（EE）
  4. 抽属性
  5. 实体链接——把「苹果」消歧成公司而不是水果

七代演进总表

代 时期 代表工作 核心机制 标注从哪来 代价/局限
一、规则时代 1980s–1992 DARPA MUC 评测；FASTUS；Hearst Patterns (1992) 语言学家手写语法规则；Hearst 换思路去语料找 such as 类句式——天然暴露上下位关系 人工写规则/人工枚举模式 限定领域很准，换领域整套重写；模式清单仍要人一条条列
二、自举 1998–2000 DIPRE (1998)；Snowball 5 个种子对迭代滚雪球，几轮从 2400 万网页抽出 1.5 万本书 人只标极少种子 语义漂移越滚越歪；Snowball 给每个模式加置信度刹车
三、特征与核方法 ~2004–2008 Kambhatla (2004) 特征模板；最短依存路径核 关系判断变成分类问题；核方法发现关系信息高度集中在两实体的依存路径上 大量人工标注 特征模板火了十年，但标注成本高企
四、远程监督 2009（真正转折） Mintz；后续多实例学习 / MultiR / MIML-RE 知识库里两实体有某关系 ⇒ 所有同时提到它们的句子都算正例 知识库反哺，零标注一夜百万级 噪声大：MIL 把句子装包只求一句对；MultiR 处理重叠关系；MIML-RE 固化通用框架
五、深度学习 2014–2021 Zeng 2014 CNN + 位置特征；PCNN 分段卷积；选择性注意力；CasRel→TPLinker→REBEL 告诉网络每个词离实体多远；挑可信句子；联合抽取从级联标注→单阶段对齐→直接生成三元组 继承远程监督数据 —
六、统一框架 2022 UIE 关系抽取/实体识别/事件抽取全压成一套 schema 生成 预训练 + 指令化 近年最流行方式
七、LLM 时代 2023– ChatIE（对话零样本）；UniversalNER（蒸馏小模型开放域 NER）；GraphRAG（抽取→建图→检索闭环） 零样本抽取、小模型蒸馏、闭环串联 零样本/少样本 垂域零样本打不过充分训练的小模型

关键转折：2009 年的知识库角色反转

Mintz 远程监督（Distant Supervision）是整条演进链的枢纽：知识库从「被填充的目标」变成「训练抽取器的燃料」。监督信号来源第一次脱离人工——不是人标得更聪明，而是不再需要人标。此后十几年（MIL→MultiR→MIML-RE→PCNN→注意力）本质上都在消化这一转向带来的噪声。

作者核心判断（结尾观点）

垂域知识抽取上，GPT 类模型在零样本关系抽取和事件抽取上打不过充分训练过的小模型；LLM 的优势在少样本和开放域。

（核验注：与 UniversalNER 2024 实证方向一致——蒸馏专用小模型在 NER 任务上超过 GPT-3.5/4 零样本表现，业界共识度较高。）

查询拓展

  • Mintz 2009《Distant supervision for relation extraction without labeled data》——远程监督原始定义，KG 反哺思想的源头文献
  • UIE (Lu et al., ACL 2022)——统一 schema 生成范式的代表，当前工业界垂域抽取的主流底座（PaddleNLP 已产品化）
  • UniversalNER (2024)——「蒸馏 ChatGPT 做开放域 NER」，直接支撑作者结尾判断的实证
  • Brin 1998《Extracting Patterns and Relations from the World Wide Web》——DIPRE 原文，Google 创始人写的 IE 论文，自举时代的起点
  • GraphRAG (Microsoft 2024)——第七代的闭环形态，库内已有成本实测笔记（见关联分析）

归纳总结

  • 主线一以贯之：七代方法换的是「标注从哪来」的答案——人工规则 → 人工种子 → 人工标注 → 知识库反哺 → 深度特征自动学 → 指令统一预训练 → LLM 零样本。每一次范式迁移，本质都是上一代标注成本的破产重组。
  • 「有多少人工就有多少智能」的真正解法：不是不要人工，而是把人工从「逐句标注」赶到「写规则/标种子/建知识库」这些能被自举放大的位置上。远程监督是这一思路的极致——已有结构化知识本身就是标注机。
  • 能力分层的实用结论：垂域 + 高频 + schema 稳定 → 微调小模型（UIE 类）；开放域 + 冷启动 + schema 多变 → LLM。这不是技术怀旧，是当前精度与成本的双重最优。
  • 方法谱系的复利：七代不是取代关系而是叠加关系——Hearst 模式至今仍在造数据，远程监督至今仍在供数据，UIE 至今仍在做底座。选型时应把七代当工具箱而非淘汰史。

趋势判断

  • 抽取与检索的合流：第七代 GraphRAG 把「抽取→建图→检索」串成闭环，意味着 IE 从独立任务变成 RAG 系统的索引前置环节——IE 的质量直接决定多跳推理上限（与库内《向量检索不够用 GraphRAG 才是多跳推理的答案》的结论互为上下游）。
  • 小模型在垂域的持续主场：LLM 通用能力增长并不自动转化为垂域抽取精度——schema 忠实度、幻觉控制、单位成本三重约束下，「LLM 造数据/评质量 + 小模型做推理」的蒸馏分工（UniversalNER 路线）大概率是未来两年的工业主流。
  • 标注问题的下一站：远程监督解决了「句子级标注从哪来」，但 schema 本身（本体设计、关系类型清单）仍靠专家。KG-FM 类「LLM 从文献自动发现 schema」的方向（见航空 KG 笔记）正在攻这最后一公里——标注从哪来的答案，正在从「数据标注」迁移到「schema 发现」。

拓展应用推荐

  • 垂域 KG 立项时的选型决策表（适航条款/型号资料场景）：schema 冷启动用 LLM 抽样探路 → 高频稳定关系转 UIE 类微调小模型 → 开放域补抽与长尾留给 LLM → 成本敏感环节（百万级文档批处理）禁用 LLM 逐句抽取（GraphRAG 笔记的 token 成本实测为证）
  • UniversalNER 式蒸馏流水线：LLM 批量造标注数据 + 一致性过滤 + 蒸馏小模型——「LLM 当老师不当工人」的性价比模板，可复用于任何垂域结构化任务（不只是 NER）

指南分析

作者给出的隐式决策指南，可提炼为三问：

  1. 你的 schema 稳定吗？ 稳定 → 微调小模型路线（第四~六代武器库）；多变/未定义 → LLM 路线（第七代）
  2. 你的语料量级多大？ 百万级批处理 → 成本主导，小模型必选；千级以下 → LLM 少样本直接上，省去训练环节
  3. 你容忍噪声还是容忍遗漏？ 远程监督数据天然带噪（适合 MIL 类鲁棒训练）；规则/模式抽取精确但召回有限（Hearst 模式适合造高精度种子集）

反例警示：拿着 LLM 在垂域高频关系上做零样本批量抽取，同时承担精度损失与 token 成本双重惩罚——这是当前最常见的选型错误。
