CompanionBot：双脑家庭陪伴机器人方案

来源：智财社 —「越疆也要发陪伴机器人了」
日期：2026-06-23

核心观点

CompanionBot — 兼具"物理脑"（做事能力）与"情感脑"（陪伴能力）的家庭机器人，填补"工具"与"伙伴"之间的空白。

维度 数据

中国单身人口 约2亿
中国独居家庭 约6000万

竞品对比

公司 产品 价格 核心策略
优必选 U1 >$15万 人设+情感投射
上纬启元 Q1 $6.99万 科研教育+创作平台
越疆 轮式人形 千台级订单 物理脑（工业迁移）
CompanionBot — 目标<$6,000 物理+情感双脑

双脑架构

模块 情感脑 物理脑
感知 语音语调 + 面部表情 深度相机 + 激光雷达
认知 情感记忆 + 偏好学习 SLAM建图 + 物体识别
决策 陪伴策略（提醒/鼓励/安慰） 导航避障 + 抓取规划
执行 语音对话 + 表情反馈 机械臂递物 + 整理

类别 成本（美元）

交互系统（屏幕+扬声器） $200

开发路线

Phase 1 (4-6周): 原型验证 → ROS 2 + 传感器 + 基础导航
  ↓
Phase 2 (6-8周): 物理脑增强 → 机械臂 + 物体识别 + 抓取
  ↓
Phase 3 (6-8周): 情感脑开发 → 情绪识别 + 情感记忆 + 陪伴策略
  ↓
Phase 4 (4-6周): 双脑融合 → 联合调度 + AgenticROS集成
  ↓
Phase 5 (8-12周): 产品化 → 结构优化 + 用户测试 + 量产

核心差异化

CompanionBot不做"会聊天的雕塑"，也不做"冷冰冰的工具"——我们要做的是既能帮你递杯水、整理桌面，又能听懂你"今天好累"并轻声安慰的真实陪伴者。
