核心论点

Full Attention 从未过时。 不需要替换架构，仅通过释放模型内生的稀疏性，就能在精度几乎无损的前提下实现 5~30x 的 KV 和 Attention 压缩。

背景格局

技术路线 代表模型 核心思路 压缩效果
Linear Attention Qwen-Next, Kimi-K2 改进线性注意力做信息压缩 存储 O(1)，计算 O(N)
Sparse Attention DeepSeek-V4 稀疏化优化计算 稀疏度 >90%
SWA + Full Attention MIMO, Gemma4, GPT-OSS 混合架构（15% Full + 85% SWA） 5x 压缩（RTPurbo V1）
RTPurboV2 本文 在 V1 基础上压缩 Full Attention 部分 再 16~32x，总计 80~160x

四大关键发现

发现一：85% 注意力头天然适配滑动窗口

预训练模型自发形成两类 Attention Head 分工：

  • 召回头（Retrieval Head，约 15%）：注意力分布稀疏，只关注关键 token，负责长距离信息召回
  • 流式头（Streaming Head，约 85%）：注意力分布均匀，关注局部上下文

关键结论：85% 的 Full Attention 可安全替换为 SWA（窗口 8192），几乎不影响能力。真正需要解决的是剩余 15% 召回头的高效计算。

发现二：长程检索由低维子空间主导

深入分析 RoPE 位置编码后，发现召回头存在维度冗余：

  • 低频分量（θ_i 较小）：承载语义相关性信号 → 有用
  • 高频分量（θ_i 较大）：随距离快速振荡，引入干扰 → 被召回头自动压制

解决方案：训练低秩投影器，将特征维度从 D 压缩至 r=16（r ≪ D），仅 16 维即达 90%+ 召回率。

发现三：序列维度的冗余——自适应聚类

低秩投影过滤高频噪声后，语义相似的 token 天然聚拢。构建两级漏斗：

  1. 粗粒度匹配：N 个 token → K 个语义簇（K=128），复杂度 O(N·K)
  2. 细粒度计算：仅在命中簇内执行完整 Attention

特征压缩与序列压缩形成乘法效应：压缩比越激进，协同增益越显著。

发现四：动态 top-p > 固定 top-k

三个召回头覆盖 90% 注意力质量所需 token 数相差三个数量级。不存在固定 k 值能满足所有场景。

方案：动态 top-p 策略 + 无排序解码核（256-bin 直方图替代排序），内存开销压缩至 O(1)。

推理架构

流式头 (85%)  →  SWA（窗口 8192）
召回头 (15%)  →  低秩投影 + 聚类索引 + 动态 top-p

两阶段微调训练

仅需约 600 步 / 1M label tokens（在数十万亿 token 预训练语境下几乎可忽略）：

阶段 目标 方法
阶段 1 投影对齐 冻结模型主体，仅训练低秩投影矩阵，最小化 KL 散度
阶段 2 端到端自蒸馏 启用稀疏模式，学习原始稠密模型的 next-token 预测分布

微调的本质：不是「教会」模型新能力，而是将模型隐式已有的稀疏性转化为显式结构。

实验结果

基准 模型 结果
Ruler（长程检索） Qwen3-Coder-30B-A3B 32K: 89.69, 64K: 85.61，显著优于所有基线
LongBenchV2 Qwen3.5-35B-A3B 全量稀疏化（70%+ 召回头），精度与 Full Attention 持平
CoT 推理 Qwen3-Coder-30B-A3B 推理能力近乎无损保留
Prefill 加速 — 最高 9.36x

吸收要点

  1. 内生稀疏性是免费的午餐：Full Attention 模型本身就蕴含巨大效率空间，释放成本极低（600 步微调）
  2. 「发现 > 发明」的方法论：不是设计新架构强加给模型，而是观察模型已自发习得的结构并加以利用
  3. 混合架构是工程最优解：15% Full + 85% SWA 的「大道至简」设计在实践中表现最稳健
  4. 低秩投影的复用价值：不仅降低计算量，更从根本改善 Key 向量的语义分布质量，为下游聚类创造理想条件
  5. 对推理部署的影响：选择 SWA + Full Attention 混合架构的团队无需替换架构即可获得接近 SOTA 的压缩效率
