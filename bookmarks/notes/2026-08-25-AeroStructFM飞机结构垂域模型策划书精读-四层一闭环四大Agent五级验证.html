一、背景与定义（前篇 §1-3）

1.1 传统流程四矛盾

需求→载荷→布局→CAD→FEA→静强/模态/颤振/疲劳→优化→试验→修改，存在：

矛盾 深层机理（深化篇 §1.1） 垂域模型切入点
高保真 vs 高效率 几何/材料非线性、复材各向异性、接触、热力/气弹耦合、多工况随机载荷 神经算子秒级预测
优化算法 vs 设计空间 SIMP/Level Set 是纯数值密度场寻优，缺“结构功能语义”；设计空间一变就重算 语义理解压缩搜索空间至工程可行子空间
设计与运行割裂 设计端知道"理论上如何响应"，运行端知道"实际经历什么" 数字孪生实时闭环
数据知识碎片化 CAD/CAE/PLM/试验库/飞参/SHM/维修/规范/专家知识九类异构 统一 Token 体系编码为可计算知识

1.2 ASDFM 定义与模型族

定义：以飞机结构领域知识、物理规律和多源工程数据为基础，通过多模态基础模型、神经算子、生成模型和智能代理实现结构设计、仿真、监测、预测和决策的一体化基础模型——不是单一模型，是模型族：

M_AS = {M_LLM(语言), M_Geo(几何/拓扑), M_Physics(物理知识), M_Operator(结构场算子), M_Damage(损伤寿命), M_Twin(孪生), M_Agent(决策代理)}

四层一闭环：基础数据层 → 物理模型层 → 垂域基础模型层 → 恰能应用层 → 设计-制造-试验-运行-维护数据闭环。

1.3 AeroStruct-FM 生态定位（深化篇）

基座层（多模态物理感知 FM）+ 智能体层（四 Agent）+ 工具链层（FEA/CAD/材料库/试验台）+ 知识层（知识图谱+规范库作长期记忆）。

模型 职责
A：Design FM 概念设计/拓扑/梯度/参数优化/多方案生成
B：Physics FM 应力/应变/位移/模态/屈曲/动响应/气动载荷

D：Decision Agent 设计决策/仿真调用/试验规划/维修决策/风险评估

五阶段训练：①基础预训练（历史 FEA/试验/CAD/材料/论文/规范/维修）→ ②物理预训练（10^5~10^7 虚拟仿真，变几何/材料/载荷/边界/缺陷/温度）→ ③多任务（Topology/Stress/Displacement/Modal/Damage/Life 同训）→ ④工程微调（真实试验/飞机/SHM）→ ⑤在线学习（New Data→Twin→Model Update 持续闭环）。

深化篇补充（§4.1 多模态对齐三机制）：
- CGPP（Contrastive Geometry-Physics Pretraining）：50 万对 (CAD 几何, FEA 应力场) 对比学习
- Text-Guided Geometry Generation：10 万对 (设计文本, CAD) 语义一致性+几何有效性
- Sensor-to-Field Mapping：5 万对 (稀疏传感器, 全场仿真) 重建训练——直接服务"虚拟传感器"

部署：INT8 量化 Text Encoder + FP16 Neural Operator + TensorRT + Triton + 语义缓存；SHM 蒸馏 <100M 上机载边缘。

五、数据工程（深化篇 §5，策划书最落地部分）

仿真数据流水线：参数化 CAD（翼盒展弦比/锥比/后掠/肋数/梁位）→ 拉丁超立方采样 10 万+组合 → 自动网格 → Nastran/Abaqus 批量（静强/模态/屈曲/疲劳）→ 物理一致性自检剔除 → HDF5/Zarr → 版本化数据湖。日均产能：64 核集群日产 ~5000 案例；元数据按 ASME V&V 20 记录不确定性。

知识图谱 Schema：7 实体（Material/Component/Load_Case/Failure_Mode/Design_Rule/Test_Method/Manufacturing_Process）× 10 关系（has_material/fails_by/governed_by/validated_by/similar_to/supersedes/manufacturable_by...）。

标注质控：三级审核+专家抽检≥10%；Kappa>0.85 / ICC>0.90；主动学习循环送标。

版本与溯源：DVC/LakeFS + 数据 snapshot hash + 完整血缘（来源→处理→标注→模型版本）+ License 合规元数据。
