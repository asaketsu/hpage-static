一、内容详细整理

半世纪范式之争的根源

认知科学的两大传统对"心智"看法根本不同：

维度 贝叶斯传统（自上而下） 联结主义传统（自下而上）
方法论 马尔"计算层面"分析 简单计算单元涌现表征
假设形式 结构化表征（规则/文法/程序） 连接权重中的分布式表征
先验 假设上的概率信念 更一般、少人为设定
学习 信念的贝叶斯更新 权重学习
优势 一两个例子学新概念；可解释 灵活逼近自然数据复杂度
短板 过度简化（符号化/参数化/独立性假设只是一阶近似） 数据饥渴、黑箱
计算成本 预测要在巨大假设空间求和（常不可解只能粗近似） 训练贵但推理快（一次前向）

研究者被迫二选一：要强先验与可解释就忍受贝叶斯的简化与高推理成本；要灵活与高效就接受神经网络的数据饥渴与黑箱。BBT 要打破这种取舍。

BBT 两步配方

第一步：贝叶斯蒸馏。用成熟贝叶斯工具把先验知识/归纳偏置指定为贝叶斯模型 → 前向采样（从先验采样假设、似然生成输入输出对）产生大量合成数据 → 训练 Transformer 逼近该贝叶斯模型的后验预测分布。关键：不需要做贝叶斯推理，只需从模型里"抽数据"。训练后权重冻结，新任务学习完全靠前向传播——本质是基于记忆的元学习。

第二步：行为微调。在人类行为数据上微调蒸馏网络，捕捉额外结构。不再受原贝叶斯先验、似然甚至贝叶斯推理逻辑约束——只要人类行为支持，可以改变先验、改变假设与数据的关系、甚至引入无法用简单符号描述的新假设。

频谱定位：贝叶斯端（强先验/符号化/参数化）↔ 联结主义端（弱先验/亚符号化/非参数化）；BBT 从贝叶斯端出发，微调后按数据质量自适应停在中间某位置。作者强调这是模型拟合流程，不是认知发展主张。

四个案例实测（共用同一 3000 万参数架构）

① 数字概念学习（Tenenbaum 数字游戏）：给神秘程序生成的数字，判断新数字是否属同类。
- BBT 预测人类是/否判断相关 r=0.81（RMSE=0.153）vs 经典贝叶斯 r=0.66
- 留出数据对数似然领先 3175 个自然对数点
- 对照组：只微调不蒸馏的网络表现最差——贝叶斯蒸馏这个"先验注入"步骤是关键

② 逻辑概念学习（Piantadosi 108 概念）：
- 优于原研究考察的全部 21 个贝叶斯模型，对数似然至少领先 7826 自然对数点
- 预测相关 r=0.88，对微调时从未见过的概念保持泛化

③ Shepard 概念学习（逐块学习的记忆与归纳）：
- 复现人类学习轨迹（相关 r=0.938）
- 刻画出年龄差异：模拟年轻成人正确率 86.9%/老年 77.7%，对应真实人类 78.6%/65.9%
- 跨研究泛化：一项研究微调好的模型预测六年后、不同实验范式的另一研究，仍保持接近水平

④ 组合式指令学习（Lake & Baroni 元学习任务）：
- 人类系统性偏置：一对一映射偏置（占人类错误 24.4%）、图标拼接偏置（23.3%）
- BBT 无需手工设计就学会了这些偏置，对数似然（-343.6）还略优于手工注入偏置的模型（-349.2）

最重要发现：人脑"偏爱简单"

对比微调前后内部表征，四个任务一致规律：微调后模型系统性转向更简单的假设——

  • 数字任务：偶数/奇数、以某数字结尾等简单规则影响力大升；幂、倍数等复杂规则减弱
  • 逻辑任务：带量词的复杂规则让位于简单规则乃至常数
  • Shepard 任务：单特征 Type I 规则占比上升，年轻人比老年人更快转向简单策略

心理学解释：人类行为系统性偏离理想贝叶斯推断，向"简单启发式"倾斜——这是纯贝叶斯模型看不到也解释不了的。

与 LLM 路线对比（可解释性换范围）

以微调 LLM 建模认知的代表工作 Centaur 为参照：
- Centaur 优势：单一模型覆盖多任务、自带海量背景知识
- Centaur 代价：预训练数据不受控、成功来源难以解释、被批评在人类反应序列上"走捷径"
- BBT：训练流程完全受控 → 能回答"模型为什么预测得好、它如何偏离理想贝叶斯表征"；代价是覆盖范围窄、必须先指定贝叶斯模型

局限与未来方向（作者自认）

  1. 解释性分析依赖对可视化层与变量的选择
  2. 稀疏分解技术限于原贝叶斯模型假设空间，可能遗漏真正刻画人类行为的新假设
  3. 蒸馏所用贝叶斯模型的选择会影响结果
  4. 未来：蒸馏多个竞争贝叶斯模型后比较；推广到强化学习等其他建模传统；自动解释方法发现新符号假设反哺贝叶斯假设空间

查询拓展

  • Tenenbaum 数字游戏 / Shepard 分类 / Lake & Baroni 组合泛化——四个经典范式的设计细节
  • Centaur（LLM 认知建模）与其"捷径"批评的具体所指
  • 前向采样 vs 真贝叶斯推理的等价条件（什么时候蒸馏会失真）
  • in-context learning = 贝叶斯推断的理论工作（Xie et al.）与 BBT 的关系

归纳总结

  1. BBT 是"先验注入→数据修正"的两段式配方：蒸馏把贝叶斯先验"烧进"网络（免推理成本），微调用真实行为把网络拉回人类实际——恰好是我们今日 AIPPT 吸收笔记"大纲先行→逐页自纠"的同构：结构先验定骨架，数据修正定细节。
  2. 关键工程洞见是"前向采样替代贝叶斯推理"：预测难（假设空间求和不可解）但采样易（从模型抽 IO 对）——用"生成数据的成本"换"推断的成本"，这是蒸馏成立的经济基础。
  3. "只微调不蒸馏最差"是本文最硬的证据：神经网络缺的不是数据是结构化先验——直接对行为数据微调等于让网络从零猜归纳偏置，先蒸馏再微调才是正序。对一切"小模型+强先验 vs 大模型+大数据"选型有普适参考价值。
  4. "人脑偏爱简单"是方法赠品：BBT 本为预测精度设计，却因可控性意外量化了人类对简单启发式的系统性偏离——受控流程的科学价值超出工程目标。
  5. 范式之争的化解方式是"频谱插值"而非"二选一"：BBT 按数据质量自适应停在贝叶斯-联结主义频谱中间——与 LLM 领域"神经+符号"混合架构（NeSy）潮流汇合。

二、趋势判断

  1. 认知建模进入"混合范式"时代：纯贝叶斯与纯联结主义都不再是终点站，"贝叶斯蒸馏+行为微调"这类配方会成为标准做法——四任务全面领先+3000 万小参数的性价比是强信号。
  2. 小模型+强先验路线在垂直建模上持续胜出：3000 万参数打赢 21 个贝叶斯模型和 LLM 微调路线——当任务域明确时，先验注入的成本远低于 scaling。
  3. "受控性"成为科学用模型的第一要求：LLM 认知建模（Centaur 系）因数据不受控被质疑，BBT 式可控流程的"能回答为什么"能力会被更多学科要价——可解释性从产品需求变成科研刚需。
  4. 行为微调数据（人类判断数据集）价值上升：配方的第二步依赖高质量人类行为数据，概念学习类的行为数据集会成为新的稀缺资源。
  5. BBT 配方向 RL/其他建模传统的推广（作者自列方向）值得跟踪——若成功，"贝叶斯先验蒸馏"会成为 Agent 策略学习的通用组件。

  1. Skill 体系就是"贝叶斯先验"的工程对应物：SKILL.md 的步骤/坑点/触发条件=结构化归纳偏置；模型=通用网络。BBT 的证据（只微调不蒸馏最差）从认知科学侧印证了"skill 注入优于纯 few-shot 示例"——我们 400+ skill 的路线正确性有了跨领域实证。实施：无需改动，作为 skill 体系价值论证的引用源存档。
  2. 两段式与 AIPPT 吸收笔记的同构链又添一员：大纲先行（结构先验）→逐页自纠（数据修正）≈ 蒸馏（先验注入）→微调（行为修正）≈ 系统提示（规则）→RLHF（偏好对齐）——"先验定骨架、数据修细节"是跨领域统一模式，值得在笔记体系里显式串成一条线（本篇已加互链）。
  3. 对 DUCK RL 重训的直接启示：RL 训练中 reward shaping=先验注入（贝叶斯蒸馏的对应物），domain randomization=数据修正。microduck_rl 栈的质量 DR 仅 ±5% 的问题（只随机 trunk_base）可解读为"先验过强、修正不足"——重训时扩大 DR 范围不只是 Sim2Real 对策，也是防止策略过拟合到先验的手段。已在此认知下复核 docs/08 的 DR 建议，无冲突。
  4. "简单性偏好"对量化体系的借喻（克制版）：人类交易者系统性偏离理想贝叶斯（过度交易/复杂指标堆砌），向简单启发式倾斜（"买分歧卖一致"）——铁律体系本质是"承认人类偏爱简单"的产品化。仅作思维印证，不加映射。
  5. 与 SKILL.state 笔记的互补：那篇管"执行时的上下文效率"（状态化），本篇管"学习时的先验效率"（蒸馏化）——一执行一学习，合起来是 Agent 工程的两翼。

指南分析

什么时候用 BBT 式配方（从原文条件提炼）：

场景 适用性 理由
域明确的人类行为建模 ✅ 最适 四案例全是此类
小数据+强领域知识 ✅ 先验注入弥补数据不足
需要解释"为什么预测对" ✅ 受控流程可归因
开放域通用任务 ❌ 覆盖窄，LLM 路线更合适
无成熟贝叶斯模型可用 ⚠️ 第一步无从做起，先建贝叶斯模型

两步配方的操作要点：蒸馏用前向采样（不碰贝叶斯推理）；微调允许突破原模型假设空间；解释靠对比微调前后内部表征。
