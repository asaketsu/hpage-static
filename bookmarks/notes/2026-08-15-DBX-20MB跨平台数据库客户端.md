| 指标 | 数据 |

## 核心卖点

1. **🪶 20MB 零膨胀**：无 Java JRE、无 Python venv、无捆绑 Chromium——单个 Rust 二进制，下载即用
2. **🤖 编辑器内嵌 AI**：选中表 → 自然语言描述 → 直接返回 SQL（无需在工具间复制粘贴）。支持 Claude / OpenAI / **本地 Ollama**，AI 生成的 SQL 先过内置安全审查再执行
3. **🔌 MCP 原生支持**：说 Model Context Protocol——Claude Code / Cursor / Windsurf 等 AI Agent 可直接查询你在 DBX 里配好的连接，一次配置处处可用
4. **🌐 三形态同源**：原生桌面 + Docker 自托管（团队用）+ 纯浏览器 Web 版，功能/连接完全一致

## MCP Server 集成（AI Agent 工作流）

```json
// .mcp.json
"mcpServers": {
  "dbx": {
    "command": "npx",
    "args": ["-y", "@dbx-app/mcp-server"]
  }
}
```

- MCP server 独立分发（装 DBX 桌面端不自动装 MCP）
- 权限三档：`read_only` / `safe_write` / `high_risk_write`，在 DBX Settings → MCP 管理连接白名单
- Docker/Web 部署时通过 `DBX_WEB_URL` + `DBX_WEB_PASSWORD` 环境变量指向后端
- 另有预编译原生二进制（免 Node.js，适合离线/服务器）和独立 CLI 包

### 💡 指导性意见（何时用/不用/怎么选）

- **用 DBX 当**：①日常多数据库管理主力工具（替代 DBeaver/Navicat）②信创环境（达梦/GaussDB/KingBase 全覆盖，同类工具罕见）③AI Agent 查库场景（MCP 权限分层比裸 SQL 工具安全）④Jetson/低配设备（20MB 无 JVM）
- **不用 DBX 当**：①需要重型 ETL/数据管线（用 Kettle/DataX）②团队级权限审批流（用企业级平台）③纯单一数据库深度管理（如只用 PostgreSQL，pgAdmin/psql 更顺手）
- **选型对比**：DBeaver（免费但需 Java、启动慢）｜TablePlus（精致但收费且仅 macOS）｜Beekeeper（轻但库支持少）｜**DBX（免费+轻+库最全+AI/MCP）**——多库+信创+Agent 场景 DBX 最优解

### 📌 案例

1. **官方 Database Test Lab**：`make db-list` / `make db-verify DB=mysql@8.4`——repo 自带版本化 Docker Compose 数据库配方，验证各驱动真实可用（不是纸上谈兵）
2. **自托管团队 Web 版**：`docker run -d -p 4224:4224 -v dbx-data:/app/data t8y2/dbx:latest` → 浏览器开 `localhost:4224`，多用户共用同一套连接配置；配 MCP server（`DBX_WEB_URL` 指向后端）让 Claude Code/Cursor 共享这些连接
3. **反向代理子路径部署**：`DBX_PUBLIC_BASE_PATH=/dbx` + 前端 `VITE_DBX_BASE_PATH=/dbx/` 构建——挂在内网网关 `/dbx` 路径下的实测方案

## 技术栈（架构参考价值）

| 层 | 技术 |
|----|------|
| 框架 | Tauri 2（Rust 壳，非 Electron——这是 20MB 的根因） |
| 前端 | Vue 3 + TypeScript + shadcn-vue + Tailwind |
| 编辑器 | CodeMirror 6 |
| 后端 | Rust + sqlx / tiberius / redis-rs / mongo-rust-driver |

## 归纳：为什么值得关注

1. **Tauri 2 路线的标杆案例**：Rust 后端 + Web 前端，比 Electron 方案小 50-100 倍，验证了"轻量桌面应用"不必牺牲功能密度
2. **MCP 生态位精准**：数据库连接是 AI Agent 最稀缺的能力之一（自然语言→SQL→真实数据），DBX 把"连接管理 + 权限白名单 + 安全审查"做成一层，比裸写 SQL 工具安全
3. **国产数据库覆盖罕见地全**：达梦/OceanBase/openGauss/GaussDB/KingBase/GoldenDB/TDengine 全部原生——对信创环境几乎是唯一选择级别的覆盖
4. **向量库 + 消息队列也算"数据库"**：Qdrant/Milvus/Weaviate + Kafka/Pulsar 同窗管理，契合 AI 时代的数据栈
5. **与 Hermes 的结合点**：`npx @dbx-app/mcp-server` 可直接挂进 Hermes 的 mcp_servers 配置，让 Agent 用自然语言查本机 SQLite/PostgreSQL——比手写查询脚本的工作流更顺
