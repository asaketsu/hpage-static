# 形态对称图MS-PPO-机器人策略对称性从软罚到硬构造

> **记录日期**：2026-10-09

**标签**：#强化学习 #足式机器人 #对称性约束 #图策略网络 #Sim2Real #PPO #策略架构

## 一、内容整理

### 1.1 核心问题：对称性该"奖励出来"还是"构造出来"

现有对称 RL 三条路（镜像数据增强 / reward shaping / 全局等变网络）要么软约束只能近似，要么把单一群表示强加在扁平 obs-action 空间上、脱离机器人运动学拓扑。本文提出**形态对称图表示**：在拓扑图上补全形态对称诱导的**置换+符号变换**，一步到位实例化 MS-PPO。

### 1.2 两种群动作的分离（表示层核心设计）

- **形态动作**（作用在物理信号上）：置换对称肢体 + 镜像关节坐标系诱导的符号翻转（如 sagittal 反射下 base 重力/指令的侧向与偏航分量翻号）
- **图动作**（作用在图索引特征上）：按对称轨道重索引节点
- 图决定信息**流向哪里**，形态动作决定物理量**如何变换**——两者缺一即不完备

### 1.3 等变 Actor + 不变 Critic（构造而非正则）

- **Equivariant Actor**：M(o) = l(z_G(h(o)))——镜像观测产生镜像动作（policy equivariance）
- **Invariant Critic**：对称轨道上做 sum pooling + disparity 项（|z−gz| 与 (z−gz)²）→ 形态对称状态同值（value invariance）
- 对称性由架构**by construction**保证，不再靠 reward 罚或数据增强软化逼近

### 1.4 实验结果（Go2 四足 + G1 人形）

**walk-figure-8 任务**（对称轨迹跟踪）：

| 方法 | Lin.TE↓ | Ang.TE↓ | 奖励↑ | 参数量 |
|---|---|---|---|---|
| PPO | 0.049 | 0.274 | 11.35 | 2,113,945 |
| PPO-EMLP | 0.672 | 0.937 | 3.55 | 1,056,979 |
| PPO-Aug | **0.031** | 0.246 | 11.95 | 2,113,945 |
| MI-PPO | 0.037 | 0.237 | 12.17 | 864,142 |
| **MS-PPO** | 0.036 | **0.198** | **13.14** | **732,046** |

- MS-PPO 用 **PPO 34.6% 的参数**拿最高奖励与最佳角跟踪
- **关节零力矩故障容忍**（30% 概率随机单关节失效）：MS-PPO hip/calf 故障下奖励最佳（8.36/3.33 vs PPO 5.88/1.76）
- **G1 人形零样本 sim-to-real**：MS-PPO 速度 MSE 0.567 最优；**PPO 与 MI-PPO 根本无法在真机上稳定行走**——图连接不够，对称性要嵌进图里才 transfer

### 1.5 硬等变的失败模式（对我们最有价值）

PPO-EMLP（扁平硬等变）在**对称破缺扰动**（单关节失效）下崩溃：训练时须放松为成对关节同时失效、仍 3 seed 只活 1 个；测试单关节失效时 Lin.TE 0.672（差 PPO 13 倍）。**全局扁平等变把左右腿锁死成木偶**，无法做非对称补偿。MS-PPO 的图局部性让故障留在节点局部、经拓扑传播，同时对称映射只共享镜像故障案例间的补偿策略。

### 1.6 消融（架构细节）

- shortcut 边（base→thigh/knee 直连）+ 4 层消息传递最优（figure-8 奖励 13.24 vs 无 shortcut 11.28）
- 6/8 层不升反降（过深消息传递过平滑）；shortcut 让 base 状态与指令直达末端关节，不必沿运动链逐跳

## 二、查询拓展

### 2.1 与 E27b（T1 mirror 对称罚）的直接对照
E27 的 T1 = q+a 镜像和软罚（-0.3 权重），属本文分类的"reward shaping"软路线。MS-PPO 证明软路线的天花板之上还有硬构造路线，但**硬全局等变（EMLP 式）在对称破缺场景（单腿弱、关节故障、载荷不对称）必翻车**——这给 E27 划了安全边界：软罚路线选对了，不必升级成硬等变。

### 2.2 头颈对称与"结构权威"的关系
用户 09-17 拍板 mirror-loss 必须保留（不能训出歪头鸭子）。本文为该决策提供了理论背书：对称性是生物步态的底层结构，by-construction 编码优于事后惩罚。但 DUCK 头颈是"非对称载荷"（头部质心偏置 5.3°），属对称破缺项——正确做法恰是 MS-PPO 式：头颈不入对称轨道、只做姿态保持罚。

### 2.3 与 rsl-rl recurrent/Transformer 对称约束被拒案例的呼应
记忆里有"rsl_rl recurrent/Transformer 策略加对称约束被拒、env 级奖励绕开"的先例。MS-PPO 给出了第三条路：不改 rsl_rl 优化器，换函数空间（图+对称 encoder）——与我们"零侵入注入自定义策略网络"的 skill 同思路。

## 三、归纳总结

### 3.1 对称 RL 三路线能力对照

```
数据增强(软)  : 近似等变,零架构改动,采样翻倍
reward罚(软)  : 近似等变,权重难调,与主奖励打架   ← E27 T1 在此
硬等变EMLP(硬): 严格等变,对称破缺场景崩溃       ← 禁用于故障容忍
图+对称(本文) : 严格等变+拓扑局部性,参数-65%    ← 需换网络架构
```

### 3.2 三个关键洞察

- **对称破缺是硬等变的死穴**：单关节失效让 EMLP 的全局 C2 等变结构性失配——机器人只要可能带伤作战，软对称或图局部对称是唯一选择
- **参数效率来自结构先验**：34.6% 参数 + 更高奖励，先验编码比堆容量便宜
- **图连接 ≠ 对称性**：MI-PPO（纯图无对称）在 G1 真机 transfer 失败——拓扑与形态变换必须联合编码

### 3.3 对 DUCK 训练线的判定

- E27b 的 T1 软罚路线**正确**，无需改硬等变（DUCK 左右舵机个体差异=真实对称破缺，硬等变会放大它）
- 若 E27 之后仍残留左脚主导，下一步不是加重软罚（S21T 教训：过重罚塌缩），而是图结构化策略网络（MS-PPO 式）——但这是架构级重训，须走 docs 提案排队
- E27 验收加"左右动作幅度差"指标与本文 reward 表的对称轨道 disparity 项同源，可再加镜像 obs 一致性测试

## 四、趋势判断

### 趋势1：策略网络从"扁平 MLP"走向"物理对齐函数空间"
依据：Body Transformer/MetaMorph/EAT/MS-PPO 一脉相承，2025-2026 密集产出；物理结构先验换来参数效率与 transfer 鲁棒性双赢。

### 趋势2：对称性编码从训练技巧升级为表示设计问题
依据：本文把对称性从"损失函数里的罚项"提为"图表示的坐标变换"，且证明软路线天花板明显低于构造路线。

### 趋势3：故障容忍成为 locomotion 策略的新验收维度
依据：30% 单关节零力矩课程 + 双机协同拖拽实验；机器人量产时代带伤作战能力比峰值性能更值钱——与 DUCK"舵机个体差异是常态"的实践吻合。

### 趋势4：Sim2Real 成败的分水岭在表示而非数据
依据：同一 PPO 算法，MLP/纯图在 G1 真机全灭、图+对称零样本 transfer 成功——表示对齐物理是 transfer 的第一因。

## 五、关联分析

E27 = E24c 热启 + T1 对称罚 + T2 失衡步幅奖 + T3 动作率罚。本文判决：T1 软罚是安全路线（硬等变会在左右舵机差异下翻车）；若 12ep 验收中左右幅度差指标不达标，升级路径=图对称架构（新提案）而非加重罚。**E27b 验收时同步记录镜像 obs 测试**：把 obs 做 sagittal 反射喂策略，量化输出对称度——低成本引入本文的评估视角。

### 5.2 与既有笔记/技能的关联

## 六、金句摘录

> 「Enforcing the desired policy and value constraints by construction rather than through reward shaping or data augmentation.」——约束的最高形态是构造，不是惩罚

> 「Topology alone is incomplete, and symmetry alone is too coarse.」——图缺对称不完整，对称离图太粗糙

## 七、行动启示

- **E27b 验收增项**（零成本）：镜像 obs 一致性测试——sagittal 反射 obs 喂策略，量左右动作对称度，作为"左右幅度差降 50%"的补充证据
- **rl-policy-architecture-selection skill 增补**：对称图网络条目 + 硬等变死穴（对称破缺崩溃）
- **docs 提案储备**：若 E27 系仍不对称，"MS-PPO 式图对称策略"作为架构级新提案排队（含 G1 零样本 transfer 证据）

## 八、拓展应用推荐

1. **DUCK 故障容忍课程**：30% 单关节零力矩训练——直接治"左脚主导"（本质是左右执行差异），量产鸭鲁棒性刚需
2. **舵机个体差异的对齐策略**：左右舵机 P/I 增益差异是天然对称破缺，图局部性让策略学到"每条腿自己的补偿"而非全局镜像死锁
3. **Agent 契约化借鉴**：等变/不变分离的函数空间设计思想迁移到 Agent 决策契约——输出对无关扰动等变、评估对等价输入不变

## 九、指南分析

**方法论价值**：把"想要的约束"从损失函数搬进函数空间——表示设计 > 训练技巧的完整论证。任何"reward 罚压不住的行为缺陷"都应先问：能否在架构层 by-construction。

**可复用的实验设计**：
- 基线梯度设计（PPO→+硬等变→+增强→+图→+图对称）逐层隔离贡献——消融的黄金标准
- 单关节零力矩作为对称破缺探针——比随机推扰更精准地测对称策略的真实柔性

**局限与保留**：仅验证双边 C2 对称（Go2/G1），K4 四足/旋转对称未测；图与轨道仍手工指定非自动学习；G1 实验锁上肢只测下肢；0.567 vs 0.811 的 MSE 优势基于 3 seed，置信度中等；未报训练墙钟成本（图网络消息传递的开销可能吃掉参数节省）。
