## 核心内容

一篇面向初学者的反向传播（Backpropagation）完整教程，从数学基础到代码实现。

## 知识结构

### 一、前向传播
输入 x → 线性变换 z=Wx+b → 激活 a=σ(z) → 输出

### 二、损失函数
MSE = ½(ŷ-y)²

### 三、链式法则（核心数学）
- **单变量链式法则**：单路径梯度传递
- **多变量链式法则**：多路径汇合时梯度求和

### 四、反向传播四步
1. 前向传播计算输出
2. 计算损失
3. 反向计算梯度（逐层回传 δ）
4. 梯度下降更新参数

### 五、NumPy vs PyTorch 对比

| 方面 | NumPy 手写 | PyTorch 自动求导 |
|------|-----------|-----------------|
| 前向传播 | 手动矩阵运算 | `nn.Linear` + `forward` |
| 反向传播 | 手动计算梯度 | `loss.backward()` |
| 参数更新 | 手动梯度下降 | `optimizer.step()` |

### 六、常见问题
- **梯度消失**：Sigmoid 导数最大 0.25，多层累积指数衰减 → 用 ReLU 替代
- **梯度检验**：双边导数公式验证正确性

### 七、激活函数导数

| 函数 | 导数 |
|------|------|
| Sigmoid | σ(1-σ) |
| ReLU | x>0: 1, else: 0 |
| Leaky ReLU | x>0: 1, else: α |
