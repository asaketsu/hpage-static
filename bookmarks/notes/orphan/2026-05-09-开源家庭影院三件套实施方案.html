🎬 Jellyfin + Stremio + IINA 开源家庭影院三件套

日期：2026-05-09 | 状态：分析完成，待实施
定位：免费开源方案替代 Netflix 等付费流媒体

一、三件套定位

组件 角色 Stars/用户 关键能力
Jellyfin 媒体服务器 51.4k ⭐ 本地片库管理、4K HDR转码、多客户端、多用户
Stremio 内容聚合器 30M 用户 插件生态找片、Torrent/Debrid 资源聚合
IINA macOS 播放器 44.8k ⭐ mpv 引擎、原生 UI、HDR passthrough

二、协作架构

Internet（资源源）
    │
    ├── Torrent/Debrid ──┐
    │                    ▼
    │              ┌──────────┐  stremio-jellyfin addon
    │              │  Stremio │◄──────────────────────┐
    │              │ (聚合层)  │                        │
    │              └────┬─────┘                        │
    │                   │                              │
    │         ┌────────┼────────┐     ┌────────────┐  │
    │         ▼        ▼        ▼     │  Jellyfin   ├──┘
    │    内置播放器  IINA    其他     │ (媒体库)    │
    │              (macOS)  播放器   └────────────┘
    │                                本地媒体文件
    └────────────────────────────────────────────────

两种路径：
- 路径A（推荐）：Stremio 为中心 → stremio-jellyfin addon 桥接本地库 + Torrentio 找片 → IINA 外部播放
- 路径B：Jellyfin 为中心 → Gelato 插件用 Stremio 增强搜索 → Web/原生客户端播放

Jellyfin Docker Compose

version: '3.8'
services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: jellyfin
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Shanghai
    ports:
      - "8096:8096"    # HTTP
      - "8920:8920"    # HTTPS
    volumes:
      - ./jellyfin/config:/config
      - ./jellyfin/cache:/cache
      - /path/to/movies:/media/movies:ro
      - /path/to/tvshows:/media/tvshows:ro
    devices:
      - /dev/dri:/dev/dri  # Intel QuickSync 硬件转码
    restart: unless-stopped

八、注意事项

  • ⚠️ Stremio + Debrid + Torrentio 涉及 P2P，注意版权合规
  • ⚠️ Stremio macOS 外部播放器偶发启动失败（已知 bug）
  • ⚠️ HDR→SDR 转码质量一般，建议直传 HDR 原片
  • ⚠️ Debrid 服务为第三方付费（Real-Debrid ~€4/月），纯免费可不用
  • ⚠️ Docker 镜像需定期更新，硬盘需备份策略
