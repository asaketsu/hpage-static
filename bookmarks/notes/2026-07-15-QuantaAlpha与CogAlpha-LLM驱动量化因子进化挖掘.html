二、QuantaAlpha：轨迹级进化框架

2.1 核心理念

将每次端到端的因子挖掘视为一条"轨迹"，通过轨迹级变异和交叉来进化因子——而非依赖无约束的重新生成。

这借鉴了 SE-Agent（Self-Evolution trajectory optimization）的思想：显式进化轨迹本身，而非仅进化最终输出。

2.3 关键机制详解

机制 1：可控因子构造（Controllable Factor Construction）

直接生成因子代码容易出错（语法错误、依赖不匹配、语义漂移）。QuantaAlpha 引入中间表示：

  1. 假设 h → 结构化语义描述 d（形式化市场机制为离散算子）
  2. 语义描述 d → 符号表达式 f（基于标准化算子库 O）
  3. 符号表达式 f → AST（抽象语法树，叶节点绑定原始特征，内部节点对应算子实例）
  4. AST → 可执行代码 c（编译失败时触发 LLM 修复）

机制 2：三重生成约束

约束 公式/方法 作用
语义一致性 LLM 验证 h↔d↔f↔c 对齐 防止生成漂移
复杂度控制 C(f) = α₁·SL(f) + α₂·PC(f) + α₃·log(1+ F_f
冗余控制 AST 最大公共同构子树 S(f) = max s(f,φ) 防止因子拥挤

机制 3：轨迹级变异（Mutation）

τ = (s₀, a₀, s₁, a₁, ..., sₙ)
         ↑ 自反思定位最差步骤 k

τ_child = (s₀, a₀, ..., sₖ, Refine(aₖ), s'ₖ₊₁, a'ₖ₊₁, ..., s'ₙ)
                                    ↑ 仅重写失败步骤，冻结前缀

变异只修改局部，保留已验证的轨迹前缀，避免从头开始的探索浪费。

机制 4：轨迹级交叉（Crossover）

从多个高奖励父轨迹中提取互补的高性能片段（假设模板、构造模式、修复策略），合并为新的子轨迹。
