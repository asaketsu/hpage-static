## τ0-WM 核心架构

### 核心命题

> 机器人必须知道：执行一个动作之后会发生什么。世界模型是学习动力学模型的一种容器。

### 三大组件

| 组件 | 全称 | 功能 |
|------|------|------|
| **VAM** | Video Action Model | 根据图像预测动作，也能生成动作 |
| **ACVS** | Action-Conditioned Video Simulator | 以动作为条件的视频仿真器，预演未来 |
| **Test-Time Computation** | 测试时计算 | 对候选动作预演打分，选择最可靠的 |

### 执行流程

```
当前状态 → VAM 生成候选动作 → ACVS 预演未来并打分 → 选择最可靠动作 → 执行
```

- 简单任务：VAM 直接输出动作（无需思考）
- 复杂任务：VAM 采样多候选 → ACVS 推演打分 → 选最优
- 闭环：执行后到达新状态 → 比较预测与实际的差异 → 继续预测

### 性能指标

| 指标 | 数值 |
|------|------|
| 训练数据 | ~2.73 万小时异构数据（1.7 万小时真机 + 6000+ UMI + ego 人类） |
| forward loop | 180-220ms（≈5Hz） |
| 数据比例 | 真机:UMI:ego ≈ 6:2:1（含失败轨迹） |

## 核心观点

### ① 关于数据：真机打底，"根本是你自己变强"

> 真机数据最多，和机器人本体没有 gap。UMI 提供视觉多样性。ego 提供人类交互先验。

> 如果你用了 VLM 的基模，里面已经包含互联网数据了。关键是你自己要有更强的 base model。

> 假设你是个婴儿 vs 28 岁成年人，使用知识的能力完全不同。**根本上，是你自己变强。**

### ② 关于失败数据：反事实推断的核心

> 世界模型的一个核心瓶颈是反事实推断：如果我不执行这个动作，会发生什么？

> 失败数据告诉模型哪些动作看似合理、其实很危险。不是告诉正确答案，而是告诉**哪些是危险的**。

> 自动驾驶也在做难例挖掘——高速上平稳直行的数据没有太大帮助，真正需要的是 corner case。

### ③ 关于 VLA vs World Model

> 我不觉得 VLA 已经死了。自然语言是描述任务最好的工具，是符号化推理和长程任务拆解的唯一成熟工具。

> 未来依然需要语言做 high-level 规划，也需要 low-level action model 做执行。τ0-WM 攻克的是后一个环节。

> 应该补上整个闭环：VLA 做高层规划 + world model 做动作执行 + RL 回收真实经验持续进化。

### ④ 关于评估：没有真实闭环，很容易变成刷榜

> 机器人最关键的问题是：部署之后失败了怎么办？失败数据如何回收？模型如何更新？

> 没有真实物理闭环，单纯做 world model 或 VLA，都很容易陷入离线指标优化，比如热衷于在榜单上刷分。

> 如果只能选一个指标，我会选：**在真实场景里，机器人无需人工干预、持续完成任务的时间和范围**，或者**接管率**。

### ⑤ 关于开源

> 具身智能处于行业比较早期的阶段，开源有助于建立生态。

> 未来物理 AI 如果分层：最底层是本体硬件 → 数据基础设施 → 模型层 → 应用。

> 让大家都有一些可以共享的组件，模型一旦被部署进去，会不断扩展边界。

### ⑥ 关于失败

> 每天都在失败。经常失败，有时又会觉得有希望。

> 但到今天都没觉得我很成功，因为最终的目标还没达到。

> 前沿基础研究本身就充满挑战，你基本上就是走在人类认知的边界，不会有人帮你，只有你自己能去做。

## 三年目标

> 证明机器人的基础模型可以在真实场景中持续部署，持续收集物理交互经验，持续后训练，其能力随着部署规模增长而提升。

> 建立一套新的机器人闭环学习范式：从预训练到部署，再从经验中学习、后训练、提升，整体形成一个**数据飞轮**。
