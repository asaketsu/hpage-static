归纳总结

一句话：所有人形机器人公司公开描述过的"大脑"都是同一个三层架构，且三层全部可用开源工具在家复现——$0~$230 硬件 + 几美元租用 GPU，8 周走完从仿真到语音对话的全链路。

作者的核心论断：
- Tesla 不卖 Optimus 也不公开其架构，但 NVIDIA（GR00T N1）、Physical Intelligence（π0）、Figure（Helix）都发了论文/技术博客，拼起来就是同一张图
- 三层 = 慢思考层（VLM 理解指令，7-9Hz）→ 快行动层（视觉动作策略，200Hz）→ 平衡层（全身 RL 策略）
- 这条 8 周路径几乎逐行对应 Figure/1X 的招聘 JD——学习路线 = 就业路线

关键命令（作者实测路径）

# 周 1：装 MuJoCo 加载 G1
pip install mujoco
git clone https://github.com/google-deepmind/mujoco_menagerie
python -m mujoco.viewer --mjcf mujoco_menagerie/unitree_g1/scene_with_hands.xml

# 周 3：mjlab 训 G1 速度跟随（4096 并行环境）
uv run train Mjlab-Velocity-Flat-Unitree-G1 --env.scene.num-envs 4096

# 周 4：GVHMR 结果重定向到 G1
uv run scripts/gvhmr_to_robot.py --gvhmr_pred_file <hmr4d_results.pt> \
  --robot unitree_g1 --record_video

# 周 5-6：LeRobot 遥操作+采集
lerobot-teleoperate   # 主臂驱动从臂：验证硬件
lerobot-record        # 50 条带相机视频，上传 Hub

# 周 7：ACT 训练
lerobot-train \
  --dataset.repo_id=${HF_USER}/record-test \
  --policy.type=act \
  --output_dir=outputs/train/act_so101_test

# 周 8：MCP agent 接入 ROS
sudo apt install ros-<distro>-rosbridge-server
ros2 launch rosbridge_server rosbridge_websocket_launch.xml
claude mcp add ros-mcp -- uvx ros-mcp --transport=stdio

指南分析

按此指南行动的要点：
1. 顺序不可乱：先仿真（周 1-4 全免费）再真机（周 5 起 $230）——前 4 周零成本验证兴趣与手感
2. Mac 用户路径明确：重活全在租用 GPU，本地只做查看/评估；mjlab 训练必须 NVIDIA（macOS 仅评估）
3. 显存选卡对照：π0 LoRA 需 >22.5GB（4090 24GB 卡线过关）；GR00T 微调 40GB+ 只有 A100/H100 档
4. 风险点：RunPod 价格是 2026-08/09 快照，波动大，用前查实时价；SO-101 需自行 3D 打印+组装（TheRobotStudio BOM）
