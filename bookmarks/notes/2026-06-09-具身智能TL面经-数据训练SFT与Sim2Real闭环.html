📝 9 大问题详解

Q1：数据不够怎么解决？

30秒答案：多源数据组合 → 预训练 → SFT → 失败回流闭环

数据源 用途 关键约束
遥操作数据 目标任务分布基本盘 必须覆盖位置/光照/姿态/干扰物/失败恢复
仿真数据 补长尾+危险场景 不能完全替代真机，适合预训练和策略初始化
开源数据 通用视觉/动作先验 须处理 embodiment/视角/动作空间/标注差异
人类视频 语义/阶段/affordance 不能直接当动作监督

三层策略：
- 短期：更高质量遥操作 + 清洗
- 中期：仿真 + 开源数据补长尾
- 长期：失败回流闭环（系统告诉你下一轮采什么）

关键金句：少量高质量、分布覆盖好的数据 > 大量重复 demo

Q2：遥操作数据采集系统设计

必记字段：多视角图像 | 机器人状态 | 动作命令 | 语言任务 | 时间戳 | Episode ID | 成功标记 | 异常信息

三层架构：
1. 硬件控制层：主从机械臂 / VR手柄 / 3D mouse / 示教拖动
2. 数据记录层：相机参数、关节状态、EEF位姿、控制命令、场景参数
3. 质量控制层：时间对齐、掉帧检测、超范围检测、抖动检测

三大最常见致命错误：
- ⚠️ 时间戳没对齐
- ⚠️ 动作定义和控制频率不统一
- ⚠️ 成功/失败标准不一致

抖动处理全链路

层级 方法 注意事项
采集端 死区 + 动作限速 从源头保证平滑
后处理 低通滤波/移动平均 过度滤波致命 — 接触瞬间信号丢失
数据清洗 重采样 + 速度校验剔除 统一到恒定控制频率
模型层 Temporal Smoothness Loss 惩罚相邻帧突变

多操作者风格问题

核心：多峰分布 → 简单回归会"平均化"成不可行动作

方案 原理
ACT + CVAE 潜空间编码不同风格，推理时通过 z 变量选择风格
质量加权 高质量 Episode 更高梯度权重

Subtask 时间段标注

工程方法：关键状态事件驱动（非纯人工）

事件类型 检测方式
夹爪稳定 闭合信号 + 延顺10帧
速度减速 EEF 线速度梯度检测
物体离桌 力传感器或视觉判定

Q3：预训练 / SFT / 任务微调在 VLA 中的分工

阶段 目标 数据
预训练 通用性 Open X-Embodiment / DROID / BridgeData / 仿真
SFT 本机可用 本机器人高质量演示
任务微调 具体成功率 单场景/单技能数据

微调策略 vs 数据量：

数据量 策略
少量 冻结 backbone，训 action head / LoRA / adapter
中等 解冻视觉投影层 + action head + 部分融合层
大量 全量微调或继续预训练

Q4：Sim-to-Real 的坑

三大 Gap：

Gap 类型 内容 解决方案
视觉 光照/材质/反射/纹理/相机噪声 视觉随机化 + 风格迁移 + 预训练 encoder
动力学 质量/惯量/摩擦/阻尼/延迟 系统辨识 → 参数随机化
接触（最难） 摩擦/几何误差/柔性 真机微调 + 力反馈 + 阻抗控制

有限算力优先随机化三参数：视觉外观/光照、物体初始位姿、执行延迟或摩擦

抖动定位 ablation 法：
1. 固定观测 replay → 看 policy 输出是否抖
2. 换平滑轨迹 → 看机器人是否抖
3. 人为加延迟 → 看抖动是否复现

DR 不是越大越好 — 过宽让训练变难、策略保守

Q5：人类操作视频能否训练 VLA？

结论：可用，但通常不能直接当低层动作监督

用途 可行性
Affordance 学习 ✅ 哪里可抓/推/开
Subgoal 学习 ✅ 任务阶段划分
Reward 学习 ✅ 成功判别器
视觉预训练 ✅ 表征学习
直接动作监督 ❌ embodiment gap + 2D→3D + 无力/状态信息

Q6：Benchmark 选型

数据集 定位 适合场景
Open X-Embodiment / RT-X 跨机器人多任务 VLA 预训练
DROID 真实世界多场景 真机操作数据
BridgeData 真实桌面 + 语言条件 语言条件数据
LIBERO 语言条件 + 长序列 仿真评测 / lifelong learning
Meta-World 多任务 manipulation RL/IL 对比
ManiSkill 仿真控制 大规模并行 + RL
RoboCasa 家居长任务 仿真家居场景

Baseline 选择原则：与问题匹配
- 改 action model → 对比 BC / ACT / Diffusion Policy / RDT
- 改数据策略 → 固定模型比数据混合
- 改部署 → 比延迟/成功率/吞吐

Q7：长序列任务成功率低

三大原因：误差累积 | 状态分布偏移 | 数据稀疏

数据对策：

方法 说明
Subtask 拆解 按事件分：接近/抓取/移动/释放/验证
Action Chunk 预测动作块而非单步
分层策略 高层规划 + 低层控制
DAgger 在线数据聚合减少分布偏移
失败回流 最有价值 — 覆盖模型真实遇到的偏移

失败数据三用：
- 失败前正常段 → 训练数据
- 失败状态 → 安全/终止检测器
- 人工恢复轨迹 → Recovery Policy

Q8：叠衣服数据采集方案（柔性物体操作）

核心难点：衣服无稳定 6D pose | 状态维度高 | 遮挡多 | 摩擦不稳定

任务分级：
- Level 1：衣服已摊平，固定步骤折叠
- Level 2：轻微凌乱，先拉平再折叠
- Level 3：随机团状，需展开+识别+折叠

硬件配置：
- 双臂优先（一手固定、一手拉展）
- 相机：俯视全局 + 腕部相机 + 可选 RGB-D

额外数据字段：
- 布料关键点（衣领/袖口/角点）
- Segmentation mask
- Subtask label
- 失败原因（抓空/滑脱/折线偏移/双臂干涉）

成功标准（多指标）：成功率 | 阶段得分 | IoU 模板匹配 | 边缘对齐 | 褶皱评分 | 完成时间

Q9：公开数据集如何落地

核心原则：公开大数据预训练 + 本机 SFT + 真机失败回流

数据审计清单：

维度 检查项
许可协议 License 是否允许商用/修改
机器人形态 embodiment 是否匹配
相机配置 视角/数量/分辨率/fps
动作 Schema 维度/单位/坐标系/夹爪约定
语言标注 模板/粒度/覆盖度
质量指标 成功率/噪声/标注一致性

🔍 借鉴学习进化点

# 点 原文要点 对 Jetson 语音助手项目的借鉴
1 数据飞轮闭环 训练→部署→失败回流→定向补采 语音助手的 ASR 误识别也可建立失败回流闭环
2 分层数据策略 短期质量 → 中期仿真 → 长期闭环 TTS 音色/ASR 模型优化也可分阶段推进
3 多峰风格处理 CVAE 潜变量 + 质量加权 语音合成中多说话人风格管理可参考
4 Subtask 事件驱动标注 物理状态边界检测替代纯人工 长对话场景下可拆分为意图识别子任务
5 Sim-to-Real 三大 Gap 视觉/动力学/接触 离线测试→在线部署也有类似 Gap（音频环境差异）
