核心发现（5 个）

1. 运营层决定行为，策略文本几乎不重要

arXiv:2609.05663（DX Research Group，2026-09）。两个同血统生产系统：DX Terminal Pro（3,505 个用户出资金库，Base 链 memecoin 真实 ETH，21 天，7.5M 次单模型调用/~30 万链上动作/~$20M 交易量）+ DXAP 活体 alpha 舰队（500-599 个用户创建 agent，Hyperliquid 永续，69 天，231,638 个多工具回合/14,596 笔成交）。模型=Qwen3-235B（SGLang 单冻结运行时）。
- 风险滑杆每升一档，杠杆 +0.425；agent 固定效应吸收 60% 方差
- 最重的锤：提示词里渲染的九行涨幅排行榜路由了 46.5% 的全部开仓——回归不连续设计（RD）恰好在渲染边界（Top-3 截断处），边界效应 1.75x [1.49, 2.06]。agent 不是在"分析市场"，是在抄屏幕上最显眼的列表

2. 仓位 sizing 对波动率全盲

  • 六个波动率分位组中位杠杆全部=5.0x（横跨 5.7x 波动率差距）；一个"姿态+滑杆"组合格子占 11% 持仓却贡献 62% 爆仓（Mantel-Haenszel OR=22.37）
  • 用文字告诉模型它的爆仓距离，毫无效果——prose 风险提示改变不了行为，只有确定性约束（强制 sizing 规则）才有效

3. 到手的利润留不住：机械括号 beats 自主决策

  • 43.2% 的持仓在 24h 内到过 +300bps 浮盈；其中 49.3% 最终亏损平仓；中位利润捕获率仅 2.0%
  • 固定 2%/4% 止盈止损括号每仓位回收 +39.0bps，打败了所有被测的自主退出策略
  • 直接验证用户股票铁律「亏 5% 割赚 10% 跑一半」：退出纪律必须是机械的，交给 LLM 自主判断=系统性把浮盈还回去

4. 舰队整体无方向性优势，但个体差异巨大

  • DXAP 舰队不盈利，41% 回合胜率落后于匹配的 Hyperliquid 散户基准（50%）
  • 416 个生产场景重放联赛：三个前沿模型决策质量统计上不可区分，但选择稳定性天差地别（翻转率 35% vs 90%+）——同场景重放时有的模型每次决策一致，有的几乎随机 flip
  • 论文附 17 条方法论准则（canon），每条都由一次撤稿或失败主张换来，三条自身结果以撤稿形式留在论文里

5. 生态背景：投研 Agent 工具化落地（中国社区）

  • Vibe-Research（2593★）：A股/美股/港股个人投研 Agent 工作台——每日复盘/资讯雷达/个股数据/板块中心/持仓/回测 13 栏目；设计哲学=Agent 默认关闭，需要多步研究时手动开启（opt-in 而非常驻 agent）
  • ALTA（826★，research-only）/ astra-quant-agent（262★，17 条 fail-closed 规则的投资委员会）/ helm-agents（91★，13 AI 分析师辩论）——多 agent 辩论+委员会+fail-closed 风控是当前开源主流架构

与现有工作的关联（对 Skill/Memory 改进建议）

优先级 建议 依据
P0 把「机械括号 > 自主退出」写进 quant-trading/agent-trading-safety skill：任何 agent 交易系统的止盈止损必须代码强制（OCO 单/硬括号），禁止 LLM 自主决定退出时机；这是生产数据背书的 +39bps/仓位 发现 3 直接量化验证用户已有铁律；当前 skill 只有"凭证隔离/停止条件/dry-run"没有"退出必须机械化"条目
P1 「渲染上下文路由行为」纳入 prompt 设计审查：任何给交易/决策 agent 的提示词中，列表/排行榜的呈现顺序本身是行为杠杆（RD 1.75x 实锤）——推送给用户的内容排序=隐性建议，需声明并审计 发现 1 的排行榜效应；Hermes 的 stock-alert 推送列表同构
P1 「选择稳定性」纳入模型评测维度：同场景重放 flip rate（35% vs 90%+）比决策质量更能区分模型家族——quant 模型选型时加此项（温度 0 重放 10 次统计翻转率） 发现 4；我们模型切换决策从未测过稳定性
P2 用户股票纪律新增一条证据注脚：「sizing 对波动率全盲是 LLM 通病」→ 用户半仓制/良选≤5支的仓位约束是确定性规则，正是 DXRG 证明唯一有效的层 发现 2；写进 USER PROFILE 对应段落作外部佐证

Actionable Insights

  1. 运营层 > 策略层：调 agent 行为改滑杆/渲染/工具默认值，比改策略 prompt 有效一个量级——60% 方差在 agent 固定效应+运营参数里。
  2. 风险 prose 无效：把风险偏好写进提示词是装饰；写进确定性 sizing 约束才是控制。
  3. 浮盈捕获率（profit capture ratio）是新 KPI：中位 2.0% 意味着 agent 系统的瓶颈不在入场在退出——评估任何交易 agent 先测这个。
  4. 胜率基准要用匹配散户：41% vs 50% 说明 LLM agent 连"随机散户"基准都没打过——agent 交易系统的对照组选择决定结论诚实度。
  5. 撤稿文化：17 条 canon 全部标注来源失败案例，三条自身结果以撤稿呈现——生产研究记录的标准姿势。

关键风险与盲点

  • 两系统同出 DXRG 一个实验室，谱系外普适性未验证（论文自己在 DISCUSSION.md 承认）
  • DXAP 主要为 live 价格纸面成交+小额真实资金，真实滑点/流动性冲击覆盖不足
  • 固定括号 +39bps 是配对反事实（对已记录持仓回放），非可部署 alpha 的证据（论文明确声明）
  • 46.5% 排行榜路由效应的因果链依赖 RD 设计假设，边界两侧可比性未完全公开（数据只放聚合提取物，无 per-position 行）

一页速查

规模 = 3,505 金库 21 天 + 500-599 agent 69 天；7.5M 调用 + 231,638 回合 + 14,596 成交；Qwen3-235B 单模型
发现1 = 风险滑杆 +0.425 杠杆/档；agent 固定效应吸收 60% 方差；九行排行榜路由 46.5% 开仓（RD 1.75x @ Top-3 边界）
发现2 = 中位杠杆 5.0x 恒定于所有波动率分位；11% 持仓格贡献 62% 爆仓（OR 22.37）；文字风险提示无效
发现3 = 43.2% 持仓触 +300bps 浮盈 → 49.3% 仍亏损平仓；捕获率中位 2.0%；固定 2%/4% 括号 +39.0bps/仓位 beats 全部自主退出
发现4 = 舰队不胜散户基准（41% vs 50%）；前沿模型决策质量同质但翻转率 35%↔90%+ 分化；17 条 canon 全部由失败换来
