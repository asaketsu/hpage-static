# Locally Coherent, Globally Incoherent: LLM Agent 组合一致性边界研究

## 核心发现

### 问题定义
多组件 LLM Agent 系统面临一个根本性缺陷：**局部一致但全局不一致**（Locally Coherent, Globally Incoherent）。每个组件只看到联合问题的部分视图，其概率声明的组装可能违反基本概率公理，即使每个组件本身是局部一致的。

### 关键指标：组合残差 eps*
- 定义为组装后的 quote 距离联合一致多面体的 L2 距离
- 可在运行时从系统输出和声明的跨组件耦合约束中计算
- 量化了全局不一致的严重程度

### 核心发现

1. **产品结构二分性**：当满足特定条件时，局部一致性足以保证全局一致性
2. **Rayleigh 商预测**：在四种关系类别中的三种上，预测与观测残差的误差在 7% 以内
3. **层次化 Boyle-Dykstra 投影**：可确定性修复组合问题
4. **Anytime-valid e-process**：提供序列一致性监控

### 实证结果

在 1,876 个集成 cliques 上（四 LLM 中端面板）：
- eps* > 0 的比例：33-94%
- 在 1,770 个已解决的赌注上，比例分配规则下每赌注后悔值 +0.115 nats
- 如果赌徒本身进行一致性处理，增益降至 +0.006

### 缓解策略评估

三种直观的 LLM 侧缓解策略均失败或退化：
- 检索增强
- 分区感知提示
- 聚合器 LLM

## 借鉴进化点

1. **一致性即约束**：Agent 系统设计应将概率一致性作为硬约束而非软目标，引入运行时监控机制
2. **组合缺陷的量化**：eps* 指标为评估多 Agent 系统提供了可计算的量化标准，可用于生产环境的健康检查
3. **修复优于预防**：Boyle-Dykstra 投影表明，确定性修复比提示工程更有效，应优先开发修复算法而非依赖 prompt 调优

## 技术细节

- **失败类型**：局部一致但全局违反概率公理
- **计算方法**：从系统输出和耦合约束实时计算
- **修复方法**：层次化投影算法，保证确定性收敛
- **监控机制**：e-process 提供序列统计保证

## 关联研究

- 概率推理与 LLM
- 分布式信念聚合
- 在线一致性监控
