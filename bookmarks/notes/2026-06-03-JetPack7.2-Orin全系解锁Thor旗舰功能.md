## 摘要

JetPack 7.2 是里程碑版本——**首次完整兼容 Jetson Orin 全系列**（包括我们的 Orin Nano）。此前 7.X 仅独占 Thor 平台，Orin 只能用 6.x。7.2 统一了底层系统（Ubuntu 24.04 + Linux 6.8）、CUDA 13 计算栈、三层智能体架构，Orin Nano 等入门设备直接对标 Thor 旗舰软件能力。

## 核心变更（与我们的设备直接相关）

### 底层系统统一

| 组件 | 版本 |
|------|------|
| Jetson Linux | 39.2 |
| Linux 内核 | 6.8 |
| Ubuntu | 24.04 |
| CUDA | 13.2.1 |
| cuDNN | 9.20.0 |
| TensorRT | 10.16.2 |

### AGX Orin 32GB 性能提升

- 新增 **MAXN_SUPER** 超级模式：200 TOPS → **241 TOPS**（+20.5%）

### ⚠️ 关键升级注意事项

- **Orin Nano 取消 SD 卡镜像**，统一采用 **ISO U盘刷机**
- Thor SBSA 架构手动刷机流程有变
- Thor MIG 多实例 GPU 为技术预览版，暂不建议量产

## 三层智能体架构

```
第三层: NemoClaw 智能体编排器
  → 单条指令全自动部署，全员普惠（含 Orin Nano）
     ↓
第二层: Jetson Agentic Skills 智能体开发技能
  → Linux 定制 / 内存优化 / 模型基准测试（开源可复用）
     ↓
第一层: JetPack 7.2 BSP 底座
  → 量产级调度、算力管理、硬件适配
```

### 第二层三大自动化能力

1. **Linux 定制技能**：自动适配自定义载板 I/O、时钟、风扇、功耗
2. **内存优化技能**：智能调校系统与推理内存占用
3. **模型基准测试技能**：自动比对筛选最优模型/运行时/优化方案

## 💡 笔记者批注

1. **直接影响**：我们的 Jetson Orin Nano Super 目前跑 JetPack 6.x，升级到 7.2 可获得 CUDA 13 + TensorRT 10.16 + Ubuntu 24.04，对 YOLO/TinyML 推理性能和开发体验有实质提升
2. **升级风险**：SD 卡镜像取消意味着需要 U盘刷机，流程比 SD 卡复杂；且 6.x→7.2 是大版本跳跃，需要验证所有现有模型的 TensorRT 兼容性
3. **NemoClaw 智能体编排器**值得关注——单条指令自动部署智能体工作流，与我们的 Hermes Agent 体系有潜在协同
4. **暂不急升**：建议等社区验证稳定后再升级，目前 JetPack 6.x + TensorRT 8.x 对我们的项目够用
