摘要

六字诀是中国古代流传的呼吸吐纳养生法，通过嘘(xū)、呵(hē)、呼(hū)、呬(sī)、吹(chuī)、嘻(xī)六个字的不同发音口型与呼吸配合，调理肝、心、脾、肺、肾、三焦六脏腑。源自南北朝陶弘景《养性延命录》，经唐代孙思邈传承发扬。核心在于"形、气、意"三者合一——发音口型调息、肢体动作调身、意念循经调心。每日练习10余分钟即可见效，对高血压、冠心病、肝胆病、呼吸系统疾病等有辅助疗效。

六字总诀（口诀）

古人留有《去病延年六字法》总诀，是六字诀配导引动作最早记述：

肝若嘘时目睁精，肺知呬气手双擎；
心呵顶上连叉手，肾吹抱取膝头平；
脾病呼时须撮口，三焦客热卧嘻宁。

六字详解：口型·意念·功效

1. 嘘（xū）—— 肝

季节对应：春季
口型：嘴角后引，槽牙上下平对中留缝隙，气从槽牙与舌边空隙呼出。属牙音。
动作：两臂如鸟张翼向左右展开，眼随呼气尽力瞪圆。左右交替各做6次。
意念引导：意领肝经之气从足大趾外侧大敦穴起，沿足背上行→太冲→中都→膝内侧→大腿内侧→绕阴器→小腹→夹胃脉两旁→属肝络胆→穿横膈→散布胸胁→沿喉咙→出额部→与督脉会于泥丸宫。支脉从肝穿横膈→注肺→中府云门→手臂内侧→少商穴。

功效：泻肝浊气、疏肝明目。治眼疾、胸胁胀满、易怒、头痛、虚烦不眠、食欲不振。
辨证配字：实症用"呵"泻之（心为肝子），虚症用"吹"补之（肾为肝母）。

2. 呵（hē）—— 心

季节对应：夏季
口型：口半张，舌尖抵下腭，腮稍后拉，舌体上拱贴上槽牙，气从舌与上腭间呼出。属舌音。
动作：两手掌心向里由小腹前抬起→膻中穴→外翻掌上托至眼部。呼气念"呵"，足大趾点地。翻转手心经面前胸腹下落。6次。
意念引导：意领脾经之气从隐白穴上行→大腿内侧前缘→入腹→穿横膈→流注心中→上夹咽连舌本→入目→通脑。直行脉从心系上行至肺→横出腋下→极泉→少海→神门→少府→小指尖少冲穴。

功效：泻心浊气、调理心脏。治心悸、心绞痛、失眠、健忘、盗汗、舌体糜烂。
辨证配字：泻心火用"呼"（脾为心子），补肾水用"吹"。

3. 呼（hū）—— 脾

口型：撮口如管状，唇圆似筒，舌放平向上微卷用力前伸。属喉音。牵引冲脉上行之气喷出。
动作：一手外旋上托至头顶，另一手内旋下按冲门穴。左右交替各6次。
意念引导：大趾稍用力，意念引经气从隐白穴→赤白肉际上行→大都→太白→公孙→三阴交→膝上→血海→箕门→冲门→入腹→属脾络胃→夹咽连舌根。

功效：健脾和胃、消食导滞。治腹泻、腹胀、水肿、消化不良、四肢疲乏。
辨证配字：力量不足可加"呵"补心益脾，肝气郁热引起脾失调先用"嘘"平肝。

4. 呬（sī）—— 肺

季节对应：秋季
口型：两唇微向后收，上下齿相对留狭缝，舌尖入两齿缝内由齿向外发音。属齿音。
动作：两手从腹前上提至膻中穴→立掌夹肘→仰头缩项→左右展臂宽胸推掌如鸟张翼。6次。
意念引导：意念引肝经之气从大敦穴上升→入肝→支脉注肺→中府云门→臂内侧→尺泽→寸口→太渊→鱼际→少商穴。拇指食指气感较强。

功效：宣肺化痰、止咳利咽。治外感伤风、发热咳嗽、痰涎上涌、背痛怕冷、气短。
辨证配字：肺气虚易受外感应练"呼"补脾（培土生金）。

5. 吹（chuī）—— 肾

季节对应：冬季
口型：口微张两嘴角后咧，舌微上翘并微后收。气从喉出经舌两边绕舌下从唇间呼出。属唇音。
动作：两臂体侧提起→经肾俞向前画弧→指尖相对如抱球→身体下蹲→两臂随落→呼气念"吹"→足五趾抓地足心空。6次。
意念引导：足跟着力，意引肾经之气从涌泉穴上升→内踝后→三阴交→腘窝→大腿内侧→长强→脊柱→入肾→络膀胱。支脉入肝→穿膈→入肺→喉咙→舌根。另一支从肺入心→胸中→心包经→天池→曲泽→大陵→劳宫→中冲穴。

功效：补肾壮腰、调和气血。治腰腿无力冷痛、目涩健忘、潮热盗汗、头晕耳鸣、遗精阳痿。
气感：手心和中指气感较强。

6. 嘻（xī）—— 三焦

口型：两唇微启稍里扣上下相对不闭合，舌微伸有缩意舌尖向下，有嬉笑自得之貌。属牙音。
动作：两手从体侧抬起如捧物→过腹至两乳平→外旋翻掌向外→向头部托举→掌心向上指尖相对。呼气念"嘻"，足四五趾点地。吸气时五指分开循胆经路线下落→风池→面颊→渊腋→足四趾窍阴穴。6次。
意念引导：出足窍阴→至阴→上踝→膀胱经→小腹→历三焦→胸中→心包经→天池→曲泽→大陵→劳宫→三焦经。吸气从关冲穴→手臂→肩→肩井→缺盆→胸中→三焦→上行穿耳→额角→面颊→胆经→风池→渊腋→日月→环跳→足窍阴。

功效：理三焦气、疏通少阳经脉。治耳鸣、眩晕、喉痛、胸腹胀满、小便不利。
气感：呼气时无名指强，下落时足四趾强。

练习顺序

养生顺序（五行相生）：嘘(肝/木) → 呵(心/火) → 呼(脾/土) → 呬(肺/金) → 吹(肾/水) → 嘻(三焦)

治病顺序（五行相克）：呵 → 呬 → 嘘 → 呬 → 吹 → 嘻

按季节可重点加强对应字诀：春嘘、夏呵、秋呬、冬吹。

高效练习要点

1. 三调合一法
先练准发音口型（调息），再将意念集中在发音上（调心合一），最后融入动作（调身合一）。或先将发音呼吸练至极度成熟，再"带入"意念和动作（《中医气功学》引申法）。

2. 呼吸要领
鼻吸口呼，逆腹式呼吸。吐气追求匀、细、柔、长，最终达到"耳不得闻"的境界。初学允许略带声响辅助找准口型，熟练后逐渐过渡至无声。吸多呼少（吸气多于呼气），可避免泻邪太过并加强补益扶正之效。

3. 不勉强、不憋气
吐气时间量力而行（初学3-5秒即可），感觉快没力气就自然过渡到吸气。身体转动不追求标准角度，以不疼、不僵、不憋气为前提。

4. 姿势灵活
站、坐均可。坐姿关键：脊柱中正舒展，大腿与地面平行，双脚踏实，腰背挺直勿僵硬，头顶如悬细线。动作幅度可缩小，重点在以动作引动内气。

5. 练习频率
每字做6次为一遍，全6字一遍约10-15分钟。每日可练2-3次，3个月为一疗程。治病可辨证重点练1-2个字，每日3次，每次5-10分钟。

6. 注意事项
- 呼气发音为本功法核心，不可偏离为纯动作体操
- 虚证患者"中病即止"，不可过度泻之
- 练习环境安静、空气清新为佳
- 饭后半小时内不宜练习

关键概念

吐纳法：以呼气为主、发音为手段的呼吸锻炼方法，吸气为补、呼气为泻。
三调：调息（呼吸）、调身（姿势动作）、调心（意念精神），三者合一是气功核心。
五行相生顺序：木→火→土→金→水，对应肝→心→脾→肺→肾，养生按此序练。
逆腹式呼吸：吸气时腹部内收、呼气时腹部外凸的呼吸方式。
中病即止：虚证不可过度泻之，见效即收。

能力边界

六字诀以泻实见长，适宜实证和以邪实为主的虚实夹杂证。纯虚证需谨慎，应配合补法或"中病即止"。它是辅助养生和康复手段，不能替代正规医疗。

最佳实践

  1. 初学从出声开始，逐步过渡到无声默练
  2. 按五行相生顺序全套练习，或按季节重点加强
  3. 每次练习前先做预备功（静站3分钟，调匀呼吸）
  4. 意念循经是核心深化手段，初学可先只做发音+动作
  5. 配合提肛缩肾（收腹敛臀），效果更佳
