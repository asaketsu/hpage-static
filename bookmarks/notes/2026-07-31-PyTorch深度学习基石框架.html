核心结论

PyTorch 是全球最主流的深度学习研究框架，两大核心能力：GPU 加速张量计算 + 基于 tape 的自动微分（autograd）。以"Python First + 动态计算图"哲学击败了 TensorFlow 的静态图范式，成为学术研究和原型开发的事实标准。10 万+ Star，几乎所有主流 LLM（Llama/Qwen/DeepSeek/GLM）都基于 PyTorch 构建。

一、两大核心能力

能力 说明
GPU 加速张量计算 类 NumPy 的 Tensor，无缝 CPU/GPU 切换，GPU 加速幅度巨大
基于 Tape 的自动微分 反向模式自动微分（reverse-mode autodiff），动态构建计算图，随时修改网络行为零开销

动态 vs 静态计算图

维度 PyTorch（动态图） TensorFlow 1.x（静态图）
图构建 运行时动态构建（define-by-run） 先定义后执行（define-then-run）
调试 ✅ Python 原生调试器直接用 ❌ 需特殊工具
灵活性 ✅ 任意修改网络行为，零开销 ❌ 改结构需重建图
直觉 ✅ 线性思维，所见即所得 复杂
结果 🏆 学术界/原型事实标准 TF 2.x 转向动态图（Keras）

"PyTorch is not a Python binding into a monolithic C++ framework. It is built to be deeply integrated into Python."

二、核心组件

组件 说明
torch Tensor 库（类 NumPy），强 GPU 支持
torch.autograd 基于 tape 的自动微分，支持所有可微 Tensor 操作
torch.nn 神经网络库，与 autograd 深度集成
torch.jit TorchScript 编译栈，创建可序列化、可优化的模型
torch.multiprocessing Python 多进程 + Tensor 跨进程内存共享
torch.utils DataLoader 等工具

典型用途

  1. NumPy 替代品：用 GPU 加速科学计算
  2. 深度学习研究平台：最大灵活性和速度

三、设计哲学

原则 说明

六、快速上手

import torch
import torch.nn as nn

# 1. Tensor 基本操作
x = torch.randn(3, 4)           # 随机张量
y = x.cuda()                     # 移到 GPU
z = x @ x.T                      # 矩阵乘法

# 2. 自动微分
x = torch.randn(3, requires_grad=True)
y = (x ** 2).sum()
y.backward()                     # 自动求导
print(x.grad)                    # dy/dx = 2x

# 3. 神经网络
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(784, 10)

    def forward(self, x):
        return self.fc(x)

model = SimpleNet()
if torch.cuda.is_available():
    model = model.cuda()

# 4. torch.compile 加速 (PyTorch 2.x)
model = torch.compile(model)     # 一行代码加速

# 5. 训练循环
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

七、PyTorch 2.x / torch.compile
