# AISmartDetect — 多模态零训练视觉检测桌面工具

> 来源：微信公众号
> URL: https://mp.weixin.qq.com/s/H_GXJTg-r1KrHznXxiteGw
> 主题：支持文本/视觉双模提示检测、免训练一键导出 ONNX、批量自动标注的桌面 AI 视觉工具
> 评分：⭐⭐⭐ (3/5) — 产品推广文，但"零训练多模态检测 + 自动标注闭环"模式值得参考

## 核心结论

**核心卖点 = 零训练 + 多模态提示 + ONNX 导出闭环。** 用户输入文本类别名或 1-3 张参考图框选目标，即可定义新检测类别，无需训练、无需配置环境，一键导出 ONNX 模型部署到产线/边缘设备。

## 技术分析

### 底层模型推测

文章未明确提及底层模型，但从功能描述可推断：

| 线索 | 推测 |
|------|------|
| 文本提示检测（输入类别名即检测） | **基于开放词汇检测模型**，如 Grounding DINO / YOLO-World / GLIP |
| 视觉提示检测（1-3 张参考图框选） | **基于少样本/视觉条件检测**，如 T-Rex / Grounding DINO + 视觉特征注入 |
| 免训练定义新目标 | 冻结主干，通过 prompt/visual embedding 注入新类别 |
| Small/Middle/Large 三档 | 对应 YOLO-World-S/M/L 或类似分档 |
| ONNX 导出 | 标准推理部署链路 |

### 核心技术亮点

| 亮点 | 说明 |
|------|------|
| **零训练检测** | 文本提示（"person, car, dog"）或视觉提示（1-3 张参考图框选）即可定义新目标，免去采集+标注+训练全流程 |
| **双模融合** | 文本提示 + 视觉提示两种方式，适应已知类别名 vs 自定义/稀有目标两种场景 |
| **ONNX 导出闭环** | 文本/视觉提示 → ONNX 模型 → 高速推理 → 批量自动标注，形成完整工作流 |
| **自动标注 + 编辑器** | 导出的 ONNX 模型对文件夹批量检测 → 生成 YOLO 格式 `.txt` → 内置标注编辑器修正 |

## 功能矩阵

| 功能模块 | 检测源 | GPU 加速 | 特色 |
|----------|--------|---------|------|
| **文本提示检测** | 图片/视频/摄像头/RTSP | ✅ | 输入类别名即检测，一键导出 ONNX |
| **视觉提示检测** | 图片/视频/摄像头/RTSP | ✅ | 1-3 张参考图框选，多类别管理 |
| **ONNX 推理** | 图片/视频/摄像头/RTSP | ✅ | ONNX Runtime，CPU/CUDA 自选 |
| **自动标注** | 图片文件夹批量 | ✅ | 生成 YOLO `.txt` + 视频抽帧 + 标注编辑器 |
| **摄像头采集** | 本地摄像头/RTSP | — | 实时预览/拍照/录像 |
| **业务案例** | 视频/摄像头 | ✅ | 目标过线计数（跳帧加速） |

## 工作流闭环

```
文本/视觉提示定义目标
        ↓
  即时检测验证效果
        ↓
  一键导出 ONNX 模型          ← 免训练，直接固化
        ↓
  ┌─────┴──────────┐
  ↓                ↓
ONNX 高速推理    批量自动标注
(产线/边缘部署)  (YOLO .txt + 编辑器)
                  ↓
            训练更高精度模型
```
