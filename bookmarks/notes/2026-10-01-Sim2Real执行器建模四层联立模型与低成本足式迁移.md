## 内容整理：四层联立执行器模型（可直接落 MuJoCo/mjlab）

### 1. 模型总架构：模块化四层串接

执行器-关节模型按四层串接，每层对应一类物理效应：

- **延时队列**：u[k] = τcmd[k] → u[k−d]，指令到生效的纯延迟，d = round(τd/Δt)
- **二阶离散系统**：u[k−d] → τ*[k]，模拟电机电气动力学（ωn 固有频率、ζ 阻尼比），连续系统经 ZOH 离散化得 Ad/Bd，离线算一次在线只做矩阵乘加
- **约束块**：τ*[k] → τ[k]，三子层——限斜率（rate limit：每步扭矩变化 ≤ rmax·Δt）→ 力矩饱和（clip ±τmax）→ 死区（|τs|<τ0 输出 0）
- **关节动力学+摩擦**：τ[k] → (q[k+1], q̇[k+1])，摩擦用平滑库伦+粘性：τf = τc·tanh(q̇/ε) + b·q̇，tanh 平滑避免 sgn() 低速抖动；积分用半隐式欧拉（先更新速度再更新位置，稳定性优于显式欧拉）

### 2. 参数包与分块辨识策略

参数集合 θ = {ωn, ζ, τd, τmax, rmax, τ0, τc, b, J}，共 9 个。

工程铁律：**分块辨识，禁全参数联合拟合**——先二阶+延时（扫频/阶跃响应），再约束块（极限测试），再摩擦/惯量（自由回落+堵转）。全参数联合辨识会互相"解释"导致不可辨识或局部最优。

### 3. 两种流派的对比：物理参数辨识 vs 神经网络学习

- **PACE 路线（物理派）**：参数扫描 + CMA-ES 进化优化拟合，通过"仿真-实机数据闭环"辨识刚度/阻尼/惯量等物理参数。优点是参数可解释、可迁移、可诊断；缺点是需要实机数据采集台架。
- **Actuator Net 路线（学习派，walk-these-ways/ANYmal）**：训练一个小神经网络，输入关节位置历史序列，输出实际扭矩（隐式建模延迟+非线性+滞回）。优点是无需假设模型结构；缺点是黑盒、需要大量实机回放数据。
- 两派共同前提：真机数据必须有。区别只是"用物理结构约束拟合"还是"用网络容量吸收"。

### 4. Microduck 全流程验证（399 美元价位的教科书闭环）

Microduck 把"仿真训练→策略导出→真机部署"完整闭环做到 399 美元并全开源，其方法论核心：

- **动作空间匹配控制模式**：串行总线舵机只收目标位置非力矩 → 策略输出"目标关节角增量"或"低通滤波后的目标位置"，并加动作平滑惩罚。仿真里给干净目标角度、真机一上电原地抽搐的经典翻车，根因就是动作空间与执行器控制模式不匹配。
- **四类现实差距逐个排查**：①执行器饱和（舵机堵转限流/发热降力，仿真无此保护——必须把实测堵转扭矩写进训练环境）②通信延迟与丢帧（动作延迟缓冲 1-4 步 + 随机掉帧注入训练）③摩擦与地面（摩擦系数 DR 0.3-1.5 宽域 + 随机外推力 + 质心偏移/连杆质量扰动模拟 3D 打印装配不对称）④传感器噪声提前注入（正态噪声 + 随机置零模拟丢包，治"病态依赖单一传感器"）。
- **奖励黑客防御**：单一"前进速度"奖励必产生贴地滑行/背部蹭地/疯狂抖动等丑解。解耦为前进速度+航向偏差+姿态惩罚+力矩/角速度惩罚+动作平滑+足端滑动六项，多目标约束下的平衡态才是自然步态。
- **课程化训练**：速度指令三档（0/0.2/0.5 m/s）随机采样，高失败率档自动降权；难度切换必须用成功率门控（连续 N 回合不摔才升档），禁用奖励曲线刚涨就升档（策略崩溃后拉不回来）。
- **训练预算与验收**：低成本足式需数千万步交互，500 万步后才现周期性步态；每 200 万步导出模型人工目测，TensorBoard 曲线只能证明数值收敛、不能证明动作不摔真机。

## 查询拓展：三个待验证的开放问题

- 四层联立模型在 mjlab/MuJoCo 中的实现粒度：constraint 块该放在 actuator 插件层还是 env wrapper 层？位置语义不同（前者影响物理引擎积分，后者只影响策略观测）。
- STS3025 舵机的 τd（通信+执行延迟）实测值如何标定：可复用 E13 真机日志的指令-回读时差统计（43°/s 带宽差已是已知事实，但纯延迟 d 与 slew rate 是两个独立参数）。
- Actuator Net 路线对 DUCK 是否可行：需要真机"位置历史→实际输出"配对数据，E13 的 jsonl 落盘链（e4_sop_log）理论上已有采集条件。

## 归纳总结

- Sim2Real 的真难点不是"仿真无限接近真实"而是"策略别依赖现实细节"——域随机化让策略学会应对不确定性，而非拟合精确参数。
- 执行器建模是低成本平台 Sim2Real 的第一优先级：E15 失败（slew 收太紧探索全灭）与 Microduck 经验互证——执行器约束的正确位置是"训练时见过"而非"训练时避开"，上限收太紧=动作空间压死。
- 四层模型的价值在于**可诊断性**：真机抖动/延迟/饱和三种病各有独立参数负责，出问题能定位到层，比黑盒 Actuator Net 更适合当前 DUCK 的调试深度。
- 分块辨识是参数工程的通用铁律，与 RL 训练中"一次只改一个变量"的实验纪律同构。

## 趋势判断

- 低成本足式（Microduck 399 美元档）正在把 Sim2Real 从"大厂专属"变成"教科书级公开方法论"，执行器建模从可选项变成标配环节。GitHub Trending 上 Microduck 刷屏印证社区重心已从"训得动"转向"迁得稳"。
- 物理派（PACE/CMA-ES）与学习派（Actuator Net）将走向混合：物理结构承担主干+残差网络吸收未建模效应，类似 Residual Dynamics Learning 的标准路线。
- 对 DUCK 项目：E16 处方（slew DR 上限≥260°/s、下限压低）与四层模型的约束块完全对应——rate limit 层的 rmax 就是 slew 参数的物理对应物，E15 的教训等于把 rmax 收到探索死亡区。

## 关联分析（与 DUCK-Pi_5 / Hermes 的落地映射）

- **E16 直接弹药**：四层模型的约束块给出 slew DR 的理论框架——rmax 是训练域参数而非真机参数，DR 应覆盖 [真机实测 43°/s, sim 原生 321°/s] 的宽区间，让策略"见过慢也见过快"，而非困死在窄带。
- **死区块 τ0 与 STS 舵机静摩擦对应**：DUCK 真机的启动死区（速度 100 负载欠行程±40°只走一半）本质是 τ0+τc 的组合效应，可从校准台账数据反推。
- **延迟注入与 act 延迟 DR（E12 处方）同源**：Microduck 的"动作延迟缓冲 1-4 步"就是 E12 obs delay DR 的动作侧对偶，两篇互证处方正确性。
- **对 Hermes 无直接映射**，但"分块辨识禁联合拟合"与 Agent 调试的"单变量对照"纪律同构，属于工程方法论迁移。

## 拓展应用推荐

- **P0（DUCK 项目）**：E16 launch 脚本的 slew DR 配置按本文框架重审——下限贴近真机实测（40-50°/s），上限保持 sim 域（≥321°/s 或干脆不设上限），中段让 DR 覆盖。配合成功率门控课程（Microduck 模式）替代固定 iter 数。

## 指南分析：Sim2Real 执行器建模操作顺序（下次直接抄）

1. 被动自由落体测试：模型进 MuJoCo 先看会不会穿模/关节反插/接触异常（很多训练失败根因是模型第一步就错了）
2. 空载最大速度 + 堵转扭矩实测 → 映射进仿真执行器参数（禁凭感觉填）
3. 阶跃响应 → 分块辨识二阶+延时参数（先这块，禁全参数联合）
4. 约束块标定：rate limit/饱和/死区三子层逐个极限测试
5. 训练域 DR 配置：摩擦 0.3-1.5、延迟 1-4 步、质量 ±10%、质心偏移、观测噪声+置零
6. 课程化：速度三档随机 + 成功率门控升档 + 每 200 万步导出人工目测
7. 验收看功能指标（步态自然度/存活时长）非代理指标（reward 曲线）
