0. 核心架构主线

在 CAA 的 Part Design 开发中，大部分操作不是直接修改几何数据，而是通过 接口操纵 feature（特征）。理解接口分类和层级可以大幅降低查文档和试错的时间。

Part 容器 → Body/GeometricalSet 容器 → Feature（草图、修饰、变换特征等）
                                      → Sketch（2D/3D 草图）
                                       → BRep 访问（面、边、顶点）

开发心智模型：一个 Pad 是一个 feature，一个 Fillet 也是一个 feature；PartBody 是一个容器，GeometricalSet 是另一个容器；选择 BRep 边/面/顶点时，拿到的是拓扑访问接口。

1. 接口 Framework 分布总览

Framework 典型接口 作用
PartInterfaces CATIPad、CATIPocket、CATIFillet、CATIChamfer、CATIShaft、CATIPrtPattern 等 具体造型特征的 C++ 原生接口，提供特征参数读写能力
MecModInterfaces CATIPrtPart、CATIPrtContainer、CATIMechanicalTool、CATIMfBRep、CATIBRepAccess、CATIGeometricalElement 等 零件容器、MechanicalTool/Body、BRep 拓扑访问、几何元素等基础设施接口
MechanicalModelerUI CATFeatureAgent、CATFeatureImportAgent 等 机械建模 UI 侧的选择代理机和交互工具

补充：草图相关接口在 SketcherInterfaces，GSM 线框/曲面工厂在 CATGSMUseItf，两者在 Part Design 命令中经常配合使用。

2. 零件容器与 Body 体系

2.1 零件根容器

CATIPrtPart 是零件根 feature（MechanicalPart）的原生接口。通过 CATIPrtContainer 从文档 spec container 获取：

CATIPrtContainer_var spPrtContainer = spSpecContainer;
CATISpecObject_var spPartSpec = spPrtContainer->GetPart();
CATIPrtPart_var spPrtPart = spPartSpec;

CATIPrtPart 核心方法：

方法 作用
GetMainTool() 获取主 Body（PartBody），返回 CATIBasicTool_var
GetCurrentTool() 获取当前激活的 Body/GeometricalSet
GetFeatureSolid() 获取 PartBody 的 result feature
GetCurrentFeature() 获取当前工作对象
SetCurrentFeature() 设置当前工作对象（等价于 Define In Work Object）
GetReferencePlanes() 获取 XY/YZ/ZX 三个参考平面

CATIPartRequest 负责遍历 Part 下的所有 Body 和 GeometricalSet：

方法 作用
GetSolidBodies() 获取 Part 级别下所有根 Body（MechanicalTool）
GetSurfBodies() 获取所有根级几何图形集（含 OGS 和 GS）
GetMainBody() 获取主 Body（PartBody）

2.2 Body 与 GeometricalSet

Body 和 GeometricalSet 是两种不同的 MechanicalTool/GSMTool startup feature：

Startup 对应接口 说明
MechanicalTool CATIMechanicalTool PartBody 或用户创建的 Body，可聚合实体特征
GSMTool (type=0) CATIMmiNonOrderedGeometricalSet GeometricalSet，可聚合线框/曲面/GSM 特征
GSMTool (type=1) CATIMmiOrderedGeometricalSet OrderedGeometricalSet，特征有序，吸附规则更严格
通用鉴别 CATIMmiGeometricalSet GS/OGS 的共同基接口，Body 不实现此接口

创建新 Body 和 GeometricalSet：

CATIMechanicalRootFactory_var spRootFactory = spSpecContainer;
// 创建新 Body（MechanicalTool）
CATIMechanicalTool_var spNewBody = spRootFactory->CreatePRTTool("MyBody");
// 创建 GeometricalSet
CATISpecObject_var spGS = spRootFactory->CreateGeometricalSet("MyGS");
// 创建 OrderedGeometricalSet
CATISpecObject_var spOGS = spRootFactory->CreateOrderedGeometricalSet("MyOGS");

切换当前工作对象：

CATIPrtPart_var spPrtPart = spPartSpec;
spPrtPart->SetCurrentFeature(spNewBody);  // 后续创建的特征进入此 Body

2.3 特征容器归属

创建特征时，工厂默认将特征放入 GetCurrentTool() 对应的容器：

CATIPrtFactory_var spPrtFactory = spPrtPart;
// 特征自动进入当前激活的 Body/GS
CATISpecObject_var spPad = spPrtFactory->CreatePad(spSketch);

一句话速记：CATIPrtContainer 拿 Part，CATIPrtPart 管当前工具，CATIMechanicalRootFactory 创建容器，CATIPartRequest 遍历容器。

3. 草图体系

3.1 草图本身

草图是 Part Design 中绝大多数成形特征的前提输入。

接口 作用
CATISketch 草图核心接口，提供几何元素创建、约束、求解等能力
CATI2DWFFactory 2D 线框工厂，在草图中创建点、线、圆、样条等
CATISketchFactory 草图级别的工厂，管理草图打开/关闭/求解

典型获取草图并创建几何：

CATISketch_var spSketch = spSketchFeature;
CATI2DWFFactory_var sp2DFactory = spSketch;
sp2DFactory->CreateLine(pt1, pt2);
spSketch->CloseEdition();

3.2 草图与特征的关联

草图与成形特征的关联是双向的。以 CATIPrism（Pad/Pocket 的基接口）为例：

// 从特征获取其剖面草图
CATIPrism_var spPrism = spPad;
CATISpecObject_var spSketchFeature;
spPrism->GetProfile(&spSketchFeature);

// 替换特征的剖面草图
spPrism->ModifyProfile(spNewSketch);

关键点：CATIPrism::ModifyProfile() 和 GetProfile() 是原生接口中管理草图关联的标准方式。Rib/Slot 等通过各自的 CATIRib/CATISlot 接口提供类似方法。草图特征在规格树中是特征的子节点，但逻辑上独立存在，可以被多个特征引用。

4. 草图基成形特征（Sketch-Based Features）

这是 Part Design 中最核心的特征族，均通过 CATIPrtFactory 创建。

4.1 拉伸类

接口 继承自 特征 关键参数
CATIPad CATIPrism 凸台 限制类型、长度、方向、镜像拉伸
CATIPocket CATIPrism 凹槽 同 Pad，方向为材料去除
CATIShaft CATIPrism 旋转体 旋转角度、方向
CATIGroove CATIPrism 旋转槽 同 Shaft，方向为材料去除
CATIRib CATIShape 筋 中心曲线、剖面、轮廓控制方式
CATISlot CATIShape 开槽 同 Rib，方向为材料去除

CATIPrism 是 Pad/Pocket/Shaft/Groove 的基接口：

方法 作用
ModifyProfile(sketch) 设置剖面草图
ModifySym(int) 设置对称拉伸
ModifyDirection(dir) 设置拉伸方向
GetProfile(sketch) 获取剖面草图

Pad 典型用法：

CATIPrtFactory_var spPrtFactory = spPrtPart;
CATISpecObject_var spPad = spPrtFactory->CreatePad(spSketch);
CATIPrism_var spPrism = spPad;
spPrism->ModifyDirection(dir);
spPrism->ModifySym(1);
// 更新 Part
spPrtPart->Update();

4.2 扫描类

接口 特征 说明
CATISweep 扫掠 显式扫掠（轮廓 + 引导线）
CATIPrism 棱柱（Pad/Pocket） 沿单一方向拉伸闭合轮廓
CATIRib 筋 轮廓沿中心曲线扫掠

4.3 多截面、筋与加厚

创建方式 特征 说明
CATIPrtFactory::CreateLoft() 多截面实体 返回 CATISpecObject，多个截面 + 引导线
CATIPrtFactory::CreateRemovedLoft() 移除多截面实体 材料去除版
CATIPrtFactory::CreateStiffener(sketch) 加强筋 返回 CATIStiffener 接口可读写参数
CATIPrtFactory::CreateRib(sketch, centerCrv) 筋 返回 CATIRib 接口

4.4 接口继承链

CATBaseUnknown
  → CATISpecObject       // 规格对象通用能力
    → CATIShape          // 形状通用能力（SetDefaultValue、BuildShape 等）
      → CATIPrism        // 拉伸基类（ModifyProfile、ModifyDirection）
        → CATIPad / CATIPocket
      → CATIShaft / CATIGroove
      → CATIRib / CATISlot / CATIStiffener / CATISweep

5. 修饰特征（Dress-Up Features）

修饰特征不创建新的整体形状，而是对已有实体进行局部修改。

接口 继承自 特征 关键参数
CATIFillet CATIShape 倒圆角基类 修剪支撑面、过渡角、分模线
CATIEdgeFillet CATIFillet 边倒圆角 ModifyRadius()、ModifyRadiusOnVertex()、ModifyPropagation()
CATIFaceFillet CATIFillet 面倒圆角 两个面组 + 半径
CATITritangentFillet CATIFillet 三切线倒圆角 两个面 + 一个移除面
CATIChamfer CATIShape 倒角 ModifyLength1()、ModifyLength2()、ModifyPropagation()
CATIDraft CATIShape 拔模 ModifyAngle()、ModifyNeutral()、AddSupportToDraft()
CATIShell CATIShape 抽壳 ModifyIntOffset()、ModifyExtOffset()、AddFaceToRemove()
CATIThick CATIShape 加厚 选择面 + 偏移方向
CATIThread CATIShape 螺纹 圆柱面 + 标准参数

EdgeFillet 典型写法：

CATIPrtFactory_var spPrtFactory = spPrtPart;
CATLISTV(CATISpecObject_var) listEdges;
listEdges.Append(spEdge);
CATISpecObject_var spFillet = spPrtFactory->CreateSolidFillet(
  &listEdges, TANGENCY, 5.0);
CATIEdgeFillet_var spEdgeFillet = spFillet;
spEdgeFillet->ModifyPropagation(MINIMAL);
spPrtPart->Update();

选型口诀：局部修改用 Dress-Up 特征，新建形状用 Sketch-Based 特征，面操作用 Surface-Based 特征。

6. 变换特征（Transformation Features）

接口 继承自 特征 关键方法
CATIMirror CATIShape 镜像 ModifyMirrorPlane()、AddMirrorObject()、SetDesignIntent()

镜像典型写法：

CATIPrtFactory_var spPrtFactory = spPrtPart;
CATISpecObject_var spMirror = spPrtFactory->CreateMirror(spFeature, spPlane);
CATIMirror_var spMirrorIntf = spMirror;
spMirrorIntf->AddMirrorObject(spAnotherFeature);
spPrtPart->Update();

7. 阵列特征（Pattern Features）

接口 继承自 特征 关键方法
CATIPrtPattern CATIShape 阵列基类 GetItem()、GetItemList()、GetTransfo()
CATIRectPatt CATIPrtPattern 矩形阵列 GetStep1()、GetStep2()、GetNb1()、GetNb2()
CATICircPatt CATIPrtPattern 圆周阵列 GetDir()、GetPto()、GetNbr()、GetNba()
CATIUserPatt CATIPrtPattern 用户阵列 自定义位置点

圆周阵列写法：

CATIPrtFactory_var spPrtFactory = spPrtPart;
CATISpecObject_var spPattern = spPrtFactory->CreateCircPattern(
  spFeatureToRepeat, spAxis, 6, 60.0, 1, 10.0);
CATICircPatt_var spCircPatt = spPattern;
int nbr = spCircPatt->GetNbr();  // 总实例数
int nba = spCircPatt->GetNba();  // 角度步数

8. 布尔运算（Boolean Operations）

布尔运算通过 CATIPrtBooleanFactory 创建，返回的 feature 可通过 CATIPrtBooleanOperation 查询运算信息：

工厂方法 运算类型 说明
CreateAssemble(iFirst, iSecond) Assemble 保留材料侧信息，有极性感知
CreateAdd(iFirst, iSecond) Add 无条件合并
CreateRemove(iFirst, iSecond) Remove 从目标 Body 减去工具 Body
CreateIntersect(iFirst, iSecond) Intersect 保留两个 Body 的交集

CATIPrtTrimFactory 提供 Trim 运算（CreateUnionTrim / CreateRemoveTrim）。

CATIPrtBooleanOperation 查询方法：

方法 作用
GetTool() 返回被操作的工具 Body
GetFirstOperand() 返回第一运算体的 CATBody
GetSecondOperand() 返回第二运算体的 CATBody

典型布尔运算流程：

// 1. 创建独立工具 Body
CATIMechanicalRootFactory_var spRootFactory = spSpecContainer;
CATIMechanicalTool_var spToolBody = spRootFactory->CreatePRTTool("ToolBody");

// 2. 设为当前，在其中创建特征
spPrtPart->SetCurrentFeature(spToolBody);
CATIPrtFactory_var spPrtFactory = spPrtPart;
spPrtFactory->CreatePad(spSketch);

// 3. 切回目标 Body，执行布尔运算
spPrtPart->SetCurrentFeature(spTargetBody);
CATIPrtBooleanFactory_var spBoolFactory = spPrtPart;
CATISpecObject_var spBoolOp = spBoolFactory->CreateRemove(spTargetBody, spToolBody);
spPrtPart->Update();

执行布尔运算后，工具 Body 会被吸收到目标 Body 中，在规格树中显示为 Assemble.1、Add.1、Remove.1 等节点。

9. 曲面基特征（Surface-Based Features）

接口 继承自 特征 说明
CATISplit CATISuSplit 分割 用曲面切割实体，SetExtrapolationType() 控制传播模式
CATISewing CATIShape 缝合 将多个曲面缝合为实体
CATIClose CATIShape 封闭曲面 将封闭曲面转为实体

Split 典型写法：

CATIPrtFactory_var spPrtFactory = spPrtPart;
CATISpecObject_var spSplit = spPrtFactory->CreateSplit(spBody, spSplitSurface);
CATISplit_var spSplitIntf = spSplit;
CATPrtExtrapolationType mode = CATPrtExtrapolation_Tangent;
spSplitIntf->SetExtrapolationType(mode);

10. 零件工厂：CATIPrtFactory

CATIPrtFactory 是 Part Design 开发中最常用的原生工厂接口，几乎所有特征都通过它创建。通过 CATIPrtPart 获取：

CATIPrtFactory_var spPrtFactory = spPrtPart;

常用工厂方法速查

CreateRib(sketch, centerCrv) 筋 CATIRib
CreateSlot(sketch, centerCrv) 开槽 CATISlot
CreateStiffener(sketch) 加强筋 CATIStiffener

CreateSolidFillet(edges, propMode, radius) 实体边倒圆角 CATIEdgeFillet
CreateSolidFillet(rsur1, rsur2, removeRsur) 三切线倒圆角 CATITritangentFillet

CreateShell(faces, intOff, extOff) 抽壳 CATIShell

特征默认放入 CATIPrtPart::GetCurrentTool() 对应的当前容器中。可通过 SetCurrentFeature() 切换后再创建。

11. BRep 访问体系

在 Part Design 命令中，用户选择面、边、顶点后，需要通过 BRep 访问接口来理解选择结果。

接口 访问拓扑 典型来源
CATIMfBRep BRep feature 的主入口 feature 的 QueryInterface(IID_CATIMfBRep)
CATIBRepAccess 单个 BRep 子元素（面、边、顶点） 选择路径的 leaf
CATIMfFsur / CATIRSur Face（面） CATIBRepAccess 的子对象
CATIMfRedge / CATIREdge Edge（边） CATIBRepAccess 的子对象
CATIMfFvertex / CATIFVertex Vertex（顶点） CATIBRepAccess 的子对象

选择后的解析链路：

CATPathElement *pPathElem = _selectionAgent->GetValue();
CATBaseUnknown *pLeaf = NULL;
pPathElem->GetFinalLeaf(&pLeaf);

CATIBRepAccess_var spBRepAccess = pLeaf;
if (!!spBRepAccess)
{
  CATIMfFsur_var spFace = spBRepAccess;
  if (!!spFace)
  {
    // 用户选中的是一个面
  }
}

读取 BRep 几何数据：

CATIMfBRep_var spMfBRep = spFeature;
CATLISTV(CATIBRepAccess) listResult;
spMfBRep->GetResults(CATIBRepAccess::ClassId(), listResult);

13. 开发速查路线

场景 1：创建草图拉伸特征

建议实践

实际开发中，建议先把 PartInterfaces 和 MecModInterfaces 的 PublicInterfaces 目录浏览一遍，结合本文的分类表格，遇到陌生接口时能快速判断它属于哪一层的哪个场景。

15. 拓展：CAA Part Design 实战要点

15.1 接口获取惯用法

CAA 使用 QueryInterface 通过智能指针赋值实现，而非显式调用：

// ✅ 正确：隐式 QueryInterface
CATIPrtPart_var spPrtPart = spPartSpec;       // 自动 QueryInterface
CATIPrtFactory_var spPrtFactory = spPrtPart;   // 链式获取

// ❌ 不推荐：显式 QueryInterface（冗长且易错）
CATIPrtPart* pPrtPart = NULL;
spPartSpec->QueryInterface(IID_CATIPrtPart, (void**)&pPrtPart);

15.2 Update 机制

每次创建或修改特征后，必须调用 CATIPrtPart::Update() 才能使变更生效。Update 会触发特征树的重新求解。如果多个特征连续创建，只需在最后调用一次 Update。

15.3 事务与撤销

CAA 的特征操作自动纳入 Part 的 Undo/Redo 栈。如果需要将多个操作打包为一个 Undo 步骤，可使用 CATCkeTransaction：

CATCkeTransaction trans("创建凸台+圆角");
trans.Begin();
// ... 多个特征创建操作 ...
trans.End();
// 用户一次 Ctrl+Z 即可撤销全部

15.4 特征定位与插入点

默认情况下特征追加到当前 Body 的末尾。如果需要精确控制插入位置：

  • 先用 SetCurrentFeature() 设置插入锚点
  • 或使用 CATISpecObject::InsertBefore() / InsertAfter() 调整规格树中的顺序

15.5 从文档获取 Part 的完整链路

// 从 Editor/Document 获取 Part 的标准链路
CATFrmLayout* pLayout = CATFrmLayout::GetCurrentLayout();
CATFrmWindow* pWindow = pLayout->GetCurrentWindow();
CATDocument* pDoc = pWindow->GetViewer()->GetDocument();

CATIIniDocument_var spIniDoc(pDoc);
CATIContainer_of spContainer = spIniDoc->GetRootContainer("CATIPrtPart");
CATIPrtContainer_var spPrtContainer = spContainer;
CATISpecObject_var spPartSpec = spPrtContainer->GetPart();
CATIPrtPart_var spPrtPart = spPartSpec;

15.6 特征删除

删除特征不能直接 delete，必须通过 CATISpecObject::Remove()：

CATISpecObject_var spSpecObj = spFeature;
spSpecObj->Remove();  // 从规格树中移除并清理依赖

15.7 孔特征特殊处理

孔（Hole）是少数有独立复杂接口的特征。CATINewHole 提供完整的孔参数控制：

CATISpecObject_var spHole = spPrtFactory->CreateHole(spSupport, spDirection);
CATINewHole_var spNewHole = spHole;
spNewHole->SetDiameter(10.0);
spNewHole->SetDepth(20.0, CATPlainHoleType);
spNewHole->SetBottomType(CATVBottomHoleType, 90.0);  // V形底，90°

15.8 常见坑点

坑 症状 解决
忘记 Update() 几何不更新，特征参数未生效 每次修改后调用 CATIPrtPart::Update()
错误的容器 特征创建到了错误的 Body/GS 先 SetCurrentFeature() 再 CreateXxx()
Body vs GS 混淆 Body 中无法放入曲面特征 曲面放 GS，实体放 Body；用 CATIMmiGeometricalSet 鉴别
BRep 选择为空 CATIBRepAccess 查询失败 检查 CATPathElement 的 leaf 是否为 BRep 子元素
布尔运算后 Body 消失 工具 Body 被吸收 这是正常行为，工具 Body 变为布尔运算的子节点
孔方向不对 孔从错误的面进入 用 CATINewHole::SetDirection() 明确指定
