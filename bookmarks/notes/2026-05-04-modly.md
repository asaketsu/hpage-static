## 项目简介
　　# Modly — 项目总览 　Modly 是一款桌面端 AI 图生 3D 应用，由 lightningpixel 团队开发并在 GitHub 上以开源形式发布（仓库地址 https://github.com/lightningpixel/modly ）。它的核心定位是将单张 2D 图像转换为高质量 3D 模型，并且所有推理过程完全在本地 GPU 上运行，无需依赖云端服务。截至 2026 年 4 月 28 日，项目版本为 0.3.4，累计获得约 2.4k Stars 和 254 个 Fork，经历了 192 次提交迭代。项目推测采用 MIT 许可证发布，面向 Windows 和 Linux 双平台。对于需要本地化 3D 生成能力的场景——例如游戏开发、工业设计快速原型、数字孪生预处理——Modly 提供了一套完整且可扩展的桌面解决方案。 　在架构层面，Modly 采用经典的 Electron + Python 双进程模型。前端基于 Electron + React 18 + TypeScript + Vite（通过 electron-vite 脚手架集成）构建，使用 Tailwin
