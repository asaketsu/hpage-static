一句话总纲

重载/结构化动力学失配不该用 domain randomization 硬扛，而该用"可微仿真解析梯度 + 两阶段解耦辨识"直接吃掉：先校准基座模型（消磨损/标定漂移），再只辨识载荷段 mass+CoM，encoder-only 数据即可让重载步态精度提升 45~73%、原地 90° 跳转提升 73%，真机高难度动作 10/10 成功——且辨识后只需极小 DR 即可零样本上机。

一、内容整理

1.1 问题定位：结构化 gap ≠ 随机噪声

失配类型 性质 传统对策 后果
传感噪声 随机、小尺度 观测滤波 易处理
载荷/质量分布变化 系统性、大规模 Domain Randomization DR 把它当扰动对冲 → 策略保守、无法压榨物理极限

关键因果链：载荷改变总质量/CoM/惯量分布 → 名义动力学下的策略退化 → DR 加大随机化范围 → 策略更保守 → 敏捷任务（跳跃/踢腿）失败。HALO 的判断：这类"结构化 sim2real gap"的正解是先辨识再训练（explicitly reduce structured model bias prior to policy training），而不是训练时穷举。

1.2 HALO 三步管线

① 数据采集（真机）           ② 梯度辨识（可微仿真）        ③ 技能训练
单脚虎钳固定 + 探索策略    →  MuJoCo XLA 解析梯度       →  mjlab 运动模仿 + PPO
encoder-only 全身 FK 重建     两阶段：基座校准→载荷辨识     极小 DR → 零样本上机

①单脚固定数据采集（sensor-minimal 的核心 trick）：
- 浮动基座机器人拿全身轨迹 normally 需要 MoCap——HALO 用两只虎钳固定一只脚，全身状态可由关节编码器经正向运动学直接重建，全局基座漂移的歧义被机械约束消除
- 仿真中施加同一运动学约束保持一致
- 传感器噪声导致 FK 重建累积漂移（左右脚高度不一致）→ 每个时间步解一个受限二次规划（QP），对根节点+下肢关节增量做最小调整消除脚高差异
- 数据量需求极小："质量或 CoM 的微小变化会很快使仿真轨迹漂移，只需要少量数据即可辨识模型与真机的主要差异"

②梯度辨识公式族（全文数学核心，照录）：

系统辨识 = 轨迹匹配优化。真机 s_{i+1}^r = Φ_real(s_i^r, a_i^r; θ^r)，仿真近似 s_{i+1}^s = Φ_sim(s_i^s, a_i^r; θ)（控制序列固定为录制的真机动作，初态同步）。目标：

min_θ L_total(θ) = L_track(θ) + R(θ)，梯度下降 θ_{k+1} = θ_k − η∇_θ L_total(θ_k)

跟踪损失（笛卡尔空间，全身 + 上身加权）：
- L_track = L_track^all + α_u · L_track^upper
- L_track^all = (1/B) Σ_b Σ_t Σ_{j∈B} ‖x_{b,t,j}^s(θ) − x_{b,t,j}^r‖²（B 条轨迹片段、N 步 rollout、全体 body 集合 B；上身子集 U 额外加权——载荷影响最大的 links 必须盯紧）

正则项四件套：
R_total = λ_com·R_com + λ_mass·R_mass + λ_damp·R_damp + λ_fric·R_fric
- R_com = Σ ‖p_i − p_i^base‖²（link CoM 偏离名义值的惩罚）
- R_mass = Σ (m_i − m_i^base)²
- R_damp / R_fric = Σ φ(α_k; 0.8, 1.2)，box 约束函数 φ(α;l,u) = max(0,l−α)² + max(0,α−u)²——只罚区间外的值，区间内自由

③两阶段解耦（本文最关键的方法论贡献）：
- 痛点：名义模型失配（磨损、标定漂移、微小结构差异——无载荷也存在）与载荷引起的模型变化纠缠。直接从载荷数据辨识，优化会把基座模型误差错误地归因到载荷参数上
- Stage 1 基座校准：用无载荷轨迹，从名义值出发优化全套模型参数
- Stage 2 载荷辨识：以校准后模型为初始化，只优化载荷附着 links（torso/hands）的 mass 与 CoM
- 实践结论：第二阶段只辨 mass+CoM、不碰惯量张量，就足以显著消除重载 gap，还避免了惯量优化的复杂度

1.4 实验结果

vs CMA-ES（传统采样式 SysID）：梯度法参数估计更准，极端载荷下优势最大（CMA-ES 无梯度采样在高维+强非线性时样本效率崩塌）。

真机重载任务对比：

方法 步态精度提升 原地 90° 跳转 燕式平衡/侧踢/回旋踢
WDR（宽域随机化） 基线 真机无法产生足够垂直推力 0/10、0/10、0/10
CM（朴素校准） 部分完成但有姿态偏差 角度误差 41.8° 5/10、7/10、5/10
HALO +45.45%~73.33% 角度误差 11.3°（+72.97%） 10/10、10/10、10/10

WDR 在爆炸性全身动作上彻底失败的机理：随机化训练出的策略对"垂直冲量生成"留了过大安全裕度——保守性直接杀死敏捷性。

三、归纳总结

  1. 结构化 gap 与随机噪声要分开治疗：DR 是"对一切参数鲁棒"的保险策略，对系统性失配（质量/CoM 大移位）既浪费（训练成本）又有害（保守性杀死敏捷动作）——WDR 真机跳跃 0/10 是最响亮的证据。
  2. 纠缠必须解耦：基座模型误差与载荷效应不做两阶段分离，梯度优化会把前者错误归因到后者——任何"增量辨识"场景（升级硬件/加装模块/换电池）都适用此原则。
  3. 最小参数集哲学：Stage2 只辨 mass+CoM 就够，惯量张量留给小 DR——与 PACE 的"49 维可解释参数胜过大而全"互为印证。
  4. 可微仿真 vs 进化算法的分水岭在维度与非线性：CMA-ES 在低维可胜任（PACE 49 维），高维+极端载荷下解析梯度的样本效率优势拉开数量级——工具选择跟着参数维度走。
  5. 机械约束是最便宜的真值发生器：一只虎钳替代整套 MoCap，"传感器最小化"不是妥协而是设计——低成本平台（百元级舵机鸭）恰恰是最大受益者。
  6. 辨识准确后 DR 可以近乎归零：zero-shot 的前提不是"策略足够鲁棒"而是"仿真器足够真实"——sim2real 的第一性答案始终是对齐。

四、趋势判断

SysID 复兴已从单点走向谱系：2025-2026 不到一年内，PACE（CMA-ES + 固定基座激振，13 台机器人）、HALO（可微梯度 + 单脚固定，重载人形）、Fey 2025（残差动力学网络）三条路线并行成型，共同信号是——领域正从"随机化艺术"（Rudin/Lee/Miki 一系）转向"辨识工程"。判据依旧是：论文开始比拼"谁用的真实数据更少、参数更可解释、跨平台更多"。

可微仿真的疆域扩张路径清晰：fixed-base 机械臂 → 四旋翼 → 四足 → 重载人形（本文）。下一站大概率是辨识与策略训练的联合优化（在 MJX 里对 θ 和 π 同时回传梯度）以及在线 SysID（部署中持续微调模型参数）。

对 DUCK-Pi_5 这类低成本平台的启示：不必追新栈。v6 分段称重 + 外科手术式 XML 修正就是"手工版 HALO Stage2"；等重训放 AutoDL 时再把梯度辨识脚本化，性价比最优。

六、拓展应用推荐

  1. 装配完成后的两阶段标定方案（最高优先，与 PACE 推荐的 identify_duck.py 合并设计）：Stage0 用 v6 分段称重硬写 mass/CoM（HALO Stage1 的低成本替代），Stage1 带电后跑一段 STAND/踏步轨迹，梯度微调 trunk/小腿 mass+CoM 残差——产出与 XML 的 diff 报告再定热启动档位。
  2. 跟踪损失加权设计：若走辨识路线，body 段（电池+Pi5 集中）设 α_u 加权——直接抄 HALO 公式（5）-（7）。
  3. DR 收窄试验：v6 修正 XML 后重训时，把质量随机化窗从当前值收窄至 ±5% 级做 A/B——验证"辨识到位则 DR 可减"在同平台的效应，收敛预算省下来加迭代数。

七、指南分析

质量：★★★★——方法干净（两阶段解耦的动机论证极佳）、公式完备可复现、真机验证覆盖敏捷任务全谱（跳跃/踢腿/平衡 10/10）。单脚固定 + QP 矫正的 sensor-minimal 设计对低成本平台参考价值极高。
局限：①场景是"外挂重物"而非"内置质量分布演化"，与自研平台的失配来源有差异（数学同构但需自己映射）；②MJX/mjlab 栈有部署门槛，非 Python+MuJoCo 用户需额外学习成本；③Stage1 全参数校准需要无载荷状态的基线数据——对已装配整机意味着要拆载荷回退采集，工程上不总是可行（我方可用"官方 XML 当 Stage1 结果"绕开）；④未公开与残差动力学学习（Fey 2025）的直接对比。
