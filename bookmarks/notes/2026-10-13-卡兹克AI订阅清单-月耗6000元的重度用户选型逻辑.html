一、内容详细整理

1.1 五项订阅全景（月总花费 ~6000 元 + API 杂费）

  • ChatGPT Pro 100刀（约670元/月）：从 200刀 降档而来。GPT-6 Astra 发布期曾同时开 3 个 200刀 账号（重构 AIHOT 一天烧一个账号额度），现因 Claude Opus 5.5 太强而降档，11 月生效，配补偿的 62500 额度+重置卡够用。使用场景：自己+公司项目的反馈/PR 自动化开发、项目运维监控自动化、后端与硬件定向优化、协议破解（当晚在优化新公司网关和 AP 设置）。评价 GPT-6.1 Sol 在 BUG 修复上不错；对普通人是"最水桶"——聊天免费+生图额度+小开发够用。
  • Claude Max 250刀（约1675元/月，Google Play 渠道多收50刀）：核心付费项。Claude Opus 5.5 被称为"版本真神"，除后端/硬件优化/浏览器操控外，GPT-6.1 Sol 和 GPT-6 Astra 都很难与之对抗。额度体感约为 Codex 的 5 倍：高强度开发+设计+动效一周，周额度只用 84%。消耗几乎全在 Opus 5.5，Fable 5.1 基本不用。
  • X Ultra 260刀（约1742元/月，首月130刀半价，今日新订）：马斯克新会员体系，合并 Grok/Grok Bot/Cursor 和 X。购买动机纯粹冲 Grok Bot（后端还给用 Claude Opus 5.5），比 ChatGPT 的 Dots 好用很多；Grok 4.7 本体"比较拉"。额度很足：200刀 Ultra 给 50x，Claude/Codex 都是 10x。明确的退订条件：若 ChatGPT 把 Dots 优化好且 Grok 4.8/5 还是拉，就不续了。
  • Suno Pro 8刀（年付折合月53元）：音乐独一档，不常用但刚需，团队共用包年。
  • LibTV 至尊版 1499元（年付打折）：视频生成，团队跑量太大才订，"现在视频的AI太贵了，贵的肉疼"。

1.2 作者的核心判断

  • "很贵，我也只想订阅一个"——多订是被迫的（各家能力错位），不是爱好
  • ChatGPT 是最全面的水桶，对所有人友好（免费聊天+生图+Sol 够用的开发）
  • 重度开发的真实主力是 Claude Opus 5.5，且额度消耗效率远超 Codex
  • 新订阅（X Ultra）的决策完全由单一功能驱动（Grok Bot），并预设退订条件——订阅决策产品化了

二、查询拓展

2.1 订阅档位经济学

ChatGPT 三档（Free/Plus 20刀/Pro 200刀）+ Claude 双轨（Pro 20刀/Max 100-250刀，250 刀档约为 5 倍 Sonnet+Opus 混用额度）。作者展示的是"额度按需升降档"策略：Astra 重构期临时开 3×200刀，事后降回 100刀——把订阅当弹性资源池，而非固定身份。

2.2 渠道费现象

Google Play 订阅 Claude Max 多 50 刀、X Ultra 多 60 刀——应用商店 30% 抽成的转嫁。重度用户避开渠道费（网页直订）一年可省 ~1300 元。

2.3 "50x/10x" 额度单位

X Ultra 的额度倍率体系：200刀 Ultra=50x（相对基础量），Claude/Codex=10x。这是订阅制从"功能解锁"转向"算力量配额"的信号——各家都在把 token 当水电气计价。

三、归纳总结

3.1 重度用户订阅决策模型

任务刚需分层:
  代码主力(日耗最大) ──→ Claude Opus 5.5 (Max 250刀, 唯一"真神"档)
  自动化/运维/协议破解 ──→ GPT-6.1 Sol (Pro 100刀, 降档保底)
  单功能亮点 ──→ Grok Bot (X Ultra, 带退订条件的尝鲜)
  垂直刚需 ──→ Suno(音乐) / LibTV(视频) 团队分摊
决策特征: ①按任务强度弹性升降档 ②新订阅必设退订条件 ③渠道费敏感度低但额度效率敏感度高

3.2 对比维度

  • 消耗结构：Claude 占作者月耗 28%（1675/6000），但承担核心产出；X Ultra 占 29% 纯为一个 Bot
  • 额度效率：Opus 5.5 的 Max 250刀 ≈ 5×Codex 额度体感——同价位下 Claude 的"每元可完成工作量"目前领先
  • 退订摩擦：作者对 X Ultra 的退订条件（Dots 优化好 + Grok 还是拉）= 把订阅当成可随时撤的仓位管理

四、趋势判断

趋势1：订阅制 AI 进入"组合配置"时代

依据：连卡兹克这种顶级用户都"只想订一个"却被迫订五个，且各项承担不同任务位——单家全能的格局还没出现，用户在用真金白银投票各家最强的单点。

趋势2：Agent 编排能力（Grok Bot/Dots）成为新的付费开关

依据：X Ultra 260刀的购买动机 100% 是 Grok Bot 而非 Grok 模型本体——"谁来替我干活"比"谁更聪明"开始更值钱。

趋势3：视频生成是当前性价比最差的一档

依据：LibTV 至尊版 1499 元/年还被称"肉疼"，作者明确"不是做视频方向的没必要定"——视频 AI 的每元产出仍远低于文本/代码。

趋势4：额度倍率（x 倍数）将成订阅页标配

依据：X Ultra 的 50x/10x 标注 + Claude Max 的 5x 体感对比——用户已经在用"倍率"横向比价，倒逼厂商透明化计价。

五、关联分析

5.1 与我们多 provider 体系的关联

我们的 fallback 链（zai → openrouter → sensenova）就是穷人版"订阅组合"：zai coding plan 当 Opus 用（夜间满额窗口=额度倍率思维），openrouter/sensenova 当保底。卡兹克的"额度效率敏感"逻辑同样适用——429 风暴的本质就是额度倍率管理失败。

5.2 与 Agent Harness 自修复闭环笔记的关联

今日 Opik 四层栈笔记（explore/2026-10-13-Agent-Harness自修复闭环）讨论的"Agent 时代的运维"，正是卡兹克用 GPT-6.1 Sol 做的"反馈和 PR 自动化开发、运维监控自动化"——重度用户已经把订阅费花在"让 AI 管 AI"上。

5.3 与免费模型 API 体系的关联

我们有 free-model-apis 四线（智谱/HF/GitHub Models 等）——对照卡兹克月耗 6000 元，个人轻度用户的理性策略是"免费额度做底+按项目租用"，只在出现稳定刚需时才进订阅制。

六、金句摘录

「很贵，我也只想订阅一个。」— 多订是能力错位的结果，不是消费偏好。

「如果ChatGPT把Dots优化好了……那我大概率不会定了。」— 订阅决策带预设退订条件，仓位化管理。

「现在视频的AI太贵了，贵的肉疼。」— 视频生成仍是性价比洼地。

七、行动启示

  • 订阅决策模板化：每项订阅写清①承担的任务位②额度效率实测③退订条件——季度复审一次
  • 弹性升降档：项目冲刺期临时升档（如卡兹克 3×200刀 一个月），结束后立即降回
  • 渠道费规避：能网页直订不走应用商店（年省 ~1300 元）
  • 对我们的落地：zai coding plan 的 5h 窗口就是我们的"Max 订阅"，错峰排程=额度倍率最大化（已落地）；openrouter 免费档=水桶保底

八、拓展应用推荐

  • 个人 AI 预算规划场景：按"任务位→供应商→月成本→退订条件"四列表格做年度审计
  • 团队采购场景：Suno/LibTV 式团队分摊模式——共享账号成本除以人头算真实单价再决策
  • 模型选型场景：卡兹克的"5 倍额度体感"对比法——同预算跑同一任务集，比"哪家聪明"更真实的指标是"每元完成量"
  • Agent 产品设计场景：Grok Bot 的付费驱动力证明"编排层"可以独立于模型本体收费
