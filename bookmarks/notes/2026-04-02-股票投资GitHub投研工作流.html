📌 一句话总结

想学股票投资，用这 5 个 GitHub 工具搭建完整的华尔街投研工作流：数据抓取 → 基本面 → 技术面 → 情报分析 → 量化回测。

🔧 五大模块

1️⃣ 数据库整理 — yfinance

最流行的 Python 金融数据抓取库

一行代码从 Yahoo Finance 拉取股票/加密货币/ETF 的历史行情和财务数据，投研必备工具。

🔗 github.com/ranaroussi/yfinance

2️⃣ 基本面分析 — Dexter

专业金融深度投研 Agent

自动规划研究任务、调用实时数据、验证分析结论，替你完成深入的基本面调研工作。

🔗 github.com/virattt/dexter

3️⃣ 技术面分析 — ta

Python 技术分析库

基于价格与成交量数据快速计算常见指标：RSI、MACD、布林带、移动均线、波动率等。

🔗 github.com/bukosabino/ta

4️⃣ 情报分析 — daily_stock_analysis

LLM 驱动的股票每日智能分析器

自动抓取实时行情和新闻，整理日报，通过 Telegram 等渠道定时推送。

🔗 github.com/ZhuLinsen/daily_stock_analysis

5️⃣ 量化回测 — Qlib

微软出品 AI 量化投资研究平台

完整覆盖：因子挖掘 → 模型训练 → 回测 → 组合优化 → 订单执行 全链路。

🔗 github.com/microsoft/qlib

💡 关键洞察

  • 从 yfinance + ta 入门最轻量，不需要复杂配置就能拿到数据和指标
  • Qlib 是重量级选手，适合有一定 Python 基础后进阶
  • Dexter 和 daily_stock_analysis 都是 AI 驱动，需要 LLM API 配置
  • 整条链路形成闭环：数据 → 分析 → 验证 → 自动化
