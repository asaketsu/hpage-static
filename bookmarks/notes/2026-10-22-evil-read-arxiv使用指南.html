evil-read-arxiv 论文技能集使用指南

安装于 2026-10-22，5 个技能已被 Hermes 识别（对话直接触发）。本笔记 = 使用速查手册。

生成日期 2026-10-22

一句话总览

你只管用自然语言下指令，技能自动触发：说"start my day"得每日推荐，扔 arXiv 链接说"分析"得深度笔记，说"提取这篇论文的图"得插图，说"搜顶会 NeurIPS 2026"得会议论文清单。

五技能触发方式

技能 对话触发（推荐） 底层命令（手动） 输出
start-my-day "start my day" / "今日论文推荐" / "推荐 X 月 X 日的论文" python3 ~/.hermes/skills/research/start-my-day/scripts/search_arxiv.py --max-results 50 --top-n 10 notes/ 下今日概览 + 推荐列表

conf-papers "搜 NeurIPS 2026 顶会论文" / "CVPR 推荐相关论文" python3 ~/.hermes/skills/research/conf-papers/scripts/search_conf_papers.py --year 2026 年度顶会推荐笔记

典型工作流

1. 每日推荐（最常用）

你：start my day
→ 自动搜索 arXiv 近30天 + S2 热文 → 四维评分（相关性/新近性/热门度/质量）
→ Top 10 推荐 + 前三名自动生成深度分析和图片提取

可加聚焦词：start my day，今天重点关注 bipedal push recovery

2. 单篇深度分析

你：分析这篇 https://arxiv.org/abs/2510.xxxxx
→ 自动识别来源类型（arXiv/PDF/项目页/博客，不伪造元数据）
→ 生成笔记：摘要翻译→方法架构→实验结果→价值评估→局限→相关论文对比
→ 自动提取论文插图插入笔记

3. 顶会扫描

你：搜 ICML 2026 有哪些跟我们方向相关的论文
→ DBLP 拉论文列表 + S2 补引用 → 三维评分 → 年度推荐笔记
支持：CVPR/ICCV/ECCV/ICLR/AAAI/NeurIPS/ICML

4. 笔记库检索

你：我之前的笔记里有没有讲 world model 的论文？
→ 按标题/作者/关键词/arXiv ID 搜本地论文笔记，相关性排序

输出位置与格式

  • 笔记：~/uclaw/bookmarks/notes/（论文笔记与其他笔记同流）
  • 图片：notes/images/ 子目录（arXiv 源码包提取的原始矢量图优先）
  • 语言：中文报告（config language: zh）

修改研究兴趣

编辑 ~/uclaw/bookmarks/99_System/Config/research_interests.yaml：

  • 增删领域：改 research_domains（每个域 = 关键词列表 + arXiv 分类 + 优先级 1-10）
  • 排除噪声：excluded_keywords（已排除 workshop）
  • 提速：免费申请 Semantic Scholar API key 填入 semantic_scholar_api_key（减少 429 限流）

当前已配置 7 域：双足足式机器人(P5)、VLA操作(P5)、强化学习(P5)、世界模型(P4)、灵巧手(P4)、量化金融(P3)、结构健康监测(P3)。

边界说明
