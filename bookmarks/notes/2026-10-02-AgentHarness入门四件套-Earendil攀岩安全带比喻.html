一、比喻底座：攀岩安全带

Harness 本义=控制/固定的带具，动词=驾驭（控制某物以利用它的力量）。攀岩安全带的功能映射：
- 支撑保护（连接绳索防坠落）→ 运行环境保护
- 控制节奏约束路线 → 行为约束框架
- 挂装备的环（粉袋/岩塞/快挂）→ 工具系统
- 换山换路线随身带走+按地形调整 → 跨模型可移植+可改造
- 岩壁外的杂技演员/树艺师也用 → 同一 harness 跨场景复用

一句话定义：Agent = Model + Harness；Harness 是为 AI 模型提供运行环境的软件——与模型不同，它是你可以拥有和改造的。

二、Harness 四件套（核心框架）

组件 职责 通俗例
①系统提示 角色与行为指引 新员工第一天的工作说明（未内化但须遵循）
②工具 可调用能力+使用说明 搜索/代码/邮件；harness 不规定何时怎么用——描述清楚后让模型自己决定
③Agent 循环 据结果继续判断行动 任务→调工具→读结果→判断→再调（小学排名例子：搜索→不够再搜→代码做表→比对→不满意回搜索→满意则发邮件闭环）
④转换层 同一 harness 配不同模型 同一封邮件交三家模型比结果比成本，答案存在自己手里

系统提示 vs 模型内置规则（如 Claude 的"灵魂文档"）的区别：前者没那么深地嵌入模型，随每次用户提示一起进对话——外挂的入职说明 vs 内化的性格。

转换层的政治学：把权力和杠杆从 AI 实验室转回最终用户——本地拥有 harness=保留自主权（自由改造工具+本地保存人机通信记录）。

三、Pi 案例：极简+可拥有

Pi（Earendil 出品）=极简 harness：系统提示很短、默认工具极少、刻意不挡在用户和模型之间。可扩展性：改系统提示/写扩展（Extension）分享——社区扩展已超 5000 个。免费开源+跑在自己笔记本上。

谱系定位：首个流行的 harness Claude Code 并非模型无关（为本地用 Claude 编程而生）；此后 OpenClaw/OpenCode/Hermes/Pi 等开源中立 harness 兴起"令人鼓舞"。

五、内容整理（归纳总结与关联分析）

归纳总结：Harness=驾驭模型的运行环境软件（攀岩安全带：支撑保护/约束路线/挂装备/可携带改造/跨场景）。四件套：系统提示（入职说明式外挂指引）/工具（提供+描述但让模型自决）/Agent 循环（据结果续判续行直到自判完成）/转换层（多模型可换+把权力从实验室转回用户）。Pi=极简可拥有路线（5000+社区扩展），Hermes 被列入开源中立谱系。

关联分析：这是 Harness 文献序列的第零篇（入门篇）——rari 篇（七职责，生产视角）与 Replit 篇（薄 harness，前沿视角）之前的"是什么"。四件套是七职责的子集：系统提示/工具/循环/转换层 ∈ 七职责的"选上下文/暴露工具/有界循环"+转换层是 LangChain 路由篇的载体——文献间已形成完整层次：入门（本篇）→生产（rari）→前沿（Replit/路由）。独特增量有二：①比喻质量（五映射至今最完整）②用户主权视角（转换层=权力转移，这是技术文献少有的政治学维度，与适航背景的"构型管理自主权"天然共鸣）。注意它与 rari 篇的差异：本文的 harness 是"给模型搭台子"（四件套轻），rari 是"替模型挡枪"（七职责重）——前者 2026-08 视角，后者 09 月后的工程共识，一个月内行业理解从"台子"进化到"防线"。

七、趋势判断

  1. "Agent = Model + Harness"成为大众级公式：类比"App = 代码 + 操作系统"的普及路径，2027 年进非技术人群词汇
  2. 开源中立 harness 谱系固化：Claude Code（厂商锁定）→ OpenClaw/Hermes/Pi（中立开源）的叙事已成型——中立性成为 harness 产品的核心卖点
  3. "你可以拥有 harness"是隐私/主权卖点：本地运行+会话自持有会从极客偏好变大众需求——与政府侧数据主权法规共振
  4. 比喻决定传播：攀岩安全带类具象比喻的技术传播价值被验证（25.5K views 的科普爆款）——"讲人话"能力本身是技术内容的核心竞争力
