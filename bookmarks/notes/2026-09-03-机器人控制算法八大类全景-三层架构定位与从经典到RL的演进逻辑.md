## 一、内容详细整理

### 1.1 认知框架：先定位，再分类

**机器人控制系统三层闭环架构**（从上至下）：

| 层 | 职责 |
|----|------|
| 任务规划层 | 目标分解、路径规划 |
| **控制算法层**（本文主角） | 八大类算法所在 |
| 伺服执行层 | 电流环/功率驱动 |

**八大类分类维度**：建模方式 / 抗扰能力 / 数据依赖度。且**非平行并列，是一条演进链**：前四类=显式建模控制，后四类=接触作业/约束优化/数据补偿/自主习得。

**核心术语先行**（原文统一口径）：系统状态/误差/扰动/稳态误差/非线性耦合/前馈控制（无滞后）/反馈控制（小幅滞后）。

### 1.2 八大类逐一展开（算法表）

#### ① 经典线性反馈控制（伺服底层基础）
适用：线性、弱扰动、SISO（单输入单输出）——电机/舵机/单关节伺服闭环，工业机器人标配底层。

| 算法 | 核心原理 | 备注 |
|------|----------|------|
| **PID** | P 实时按误差出力 / I 累计历史误差消除稳态误差 / D 按误差变化率预判提前制动 | 最通用无模型线性控制；开车类比：P=按偏离幅度打方向，I=修正长期跑偏，D=预判偏移速度提前回正 |
| **LQR** | 状态空间多变量最优：同时最小化轨迹跟踪误差+控制能耗，矩阵求解固定反馈增益 | 配套**龙伯格观测器**从部分传感器估算不可测内部状态 |
| **极点配置** | 人为指定极点位置=主动定义收敛快慢/震荡幅度 | 高精度伺服动态调校 |

#### ② 基于模型的非线性动力学控制（多关节机器人）
适用：多自由度机械臂/人形机器人，强非线性强耦合。依赖精确动力学模型（惯性/重力/离心/科氏四项）。

| 算法 | 核心原理 | 缺陷 |
|------|----------|------|
| **CTC 计算力矩控制** | "前馈+反馈"复合：动力学模型算前馈力矩抵消非线性耦合→"线性化"为解耦弹簧阻尼系统→叠加 PID 消轨迹误差 | 高度依赖精准参数，**模型失配性能大降** |
| **IDC 逆动力学控制** | 目标轨迹的位置/速度/加速度逆解理论力矩作前馈，少量反馈修正 | 侧重前馈，闭环修正弱于 CTC |
| **全局反馈线性化** | 数学变换完全消除所有非线性→复用全部线性控制算法 | CTC 是其在机器人领域的工程实现 |

#### ③ 鲁棒控制（抗扰动、模型失配）
策略：**被动抵抗**——不依赖精准模型，强制保证扰动下稳定。适用户外移动机器人/重载机械臂。

| 算法 | 核心原理 | 工程要点 |
|------|----------|----------|
| **SMC 滑模控制** | 预设误差收敛滑模面，高频切换驱动力强制状态贴面滑向零误差 | 对碰撞/模型误差完全不敏感；**抖振**是主要抑制目标（高阶滑模/终端滑模改良） |
| **H∞ 控制** | 最优鲁棒：最小化"扰动→跟踪误差"最大传递增益，最坏工况误差仍在安全范围 | 精密手术/航空机器人 |
| **μ 综合** | H∞ 进阶，量化多关节耦合参数不确定性 | 多自由度复杂机器人 |

#### ④ 自适应控制（参数时变场景）
策略：**主动辨识**——区别于鲁棒的被动抵抗，在线辨识参数并修正模型。适用负载变化/零件磨损/工况漂移。

| 算法 | 核心原理 |
|------|----------|
| **MRAC 模型参考自适应** | 预设理想参考模型→实时对比实际输出差值→自适应律在线更新控制器参数 |
| **A-CTC 自适应计算力矩** | 在线辨识质量/惯量未知参数，动态修正动力学补偿项——解决 CTC 的参数依赖缺陷 |
| **RLS 递归最小二乘** | 参数辨识基础工具：迭代最小化预测误差持续更新参数估计 |

#### ⑤ 位置/力混合控制（环境接触作业）
前四类均为位置控制（仅适用无接触自由运动）。接触任务（打磨/装配/人机交互）纯位置控制会产生巨大冲击力。

| 算法 | 核心原理 |
|------|----------|
| **阻抗控制** | 不控位置不控力，调末端等效刚度/阻尼：高刚度保精度，低刚度柔顺退让（类比调弹簧硬度） |
| **导纳控制** | 阻抗的对偶：六维力传感器外力输入→计算位置修正量，力输入/运动输出（推它会退让），大负载/人机协作 |
| **位置/力混合** | 任务坐标系解耦：自由方向位置闭环，接触方向力闭环（插销装配：XY 控位置，Z 轴控顶紧力） |
| **直接力反馈** | 最简力控：目标接触力闭环跟踪，精密按压/恒力打磨 |

#### ⑥ 滚动优化与迭代学习（约束/重复轨迹）
针对两类超出单步反馈的需求：硬约束（电机限位/避障，如人形行走）与高度重复轨迹（流水线）。

| 算法 | 核心原理 |
|------|----------|
| **MPC 模型预测控制** | 每时刻预测未来时域窗口轨迹+结合硬件约束求最优控制序列，**只执行第一步，下时刻重新预测**（滚动时域） |
| **ILC 迭代学习控制** | 重复轨迹：记录上一批次全程误差→转化为前馈补偿叠加到当前批次，迭代越多精度越高 |

#### ⑦ 机器学习驱动控制（数据驱动建模补偿）
解决解析模型无法描述的建模残差（复杂摩擦/柔性形变）。定位：**从传统控制器的补偿模块→渐成主流**。

| 算法 | 核心原理 |
|------|----------|
| **神经网络补偿** | 离线采集轨迹/力矩/摩擦数据训练网络拟合建模残差，运行时输出补偿力矩叠加到传统控制器（FC/LSTM/Transformer 细分） |
| **高斯过程 GP** | 非参数：少量数据建概率动力学模型，**输出预测不确定度**→安全约束下高精度控制，低数据场景（手术机器人） |
| **模糊逻辑** | 人工经验→"If-Then"模糊规则，无需动力学方程 |
| **无监督聚类故障补偿** | 工况聚类自动识别摩擦漂移/磨损，实时切换补偿参数 |

#### ⑧ 强化学习智能控制（交互试错自主优化）
区别于监督学习：**无标注数据集**，与环境持续试错交互，靠奖励函数自主优化策略。

| 分支 | 代表算法 | 要点 |
|------|----------|------|
| 值函数（离散） | Q-Learning / DQN / Double-Dueling DQN | 查表→神经网络替代 Q 表；修正过估计偏差 |
| **策略梯度（连续主流）** | **PPO** / TRPO / PG / A2C-A3C | PPO=工业最常用，限制单次更新幅度保稳定，**机械臂装配/人形步态优化** |
| 基于模型 | PILCO / **Dreamer** | GP 概率模型/世界模型"想象"学习，减少真实硬件损耗 |
| 分层 HRL | Option-Critic / 分层 PPO | 上层拆子任务，底层子策略执行 |
| 衍生鲁棒 | 鲁棒 RL / 自适应 RL | 训练注入扰动天生抗扰；负载变化在线微调 |
| 模仿学习 | BC / GAIL | 示教轨迹预训练+RL 微调，解决从零试错效率低 |

### 1.3 全文的两个关键论断（最重要）

1. **工业级系统是多类算法叠加/级联融合**：典型架构——工业机械臂"**CTC 动力学前馈 + 滑模鲁棒修正 + ILC 迭代优化**"；人形机器人"**MPC 约束控制 + RL 步态优化**"
2. **演进不等于传统控制失效**："没有 PID 对电流环的精确闭环，任何上层学习算法都无法转化为实际力矩输出；**没有 CTC 对非线性耦合的有效抵消，RL 策略将面对极度不稳定的被控对象，训练收敛无从谈起**"——ML/RL 的成功建立在底层伺服稳定+中层动力学准确之上

**收尾金句**："控制不是选择题，而是一道系统集成题。"

## 归纳总结

1. **分类的三个维度（建模方式/抗扰能力/数据依赖度）是选型坐标系**：任一实际项目可按"模型可得性→扰动量级→数据可得性"三问定位到 2-3 个候选类
2. **前馈/反馈贯穿八大类**：PID（纯反馈）→CTC（前馈主导+反馈修正）→NN 补偿（前馈残差）——"前馈无滞后但怕模型错，反馈稳但滞后"的权衡是控制领域不变的张力
3. **鲁棒 vs 自适应是"被动/主动"哲学分野**：SMC 不问扰动来源硬扛（抖振代价），MRAC 在线学习扰动结构（收敛性风险）——工程上常混合使用
4. **力控是接触作业的独立维度**：阻抗/导纳的对偶（调刚度 vs 力转位置）与任务坐标系解耦是接触任务的通用解法
5. **RL 不是替代而是栈顶**：PPO/Dreamer 站在 PID+CTC 地基上——"RL 策略面对不稳定被控对象则训练收敛无从谈起"是对"RL 万能论"的最好解毒剂
6. **融合架构是工程现实**：真实系统=多层算法级联（CTC+SMC+ILC / MPC+RL），教科书式的单算法选型在工业中不存在

## 二、趋势判断

1. **机器学习补偿从"外挂"走向"主流"**（原文判断）：NN 残差补偿/GP 概率模型正在从传统控制器的附属模块变成标配——解析模型描述不了的摩擦/柔性只能靠数据
2. **人形机器人= MPC+RL 融合架构的主战场**：约束优化（限位/避障）与步态学习（PPO）天然互补，这条架构路线在 2026 已成行业默认
3. **Dreamer 类世界模型会向低端硬件下沉**：虚拟"想象"学习降低真机损耗的成本逻辑，对 DUCK 类低成本平台尤其关键
4. **"控制是系统集成题"的论断预示复合人才需求**：只会 RL 不懂 PID/CTC 的工程师做不好具身智能——底层伺服理解是被低估的护城河
5. **编译综述的中文生态在成熟**：深蓝具身智能这类系统化编译内容填补了中文技术社区的结构化知识空缺

## 四、指南分析

**按场景选算法**（本文框架的实用化）：

| 你的场景 | 候选算法 |
|----------|----------|
| 单电机/舵机闭环 | PID（①） |
| 多关节机械臂轨迹跟踪 | CTC/A-CTC（②/④） |
| 户外/重载/模型不准 | SMC（③） |
| 负载常变（抓取不同工件） | MRAC/RLS（④） |
| 打磨/装配/人机接触 | 阻抗/导纳/混合（⑤） |
| 硬约束轨迹（限位/避障） | MPC（⑥） |
| 流水线重复轨迹 | ILC（⑥） |
| 摩擦/柔性难建模 | NN 补偿/GP（⑦） |
| 未知环境/多任务 | PPO/Dreamer（⑧） |
| 工业级系统 | 融合：CTC+SMC+ILC 或 MPC+RL |
