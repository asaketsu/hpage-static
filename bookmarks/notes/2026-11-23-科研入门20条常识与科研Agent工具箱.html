内容整理：四层认知框架重组 20 条常识

原文按"论文类型 → 索引体系 → 期刊评价 → 发表流程"平铺 20 条。按认知递进重组为四层框架：

第一层：论文是什么（原文 01-04）

条目 原文要点 易错点
01 大论文 硕/博学位论文，含完整研究链（问题-综述-方法-过程-结论），需过评审答辩 不是"大一点的论文"，是学位申请载体
02 小论文 期刊/会议论文的日常说法，非严格学术名称 是否必须发表以本届培养方案为准，勿信师兄师姐转述
03 期刊 vs 会议 期刊走编辑初审+同行评议；会议围绕学术会议提交 CS 顶会认可度高 vs 其他学科重期刊——不能脱离学科比轻重
04 DOI 永久数字标识符，解决"找到"不解决"质量" 有 DOI ≠ 高质量论文

第二层：发在哪——索引与收录体系（原文 05-11）

条目 体系 覆盖领域 关键辨析
05 SCI 自然科学 是引文索引不是论文类型；"SCI论文"=发在 SCI 收录期刊上，收录只是基础标签
06 SSCI 社会科学（经管/教育/传播/心理/社会） 不能说"SCI 一定比 SSCI 厉害"——做社科 SSCI 才是对口体系
07 EI 工程技术（期刊+会议） EI 期刊与 EI 会议认可方式不同，投稿前先查本校认定规则
08 北大核心 多学科中文期刊 《中文核心期刊要目总览》简称，不是北大主办的期刊
09 CSSCI（南大核心） 人文社科 来源期刊/扩展版/集刊三个概念，认定时学校可能区别对待
10 科技核心 自然科学/工程/医学 中国科技论文统计源期刊（中信所遴选），与北大核心、CSSCI 是三张不同名单
11 普刊/国家级/省级 — 按主管主办层级称呼，不是国家划定的质量等级；投稿看正规性/方向匹配/审稿规范/学校认可四项

第三层：期刊怎么评——评价与风险信号（原文 12-17）

条目 概念 原文要点
12 影响因子 反映期刊整体近两年平均引用表现，不能推断其中每篇论文优劣；单篇论文价值回到问题/方法/证据/结论
13 JCR 分区 同学科类别内按指标排序切 Q1-Q4；一本期刊可属多个学科、分区不同——见"一区"先问哪个学科类别
14 中科院分区 国内另一套体系，与 JCR 方法不同——同一期刊 JCR Q1 ≠ 中科院一区；见"一区"先问是哪套分区
15 OA / 非 OA OA=开放获取（读者免费），常收 APC 但非必然；OA 是商业模式不是质量等级
16 水刊 口语化称呼，无全国统一判断线；审稿快/影响因子低/收版面费单独都不等于水刊
17 预警期刊 机构按撤稿/出版行为发布的风险名单；投稿前查本校文件+最新预警名单，防"发表了却无法认定"

第四层：流程怎么走——发表与规范（原文 18-20）

  • 18 作者排序：一作=主要贡献；通讯=对外负责（投稿/修改/沟通）。"导师一作学生二作视学生为一作"等规则各校差异大，唯一依据是本校白纸黑字文件
  • 19 审稿周期：编辑初审→外审→返修→再审→终审，任一环节可拒/可多轮；周期几周到数月无统一答案——审稿快慢不判期刊质量
  • 20 参考文献格式：GB/T 7714（国内学位论文/中文期刊）、APA（社科）、IEEE（工程/CS）、MLA（人文）四主流；执行铁律=学位论文看学校模板、期刊投稿看期刊要求，禁凭感觉拼格式；引用回原文核对作者/题名/卷期页码/DOI——AI 能整理格式，不能替你证明文献真实存在

第五部分：科研 Agent 工具箱三分类（原文增量，含推广嫌疑）

作者按"动手能力 × 配置意愿"把科研 Agent 分三类：

类型 代表 适合人群 原文评价要点
终端编码型 Codex / Claude Code 会编程、愿折腾环境/Skill 自由度最高（读本地文件/执行命令/自动化）；门槛=网络/账号/支付/终端；Claude Code 有国内账号风控问题
开箱即用型 YILA (yila.ai) 零配置新手 内置 ChatGPT/Gemini 等模型+论文数据库+学术工作流；⚠️ 原文"再也不愿意用豆包和deepseek了"属推广语气
本地 DIY 型 WorkBuddy 想要本地运行、自己装 Skill 国产桌面 Agent（⚠️ 原文未提：腾讯出品，2026-03 上线），支持文件/办公任务+Skill 扩展，教程生态丰富

归纳总结

  1. 20 条常识的公共内核是"破除字面义"：SCI 不是论文、北大核心不是北大办的、OA 不是质量等级、国家级不是国家评级——每条都在纠正一个"望文生义"陷阱。学术话语体系高度依赖圈内约定，新手成本本质是隐性知识的显性化成本
  2. 判断权层层下沉到本校文件：小论文要求、EI 会议认定、作者排序规则、成果认定——原文反复强调"以本校白纸黑字为准"，这是国内学术评价碎片化（各校自主认定）的忠实反映，也是新生最易踩的坑：拿 A 校经验套 B 校
  3. 工具箱三分类本质是"配置成本 × 能力上限"的权衡：终端型上限最高门槛最高，开箱型门槛最低但受制于厂商能力边界，本地 DIY 型居中。作者隐含的教学立场：新手从第二类起步，长出动手能力后再迁移
  4. 软广识别样本：前四部分（常识）与第五部分（工具）文体断裂——前者克制辨析，后者出现"再也不愿意用 X 和 Y"式斩钉截右的对比贬损，这是典型的推广文体特征。常识部分可信度高，选型结论需自行试用验证

趋势判断

  • "研0 扫盲"内容是稳定刚需赛道：收藏/赞比 1.27，工具书式内容在开学季周期性回流；作者系列化产出（前作讲文献检索工具）正在把个人 IP 绑定到"AI+学术训练"垂类
  • 科研 Agent 已完成"通用聊天 → 垂直工作流"的分化：YILA 定位"Codex for research"（检索-阅读-综述-数据-绘图-排版全链），与通用助手的差异点在证据链可溯源（每条结论回原文核对）——这与通用 LLM 的"流畅但不可验"形成对照，可溯源性正在成为科研 AI 的核心卖点
  • 桌面 Agent 大厂收口进行中：2026 年中腾讯收 WorkBuddy、阿里并千问办公、字节打通 TRAE/豆包办公——竞争从"多产品"转向"统一入口"。科研垂直 Agent（YILA 类）与巨头通用工作台（WorkBuddy 类）将分层共存：前者吃方法论深度，后者吃生态广度
  • 参考文献国标迭代周期（约10年/版：87→05→15→25） 与学术 AI 引用核查需求汇流：AI 幻觉文献是当前学术写作最大风险点，"格式合规"正在从人工技能变为 Agent 内置检查项
