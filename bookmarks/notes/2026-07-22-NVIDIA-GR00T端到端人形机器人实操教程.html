一、教程架构：两条并行解耦路径

┌─ 仿真工作流（无需实体机器人）──────────────────────────┐
│ Isaac Lab-Arena 仿真                                      │
│   ↓ 遥操作采集演示数据 (HDF5)                              │
│   ↓ 数据标准化 → LeRobot 格式                              │
│   ↓ GR00T 1.7 VLA 微调                                     │
│   ↓ 仿真内量化评估（任务成功率）                           │
└──────────────────────────────────────────────────────────┘

┌─ 真机工作流（硬件落地导向）──────────────────────────────┐
│ 宇树 G1 + Jetson Thor                                     │
│   ↓ 真实物理环境遥操作采集 (MCAP)                          │
│   ↓ 数据标准化 → LeRobot 格式                              │
│   ↓ GR00T 1.7 VLA 微调                                     │
│   ↓ 策略部署至 G1 真机                                     │
└──────────────────────────────────────────────────────────┘
路径 硬件需求 耗时 适合人群
纯仿真 仅需 GPU 算力 3-6h 学生、科研预研
真机部署 Unitree G1 + Jetson Thor 3-6h 产品落地工程师

两条路径完全解耦，可单独学习。

二、核心技术栈

组件 角色 说明
GR00T 1.7 VLA 基础模型 Cosmos-Reason2-2B 视觉语言骨干，预训练 32000h 人类演示 + 8000h 仿真
Isaac Lab-Arena 仿真环境 人形机器人全身平衡 + 视觉感知 + 操作仿真
Isaac Teleop (AGILE) 遥操作系统 演示数据采集，仿真输出 HDF5，真机输出 MCAP
LeRobot 数据标准格式 跨平台轨迹数据标准化，适配 GR00T 后训练
Jetson Thor 边缘算力 真机端模型推理
Unitree G1 人形硬件 目标机器人平台

三、六步能力链

步骤 技能 产出
① 环境搭建 Isaac Lab-Arena + Isaac Teleop 配置 开发底座
② 数据工程 AGILE 遥操作采集 HDF5(仿真)/MCAP(真机) 轨迹数据
③ 数据标准化 转换为 LeRobot 格式 标准化训练数据集
④ VLA 微调 GR00T 1.7 后训练 任务定制化策略模型
⑤ 量化评估 仿真内任务成功率测试 性能基准
⑥ 硬件部署 Jetson Thor → G1 真机 真实世界作业能力

四、GR00T 1.7 模型详情

指标 值
视觉语言骨干 Cosmos-Reason2-2B
预训练数据 32000 小时人类真实演示 + 8000 小时仿真
核心能力 长时序任务推理、跨机体泛化
输入 视觉 + 语言指令
输出 动作策略（关节级控制序列）

六、解决的行业痛点

痛点 教程方案
工具链割裂 Isaac + GR00T + LeRobot 一站式
Sim-to-Real 迁移难 仿真/真机双路径，直面光影/物体误差/机体平衡
VLA 落地门槛高 GR00T 1.7 预训练模型 + 标准化微调流程
从零搭建成本大 开源可复现，3-6h 跑通

七、与用户项目的关联

项目 关联点
双轮腿机器人 GR00T 工作流可直接迁移——全身平衡 + 视觉感知 + 动作策略
NVIDIA Cosmos 研究 GR00T 1.7 的骨干就是 Cosmos-Reason2-2B，与已研究的 Cosmos 平台衔接
Jetson Orin 仿真工作流可在 Jetson Orin 上跑（需足够 VRAM），真机部署需 Jetson Thor
STM32 + ODrive GR00T 输出关节级控制序列，STM32 可作为底层执行器接收 GR00T 策略
无感 FOC 虚拟传感器 GR00T 做高层策略决策，FOC 做底层电机控制——大脑/小脑分离架构
ESP-VISION ESP-VISION 做边缘视觉预处理，GR00T 做云端策略推理

硬件对照

教程硬件 用户现有 差距
