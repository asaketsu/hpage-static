1. 研究背景与必要性

1.1 问题提出

飞机结构设计知识密集、验证链条长，当前痛点集中于四点：

  • 知识难复用：规范、型号资料、试验报告与历史问题单分散异构，检索与追溯成本高；
  • 仿真成本高：高保真 CAE 单点小时级，设计空间探索不足，多轮迭代受限；
  • 试验与仿真脱节：模型校准依赖经验，参数不确定性与误差来源缺乏定量分解；
  • 证据链难审查：条款—设计—分析—试验的追溯关系靠人工维护，评审与变更影响分析效率低。

1.2 国内外研究现状与发展趋势

国外（2025-2026）：

  • 适航 AI 标准进入成型期：EASA AI Concept Paper Issue 2 确立 Level 1（人类增强）/ Level 2（人机组队）分级与 learning assurance 要求；NPA 2025-07 提出可信性规范框架；SAE/EUROCAE 联合标准 ED-324/ARP6983 于 2025 年完成公开咨询推进出版，首版范围限定"离线监督学习"。
  • 数据底座与机队孪生先行：AFRL Digital Hangar 建设空军装备全生命周期数字底座；美空军以退役 F-16 实体拆解扫描建孪生用于延续保障；2025-12 洛马为 F-35 引入 IBM+达索 PLM 强化构型协同；SwRI 依托 ASIP 大纲发展 NASGRO 裂纹扩展工具链（100+ 构型）与机队数字线程。
  • AI 融合层活跃：ONERA-DLR 建立航空 AI 联合虚拟研究中心；密歇根大学 Agentic MDAO（2025）以多 Agent 自动合成优化工作流，报告将 3-8 周设计迭代压缩至 30-90 分钟量级；SimScale 在 Design & Simulation Week 2026 演示多智能体工程评审与人机协同仿真；Bath 大学完成加筋壁板 FE 模型贝叶斯校准（Abaqus + 应变片压缩试验反推铺层参数后验）。
  • 架构共识：Agentic Twins 分层框架（Array 2026）明确 LLM 只承担认知层、决策层交给规则/优化器——"认知—决策分离"成为国际同构做法。

国内：知识图谱、代理模型、数字孪生研究活跃（《航空学报》2025 飞行器数字孪生专刊等），但在真实型号约束（适航/构型/试验）下的智能体闭环验证与证据链标准化上存在空白——即本研究切入点。

1.3 必要性与机遇窗口

  • ED-324/ARP6983 首版覆盖"离线监督 ML"，本研究的代理模型+知识库路线恰在可对齐范围内，按其骨架预留证据包接口可低成本获得适航兼容性；
  • 差异化定位：裂纹扩展工具、机队数据底座国外已成熟不自研，增量集中在 AI 融合层（知识追溯/多保真加速/残差闭环校准/概率化寿命）；
  • 产业价值量化：航空防务数字孪生市场 $2.49B(2025)→$3.07B(2026)、CAGR 23.3%，单次避免 AOG 价值 $150k-500k。

2. 研究目标

2.1 总体目标

建设一套受构型与适航规则约束的航空结构智能体科研闭环：

知识可追溯 → 仿真可加速 → 试验可校核 → 结论可审查 → 数据反哺下一轮设计

不是让大模型自动设计飞机，而是让每个设计结论都有数据、物理和证据支撑，人工责任保留。

2.2 具体目标（四层增强，量化）

增强层 目标 量化指标（建议值）
知识增强 找到正确资料，知道证据在哪 引用准确率 ≥95%；无依据回答率 ≤2%；单问题检索 ≤5min
计算增强 更快探索设计空间，知道预测是否可信 加速 ≥100×；留出集误差 ≤10%；90% 置信区间覆盖率 ≥90%；域外 100% 回退
决策增强 看到风险、候选与证据链，人工担责 评审材料准备时间 −50%；建议 100% 可回链（文档/页码/版本/工况）
证据增强 结论携带可审查证据包 证据包字段完整率 100%；模型更新 100% 审批制、可回滚

2.3 职责边界（对标 EASA Level 1）

LLM 不作符合性判定、不签发放行、不冻结构型；硬门禁归规则引擎与优化器，物理模型负责可验证响应，工程师负责技术判断与签署。

3. 研究方向

贯穿主线：结构数字线程与证据链（统一对象主键：部件/区域 ID → EBOM 版本 → 材料/铺层/连接 → 分析工况 → 试验结果 → 制造偏差/NDI → 飞参/维修 → 适航证据）。

方向 定位 解决的问题
3.1 结构知识智能体 认知层入口 规范/型号资料/试验报告/历史问题单难检索、难复用
3.2 试验代理模型 计算加速层 高保真 CAE 成本高、设计空间探索不足、仿真与试验脱节
3.3 结构数字孪生与寿命预测 价值兑现层 设计—载荷—损伤—寿命—维修决策链路不通

4. 研究内容

  • 4.1 知识管理（R1）：RAG 知识库 + 结构知识图谱（以失效模式为节点组织）；版本感知检索（构型状态为过滤条件）；每个结论回链原始文档、页码和版本。
  • 4.2 仿真加速（R2）：多保真代理模型谱系——Kriging/GPR（小样本+原生方差）→ Co-Kriging（高低保真联结）→ POD-GPR（场量输出）→ 神经算子（储备）；快速预测器、设计空间图与置信区间。
  • 4.3 模型校准（R3）：贝叶斯校准形成参数后验 + 残差学习分解系统误差，连接仿真与试验（对标 Bath 大学加筋壁板实证）。
  • 4.4 缺陷识别（R4）：CV、时序异常检测与多模态识别处理 NDI/DIC/FBG/PZT 及应变数据；损伤样本稀缺用生成式增广；传感器故障识别与数据重构。
  • 4.5 寿命预测（R5）：融合飞参、载荷谱、检测结果与裂纹扩展模型（NASGRO 类），输出概率化 RUL（分布而非点值），UQ 全链传播。
  • 4.6 工程协同（R6）：多智能体流程编排辅助评审、变更影响分析与证据包整理；按"单智能体工具 → agent-flow（阶段化+可审计中间产物）→ 多智能体协同（广度优先任务）"三步演进，防止过度工程。

5. 关键技术与技术路线

5.1 面向适航追溯的飞机结构知识智能体

  • 难点：非受控文档结构化；条款—设计特征—分析—试验—问题单五级追溯矩阵的自动生成与构型变更后的增量维护。
  • 技术路线：选定典型专业域（CCAR 25.305 静强度或 25.571 损伤容限）→ 文档结构化与图谱 schema → 追溯矩阵自动生成 → 变更影响分析 agent（EC 单→受影响条款/分析/试验清单）→ 评审 agent-flow 演示。
  • 验收：50 个真实工程问题盲测，引用准确率 ≥95%、版本正确率 100%、无依据回答率 ≤2%；证据包对齐 ED-324 learning assurance 骨架。

5.2 面向结构快速迭代的多保真代理模型

  • 难点：后屈曲等强非线性响应的低保真建模；高保真样本成本控制；置信区间真实覆盖率。
  • 技术路线：复材加筋壁板参数化（铺层比例/筋距/筋截面/长宽比）→ LHS 采样 20-50 低保真点 + 10-20 高保真点 → Co-Kriging + 自适应加样 → 贝叶斯校准 → 独立试验验证（不复用校准数据）；配域判定器 + 保守回退高保真。
  • 验收：加速 ≥100×；独立试验点误差 ≤10%；区间覆盖率 ≥90%；域外 100% 触发回退；校准后残差降幅 ≥50%。

5.3 面向结构与维修决策的结构数字孪生平台

  • 难点：实测—预测残差的工程可解释；单机预测到机群决策的价值兑现；传感器故障鲁棒性。
  • 技术路线：一个关键件（翼身连接区接头或主承力框）→ 接入载荷谱 + NDI/应变实测 → 裂纹扩展 + POD → 概率 RUL（中位数 + P90 区间）→ 维修建议样机（视情维修）；更新走审批制 + 可回滚。
  • 验收：RUL 必为分布输出；Demo 全程证据链可回放。

5.4 总体技术架构

L1 数据与构型层：PLM/PDM·CAE·试验·质量·飞参·文档（主键+版本+权限）
L2 知识与规则层：RAG·知识图谱·适航条款库·结构规则
L3 物理与学习层：FE·裂纹扩展·Kriging/Co-Kriging·POD-GPR·贝叶斯校准
L4 协同与决策层：工程师 Copilot·优化器·工作流 Agent
闭环：试验/SHM/服役数据 → 残差监控 → 模型更新（审批制、可回滚）

6. 应用案例与验证方案

案例：复材加筋壁板——多保真代理模型→试验校准→损伤容限预测一体化研究。

选型理由：参数化空间清晰；非线性 FE 与 DIC/应变试验可闭环；Bath 大学同构实证可对标；同时覆盖结构设计、代理模型、试验校准、复材损伤、数字孪生雏形五个科研点。

最小闭环 = 一个部件 + 一类失效模式 + 一套 FE 基线 + 一批试验数据
         + 一个带置信度的 AI 模型 + 一条可追溯证据链
里程碑 内容 验收门禁
M1（0-2 月） 参数化 + 低保真基线 + 数据盘点/对象编码 无 AI 可信基线建立（先证基线，再证 AI 增量）
M2（3-5 月） 高保真样本 + Co-Kriging 代理 + UQ 误差/覆盖率/域外拒答三项达标
M3（6-9 月） 试验校准 + 独立试验验证 校准后残差降幅 ≥50%，独立点误差 ≤10%
M4（10-12 月） 损伤容限/概率 RUL + 知识回链 + 评审演示 证据包完整率 100%，RUL 分布输出

7. 预期成果与考核指标

  • 平台/原型：结构知识智能体原型、多保真代理模型工具链、关键件孪生 Demo（三件可演示）；
  • 标准与知识产权：证据链企业标准建议 1-2 项（对齐 ED-324）、专利/软著 3-5 项、论文 2-4 篇；
  • 数据资产：加筋壁板"参数化-仿真-试验"数据集 1 套（后续型号可复用基线）；
  • 方法论："数字线程+证据链"可复制到其他专业域（起落架/接头/机身壁板）。

9. 风险分析与应对

风险 应对措施
数据密级/合规 私有化部署开源模型，数据不出域，L1 层强制分级权限
LLM 幻觉进设计依据 五件套输出 + 无依据拒答 + 硬门禁归规则引擎，幻觉率入验收
代理模型域外误用 域判定器 + 保守回退高保真，域外行为写入失效条件
高保真样本/试验成本 多保真架构降低高保真需求；主动学习选最有信息量试验点
多智能体过度工程 严格三步演进，无新增独立信息的 agent 不加
组织接受度 从检索/评审辅助等低风险高频场景切入，养成使用习惯后再进分析链

10. 保障条件

  • 组织：结构设计+强度+AI 工程师混编团队（建议 5-8 人核心组）；型号总师系统技术监督；
  • 数据：依托 PLM/构型管理系统划定的受控数据集与权限；
  • 工具：FE 商用许可（高保真）、开源栈（Kriging/Co-Kriging/贝叶斯校准/图谱/RAG）、NASGRO 类裂纹工具；
  • 合作（可选）：对标 ONERA-DLR 模式，与高校共建试验与校准联合课题。
