一、内容整理

本文系统拆解了人形机器人运动控制中主流 RL 算法 PPO（近端策略优化）的完整算法原理，共七部分，从 MDP 到泛化迁移。以下按原文逻辑逐段提炼。

1.1 为什么人形运控要用强化学习

传统控制需要显式建模动力学，但人形机器人的刚体接触、摩擦、碰撞无法精确解析。RL 的路线是：训练阶段在仿真里反复试错学出策略网络，部署阶段只做一次前向推理，极快。

核心洞察：适合 RL 的原因是动力学强非线性 + 有接触切换 + 目标多样（站/走/跑/抗扰），手写模型难，采样试错相对容易。

1.2 用 MDP 描述问题

强化学习把"序贯决策"问题建模为马尔可夫决策过程（MDP），由五个要素组成：状态空间、动作空间、状态转移、奖励函数、折扣因子 γ。

现实往往是 POMDP：真实速度、地面摩擦、外部推力无法直接测量。补救：把历史观测/动作喂进策略，让网络从时序推断隐藏量。

1.3 策略梯度与 REINFORCE

策略梯度定理的推导关键：log-derivative trick（对数求导技巧），把对概率密度的梯度转为对数概率梯度的期望，才能用采样估计。重要发现：梯度表达式中完全没有动力学模型——这就是 model-free 的含义。

REINFORCE 问题：方差极大。根本原因：用整条回报 G_t 当权重，环境的随机性被一股脑算进"动作的功劳"。

解法：减 baseline（状态价值 V(s)），只保留相对平均的好坏：

advantage = G_t - V(s)

减去只依赖状态的 baseline 不改变梯度期望（无偏），但大幅降低方差。

1.4 价值估计与 Actor-Critic

  • Actor（策略网络）：采动作，训练完成后的产品，部署时只用它
  • Critic（价值网络）：训练期的脚手架，估算状态价值 V(s)，只在训练时用

GAE（广义优势估计）— 一根旋钮调偏差-方差：

A_t = Σ(γλ)^k · δ_{t+k}   （δ = TD error）
  • λ→0：接近一步 TD（偏差大、方差小）
  • λ→1：接近 MC（偏差小、方差大）
  • 实践常用 γ=0.99, λ=0.95

⚠️ value loss 下降 ≠ 策略变好：critic 只负责"记分准不准"，不关心策略好不好。真正该盯的是回报曲线和任务指标。

On-policy 的核心矛盾：θ 一更新，策略就变了，之前那批数据不再是"当前策略"采的。想多复用但别跑偏——这是 PPO 要解决的问题。

1.5 PPO 核心：clipped objective

L = min( r·A, clip(r, 1-ε, 1+ε) · A )

其中 r = π_new / π_old（重要性采样比），ε ≈ 0.2

  • A > 0（好动作）：r 推到 1+ε 以上时目标变平、梯度归零 → 不鼓励过度增大概率
  • A < 0（差动作）：r 压到 1-ε 以下时目标变平 → 不鼓励过度抑制

本质：让目标函数对"过大的更新"不再给奖励，温和地把策略变化拉住。是 TRPO 信赖域思想的廉价一阶近似。

1.6 连续控制的策略设计

高斯策略：输出高斯分布的均值 μ，可选全局/状态相关 std。训练时按分布采样保留探索，部署时直接用均值平滑可复现。

action_scale 的物理含义：网络输出无量纲，q_target = q_default + action_scale · a，决定动作量纲。过大→乱甩，过小→迈不开步。

1.7 泛化与迁移

  • 课程学习：由易到难，始终保持在"够得着但有挑战"的可学习区间
  • 域随机化：训练时持续改变质量、摩擦、延迟等，使策略在一族动力学条件下鲁棒
  • 特权信息 + Asymmetric Actor-Critic：critic 接收仿真特权信息，actor 只用机载传感器
  • Teacher-Student：teacher 用全状态学出高水平行为，student 只依赖真机观测
  • Reward 设计原则：策略只会最大化奖励函数的标量，不会理解设计意图

1.8 算法对比

算法 运控地位 理由
PPO 主流 契合大规模并行仿真 + clip 稳定 + 实现简单
SAC 偶用 样本效率高但高维接触调参难
TD3 偶用 比 DDPG 稳但仍难调
TRPO 已被取代 思想重要但实现复杂

1.9 完整训练循环

并行环境 rollout
→ 记录 obs/action/reward/value/old_log_prob
→ bootstrap 末状态
→ GAE 算 advantage
→ advantage 归一化
→ 打乱切 minibatch
→ K 个 epoch 更新
→ 丢弃旧数据重采

二、查询拓展

2.1 Proximal Policy Optimization (PPO)

PPO 由 OpenAI 2017 年提出（Schulman et al., "Proximal Policy Optimization Algorithms"），是 TRPO 的工程化简化版本。核心创新是用 clip 裁剪替代 TRPO 的硬 KL 约束 + 共轭梯度求解，实现成本从二阶优化降到一阶梯度下降，且能跑多个 epoch、支持 minibatch。

2.2 Advantage Function 与 TD Error

优势函数 A(s,a) = Q(s,a) - V(s)，衡量"在状态 s 下选动作 a 比平均水平好多少"。TD error δ_t = r_t + γV(s_{t+1}) - V(s_t)，是单步 advantage 的无偏估计（理想情形下）。GAE 用望远镜抵消将多步 TD error 加权累加，塌缩成极简形式。

2.3 Sim-to-Real Gap

仿真与真机之间的差距是 RL 运控的核心挑战。域随机化的目标是让仿真覆盖一个包含真机参数的参数空间，真机落在这个空间内时策略保持鲁棒。这一思想最早由 Tobin et al. (2017) 系统阐述，已成为 sim2real 的标准范式。

2.4 人形机器人运控框架

RSL-RL（NVIDIA Isaac Gym 生态）是目前工业界最常用的 PPO 训练框架，采用大规模并行仿真（4096+ 环境）。代码概念 actor_critic.act 对应策略采样，compute_returns 对应 GAE 计算，ratio 对应重要性采样比，desired_kl 对应 KL 监控。

3.3 关键因果关系链（全文一页总结）

强化学习要解决的是"在序列决策中学出好策略"。

observation 决定策略能看见什么 → action 决定它能控制什么 → reward 决定我们想优化什么。

策略（高斯分布）把观测映射成动作分布，log_prob 量化"采到的动作有多符合当前策略"。

value + advantage 告诉每个动作比平均好多少——这是驱动学习的真正信号。

PPO 的 clip + KL + entropy 共同决定改得多快、多稳、多敢探索。

curriculum + domain randomization + imitation 决定仿真策略能否泛化到真机。

四、趋势判断

4.1 PPO 在运控中的统治地位短期内不会动摇

依据：PPO 的"稳 + 简单"在高维富接触任务中经过大规模工业验证。off-policy 算法（SAC/TD3）虽样本效率更高，但对超参数敏感、难稳定，且仿真采样足够便宜——样本效率优势被工程复杂性抵消。

4.2 RL + 传统控制的混合路线将成主流

依据：文章指出 RL 与 MPC 可以混合——用 MPC 当 teacher 生成示范，再用 RL 学策略；或让 RL 只学 MPC/基础控制器之上的残差修正。这种"模型先验 + 学习灵活性"的路线兼顾了两者优势，符合具身智能工程化趋势。

4.3 sim2real 将成为技术竞争的焦点

依据：纯算法差距正在缩小，真正的挑战是"仿真里训好的策略能否上真机"。域随机化、课程学习、Teacher-Student 的方法论竞争将决定谁家的机器人走得最稳。

4.4 高斯策略 → 多模态策略的演进

依据：当前高斯策略假设动作维度独立，对复杂接触场景（足式机器人、全向步态）能力有限。未来可能出现更灵活的策略参数化（如混合策略、多模态高斯），让策略同时探索多种动作模式。

五、关联分析

5.1 与双轮腿机器人 V2 项目（~/uclaw/project/wheel-legged-robot-v2）的关联

本项目当前采用 LQR + 五次多项式站起轨迹 的传统控制路线。本文的 PPO 框架提供了一条升级路径：

  • 用 PyBullet/Gym 建双轮腿动力学模型，训练站起+平衡策略
  • 高斯策略动作输出：关节目标角度交底层 PD，用 action_scale 映射到物理量
  • 特权信息：仿真中给 critic 真实速度/质心位置，actor 只用 IMU pitch + 编码器
  • 课程学习：先学直立平衡 → 加扰动 → 加行走命令
  • 域随机化：随机化质量、摩擦、延迟，覆盖 2.5kg 机体的不确定性范围

5.2 与 AI 人格模拟研究的关联（用户研究方向）

RL 的 reward 设计哲学——"策略只会最大化标量奖励函数，不理解设计意图"——与 AI 人格系统有类比意义：一个被单一指标优化的 AI agent，可能以不可预见的方式"刷指标"。这对应 reward hacking 现象，在 persona 系统中同样需警惕：单一满意度指标可能被 agent 以"讨好"方式刷高，而失去真实性。

六、金句摘录

「强化学习真正关心的从来不是某一步的小费（reward），而是长期的总收入（return）。」

「梯度里完全没有出现动力学模型。这就是 model-free 的含义。」

「Critic 是训练期的脚手架，不是成品的一部分。部署时丢掉。」

「PPO 不是硬约束 KL，也不保证新旧策略一定接近。它做的事更朴素：让目标函数对'过大的更新'不再给奖励。」

「探索不等于乱动。有效的探索是在'还能恢复'的范围内试探不同动作。」
