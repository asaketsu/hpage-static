Agent 自我进化与学习系统：从 Reflexion 到 Self-Discover 的技术演进

摘要

Agent 自我进化是 AI 系统从"被动工具"迈向"主动协作者"的核心能力。本文整合三篇关键论文（Reflexion、OPRO、Self-Discover）与本地已有知识（Small Rust Hermes 闭环设计、Hermes Agent 记忆架构、元认知不确定性感知），系统梳理 Agent 自我进化的技术演进路径，并提出可落地的实践框架。

一、核心论文精读

1.1 Reflexion: Language Agents with Verbal Reinforcement Learning (2303.11366)

核心思想：传统 RL 需要更新权重，Reflexion 通过语言反馈强化 Agent——Agent verbally reflect on task feedback signals，并将反思文本存储在 episodic memory buffer 中，引导后续决策。

关键机制：
- 反馈信号类型：标量值（success/failure）或自由语言（错误描述、改进建议）
- 反馈来源：外部（环境反馈）或内部（自我模拟）
- 记忆存储：反思文本作为 episodic memory，在后续 trial 中检索注入

实验结果：
- HumanEval 编码基准：91% pass@1（超越 GPT-4 的 80%）
- 在 sequential decision-making、coding、language reasoning 任务上均有显著提升

与本地知识的关联：
- Small Rust Hermes 的"反思改进闭环"直接借鉴此思想：审批历史喂回反思提示词
- Hermes Agent 的 agent-reflection skill 的双轨设计（全量反思 + 微反思）是 Reflexion 的工程化延伸

1.2 OPRO: Large Language Models as Optimizers (2309.03409)

核心思想：LLM 本身可以作为优化器。在每次优化步骤中，LLM 从包含历史解及其值的 prompt 中生成新解，评估后加入 prompt 进行下一轮优化。

应用场景：
- 线性回归、旅行商问题
- Prompt 优化：找到最大化任务准确率的指令（GSM8K 提升 8%，Big-Bench Hard 提升 50%）

关键洞察：
- 优化任务用自然语言描述
- 历史解 + 值 → 新解 → 评估 → 加入历史 → 迭代
- 无需梯度，纯语言驱动优化

与本地知识的关联：
- 与 Hermes Agent 的 auto-prompt-optimization skill 直接相关
- 可用于优化 system prompt、skill 匹配策略、不确定性阈值

1.3 Self-Discover: LLMs Self-Compose Reasoning Structures (2402.03620)

核心思想：LLM 可以 self-discover 任务内在的推理结构。通过选择多个 atomic reasoning modules（如 critical thinking、step-by-step thinking），组成显式推理结构供解码时遵循。

关键机制：
- Self-discovery 过程：LLM 选择并组合 reasoning modules
- 推理结构：显式、可解释、可复用
- 性能提升：BigBench-Hard、MATH 等基准提升高达 32%（vs CoT）
- 计算效率：比 CoT-Self-Consistency 少 10-40x 推理计算

关键洞察：
- 自发现的推理结构在不同模型家族间通用（PaLM 2 → GPT-4 → Llama2）
- 与人类推理模式有共性

与本地知识的关联：
- 与 Hermes Agent 的 state-machine-loop skill 的 10 步状态机循环模拟理念相通
- 可作为 skill 生成的高级模式：从任务中自动提取推理结构

二、技术演进路径

Level 1: 被动执行 (ReAct)
  └── 观察 → 思考 → 行动 → 观察...
  └── 无记忆，无反思，单次任务

Level 2: 主动反思 (Reflexion)
  └── 添加 verbal reflection + episodic memory
  └── 从 trial-and-error 中学习，不更新权重

Level 2.5: 反馈驱动反思 (Small Rust Hermes)
  └── 审批历史喂回反思提示词
  └── 技能有效性追踪 + 延迟候选队列

Level 3: 元认知 (Uncertainty-aware)
  └── 知道自己"不知道什么"
  └── 不确定性检测 → 量化 → 表达 → 行动

Level 4: 自我发现 (Self-Discover)
  └── 自动发现任务内在推理结构
  └── 推理结构跨任务、跨模型通用

Level 5: 自优化 (OPRO)
  └── LLM 作为优化器优化自身 prompt/策略
  └── 自然语言描述的优化循环

三、闭环设计模式（从本地知识提炼）

3.1 三个断裂的闭环（Small Rust Hermes 诊断）

断裂点 症状 根因
记忆检索是盲的 LLM 只能看到一行摘要，看不到正文 记忆被存储但不被检索回来影响推理
反思没有反馈环 第 N 次反思和第 1 次一样粗糙 审批日志被记录但从未被消费
技能匹配没质量追踪 低质量技能和高质量技能权重相同 匹配被触发但从不评估是否真的被用到

共同特征：数据在产生，但没有回流。

3.2 闭环修复方案

闭环 1：记忆检索闭环
- TF-IDF 检索 + 相关记忆注入系统提示
- 可选嵌入模型（fastembed AllMiniLML6V2）双层检索
- 混合匹配：0.4 token_overlap + 0.6 embedding_score

闭环 2：反思改进闭环
- 审批历史喂回反思提示词（最近 10 条）
- 延迟候选队列：跳过≠丢失
- 技能有效性追踪：有效性因子 = clamp(used/matched, 0.5, 1.0)

闭环 3：语义升级闭环
- 本地嵌入模型：AllMiniLML6V2（384 维，22MB）
- 冲突自动检测：余弦相似度超阈值 → 标记潜在冲突
- Feature gate 保护，可选编译

四、元认知：不确定性感知框架

4.1 不确定性检测方法

方法 原理 适用场景
Self-Consistency 多次采样统计一致性比例 有明确答案的任务
Token-level 概率 平均 token log probability 快速不确定性信号
语义聚类 embedding cosine similarity 聚类 长文本生成
校准技术 Platt Scaling / Temperature Scaling 需要概率校准
外部验证 RAG 检索比对、工具验证、多模型交叉 高风险场景

4.2 分层不确定性管理

不确定性级别 策略 触发条件
低 直接输出答案 self-consistency > 0.9 或置信度 > 8/10
中 输出答案 + 标注不确定性 0.5 < consistency < 0.9
高 拒绝回答 / 触发 RAG / 请求人工 consistency < 0.5 或置信度 < 4/10

五、实践启发

5.1 对 Hermes Agent 的改进建议

  1. 记忆检索增强
  2. 当前：MEMORY.md + topics/index.json（关键词索引）
  3. 改进：添加语义检索层（fastembed 或本地向量 DB）

  4. 优先级：P1（高 ROI）

  5. 反思反馈闭环

  6. 当前：agent-reflection skill 有双轨反思，但审批历史未被消费
  7. 改进：将审批历史（accept/reject 原因）喂回反思提示词

  8. 优先级：P1

  9. 技能有效性追踪

  10. 当前：skill matching 无质量追踪
  11. 改进：记录 matched/used 事件，计算有效性因子

  12. 优先级：P2

  13. 不确定性门控

  14. 当前：无显式不确定性检测
  15. 改进：在工具调用链中嵌入不确定性检查
  16. 优先级：P2

5.2 可落地的 Skill 设计

Skill: agent-self-improvement-loop

trigger: 任务完成后自动触发
steps:
  1. 执行反思：生成反思文本（任务难点、改进建议）
  2. 检索相关记忆：top-5 相似历史反思
  3. 对比分析：识别重复模式、新发现
  4. 更新技能：如有新工作流 → 创建/更新 skill
  5. 更新记忆：写入 memory 或 memory-write
  6. 记录进化日志：~/.hermes/evolution-log.jsonl

六、知识缺口

  1. 长期记忆衰减机制：如何自动遗忘低价值记忆？需要重要性评分 + TTL
  2. 跨 Agent 经验共享：ubot ↔ jbot 的经验池如何与自我进化闭环结合？
  3. 推理结构自动提取：Self-Discover 的 reasoning modules 如何工程化落地？
  4. 不确定性校准漂移：如何持续监控和修正模型的自我评估能力？

七、核心发现（≥3 条）

  1. Reflexion 证明语言反馈可替代权重更新：Agent 通过 verbal reflection + episodic memory 即可实现显著性能提升，无需 fine-tuning。这对 Hermes Agent 的 self-improving 机制是直接验证。

  2. 闭环设计是系统进化的核心：数据产生后必须回流（记忆检索、反思反馈、技能追踪），否则系统只是"能反思"而非"会学习"。Small Rust Hermes 的三个闭环设计模式值得全面借鉴。

  3. Self-Discover 揭示推理结构可自动发现：LLM 可以 self-compose reasoning structures，且跨模型通用。这为 skill 生成提供了新模式：从任务中自动提取推理结构，而非人工编写。
