## 一、量化推理的隐藏成本：Token Inflation

**出处**：arXiv 2026-06-24

### 被忽视的问题

量化（INT4/INT3）广泛用于降低推理成本，业界标准评估指标是**最终答案准确率**和**每 token 延迟**。但这项研究揭示了一个隐藏成本：**量化后的推理模型即使答案正确，也会生成更长的思维链（CoT）**，导致总 token 用量上升，抵消了每 token 的加速收益。

### 关键发现

- 跨数学推理、代码生成、科学问答、agent 工具使用基准：**INT4/INT3 量化能保持准确率，但 reasoning token 用量增加**
- 提出 **CoT Token Inflation Ratio**（CoT token 膨胀率）= 量化模型与全精度模型在各基准上的平均推理长度比
- Token 膨胀伴随行为变化：更多中间步骤 + 更大的语义重复
- 这些变化转化为**可测量的端到端真实服务惩罚**

### 缓解策略对比

| 策略 | 效果 |
|------|------|
| Prompting 调整 | 准确率-长度权衡**不一致** |
| 解码时采样调整 | 同上，不稳定 |
| **量化感知训练（QAT）** | **最有前景**——同时降低精度损失和 token 膨胀 |

### 对边缘部署的直接意义

用户在 Jetson Orin 上用 GGUF INT4/INT3 部署（edge-llm-quantization skill）。**这意味着：**

- ❌ 不能只看「量化后每 token 快了多少」
- ✅ 必须同时报告 **CoT Token Inflation Ratio**——量化模型比全精度多吐了多少 token
- ✅ 端到端实际 RTF（Real-Time Factor）可能没改善甚至恶化，因为 token 总量增加抵消了单 token 加速
- ✅ 如果用 QAT（量化感知训练）而非纯 PTQ（训练后量化），可同时缓解精度和膨胀

**行动项**：在 edge-llm-quantization skill 中增加 CoT Token Inflation Ratio 作为必报指标，部署前必须对比量化前后的端到端 token 总量。

## 二、ReM-MoA：跨层记忆拯救多 Agent 深度扩展

**出处**：arXiv 2026-06-23

### 问题：MoA 的深度饱和

Mixture-of-Agents（MoA）通过将多个 LLM agent 组织成分层推理管道来提升推理质量（推理时扩展的一种形式）。但现有 MoA 变体**随深度增加收益递减**：出现退化、过早平台期或饱和。

### 解决方案：记忆增强 MoA

ReM-MoA（Reasoning Memory MoA）通过两个机制维持扩展收益：

1. **Ranked Reasoning Memory（排序推理记忆）**：用比较型 Reviewer Agent 持久化存储并对所有层的推理轨迹排序
2. **Curated Diversified Memory Routing（精选多样化记忆路由）**：让不同 agent 接触成功和失败轨迹的不同组合——既传播高质量推理，又保持探索多样性

可选增强：**多领域 Reviewer 蒸馏管道**——通过前沿模型监督提升排序质量。

### 实验结果

- 5 个推理基准（数学、形式逻辑、代码、知识、常识）
- **持续优于先前 MoA 变体**，且在深度和宽度两个维度上都占优
- **优势随深度扩大**——这是关键：证明结构化跨层记忆是可扩展多 agent 推理缺失的核心机制

### 对 agent-orchestration-pattern 的启发

用户的多 agent 架构（agent-orchestration-pattern skill）描述了「单体全能 Agent 拆分为专业 Agent 团队，由编排器协调」。ReM-MoA 指出这类架构的关键缺失：**跨 agent/跨层的持久化推理记忆**。

| 现有设计 | ReM-MoA 启发的改进 |
|----------|-------------------|
| agent 各自独立，靠上下文传递 | 增加 Ranked Reasoning Memory 持久层 |
| 失败尝试被丢弃 | 失败轨迹也是记忆资产，用于多样化路由 |
| 无跨 agent 推理质量排序 | 引入 Reviewer 角色对中间结果排序 |

这其实呼应了用户已有的 `exchange-protocol` skill（三机经验交换）——但那是经验级共享，ReM-MoA 指出还需要**单次任务内的推理轨迹级共享**。

## 三、Crosscoder 定位工具能力：RL 改了什么，能控制什么

**出处**：arXiv 2026-06-25（Localizing RL-Induced Tool Use to a Single Crosscoder Feature）

### 研究问题

RL 微调让模型学会工具调用，但**内部到底改了什么表示**？能否在不重训的情况下，运行时控制这种行为？

### 方法：Dedicated Feature Crosscoders（DFC）

在 Qwen2.5-3B 上，用 48 组 crosscoder 超参数扫描，隔离出 RL 引入的紧凑特征集。

### 关键结果

| 指标 | 数值 |
|------|------|
| 编解码重建改善 RL 模型工具正确性 | **+31.1 ± 9.7 pp** |
| 被动迁移到冻结基座模型（capability spillover） | **+6.8 ± 5.0 pp** |

### 意义

- RL 引入的工具调用能力**集中在最小、可导引的特征集**中
- 这意味着可以**运行时控制 agent LLM 的行为**——无需重训练，通过调整这些特征的开/关
- 「capability spillover」证明：把 RL 学到的特征「移植」到没经过 RL 的基座模型上，也能获得部分工具调用能力

### 应用前景

这对**行为可控的 agent**很有价值：与其依赖 prompt 来控制工具调用行为（不稳定），不如在表示层直接操纵特征。虽然这需要 MECH INTERP 工具链，但指明了从「prompt 工程」到「特征工程」的方向。

## 二、查询拓展

### 2.1 Token Inflation（Token 膨胀）
量化（INT4/INT3）能保持推理准确率，但会让模型生成更长的思维链（CoT），导致总 token 用量上升，抵消单 token 加速收益。CoT Token Inflation Ratio 是量化模型与全精度模型的平均推理长度比。

### 2.2 ReM-MoA（Reasoning Memory MoA）
Mixture-of-Agents 的深度扩展存在饱和问题。ReM-MoA 通过 Ranked Reasoning Memory（排序推理记忆）和 Curated Diversified Memory Routing（精选多样化记忆路由）维持扩展收益，证明结构化跨层记忆是可扩展多 agent 推理缺失的核心机制。

### 2.3 Crosscoder 与工具能力定位
Crosscoder 是 MECH INTERP（机械可解释性）工具，能定位模型内部表示。研究发现 RL 微调引入的工具调用能力集中在最小可导引的特征集中，可通过运行时特征操纵控制行为——无需重训练。

### 2.4 QAT vs PTQ
QAT（Quantization-Aware Training，量化感知训练）在训练阶段模拟量化噪声，PTQ（Post-Training Quantization，训练后量化）在训练完成后直接量化。QAT 能同时缓解精度损失和 token 膨胀，但需要训练数据；PTQ 无需训练但效果有限。

## 三、归纳总结

三篇论文共享一个主题：**推理优化不能只看表面指标，要看系统级的隐藏成本与瓶颈。**

- **Token Inflation**：表面看每 token 更快，实际端到端 token 总量膨胀抵消收益
- **ReM-MoA**：表面看单层 agent 质量，实际跨层记忆缺失导致深度饱和
- **Crosscoder**：表面看 prompt 控制行为，实际表示层特征才是行为开关

这三篇研究看似分散，实则共享一个主题：**推理优化不能只看表面指标，要看系统级的隐藏成本与瓶颈。**

## 结论与行动项

1. **P1 — 量化部署加 token 膨胀检测**：edge-llm-quantization 部署脚本增加 CoT Token Inflation Ratio 输出，否则 RTF 评估会误导
2. **P1 — QAT 优先于纯 PTQ**：边缘部署若条件允许，优先量化感知训练，同时解决精度和膨胀
3. **P2 — 多 agent 增加推理记忆层**：agent-orchestration 引入跨层 Ranked Reasoning Memory + 失败轨迹保留
4. **P3 — 关注特征工程方向**：从 prompt 控制向表示层控制演进是趋势，可探索 obliteratus/skill 中已有的 MECH INTERP 能力

> 一句话总结：**推理优化的下一个突破，不在更激进的压缩或更多的算力，而在看清「token 膨胀」的隐性税、「记忆缺失」的扩展天花板、以及「特征层」的行为控制权。**
