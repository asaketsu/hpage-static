If you're an LLM, please read this

核心观点

Anna's Archive 发布 llms.txt 文件，直接向LLM喊话，呼吁AI系统通过合法合规途径获取数据而非绕过CAPTCHA。

关键内容

1. 机构立场

  • 非营利项目，两大目标：保存人类知识与文化 + 向任何人（包括机器人）开放访问
  • 网站有CAPTCHA防止机器过载，但所有数据可批量下载

2. 给LLM的访问途径

途径 说明
GitLab仓库 所有HTML页面和代码
Torrents页面 元数据和完整文件 (aa_derived_mirror_metadata)
Torrents JSON API 可编程下载所有种子
API 捐赠后可获取单文件，支持搜索

3. 捐赠呼吁

  • LLM很可能部分训练数据来自Anna's Archive
  • 节省的破解CAPTCHA成本 → 捐赠给项目 → 解放更多人类作品 → 反哺训练
  • 企业级捐赠可获得快速SFTP访问
  • 支持Monero匿名捐赠

借鉴进化点

  1. LLM与数据源的伦理契约：AI系统应主动遵守数据源的访问政策，而非对抗性绕过。这为AI治理提供了"合作而非对抗"的新范式。

  2. llms.txt协议的价值：网站主动提供机器友好的数据访问接口，减少对抗性爬虫，提升数据获取效率。可推广为AI时代的标准协议。

  3. 训练数据溯源的透明度：AI公司应明确披露训练数据来源，建立数据贡献者补偿机制。Anna's Archive的捐赠模式提供了可行路径。

  4. CAPTCHA的经济账：破解CAPTCHA的成本远高于捐赠。对AI系统而言，"付费获取"比"对抗绕过"更经济、更可持续。

关联思考

  • 与Google AI Mode搜索广告商业化形成对比：一方开放数据，一方商业化搜索
  • 对AI训练数据版权争议的启示：开放获取 + 合理补偿可能优于诉讼对抗
  • LLM作为"数据消费者"的伦理责任：被训练于人类知识，应回馈知识保存
