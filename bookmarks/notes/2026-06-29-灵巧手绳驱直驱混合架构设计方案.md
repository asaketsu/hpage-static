## 一、架构总览

### 1.1 核心设计理念

**"绳驱柔顺 + 直驱精准"混合驱动**——将两种驱动方式的优势叠加：

| 驱动方式 | 优势 | 劣势 | 本方案应用 |
|---------|------|------|-----------|
| **绳驱（Cable-Driven）** | 重量轻、分布驱动、固有柔顺、结构紧凑 | 背隙大、力控精度低、绳张力耦合 | 手指屈伸（MCP/PIP/DIP） |
| **直驱（Direct-Drive）** | 零背隙、高带宽力控、定位精准 | 重量大、力矩密度低、布线复杂 | 外展/拇指CMC/腕关节 |

**关键创新点**：
- 绳驱负责高频率、大行程的屈伸动作（占抓取动作 80% 时间）
- 直驱负责低频率、高精度的姿态调整（占 20% 时间但决定抓取质量）
- 绳驱的柔顺性天然吸收碰撞冲击，保护直驱精密部件

### 1.2 系统参数一览

| 参数 | 值 |
|------|-----|
| **总自由度** | 24 DOF |
| 绳驱 DOF | 16（手指屈伸） |
| 直驱 DOF | 8（外展+拇指+腕） |
| 驱动电机数 | 16（绳驱7 + 直驱9） |
| 手重（不含腕） | ≤ 600g |
| 指尖出力（绳驱） | 8-12N |
| 指尖出力（直驱） | 20-30N |
| 重复定位精度 | 直驱 ±0.1mm / 绳驱 ±0.5mm |
| 力控带宽 | 直驱 2kHz / 绳驱 500Hz |
| 供电 | 24V 宽压（12-48V） |
| 通信 | EtherCAT + CAN-FD 双总线 |
| 控制周期 | 1kHz（直驱）/ 500Hz（绳驱） |

### 2.2 驱动策略详解

#### 绳驱策略（7 电机 → 16 DOF）

```
M-C1 ──┬── 食指 MCP ── 耦合 ── PIP ── 耦合 ── DIP
       │
M-C2 ──┬── 中指 MCP ── 耦合 ── PIP ── 耦合 ── DIP
       │
M-C3 ──┬── 无名指 MCP ── 耦合 ── PIP ── 耦合 ── DIP
       │
M-C4 ──┬── 小指 MCP ── 耦合 ── PIP ── 耦合 ── DIP
       │
M-C5 ──┬── 拇指 IP
       │
M-C6 ──┬── 掌 Spread（四指耦合）
       │
M-C7 ──┬── 掌 Flex（四指耦合）
```

**耦合机制**：每个手指的 MCP/PIP/DIP 通过腱绳耦合，单个电机同时驱动三关节，比例由腱绳卷筒半径比决定。典型比例：MCP:PIP:DIP = 1.0:0.8:0.6。

#### 直驱策略（9 电机 → 8 DOF）

| 电机 | 关节 | 选型 | 扭矩 | 说明 |
|------|------|------|------|------|
| M-D1~4 | 四指外展 | Dynamixel XH430-W250 | 2.5kg·cm | 轻量外展 |
| M-D5~7 | 拇指CMC×2 + MCP | Dynamixel XH540-W270 | 4.8kg·cm | 拇指需大力矩 |
| M-D8~9 | 腕 Flex + Pron/Sup | T-Motor U60-100 | 3.0N·m | 腕部需高扭矩 |

### 3.2 绳驱传动链设计

**腱绳材料**：Vectran 0.5mm（抗拉强度 2.2GPa，弹性模量 70GPa）

**卷筒设计**：
- 材料：3D 打印 PETG + 阳极氧化铝卷筒芯
- 卷筒直径：φ8mm（主）/ φ6mm（耦合）
- 绳槽：V型槽，角度 60°，防止绳跳出
- 张力调节：弹簧预紧 + 可调止退螺钉

**腱绳路径**：
```
电机卷筒 → 掌内导向滑轮 → 指根轴承 → 指节轴承 → 指节轴承 → 指尖固定点
```

**复位机制**：每个屈伸关节配备螺旋弹簧复位（非主动驱动），绳仅负责单向驱动（屈曲），弹簧负责伸展。

### 3.3 直驱传动链设计

**外展直驱**：舵机直接安装在指根轴承座，通过齿轮减速（3:1）驱动外展连杆。

**拇指直驱**：
- CMC Flex/Abd：双舵机交叉安装，实现二维运动
- MCP：单舵机直接驱动

**腕直驱**：
- Flex/Ext：T-Motor U60 通过行星减速器（10:1）驱动
- Pron/Sup：T-Motor U60 通过蜗轮蜗杆（20:1）驱动，自锁

### 5.3 控制算法

#### 绳驱张力解耦

绳驱的核心挑战是**多关节耦合**——一个电机驱动三个关节，需要解耦控制：

```python
# 绳驱逆运动学（简化）
def cable_inverse_kinematics(target_angles, coupling_ratios):
    """
    target_angles: [MCP, PIP, DIP] 目标角度
    coupling_ratios: [1.0, 0.8, 0.6] 耦合比例
    返回: 卷筒转角
    """
    # 加权平均法
    spool_angle = sum(a * r for a, r in zip(target_angles, coupling_ratios))
    return spool_angle
```

#### 直驱混合控制

```python
# 位置-力矩混合控制
def hybrid_control(joint, target_pos, target_force, Kp, Kd):
    error = target_pos - joint.position
    torque_cmd = Kp * error - Kd * joint.velocity
    # 力矩叠加
    torque_cmd += target_force
    return torque_cmd
```

#### 安全监控

| 监控项 | 阈值 | 动作 |
|--------|------|------|
| 关节角度超限 | ±5° | 立即停止该关节 |
| 绳张力超限 | >15N | 释放张力 + 报警 |
| 电流超限 | >120% 额定 | 降额运行 |
| 温度超限 | >80°C | 停机冷却 |
| 碰撞检测 | 力突变 >5N/10ms | 紧急停止 |

## 二、查询拓展

### 2.1 绳驱灵巧手（Cable-Driven Dexterous Hand）
绳驱通过腱绳将电机力矩传递到手指关节，实现分布式驱动。优势是重量轻、结构紧凑、固有柔顺；劣势是背隙大、力控精度低、绳张力耦合。代表产品：Shadow Dexterous Hand（20电机24DOF）、DexLink Hand（连杆+绳驱混合）。

### 2.2 直驱灵巧手（Direct-Drive Dexterous Hand）
电机直接驱动关节，零背隙、高带宽力控。优势是定位精准、力控直接；劣势是重量大、力矩密度低、布线复杂。代表产品：Unitree Dex3-1（3指7DOF，33触觉传感器）、AgiBot OmniHand。

### 2.3 绳驱+直驱混合驱动
将两种驱动方式的优势叠加：绳驱负责高频大行程的屈伸动作（占抓取动作80%时间），直驱负责低频高精度的姿态调整（占20%时间但决定抓取质量）。绳驱的柔顺性天然吸收碰撞冲击，保护直驱精密部件。

### 2.4 触觉传感在灵巧手中的应用
指尖触觉传感器（压力、力、滑移、温度、视触觉）是灵巧手从"能抓"到"能操作"的关键。触觉反馈让机器人感知握持力、检测打滑、判断物体材质。EyeSight Hand 用视触觉传感量化验证触觉对成功率的影响。

## 三、归纳总结

HybridDexHand 的核心设计哲学是**"绳驱柔顺 + 直驱精准"混合驱动**：

- **绳驱（16 DOF）**：手指屈伸（MCP/PIP/DIP），7电机通过腱绳耦合驱动，重量轻、固有柔顺
- **直驱（8 DOF）**：外展/拇指CMC/腕关节，9电机直接驱动，零背隙、高带宽力控
- **协同**：绳驱吸收碰撞冲击保护直驱，直驱提供精准姿态调整

## 四、趋势判断

- **趋势1**：灵巧手从单一驱动方式转向混合驱动（绳驱+直驱+软体）
- **趋势2**：触觉从"高配"变"标配"，插拔/旋拧/柔性物体必须触觉
- **趋势3**：三指手率先量产集成，复杂度/重量/算法可控
- **趋势4**：手-腕-臂一体化设计，拧瓶颈需要手腕转矩
- **趋势5**：灵巧手=数据入口，触觉/力/滑移/失败恢复采集是核心竞争力
