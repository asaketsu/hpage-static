## 一、核心问题与解法

**痛点**：固定网格拓扑优化中连续变量方便梯度求解，但留下难制造、难解释的灰度单元；传统 SIMP 把二值化与材料惩罚绑定（惩罚系数调"灰"是隐式技巧）。

**EBTO 核心变化**：把全局灰度写成优化问题中的**显式可微不等式约束**，与材料模型解耦——弹性模量直接用线性插值 E(x)=xE₁，设计变量保持清晰的体积分数含义。

灰度度量函数演进：
- 基础版：γ=4x(1−x)（x=0/1 时灰度为 0，x=0.5 最灰），但靠近 0/1 时推动力偏弱
- 可调版：**有理二次函数 γ_rq**，参数 κ 控制斜率——中间区域保留搜索自由，变量靠近边界时获得更强二值化推动
- 全局约束：所有单元灰度取平均得 Γ_rq ≤ 阈值（从宽松逐步收紧）

## 二、三场框架与"收敛≠可用"的关键设计

设计场—滤波场—物理场三场结构：MMA 更新设计变量，距离滤波控制网格依赖与最小尺度，Heaviside 投影消除滤波模糊，**真正压灰度的是显式约束**（投影与二值化约束承担两件不同的事）。

最有工程价值的一环——**"平滑—重离散—验证"循环**：
1. 收敛后从离散密度场提取平滑 0/1 边界
2. 投影回原有限元网格重新分析
3. 目标函数、约束值、设计差异三项都 <1% 容差才接受最终结构，否则继续收紧阈值

这一步把"数值收敛"与"最终几何性能"真正接了起来——数值收敛不等于可用结构。

## 三、跨目标验证结果（论文核心证据链）

| 算例 | 结果 |
|------|------|
| 2D half-MBB 梁 | 平滑结构柔度比同后处理 SIMP 低 **2.30%–4.52%**；比同线性材料的 FPTO 低 1.19%–3.51%（全测试半径） |
| 3D 悬臂 | 滤波半径增大，结构从薄壳/板状渐转桁架状——框架直接延伸三维 |
| 柔顺夹持器 | 水平输入转化为竖向夹持位移 |
| 牛腿应力优化 | p=28 时最大 von Mises 应力从柔度最优方案的 333.22 MPa 降至 **124.73 MPa（降幅 62.57%）**；L 形支架同趋势 |

论文真正要证明的不是单个算例"赢了"，而是**显式二值化约束能跨目标函数重复工作**。

## 四、约束函数设计五原则（可复用的方法论）

1. 0/1 端点必须为零、中间状态为正
2. 最好归一化，使阈值有直观尺度
3. 连续可微且边界梯度有限
4. 整体保持凹性——帮助 MMA 构造保守近似
5. 有参数控制二值化推动强度

论文定位转变：**二值化从"技巧"变成"原则"**——从藏在惩罚/投影/参数经验里，变成可测量、可求导、可调节的数学约束。下一步方向：多材料、壳—填充、屈曲约束、微结构、多物理场。

## 六、内容整理（归纳总结与关联分析）

**归纳总结**：EBTO = 灰度度量 γ_rq（κ 可调，近边界推动强）+ 全局灰度约束 Γ_rq ≤ 阈值（渐进收紧）+ 线性材料 E=xE₁ + 收敛后"平滑-重离散-验证"循环（<1% 三项容差）。一句话：把拓扑优化的黑白化从惩罚技巧升格为显式数学约束，换来清晰物理意义+跨目标复用+可制造 0/1 结构。关键数字：SIMP 对比降柔度 2.3-4.5%、应力降 62.57%、容差 1%。

**关联分析**：本周三篇笔记（达索/ROSClaw/EBTO）呈现同一元趋势——**把工程实践中依赖经验和隐性知识的环节（AI 黑盒/物理参数/二值化技巧）显式化为可验证的数学契约**。达索用"物理世界模型"约束 AI，ROSClaw 用 digest/Verifier 约束 Agent，EBTO 用不等式约束灰度——三个领域独立收敛到同一范式，这本身是比单篇论文更强的信号，值得作为周综合的归纳命题。
