## 二、AFTER：过程记忆（Skill）的可迁移性基准

**论文**：arXiv 2606.23127 — Managing Procedural Memory in LLM Agents

### 基准设计

382个真实企业任务，6个职业角色，22种过程技能：
- 本地改进测试
- 跨任务迁移测试
- 跨角色迁移测试
- 跨模型泛化测试

### 关键发现

1. **一轮精炼提升 3.7-6.7 分**：过程记忆（Skill）对企业工作流有持续增益
2. **多模型轨迹训练的效果最佳**：从多样化多模型执行轨迹演化的技能达到 **73.1% 跨模型测试准确率**，超过所有单模型轨迹来源
3. **技能分两类**：
   - 通用技能：跨任务、跨模型广泛泛化
   - 专用技能：与特定角色工作流绑定，迁移时失效

### 对 Hermes Skills 系统的启示

| 发现 | Hermes 应用 |
|------|-------------|
| 多模型轨迹更优 | 同一 Skill 应在多模型上验证后固化 |
| 技能需要分类 | 引入「通用技能」和「角色专用技能」标签 |
| 一轮精炼有效 | Skill 创建后应有一个自动精炼循环 |
| 跨模型泛化≠跨角色泛化 | 测试 Skill 时应同时评估两种迁移性 |

## 三、RaMem：上下文重建解决「上下文坍塌」

**论文**：arXiv 2606.22844 — Contextual Reinstatement for Long-term Agentic Memory

### 问题：上下文坍塌

当记忆被压缩为可复用片段时，来自不同情境的记忆可能看起来同样相关（如果涉及相同实体或用户状态）。结果：Agent 基于看似相关但实际不适用于当前查询的记忆做出错误决策。

### RaMem 四阶段方案

```
(i) 证据锚定 → 将每条记忆锚定到原始情境条件
    事件时间、提及时间、会话跨度、参与者
(ii) 召回条件推导 → 从查询中推导出证据条件
(iii) 有效性感知检索 → 优先选择上下文兼容的记忆
    同时保留内容相关的候选作为后备证据
(iv) 上下文保留合成 → 保持选中记忆的结构化上下文
```

**性能**：F1 平均提升 10%+

### 与 Hermes 记忆系统的关联

Hermes 当前的记忆检索主要基于关键词匹配和 session_search 全文检索。RaMem 的「有效性感知检索」概念可以改进：
- 当前：搜索到的记忆直接使用
- 改进：增加一层「上下文有效性验证」——这条记忆在当前情境下是否仍然有效？

## 四、AtomMem：简单有效的原子事实记忆

**论文**：arXiv 2606.19847

### 设计理念

将记忆拆分为**原子事实**（Atomic Facts），实现：
- 价值密集存储（不存冗余信息）
- 稳定更新（约束式写入，不是无约束追加）

### 与 Hermes memory-write Skill 的对比

Hermes 已有 `memory-write` Skill 实现原子记忆写入和实体链接。AtomMem 论文验证了这个方向的正确性：
- 原子事实 > 粗粒度段落
- 约束更新 > 无约束追加
- 实体链接提升检索精度

## 五、EvoEmbedding：可进化嵌入表示

**论文**：arXiv 2606.21649 | 项目页：https://clare-nie.github.io/EvoEmbedding

### 核心创新

传统嵌入模型是**静态的**：孤立编码文本段，忽略上下文和时间顺序。

EvoEmbedding：
- 维护**持续更新的隐式记忆**
- 用隐式记忆 + 原始内容**联合生成可进化嵌入**
- 对于同一个查询，根据不同进化上下文检索不同目标

**惊人发现**：
- 朴素 RAG + EvoEmbedding **超越专用 Agent 记忆系统**
- 性能超过更大规模专家模型（Qwen3-Embedding-8B、KaLM-Embedding-Gemma3-12B）
- 训练加速 3.8×
- 泛化到训练窗口 10× 长的上下文

### 技术细节

- **EvoTrain-180K** 数据集：联合优化隐式记忆和检索
- **记忆队列**：防止循环编码中的表示坍塌
- **分段批处理**：解决长度差异，加速训练

## 六、技术趋势与改进建议

### 趋势总结

1. **记忆验证 > 记忆检索**：RaMem 证明「检索到」不等于「有效」，需要上下文验证层
2. **原子化 > 聚合化**：AtomMem 和 EvoEmbedding 都在向更细粒度的记忆表示发展
3. **进化嵌入是范式转移**：EvoEmbedding 的「同一个查询在不同上下文中检索不同结果」可能改变 Agent 记忆的构建方式
4. **自进化安全是新领域**：传统安全措施对自进化系统几乎无效，需要全新的安全框架
5. **过程记忆需要分类管理**：AFTER 证明通用技能和专用技能的迁移性截然不同

### 对 Hermes 的改进建议（P0/P1/P2）

| 优先级 | 改进项 | 关联论文 | 实施方式 |
|--------|--------|----------|----------|
| **P0** | 自进化安全审计 | Safety in Self-Evolving | 在 evolver 中加入血统追踪和变更审计 |
| **P1** | 记忆有效性验证 | RaMem | 在 memory-write 中增加上下文锚定字段 |
