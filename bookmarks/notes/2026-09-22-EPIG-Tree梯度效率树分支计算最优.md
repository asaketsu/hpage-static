## 查询拓展

DUCK TRANS4 死于"熵先坍缩→value 后爆→reward 断崖"级联，本质是 PPO 单标量优势估计在随机环境中的信用分配失真。本文给出这个问题最干净的理论框架：**树 rollout 是估计策略梯度的实验装置，分支应该加在"每单位成本最大降低梯度估计误差"的地方——不是策略不确定的地方**。这直接回答 DUCK 训练体系的一个悬而未决的问题：如果未来用树采样/多分支 rollout 加速 TRANS 训练（当前平坦 rollout），分支点怎么选？熵是不是好指标？本文结论：熵只是提案机制，不是分配目标。

## 内容整理

### GRPO/PPO 单标量优势的三个结构性失败模式（S1）

1. **恢复行为信用错配**：轨迹中途犯错但后续动作正确而失败 → 整条轨迹组相对奖励为负 → 正确的恢复动作也被惩罚。反之侥幸成功的轨迹里坏动作被强化。恢复行为不是长视野信用分配的特例，而是"一条路径一个标量"的直接后果。
2. **非确定性处理低效**：随机环境中终端奖励是 Q(h,a)=E[Y|h,a] 的噪声观测。单轨迹把策略选择与环境随机性混在一起——环境随机毁掉好动作会被惩罚，随机救了坏动作会被强化。估计条件后继价值需要从同一状态重复采样反事实后缀。
3. **rollout 数扩展性差**：增加独立全轨迹只增加低重要性差异（格式/噪声），不提供学习信号。

### 核心理论：方差分解定理（S4，Proposition 1）

单样本局部梯度贡献 Z_h = μ_h·ψ_h(A)·Y 的方差按全方差律分解为两项：

- **决策不确定性**（decision uncertainty）：μ²·Var_A[ψ_h(A)·Q_h(A)] —— 该在哪个动作上分支
- **后继不确定性**（continuation uncertainty）：μ²·E_A[ψψᵀ·σ²_h(A)] —— 该在已有分支下加多少后缀样本

对应两个计算动作：**加新分支降前者；加后缀样本降后者**。由此导出计算最优后缀分配律 n_e* ∝ w_e·‖∇log π(a_e|h_e)‖·σ_e/√c_e（占用权重×score 范数×价值标准差/成本平方根）。

### EPIG 算法骨架（S6）

熵提案候选分支点（推理步边界/高熵 token 段）→ EPIG 分数分配分支预算（只加有正边际增益的分支）→ 按分配律配置后缀 rollout → 树内局部优势 Â(h,a)=V̂(child)−V̂(h) → PPO/GRPO 式裁剪更新（带动作 token/分支段掩码，优势只训练引发分支的 token）。

### 关键实验结果（S7-S8 实测）

- **克隆态连续控制**（Gym/MuJoCo 13 环境，分支预算 8，参考梯度 32 后缀/动作）：EPIG/价值信息法在 **9/13 环境梯度 MSE 获胜**（全部为稠密连续控制），恢复参考梯度方向余弦 0.998-1.000。熵指引分支在控制任务上系统性指错方向。
- **冻结 LLM 梯度校准**（Qwen3-8B，64 prompt×3 seed，64 叶参考）：树梯度对齐提升、Wordle 价值 MSE 下降。
- **在线单轮数学**（GSM8K-hard/MATH-small，Qwen 级模型）：树局部信用有帮助但**分支放置不是瓶颈**——token loss 掩码和优势构造主导。近饱和任务上 EPIG 与便宜基线打平。
- **在线多轮 Wordle**：EPIG 分配优势重现——最终平台期更高，超过快饱和的平坦 GRPO 和所有基线。
- 边界条件诚实标注：动作空间极小时均匀覆盖已近最优；稀疏奖励下纯价值信息分配过于剥削性；分支优势若作用到无关 token 拓扑无效。

## 归纳总结

1. **熵≠分支目标**：高熵但在奖励等价的措辞间选择，不值得分支；中熵但在高低价值动作间选择，可能是关键分叉点。熵只回答"分支能不能不同"，EPIG 回答"分支重不重要"。
2. **树 rollout 的本质是梯度估计的实验设计**——不是搜索更优动作，而是把算力花在梯度最难估计的地方。这是对"树=探索"直觉的修正。
3. **平坦 GRPO 的信用分配噪声是结构性的**——恢复动作继承无关终端事件的符号。DUCK TRANS4 "value 爆炸前先熵坍缩"的级联与此框架自洽：尖锐化策略 → 优势估计失真 → 价值函数追不上 → 更新方向错。
4. **稠密奖励连续控制是树方法最受益的场景**——恰好是 locomotion 的属性（稠密 shaping）。DUCK 若引入树采样，理论收益上限高于 LLM 数学场景。
5. **边界条件意识**：稀疏奖励+小动作空间+优势掩码错位三个条件下树方法退化为平基线——引入前先对照自查。

## 趋势判断

- **短期**：DUCK 训练栈（rsl_rl PPO）不直接受益——树 rollout 需要框架级改造，当前 W5/h1xr 平坦 rollout 继续跑。但"分支点选择用价值信息不用熵"的原则可用于**评估侧**：变异策略评估时在价值分歧大的状态克隆重采样，比随机重采样检测力更强。
- **中期**：RL 训练算力分配从"均匀撒 rollout"走向"按梯度估计难度分配"是清晰方向。机器人 RL 社区当前主流仍是平坦 rollout，树采样在 locomotion 的系统研究是空位。
- **长期**：EPIG 的"熵提案+价值分配"两层结构可能成为树 RL 标准配置，类似 PPO clip 从 trick 变标配。

## 拓展应用推荐

1. **P0·克隆态评估法引入 DUCK 评估脚本**：当前策略评估是"整条轨迹从头跑"，可改为"在 FELL 前的关键状态（价值分歧大/姿态分歧大）克隆状态+多后缀重采样"，直接测策略的条件稳定性。工作量：评估脚本 +mjlab clone state API 查证（mjlab 支持以 state 为根重置）。收益：比轨迹级验收（倒/不倒）细一档，能定位"哪个状态是真正的分叉点"。
2. **P1·TRANS 复活下下代选项**：若 W2 TRANS 仍不稳，树采样+局部优势是文献依据的下一代选项——但需换训练框架（rsl_rl 不支持），成本高，排 MLP 蒸馏之后。
3. **P2·熵监控语义修正**：把守护脚本里"熵坍缩=坏事"的单义解读升级为"熵坍缩+价值分歧扩大=真坏事"双指标——熵低但价值分歧也小=收敛（好事），熵低但价值分歧大=坍缩（坏事）。工作量：守护脚本加 value divergence 指标（组内 value std）。
4. **P3·论文转化候选**：本文核心命题"树是梯度估计的实验装置"+ DUCK 实测"TRANS 熵坍缩级联"可合成周论文选题——「策略训练稳定性的信息论判据：从熵单指标到梯度不确定性分解」，新颖性足够（机器人侧无此框架）。

## 指南分析

对 DUCK 训练体系的落地指南：
- **可立即抄**：占用加权（occupancy weighting）概念——评估变体时按状态占用频率加权指标，避免稀有前缀（如特定扰动后状态）主导评价。
- **可立即抄**：优势掩码思想——DUCK 若做蒸馏，只让"引发分叉的观测-动作对"承载蒸馏损失，不是全序列均匀蒸馏。
- **需工程改造**：树 rollout 需要框架支持（rsl_rl 无树采样），mjlab 的 state clone 能力需查证后才可实施 P0。
- **不适用**：EPIG 完整算法（含 Goodhart 修正项）对 DUCK 过重，平坦 PPO + 好的 DR 仍是当前最优性价比。
