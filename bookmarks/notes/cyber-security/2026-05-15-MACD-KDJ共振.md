# MACD+KDJ 共振策略：技术指标组合实战

> 关键词：MACD, KDJ, 指标共振, 技术分析
> 来源：知乎 / 新浪财经 / 什么值得买 / PressPlay
> 日期：2026-05-15

## 摘要

MACD 与 KDJ 组合的"指标共振"是技术分析中经典的趋势+波动率组合策略。核心逻辑是通过双重确认提高信号可靠性，过滤假突破。MACD 作为趋势指标提供方向判断，KDJ 作为摆动指标提供精确入场点。

## 关键发现

### 1. 核心逻辑
- **MACD**：趋势指标，判断大方向（零轴上方看多，下方看空）
- **KDJ**：摆动指标，寻找超买超卖和精确入场点
- **共振**：当 MACD 金叉与 KDJ 金叉同时出现时，形成双重确认

### 2. 四种行情下的操作策略

| 行情类型 | MACD 状态 | KDJ 操作 |
|----------|-----------|----------|
| 上升趋势 | 均线在零轴上方 | KDJ 低位超跌时做多 |
| 下降趋势 | 均线在零轴下方 | KDJ 高位超买时做空 |
| 横盘震荡 | 均线贴近零轴 | KDJ 高位超买做空，低位超卖做多 |
| 背离信号 | MACD 顶/底背离 | 等待 KDJ 确认后进场 |

### 3. 背离共振（最强信号）
- MACD 顶背离 + KDJ 高位超买 → **做空信号**
- MACD 底背离 + KDJ 低位超跌 → **做多信号**
- 两者同时背离时，信号可靠性更强

### 4. 实战注意事项
- **主次之分**：以 MACD 方向为主，KDJ 为辅助寻找入场点
- **周期限制**：不适合过小（1 分钟）或过大的周期
- **获利空间**：指标共振可以把握进场点，但**不能预测获利空间**
- **强势单边行情**：KDJ 很难打到超买/超卖区域，关注 KDJ 三线的发散程度（快线大幅偏离慢线时可进场）

## 个人分析

MACD+KDJ 组合的本质是**趋势跟踪 + 择时入场**：

1. **MACD 负责"看大势"**——确定当前是多头还是空头市场
2. **KDJ 负责"找时机"**——在趋势方向上寻找最佳入场点
3. **共振是过滤器**——减少假信号，提高胜率

**局限性**：
- 震荡行情中 MACD 会频繁交叉，产生噪音
- 无法预测获利空间，需要配合其他工具（如支撑阻力位、成交量）
- 不适合高频交易（小周期噪音太大）

**进阶思路**：
- 结合成交量确认（量价配合）
- 结合支撑阻力位判断目标位
- 结合基本面筛选标的

## 行动建议

- **短期**：在模拟盘中验证 MACD+KDJ 共振策略在不同周期（15min/1h/4h）的表现
- **中期**：加入成交量因子，构建"量价指标共振"增强版
- **长期**：结合机器学习，自动识别共振信号并回测历史表现
