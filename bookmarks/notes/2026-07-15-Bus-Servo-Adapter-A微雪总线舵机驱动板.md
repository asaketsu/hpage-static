## 一、内容详细整理

### 1.1 产品概述

Bus Servo Adapter (A) 是微雪（Waveshare）推出的一款**总线舵机驱动板**，集成舵机供电功能和舵机控制电路，用于统一管理总线舵机（Bus Servo / Serial Servo）。

> 理论上可控制 **253 个总线舵机**，并读取每个舵机的当前角度、负载、电压、模式等信息。

适用场景：机械手臂、六足机器人、人形机器人、轮式机器人等需要反馈舵机角度和负载的机器人项目。

### 1.2 核心功能

- **舵机供电**：集成电源管理，为总线舵机提供稳定供电
- **舵机控制**：通过串口连接上位机，控制总线舵机转动
- **信息读取**：实时读取舵机角度、负载、电压、工作模式
- **ID 编程**：可修改舵机 ID（地址），实现多舵机总线寻址
- **模式切换**：支持舵机模式（位置控制）和电机模式（连续旋转）
- **多语言例程**：提供不同编程语言的舵机控制例程

### 1.3 总线舵机通信原理

总线舵机（Bus Servo）与传统 PWM 舵机的本质区别：

- **传统 PWM 舵机**：每个舵机需要一根独立信号线，N 个舵机 = N 根线，无法读取反馈
- **总线舵机**：所有舵机共享一根半双工串口线（TTL），通过 ID 寻址，可串联 253 个

通信协议为半双工 TTL 串口（通常 115200bps 或 1000000bps），单总线完成双向通信。

### 1.4 与本机机器人项目的关联

本机双轮腿机器人项目（`two-wheel-legged-robot`）使用 **STS3025BL 总线舵机 + ODrive 3.6**。Bus Servo Adapter (A) 可作为 STS3025BL 的上位机调试工具：
- 批量设置舵机 ID
- 校准舵机零位和中位
- 实时监控舵机负载（用于平衡控制反馈）
- 测试舵机响应曲线

## 二、查询拓展

### 2.1 总线舵机协议（以 Feetech STS3025 为例）

STS3025 系列使用 Feetech（飞特）SCS/STS 协议簇：
- 帧格式：`[0x55][0x55][ID][Length][Instruction][Params...][Checksum]`
- 帧头 `0x55 0x55` 用于帧同步
- Instruction 字段定义操作类型（读/写/同步写/广播）
- 每个 ID 可独立寻址（1-253），ID=254 为广播地址
- 寄存器映射：角度、速度、扭矩、电压、温度、位置环 PID 等

### 2.2 舵机模式 vs 电机模式

- **舵机模式（位置控制）**：发送目标角度，舵机内部 PID 闭环到指定位置。适合关节定位。
- **电机模式（连续旋转）**：发送目标转速/方向，舵机持续旋转。适合轮式驱动。

切换通过写入控制寄存器（Mode bit）实现。双轮腿机器人中，髋关节用舵机模式，踝关节可能需力矩控制（介于两者之间）。

### 2.3 半双工单线通信的硬件实现

总线舵机的 TX/RX 共用一根信号线，需要硬件方向切换电路。Bus Servo Adapter 内部集成了方向控制逻辑（通常用 74HC126 三态缓冲器 + 自动方向检测电路）。自制驱动板需注意：TX 发送时使能 TX 方向，发送完后立即切换到 RX 方向接收舵机回复。

## 三、归纳总结

### 3.1 总线舵机 vs PWM 舵机对比

- **布线**：总线（1 线串联 N 舵机）vs PWM（N 线一对一）
- **反馈**：总线（角度/负载/电压/温度全可读）vs PWM（无反馈）
- **寻址**：总线（ID 寻址）vs PWM（无寻址，靠物理接线区分）
- **成本**：总线舵机单价略高，但省去大量线束和驱动板
- **生态**：Feetech STS/SCS、Lewansoul LX、Waveshare ST 系列总线舵机广泛兼容

### 3.2 选型定位

Bus Servo Adapter (A) 定位为**开发调试工具**而非量产控制器。量产机器人通常直接用主控 MCU（STM32/ESP32）的 UART 接口 + 方向控制电路驱动总线舵机，无需 Adapter 板。
