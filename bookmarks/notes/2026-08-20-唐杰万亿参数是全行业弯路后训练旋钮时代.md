## 一、核心概念（内容整理）

**唐杰的行业大实话**：万亿参数那一轮，是整个领域一起走的弯路。

**GLM-5.3 控制变量实验**（正面回应"智谱为什么不训新基座"）：

| 控制项 | 数值 |
|--------|------|
| 基座 | 与 5.2 完全相同 |
| 架构 | 完全相同 |
| 总参数 | 753B |
| 激活参数 | 40B |
| **唯一变量** | **一个月长时域环境训练 + 强化学习（后训练）** |
| 结果 | Coding 被开发者评为国产当前最优 |

结论：参数旋钮已转到收益递减，下一个最值得拨的是**后训练**。

**推导链（Scaling Law 三部曲）**：
- 2020 Kaplan：参数增长要快于数据（2.7:1）→ 催生 GPT-3、Gopher 万亿参数潮
- 2022 Chinchilla：用 400+ 模型推翻，参数与数据应同速增长 → 行业跟着 2.7:1 冲了两年然后集体折返
- 关键新变量 = **推理成本**：Chinchilla 优化的是"训练一次评测一次"的模型；今天主流模型每天被调数十亿次，推理成本远超训练成本 → 最优解变成**「更小模型、训练更久」**（Llama-2-7B、Gemma-2-9B 都是刻意过训练的例子）

**MoE 二象性**：总参数决定能装多少知识，激活参数决定长程推理。

**Roberts 2025 反直觉发现**：固定每参数 Token 数时，加总参数会**降**推理能力，激活更多专家才稳定提升。

**行业格局**：DeepSeek 拼算力效率，智谱拨后训练旋钮——Scaling Law 从「堆规模」变成「拨旋钮」，后训练和数据质量成为新战场。

## 二、技术要点（指南分析）

### 2.1 三种 Scaling 路线的收益转移

| 时代 | 优化目标 | 代表 | 现状 |
|------|---------|------|------|
| Kaplan 时代 | 参数规模最大化 | GPT-3 (175B) | 弯路，已证伪 |
| Chinchilla 时代 | 训练一次的算效最优 | Llama-2-7B 290TP / Gemma-2-9B 889TP 过训练 | 仍是基线共识 |
| 推理时代 | 全生命周期成本（训练+部署推理） | GLM-5.3 同基座后训练 | **当前主战场** |

### 2.2 MoE 参数二象性的操作含义

- 总参数 = 知识容量（记忆/事实）——"装"
- 激活参数 = 推理链深度（长程推理）——"想"
- 加大总参不提升推理（Roberts 2025），提升推理要激活更多专家——**给 MoE 扩容指了方向：扩专家数，不扩单专家容量**

### 2.3 与 GLM-5.3 对照实验的互证

本推与 jietang 原帖（8-19《Thoughts About Scaling Law》）是同一实验的两次传播：jietang 是第一手（含"旋钮不必一起拧"原话），本推是第三方解读（码良补充了 Roberts 2025 引用与 DeepSeek 对照）。两者互证：**753B/40B 冻结 + 一个月后训练 = Coding 国产最优**。

## 三、复现验证（归纳总结）

- 实验数据源自唐杰公开表述，非独立可复现（753B/40B 冻结条件下的消融只有智谱自己能做）
- Roberts 2025 结论在推文中为转述，未附论文链接——按"固定 TPP 时加总参降推理"理解，与 MoE 稀疏激活文献方向一致
- 热评第一（119 赞）："后训练才是 alpha，参数卷不动了"——与用户在飞机设计知识库白皮书中"检索策略才是 alpha"形成同构句式：**alpha 永远在别人还没系统性投入的环节**

## 四、可学到的点（Hermes 借鉴）

1. **控制变量是说服力的黄金标准**：同基座同参数只动后训练——实验设计本身比结论更有传播力。写分析报告时"冻结一切只动一个变量"的对照结构值得复用
2. **推理成本改变了最优解形状**：任何"训练一次"视角的优化在"日均数十亿次调用"下都会变形——自己做模型选型时按"部署全周期成本"算账，不按榜单算
3. **alpha 转移律**：参数（2020）→ 数据配比（2022）→ 推理成本（2024）→ 后训练（2026），每一轮 alpha 都在"上一轮共识固化后大家不再投入"的地方出现——个人的 skill/记忆体系同理：别人不维护的环节就是你可以复利的环节
4. **MoE 扩容方向**：扩专家数不扩单专家容量——对应 Agent 技能体系：加新 skill（专家数）比加深单个 skill（单专家容量）对长任务推理更有效

## 五、趋势判断（拓展应用）

1. **基座换代周期拉长**：5.2→5.3 同基座说明头部厂商开始"一鱼多吃"，基座投资摊薄到多个后训练版本——中小厂商跟随策略应是"锁死一个好基座+自建后训练能力"
2. **后训练军备竞赛显性化**：环境训练（长时域）+ RL 是 GLM-5.3 的配方，Alloomi 的"经验焊权重"（见关联笔记）是同一方向的应用侧版本——两条线会在"机构级 post-training 服务"汇合
3. **评测口径跟不上旋钮时代**：榜单测的是"能力快照"，测不出"后训练迭代速度"——下一代评测会引入时间维度（同基座 N 个月后的能力增益曲线）
4. **数据质量 > 数据数量的定价权**：后训练战场的数据是专家演示/环境交互/偏好对，公开语料价值进一步稀释——与"会话即数据资产"判断互相印证

## 六、Yanhua 批判性补全：三认同 + 三质疑与解答（2026-08-20 增补）

> 来源: [@Yanhua](https://x.com/yanhua1010/status/2089984341061599594)（8-19，8.3K 浏览）对唐杰说明的逐条审视。这是对本笔记核心论断最重要的第三方校准——前文"拨旋钮"叙事需要按此降调。

### 6.1 Yanhua 认同的三点

1. 单独比较参数量已无意义——训练 Token、数据质量、总参数、激活参数、后训练、推理时计算共同决定最终能力
2. Chinchilla 的 ~20 Token/参数只是特定训练目标下的经验最优点；计入生命周期推理成本后"更小、训练更久"可能更合理
3. MoE 已把"模型容量"与"每次实际计算量"分开，稠密模型的 Scaling 配方不能直接套用

且 Yanhua 确认对照实验的真正含义：**既有基座的能力上限，可能远未被后训练充分开发**（5.3 证明了余量存在）。

### 6.2 三点质疑与解答（逐条回应）

**质疑①：总参数是否存在"足以容纳世界"的通用阈值——目前没有可测量的定义**

解答：承认无解，且理论上可能不可判定。热评 @Maxwell_SCU（218 赞）给出了精确表述：问题的本质是**真实世界生成系统边界的不可知性**——开放世界通用任务所需的"极小本征信息下界 (T, δ)"是否作为有限且收敛的数学客体存在，目前**既不能证实存在，也不能证实不存在**。可操作的替代方案：放弃寻找通用阈值，改为**分领域容量探针**（按知识域做 bits/param 实测定标——Allen-Zhu《Physics of Language Models》系的 2-3 bit/参数估计是封闭分布下的可测版本），"容纳世界"降级为"容纳本领域任务集"即可工程化。

**质疑②："总参数管知识、激活管推理"更像工程近似，而非严格机制**

解答：判定为正确的批评，但近似仍有价值。机制上存在交叉：专家既存事实也能存推理程序；Roberts 2025"激活更多专家提升推理"本身就说明**专家多样性（总参的函数）也影响推理**，二分法被自己的证据模糊了边界。正确的重构：这不是**机制分解**（mechanism），而是**成本核算分解**（cost accounting）——总参数映射到显存/部署成本线，激活参数映射到每 token FLOPs/延迟成本线。按成本线做预算分配时二分法依然是最优工程工具，但不应再当作大脑机制来陈述（本笔记 2.2 节"装/想"表述据此降级为记账比喻）。

**质疑③：两个模型版本只能证明后训练有余量，不足以拟合一条可外推的新 Scaling Law**

解答：完全成立。n=1 的受控实验是**存在性证明**（headroom exists），不是**函数形式**（scaling curve）。类比史实：Kaplan(2020)→Chinchilla(2022) 用了 400+ 模型才完成一次修正；后训练目前处于"有方向、无曲线"的 Kaplan 早期阶段——没有"后训练 Chinchilla"（SFT/RL/环境构建三类算力的最优配比），就没有可外推的定律。在此之前，"更小模型+更久训练+更重后训练"只是与 Llama-2-7B/Gemma-2-9B 过训练、DeepSeek 算力效率路线**方向一致的行业共识**，不是定律。

### 6.3 Yanhua 的重构（本话题目前最精确的一句话）

> 预训练 Scaling 没有结束，模型训练正在从"扩大参数"升级为一门更完整的**计算资源配置科学**。

对照本笔记原表述"从堆规模变成拨旋钮"：Yanhua 版本更准确——旋钮不是替换规模，而是**把规模泛化为联合优化问题**（数据 Token/质量 × 总参 × 激活 × 后训练算力 × 推理算力，每轴各有边际收益曲线，最优解是联合解）。
