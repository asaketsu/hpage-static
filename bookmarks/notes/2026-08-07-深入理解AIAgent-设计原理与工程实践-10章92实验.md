### 第 1 章：Agent 基础知识

核心公式：**Agent = LLM + 上下文 + 工具**

> **Harness 工程才是竞争力**——不是模型本身，而是围绕模型构建的上下文管理、工具编排、评估闭环。

### 第 2 章：上下文工程

上下文决定 Agent 的能力上限。涵盖：
- **KV Cache** 机制与 Prompt Caching
- **提示工程**（结构化提示词）
- **Agent Skills**（把可复用知识固化）
- **上下文压缩**（解决 Context Rot）

### 第 3 章：用户记忆和知识库

- **用户记忆**：跨会话记住用户偏好
- **RAG**：检索增强生成
- **结构化索引**
- **知识图谱**

### 第 4 章：工具

- **MCP 协议**（Model Context Protocol）
- 三类工具：**感知（读取）/ 执行（写入）/ 协作（通信）**
- **事件驱动异步 Agent**
- **主动工具发现**（Agent 自主发现可用工具）

### 第 5 章：Coding Agent 与代码生成

> 代码是「能创造新工具的工具」

生产级 Coding Agent 全景——从代码补全到自主开发。

### 第 6 章：Agent 的评估

> 把表现变成可比较信号

- 评估环境（SWE-bench、OSWorld、Android World、GAIA、tau2-bench、terminal-bench）
- 评估指标
- 统计显著性
- **评估驱动选型**

### 第 7 章：模型后训练

- **预训练 → SFT → RL** 三阶段
- 何时选 SFT、何时选 RL
- **工具调用内化**（通过训练让模型自动使用工具）
- 样本效率

包含从零训 LLM（MiniMind）、从零训 VLM（MiniMind-V）、SFT vs RL 对比、RLVP（视觉-语言-动作 RL）、SimpleVLA-RL 等 16 个实验。

### 第 8 章：Agent 的自我进化

> **不改权重也能成长**

- **经验学习**：从交互中提取可复用经验
- **从工具使用者到创造者**：Agent 学会自己编写工具
- Prompt 蒸馏 / CoT 蒸馏

### 第 9 章：多模态与实时交互

## 结合最新研究与技术变化

### 1. 与 Coding Agent Harness 解剖学（Mastra）笔记的直接关联

Ch 1 的"Harness 工程才是竞争力"与 Mastra 文章的核心论点完全一致——Agent 的竞争力不在 LLM 本身，而在上下文管理、工具编排、会话持久化、审批链等 Harness 层。Ch 2 的上下文工程直接对应 Mastra 的 Observational Memory。

### 2. 与自进化四波浪潮 + Prime Agent 笔记的关联

Ch 8（Agent 的自我进化）的"不改权重也能成长"正是 Prime Agent Continual Harness 和 SkillOpt 的理念——通过外部经验积累（Skill/Prompt 蒸馏）实现进化，而非修改模型权重。

### 3. 与 LLM 微调成本工程笔记的关联

Ch 7（模型后训练）的"何时选 SFT、何时选 RL"决策框架与微调笔记的 2×2 矩阵互补——前者从训练方法角度，后者从成本/频率角度。

### 4. 与 Hands-On Modern RL 笔记的互补

两本书形成完美互补：
- **本书（AI Agent Book）**：Agent 的工程实践（上下文/工具/记忆/评估/协作）
- **Hands-On Modern RL**：Agent 的训练理论（RLHF/DPO/GRPO/Agentic RL）
- 交叉点：Ch 7（后训练）↔ Modern RL Part IV（LLM 对齐）

### 5. 与具身智能方向的关联

Ch 9 的 SimpleVLA-RL + XLeRobot + Sim2Real 抓取实验直接对应用户的 VLA/具身智能研究方向。Ch 7 的 RLVP（视觉-语言-动作 RL）是 VLA 模型的训练方法。

## 趋势判断

- **Agent 教材正在系统化**——从零散博客到 10 章 92 实验的系统教材，说明 Agent 工程正在成熟为独立学科
- **"Harness 工程才是竞争力"成为共识**——不再是"哪个模型更强"，而是"围绕模型的工程体系更完善"

- **VLA + Sim2Real（Ch 9）是具身智能的工程入口**——从仿真训练到真实部署的完整链路已有开源实验
