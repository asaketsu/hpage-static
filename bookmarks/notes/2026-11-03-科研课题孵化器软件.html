科研课题孵化器：从"平时积累"到"申报窗口一键成稿"的软件化实践

需求：课题按短/中/长期管理，平时积累打磨，按需提取，报项目时快速形成方向与建议书；AI 输出要"去 AI 味"；支持局域网 deepseek；HTML 页面 + 独立 App 双形态；Win7 可运行可编译。

生成日期 2026-11-03

为什么造：科研申报的真正瓶颈是"课题资产的平时密度"

申报窗口打开时才发现：素材散落在聊天记录里、构想停在半年前的脑暴、指标口径从来没对齐过——这是工程科研团队的最常见失败模式。窗口期通常只有 2-4 周，而从零拼一份建议书至少需要：方向决策（选哪个课题报）+ 素材聚合 + 七章成稿 + 文风打磨，四个串行环节。

本项目的核心判断：申报速度不是窗口期问题，是平时积累的结构化程度问题。因此软件的第一公民不是"文档编辑器"，而是"课题资产池"——三期（短/中/长期）泳道 × 四阶段（灵感→调研→成型→可申报）成熟度模型，让每个课题的"申报就绪度"随时可见。

与既有项目的关系：au（航空结构设计智能体申报书工程）是本工具的典型内容客户——au 类课题在孵化器里积累素材，窗口期由孵化器产出建议书初稿。

怎么造：五个关键设计决策

1. 成熟度评分驱动行为，而非摆设

评分公式：素材 40 分（六类覆盖 30 + 数量 10）+ 打磨 20 + 构想 20 + 建议书 20。六类素材（构想/文献/方法/数据/指标/成果）的覆盖度直接对应建议书各章的"原料充足度"——立项依据靠文献、考核指标靠指标类素材，缺哪类补哪类。阶段只升不降（人工可回调），避免评分抖动。

2. 建议书三模式：模板补全是刚需

  • 内置七章骨架：立项依据/研究内容/关键技术/技术路线/考核指标/创新点/风险对策
  • word 模板补全：解析 .docx 章节结构（pStyle 标题样式 + 中文序号正则双识别），按原章节标题逐章生成，模板已有内容强制保留融入——"按参考文档或模板补全输出完整内容"的正解是结构对齐 + 内容保全，不是格式模仿
  • 参考文档对齐：范文注入 prompt 对齐文风与章节组织，内容独立（禁止照抄数据）

纯 stdlib 解析 docx（zipfile + ElementTree 提取 w:p/w:t/w:pStyle），零依赖；生成 docx 用最小三文件包（Content_Types + rels + document.xml），标题带 outlineLvl 可进 Word 导航窗格。

3. 去 AI 化：确定性扫描 + LLM 五步流水线双层架构

  • 离线层（零 LLM 依赖）：三级黑名单（P0 必改/P1 建议/P2 容忍，中英双语）+ 段首机械连词检测 + 绝对化表述检测 + 句法节奏分析（burstiness=句长变异系数）。评分 0-100 映射 clean/light/heavy/severe 四档。这层永远可用——LLM 挂了也能扫
  • LLM 层：paper-humanizer 五步串行（词汇清洗→句法节奏→衔接隐蔽→学术克制→困惑度重构），每步一个独立 prompt，串行传递文本，前后评分对比可见

实测踩坑：句式单调罚分初版对"短句群"误报——工程文本均长 11 字、CV 0.29 是正常文体，不是 AI 痕迹。修复为句子数≥6 且均长≥15 才判单调。教训：文风检测器的阈值必须用目标领域的真实文本校准，通用语料假设会伤工程文体。

4. 指标纪律写进 prompt（继承 research-proposal-planning 硬性偏好）

准确率类禁写 95%+（评审易质疑）、效率类 30-50% 安全区间、每条指标带验证条件、区分研究指标与验证指标。这是"生成的内容能过评审"的关键——AI 默认倾向写"95%+ 显著提升"，恰好是评审最反感的模式。

5. 双形态同核：73KB 单文件 HTML 是唯一前端

HTML 版：单文件零依赖（内联 CSS/JS），file:// 直开，localStorage 存储；App 版：Python stdlib HTTP 服务（静态托管 + /api/llm 代理免 CORS + /api/data 文件持久化 + docx 上传解析/导出），双击 run.bat/run.sh 自动开浏览器。前端启动时 fetch /api/ping 自适应判别模式。数据以 JSON 导入导出互通。

Win7 兼容：全代码 py3.9 语法审查（无 match/PEP604 注解）、PyInstaller frozen 路径适配（资源读 _MEIPASS、数据写 exe 旁）、build_win.bat 一键编译（锁 PyInstaller 5.x——6.x 不支持 Win7）。

学到什么

  1. "管理软件"的第一性问题是数据模型，不是界面。三期×四阶段×六类素材的矩阵定下来后，所有界面都是它的投影。成熟度评分公式比任何甘特图都更能驱动"平时积累"行为
  2. 确定性层与 LLM 层分离是 AI 功能的可靠架构。黑名单扫描离线可用、结果可复现；LLM 润色锦上添花、可中断可重跑。检测器（确定性）和改写器（LLM）各司其职
  3. 中途插入需求可以不返工：word 模板补全和 Win7 兼容都是开发中途插入，因为数据模型（topics/templates 分离）和传输层（JSON 单一接口）足够干净，插入点变成"新增模板库 + prompt 分支 + frozen 路径"三个局部改动
  4. pkill/pgrep 自匹配坑复现：模式串出现在自己 shell cmdline 里会自杀（SIGTERM），端口定位（ss -ltnp → pid → kill）是旁路由系统的正解
