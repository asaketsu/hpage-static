各论文技术细节

1. AlphaCrafter（CSI 300 + S&P 500 实测）

问题定义：现有 agent 交易系统用"松散的自然语言工作流"描述流程，导致三个风险——推理过程不透明、跨基础模型行为不一致、可控性与可验证性差。

核心设计：不把 agent 行为当作"无约束的 prompt 执行"，而是把每个 agent 封装进可编程的策略规范（programmable policy specifications），内含三要素：程序化工作流 + 执行约束 + 显式验证机制。整个交易流水线（因子发现→信号聚合→组合执行）变成一串定义良好、可复现、可审计的决策过程。

实测结论：CSI 300 与 S&P 500 上取得更优风险调整收益，且跨模型、跨试跑的方差显著降低——这是 harness 设计相对自由 prompt 的决定性优势。

2. OpenPM（点时审计框架）

问题定义：LLM 交易 Agent 的论文成绩可能被三件事吹大——①前视泄漏（look-ahead leakage，用了决策时刻不可能拿到的数据）②乐观执行假设 ③风险约束"写在纸上但没在代码里强制执行"。

核心设计：
- Agent 管理 $1M 纯多头组合，标的池 S&P 500，5 分钟频率行情；
- Point-in-Time 铁律：agent 能看到的每条记录必须在决策时刻已可用；
- 自然语言风险指令被转换成类型化约束（typed constraints）并在执行组合上强制校验；
- 每次运行产出审计工件：污染证书、成本敏感曲线、约束遵守报告；
- 参考实现 tiered allocator：类型化分析师打分 → 构造器 LLM 提权重 → 确定性批评器保证可行性（三段式中最后一段不用 LLM）。

关键发现（比框架本身更有价值）：短窗口案例研究中，换更强的构造器只能带来"温和且依赖模型"的收益，而分析师质量比构造器选择更重要，换手率才是主要成本驱动。作者明确声明：所有收益是单一冻结窗口、无市场冲击的上界，"不是经过验证的 alpha"。

3. TrustTrade（选择性共识）

问题定义：命名了一个行为偏差——均匀信任（uniform trust）：LLM 把检索到的信息默认为事实、把异质信息源当作同等可信。人类决策靠选择性过滤、交叉验证、经验驱动的权重，LLM 交易系统在这方面的缺失使其对多源噪声和虚假信息极其脆弱，放大事实幻觉并导致风险收益不稳定。

核心设计（Trust-Rectified Unified Selective Trader）：
- 多个独立 LLM agent 交叉聚合，按语义与数值一致性动态加权信号；
- 一致信号优先，发散/弱 grounded/时间不一致的输入被选择性折价；
- 加入确定性时序信号作为可复现锚点；
- 反思记忆机制在测试时自适应风险偏好，无需额外训练。

实测：2024Q1 与 2026Q1 高噪声市场受控回测中，把 LLM 交易行为从极端风险-收益区校准到人类对齐的中风险中收益档位。

4. A股可解释因子分解（3632 只 A 股 2009-2019）

  • 管线：XGBoost + TreeSHAP 归因，60 个月滚动窗口训练，55 个月样本外；
  • 预测性能：mean AUC 0.547（rank IC=0.119），Top-Bottom 五分位多空价差 +2.38%/月（Newey-West t=5.94，年化 Sharpe 2.23）；
  • Carhart 四因子调整后仍 +2.31%/月（t=7.48）——alpha 不是已知因子的马甲；
  • 归因结构（对 A 股短线最有参考价值）：行为信号（换手率+动量）占预测归因 58.2%，估值比率仅 10.7%，跨 50 个行业组平均；
  • 方法论提醒：SHAP 与 ablation 会发散，发散模式揭示了"特征可替代性结构"——单独用任一方法都看不见。

5. FPILOT（推理时优化）

  • 洞察：未来价格基本不依赖单个 agent 的持仓分配 → 不需要 RL 那种"动作条件滚动"，一个合适的预测器就能产出多步价格轨迹；
  • 设计：MPC 式插件——每个决策步用预测价格轨迹构造"基于仓位的想象收益目标"，在执行前推理时优化策略，兼容任何预训练 agent，零重训练；
  • 实测：TradeMaster DJ30 上五种策略学习算法一致提升总收益与风险调整指标（Sharpe/Sortino/Calmar），随机策略比确定性策略受益更多；
  • 合成预测实验：预测器质量越高收益越大——意味着该框架随金融预测技术进步水涨船高。

6. EvoTS-Agent（自进化 × 金融时序的交叉）

  • 场景：金融时序非平稳且统计性质异质，没有单一无监督变点检测算法在所有资产/regime 下都好——传统流程严重依赖专家选模型/设计特征/调参；
  • 设计：验证引导的自进化 LLM agent，先做探索性数据分析初始化候选模型，再用三个算子进化可执行实验轨迹——Revision（利用当前最优）、Alternative Strategy（停滞时换根本不同的建模方向）、Recombination（合成高性能轨迹的互补证据）；
  • 结果：四个基准数据集上超过现有 LLM-based agent，且在所有骨干 LLM 上保持 100% 执行成功率。

归纳总结：三条主线收敛

主线一：从"自由 prompt"到"结构化 harness"（AlphaCrafter + OpenPM）

两篇论文从不同角度打同一个靶：LLM 金融决策的可靠性不靠更强的模型，靠更强的结构约束。AlphaCrafter 把 agent 封装进可编程策略规范；OpenPM 把风险指令转成类型化约束+确定性批评器。共同的哲学：LLM 负责提议，确定性代码负责验证与执行。这与"AI 层（建议）→ 确定性核心（构建+验证）"的认知设计范式完全同构——金融领域和工程设计领域在 2026 年独立收敛到同一架构答案。

主线二：对抗 LLM 的认知偏差（TrustTrade + OpenPM）

TrustTrade 命名的"均匀信任"偏差是 LLM 交易系统的系统性风险：多源信息不加权、不加验就进决策。修复手段有三层——多 agent 交叉一致性、确定性锚点信号、反思记忆。OpenPM 则从评估端补刀：你声称的风险约束必须被机器强制执行才算数。两者合起来构成"决策时防御 + 评估时审计"的完整闭环。

主线三：推理时/进化时优化成为新增长点（FPILOT + EvoTS-Agent）

训练时优化（RL 微调）成本高且易过拟合，2026 年的新路线是把智能移到推理时刻：FPILOT 用预测轨迹在每次交易前即时优化策略；EvoTS-Agent 用验证反馈在实验轨迹空间进化。共同点：不动模型参数，只动"策略周围的结构"，改起来便宜、可回滚、可审计。

趋势判断

  1. "可审计性"成为 LLM 金融论文的入场券。OpenPM 直接点名前视泄漏/乐观执行/纸面约束三大作弊通道，2026 年下半年起的量化 Agent 论文如果不带 point-in-time 审计工件，可信度会被系统性打折。
  2. 分析师质量 > 构造器质量（OpenPM 实证）。对自建体系的启示：投入产出比最高的环节是"信号质量"（选股/因子层），不是"权重优化层"。
  3. 换手率是主要成本驱动。A 股 T+1 + 印花税环境下更甚，任何策略优化的前提是控制换手——这与 5 日超短模式的"时间止损换股"纪律形成张力，需要用回测器量化。
  4. A 股的 alpha 主要藏在行为信号里（换手+动量 58.2% vs 估值 10.7%）。这与"买分歧卖一致""量比控盘"等本土经验互相印证——学术定量证据支持短线情绪/动量路线，而非价值路线。
  5. 自进化 agent 进入垂直领域（EvoTS-Agent 的变点检测）。三算子设计（Revision/Alternative/Recombination）是通用的实验进化模式，可迁移到因子挖掘场景。

拓展应用：可落地清单

  1. 回测器加换手率成本敏感度曲线（OpenPM 审计工件）：在 iron-rules-backtester 输出中加一维——按手续费 1x/2x/3x 档位重算收益，看策略在真实成本下是否存活。成本低（纯后处理），直接堵住"回测赚钱实盘亏钱"最大来源。
  2. 回测器加 per-signal 归因（A股论文方法）：把胜率/收益拆到每条铁律/每个信号（P1 涨停基因、P2 箱体突破、量比、VWAP……），用现有逐单记录即可做——确认哪条规则在贡献 alpha、哪条在拖后腿。SHAP 不必上，简单的按信号分组的条件收益表就能回答 80% 的问题。
  3. 反向辩论审查器加"多源一致性"层（TrustTrade）：目前 E1-E10 是单源空方证据；可加一条 E11——当技术面证据与量价证据方向冲突时标记 🟠。不需要多 LLM，用现有指标间的逻辑冲突（如 RSI 超买 vs 量比萎缩）即可实现确定性版本。
  4. EvoTS-Agent 三算子模式用于参数实验台：现有 strategy-param-lab 是网格搜索；可加 Alternative Strategy 算子——当网格内所有参数组合都停滞时，自动切换到根本不同的信号构造（如从 PCT4 切到量价背离），而不是继续加密网格。
  5. 不建议跟进 FPILOT：依赖可靠的价格预测器（A 股短线预测本身是未解难题），且我们的决策频率（T+1 日线）远低于其 5 分钟场景，推理时优化的边际收益小。

查询拓展：未覆盖的延伸方向

  • LLM 因子挖掘的可复现性：AlphaCrafter 只在 CSI 300/S&P 500 验证，中证 500/1000 及 A 股小票池是否同样受益于 harness 约束？未检索到证据。
  • OpenPM 框架的开源可用性：摘要未提代码开放，污染证书/成本敏感曲线的具体实现格式未知——跟进 GitHub 搜索确认。
  • TrustTrade 的 A 股适用性：其实验基于美股信息源生态；A 股的信息源（公告/龙虎榜/股吧）异质性更强，"选择性共识"的加权机制需要重新校准。
  • 行为信号 58.2% 的时效性：A股论文数据止于 2019，注册制后（2020+）小票数量翻倍、退市常态化，动量/换手归因占比是否仍成立待验证。
  • FPILOT 与 T+0 市场的组合：若未来 A 股局部 T+0（如 ETF），5 分钟级推理时优化才有适用土壤——留作长期跟踪项。

指南分析：方法论收获

  • 评估先于优化：OpenPM 的价值不在提出更强的 agent，而在给出"怎么判断别人声称的收益是不是真的"的清单。做任何回测结论汇报前，先过一遍：有没有前视泄漏？执行假设是否乐观？约束是否真的强制执行了？
  • 命名偏差是研究的第一步：TrustTrade 把模糊的"LLM 乱信信息"命名为 uniform trust 后，修复路径（选择性共识+确定性锚）就自然浮现。我们遇到"策略在某种行情下总犯错"时，先尝试给这个错误模式起名字。
  • 确定性批评器模式：LLM 提议 → 确定性代码否决，这个三段式（分析师/构造器/批评器）中批评器必须是纯代码。反向辩论审查器已经是这个模式，可继续强化"批评器的否决不可被 LLM 覆盖"原则。
  • SHAP 与 ablation 的发散是特性不是 bug：两种归因方法分歧的地方恰是特征可替代性所在——单一归因方法得出的"最重要因子"结论要谨慎。

可学到的点

  1. Harness 约束 > 模型能力（AlphaCrafter：跨模型方差降低是结构性收益）
  2. 分析师质量 > 构造器质量（OpenPM：资源应投向信号层而非权重层）
  3. 换手率是隐形 alpha 杀手（OpenPM：成本敏感曲线是必备审计件）
  4. A 股 alpha 在行为信号（58.2% vs 10.7%，本土短线经验的学术定量印证）
  5. 推理时优化是零训练成本的升级路径（FPILOT：MPC 思想，预测器进步自动受益）
  6. 三算子进化模式（EvoTS-Agent：利用/换向/重组，可直接搬到参数实验台）
