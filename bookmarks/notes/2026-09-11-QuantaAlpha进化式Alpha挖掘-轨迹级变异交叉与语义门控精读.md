## 零、结论先行

**QuantaAlpha 把"每次端到端挖掘运行"视为一条可进化的轨迹（trajectory），用变异（只改失败步骤）+ 交叉（重组高奖励父代片段）替代"基于噪声反馈的随机重新生成"，在 CSI300 上 IC 0.0472、四年跨市场迁移 CSI500 +40.28% / S&P500 +19.1% 累计超额，全面碾压 RD-Agent（IC +0.0186）和 AlphaAgent（IC +0.0125）。**

对我们体系的最大冲击不是数字，是三个方法论移植点：①**变异=前缀冻结+单步重写**（与 skill patch 哲学同构，可反向强化 evolver）②**RankIC 门禁只在验证期计算，测试窗在进化期间永不触碰**（比我们 quant-evidence-governance 的时间前视防护更严格的实操范本）③**11-12 次迭代后继续迭代反而劣化**（预算收敛意识，直接可写进 llm-factor-mining）。

## 一、内容整理（忠实还原）

### 1.1 现有 LLM 因子挖掘的三大缺陷

| 缺陷 | 机制 |
|------|------|
| 脆弱可控性 | 迭代精修由噪声回测反馈驱动 → 语义漂移 → 逐渐偏离预期经济机制、锁死伪相关 |
| 有限可信度 | 随机重新生成不显式继承已验证的 rationale → 无可追溯谱系，因子难审计 |
| 受限探索 | 过度开发初始种子邻域 → 冗余 + 因子拥挤，假设空间覆盖不足 |

### 1.2 轨迹形式化

每次挖掘运行 = 轨迹 τ=(s₀,a₀,s₁,…,sₙ)，s₀=初始上下文，aᵢ=多 Agent 系统的动作，sₙ=含评估结果的终态。目标：学轨迹生成策略 π 最大化期望终态奖励 R(τ)=L(f_τ(X),y)−λR(f_τ)。

### 1.3 挖掘流程三阶段（多 Agent 分工）

- **假设生成**（idea agent）：市场观察 + 金融理论先验 + 参数规格 → 可执行市场机制假设
- **可控因子构造**（factor agent）：假设 → 符号表达式（标准化算子库 O + AST 中间表示）→ 编译成代码；编译失败触发 LLM 修复。**不直接生成自由代码**——AST 让计算依赖和数据流完全透明
- **因子评估**（evaluation agent）：标准化回测（预测力 IC/ICIR/RankIC + 收益 ARR/IR + 风控 MDD）+ 维护评估历史、总结成败模式

### 1.4 两道生成门禁

**一致性验证**：LLM verifier 检查 (i) 假设 h ↔ 语义描述 d ↔ 符号表达式 f 对齐 (ii) f ↔ 代码 c 忠实；失败则重写不一致组件直到通过或耗尽重试预算。

**复杂度与冗余控制**：
- 复杂度 C(f)=α₁·SL(f)+α₂·PC(f)+α₃·log(1+|F_f|)——符号长度+自由参数+特征数
- 冗余：AST 最大公共子树同构匹配 s(fᵢ,fⱼ)，对已有 alpha zoo 超限即拒绝重写
- 输出级二次过滤：2021 验证面板上 |相关系数| 超限则丢弃 RankIC 较低者（结构冗余+功能冗余双阶段）

### 1.5 进化算子

- **多样化初始化**：Alpha158(20) 种子按低相关分组 → 初始化 agent 生成互补假设集（信号源/时间尺度/机制类型三轴互补）
- **变异**：自反思定位最致劣决策节点 k → 冻结 s₀…sₖ 前缀 → 只重写 aₖ → 后续步骤在前缀条件下重新生成保连贯。重写可更新假设/表达式/代码，引入机制级变化（改时间尺度、加 regime 条件）
- **交叉**：从高奖励父代轨迹中提取持续贡献高累计奖励的片段（假设模板、构造模式、修复行为）合并成子代——显式继承已验证组件，谱系可信

### 2.2 Backbone 谱系窄 gap 的解释

五个 backbone IC 全落在 0.0445-0.0472（gap 0.004）——框架收益与 backbone 解耦。Claude 略低的归因：反馈输出更长 → 固定上下文预算里能装的历史轨迹更少 + 变异偏局部；DeepSeek 更常做大幅探索跳跃。

### 2.3 迭代收敛研究（Appendix E，最有实操价值）

15 次迭代（DeepSeek-V3.2，每次=变异相+交叉相），因子池贪心 RankIC 驱动维护：
- **准入门**：RankIC 只在 2021 验证期计算，2022-2025 测试窗在进化和池构建期间**永不访问**
- **冗余门**：与池内所有因子 |相关| < 0.7 才准入
- **池上限**：当前已挖因子总数的 50%
- **收敛点**：11-12 次迭代（约 350 个因子）是收益-回撤最优平衡点；之后迭代无显著提升，反而引入冗余信息 → 稳健性下降、回撤恶化

## 三、归纳总结

1. **轨迹级进化 > 随机重生成**：在低信噪比、非平稳市场里，把"继承什么"显式化（前缀冻结/父代片段）比"让 LLM 看反馈再roll一次"可控得多——本质是把进化算法的稳定优化单元套在 Agent 工作流外层
2. **中间表示是语义门控的支点**：h→d→f(AST)→c 四层链条的一致性验证，防的就是"代码能跑但和假设无关"的语义漂移——这与《三种写的不可混同》中 W2 写入需验证器门控完全同构
3. **生成侧正则 > 事后过滤**：复杂度/冗余约束在生成时即拒绝，而非回测后再筛——AlphaAgent 的拥挤正则化思路被推进到 AST 结构级
4. **验证期门禁+测试窗隔离**是因子挖掘版的时间前视防护，工程上比"事后 walk-forward"更早卡住污染
5. **收敛后继续跑=负收益**：350 因子/12 迭代是预算止损线，进化框架同样过拟合

## 四、趋势判断

- **LLM 因子挖掘的竞争焦点从"自动化程度"转向"可审计谱系"**：RD-Agent（全栈自动化）→ AlphaAgent（正则化）→ QuantaAlpha（可追溯进化谱系）的演进线说明：当自动化普及后，trustworthiness 成为差异化主战场
- **进化算子外挂在 Agent 框架上会成为通用范式**：AlphaEvolve（科学发现）→ CogAlpha（代码级进化）→ QuantaAlpha（轨迹级进化），"把 Agent 运行轨迹当基因"的思路正在跨域复制，Hermes 的 evolver/error-case-library 已是无意识同构
- **因子池管理规则标准化**：RankIC 准入 + 相关 0.7 门 + 50% 容量上限这类池维护规则，正在从各家私有技巧沉淀为公共范式，预计会成为 LLM 挖矿框架的标配组件
- 诚实风险提示：IC 0.047 量级 + A 股 CSI300 + 四年测试窗，统计上稳健但容量有限；ARR 4.68% 对个人投资者是弱收益，价值主要在方法论而非直接套利
