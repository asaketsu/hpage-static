1. 能干什么（开箱动作 + 装轮换脑）

  • 走路（手柄可直接控）
  • 摔倒后自己重新站起来
  • 低头捡地上的东西（袜子、记号笔）
  • 坐下 / 起立 / 踢球 / 前滚翻
  • 跟随激光笔移动、NFC 触发
  • 唱歌——每台首次启动获得唯一声音身份，永久绑定该硬件
  • 加装脚底轮子 → 切换到另一套强化学习策略：滑行、转圈、下坡，甚至能在轮滑状态下自己起身

2. 硬件架构与执行机构规范

原文只给了标题"硬件架构与执行机构规范"，具体明细需 GitHub 与新闻源补充：

  • 处理器：瑞芯微 RK3566（四核 A55 + Mali G52）
  • 传感：RGB 摄像头、立体麦克风阵列、扬声器、2D LiDAR、Wi-Fi、BLE、2× IMU
  • 电机：15 个（腿 × 2 + 头 + 颈 + 鸭嘴）
  • 无传统双臂——鸭嘴兼任抓取机构

3. 强化学习与 Sim2Real 迁移流水线

依托 microduck_rl 开源训练仓库，系统构建了端到端的高拟真物理仿真与真机迁移框架。

3.1 仿真与优化算法

项 值
仿真平台 MuJoCo / MuJoCo Warp
核心算法 PPO (Proximal Policy Optimization)
训练控制周期 50 Hz（与真机严格一致）
部署格式 ONNX（训练侧导出，真机 runtime 加载）

3.2 物理级误差拟真（Sim2Real Gap 的核心）

在 800g 双足 + 微型舵机的量级，执行器保真度是 sim2real gap 的最大头——所以舵机不是被当作理想 PD，而是建模到电压控制律这一层。

  • 传动非线性：显式建模舵机齿轮组的齿隙（Backlash）松动量
  • 电气特性：模拟电池电量下降引起的母线电压动态波动对执行器出力的影响
  • 延迟与摩擦：拟合端到端控制系统延迟 + 关节轴承的动/静摩擦力分布
  • 域随机化：训练流程深度集成，覆盖上述全部维度

4. 端侧软件工程架构

  • 语言：Rust 原生开发
  • 架构：无臃肿依赖、模块化解耦的微服务守护进程架构
  • 通信：服务间统一通过 Unix Domain Socket + JSON-RPC 2.0

4.2 动作意图与执行权限隔离（安全核心设计）

系统采取特权隔离设计：

  • padd、btd 等上层或外设模块 仅能向 robotd 提交抽象的运动意图（不能直接下发关节角）
  • robotd 拥有底层舵机驱动的排他性控制权
  • 在下发目标关节角前 必须通过姿态极限、防撞自保等安全策略校验
  • 目的：彻底杜绝非法输入损坏机械结构

这是"意图层"与"执行层"分离的经典做法，与汽车功能安全 ASIL 分级思路同构。

5. 高可用 OTA 固件交付机制（updaterd 自愈）

针对具身智能设备频繁迭代模型与控制策略的特点，updaterd 实现了全闭环自愈型 OTA 更新流水线：

  • 推送模型或代码后，即使极端情况下导致 Runtime 崩溃
  • 机器人也能在无人值守状态下自动恢复至可用版本
  • 目标：杜绝变砖风险

6. 商业模式与产业意义

  • 399 美元 把双足机器人从实验室价格带直接拉到消费电子区间（对比 1X NEO 2 万美元）
  • 定位不是家用家务机器人，而是低成本物理 AI 实验平台 + 教育硬件 + 开发者平台
  • 软件与 Reachy Mini 一样开源，硬件本身仍需付费——开源边界恰好停在物理层
  • Clem Delangue 定位："首款可以通过强化学习教授新技能的平价 AI 机器人"
  • 官方口号："Made to move · Ready to learn" / "为运动而生，也准备好摔倒"
  • 销售表现：Thomas Wolf 称发布初期约 5 秒卖出一台，销售额已破 100 万美元
  • 产业意义：Hugging Face 在具身智能领域复刻其机器学习开源路线，试图在机器人软件生态尚未定型时抢占开发者心智

以下为本笔记附加的对照分析（原文之外的延伸），列出 Microduck 架构中对本机可借鉴的工程模式。

Microduck 设计 本机可借鉴点 落点
