AI Agent 记忆架构前沿：从描述性记忆到可执行记忆

学习日期：2026-05-01
学习深度：L3（深度研究 + 交叉验证 + 可落地建议）
来源：本地笔记 3 篇 + 网络 12 篇 + 论文 2 篇
标签：#Agent记忆 #可执行记忆 #Hindsight #Mem0 #Letta #M-Flow #GraphMemory

TL;DR

2026 年 AI Agent 记忆赛道已从「简单向量检索」进化为「结构化推理基座」。三大关键转变：
1. 从搜索到联想：记忆不只是 top-k 相似匹配，而是沿实体关系图谱的联想激活
2. 从描述性到可执行性：Hyperagents 证明记录「下次怎么做」比记录「发生了什么」有效得多
3. 从单一存储到分层基座：Hindsight 的四网络架构（事实/经验/实体摘要/信念）在 LongMemEval 达 91.4%

一、核心发现

1. 记忆分类学突破：Forms × Functions × Dynamics 三轴框架

论文："Memory in the Age of AI Agents: A Survey" (arXiv:2512.13564, 102页, 1.9k GitHub stars)

传统长/短期记忆分类已无法描述现代 Agent 记忆系统。该综述提出三轴统一框架：

维度 含义 具体类型
Forms（形态） 记忆存储在哪里 Token-level（上下文）/ Parametric（权重）/ Latent（隐状态）
Functions（功能） 为什么需要记忆 Factual（事实）/ Experiential（经验）/ Working（工作记忆）
Dynamics（动态） 记忆如何随时间变化 Formation（形成）/ Evolution（演化）/ Retrieval（检索）

对我们的意义：现有 memory-system 只有 Working Memory（L3 临时），M-Flow 添加了 Factual（FacetPoint），但缺少 Experiential（经验） 层。Hyperagents 的 Context Memory 正是 Experiential Memory 的实例。

2. Hindsight：四网络架构的记忆推理基座

论文："Hindsight is 20/20: Building Agent Memory that Retains, Recalls, and Reflects" (arXiv:2512.12818)

当前最强开源 Agent 记忆系统，在 LongMemEval 达 91.4%，LoCoMo 达 89.61%。

核心创新 — 四个逻辑网络：

网络 功能 类比
World Facts 世界事实（客观知识） 百科全书
Agent Experiences Agent 自身经历（经验记忆） 日记
Entity Summaries 实体摘要（人物/项目画像） 人事档案
Evolving Beliefs 演化信念（动态更新的判断） 工作笔记

三个核心操作：
- Retain：从对话流中提取结构化信息
- Recall：基于实体感知的时序检索
- Reflect：推理层对记忆库进行推理和更新（可追溯）

关键数据：用开源 20B 模型，Hindsight 将准确率从 39% 提升到 83.6%，超过 GPT-4o 的 full-context 基线。说明问题不在模型能力，而在记忆结构。

3. Letta (MemGPT)：文件系统就是最好的记忆？

发现：Letta 用 gpt-4o-mini，仅靠文件存储对话历史，在 LoCoMo 达 74.0%——比许多专用记忆系统还高。

启示：
- 当前记忆 benchmark（如 LoCoMo）可能不够 meaningful
- 记忆质量更取决于 Agent 的上下文管理能力，而非检索机制本身
- MemGPT 的核心范式是 LLM-as-OS：让模型像操作系统一样自己管理内存（context = RAM, storage = disk）

Letta 还宣称：在 Terminal-Bench 上以 #1 开源 agent 超越 Claude Code。这值得后续关注。

4. Mem0 生态现状

  • 48k GitHub stars，最大独立记忆层
  • Mem0g（图增强版）：存储为有向标记图（实体=节点，关系=边）
  • 时间推理任务得分 58.13% vs OpenAI 21.71%
  • 但记忆占用极低（1,764 tokens/对话 vs Zep 的 600,000 tokens）
  • 局限：最强项是个性化（记住用户偏好），机构知识（Institutional Knowledge）较弱

5. 2026 记忆赛道格局

玩家 路线 优势 劣势 适合场景
Hindsight 四网络结构化 最高 benchmark，机构知识 新项目，生态小 长期运行 Agent
Mem0 向量+图混合 最大生态，低占用 机构知识弱 个性化对话 Agent
Letta LLM-as-OS 无限记忆，文件即够 复杂度低 长对话 Agent
Zep 时序感知图谱 时序推理强 占用 600k tokens/对话 需时序推理
Cognee 知识图谱优先 图谱结构好 不适合对话场景 文档密集型 Agent
M-Flow 锥形图谱+联想 概念创新 PR 嫌疑，生态小 联想式检索实验

6. Benchmark 现状：LoCoMo 不够用了

  • LOCOMO：长对话记忆基准，但 Letta 证明文件系统就能刷 74%
  • LongMemEval：更难，Hindsight 在此拉开差距
  • BEAM (Agent Memory Benchmark)：Hindsight 团队推出，关注 agentic tasks（跨工具调用的记忆、多步决策偏好）
  • 10M tier：「是否能称得上真正的记忆系统」的分水岭

二、关键概念深入

可执行记忆 vs 描述性记忆（核心洞察）

这是 2026 年最值得关注的范式转变：

维度 描述性记忆（现有） 可执行记忆（Hyperagents 路线）
存什么 「发生了什么」 「下次怎么做」
格式 自然语言摘要 策略脚本 + 约束条件
使用方式 检索 → 阅读 → 理解 检索 → 直接执行/适配
更新方式 追加 覆盖+验证
类比 日记 教程/手册

Hyperagents 的实现：Context Memory 的每条记忆 = 状态特征 + 针对性策略 + 执行结果。策略是可直接用于生成新 prompt/代码的。

多层记忆架构（四层写入权限模型）

来自 graph.digital 的多 Agent 记忆架构：

层 内容 生命周期 写权限
In-Context 当前对话 单次运行 所有 Agent
Persisted State 观察和任务输出 跨轮次 Worker Agent
External Memory 外部知识 永久 Orchestrator
Episodic 经验记录 永久 所有 Agent（append-only）

三、与现有工作的关联

与 Hermes 记忆体系的映射

新框架概念 Hermes 现有对应 差距
Factual Memory memory 条目、笔记 ✅ 已有
Experiential Memory experience-bank（概念有，实现浅） ❌ 需加强
Working Memory session 上下文 ✅ 已有
Entity Summaries M-Flow Entity YAML 🟡 有结构，缺自动维护
Evolving Beliefs 无 ❌ 全新概念
可执行记忆 Skill 文件（部分） 🟡 Skill 是可执行的，但不自动进化
Retain/Recall/Reflect memory-write（Retain only） ❌ 缺 Recall 和 Reflect

与 M-Flow 体系的关系

M-Flow 的 Cone Graph（Episode → Facet → FacetPoint + Entity 横切）是 Factual Memory 的一种优秀实现，但：
- 缺少 Experiential 层（经验/策略）
- 缺少 Belief 层（动态判断）
- 缺少 Reflect 操作（主动推理更新）
- Hyperagents 的 Context Memory 可作为 M-Flow 的 Experiential 扩展
