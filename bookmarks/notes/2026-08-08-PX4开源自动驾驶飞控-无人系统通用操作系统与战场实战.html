一句话定义

全球最主流的开源自动驾驶飞控平台——一套完整的自主运动控制底层，为无人机、无人车、无人船、水下机器人提供统一控制底层。飞行控制栈 + 中间件两层架构，所有平台共用同一套代码库，一次开发多平台部署。在俄乌战场实战验证——从乌克兰 FP-5"火烈鸟"巡航导弹到俄军"克林"自杀式无人机，都在使用开源飞控 + 商用硬件的组合。

完整原文核心内容

一、PX4 是什么

维度 说明
定位 无人机/无人车/无人船/水下机器人的统一控制底层
架构 飞行控制栈（姿态/状态/控制）+ 中间件（uORB 消息总线/驱动/通信）
开源协议 BSD-3（可商用、可二次开发、无厂商锁定）
能力 状态估计、姿态控制、航路规划、安全逻辑、任务执行
硬件支持 多机型、多硬件、多通信协议（I2C/SPI/CAN/UART/PWM）

类比：如果无人机是一个生命体，传感器是眼睛耳朵，电机是四肢，电池是能量来源，PX4 是大脑。

结合最新研究与技术变化

1. 与 Jetson Orin 平台的直接关联

俄军"克林"无人机使用的 Jetson TX2 正是 Jetson 系列的前身。你的 Jetson Orin Nano 是同一产品线的最新一代——从 TX2（256 CUDA cores）到 Orin Nano（1024 CUDA cores），AI 推理能力提升了 4 倍以上。

PX4 + Jetson Orin 的组合潜力：
- PX4 负责飞行控制（飞控栈+uORB+EKF）
- Jetson Orin 负责 AI 推理（YOLO 目标检测/VLA 模型）
- 两者通过 MAVLink 或 ROS 桥接

2. 与 dual-mcu-robot-architecture Skill 的关联

PX4 的飞控栈 + 中间件两层架构与双 MCU 架构理念一致——飞控（实时控制）+ AI（非实时推理）分工。PX4 飞控对应 STM32（实时层），Jetson 对应 ESP32/AI 层。

3. 与 embodied-ai-control Skill 的关联

具身智能闭环控制需要 PX4 这样的底层平台——VLA 模型输出运动指令，PX4 翻译为电机控制信号。PX4 的级联控制结构（位置→速度→姿态→电机）正好是 VLA 输出到硬件执行的桥梁。

4. 与 ESP32 嵌入式方向的关联

ESP32 可以作为 PX4 的传感器节点或遥控前端——通过 MAVLink 或 WiFi 与 PX4 飞控通信。

5. 与 HomeBridge 的关联

HomeBridge 是 IoT 领域的"协议翻译桥"，PX4 是无人系统领域的"通用操作系统"——两者都是用开源+模块化+协议标准化来统一碎片化生态。

  • 与 Jetson Orin 平台：Jetson TX2（俄军"克林"）→ Orin Nano（你的设备）= 同一产品线迭代
