## 核心结论

**2026 年 7 月最后一个周末，达索和西门子不约而同宣布自己不再只是"卖工具"的公司——CAD 厂家的竞争维度从"谁的建模功能更强"转向"谁的 AI 平台更智能"。** 四个信号共同指向一个趋势：工业软件商业模式从"卖 license"转向"卖智能密度"。

## 四个关键信号

### 信号一：达索 18 亿美元收购 ArisGlobal — 工业软件边界被打破

| 维度 | 内容 |
|------|------|
| **金额** | ~18 亿美元现金 + 最高 2 亿美元里程碑对赌 |
| **时间** | 2026-07-23 签署最终协议 |
| **标的** | ArisGlobal — 生命科学 AI 合规平台 |
| **客户** | 200+ 家，含全球前 50 大生物制药公司的一半 |
| **核心能力** | 监管/安全/质量/医学事务 — 药品研发到上市全生命周期合规数据 |

**战略意图**：达索把药物研发→临床试验→生产制造→真实世界证据连成数据闭环，AI 在闭环里持续学习。**收购标的完全在传统 CAD/CAE 疆域之外**——达索在用跨界收购扩展 AI 平台的数据覆盖面。

### 信号二：LEO 从 PPT 走进 CATIA — AI 开始"动手"

| 维度 | 内容 |
|------|------|
| **产品** | 3DEXPERIENCE CATIA R2026x FD03 |
| **时间** | 2026-07-28 发布 |

| **可执行能力** | 装配结构生成、仿真研究、模型诊断、设计错误修复 |

**关键变化**：从"告诉你怎么做"到"直接做给你确认"。LEO 背后是被结构化的 Competencies — 工业岗位知识的封装。

### 信号三：西门子 PhysicsAI Generate — 仿真从"验证"变成"生成"

| 维度 | 内容 |
|------|------|
| **产品** | 统一版 Simcenter 产品组合 |
| **时间** | 2026-07-29 发布 |
| **整合** | 首次整合 Altair 仿真技术 |
| **核心** | Simcenter PhysicsAI Generate — 物理感知生成式 AI |
| **能力** | 根据目标尺寸/性能 KPI/历史数据，**秒级生成结构可行的设计方案** |
| **速度** | 仿真评估速度提升到传统求解器的 **1000 倍** |

**关键区别**：与 Stable Diffusion 式"生成好看图片"不同，PhysicsAI Generate 输出必须满足物理约束，是可被工程验证的设计方案。

## 深度分析：CAD 厂家的四个战略判断

### 判断一：商业模式从"卖 license"转向"卖智能密度"

| 维度 | 过去（30 年） | 未来 |
|------|-------------|------|
| **盈利方式** | 软件授权 + 订阅 | 智能服务订阅 |
| **价值来源** | 功能更强大的工具 | 企业知识+数据+AI 能力的汇聚平台 |
| **客户买单** | 为自动化功能付一次开发费 | 为持续产生工程建议的智能服务付订阅 |
| **竞争壁垒** | 几何内核（十年积累） | 行业数据闭环 + AI 学习能力 |

**核心逻辑**：ArisGlobal 的价值不在于界面，而在于它掌握了生命科学最核心的合规数据。数据与达索虚拟孪生结合 → 产生传统 license 无法比拟的智能密度。西门子 PhysicsAI = 把仿真知识变成可复用的智能资产。

> 试问：一个不带"AI"的工业软件，企业还会考虑吗？

### 判断二：工作对象从"几何模型"扩展到"可执行的知识封装"

| 层级 | 过去 | 未来 |
|------|------|------|
| **封装形式** | VBA 宏 / CAA 插件 | CATIA Competency（语义单元） |
| **输入/输出** | 文件读写 | 有输入、有输出、有约束、有失败处理 |
| **调用方式** | 手动执行 | 智能体自动发现和调用 |
| **价值锚点** | 写代码加速操作 | 封装企业 Know-how 为 AI 可用服务 |

**LEO 能调用 CATIA 的前提**：背后有被结构化的 Competencies——工业岗位知识封装。达索 Industry World Model = 把几十年工程经验+行业标准+物理规律编码成 AI 可理解形式。

**对二次开发工程师**：你写的不再是一个脚本，而是一个"CATIA 机械设计 Competency"，LEO 根据任务需要自动调用。

### 判断三：设计-仿真闭环缩短，从"工具链拼接"转向"闭环编排"

| 维度 | 过去 | 未来 |
|------|------|------|
| **仿真位置** | 设计后期验证 | 设计早期决策伙伴 |
| **开发需求** | "把 CATIA 模型导出送进仿真软件" | CAD 参数改→仿真自动重跑→AI 建议→写回 CAD |
| **能力模式** | 线性工具链拼接 | 闭环编排（数据流+控制流+错误处理+人机确认） |
| **复杂度** | 单向导出 | 闭环比单向复杂一个数量级 |

**PhysicsAI Generate + LEO 的共同特征**：仿真前置到设计阶段。设计师构思阶段就能得到 AI 性能预测和改进建议。

### 判断四：国产工业软件加速成熟，横向迁移成为竞争力

| 维度 | 说明 |
|------|------|
| **国产平台** | 华天 CrownCAD / 中望 3D / 浩辰 CAD 等 |
| **中试平台作用** | 补齐"从能用到敢用"最后一公里 |
| **CATIA 能力迁移性** | 参数化建模/装配/BOM/几何约束/设计规范 — 大部分通用 |
| **策略** | 不需转行，但了解 1-2 个国产平台 API → 多一种选择+多一条退路 |

## CAD 厂家未来布局矩阵

基于四个信号和判断，推演各玩家的战略走向：

| 厂家 | 当前优势 | AI 平台化布局 | 核心赌注 |
|------|----------|-------------|----------|
| **达索** | CATIA + 3DEXPERIENCE + SIMULIA | LEO/AURA/MARIE Virtual Companions + ArisGlobal 跨界 | Industry World Model — 行业知识 AI 化 |
| **西门子** | NX + Simcenter + Altair 整合 | PhysicsAI Generate + 统一仿真平台 | 物理感知 AI — 仿真前置到设计 |
| **PTC** | Creo + Granite 内核 + ThingWorX | Onshape Cloud AI + AR | 待加速（文章未提及新动作） |
| **Autodesk** | Inventor + Fusion + ShapeManager | Forma (AI 建筑生成) + Fusion AI | 云原生 + AEC 行业 |
| **国产** | 华天/中望/浩辰 | 中试验证 → 产线可用 | 国产替代 + 政策红利 |

### 三条战略路线

```
路线 A：知识平台化（达索）
  几何内核 → AI 伴侣 → 行业知识封装 → 跨界数据闭环
  核心能力：Competency 结构化 + Industry World Model

路线 B：物理 AI 生成（西门子）
  仿真引擎 → 物理感知 AI → 生成式设计 → 闭环优化
  核心能力：PhysicsAI Generate + Altair 整合

路线 C：国产替代 + 产线验证
  开源内核 → 中试验证 → 行业适配 → 规模化部署
  核心能力：政策红利 + 产线场景验证
```

## 终局推演：CAD 的三层 AI 化

```
第一层：AI 辅助（当前主流）
  - AI 建议工程师怎么做
  - 自动化重复操作（宏/插件）
  - 参数优化推荐

第二层：AI 执行（2026 正在发生）
  - AI 直接操作 CAD 工具（LEO）
  - 仿真前置生成设计方案（PhysicsAI）
  - 闭环编排（CAD↔仿真↔AI）

第三层：AI 自主设计（3-5 年后）
  - AI 理解工程需求 → 自主生成完整设计
  - 跨系统数据闭环持续学习
  - 工程师角色从"操作者"变成"审核者"
```
