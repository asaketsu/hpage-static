## 一、核心概念（内容整理）

核心方法论：**别上来训 7B/13B**，先用 27M 玩具模型把训练全流程跑通——不依赖 HuggingFace Trainer、不用任何封装。跑通 ≠ 训好，小模型验证的是"链路正确性"（每一行都理解），大模型只是改参数加工程。

文章最核心的主张：**训练循环是整个系列最重要的代码段**——写不好模型训不动、训不对、训不快。小模型上理解每个设计决策，放大就不慌。

三层认知框架：

| 阶段 | 内容 |
|------|------|
| 模型 | SmallLM 27M（Embedding+4 层 nn.TransformerEncoder+LM Head，Pre-LN，weight tying，ignore_index=-100） |
| 数据 | ToyLMDataset（随机 token，错一位 X[:-1]/Y[1:]；实际训练换真实语料即可） |
| 训练循环 | AdamW（wd 分组）+ cosine+warmup + clip=1.0 + zero_grad(set_to_none) + 检查点 |

## 二、技术要点（指南分析）

### 2.1 模型 5 个设计决策

| 设计 | 原因 |
|------|------|
| `norm_first=True`（Pre-LN） | GPT-2 之后主流；Post-LN 深层易梯度爆炸需 warmup 慢慢拉起 |
| weight tying | `lm_head.weight = token_embedding.weight`，省参数 + 正则化 |
| 因果掩码 | 下三角 bool buffer；防止看到未来 token |
| ignore_index=-100 | CrossEntropy 跳过 padding |
| 可学习 pos_embedding | 简单（下篇手写 Transformer 再用 RoPE） |

**⚠️ 本项目实测踩出两处 torch 2.13 兼容性 bug（原文代码在新版会 NaN）**：

1. **双层 mask 不要叠加**：`encoder(x, mask=mask, is_causal=True)` 双重遮蔽 → 某行全 -inf → softmax NaN。修复：只传显式 mask。
2. **bool mask 语义陷阱**：`nn.MultiheadAttention` 的 bool `attn_mask` 是 **True=禁止**（与 `scaled_dot_product_attention` 的 True=保留**相反**）！原文 `torch.tril(ones).bool()` 把"过去"全遮掉 → 首行 NaN。修复：`torch.triu(..., diagonal=1)`。

（教材代码 = 作者当时环境的快照；跨 API 复用 mask 必须查文档/真跑验证。）

### 2.2 训练循环 4 大标配

| 设计 | 原理 |
|------|------|
| `zero_grad(set_to_none=True)` | .grad 置 None 而非清零，backward 直接分配新内存，快于 zero_grad() |
| weight_decay 分离 | bias/LayerNorm（dim<2 / 'norm' / 'bias'）不做 L2——bias 是偏移不该被拉向 0 |
| cosine + warmup | warmup 线性 0→1 防初期梯度震飞；cosine 后期精细学习；floor=10% |
| 梯度裁剪 clip=1.0 | batch 级保险，梯度爆炸时砍 L2 范数 |

### 2.3 放大路径（代码结构不变）

| 维度 | 27M | 350M | 7B |
|------|-----|------|----|
| d_model | 512 | 1024 | 4096 |
| n_heads | 8 | 16 | 32 |
| n_layers | 4 | 24 | 32 |
| batch_size | 16 | 64 | 256~1024 |
| seq_len | 256 | 1024 | 2048~8192 |
| 显存 | <2GB | ~8GB | ~30GB 单卡 fp16 |
| 数据 | 玩具 | ~10B tokens | ~1T tokens |

区别只在：AMP（本项目已落盘 AMPTrainer）+ FSDP + 梯度检查点 + 真实数据。

### 2.4 loss 不收敛排查清单（文章精华）

按序：① 学习率（1e-4/3e-4/1e-3） ② 梯度爆炸（NaN；裁剪=1.0；`clip_grad_norm_(p, 1e10)` 看范数） ③ 数据（labels 错位 / padding 非 -100 / 数据太少背诵） ④ 模型 bug（因果掩码写反 / embedding 未 ×√d_model / wd 加错参数） ⑤ 初始化（残差输出未 ×1/√(2n_layers)）。**这 5 条就是"从零训模型"最常见的翻车点全集。**

## 四、可学到的点（归纳总结·续）

1. **"先小后大"方法论**：对抗"环境地狱/OOM/loss 不收敛"三座大山的正确姿势。跑通链路正确性，参数放大不慌。
2. **训练循环 4 标配**：set_to_none、wd 分离、cosine+warmup、grad clip——新手教程常忽略，却是大模型训练的标配。
3. **bool mask 语义跨 API 不同**：`scaled_dot_product_attention`（True=保留）vs `MultiheadAttention`（True=禁止）——本项目实测踩出的最隐蔽的坑，验证必须真跑。
4. **双层 mask 不要叠加**：`mask + is_causal=True` 同时传 = 全遮行 NaN。
5. **loss 不收敛排查清单**：5 类原因 × 具体解法，应当作 checklist 而非经验。
6. **教材代码 = 快照**：公众号代码是当时环境快照；落盘成可运行项目必然要加"版本适配+真跑验证"。
