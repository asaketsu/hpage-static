## 一句话定义

> **GLIM 是基于直接多扫描配准误差最小化（因子图上）的通用 3D 定位与建图框架——消除传感器特定流程后支持几乎所有类型的距离传感器（旋转 LiDAR / 非重复扫描 LiDAR / 固态 LiDAR / RGB-D 相机），并提供交互式地图纠正界面和全局回调插槽扩展机制。** 已在 **NVIDIA Jetson Orin (Jetpack 6.1)** 上验证通过。

## 完整原文核心内容

### 一、四大核心特性

| 特性 | 说明 |
|------|------|
| **Accuracy（精度）** | 基于因子图的直接多扫描配准误差最小化，精确保持建图一致性。支持 GPU 加速最大化建图速度和质量 |
| **Easy-to-use（易用性）** | 提供交互式地图纠正界面，用户可以手动修正建图失败并轻松细化建图结果 |
| **Versatility（通用性）** | 消除传感器特定流程，支持任何类型的距离传感器 |
| **Extensibility（可扩展性）** | 全局回调插槽（global callback slot）机制，允许访问建图过程内部状态并向因子图插入额外约束 |

### 二、支持的传感器类型

| 类型 | 代表硬件 |
|------|---------|
| 旋转式 LiDAR | Velodyne HDL32e, Ouster OS1-32 |
| 非重复扫描 LiDAR | Livox Avia, Livox MID360 |
| 固态 LiDAR | Intel RealSense L515 |
| RGB-D 相机 | Microsoft Azure Kinect |

> 设计哲学：**消除传感器特定流程** = 通用性。不针对特定传感器优化，而是把配准误差最小化做成通用的因子图问题。

#### 估算模块（多场景覆盖）

GLIM 提供多个估算模块，从 GPU 精确建图到 **树莓派级别的轻量实时建图**：

- GPU 加速高精度建图
- CPU 实时建图
- 低规格 PC 轻量实时建图（如 Raspberry Pi）

### 四、交互式地图纠正

| 功能 | 说明 |
|------|------|
| 手动回环闭合 | 用户手动指定回环约束 |
| 多次建图会话合并 | 将多次独立建图结果合并为统一地图 |
| 物体分割与移除 | 从点云地图中分割并移除动态物体 |

### 五、扩展机制

全局回调插槽（Global Callback Slot）允许：
- 访问建图过程的内部状态
- 向因子图插入额外约束
- 自定义数据处理流程

扩展示例库 [glim_ext](https://github.com/koide3/glim_ext) 提供：
- 显式回环检测
- LiDAR-视觉-惯性里程计估计
- 其他扩展函数的示例实现

## 结合最新研究与技术变化

### 1. 与 Jetson Orin 平台的直接关联

GLIM 是 **少数明确在 Jetson Orin (Jetpack 6.1) 上验证过的 SLAM 框架之一**。你的 Jetson Orin Nano 8GB 可以直接运行 GLIM 的 CPU 实时建图模块（GPU 加速模块可能受 8GB 共享显存限制）。Livox MID360 等低成本 LiDAR + Jetson Orin = 移动建图平台。

### 2. 与具身智能方向的关联

具身智能的核心挑战之一是**空间感知和导航**。GLIM 提供的 3D 定位与建图能力是机器人导航的基础设施：
- VLA 模型需要环境感知 → GLIM 提供精确 3D 地图
- 机械臂/移动机器人需要定位 → GLIM 提供实时里程计
- 多传感器融合 → GLIM 的因子图统一框架

### 3. 与 PX4 无人机飞控的关联

GLIM 的点云建图可以直接用于无人机室内/室外导航——GPS 不可用的环境中，LiDAR SLAM 是定位的唯一可靠方案。Livox MID360 重量轻（265g）、功耗低（7W），非常适合无人机搭载。

### 4. 与外骨骼控制系统的关联

外骨骼在复杂地形中行走需要实时地形建图。GLIM 的轻量级实时模块可以在嵌入式平台上运行，为外骨骼提供地形高程图和障碍物信息。

### 5. 与 embodied-ai-control Skill 的关联

embodied-ai-control 描述的"大脑-小脑分离设计"中，GLIM 属于小脑层级——提供空间感知和运动估计的底层能力。

### 6. 与 robot-kinematics-simulation 的关联

GLIM 是感知层的工具，与 robot-kinematics-simulation（运动学）互补——一个负责"我在哪、周围是什么"，一个负责"怎么动"。

## 趋势判断

1. **LiDAR SLAM 正在从旋转式向固态/非重复扫描扩展** — GLIM 的通用设计正好抓住这个趋势
2. **因子图优化成为多传感器融合的标准范式** — GTSAM 生态（GLIM/gtsam_points）正在统一 SLAM 后端
3. **GPU 加速点云处理在边缘设备上普及** — Jetson Orin + CUDA 让实时大规模点云配准成为可能
4. **低成本 LiDAR（Livox MID360 ~$700）+ 边缘 GPU = 移动建图平台** — SLAM 从实验室走向消费级
5. **交互式地图纠正成为标配** — 纯自动 SLAM 不可靠的场景，Human-in-the-loop 是务实选择
6. **SLAM 框架的模块化/插件化** — GLIM 的回调插槽机制预示着 SLAM 从单体走向可组合
