内容整理：七步全链实录

步骤 关键动作 硬数据
1 玩具语料 中英混排 8 种句式，围绕虚拟人物"小明"，复制 4000 遍 314 KB / 4.6 万 token，9:1 切训练/验证
2 BPE 分词器 tokenizers 库 ByteLevel BPE，注册 3 个特殊 token（<\|endoftext\|>/<\|user\|>/<\|bot\|>） vocab_size 配 2048，实际只学到 428；后续参数量按 428 算
3 手写 MiniGPT 可学习位置嵌入（GPT-2 式查表）+ 4 层 Block（Pre-Norm + 多头自注意力 + 4 倍扩展 FFN） d=384 / 6 头 / 4 层 / max_len=128 → 7.48M 参数（GPT-2 最小档 124M 的 6%）
4 显存 + 梯度累积 权重+梯度+AdamW 一阶二阶动量+激活值逐项观察；4×micro-batch 累积 7.5M 模型显存峰值约 120 MiB；等效 batch 放大 4 倍不涨显存
5 预训练 AdamW(lr=3e-4, wd=0.1) + 余弦退火 T_max=1000 + 梯度裁剪 1.0 loss 6.23 → 0.31（50 步）→ 0.01（100 步后归零）
6 生成验收 temperature=0.8 采样，只取最后 max_len 个 token 喂入 训练前输出乱码 → 训练后整段复述语料原句
7 SFT 12 条 <\|user\|>…<\|bot\|>…<\|endoftext\|> 问答，lr 降一个量级到 1e-4，300 步 loss 8.5 → 0.2；生成到 <\|endoftext\|> 自然停住，超纲问题仍胡诌

关键工程点（逐条带证）：

  1. Sanity Check 不写代码：第 0 步 loss 应≈ln(词表实际大小)。428 词表理论值 ln(428)≈6.06，实测 6.23 ✅；若明显偏离（如 12 或 0.5）= 实现有 bug。实现正确性在第 0 步就能判死，不用等训完。
  2. 梯度累积三件套：zero_grad 放每个 step 开头（不是每个 micro-batch）；loss / ACCUM 再 backward（否则等效学习率被放大）；攒够统一裁剪+更新。
  3. 位置嵌入选可学习查表而非 RoPE/正弦——理由是最简单（两行代码），教学场景的正确取舍。
  4. Pre-Norm（先 LayerNorm 再进注意力/FFN）——训练更稳定。
  5. SFT 简化了 loss 掩码：真项目只对回答部分算损失（避免学提问），文中数据少直接省略，指向 TRL SFTTrainer 实现。
  6. <|endoftext|> 是停止信号——SFT 后生成函数必须加"采到即停"，否则答完继续续写。学会停比学会说更关键。
  7. loss 归零 = 背诵不是泛化：作者自己点破——玩具语料 8 句话整个背下来，困惑度 e^0.01≈1.01 只说明"十拿九稳地背"，不代表任何理解。

归纳总结

核心命题：训练管线的教学验证价值 = 让每个概念在手上跑起来。全篇没有一个新概念，但把"看似神秘的能力背后是一环扣一环的朴素工程"这句话变成了可复现的证据链。

  • 缩放定律的反向直觉应用：小模型配大数据 = 欠拟合（容量装不下规律）；小模型配小数据，loss 才降得漂亮——玩具规模的设计是刻意的，不是偷懒。
  • "loss 只是数字，真正的验收是让模型开口"——最终验收是生成质量（乱码→复述→对话），与训练指标分属两层。
  • 判实现正确性有免费的确定性锚点（初始 loss vs ln(vocab)），这类锚点的价值在于零成本排掉整类 bug。

指南分析

可复用实操要点：

  1. 判实现正确性：训练第 0 步 loss 对照 ln(词表实际大小)，偏离即停（先修实现再烧卡）。
  2. 梯度累积三件套口诀：开头清零 / loss 除以累积数 / 攒够统一更新。
  3. SFT 学习率比预训练降一个量级（3e-4→1e-4），防止破坏预训练语言规律。
  4. 生成函数两处必改：截断到 max_len / 采到 <|endoftext|> 停。

坑表：

坑 症状 解法
ByteLevel BPE 不配 decoder 中文解码乱码 tokenizer.decoder = decoders.ByteLevel()
词表按配置大小算参数 参数量虚高 用实际学到的词表大小（428 而非 2048）
把 loss 归零当能力 玩具语料上困惑度≈1 那是背诵；验收用生成 + 超纲问题测试
SFT 后生成不停 答完继续续写 采样循环里判 <\|endoftext\|> break

拓展应用推荐

  • 管线最小验证层：正式训领域模型前，先用玩具语料 1000 步跑通 tokenizer→模型→训练→生成四件套（分钟级 CPU 成本），把实现级 bug 挡在真数据真算力之前——可作为 domain-llm-training-pipeline 的前置冒烟层。
  • 教学素材：7 步 × 真实数字（6.23→0.01、7.48M、428）是讲"LLM 训练直觉"的现成案例库。
