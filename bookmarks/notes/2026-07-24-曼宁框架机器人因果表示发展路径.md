## 一、曼宁框架：五大命题

| 命题 | 核心论断 | 对应章节 |
|---|---|---|
| **1. 预测≠理解** | 纯预测系统学习P(下一状态\|当前观察)，但机器人需要P(下一状态\|do(动作)) | 第三章 |
| **2. 规划靠内部模拟** | "你只能通过在AI内部拥有一个模拟世界，来获得长期规划和智能" | 第四章 |
| **3. 模仿不如强化** | 模仿的性能上界=演示者；强化学习可涌现超越人类的能力 | 第五章 |
| **4. 语言不能驾驶** | 语言是说明书，不是驾驶员；VLM/LLM不应直接充当物理规划器 | 第六章 |
| **5. 表示须显式可控** | 显式3D表示+薄神经残差 > 纯潜在表示；可控性是应用核心 | 第七章 |

## 二、三维评价框架：效率—时间线—可控性

| 维度 | 含义 | 曼宁判定 |
|---|---|---|
| **效率** | 获得单位因果能力需要多少计算与数据代价 | 仿真 > 真机（3个数量级） |
| **时间线** | 技术路线到达可用需要多长日历时间 | 仿真可万倍并行；真机被物理时钟锁定 |
| **可控性** | 系统行为能否被稳定约束 | **"真正拉开差距的地方"** |

### 关键对比

| 指标 | 真机数据采集 | 仿真合成数据 |
|---|---|---|
| 数据效率 | 连续9个月人工演示 | **11小时等效78万条轨迹** |
| 标注成本 | 昂贵且不准 | **零（ground truth全在手上）** |
| 可并行性 | 不可 | 万级并行 |
| 成本曲线 | 恒定/递增 | **逐年指数下降** |

## 三、因果表示 vs 预测范式

### 3.1 预测的盲区

```
纯预测系统学习： P(下一状态 | 当前观察)     ← 训练分布内强
机器人真正需要： P(下一状态 | do(动作))     ← 分布外会崩溃
```

### 3.2 数据价值的重估

> "数据对训练模型一直没什么用——除非你理解正在被采取的动作，以及这些动作对世界产生的影响。"

| 数据类型 | 因果价值 | 产业定位 |
|---|---|---|
| 无动作标注的视频 | **近乎废料** | 当前行业巨额投入的误区 |
| 遥操作数据（无完整干预结构） | 低 | 大量隐性信息丢失 |
| 仿真数据（完整ground truth） | **极高** | 应承担规模化预训练主体 |
| 真机数据 | 校准用 | 仅占最终调优的~1% |

### 3.3 举一反三试金石：从拿碗到抱碗

- "拿"依赖指尖摩擦闭合（单件、轻质）
- "抱"依赖手臂-躯干接触面（多件、重载）
- 因果系统：理解"接触力如何支撑物体抵抗重力"→自动切换策略
- 轨迹记忆系统：只会在训练流形附近插值，超出即崩溃

## 四、仿真作为因果实验室

### 4.1 为何必须仿真

| 真实世界 | 仿真器 |
|---|---|
| 每秒=1秒，不可加速 | 万倍并行 |
| 不可回滚 | 可回滚、可重置 |
| ground truth匮乏 | **每个像素背后：深度/法向/分割/碰撞力/关节力矩全部可知** |
| 标注昂贵且不准 | 标注误差为零、成本为零 |

### 4.2 Sim-to-Real 弥合三法

| 方法 | 因果含义 |
|---|---|
| **域随机化** | 把未知物理参数θ视为混杂变量，对θ求边缘获得因果稳健策略 |
| **系统辨识** | 用真实数据反推仿真参数，因果机制逼近 |
| **真实数据微调** | 最后~1%校准 |

## 五、强化学习 vs 模仿学习

| 维度 | 模仿学习（行为克隆） | 强化学习 |
|---|---|---|
| 性能上界 | = 演示者（人类，非最优） | 自主涌现，可超越人类 |
| 泛化能力 | 训练流形内插值 | 因果变量空间泛化 |
| 因果理解 | 无反事实 | 完整干预结构 |
| 代表成果 | Mobile ALOHA（任务内成功） | 宇树后空翻/抗扰恢复（**超越人类**） |

### 因果训练飞轮

```
世界模型 → 因果表示 → 奖励结构 → 强化学习 → 探索反馈 → 丰富世界模型
    ↑_________________________________________________↓
  每一圈为下一圈积累资产：飞轮模式边际成本递减
```

## 六、语言的边界

> "语言是说明书，不是驾驶员。"

| 语言 | 物理世界 |
|---|---|
| 离散、低维、为交流优化 | 连续、高维、为演化优化 |
| 极度压缩→极度损失 | 接触力/摩擦/质心无法语言编码 |
| 适合任务下发/解释 | 不适合物理推演/规划 |

**工程结论**：语言→交互接口层；视觉→接回规划回路（回答"推它会怎样"）；像素竞赛→让位于因果竞赛。

## 七、显式表示与可控性

### 表示形式即命运

| 路线 | 效率 | 时间线 | 可控性 |
|---|---|---|---|
| 纯潜在表示（视频世界模型） | 差 | 差 | **无解** |
| 纯手工显式建模 | 受人工限制 | 慢 | 最优 |
| **显式3D + 薄神经残差** | **帕累托最优** | **好** | **好** |

### 可控性必须内生

> "可控性不应该靠外挂监控层，应该用本身的机制——基因里就应该控制了。"

- 外挂监控 = 事后安全（慢于事故一拍）
- 机制内生 = 先天安全（危险状态物理不可达）

## 十、路径重构：从预测到因果

### 旧模式五部件（需整体替换）

```
① 语言模型当大脑 ─┐
② 视频像素当世界   ├──→ 自锁循环：演示惊艳→落地翻车
③ 真机遥操作数据   │
④ 行为克隆训练   ─┤
⑤ 演示视频里程碑 ─┘
```

### 反推经济学

```
综合时薪 u = P / (Y × D × H) + C / H

P=整机价格, Y=年限, D=年工作日, H=有效工时, C=日均维护成本

关键：u < 人工时薪(30-50元) → 大规模替代到来
条件：因果能力→可靠性→有效工时H达标→u摊薄到阈值以下
```

### 五年三阶段路线

| 阶段 | 时间 | 目标 | 交付物 |
|---|---|---|---|
| **筑基** | 1-2年 | 仿真因果实验室+物理参数辨识 | 场景覆盖率80%+实机校准收敛 |
| **造血** | 2-3年 | 动作发生器+因果蒸馏→技能原语库 | 有效工时>14h、综合时薪<30元标杆产线 |
| **放大** | 3-5年 | 技能原语迁移+接口层产品化 | 3+任务族、可审计安全证明、规模化部署 |
