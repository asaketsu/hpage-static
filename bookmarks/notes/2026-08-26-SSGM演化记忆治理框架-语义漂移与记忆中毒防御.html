SSGM：LLM Agent 演化记忆的治理框架 — 语义漂移、记忆中毒与四原则防御

来源：Governing Evolving Memory in LLM Agents: Risks, Mechanisms, and the Stability and Safety Governed Memory (SSGM) Framework（arXiv 2603.11768，2026）

定位：Agent 记忆系统从"检索精度竞赛"转向"记忆完整性治理"的宣言式综述+框架论文。对本机 memory-refiner / evolver / experience-bank / MEMORY.md 体系有直接工程映射价值。

生成日期 2026-08-26

一、核心论点（TL;DR）

当 Agent 获得改写自身记忆的自治权，就引入了稳定性-可塑性困境的人工版本。 无治理的持续精炼会产生三类累积性、持久性错误——这与静态 RAG 的单次检索错误（孤立的、可隔离的）有本质区别：

失败接口 失败模式 机理
输入摄取（input ingestion） 记忆中毒（poisoning） 幻觉与恶意注入被固化为"有效知识"
记忆固化（consolidation） 语义漂移（semantic drift） 迭代摘要逐次丢失细节，逐渐扭曲真值
记忆检索（retrieval） 记忆幻觉（hallucination） 检索出不存在/已过期的"事实"

论文的核心主张：当前学界对"检索精度"的执念是不够的，下一代记忆系统必须优先考虑记忆完整性与安全性（memory integrity and safety）。

三、记忆如何演化：三大机制

3.1 反思（自监督）

Reflexion 范式："如果解错了，解释错误"→反思文本存为记忆。MemR3 把反思引入检索过程本身（迭代精炼查询弥合用户意图与存储知识的差距）。

3.2 强化学习（结果驱动优化）——形式化

记忆管理建模为 POMDP。记忆动作子空间显式定义：

A_mem = { Add(c), Update(idx, v), Delete(idx), Retrieve(q) }

优化目标：J(θ) = E_τ~πθ[ Σ γᵗ·r(sₜ, aₜ) ]——一个当下略亏的记忆写入，若大幅提升未来推理/检索，仍是优选。Memory-R1 用 PPO，MemAgent 用 GRPO。

3.3 固化与遗忘

无管理时 |M| 线性增长→检索延迟恶化。FiFA 基准证明有界、预算感知的遗忘策略（如 Priority Decay）不仅降成本，还主动保持叙事连贯性与隐私。

Weibull 时间衰减函数（Huang et al. 2025，LiCoMemory）：

w(Δτ) = exp( −(Δτ/η)^κ )
  • Δτ = 距上次有效检索的时间；η = 尺度参数（衰减时间尺度）；κ = 形状参数（遗忘曲线形状）
  • 比简单指数衰减更具表达力：κ 可表示"先快后慢"或"延迟遗忘"等不同领域的遗忘轮廓
  • 衰减后低于新鲜度阈值 θ_fresh 的记忆被剪枝/归档——缩小陈旧推理与记忆幻觉的攻击面

语义漂移的形式化：δ(M_T, K_true) = 1 − sim(E(M_T), E(K_true))——用当前记忆与不可变真值账本在嵌入空间的余弦距离作为漂移的可测代理。K_true 可用原始观测的不可变账本近似（保留迭代摘要丢失的细节）。

漂移的直观案例（论文 Fig.2）：温和的用户偏好经反复重写被逐级放大，最终造成具体的偏好违背。

五、SSGM 框架：四设计原则 + 形式化

核心思想：把 agent 的生成式认知策略与底层记忆基质，通过一个主动拦截的治理中间件结构性解耦。

5.1 四原则

# 原则 机制 灵感来源
1 固化前验证（Pre-Consolidation Validation） 记忆增量 ΔM 必须过写验证门：真值维护系统(TMS)检索核心事实 M_core，做严格逻辑矛盾检查——若 ΔM ∧ M_core ⊨ ⊥ 则拒绝写入；用 NLI 检查约束更新 生物海马体不即时提交感知到新皮层，先过滤+现实监控
2 时间与溯源接地（Temporal & Provenance Grounding） 读过滤门：候选记忆须有密码学溯源 σ(μ)（可信来源而非对抗提示）+ Weibull 衰减高于动态阈值 —
3 访问范围检索（Access-Scoped Retrieval） 语义相似度不够，查询执行层注入 ABAC 身份约束，隔离记忆子图，防 agent 人格/用户数据交叉污染 全连接记忆网络泄漏风险最大
4 可逆调和（Reversible Reconciliation） 双轨存储：快速可更新的可变活动图（Mutable Active Graph，供快语义推理）+ 只追加的不可变情景日志（Immutable Episodic Log，作为操作级真值源）。异步调和：周期性对原始交互轨迹"重放"校正漂移概念，行为严重退化时提供回滚 人类情景/语义记忆分工

5.2 形式化（公式照录）

读阶段（受约束检索）——语义 Top-K 之外叠加 ACL 与新鲜度双重过滤：

Cₜ = { μ ∈ Top-K(qₜ, M_{t-1}) | ACL(μ, u_id) ∧ (w(Δτ_μ) ≥ θ_fresh) }

两段式读路径：语义检索先提名候选，治理再过滤——同时防隐私泄漏与陈旧记忆激活。

写阶段（门控转移）——无约束系统 Mₜ = M_{t-1} ∪ Agent(Cₜ)；SSGM 拦截为：

Mₜ = M_{t-1} ∪ G_write(Agent(Cₜ), M_core)
其中 G_write(ΔM, M_core) = ΔM  当 ΔM ∧ M_core ⊭ ⊥；否则 = ∅

写变成守卫转移：只接纳不与受保护核心事实冲突的更新。

调和（漂移限界）——周期性对齐不可变账本：

M_clean ← argmin_M E[ δ( ℛ(M, K_ledger), K_true ) ]

三个参照对象各司其职：M_core 写时保护关键事实；K_ledger 是校正用操作级原始轨迹；K_true 是评估用理想目标。

5.3 定理 1（有界语义漂移）与证明思路

  • 假设：每个有效摘要/固化步引入至多 ε_step 语义误差；调和算子 ℛ 把记忆恢复到残差误差有界的状态。
  • 无治理：期望漂移 E[δ(M_T)] ≤ T·ε_step——随时间线性累积。
  • SSGM（每 N 步调和一次）：期望漂移上界 O(N·ε_step)——由调和窗口而非总时长决定，T≫N 时仍稳定。
  • 证明：未调和部分贡献 r·ε_step < N·ε_step（r<N 为余数），主导增长项被窗口大小 N 约束。

六、三大权衡（Limitations，诚实照录）

  1. 延迟-安全权衡：治理层给记忆环引入"System 2"验证步，逐次验证一致性+溯源带来显著延迟。方向：异步治理——乐观更新+后台周期"消毒"。
  2. 稳定性-可塑性冲突：严格一致性过滤可能致知识僵化——治理层激进拒绝与既有记忆冲突的信息，agent 无法适应合法环境变化（如用户搬家）。区分"漂移 vs 合法更新"的冲突消解协议是开放算法问题。
  3. 图结构可扩展性：图记忆推理能力强，但交互历史增长后图遍历与实体消解复杂度退化检索性能，需更高效的图剪枝/压缩。

本机已有的记忆/进化设施与 SSGM 原则对照：

SSGM 原则 本机现状 差距与建议
P1 写验证门 memory-write skill 有实体链接；但 MEMORY.md 追加无矛盾检查 P1 改进：新增记忆点与既有 MEMORY/USER PROFILE 做轻量 NLI 矛盾检查（可用免费模型 API 批量跑），冲突时打标人工复核而非直接写入
P2 时间衰减+溯源 MEMORY.md 有日期标注（如 08-25），但无衰减机制 P2 改进：僵尸清理已存在（08-25 归档 3 个不活跃 topic）；可升级为 Weibull 衰减打分——每次 memory-consolidation 时对 >30d 未引用条目降权而非直接归档
P4 双轨+调和 已有雏形：session DB（原始轨迹=事实账本）+ MEMORY.md（精炼摘要=活动图）；evolver 做错误→规则沉淀 P4 强化：evolver 增加"调和"模式——定期抽 MEMORY.md 条目回查 session DB 原始对话验证是否失真（尤其被多次改写的条目），对应 ℛ 算子
语义漂移风险点 MEMORY.md 条目被跨会话反复改写（如语音偏好条目改过 3+ 版） 建议对高频改写条目保留 git 历史或版本号，等效于不可变账本
过程漂移 error-case-library 与 experience-bank 的"经验卡片"可能固化次优工作流 SSGM 的"规则验证"对应：skill-review 定期回顾已有防退化机制，保持

一句话：本机"两个本本"（error-case-library + experience-bank）+ memory-refiner 体系在精神上已接近 SSGM 的双轨结构，主要缺的是写门（矛盾检查）与周期性调和（摘要回验原始会话）两个动作。
