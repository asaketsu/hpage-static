一、核心命题：机器人的"GPT-2 时刻"

预训练（VLA、世界-动作模型）已规模化，给了模型广而不稳的能力；行业缺的是标准化可复用的后训练配方，把"能做"变成"每次都可靠地做"。语言模型路径已收敛：SFT→RLHF→RLVR = 强底座+明确环境/奖励定义+锚定参考模型的 RL+reward hacking 监控。机器人需要等价方案，且可靠性要求更苛刻——"机器人的一次坏动作不会等人来审核，它直接就发生了"。

配方需要两样：①算法：十亿参数级稳定+极少量真实经验可学；②协议：成功定义/场景复位/人如何介入——目前全是手工活。

二、为什么机器人 RL ≠ LLM RL（三大结构性差异）

差异 LLM 机器人
样本成本 动作生成廉价/可并行/易验证 经验昂贵；"对真实物体的仿真可能比任务本身更难"→必须重用历史 off-policy 数据
时间形状 一回合=一条完整回复 抓一个杯子≈500 次决策（20ms 一拍），奖励只在链条末端→信用分配极难
随机性 低 物体滑落/传感器噪声/扰动→非确定环境进一步污染信用分配

三者共同把机器人推向 value-based RL——恰好是十亿参数规模上最缺验证的方法族。这是全文核心矛盾。

三、排除法地图：现有四路全不行

  1. Q 梯度反传去噪过程（Diffusion Q-Learning 系）：信号穿长去噪链，贵且不稳；蒸馏到 1-2 步牺牲表达力
  2. 采样后选择（EMaQ/SfBC/IDQL）：稳定，但策略本身从不学习，上限被底座提议能力封死
  3. 动作梯度引导去噪步（Psenka 2023/Fang 2024）：需精细正则化，易不稳定
  4. 输入噪声空间引导（Wagenmaker 2025）：低风险，但只能重组冻结模型已知行为，技能天花板由预训练决定

更深一层：经典 value-based RL（DDPG/TD3/SAC）假设高斯单峰策略，而前沿模型用扩散/流式生成表达多模态行为（抓杯柄 or 抓杯身）；且价值方法"靠预测自己的未来预测来学习，再把这些预测当真值使用"——自举误差在十亿参数规模被放大成不稳定。

四、EXPO-FT 三段式（大小模型分工+吸收回写）

  1. 编辑策略（edit policy）：轻量小模型对底座输出的候选动作做有界小幅修正——把动作从低价值区推向所在模态的价值高峰（图：橙点沿模态内爬坡，不跨模态）。RL 的全部不稳定性被限制在小模型里，一步小推不可能产生危险动作
  2. 执行时选择：底座采样若干候选→逐一编辑→价值函数挑最优执行（test-time selection）
  3. 吸收（absorption）：被选中且成功的动作回灌给预训练大模型继续训练——小编辑策略发现的改进被大模型全部容量消化，真正学到新行为而非噪声空间重组

人在环路=监督者（Waymo 远程安全员类比，一人看多车）。EXPO 三篇：EXPO（机制）→EXPO-FT（真机框架）→Real-Time EXPO-FT（慢速底座生成与快速反应式编辑解耦，用于快控制动态任务）。

实验：六任务（彩灯绕钩走线+插电点亮/台球进球/花插酒瓶口/翻鸡蛋/平衡球）30/30 全成功，平均仅 19 分钟在线交互，碾压 SFT on π0.5、HG-DAgger、DSRL、HIL-SERL（平均 5.5-20.5）。前沿预训练模型事前无法可靠完成这些任务。

五、诚实的边界（作者自述三条未解决）

  1. 人在环路程度仍大：人定义成功/复位/干预——可扩展（Waymo 式一人多机）但未量化
  2. 长视野压迫价值函数：安全性依赖价值估计质量，数千步+末端奖励的信用分配只测了短视野端
  3. 计算成本高：19 分钟交互 ≠ 19 分钟后训练——大模型梯度更新主导墙钟时间

六、标准协议五问（"Universal"的真正所指）

协议问题 现状 候选方向
奖励指定 机器人无 RLVR 等价物；成功检测器逐任务手建或人盯轨迹 学习型成功分类器/奖励模型
复位 通常是人的活 学习型复位策略/可逆任务设计/干脆不复位换下一任务
人介入 证明有用但多少/何时/如何用未知 直接决定能否扩展过"一机一人"
超参默认值 value-based RL 敏感且无公认默认（lr/UTD/停止准则/时域/控制频率） 已发布 EXPO-FT 调参参考作第一步
初始化数据 加权/内容/规模无答案（LLM 已有答案） 开放

七、💡 对我们的价值分析（DUCK 视角逐条对照）

✅ 已在做的（印证程度惊人）

  • "广而不稳→后训练求可靠" = DUCK 全部工作的问题定义（G/H/S 系全是"把能站变成每次都站"）
  • 奖励指定之难 = 我们的判据按任务家族定制铁律（velstand/standup tag 地图）+ 真实位移验收——正是在补"成功定义"协议
  • 复位协议 = 我们的开训门禁+spawn 探针+keyframe 逐值复制——复位错误=白训的教训吃过三轮
  • 人在环路 = 用户清晨验收/悬空确认/拍板文化——"kill 决策等拍板"就是 human-in-loop 的实例化
  • reward hacking 监控 = 站桩检测/ep_len 假象/fake burst peak_height gate——三案在册

⚠️ 可改进的（差距=机会）

  • 编辑策略思路可移植：DUCK 现在是"整策略重训"，EXPO 的"小模型有界修正+吸收回写"提供中间档——换域时冻结主干只训 edit head（LoRA），可能比 warm start 全网微调稳
  • 执行时选择：asa 播放器只跑单策略——采样 N 候选+价值挑优的 test-time selection 可作为 sim 评测增强
  • UTD/停止准则无默认正是我们"止损器门禁贴收敛值"原则的学术对应——可引用加固

八、内容整理（归纳总结与关联分析）

归纳总结：机器人处 LLM 的 GPT-2 时刻——预训练广而不稳，缺标准化后训练配方。三大结构差异（样本贵须 off-policy/长链信用分配难/环境非确定）→ 推向 value-based RL → 恰是十亿参数最缺验证的方法族 → 四路现有方法排除法全灭（贵不稳/不学习/需精调/天花板）→ EXPO-FT 三段式（小模型有界编辑+执行时价值选择+成功动作吸收回写大模型）→ 六任务 30/30、19 分钟在线交互。诚实边界三条+协议五问（奖励/复位/人介入/超参/初始化）。关键数字：30/30、19min、基线 5.5-20.5、抓杯≈500 决策。

关联分析：与同日 [[2026-09-28-Agent即策略模型-四层解剖与跨体系验证]] 构成完美对偶——那篇说"Agent=控制循环里的策略模型"，本篇是物理世界的同名命题：机器人=控制循环里的 VLA 策略模型，且两个世界的"策略改进"面临同构难题（信用分配/reward hacking/验证器缺位）。EXPO 的"编辑策略"与 Jev 的"决策层"是同一个思想的两种投影：把不稳定性装进小而可控的盒子里，让大模型保持安全。DUCK 项目是这两个理论的最小实验场。

十、趋势判断

  1. 机器人后训练将复刻 LLM 的"SFT→RLHF→RLVR"剧本，2-3 年内出现社区默认配方（lr/UTD/停止准则有默认值）——EXPO-FT 的调参参考是第一块砖
  2. "编辑策略"模式会扩散：冻结大模型+小模型有界修正+吸收回写，将成为"大模型时代增量学习"的标准形态（LLM 侧对应：LoRA+merge 的 RL 版）
  3. 学习型成功分类器成为热点赛道：机器人版 RLVR 的缺口就是机会——与 Jev 决策层（判断不生成）完全同构，可能被同一批决策模型填掉
  4. 快慢解耦成为 VLA 部署标配：慢速规划（大模型）+快速反应（小编辑器）的双频架构，正好匹配舵机 50Hz 控制现实——DUCK 的 Pi5 管线已经是这个形状的雏形

十一、指南分析（怎么用这篇文章）

  • 判断自己是否需要后训练配方：数一数"每任务手工定义成功+人复位+人盯轨迹"的工时——占比过半就该读这篇
