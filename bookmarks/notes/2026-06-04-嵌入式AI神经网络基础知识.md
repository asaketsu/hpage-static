## 一、输入/输出/张量/形状

### 样本·特征·标签

| 概念 | 含义 | 示例 |
|:---|:---|:---|
| 样本 | 一条可训练/推理的数据 | 连续 128 个时刻的三轴加速度 |
| 特征 | 模型真正看到的输入值 | 128×3 个数字 |
| 标签 | 训练时的标准答案 | 0=静止, 1=走路, 2=跑步 |

### 常见输入 Shape

| Shape | 含义 |
|:---|:---|
| `(1, 128)` | 单条一维序列 |
| `(1, 128, 3)` | 多通道时间序列 |
| `(1, 32, 32, 1)` | 单张灰度图 |
| `(1, 40)` | 特征向量 |

MCU 部署时 batch size 通常为 1。

**三大致命错误**：训练用 `(128,3)` 部署按 `(3,128)` 填；训练归一化部署送原始值；训练 float32 部署 int8 不做 scaling。

## 二、神经元·权重·偏置·激活函数

### 数学模型

```
y = activation(w1*x1 + w2*x2 + ... + wn*xn + b)
```

- **权重 w**：每个输入的重要性
- **偏置 b**：整体偏移
- **参数量 = 输入×输出 + 输出**（直接决定 Flash 占用和推理速度）

### 激活函数速查

| 函数 | 公式 | 适用场景 |
|:---|:---|:---|
| **ReLU** | max(0,x) | 隐藏层默认选择，部署最友好 |
| **Sigmoid** | 1/(1+e⁻ˣ) | 二分类输出层 |
| **Tanh** | -1~1 | 部分时序任务 |
| **Softmax** | 概率归一化 | 多分类输出层 |

**无激活函数 → 多层全连接 = 一个线性变换**，非线性能力为零。

## 三、网络层与嵌入式适配

### 全连接层（Dense）

- 参数量爆炸：输入 128 × 输出 64 = **8,256 参数**
- MCU 上可用但不能无限堆大

### 卷积层（Conv）

- 用小窗口滑动提取局部模式，参数高效
- 适合图像、音频频谱、时序局部模式
- **注意**：卷积核大小/通道数/特征图尺寸影响 RAM 压力

### 辅助层

| 层 | 作用 |
|:---|:---|
| Pooling | 压缩特征图，减少计算和 RAM |
| Flatten | 多维摊平一维，接 Dense |
| Normalization | 稳定训练，部署时检查是否可折叠 |

### 输出层配置

| 任务 | 输出层 | 后处理 |
|:---|:---|:---|
| 二分类 | 1 神经元 + Sigmoid | > 阈值判正 |
| 多分类 | N 神经元 + Softmax | 取最大概率 |
| 回归 | 线性输出 | 直接读数值 |

## 四、训练阶段核心知识

### 损失函数

| 任务 | 常用损失 |
|:---|:---|
| 回归 | MSE / MAE |
| 二分类 | Binary Cross Entropy |
| 多分类 | Categorical Cross Entropy |

### 训练 vs 推理

| 阶段 | 操作 |
|:---|:---|
| **训练** | 前向 + 误差 + 反向传播 + 参数更新 |
| **推理** | 仅前向计算 |

MCU 只做推理——训练太耗算力/内存/时间。

### 过拟合判断

```
epoch 1:  train_acc=0.72  val_acc=0.69
epoch 10: train_acc=0.96  val_acc=0.75  ← 训练↑验证↓ = 过拟合
epoch 20: train_acc=0.99  val_acc=0.71  ← 继续训练无意义
```

应检查：数据量、分布、模型大小、正则化、数据增强。

### 评估指标

| 指标 | 关键场景 |
|:---|:---|
| Accuracy | 类别均衡时参考 |
| **Precision** | 误报成本高时重要 |
| **Recall** | 漏报成本高时重要（异常检测必看） |
| F1-score | 类别不均衡时常用 |

**铁律**：漏掉异常比多报更严重 → 重点看 Recall。

## 五、嵌入式 AI 特有知识

### 量化

| 类型 | 每参数字节 | 特点 |
|:---|:---|:---|
| float32 | 4 | 精度高，占空间大 |
| float16 | 2 | 更小，MCU 上不一定最优 |
| **int8** | **1** | **嵌入式部署最常见** |

20K 参数模型：float32 ≈ 78KB → int8 ≈ 19.5KB，差距 4 倍。

量化公式：`real_value ≈ scale × (quantized_value - zero_point)`

### 部署四维检查清单

| 维度 | 决定什么 |
|:---|:---|
| **参数量** | Flash 占用 |
| **激活内存** | RAM 压力 |
| **MAC 数量** | 计算负担/推理速度 |
| **算子支持** | 框架能不能跑 |

### 模型判断六步法

1. 输入 shape → 传感器数据能否组织成该格式？
2. 输出含义 → 部署后如何解释？
3. 层类型 → 目标推理框架是否支持？
4. 参数量+运算量 → MCU 资源够不够？
5. 量化状态 → 精度可接受？
6. 前处理流程 → 能否在嵌入式端完整复现？
