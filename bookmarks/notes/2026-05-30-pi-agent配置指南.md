## 什么是 Pi？

Pi（Pi Coding Agent）是 OpenClaw 背后的编码智能体框架，核心设计哲学：**极简**。

0 配置的 Pi Agent 只支持 4 种工具：`bash`、`read`、`write`、`edit`。

没有 MCP、没有 sub-agents、没有 plan mode、没有 permission popups。**一切都没有，都需要自己配置。**

> 如果你想要开箱即用的 coding agent，可以转向 Codex 和 Claude Code。

Pi 保持内核精简，将工作流相关行为推向了**扩展（Extensions）、Skills、提示词模板（Prompt Templates）以及包（Packages）**。

---

## 三大核心抽象

### 1. Extension（扩展）

TypeScript 模块，扩展 Pi 的行为。位置：`.pi/agent/extensions/*`，Pi 会自动发现，支持 `/reload` 热更新。

**关键能力：**

- **自定义工具/命令**：`pi.registerTool()` + `pi.registerCommand()`
- **事件拦截**：阻止或修改工具调用、注入上下文、自定义压缩（丰富的 [Lifecycle 事件](https://pi.dev/docs/latest/extensions#events)）
- **用户交互/界面渲染**：自定义 QA 问答框、Editor 样式、甚至等待时的小游戏
- **会话持久化**：`pi.appendEntry()` 存储重启后仍保留的状态

> 在 AI 时代，不必手写 lua 代码，直接对 Pi 说需求让它自己写扩展，热加载即生效。

### 2. Prompt Templates（提示词模板）

类似 Claude Code 的自定义斜杠命令。格式：带 front-matter 的 Markdown 文件。

- `description`：下拉菜单描述（可选）
- `argument-hint`：参数提示（可选）
- 支持位置参数 `$1`、`$2` 和切片 `${@:N}`

### 3. Pi Package（包）

Extensions + Skills + Prompt Templates + Themes 的集合，可通过 git 或 npm 分享安装。

> ⚠️ **安全警告**：Pi 包以完整系统权限运行，扩展可执行任意代码。安装第三方包前务必审查源代码。

## 推荐 Pi Package（Top 10）

截至 2026 年 5 月，[pi.dev/packages](https://pi.dev/packages) 已收录 **3,328+** 个包。

| 包名 | 功能 |
|------|------|
| **context-mode** | 节省 98% 上下文窗口，沙箱执行 + FTS5 知识库 + 意图驱动搜索（几乎必装） |
| **pi-subagents** | 子代理委派，链式调用 + 并行执行 + TUI 确认 |
| **pi-mcp-adapter** | MCP 适配器，连接外部 MCP 服务器扩展工具能力 |
| **pi-web-access** | Web 搜索、URL 抓取、GitHub 克隆、PDF 提取、YouTube 理解 |
| **pi-lens** | 实时代码反馈：LSP、linter、formatter、类型检查、结构分析 |
| **pi-simplify** | 自动审查变更代码的清晰度/一致性/可维护性 |
| **@juicesharp/rpiv-todo** | 持久化 TODO 列表，reload/压缩后仍保留 |
| **@plannotator/pi-extension** | 交互式计划审查与批注，适合复杂任务前方案评审 |
| **@narumitw/pi-goal** | `/goal` 模式，保持代理工作直到任务完成 |
| **@narumirw/statusline** | 丰富状态栏：模型、工具、git 分支、上下文、token、费用、时间 |

## 个人思考

Pi 的设计哲学与 Hermes Agent 有异曲同工之处——内核极简、扩展在外。不同的是 Pi 聚焦编码场景（类似 Claude Code 的定位），而 Hermes 面向通用 Agent 场景（IM 网关 + Cron + 多平台）。两者都体现了"乐高式组装"的趋势：**用户用自然语言描述需求，Agent 自己写插件**。
