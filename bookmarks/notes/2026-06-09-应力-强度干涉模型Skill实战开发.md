# 应力-强度干涉模型Skill实战开发

> 来源：微信公众号「可靠性不可靠」 | 作者：千堇年 | 2026-06-07
> URL: https://mp.weixin.qq.com/s/drKEUvWZLXXaZFlFnJEobQ

## 简介

一篇面向工程可靠性分析的 AI Skill 开发实战文章，展示如何将**应力-强度干涉模型**（Stress-Strength Interference Model）封装为可复用的 AI Agent Skill，实现从数据输入到报告生成的全流程自动化。

## 核心要点

| 模块 | 内容 |
|------|------|
| **模型** | 应力-强度干涉模型 — 概率论可靠性分析的经典方法 |
| **支持分布** | 正态、对数正态、威布尔 |
| **计算算法** | 解析法、FOSM、SOSM、蒙特卡洛模拟(MCS)、威布尔迭代 — 共5种 |
| **输出** | 可靠度R、失效概率Pf、可靠性指数β、安全裕度 |
| **扩展分析** | 参数灵敏度分析（±5%/±10%扰动） |
| **报告** | HTML/Word 自动生成，含干涉分布图、可靠度曲线、灵敏度图 |

## 六步执行流程

```
数据输入 → 概率分布拟合 → 多算法计算 → 灵敏度分析 → 可视化 → 报告生成
```

### 关键设计决策

1. **多算法对比**：正态/对数正态用解析法（精确），威布尔必须迭代法，其余用FOSM/SOSM/MCS
2. **数据校验前置**：标准差>0、异常值检测（3σ外）、威布尔禁用解析法
3. **灵敏度梯度**：严格±5%/±10%微扰动，输出灵敏度系数+重要度权重+风险排序
4. **性能约束**：单组≤1s，批量50组≤5s，图表≤3s

## Skill 架构

```
skill/
├── references/
│   ├── algorithms.md          # 5种算法数学模型
│   └── distribution_params.md # 分布参数与拟合方法
└── scripts/
    ├── stress_strength_calculator.py  # 核心计算
    ├── sensitivity_analyzer.py        # 灵敏度分析
    └── report_generator.py            # 报告生成
```

## 五种算法适用场景

| 算法 | 适用场景 | 精度 | 速度 |
|------|---------|------|------|
| **解析法** | 正态+正态 / 对数正态+对数正态 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **FOSM** | 快速估算、任意组合 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **SOSM** | 精确计算、任意组合 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **MCS** | 高精度验证 | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **威布尔迭代** | 含威布尔分布 | ⭐⭐⭐⭐ | ⭐⭐⭐ |

## 💡 对我们的价值分析

### ✅ 已在做的
- Skill 架构（references/ + scripts/ 分层）与我们的 Skill 规范一致
- 多算法降级/对比选择模式

- **报告模板借鉴**：HTML 报告自动生成+图表嵌入的模式值得推广到其他工程 Skill
