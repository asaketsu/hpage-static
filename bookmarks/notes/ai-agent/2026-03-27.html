[⭐⭐⭐⭐⭐] jina-cli — 轻量级 Jina AI Reader CLI

[⭐⭐⭐⭐⭐] feedgrab — 万能内容抓取器

  • 来源: https://github.com/iBigQiang/feedgrab
  • 分类: 工具
  • 摘要: 从 8+ 平台（微信、小红书、X、YouTube、B站、Telegram、RSS、GitHub）抓取、转录和消化内容。支持 CLI/Python 库/MCP 服务器四种方式，输出统一 Markdown。
  • 关键要点:
  • 平台覆盖最全：微信(搜狗搜索+专辑+历史)、小红书(搜索+用户)、X(书签/推文/列表)、YouTube(视频/音频/字幕)、B站、Telegram、RSS、GitHub
  • 多平台搜索：x-so、xhs-so、mpweixin-so、ytb-so
  • 批量抓取：X 书签、用户推文、Twitter 列表、公众号历史文章
  • 视频转录：Whisper 转录；下载：YouTube MP4/MP3/SRT
  • 输出统一格式：output/平台/作者_日期：标题.md，支持按日期过滤、汇总表格(MD+CSV)
  • 实施建议:
  • 强烈推荐：目前开源生态平台覆盖最广的内容抓取工具
  • 安装 Python CLI 版本，测试公众号和 X 抓取效果
  • 搭配 OpenClaw 实现：多平台采集 → AI 分析 → 书签笔记全链路

[⭐⭐⭐⭐] AI时代最吃香的五种职业

  • 来源: https://mp.weixin.qq.com/s/yFQE-YDP_ASxe5s3UnZ7Gg
  • 作者: 野未央 / 100层未央（2026-03-27）
  • 分类: 行业洞察 / 职业规划
  • 摘要: 基于黄仁勋「AI是一个五层蛋糕」理论，梳理AI时代五类稀缺职业。
  • 关键要点:
  • AI应用开发者（第5）：领域知识+AI工具=复合人才，考的是对世界的理解不是编程
  • AI模型工程师（第4）：年薪50-100万，门槛极高，少数人的游戏
  • AI基础设施工程师（第3）：液冷散热/组网调度，全球疯抢的硬核基建人才
  • 芯片工程师（第2）：算力尽头是半导体，字节已组建千人芯片团队
  • 电力与能源工程师（第1）⚡：AI终点是能源，训练GPT-4耗电4万度，巨头都在抢购电厂
  • 核心观点: 别只盯着互联网红利，底层基建（电力、半导体、基础设施）才是AI时代最确定的机会
  • 实施建议: 长期关注能源+AI交叉领域，底层基建比应用层更稳

[⭐⭐⭐⭐⭐] opencli — 任意网站/Electron应用的CLI化工具

  • 来源: https://github.com/jackwener/opencli
  • 分类: 工具
  • 摘要: 将任意网站、Electron 应用、本地 CLI 工具转化为标准化命令行接口。通过复用 Chrome 登录状态实现零风险操作，50+ 站点预置适配（B站、知乎、小红书、X、Reddit、YouTube 等），零 LLM 消耗、确定性输出。
  • 关键要点:
  • 核心卖点: 零 LLM 成本、确定性输出（同命令同结果）、可管道/脚本/CI
  • 平台覆盖: 50+ 站点（国内外），支持 Electron 应用控制（如 Antigravity Ultra）
  • 安全设计: 复用 Chrome 登录态，凭证不离开浏览器
  • AI Agent 友好: opencli list 发现可用工具，支持 AGENT.md / .cursorrules 配置自动调用
  • 双引擎: YAML 声明式 + TypeScript 浏览器注入
  • 与 feedgrab 对比: feedgrab 侧重抓取+内容提取，opencli 侧重网站交互+操作自动化
  • 实施建议:
  • 与 feedgrab 互补：opencli 负责登录态操作和结构化数据提取，feedgrab 负责批量内容抓取
  • 需要 Chrome 运行，我们的无头服务器需要确认是否有 Chrome 环境
  • 值得长期关注，AI Agent 生态的重要基础设施
