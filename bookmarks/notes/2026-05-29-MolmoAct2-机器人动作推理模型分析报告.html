二、核心问题：它解决什么？

具身智能（Embodied AI）领域的核心瓶颈：

  1. 闭源模型无法部署 — Frontier 模型（GPT-5、Gemini Robotics）闭源，无法在真实机器人上运行
  2. 开源模型性能不足 — 现有开源 VLA 模型成功率低，达不到可靠部署门槛
  3. 推理延迟过高 — 推理增强型策略（reasoning-augmented）为获取 grounding 支付高昂延迟代价
  4. 硬件依赖昂贵 — 开源模型往往需要昂贵硬件才能运行
  5. 动作 Tokenizer 闭源 — Physical Intelligence 的 FAST tokenizer 闭源，社区无替代方案

MolmoAct2 的解法：构建一个"完全开源、面向真实部署"的动作推理模型，在性能、速度、开放性三个维度同时突破。

3.2 五大技术突破

突破点 技术细节 效果
① Molmo2-ER VLM Backbone 基于 SigLip2 + Qwen2.5-7B/72B，3.3M 样本 specialize-then-rehearse 训练 13 个具身推理基准平均 63.8/100，超越 GPT-5、Gemini 2.5 Pro、Qwen3-VL-8B、GR-ER 1.5
② Per-Layer KV-Cache Conditioning DiT 风格 Action Expert 在每一层 cross-attend 到 VLM 的 projected KV，而非仅最终 hidden state 复用已计算信息，延迟降低 37x（相比 MolmoAct v1）
③ Flow-Matching 连续动作专家 训练时用离散动作 Token，推理时用流匹配预测连续动作 chunk 动作流畅精准，支持 450ms/动作（base）或 1300ms（MolmoThink）
④ OpenFAST 动作 Tokenizer 开源权重 + 开源训练数据，跨 5 种机器人形态训练 替代 PI 闭源 FAST，社区可用
⑤ MolmoThink 自适应深度推理 仅对场景变化区域重新预测深度 token，保留几何 grounding 推理延迟大幅降低

3.3 关键架构创新：Per-Layer KV-Cache Conditioning

这是 MolmoAct2 最核心的架构设计：

传统 VLA 的做法：VLM 输出最终 hidden state → 传给 Action Head → 预测动作。问题：VLM 的中间层空间推理信息在最终输出中被压缩丢失。

MolmoAct2 的做法：Action Expert（DiT 风格）在每一层都 cross-attend 到 VLM 的 projected KV cache。这意味着：
- 浅层 VLM 的视觉细节信息被保留
- 深层 VLM 的语义推理信息也被保留
- Action Expert 可以"看到"VLM 的完整推理过程
- 同时复用 KV cache，避免重复计算

VLM Layer 1 KV → Action Expert Layer 1
VLM Layer 2 KV → Action Expert Layer 2
...
VLM Layer N KV → Action Expert Layer N

十一、评价与局限

✅ 优势

  • 完全开源 — 权重、代码、数据全部开放，无供应商锁定
  • 性能领先 — 超越 π0.5，具身推理超越 GPT-5
  • 推理速度快 — 450ms/动作，37x 加速
  • LeRobot 原生 — 开箱即用，降低使用门槛
  • 双手机器人 — 最大开源双手机器人数据集
  • 自适应推理 — MolmoThink 大幅降低延迟

⚠️ 局限

  • 参数量限制 — 7B 版本在复杂任务上可能不足，72B 版本推理成本较高
  • 硬件依赖 — 虽然比 v1 快，但仍需要 GPU 支持
  • 真实场景覆盖 — 当前数据集以桌面操作为主，工业/户外场景数据有限
  • 安全性 — 模型输出的动作需要外部安全约束层（速度、力矩、工作空间限制）
  • 社区规模 — 相比 PyTorch/Transformers 等成熟生态，机器人学习社区仍在成长

十二、结论

MolmoAct2 代表了具身智能领域的开源拐点：它不仅在性能上首次超越闭源竞品（π0.5），更在开放性上树立了行业标杆——权重、代码、数据全部开放。

核心价值不在于模型本身，而在于它验证的"完全开源 VLA 可真实部署"这一范式。对于我们的项目，最值得吸收的三点：

  1. Per-Layer KV-Cache Conditioning — 架构级创新，VLM + Action Expert 的高效连接方式
  2. OpenFAST Tokenizer — 开源动作 Tokenizer 替代闭源方案，降低供应链风险
  3. LeRobot 全链路集成 — 训练→评估→部署的标准化流程可复用

一句话总结：MolmoAct2 让"用开源模型控制真实机器人"从概念验证走向了工程可行。
