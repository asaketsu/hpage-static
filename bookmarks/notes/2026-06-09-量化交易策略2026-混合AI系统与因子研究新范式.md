## 一、2026 年量化策略全景图

### 1.1 九大量化策略类别（Quantt Finance 总结）

| # | 策略 | 持仓周期 | 边际来源 | 现实 Sharpe |
|---|------|---------|---------|------------|
| 1 | 统计套利 | 小时-天 | 相关资产均值回归 | 1.0-2.0 |
| 2 | 配对交易 | 天-周 | 协整 + 相对价值回归 | 0.8-1.5 |
| 3 | 做市商 | 毫秒-秒 | 买卖价差 + 库存管理 | 3.0-8.0+ |
| 4 | 动量/趋势跟踪 | 周-月 | 价格趋势持续性 | 0.5-1.0 |
| 5 | 均值回归（截面） | 天 | 短期过度反应反转 | 0.6-1.2 |
| 6 | 机器学习 | 天-周 | 模式检测 + 特征工程 | 0.5-1.5 |
| 7 | 期权波动率/波动套利 | 天-周 | 波动率曲面定价偏差 | 0.8-2.0 |
| 8 | 高频交易 | 微秒 | 延迟 + 微观结构 | 5.0-20.0+ |
| 9 | 加密量化 | 变动 | 资金费率、基差、链上低效 | 1.0-3.0+ |

> ⚠️ **Sharpe > 3 应警惕方法论错误**（前视偏差、幸存者偏差、多重测试）。高频/做市商的高 Sharpe 反映了低边际策略上的激进杠杆使用。

### 1.2 策略选择矩阵

```
个人量化 → 统计套利/配对交易/均值回归/机器学习
小型团队 → 多因子模型 + 期权波动率
机构级 → 全品类（做市/HF 需要基础设施投入百万级）
```

## 二、混合 AI 交易系统：多模态信号融合（arXiv:2601.19504）

### 2.1 系统架构

ComSIA 2026 接收论文，提出了五层混合架构：

```
Layer 1: 趋势跟踪 → EMA + MACD → 方向性动量捕获
Layer 2: 均值回归 → RSI + Bollinger Bands → 价格归一化检测
Layer 3: 情绪分析 → FinBERT → 市场心理解读
Layer 4: ML 信号 → XGBoost → 综合信号生成
Layer 5: 市场状态过滤 → 波动率 + 收益环境 → 动态敞口调整
```

### 2.2 核心成果

| 指标 | 值 |
|------|-----|
| 最终组合价值 | $235,492.83 |
| 总收益率 | **135.49%** |
| 回测期 | 24 个月 |
| 基准对比 | 超越 S&P 500 和 NASDAQ-100 |
| 关键优势 | 多市场状态适应性 + 低下行风险 |

### 2.3 技术细节

**情绪分析集成**：
- FinBERT（金融领域预训练 Transformer）实时分析新闻标题和财报
- 情绪评分阈值：低于 -0.70 时暂停主动交易
- **风控价值**：纯技术策略在突发新闻（SEC 调查、季度业绩暴雷）前完全暴露，FinBERT 层提供"新闻风控"

**市场状态过滤**：
- 基于波动率和收益环境动态调整持仓
- 高波动 → 减仓；低波动稳定期 → 加仓
- 解决传统策略在"状态切换"时失效的核心痛点

**信号融合**：
- XGBoost 不直接预测价格，而是**融合 Layer 1-3 的多源信号**
- 输入特征：EMA 斜率、MACD 直方图、RSI 值、Bollinger 带宽、FinBERT 情绪分数
- 输出：综合交易信号（买入/卖出/持有 + 置信度）

### 2.4 关键洞察

1. **孤立策略的失败模式**：
   - 趋势跟踪在横盘市场失效（EMA/MACD 频繁假信号）
   - 均值回归在强趋势市场失效（RSI/Bollinger 过早入场）
   - 纯 ML 模型在市场状态切换时泛化能力差

2. **混合系统的价值**：不是"更多模型更好"，而是**不同类型的信号互补**：
   - 技术指标捕捉价格模式
   - 情绪分析捕捉突发信息
   - 市场状态过滤捕捉宏观环境变化

## 三、机器学习在量化中的角色演进

### 3.1 监督学习（主流）

| 模型 | 适用场景 | 优势 |
|------|---------|------|
| **XGBoost/LightGBM** | 表格数据预测（核心工具） | 高效、可解释、处理缺失值 |
| **Random Forest** | 需要解释性的场景 | 对异常值鲁棒 |
| **神经网络** | 非结构化数据（财报 NLP） | 自动特征学习 |
| **Lasso/Ridge/Elastic Net** | 透明度要求高的场景 | 正则化线性模型，仍在广泛使用 |

### 3.2 强化学习（前沿）

训练 Agent 做序列交易决策，最大化累计 PnL。关键挑战：
- **奖励设计**：金融市场的噪声奖励信号比游戏/机器人差几个数量级
- **过拟合风险**：RL Agent 容易"记住"特定市场环境而非学到通用策略
- **交易成本建模**：忽略滑点和冲击成本的 RL 策略在实盘中必然失败

### 3.3 因子研究的现代工作流

```
数据采集 → 特征工程 → 因子构建 → IC/IR 评估 → 组合优化 → 回测 → 实盘
   ↑                                                           ↓
   ←←←←←←←←←← 失败时回到上一步 ←←←←←←←←←←←←←←←←←←←←←
```

**特征工程仍然是最关键的环节**。机器学习模型的优势在于处理高维特征空间，但"Garbage In = Garbage Out"在量化中比任何领域都更残酷。

## 四、与 Hermes 量化系统的关联

### 4.1 现有 Skill 的对标

| 现有 Skill | 论文对应 | 改进方向 |
|-----------|---------|---------|
| `iwencai-stock-screener` | Layer 1 趋势跟踪 | 可扩展加入情绪分析层 |
| `quant-trading` | Layer 4 ML 信号 | XGBoost 信号融合可参考 |
| `a-stock-lianban-strategy` | Layer 5 状态过滤 | 需要增加市场状态检测（波动率+收益环境） |
| `llm-factor-mining` | Layer 3 情绪分析 | 可直接对接 FinBERT |

### 4.2 可直接复用的技术

1. **FinBERT 情绪分析**：在 Jetson Orin 上部署 FinBERT（110M 参数），量化后可在 <100ms 内完成推理。结合已有的 `nexa-local-inference` Skill 可快速实现
2. **市场状态分类器**：用波动率百分位数 + 趋势强度构建 4 状态分类（低波动上涨/低波动下跌/高波动上涨/高波动下跌），每个状态对应不同的策略参数集
3. **XGBoost 多信号融合**：将技术指标、情绪分数、市场状态作为特征，训练信号融合模型

### 4.3 A 股特异性

论文基于美股验证，A 股应用需注意：
- **T+1 限制**：日内动量策略需调整持仓周期
- **涨跌停板**：极端波动时无法交易，需要在回测中建模
- **北向资金**：A 股特有信号源，可作为额外因子
- **监管环境**：高频/做市策略在国内受限，个人量化更适合统计套利 + 机器学习路线

## 五、策略评估的防坑指南

### 5.1 常见过拟合陷阱

| 陷阱 | 症状 | 解法 |
|------|------|------|
| 前视偏差 | Sharpe 异常高（>3） | 严格 Walk-Forward 验证 |
| 幸存者偏差 | 策略只回测现存股票 | 使用点-in-time 股票池 |
| 多重测试 | p-hunting 后"发现"显著因子 | Bonferroni 校正 / 最低通过率 |
| 交易成本忽略 | 理论收益好但实盘亏损 | 至少 10bp 单边交易成本 |
| 过拟合 | 回测好但样本外崩盘 | 跨时间段 / 跨市场验证 |

### 5.2 评估指标优先级

```
实盘 Sharpe > 样本外 Sharpe > 回测 Sharpe
最大回撤 > 年化波动率 > 总收益
IC 均值 > IC_IR > 单次 IC
```
