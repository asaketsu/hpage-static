     1|# Claude Code 的四层记忆架构与人类大脑记忆的同构性

     9|
    10|## 核心观点
    11|
    12|Claude Code 的四层记忆架构（CLAUDE.md → Auto Memory → Session Memory → Auto Dream）与人类大脑的三层记忆系统（感官记忆 → 短期记忆 → 长期记忆）几乎同构。AI 的"做梦"（Auto Dream）机制与人类睡眠中的记忆巩固过程高度相似——不只是加强记忆，还有选择性遗忘。
    13|
    14|## Claude Code 的四层记忆
    15|
    16|| 层级 | 名称 | 类比人类 | 功能 |
    17||------|------|----------|------|
    18|| L1 | CLAUDE.md | 习得规则/教育 | 手写的最高权限指令，项目规范、编码标准 |
    19|| L2 | Auto Memory | 工作笔记 | Claude 工作中自动记录的笔记 |
    20|| L3 | Session Memory | 短期记忆 | 单次对话上下文，结束后消失（JSONL 保留） |
    21|| L4 | Auto Dream | 睡眠记忆巩固 | 后台定期清理、整理、优化 Auto Memory |
    22|
    23|## 人类记忆三层架构（对照）
    24|
    25|1. **感官记忆（瞬时记忆）**：视觉/听觉输入停留几秒，绝大部分信息死在这一步
    26|2. **短期记忆**：容量 7±2 个项目，不重复则 15-30 秒消失
    27|3. **长期记忆**：理论容量无限，需经编码和巩固过程（睡眠中完成）
