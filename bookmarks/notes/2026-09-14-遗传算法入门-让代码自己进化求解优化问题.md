## 核心命题

梯度下降像登山者——站在局部小山包上往哪走都是下坡，困死在局部最优。遗传算法（GA）不登山，它派出一群解散布整个搜索空间，让它们繁殖、竞争、淘汰，适应度高的多生孩子，低的被淘汰——若干代后种群自然向全局最优聚集。1975 年密歇根大学约翰·霍兰德提出，核心思想一句话：**不追单一路径，维持种群用群体智慧搜索全局最优**。

## 内容整理

### 1. 五个关键概念

| 概念 | 定义 | 类比 |
|---|---|---|
| 基因 | 解的编码表示（二进制串每位 0/1） | DNA 碱基 |
| 个体 | 一个完整解（一个二进制串 → 一个 x 值） | 一个生物体 |
| 种群 | 一堆个体的集合（初始随机生成 50 个） | 物种群体 |
| 适应度 | 个体好坏评判（求最大值时 f(x) 本身就是适应度） | 生存能力 |
| 代 | 一轮迭代（选择→交叉→变异→新种群） | 一代繁殖 |

### 2. 三个核心操作

| 操作 | 机制 | 生物学对应 | 作用 |
|---|---|---|---|
| 选择 | 轮盘赌：被选概率 = 自身适应度/总适应度 | 自然选择 | 保留优秀基因（但不保证，保留多样性） |
| 交叉 | 两个父代随机切一刀交换前后段 → 两个子代 | 基因重组 | 组合优秀基因 |
| 变异 | 以小概率（通常 1%）翻转某个基因位 0↔1 | 基因突变 | 引入新基因、跳出局部最优 |

三操作缺一不可：缺选择→随机搜索；缺交叉→个体无法交换信息；缺变异→种群早熟收敛到次优解。

### 3. 变异跳出局部最优的机制（全文最核心）

当种群全聚集在某个局部峰附近时，所有个体基因太相似→交叉=原地重组跳不出。变异不断往种群里"注射"新基因模式：某些变异恰好落在更高的峰→被选择放大→几代后种群迁移到全局最优。**变异提供原材料，选择负责筛选——两步配合自然向全局最优迁移。**不是"一次跳到全局最优"，而是概率性的"持续探索+优胜劣汰"。

### 4. 实跑案例

目标函数 f(x) = x·sin(10πx) + 2，区间 [-1, 2]，真实最大值 3.8503。

| 参数 | 值 |
|---|---|
| 种群大小 | 50 |
| 二进制编码 | 22 位 |
| 交叉率 | 0.8 |
| 变异率 | 0.01 |
| 迭代代数 | 100 |

结果：GA 找到 3.8502（误差 0.00005），第 38 代首次达 95% 最优值。初始平均适应度 1.82 → 最终 3.49。

### 5. 变异率灵敏度分析

| 变异率 | 表现 |
|---|---|
| 0.001 | 收敛偏慢（新基因太少，多样性不够） |
| **0.01** | **最优：收敛快且稳** |
| 0.05 | 开始抖动（收敛解被随机打乱） |
| 0.15 | 几乎无法收敛（退化成随机搜索） |

经验值：变异率 0.001–0.05，0.01 为起点；交叉率 0.6–0.9，0.8 常用；种群 50–200 够用。

### 6. 适用场景判断

| 适合 | 不适合 |
|---|---|
| 多峰函数优化 | 凸优化（梯度下降又快又准） |
| 组合优化（TSP/排班/背包） | 解空间小（暴力枚举更直接） |
| 参数调优（ML 超参搜索） | 要求精确解（GA 是近似算法） |
| 工程设计（天线/翼型） | 实时性要求高（多代迭代慢） |
| 路径规划（多目标） | — |

## 归纳总结

三条通用规律收敛全文：

1. **群体智慧 > 单点爬山**：GA 维持种群并行搜索，天然对抗局部最优——这是它区别于梯度法的本质优势。
2. **三操作分工明确**：选择=保留优秀、交叉=组合优秀、变异=引入新基因。变异率是灵魂参数——太大变随机搜索，太小早熟。
3. **近似算法定位**：GA 不保证全局最优，标准做法是跑 10–20 次取最优再报告均值+标准差。能用梯度法就别用 GA——GA 是"梯度搞不定时的备选"。

## 趋势判断

1. **GA 在 LLM 时代的定位变化**：可微分编程（JAX/PyTorch autograd）让更多传统"不可导"问题变得可导，GA 的领地在缩小。但在**离散组合优化**（TSP/排班/层合板铺层顺序）领域 GA 仍是主力——这些问题的解空间天然离散，梯度无定义。
2. **NSGA-II 多目标版本**在工程设计领域出场率持续高——飞机结构多目标（重量/强度/成本/制造性）天然适合。
3. **GA+深度学习交叉**：神经架构搜索（NAS）早期用 GA，现已被可微分 NAS 取代主流；但**演化策略（Evolution Strategies, ES）**在 RL 中作为替代 PPO 的离策方法仍有生命力（OpenAI ES 论文）。

## 查询拓展

- **NSGA-II**：非支配排序遗传算法，多目标优化标准方法，工程领域出场率极高
- **演化策略（ES）**：与 GA 同属进化计算，但操作在实数空间直接加噪声，OpenAI 2017 证明可做 RL
- **PMX 交叉 / 交换变异**：排列编码下的交叉/变异操作（TSP 专用）
- **可微分编程**：JAX 等框架让传统不可导问题变可导，GA 领地受压缩
- **CMA-ES**：协方差矩阵自适应演化策略，GA 的高性能变体，连续优化强
