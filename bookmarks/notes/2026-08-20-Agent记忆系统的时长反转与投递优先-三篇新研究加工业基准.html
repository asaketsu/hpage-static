一、内容详细整理

1.1 核心问题：记忆评测的两大盲区

三篇论文从不同角度攻击同一个问题：现有 Agent 记忆系统的评测和实践都系统性忽略了"时间"和"投递"两个维度。

盲区 现状 后果
基准先造对话后抽答案 label 错误 + 污染问题已被记录 排名不可信，短期领先 ≠ 长期领先
只测短历史（数天~数周） 绝大多数基准测 3 周内交互 九周时架构排名整体反转无人知晓
记忆 = 自愿读写的文档 agent 必须"选择写、选择读" 自愿使用率实测 0/114 turns
上下文压缩后事实丢失 compaction 摘要不保留细节 10 个事实在 108 次 compaction 中 106 次消失

1.2 Ground Truth First：反向流水线与"任期反转"（Tenure Crossover）

方法论——把流水线倒过来：

传统：先造对话 → 事后抽答案键（label 错误 + 污染）
GTF ：种子化生活脚本采样器先发射事实
      → 每个事实带 [有效期区间, 波动类别, 来源渠道]
      → LLM 渲染器按事实清单写 chat/email
      → 保真校验器确认每个植入事实
      → 题目从脚本机械化生成（gold 答案构造即正确）

合成语料约 380 题、15 种题型，嵌入了现有基准没有的四类特征：逐事实有效期、发件/收件信任区分、良性 harness 中的注入探针、as-of 日期题集。

核心实验结果（5 种记忆架构 + 无记忆对照，固定答题者，版本化 LLM judge，3 次重复，2 个时间跨度）：

架构 3 周 9 周 崩溃原因
预算化精选 map 记忆（短期冠军） 领先 96% → 72% 被逐出内容不可恢复
溯源类型化图（provenance-typed graph） 落后 升至 90% 无逐出，只追加
分层架构（Veracium，开源） 96.8% 双域最佳 —
全量渲染历史基线 短期打平最优 9 周无 judge 无关优势 读成本约 2 倍

反转对全部 6 个用户在跨家族重判下为正（exact p=0.031）。两个附带发现：写入质量强相关下游质量（弱写法事实失败率 24% vs 良好写法 2%）；注入抵抗取决于溯源边界是否在表示层存活。

1.3 Delivery, Not Storage：cue 锚定工作记忆是 harness 属性

论点：编码 agent 只有一类记忆——文档（指令文件、plan 工件、自动写的 memory 目录），它们是"故意写、故意读"的。人类专长的第二层（gotcha、位置、本地约定）是工作副产物编码、情境线索非自愿提取——这一层才是长程 agent 的承重层，且必须是 harness 属性，不能是 agent 选择。

设计：记忆携带一等公民触发条件，词汇表可组合——path / symbol / semantic / event / temporal 五类，由 harness 确定性求值注入。作者断言：被调研的所有学术与已发布系统均无此组合。

对照实验数据（真实编码任务）：

机制 结果
自愿记忆使用（预置了记忆库） 114 turns 中 0 次记忆操作
确定性注入 每次种子运行都命中，0 误报
压缩边界后同 session 重读 39% 的重读在"重复购买"压缩前已付费的内容
10 个只存于对话的事实 首次摘要即消失，108 次 compaction 中 106 次持续缺席；被剥夺的 agent 去grep harness 自己的 session 文件重建
同样 10 个事实从 harness 注入 138 次 compact-resume 全部完整到达

结论原话："Delivery, not storage, is the product——可靠的记忆通道是 agent 从不需要惦记的那条。"

1.4 The Working Set：一致性债务（Coherence Debt）

仓库级编码要求 agent 在有限上下文内保持测试/imports/配置/迁移规则一致。论文将其建模为耦合事实图重建：每次编辑所需事实要么来自近期上下文，要么来自参数记忆，两者都不覆盖的部分构成 coherence debt。

七个模型 × 五种 harness 的供需实验（人为供给/扣留事实 + 注入故障）：

  • 可用性决定结果，距离不决定：扣留一个事实的代价恰好等于它支撑的那部分工作；供给的事实放在编辑点远处和近处效果一样。
  • harness 为同一件事支付不等的代价：全部通过测试的配置之间 token 消耗相差 10 倍以上（不同速率重建同一内容）；事实被扣留时多花钱什么都换不回。
  • 缺失事实产生错误工作而非没有工作：被要求行动的 agent 会行动——编造文件或猜值。建立在"读取"上的观测工具看到的是已被幻觉填满的洞。
  • 主动报告被阻塞是模型属性：有的模型每次都报，有的从不报。
  • 过时的规范文件比没有文件更贵：标准与代码冲突时，七个模型都跟随标准哪怕它规定的是更差的代码。
  • SWE-bench 上（模型大概率认识仓库）读取不再预测成功——参数记忆替代了读取。

1.5 工业现状：Mem0 2026 报告的基准与架构

三大基准定义了测量版图：LoCoMo（1540 题：单跳/多跳/开放域/时序）、LongMemEval（500 题 6 类，考知识更新与多 session）、BEAM（1M/10M token 规模，扩展上下文窗口解决不了，最贴近生产）。评测五维：BLEU / F1 / LLM score / token 消耗 / 延迟——防止单轴优化。

Mem0 2026 年 4 月新算法成绩：

基准 分数 平均 tokens/查询
LoCoMo 92.5 6,956
LongMemEval 94.4 6,787
BEAM (1M) 64.1 6,719
BEAM (10M) 48.6 6,914

最大增益在时序查询（+29.6）与多跳推理（+23.1）。两项架构改动驱动：单遍 ADD-only 提取（agent 生成的事实一等公民化，确认/建议与用户陈述同权重入库）；多信号检索（语义相似 + 关键词 + 实体匹配三路并行打分融合）。集成面：21 框架（LangChain/LangGraph/CrewAI/AutoGen/OpenAI Agents SDK 等）+ 3 个语音专线（ElevenLabs/LiveKit/Pipecat——语音场景不能回滚翻聊天记录，记忆缺失的摩擦即刻暴露）。自认最难开放问题：跨 session 身份、规模化时间抽象、记忆陈旧化。

1.6 创新点与局限

  • GTF 的合成语料是构造即正确，但合成分布与真实用户行为分布的 gap 未讨论；单作者论文，复现待验证。
  • Delivery 论文的"确定性注入 0 误报"基于单一真实任务 + 种子记忆库，触发词汇表的组合爆炸与维护成本是暗面。
  • Working Set 的"读取不预测成功"依赖模型对仓库的预训练污染——这既是发现也是其外部效度边界。
  • Mem0 报告是厂商一手资料，基准自选自报，但评测框架已开源（github.com/mem0ai/memory-benchmarks）可独立复核。

二、查询拓展（概念指南分析）

2.1 Incidental encoding（附带编码）

认知心理学术语：人类在执行任务时无意识地编码情境相关信息（位置、工具、gotcha），不需要显式记忆意图。Delivery 论文用它论证第二层记忆的合法性——agent 需要的不是更强的"意图性记忆"，而是复刻这种无意识通道。

2.2 Event-based prospective memory（事件性前瞻记忆）

"当 X 发生时记得做 Y"的人类记忆形态。对应 Delivery 论文的 event/temporal 触发条件——记忆的提取由事件触发而非检索查询触发，这是与 RAG 检索式记忆的根本分叉。

2.3 Supersession 边与 as-of 快照

昨日《图谱做 Agent 记忆三个工程坑》的核心方案：旧节点不变、追加新节点 + supersession 边 + as-of 查询。GTF 的"逐事实有效期 + as-of 日期题集"正是该方案的评测端对应物——两条线在 2026-08 汇合不是巧合，是行业对"时间维度记忆"的需求共振。

2.4 Coherence debt（一致性债务）

借自技术债的类比：每次编辑欠下的"未覆盖事实"像债务累积，harness 的补偿手段（重读、重建）是利息。10 倍 token 差异 = 不同 harness 的"利率"差异。

三、归纳总结

3.1 借鉴点评估（关联 Hermes Agent / 本地体系）

优先级 借鉴点 落地路径
P0 compaction 事实丢失是可量化问题（106/108） Hermes 长会话压缩后关键事实（路径/铁律/决策）应进 harness 级注入清单，而非依赖 agent 自觉写 memory——现有 MEMORY.md 是"自愿写"模式，恰好是论文证伪的那类
P1 触发条件一等公民化（path/symbol/event） memory-write skill 的记忆条目可加 trigger: 字段（如 path 前缀触发），由 hook 确定性注入而非等待检索
P1 基准要有时间维度 本地记忆体系（memorygraph/L1-L3）评估时应做"3 周前事实 vs 9 周前事实"分段召回测试，防短期幻觉
P2 写入质量 24% vs 2% memory-refiner 的写法规范值得对齐 GTF 的"良好写法"标准（带有效期、带来源渠道、带信任级别）
P3 读取不预测成功 watchdog/巡检类 skill 不应以"agent 读过日志"为完成证据，要以产出物为证据——Working Set 的直接推论

四、趋势判断与拓展应用推荐

4.1 时间维度成为记忆系统第一分类轴

三篇论文 + Mem0 报告在 30 天内全部强调 validity interval / as-of / staleness——记忆评测从"能不能记住"转向"能不能记住什么时候的什么"。预计 2026 下半年基准全面加装时间轴，排行榜将重排。

4.2 记忆架构从"agent 选择"迁移到"harness 属性"

Delivery 论文用 0/114 的自愿使用率宣判了"agent 自觉记忆"路线死刑。harness 确定性注入 + 触发词汇表会成为 agent 框架标配——正如今天的 context compaction 已经是 harness 功能而非 agent 功能。

4.3 评测流水线反转方法论扩散

"先有 gold 再生成语料"（construct-by-design）会从记忆基准扩散到 agent 评测全域——它同时解决 label 错误和污染，且天然支持注入探针。
