内容整理：Qwen3.0 → Qwen3.8 十项架构演进

1. 全景对比表（原文核心资产）

要点：Qwen3→3.8 的画风从「换零件」变成「整机工程化魔改」——每个改动只带来边际收益（省显存/稳训练/快 decode），叠加成最新开源水位。架构谱系：Qwen3-Next (2025.09) → Qwen3.5/3.6 → 3.8 沿用，HF model_type 仍是 qwen3_5；最新 Qwen3.8-Flash-Next 是全新架构（作者持观望）。dense 与 MoE 两版本注意力完全相同，仅 FFN 不同。

2. Gated DeltaNet 演进史（一条状态矩阵 S 串起五步）

  1. 线性注意力（2020, Katharopoulos, Transformers are RNNs）：去 softmax、KV 先外积 → Attention 在数学上= RNN，每 token 对固定状态 S 做写入。缺陷：只加不减，状态越写越乱（interference）。
  2. 加遗忘门（RetNet/Mamba2/GLA, 2023-24）：每步按 α 衰减旧记忆，但 α 一刀切，无法精确修改单条记忆。
  3. Delta rule（2021, Schlag et al. Fast Weight Programmers 提出 DeltaNet；2024 Yang et al. 解决并行训练）：用 k 从 S 读旧值按误差纠正 = 对 S 做一步在线梯度下降，可精确覆盖某 key 的记忆。
  4. Gated DeltaNet（ICLR 2025, Yang/Kautz/Hatamizadeh）：2+3 合体，遗忘 α_t 整体衰减 + β 精确改写，论文副题即 Improving Mamba2 with Delta Rule。
  5. 混合架构：纯线性注意力在精确检索（大海捞针）弱于 softmax，故保留少量全注意力兜底。比例：Qwen3-Next/3.5/3.8 与 Kimi Linear 均 3:1，MiniMax-01 为 7:1；3:1 是 Qwen 团队效率/效果折中。

动机：softmax 注意力训练 O(T²) + 推理 KV cache 线性增长；Qwen3.8 支持 262K 上下文，GDN 层只维护固定状态 S，推理显存 O(1)。

未竟方向（作者列）：①门控粒度——GDN 的 α 是每头一个标量，Kimi Linear 的 KDA（2025.10）细化到每通道一个衰减 ②3:1 比例与全注意力层位置值得搜索；MiniMax M2 大规模部署后回归全注意力 = 线性注意力在复杂推理/检索的短板未完全解决 ③理论优势依赖高度优化 kernel（FLA 库 Triton 实现）才能兑现。

3. 训练并行化：WY 表示与作者的分块求逆 kernel（本文独家踩坑）

  • 串行递推（T 长循环）训练不可用；Yang et al. 2024 等价变换后，rank-1 更新结构 = 广义 Householder transformation，可经 WY representation 压缩，支持 chunk-wise 分块并行（如 chunk=64：128 token 问题从 128 次矩阵向量乘 → 2 次矩阵乘 + 1 次状态传递，路径缩短 64 倍）。
  • 踩坑：chunk 内需解单位下三角方程组，官方用 torch.linalg.solve_triangular，在 Apple M4 Pro MPS 上一次前向 130+ms——torch 2.9 该算子为 batch 内每个矩阵单独提交 GPU kernel（batch=32×head 8×chunk 数 4=1024 个小矩阵），每次提交 ~0.066ms 而计算本身仅几微秒，时间全耗调度。
  • 自研解法：用分块求逆恒等式写 invert_unit_lower_triangular()——从 64 个 1×1 逆出发逐轮合并相邻对角块，每轮所有矩阵对彼此无关 → 一次 batched matmul，共 log₂ 轮（对数复杂度），batch 1→1024 时官方耗时翻 680 倍而自研近似对数增长，提速十几倍，fp32 最大误差 1e-6 级（精确代数、无近似）。
  • 乌龙：准备提 PR 时发现 torch 2.15 已修复该算子（思路不同、效果更好）。

4. Gated Attention（1/4 全注意力层的魔改）

  • 改动：注意力输出先乘 sigmoid gate 再进 o_proj。动机：StreamingLLM (2023) 发现 attention sink（大量注意力分数倾倒首个 token）；后续工作发现 massive activation——softmax 必须归一化到 1，头"不想看任何东西"时只能找垃圾桶 token。
  • Qwen 2025 论文 Gated Attention for Large Language Models 系统比较 gate 位置，SDPA 输出后逐元素依赖输入的 sigmoid gate 最优：引入非线性+稀疏性，头可直接关断输出，attention sink 与 massive activation 基本消失，训练更稳、长上下文外推更好。该论文获 NeurIPS 2025 best paper。
  • 提升空间：逐元素 gate 使 q_proj 输出维度翻倍（参数/计算多一倍），headwise gate 更便宜但效果略差。
  • 代码模式：q_proj 输出 [query, gate] 拆分 → QK-Norm → PartialRoPE → GQA repeat_kv → SDPA → attn * sigmoid(gate) → o_proj。

5. Partial RoPE（只转 25% 维度）

  • 非新事物：GPT-J (2021)、GPT-NeoX-20B (2022) 就是 25%；DeepSeek MLA 也拆分带/不带 RoPE 的部分。
  • 思路：一部分维度专职位置，其余专职语义匹配不受旋转干扰；未旋转维度不会遇到没见过的角度，对长上下文外推友好。θ 从 1e4 → 1e7。
  • 官方配置是 mRoPE（时间/高/宽三段），纯文本下三段位置 id 相同退化为 1D，作者只实现 1D 版。rotary_dim = head_dim*0.25，其余直通 concat。

6. Zero-centered RMSNorm + weight decay（最不起眼但最"工程"）

  • 背景：Qwen3-Next 训练发现 QK-Norm 后部分 norm 权重异常增大影响稳定。
  • 悖论：普通 RMSNorm gain 初始 1，weight decay 把它拉向 0 = 错误先验（0 是关通道、1 才中性）→ 实践中 norm gain 不做 decay → 无约束增长。
  • 解法：out = x/rms(x) · (1 + w)，w 初始 0——decay 拉 w→0 等价 gain→1。Gemma 早有 (1+w) 写法，Qwen3-Next 首次与 weight decay 组合。
  • 细节（只有读官方代码才知道）：GDN 输出端 GatedRMSNorm 官方未做 zero-centered，须排除在 weight decay 外（A_log/dt_bias 同理）。

7. Sparse MoE 与 MTP（略讲）

  • Qwen3.6-35B-A3B：256 小专家 top-8 + 1 共享专家；总参 35B 每 token 仅激活 3B，推理成本≈3B 模型，省 10 倍算力。
  • aux loss（系数 0.001）应在全局 batch 统计而非 micro-batch（Qwen 2025 论文 Demons in the Detail），否则逼专家在局部数据也均匀反而损害专精。
  • 作者逐专家循环"能跑但超慢"——真 MoE 训练依赖专家并行 + grouped GEMM 专用 kernel。
  • MTP：同时预测下下个 token，训练时提升样本效率（作者实现仅作训练信号，未做投机解码）。

9. 未实现清单（诚实边界）

视觉编码器/mRoPE、推理缓存（KV cache + GDN 递推状态）、MTP 投机解码、融合 kernel（FLA Triton/causal-conv1d CUDA，MPS 跑不了）、高效 MoE（专家并行/grouped GEMM/全局负载均衡）、混合精度、262K 长上下文、后训练（SFT/RL/思考模式）。

查询拓展

  • GDN 与 Mamba2 什么关系？ GDN 论文副题即"用 Delta Rule 改进 Mamba2"——Mamba2 是带遗忘门的 SSM（上述第 2 步），GDN 在其状态更新外再套 delta rule 精确改写。
  • 为什么不是纯线性注意力？ 精确检索任务（大海捞针）仍需 softmax 全注意力兜底；MiniMax M2 部署后回归全注意力是反向证据。
  • Qwen3.8 与 Qwen3-Next 的关系？ 同一 text decoder 架构一路沿用（HF model_type=qwen3_5）；3.8-Flash-Next 才是新架构。
  • MoE 的 aux loss 为何要全局 batch 统计？ micro-batch 统计逼专家在局部数据均匀，损害"专精"——负载均衡的粒度选择本身是设计点。
  • 262K 上下文靠什么撑？ 3:1 混合——75% 层 GDN 状态 O(1) + 25% 层全注意力，KV cache 总量降到 1/4；部署侧另配量化（见关联笔记实测）。

归纳总结

  1. 架构演进本质是工程边际收益的堆叠：GPT-2→Qwen3 是换零件（SwiGLU/RoPE/RMSNorm），Qwen3→3.8 是把推理成本、训练稳定性、长上下文拆成几十个小问题逐个工程化推动——没有单项革命，合起来是开源新水位。
  2. "状态矩阵 S 的更新公式"是线性注意力家族的主线：加（线性注意力）→ 减/衰减（遗忘门）→ 精确改写（delta rule）→ 合体（GDN）→ 与 softmax 混编（3:1）。一条公式串起 2020-2025 五年演进。
  3. 数学等价变换是并行化的钥匙：串行递推不可训 → Householder/WY 表示 → chunk 分块并行（64 倍路径缩短）。理论优势兑现依赖 kernel 工程（FLA Triton、作者的分块求逆）。
  4. 训练稳定性的细节藏在初始化与正则化的配合里：(1+w) zero-centered RMSNorm 让 weight decay 的"拉向 0"变成"拉回中性 1"——用参数化换正确先验，Gemma 铺路、Qwen 组合。
  5. 复现验证的金标准是与官方实现对齐：随机权重转 HF 格式比 logits（<1e-6）+ 训练保存恢复比对参数（=0）——比"loss 降了"强得多的正确性证据。

趋势判断

  • 混合架构 3:1 成为 2026 开源主流配方（Qwen3-Next/3.5/3.8、Kimi Linear 同比例），但 MiniMax M2 回归全注意力说明线性注意力短板未解——方向未收敛，门控粒度（KDA 每通道衰减）与混合比例搜索是活跃前线。
  • Gated Attention 获 NeurIPS 2025 best paper 标志"attention sink/massive activation 治理"从现象发现走向标准组件，预计 gate 变体（headwise vs elementwise）继续演化。
  • MoE 从架构创新转入 Infra 竞赛：256 专家/激活 3B 的解耦已成商品，差异化在 grouped GEMM/专家并行/全局负载均衡等 kernel 层。
  • MTP 从推理加速（投机解码）延伸到训练样本效率，训推一体设计（一个模块两种用途）是明显信号。
  • 手搓复现赛道（CS336 → llm-from-scratch → qwen38-from-scratch）持续与官方架构保持 1-2 代距离，是跟踪架构水位的高性价比信源。
