> 主题：强化学习策略 Sim2Real 迁移中的关节动力学参数辨识方法论
> 评分：⭐⭐⭐⭐⭐ (5/5) — 机器人 Sim2Real 领域极具工程实践价值的方法论文档

## 核心结论

**Sim2Real 失败的常见原因不是"某个参数差了一点"，而是几个参数的影响长得太像——惯量偏大和延迟未建模都让响应变晚，摩擦和阻尼都让曲线衰减得更快。** 本文系统阐述了如何设计实验让每个参数暴露在它独有的现象里，以及如何从数据中提取出来。三部分：动力学模型→参数辨识→实验设计。

## 第一部分：动力学模型

### 单关节二阶阻尼系统

标准二阶阻尼方程（旋转关节）：

$$J\ddot{\theta} + (b + K_d)\dot{\theta} + K_p\theta = K_p\theta_{target}$$

**核心洞察**：刚度完全由 PD 控制器提供（$K_p$），阻尼是控制器 $K_d$ 与关节被动阻尼 $b$ 之和。**二者在方程中形式完全相同，位置曲线只能看到 $(b + K_d)$ 这一个数——结构性地不可辨识**。

### 自然频率与阻尼比

$$\omega_n = \sqrt{K_p / J}, \quad \zeta = (b + K_d) / (2\sqrt{K_p \cdot J})$$

- **$J$ 决定快慢**（时间尺度 $\omega_n$）
- **$\zeta$ 决定形状**（超调/衰减）

**归一化检验**：把时间按 $1/\omega_n$ 归一化、响应按阶跃幅值归一化后，同一 $\zeta$ 的曲线完全重合。若真机上不同幅值的归一化曲线不重合 → **非线性证据**（摩擦/死区/饱和）。

### 五种非理想因素及其"指纹"

| 因素 | 方程项 | 指纹特征 | 与谁纠缠 |
|------|--------|----------|----------|
| **纯延迟 $\tau$** | 目标通道时移 | 整条曲线平移；频域只改相位不改幅值 | 惯量 $J$ |
| **库仑摩擦 $F_c$** | 与速度符号相关的常数力矩 | 在小阶跃里占主导（$\propto 1/A$），大阶跃被淹没 | 黏性阻尼 $b$ |
| **静摩擦/死区** | 启动阈值 | 走不到位，效果随幅值反比衰减 | 低增益 $K_p$ |
| **饱和** | 电流/扭矩/速度限幅 | 有阈值，小幅值不出现，超阈值后峰值受限 | 线性惯量变化 |
| **链路增益 $\alpha$** | 实际力矩 = $\alpha \times$ 命令力矩 | 不改变形状只缩放力矩 → 与惯量完全等价 | 惯量 $J$ |

### 有效惯量构成

$$J_{eff} = J_{link} + N^2 \cdot J_{rotor}$$

- $J_{link}$：下游连杆质量分布
- $N^2 \cdot J_{rotor}$：电机转子折算（**乘以减速比平方**）
- 对高减速比关节，转子折算项远大于连杆惯量
- 对应仿真中的 `armature` 参数——**是真实物理量，不是数值旋钮**

## 第二部分：参数辨识的三个原则

### 原则一：实验约束的是输入输出映射，不是参数

如果两组不同参数产生完全相同的输出，无论什么算法都无法分开。

**经典例子**：$J$ 和 $K_p$ 同时乘以常数 $c$，方程完全不变 → 只测位置无法区分"惯量大一倍+增益也大一倍"与原系统。

**打破方法**：引入量纲独立的新观测——**扭矩**。

### 原则二：要分开两个参数，必须找到让它们表现不同的工况

| 纠缠的一对参数 | 为什么在阶跃里分不开 | 什么工况能分开 |
|----------------|---------------------|---------------|
| 纯延迟 $\tau$ ↔ 惯量 $J$ | 二者都让响应"变晚" | 扭矩通道测起效时刻；频域（延迟只改相位） |
| 库仑摩擦 $F_c$ ↔ 黏性阻尼 $b$ | 单次阶跃速度单向变化 | 多档恒定低速：$F_c$ 不变，$b$ 随速度线性增长 |
| 静摩擦/死区 ↔ 低 $K_p$ | 单幅值都表现"走不到位" | 多幅值：摩擦相对影响 $\propto 1/A$ |
| 控制器 $K_d$ ↔ 机械阻尼 $b$ | 位置曲线只看到二者之和 | 扫多个 $K_d$ 设置，外推到 $K_d=0$ |
| 结构柔性 ↔ 大 $J$ | 都让曲线出现额外衰减 | 扫频：柔性有共振峰，阻尼没有 |
| 惯量耦合 ↔ 独立关节 | 单轴实验只看到对角投影 | 交叉轴激励 |

### 原则三：按可分离程度排序，逐级固定

先定能被单独暴露的量，再逐级往下，每级把上级结果当已知量代入。

## 第三部分：实验设计（五级流水线）

### 分级辨识流水线

| 顺序 | 实验 | 交付的参数 | 为什么排在这里 |
|------|------|-----------|---------------|
| ① | 双向多幅值阶跃（含扭矩通道） | 纯延迟 $\tau$、饱和拐点、$J$、总阻尼 | 先从时间戳定延迟，再拟合曲线 |
| ② | 低速往返 + 恒扭矩 | $F_c$、$b$、死区、重力矩（分方向） | 准静态工况让惯量项自动消失 |
| ③ | 扫频/Chirp | 传动刚度、共振频率、结构阻尼 | 只在特定频率显形 |
| ④ | 自由衰减 | 被动阻尼 $b_{mech}$、恢复刚度 | 撤去输入后方程齐次 |
| ⑤ | 交叉轴激励（并联机构） | 随姿态变化的惯量矩阵 | 需单轴结果作参照 |

**①→⑤ 越靠前越不依赖模型假设，结果被后面各级当已知量代入。**

### 阶跃实验要点

1. **幅值逐级放大**：每级通过安全检查后进入下一级
2. **有扭矩通道时**：$J$ 可直接从牛顿方程回归（不依赖延迟）
3. **只有位置数据时**：用截距法——$t_{threshold}$ 对 $1/\sqrt{K_p}$ 作图，截距 = $\tau$
4. **拟合整段曲线**（正向仿真），而非特征点

### 低速往返实验

**核心原理**：低速让惯性项 $J\ddot{\theta}$ 可忽略，方程退化为静力平衡：

$$\tau_{drive} = F_c \cdot \text{sgn}(\dot{\theta}) + b\dot{\theta} + \tau_{gravity}$$

- 多档恒定低速 → 扭矩-速度图
- 正负分支截距差 = 库仑摩擦 $F_c$
- 分支斜率 = 黏性阻尼 $b$

### 恒扭矩实验

**原理**：在即将启动的临界点 $\dot{\theta}=0, \ddot{\theta}=0$，惯量和阻尼完全不参与。

- 正负方向阈值：**半差给摩擦，半和给偏置（重力/装配）**
- 对惯量估计误差免疫

### 扫频实验

- **延迟 vs 惯量**：幅频滚降斜率认惯量，相频下滑斜率认延迟
- **柔性 vs 阻尼**：柔性是局部共振峰，阻尼是全局压平

### 自由衰减实验

- 撤去输入后齐次方程 → 只由特征根决定
- 对数衰减率 $\delta = \ln(q_n/q_{n+1})$ → 模态参数
- **区分黏性/库仑**：黏性 = 等比衰减（指数包络），库仑 = 等差衰减（直线包络，有限时间停止）
- 扫多个 $K_d$ → $b_{total}$ 对 $K_d$ 线性拟合 → 斜率 = $K_d$，截距 = $b_{mech}$

## 实验前提（通用要求）

| 要求 | 说明 |
|------|------|
| **刚性固定基座** | 非固定时有效惯量退化为约化惯量，影响随下游质量比增大 |
| **锁定其他关节** | 单关节隔离 |
| **统一时间戳** | 所有通道同一时钟基准 |
| **记录扭矩** | 限幅后扭矩 + 软件计算扭矩 |
| **温度/电压** | 影响扭矩常数 |

## 💡 分析与借鉴

### 对具身智能 Sim2Real 的直接价值

| 要点 | 内容 |
|------|------|
| **`armature` 是物理量** | MuJoCo/Isaac Gym 中的 armature = 电机转子折算惯量 $N^2 J_{rotor}$，不是数值旋钮。随便改 = 随便改关节时间尺度 |
| **扭矩通道是辨识的关键** | 没有扭矩数据，$J$ 和 $K_p$ 结构性不可辨识——必须记录限幅后扭矩 |
| **五级流水线可直接执行** | 阶跃→低速往返→扫频→自由衰减→交叉轴，每一级交付特定参数 |
| **纠缠参数表是诊断地图** | 遇到 Sim2Real 差距时，先查是哪对参数纠缠，再设计针对性实验 |
| **归一化检验非线性** | 不同幅值阶跃归一化后不重合 → 存在摩擦/死区/饱和 |
| **延迟必须先于惯量辨识** | 反了的话延迟会被吸进惯量，惯量虚高 |

### 对 Jetson 边缘部署的含义

边缘端做 Sim2Real 时，动力学参数辨识的五级实验可以在 Jetson 上做数据采集（记录位置/扭矩/时间戳），离线分析在 PC 上做。
