内容整理

核心命题：DUCK 当前最大真机痛点是"跺脚/抖动/动作不自然"（act_absmax 8.0→2.68 的软件抑制已到天花板），业界解法已收敛到三条正交路线：①熵调度治理探索-收敛节奏 ②动作平滑正则（一阶/二阶差分罚）③残差策略（先验吃掉大部分动作幅度，策略只学修正量）。ECIM 与 RuN 分别是①+②与③的 2025-2026 代表作，两者的共同前提是"动作抖动不是策略能力问题，是优化目标的度量问题"。

1. ECIM（arXiv:2512.06486，北工大，Isaac Gym 四足六地形）：PPO 的已知病=过早收敛到次优步态。ECIM = PPO + 三机制联合：
- AECPOM（自适应熵调度）：熵系数随经验回报动态调整——训练早期宽探索、策略稳定后自动偏向利用。直接回应"太多熵→动作随机伤精度，太少熵→行为多样性不足卡局部最优"的两难。
- MCRF（运动连续性正则）：跨时间步约束动作变化 + 状态空间约束降低对微小感知扰动的敏感度。论文实测：拆掉 MCRF 后 Acc RMS 恶化、机器人出现"振荡和抽搐运动（oscillatory and jerky movements）"，尤其在坡面和下楼梯地形。
- IMDEEM（内在动机探索增强）：把探索导向"既新颖又任务相关"的状态（可通行区域/稳定落脚点）。

硬数据（vs PPO 基线，六地形）：任务奖励 +4-12%，身体俯仰振荡峰值 -23-29%，关节加速度 -20-32%，关节力矩消耗 -11-20%。

2. RuN（arXiv:2509.20696，Unitree G1 真机部署）：单策略同时学"动作模仿+速度跟踪+稳定维持"三目标会互相打架。RuN 解耦：
- CMG（条件动作生成器）：自回归生成运动学先验轨迹（离线学人类动作分布）。
- 残差策略：只学"对先验的小幅动态修正"，最终动作 = CMG 先验 + 残差。探索空间骤缩，策略容量聚焦动态交互。
- 真机结果：0-2.5 m/s 连续速度域平滑走跑过渡，无可见停顿或抽搐；训练效率与最终性能超 SOTA。
- 消融证据（动作量级）：拆掉 qpos 跟踪项残差范数 4.06（满配 0.88）；拆掉 qvel 项 1.03；拆掉 task 项 0.95 但速度误差 1.69（满配 0.29）——三个正则项各自压制残差的不同维度。

3. 正则项量化参照（RuN Table I 摘录）：动作平滑罚 ‖a_t − 2a_{t−1} + a_{t−2}‖²₂ 权重 −0.06；关节加速度罚 −5×10⁻⁸；关节越限 −2.0；选中关节偏离默认姿态 −0.2。二阶差分平滑罚是业界标配（同时约束"急动"和"漂移"），DUCK 现有配方只罚一阶 action_rate，缺二阶项。

查询拓展

  • ECIM 的熵调度与 E11/E22 黄金档现象（iter1500-15000 upright 到账 1.0-1.32、末段过度收敛退化）同构——黄金档=熵降到恰好、尚未塌缩的窗口，ECIM 把这个窗口从"碰运气"变成"调度对象"。可追：Isaac Lab / mjlab 是否有 entropy coefficient scheduler 现成实现。
  • RuN 残差思路对 DUCK 的具体形态：五段式起立/下蹲 skill（已定稿）天然是"运动学先验"，策略接管后只学残差修正——与现行"整网 RL 从零学全部动作"路线正交。E31v2 老师分布蒸馏已验证"先验有效"，残差学习是更轻的等价物。
  • 未决问题：ECIM 六地形全是四足，小双足（17 DoF 级别）上熵调度收益是否同样成立；RuN 的 CMG 需要离线人类动作数据，鸭子无 mocap 源，先验须来自脚本化轨迹或已验证的技能链。
  • 检索关键词备忘：action smoothness reward second-order difference / residual policy locomotion prior / entropy coefficient schedule PPO premature convergence。

归纳总结

路线 代表 治什么 对 DUCK 的适配度
熵调度 ECIM-AECPOM 过早收敛/末段塌缩 ★★★ E11/E22/E23b 末档退化直接对症
二阶动作平滑罚 ECIM-MCRF / RuN 抖动/抽搐/跺脚 ★★★ 配方级一行改动，成本最低
残差先验 RuN CMG+residual 探索空间过大/动作幅度 ★★ 需先验源，五段 skill 可当先验
内在动机探索 ECIM-IMDEEM 样本效率 ★ E 系当前瓶颈非探索效率

一页速查：动作抖动的三种死法——①熵没调好（收敛节奏失控）②目标函数没量"平滑"（只罚一阶差分漏掉二阶急动）③让策略从零学全部动作（幅度无先验锚）。三条各有一条已验证的修法，且互相正交可叠加。

趋势判断

2026 足式 RL 的评价重心正从"存活+跟踪"移向"运动质量"：ECIM 用俯仰振荡/关节加速度/力矩消耗三个新指标替换纯任务奖励，RuN 用"自然度"作为一等指标且真机验收。这与 DUCK 用户验收标准的行为级转向（"完美静立不跺脚，轻推一步自平衡"）完全同频——用户要的从来不是 ep_len，而是官方原版 MiniDuck 的"不疾不徐"。判断：接下来 6-12 个月，"自然度正则+残差先验"会成为足式 RL 配方标配，如同 2024 年 domain randomization 的地位。

关联分析

  • 与 2026-10-06-步态条件奖励路由：奖励路由解决"多姿态单一策略"的结构问题，ECIM/RuN 解决"动作质量"的度量问题——两者正交，可同配方叠加（路由 + 二阶平滑罚 + 熵调度）。
  • 与 2026-10-01-Sim2Real执行器建模四层联立模型：执行器建模治"sim 预期 321°/s vs 真机 43-133°/s"的带宽差，动作平滑罚治"策略输出的高频分量"——前者是硬件侧，后者是策略侧，双管齐下才等效官方原版行为。
  • 与 Hermes 自身：E23b 静止奖励（e^-2.5 门+动作变化率门变量）本质是 IMDEEM 的退化版——把内在奖励导向"静止且稳定"的任务相关状态。ECIM 的启示是把"静止奖励门变量"从手工阈值改成随训练进度自适应。
  • 与 2026-09-30-Cassie双足全地形盲走控制器：Cassie 证明小双足+欠驱动踝也能全地形，其冲击图线性化是"模型先验"路线；RuN 残差是"数据先验"路线——先验的来源不同但架构角色相同（吃掉主干动作，策略学修正）。

指南分析

对 DUCK-E24 及后续训练的落地方案（按成本排序）：
1. P0 立即可做（配方一行）：E24 配方加二阶动作平滑罚 ‖a_t − 2a_{t−1} + a_{t−2}‖²₂，权重从 −0.06（RuN 参照）起步扫到 −0.1。与现有一阶 action_rate 罚并存，一阶管"速度"、二阶管"急动"。
2. P1 熵调度（需 mjlab 支持）：检查 RSL-RL 的 entropy coefficient 是否可挂 scheduler；若不可，用 E 系已验证的"黄金档早停"做外环调度（每 500iter 跑 12ep 验收，熵监控进看门狗）。
3. P2 残差架构（下一变体）：以五段起立/下蹲 skill 的关节轨迹为先验，策略输出 residual（限幅 ±5°），先验+residual 进 PD。与 E24"校平态零位"路线兼容——校平锚就是先验的站立段。
4. 验收指标升级：12ep 验收器加关节加速度 RMS 与俯仰振荡峰值两列（ECIM 口径），与 z 高度并列为一等门禁——治"epl 健康但动作丑"的假 PASS。
5. 反例警示：RuN 消融显示拆掉 qpos 跟踪后残差范数×4.6——残差架构里"先验跟踪项"是残差小幅度的保证，不可为省算力砍掉。

拓展应用推荐

  • ECIM 熵调度思想迁移到 Hermes 夜间自进化：evolver/skill-review 的"探索（新建 skill）vs 利用（patch 现有）"节奏目前靠固定 cron 周期，可改成按"近 N 次 patch 的采纳率"自适应——采纳率高=已收敛应多 patch，低=该探索新 skill。
  • RuN 残差架构迁移到 duck_show.py 快速版：已定稿的 ×1.7 速度拍式轨迹是"先验"，IMU 闭环微调是"残差"——提案 130（连续插值流）的架构描述可直接引用 RuN 的先验+残差分解语言。
