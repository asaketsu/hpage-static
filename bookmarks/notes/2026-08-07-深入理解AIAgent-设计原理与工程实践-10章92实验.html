归纳总结

这是目前最系统的中文 AI Agent 工程教材——10 章 92 个实验，从 Agent 基础公式到自我进化、多模态、多 Agent 协作全覆盖。核心特点：

  1. 核心公式贯穿全书：Agent = LLM + 上下文 + 工具，每一章都是这个公式的某个维度的展开
  2. Harness 工程优先：第 1 章就明确"Harness 工程才是竞争力"——不是模型，而是围绕模型构建的工程体系
  3. 92 个可运行实验：不是纯理论，每个概念都有配套代码
  4. 覆盖最新前沿：MCP 协议、SFT vs RL、VLA 模型、Sim2Real、斯坦福 AI 小镇
  5. 第 7-8 章最有深度：模型后训练（16 实验）+ 自我进化（6 实验）是全书的精华

结合最新研究与技术变化

1. 与 Coding Agent Harness 解剖学（Mastra）笔记的直接关联

Ch 1 的"Harness 工程才是竞争力"与 Mastra 文章的核心论点完全一致——Agent 的竞争力不在 LLM 本身，而在上下文管理、工具编排、会话持久化、审批链等 Harness 层。Ch 2 的上下文工程直接对应 Mastra 的 Observational Memory。

2. 与自进化四波浪潮 + Prime Agent 笔记的关联

Ch 8（Agent 的自我进化）的"不改权重也能成长"正是 Prime Agent Continual Harness 和 SkillOpt 的理念——通过外部经验积累（Skill/Prompt 蒸馏）实现进化，而非修改模型权重。

3. 与 LLM 微调成本工程笔记的关联

Ch 7（模型后训练）的"何时选 SFT、何时选 RL"决策框架与微调笔记的 2×2 矩阵互补——前者从训练方法角度，后者从成本/频率角度。

4. 与 Hands-On Modern RL 笔记的互补

两本书形成完美互补：
- 本书（AI Agent Book）：Agent 的工程实践（上下文/工具/记忆/评估/协作）
- Hands-On Modern RL：Agent 的训练理论（RLHF/DPO/GRPO/Agentic RL）
- 交叉点：Ch 7（后训练）↔ Modern RL Part IV（LLM 对齐）

5. 与具身智能方向的关联

Ch 9 的 SimpleVLA-RL + XLeRobot + Sim2Real 抓取实验直接对应用户的 VLA/具身智能研究方向。Ch 7 的 RLVP（视觉-语言-动作 RL）是 VLA 模型的训练方法。

趋势判断

  • Agent 教材正在系统化——从零散博客到 10 章 92 实验的系统教材，说明 Agent 工程正在成熟为独立学科
