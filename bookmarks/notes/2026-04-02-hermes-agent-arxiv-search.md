## 摘要

最近 Hermes Agent 很火。一个做 NLP 的同学问作者：知不知道哪篇论文用了 learning rate schedule（学习率调度）？

这个问题促成了这篇文章——展示 Hermes Agent 新增的学术论文搜索功能。

## 关键要点

1. **学术论文搜索能力**: Hermes Agent 新增了搜学术论文的功能，可以直接查询特定技术/方法在论文中的应用
2. **典型场景**: 当研究者想找"某篇论文用了某某方法"时，Hermes Agent 可以快速定位
3. **与 arxiv 集成**: 底层利用 arxiv 等学术数据库进行检索

## 技术启发

- Hermes Agent 持续扩展能力边界，从日常助手向科研工具演进
- 学术搜索是 AI Agent 的重要应用方向——将自然语言问题转化为精确的论文检索
- 类似能力可参考 Hermes 的 `arxiv` skill（scholar-assist）

## 相关资源

- Hermes Agent arxiv skill: 已内置，支持论文检索/摘要/翻译
- Karpathy 的 LLM Wiki 项目: 知识库构建思路
