# 灵巧手的控制方法与模型——从"算力不够经验凑"到"数据驱动"

## 出处

微信公众号「VPERED 前进挡」，2024年以来灵巧手赛道综述，拆解三大控制范式的技术路线与优劣。

## 内容整理

### 三大控制范式

| 范式 | 核心思路 | 代表方法 |
|------|---------|---------|
| **基于模型控制** | 建物理模型→控制理论计算 | 力位混合、阻抗控制、MPC |
| **无模型学习控制** | 让机器自己学 | 深度RL（PPO/SAC）、模仿学习（BC/扩散策略/DAPG） |
| **混合分层控制** | 取各家之长 | 高层学习型+低层模型型、KineDex |

---

### 一、基于模型控制：经典但遇到瓶颈

#### 力位混合控制（Force/Position Hybrid Control）

任务空间分解为"用力控制方向"和"用位置控制方向"：

```
F_cmd = S · F_desired + (I − S) · K_p · (x_desired − x_actual)
```

S 是对角选择矩阵：元素为1的方向用力控，为0的方向用位置控。

**典型场景**：拧瓶盖——轴向用力控制保证不捏碎，旋转方向用位置控制保证拧得动。

#### 阻抗控制（Impedance Control）

控制力与位置的关系，给末端设计"虚拟弹簧-阻尼-质量"系统：

```
M_d · ẍ + B_d · ẋ + K_d · (x − x_d) = F_ext
```

- 阻抗高 → 刚性大，外力难改变运动
- 阻抗低 → 柔顺性好，轻轻一碰就偏移

**代表工作**：DLR-HIT II 五指灵巧手用笛卡尔阻抗控制处理柔性关节。

#### 基于优化的控制（MPC）

```
min Σ [ ℓ(x_k, u_k) ] + V_f(x_N)
k=0..N-1
s.t. x_{k+1} = f(x_k, u_k),  x_0 = x(t)
```

每个控制周期求解优化问题，只执行第一个控制量 u₀，然后滚动前进。

**致命问题**：灵巧手的接触动力学太复杂——20自由度Shadow Hand + 未知物体接触面变化，建模误差迅速累积。

---

### 二、学习型控制：当前主流方向

#### 深度强化学习（Deep RL）

最大化期望累积奖励：

```
J(π) = E_{τ~π} [ Σ γ^t · r(s_t, a_t) ]
```

**里程碑**：OpenAI 2018 用 Shadow Hand 在仿真里学会解魔方，然后 Sim-to-Real 迁移到真实硬件。

**常用算法**：
- **PPO（Proximal Policy Optimization）**：工业界最常用，clipped objective 防止策略更新太大导致崩溃
- **SAC（Soft Actor-Critic）**：最大熵强化学习，探索效率更高

**两个硬伤**：
1. 数据效率低——数亿步交互才能学会一个任务
2. 奖励设计难——reward hacking 风险

#### 模仿学习（Imitation Learning）

不从零探索，直接从人类演示中学习。2025年4月天津大学、ETH、中科院自动化所联合发表综述《Dexterous Manipulation through Imitation Learning: A Survey》。

**行为克隆（Behavior Cloning）**：

```
L_BC = − Σ log π_θ(a | s)  (s,a) ∈ D
```

让策略 π_θ 在状态 s 下尽可能复现专家动作 a。简单有效，但有"复合误差"问题——小错误逐步累积导致任务失败。

**扩散策略（Diffusion Policy）**：2024年以来明星方向，用扩散模型建模多模态动作分布。

```
a_{t-1} = (1/√α_t) · (a_t − (1−α_t)/√(1−ᾱ_t) · ε_θ(a_t, s, t)) + σ_t · z
```

从高斯噪声 a_T 开始，逐步去噪生成动作序列。优势：同一个状态可以生成多种合理动作，完美解决多模态问题。

**DAPG（Demo Augmented Policy Gradient）**：RL + IL 结合，用人类演示提供初始策略，再用 RL 微调。

```
L = L_RL + λ · L_Demo
L_Demo = Σ log π_θ(a | s)  (s,a) ∈ D
```

既减少探索成本，又保留 RL 的优化能力。

### 三、混合与分层控制

高层用学习型方法做任务规划和策略选择，低层用基于模型的方法做力位控制。

**KineDex 框架**（同济/清华/上海交大/港大，CoRL 2025）：通过"手把手"示教直接传递人类动作到灵巧手，同步采集触觉信息。九项精细任务平均成功率 74.4%，数据采集效率比遥操作提升两倍以上。

---

### 四、Sim-to-Real：跨越仿真与现实鸿沟

**Domain Randomization**：在仿真中大量随机化物理参数（摩擦系数、质量、阻尼等），让策略学会在各种参数下都能工作。

```
max_θ E_{ξ~p(ξ)} [ J(π_θ, ξ) ]
```

OpenAI 魔方项目随机化了摩擦、质量、视觉外观等几十个参数，最终成功迁移到真实 Shadow Hand。

**Domain Adaptation**：学习一个从仿真到现实的映射，缩小分布差异。

**系统辨识**：用真实数据校准仿真参数，让仿真更接近现实。

---

### 五、触觉感知：被低估的关键维度

大部分控制方法依赖视觉输入，但精确操作（插入卡片、转动钥匙、处理可变形物体）时视觉不够用。

- **T-Rex 框架**（UC Berkeley/NVIDIA/斯坦福）：把视觉、语言和触觉集成到统一学习框架
- **NeuralFeels**（Meta FAIR）：融合触觉和视觉，让机械手对未知物体持续 3D 建模，跟踪精度最高提升 94%

---

### 各路线对比一览

| 控制方法 | 优势 | 劣势 | 代表工作 |
|---------|------|------|---------|
| 力位混合控制 | 物理意义清晰，实时性好 | 需精确建模，泛化差 | 经典工业机器人控制 |
| 阻抗控制 | 柔顺性好，适合接触任务 | 参数调节依赖经验 | DLR-HIT II |
| 深度强化学习 | 无需精确模型，可处理高维空间 | 数据效率低，奖励设计难 | OpenAI魔方 |
| 行为克隆 | 简单高效，无需奖励函数 | 复合误差，多模态建模弱 | DAPG |
| 扩散策略 | 多模态建模强，泛化好 | 推理速度慢，计算成本高 | Diffusion Policy |
| 混合分层控制 | 取各家之长，鲁棒性好 | 系统复杂，工程量大 | KineDex |

---

## 归纳总结

灵巧手控制正在经历从"模型驱动"到"数据驱动"的范式迁移。最优秀的系统不是纯模型或纯学习，而是把学习型方法的泛化能力和基于模型方法的可解释性融合在一起。

**三大趋势**：
1. 触觉感知将深度融入控制闭环——纯视觉控制的天花板已经到了
2. Foundation Model for Manipulation——类似 RT-2、OpenVLA 的大模型正在尝试做通用操作策略
3. Sim-to-Real 效率——数据采集成本居高不下，仿真训练效率直接决定技术落地速度

## 趋势判断

1. **触觉是下一个突破口**：纯视觉控制的天花板已经到了，触觉感知正在从"可选模块"变成"必选项"
2. **扩散策略是模仿学习的新方向**：多模态建模能力强，能处理同一个状态多种合理动作的问题
3. **Sim-to-Real 仍是 open problem**：没有银弹，Domain Randomization 是当前最实用的方法
