一句话总纲

几百行 C++11 标准库（vector/cmath/random，零第三方依赖）就能把神经网络从黑盒变白盒：数学工具层→激活函数（前向+导数成对）→Linear 层（前向 y=Wx+b / 反向三偏导）→NN 总装（多态流水线）→XOR 万轮训练 0.693→0.0004 收敛。核心只有一句话：反向传播就是链式法则——每层拿到上游梯度，乘自己的导数，传给下一层。

一、内容整理

1.1 为什么值得折腾

会调包 ≠ 懂原理：loss.backward() 里权重怎么更新？梯度怎么逐层传回？ReLU 负区间导数为何 0？Sigmoid 梯度消失从哪来？——答不上来说明你和神经网络之间隔着一个 PyTorch。会开车不等于懂发动机。

1.2 训练 = 猜数字 + 修正的循环（四步）

步骤 干什么 直觉
① 前向传播 数据逐层"加权求和+非线性变换"到输出 网络猜答案
② 算损失 预测 vs 真实 → 错得多离谱的分数 评估猜得偏不偏
③ 反向传播 链式法则逐层回传"贡献度"（梯度） 找出谁的罪责大
④ 梯度下降 每权重沿梯度反方向走一小步 有错就改

循环几千次：瞎猜 → 会猜。

1.3 分层架构（本机验证版实现）

应用层：XOR Demo / 自定义数据 / predict
   ↓
NN 类：add()（搭积木加层）/ forward_prop / backward_prop / fit()
   ↓ layers: [Linear]→[ReLU]→[Linear]→[ReLU]→[Linear]→[Sigmoid]
数学工具层：dot / transpose / element-wise / 均匀初始化

多态核心：所有层继承 Layer 基类，两个纯虚函数 forward/backward——NN 类不知道每层是什么，只按顺序调用；加新层=继承+实现+add。

1.4 反向传播三偏导（全系统灵魂）

梯度 公式 含义
dL/dW dY · X^T 权重梯度——决定权重怎么改
dL/dB dY 偏置梯度——直接相等
dL/dX W^T · dY 输入梯度——传给上一层继续反传

激活层无可学参数，反向只做一件事：上游梯度 ⊙ 激活函数导数（链式法则）。

1.5 为什么必须有激活函数（数学证明）

两层线性叠加：y = W2(W1·x + b1) + b2 = (W2·W1)x + (W2·b1+b2) = W'x + b'——还是一层。没有非线性，再深也是白搭。激活函数的作用是"把直线掰弯"。

1.6 XOR：神经网络的入学考试

(0,0)/(1,1) 一类，(0,1)/(1,0) 一类——没有直线能分开，单层感知机永远解不了；至少一个隐藏层引入非线性才行。万轮训练后 4/4 全对。

1.7 工程决策四条

决策 理由
面向对象+多态 Layer 基类两个纯虚函数，新层即插即用
前向缓存输入 Linear 存下 x，反向直接用（空间换时间）
逐样本 SGD 教学简单直观（生产用 batch 更稳）
随机初始化 全 0 初始化 → 神经元全一样 → "复制粘贴"退化

1.8 调参速查

现象 原因 解决
Loss 不降 lr 太小 0.01→0.1
Loss 震荡/NaN lr 太大 0.1→0.001
预测全 0/1 初始化不当 换种子/缩范围
不收敛到 0/1 Sigmoid+MSE 二分类用 BCE

3.3 梯度消失/爆炸的代码级理解

Sigmoid 导数两端趋 0 → 手写 sigmoidDer(input)*gradOut 连乘逐层缩小——消失在代码里看得见；权重初始化太大 → 反之爆炸。解决方案（Xavier/He/残差连接）都是对这个连乘的对抗。

四、归纳总结：核心公式速查

前向：  y = Wx + b → a = σ(y)
反向：  dL/dW = dY·X^T    dL/dB = dY    dL/dX = W^T·dY
激活：  dL/dZ = dL/dA ⊙ f'(Z)
更新：  W = W - lr·dW
链式：  dL/dW = dL/dY · dY/dZ · dZ/dW（复杂度 ∝ 层数，非指数）
