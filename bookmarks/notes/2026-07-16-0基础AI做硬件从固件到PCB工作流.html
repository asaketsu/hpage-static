一、内容整理

1.1 核心主张

不会写代码、不会画板，现在也能做出能跑的硬件——AI 把"写固件"和"画 PCB"这两步最劝退的门槛压到几乎为零。全流程 0 成本起步（工具全免费，只花板子钱），一个周末就能搞定。

1.2 上半场：0 成本写固件 — Aily Blockly

工具：Aily Blockly（GitHub 2.2k ⭐ 开源项目），浏览器打开即用，支持云端+本地混合编译，直接烧录到开发板。

核心能力：
- 将「图形化积木」和「AI 自然语言」结合
- 用大白话描述需求 → 自动生成代码
- 支持硬件：Arduino、ESP32、STM32、RP2040、NRF5x
- 国内下载：yiyu.pro/download

实战示例：ESP32 读取 BMS 保护板过充状态引脚

自然语言输入："用 ESP32 写一个程序：读取 BMS 保护板的过充状态引脚，引脚为高时红灯亮、绿灯灭；正常时绿灯亮、红灯灭。用 Arduino 框架，引脚用 GPIO 定义。"

AI 几秒内生成完整代码，下载→编译→烧录，一次成功。从打开软件到看到灯亮，不到 1 小时。

踩坑提示：AI 不知道你的硬件实际怎么接线。生成后一定要对照原理图检查引脚配置。焊接、接线、万用表测量，这些 AI 帮不了你。

1.3 下半场：0 基础画 PCB — EasyEDA Agent

工具：EasyEDA Agent（嘉立创 EDA 专业版 + AI 原生自动化层），用自然语言说需求，调用立创 EDA 官方接口自动画原理图和 PCB。

三大核心优势：

① 电路块库（最实用）
- 社区积累成熟外设电路：CH340 串口、ESP32 自动下载、按键去抖、USB-HUB、降压模块等
- 不用从头画，照拓扑抄，只把对外几根线重绑到主控网络即可
- 引脚用功能名引用，零改号

② 全流程自动化
- 原理图生成 → 导入 PCB → 布局 → 铺铜 → 丝印 → DRC，一条龙
- 每一步都跑 sch check / pcb drc，结果以数据说话

③ 真实校验
- 每一步都有门控验证（gate check），不是"看起来画完了"，而是 DRC 双归零

1.4 EasyEDA Agent 安装与使用

Agent 工具选择：WorkBuddy（内置免费 hy3 模型，开箱即聊，不用申请 API key）

安装四步：
1. 把 GitHub 地址丢给 Agent：github.com/zhoushoujianwork/easyeda-agent，Agent 自动跑一键脚本
2. 打开立创 EDA 专业版，开启「允许外部交互」
3. 装上连接器 .eext（或从立创插件市场一键装）
4. 启动并查健康：看到 healthy 就说明连上了

画图流程（对 Agent 说需求 → 确认里程碑）：

需求描述："画一个 ESP32-S3 小板，USB 5V 供电、降压到 3V3、CH340 烧录、两个按键、四角 M3 安装孔。"

自动流程：
原理图生成 → 导入 PCB → 四层叠层 → 布局 → GND 内电层/电源平面 → 丝印 → 挖槽
（每步跑 DRC，最终 pcb drc 双归零，layout-lint 100/100）

全程不用懂 EDA，只需在每个里程碑点确认（单面/双面、接口朝向等需要人拍板）。

1.5 完整项目串联：BMS 监控小板

将两部分合起来就是一个能跑的完整项目：

  1. 板子：EasyEDA Agent 画 ESP32-S3 小板（USB 供电 + CH340 烧录 + 状态 LED）
  2. 固件：Aily Blockly 写程序，读取保护板状态，过充红灯/正常绿灯
  3. 打样：嘉立创打板几十块钱，几天到手

1.6 踩坑总结

  1. AI 不是万能的：引脚接错、规则漏检，生成完必须对照检查、亲自确认
  2. 硬件苦力活还在：焊接、接线、上电测试，AI 替不了
  3. 从小项目开始：先让一个 LED 闪起来、读个传感器，把"学习成本"降到"玩的成本"
  4. AI 是加速器，不是替代品：你得知道自己要什么，AI 才能帮你实现

二、查询拓展

2.1 EasyEDA Agent 与 EDA 自动化趋势

EasyEDA Agent 代表了 EDA 工具从"辅助画图"到"自动化生成"的范式转变。传统 EDA（Altium/KiCad）的 AI 辅助仅停留在自动布线层面，而 EasyEDA Agent 通过 Agent + 官方 API 接口实现了从需求描述到原理图/PCB 的全自动生成。GitHub 项目地址 zhoushoujianwork/easyeda-agent 采用 CLI + Skill 模式，本质是给 LLM 装了调用 EDA API 的"手"。

2.2 Aily Blockly 与图形化编程

Aily Blockly 是基于 Google Blockly 的扩展项目，核心创新是加入了 AI 自然语言生成代码层。区别于传统 Scratch（MIT 教育编程），Aily 直接面向硬件开发，生成的代码可以直接编译烧录。2.2k ⭐ 说明社区认可度较高。支持的芯片覆盖了主流嵌入式平台（Arduino/ESP32/STM32/RP2040/NRF5x）。

2.3 AI 辅助硬件开发的局限性

文章诚实地指出 AI 无法替代的部分：硬件接线验证、焊接、上电测试。这是因为 AI 只能操作"数字域"（代码+图纸），而硬件的"物理域"（信号完整性、EMC、热设计、机械装配）仍需工程师经验。AI 把"设计门槛"降低了，但"验证门槛"没有降低。

3.2 传统入门 vs AI 辅助入门

  • 传统：学 C → 装 IDE → 配编译链 → 画元件 → 连网络 → 布线 → DRC（数月）
  • AI 辅助：说需求 → 生成代码 → 说需求 → 生成 PCB → 确认里程碑 → 打样（周末）
  • 关键差异：学习路径从"啃手册+配环境"变为"说需求+看结果"，动手能力门槛大幅降低

四、趋势判断

4.1 EDA 工具的"Agent 化"将成为硬件开发新范式

依据：EasyEDA Agent 已实现从自然语言到 PCB 的全自动生成（含 DRC 校验），GitHub 开源 easyeda-agent CLI+Skill 模式可被 LLM Agent 调用。Altium/KiCad 等传统 EDA 如果不跟进 Agent 化，将面临用户流失。

4.2 "AI 加速器而非替代品"是当前阶段的准确认知

依据：文章多次强调 AI 替代不了焊接、接线、测试等"物理域"操作。当前 AI 在硬件领域的定位是"把设计门槛压到零"，但验证和实施仍需人工。这一认知与 LLM 在软件开发中的定位一致。

4.3 硬件开源生态将受益于 AI 工具链普及

依据：Aily Blockly（2.2k ⭐）和 EasyEDA Agent 均开源，降低了硬件入门门槛。更多人能参与硬件开发 → 更多开源硬件项目 → 更多成熟电路块 → 工具更好用，形成正循环。

4.4 "Agent + 专业工具 API"模式将扩展到更多工程领域

依据：EasyEDA Agent 的本质是 LLM + EDA API，这种"Agent 调用专业工具 API"的模式可以复制到机械 CAD（SolidWorks/Fusion360）、仿真（ANSYS/COMSOL）、PLC 编程等领域。WorkBuddy + hy3 模型的组合证明了无需自建 API 即可跑通。

五、关联分析

5.1 与双轮腿机器人 V2 项目（~/uclaw/project/wheel-legged-robot-v2）的关联

本文的工具链直接适用于双轮腿机器人的 PCB 迭代：
- EasyEDA Agent 可用于重新设计主控板（当前项目用 WeAct STM32H743 成品板，未来可定制 PCB）：描述需求如"STM32H743 + ODrive CAN 接口 + STS3025 舵机 TTL 总线 + MPU6050 I2C + ESP32-S3 USART3 + 电源三路隔离"，Agent 自动生成原理图和 PCB
- Aily Blockly 不适用于本项目（固件已用 C 手写，复杂度远超 Blockly 能力），但适合快速原型验证阶段

5.2 与 stm32-embedded-dev skill 的关联

stm32-embedded-dev skill 中定义的 STM32 嵌入式固件开发工作流（HAL 驱动 + FreeRTOS），与本文的 Aily Blockly 形成对比：
- Aily Blockly 适合：零基础快速验证、简单逻辑（LED/传感器读取）
- C + HAL 适合：复杂实时控制（LQR 平衡、IK 求解、1kHz 控制环）
- AI 辅助可加速：从自然语言生成 HAL 初始化代码框架，再人工细化

5.3 与 index-tts-analysis 项目（~/uclaw/project/index-tts-analysis）的关联

两者都是"AI 降低专业门槛"的案例：IndexTTS2 降低了语音合成的算法门槛，EasyEDA Agent 降低了 PCB 设计门槛。共同趋势是"AI Agent + 专业工具 API"正在重塑专业工具链。
