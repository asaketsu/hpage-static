## 摘要

开源 text-to-3D 领域在 2024-2026 年经历了从 LRM feed-forward 到 Flow-matching DiT 的范式跃迁。当前格局由三大阵营主导：微软 TRELLIS/TRELLIS.2（Structured Latents 表示，MIT 协议，13.2k★ / 8.8k★）、腾讯 Hunyuan3D 2.0/2.1（双阶段 DiT+Paint，14.3k★ / 3.7k★）、以及 VAST-AI TripoSR/TripoSG（单图快速重建）。行业已形成完整的 3D AIGC 管线：建模 → 纹理 → 重拓扑 → UV 展开 → 绑骨/动画，每个环节都有专门的开源模型。3D 场景生成（World Models）正成为下一个竞争焦点。

## 关键发现

### 1. 三大主流开源方案对比

**TRELLIS（微软，CVPR'25 Spotlight）**
- 核心：Structured LATent (SLAT) 统一表示，可解码为 Radiance Fields / 3D Gaussians / Mesh
- 架构：Rectified Flow Transformers + SLAT，参数量最大 2B
- 输入：text 或 image → 多格式 3D 资产
- 数据集：TRELLIS-500K（50 万多样化物体）
- 特色：灵活输出格式选择 + 局部 3D 编辑（variants generation）
- 硬件：最低 16GB VRAM（A100/A6000 验证），CUDA 11.8 或 12.2
- GitHub: https://github.com/microsoft/TRELLIS（MIT，13.2k★）

**TRELLIS.2（微软，CVPR'26 Oral）**
- 核心：Native and Compact Structured Latents（O-Voxel 表示）
- 定位：TRELLIS 的下一代，更紧凑高效的 latent 表示
- 已有 Apple Silicon 原生运行方案（trellis-mac，202pts HN 热帖）
- GitHub: https://github.com/microsoft/TRELLIS.2（MIT，8.8k★）

**Hunyuan3D 2.0/2.1（腾讯）**
- 架构：双阶段 — 3D-DiT 生成几何 + 3D-Paint 合成纹理（形状/纹理解耦）
- 输入：文本/图像/草图 → 高分辨率 3D + PBR 材质
- 2.1 升级：Production-Ready PBR Material，流程更完整
- 模型矩阵：从 0.6B mini 到 1.3B Paint，含 Fast/Turbo 蒸馏变体
- 生态：Blender 插件、FlashVDM 加速器（ICCV'25）、HY3D-Bench 基准
- GitHub 2.0: https://github.com/Tencent-Hunyuan/Hunyuan3D-2（14.3k★）
- GitHub 2.1: https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1（3.7k★）

**TripoSR（Stability AI × Tripo AI）**
- 定位：极速单图→3D（A100 上 <0.5 秒），轻量级（~6GB VRAM）
- 架构：基于 LRM（Large Reconstruction Model），Transformer feed-forward
- 适用：快速原型、游戏背景资产
- 局限：拓扑质量一般，非 DiT 架构（属于上一代范式）

### 2. 行业管线全景（来自 awesome-3D-Generative-Models）

3D AIGC 已形成完整流水线，每个环节都有专门开源模型：

- **3D 表示**：VecSet（Hunyuan3D/TripoSG/Step1X-3D 共用）、SLat（TRELLIS）、O-Voxel（TRELLIS.2）、GShell、FACE
- **建模（Flow-matching DiT）**：Ultra3D、Hunyuan3D-2/2.1、TripoSG、Step1X-3D、Direct3D-S2、Hi3DGen、TRELLIS/.2、LATO.2（Meshy AI）、MeshGen
- **纹理生成**：SyncMVD、TEXGen、MaterialAnything、MaterialMVP、RomanTex、NaTex、SeqTex（SIGGRAPH Asia'25）
- **重拓扑（Artist Mesh）**：BPT、DeepMesh（RL 对齐）、MeshMosaic、SATO
- **UV 展开**：SeamGPT、ArtUV、SeamCrafter（RL）、PartUV、MeshTailor
- **绑骨/动画**：UniRig（SIGGRAPH'25）、AnimateAnyMesh、FreeArt3D、PhysX-3D（NIPS'25 Spotlight）
- **加速**：FlashVDM（腾讯，ICCV'25，lightning vecset decoder）
- **后训练对齐**：DeepMesh（RL）、Nabla-R2D3、DreamDPO

### 3. 3D 场景生成（World Models）— 下一战场

- 开源：HY-World-2.0（腾讯）、InSpaTio WorldFM、NVIDIA Lyra2、WorldGrow、FantasyWorld
- 闭源：World Labs（Marble）、Spaitial AI、Google DeepMind Genie、Runway ML、Odyssey ML

### 4. 范式演进时间线

- 2024 前：NeRF / Gaussian Splatting（需多视角输入）
- 2024：LRM 范式（单图 feed-forward）— TripoSR、OpenLRM
- 2024-12：SLAT 范式（TRELLIS，统一表示 + Flow Transformer）
- 2025：Flow-matching DiT 成主流 — Hunyuan3D 2.0/2.1、TripoSG、Step1X-3D
- 2025-06：PBR 材质生成成熟（Hunyuan3D 2.1 Production-Ready）
- 2025-12：O-Voxel 紧凑表示（TRELLIS.2，CVPR'26 Oral）
- 2026：3D 场景/世界模型起步，物理属性生成（PhysX-3D）

### 5. 评估指标体系

- 几何：ULIP-T/I、Uni3D-T/I（语义一致性）、Chamfer Distance（形状相似度）、Normal Consistency
- 纹理：CLIP-FiD、CMMD、CLIP-I、LPIPS
- 基准：HY3D-Bench（腾讯开源）

## 对工作的价值

1. **Jetson Orin Nano 部署评估**：TripoSR（6GB VRAM）和 Hunyuan3D-mini（0.6B）是边缘部署可行选项；TRELLIS 需 16GB+ 不适合 Jetson
2. **内容管线闭环**：text→image（SD/Flux）→3D（TRELLIS/Hunyuan3D）→动画（UniRig）→场景（HY-World），全开源可串联
3. **Blender 集成**：Hunyuan3D 已有官方 Blender 插件，可直接嵌入现有 3D 工作流
4. **开源协议友好**：TRELLIS（MIT）、TripoSR（MIT）、Hunyuan3D（Other/腾讯协议），均可本地部署定制
