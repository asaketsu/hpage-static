## 摘要

距上次笔记 9 天，Molmo 指向能力领域无颠覆性范式转移（grounding token 范式仍是核心），但有 4 条论文级增量：MolmoPoint 技术报告正式发布（arXiv:2603.28069）、MolmoWeb 论文发表（含 94.7% test-time scaling 结果）、NVIDIA PIO 基准独立验证 Molmo grounding 数据的价值、MolmoAct2 训练配方细节披露（720 小时 BimanualYAM 数据集）。

## 关键发现（增量）

### 1. MolmoPoint 技术报告发布 — arXiv:2603.28069

历史笔记基于官方博客，本次论文正式版提供了完整消融数据：
- MolmoPoint-8B 在 MeViS valid/valid-u 达 63.5/72.2 J&F（vs Molmo2-8B 62.3/70.8）
- Molmo2-Track 全域 +5.7 J&F、+3.1 F1、+2.5 HOTA
- **消融关键结论**：grounding tokens 贡献主要提升，新追踪数据改善多样性场景 — 证明架构改进 > 数据堆量
- 同数据同训练流程下，MolmoPoint-8B 仍比 Molmo2-8B 高近 2 点（PointBench），隔离验证了 grounding token 本身的价值

### 2. GUI 指向的 64-crops 技巧

论文披露 64 crops 推理增强：MolmoPoint-8B 从 36.4→39.4、MolmoPoint-GUI-8B 从 60.2→61.1（ScreenSpot-Pro 口径）— 推理时多裁剪是零训练成本的 GUI grounding 提升
手段，可直接复用。

### 3. MolmoWeb 论文发表 — arXiv:2604.08516

- 超越同规模开源模型 Fara-7B、UI-Tars-1.5-7B、Holo1-7B
- 超越基于 GPT-4o 的 set-of-marks（SoM）Agent
- **94.7% 成功率来自 best-of-N 并行 rollout 测试时扩展** — 单次性能与 BoN 性能差距是该模型的关键特征
- HF checkpoint 2026-03-29 有过更新，早下载的需重新拉取

### 4. NVIDIA PIO 基准独立验证

NVIDIA Cosmos Lab 的 PIO（embodied 指向基准，覆盖自动驾驶/机器人操纵/室内/厨房四场景）结论：有 grounding 监督的模型（Molmo-7B-D、Gemini-2.5-Pro、Qwen-2.5-VL）在精确空间任务上显著优于 GPT-4o、Claude-3.7 等通用 VLM — **第三方证据：grounding 数据配比是空间能力的关键变量，纯通用 VLM 不擅长指
向**。

### 5. MolmoAct2 训练配方细节（YouTube 论文解读补充）

- BimanualYAM：720 小时双臂遥操作数据，28 个实用任务（叠衣、收桌、扫码购物）
- OpenFAST 开放权重 action tokenizer + flow-matching 连续动作专家
- MolmoAct2-Think 自适应深度推理：训练时注入噪声深度预测，强制策略学会补偿 — 「把韧性训进策略」

## 对工作的价值（增量）

- 64-crops 推理增强是零成本可复用技巧，适用于任何 GUI grounding 场景
- MolmoWeb 的 best-of-N 路线证明小模型 + 并行 rollout 可逼近大模型 Agent 成功率 — 与本地推理成本模型契合
- PIO 基准可作为我们评估「哪个 VLM 能做精确指向」的第三方标尺

## 行动建议（增量）

1. 如需 GUI 自动化指向精度，直接采用 64-crops 推理配置（论文已验证 +3 点）
2. MolmoWeb-8B 已上 HuggingFace（allenai/MolmoWeb-8B），可用于本地浏览器自动化实验
3. 引用 MolmoPoint 论文消融数据（而非博客口径）作为 grounding token 范式的论据
