## 三大核心组件

### 1. 广告系统（ads/）

| 文件 | 功能 |
|------|------|
| `partition_organic_blender.rs` | 广告与自然内容混排 |
| `safe_gap_blender.rs` | 控制广告间距（至少隔 N 条自然帖子） |
| `ads_brand_safety_hydrator.rs` | 品牌安全过滤（广告不挨暴力/色情内容） |

关键设计：广告不是硬插，是跟自然内容一起排队打分，"赢"了才出现。

### 2. 内容审查管线（grox/）

| 分类器 | 功能 |
|--------|------|
| `spam.py` | 垃圾内容检测 |
| `post_safety_screen_deluxe.py` | 安全审查（"豪华版"） |
| `safety_ptos.py` | 平台服务条款策略检查 |
| `banger_initial_screen.py` | **爆款初筛**（判断帖子"炸不炸"，炸的优先排） |
| `reply_ranking.py` | 回复排序 |
| `classifier.py` | 通用内容分类 |

用 Python 写审查逻辑，Rust 跑毫秒级排序。Python 管"该不该存在"，Rust 管"排在哪"。

## 🔑 最核心：15 种行为概率预测

Phoenix 的 Grok Transformer 对每条帖子预测 15 种用户行为概率：

**正向（11 种 — 加分）**

| 行为 | 含义 |
|------|------|
| P(favorite) | 点赞 |
| P(reply) | 回复 |
| P(repost) | 转发 |
| P(quote) | 引用 |
| P(click) | 点击 |
| P(profile_click) | 查看主页 |
| P(video_view) | 看视频 |
| P(photo_expand) | 展开图片 |
| P(share) | 分享 |
| P(dwell) | 停留浏览 |
| P(follow_author) | 关注作者 |

**负向（4 种 — 重扣）**

| 行为 | 含义 |
|------|------|
| P(not_interested) | 不感兴趣 |
| P(block_author) | 拉黑 |
| P(mute_author) | 静音 |
| P(report) | 举报 |

最终得分：`Final Score = Σ (weight_i × P(action_i))`

**关键设计：Candidate Isolation** — Transformer 推理时候选帖子互相"看不见"，每条只看用户历史行为。注意力掩码切断候选间依赖，保证分数独立、稳定、可缓存。

**100% 端到端学习**：所有手工规则全砍了，靠 Transformer 端到端学出权重。

## 💡 对 AI Agent 推荐系统的启示

1. **多行为预测优于单目标** — 不只预测"点击"，而是 15 维行为向量，正负双向
2. **候选隔离设计** — 评分必须独立于候选数量，否则不可缓存
3. **审查与推荐分离** — Python 管"能不能发"，Rust 管"排在哪"，语言分层
4. **爆款优先信号** — 专门的 `banger_initial_screen` 分类器，"炸不炸"影响排序
5. **广告不是硬插** — 跟自然内容同排队同打分，用户体验更好
