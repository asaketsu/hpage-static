〇、定锚：我的现状与目标

我的 Hermes Agent 体系已积累 300+ Skills，正在从「人工添加技能」向「自进化技能生命周期」演进（skill-health-tier、MDSKILL 精读刚提出动态后验化）。当前核心痛点：技能库越大，选择哪个技能/技能组合来服务具体任务实例，成为最大瓶颈——MDSKILL 的消融已证明检索方式差 20.4 分（动态检索 93.8 vs 仅相关性 73.4）。这篇论文恰好回答同一问题的模型层版本：原子能力专家库建好后，如何按「实例」路由组合。期望从中拿到可迁移的路由蒸馏模式。时间尺度：本周内可评估是否落地到 skill 路由层。

一、内容整理

1.1 核心问题：分解 ≠ 组合

  • 〔观点，2026〕现有数学推理增强（指令微调/工具调用/RL on CoT）都把推理当作单体能力优化；Kuang et al. 的 Atomic Thinking（arXiv 2509.25725）已把数学推理分解为原子技能并逐个训练，但分解本身不回答"一个具体问题该用哪组技能"——推理时的技能选择与组合机制缺位。
  • 〔方法，2026〕AMR 的答案：两阶段框架——离线搜索组合原型 + 在线轻量路由，把「每题在线优化」的代价压缩成「一次 TF-IDF + 逻辑回归前向」。

1.2 方法三组件

  • LoRA 专家库〔方法，2026〕：按 Kuang 分类法训练 N=7 个原子能力 LoRA（代数/几何/分析/拓扑 + 概念理解/正向推理/反向推理）。训练配方统一：4-bit 量化、LoRA rank 16、batch 16、lr 1e-4、2 epochs、LLaMA-Factory。
  • 组合原型集〔方法，2026〕：线性组合 W(w) = W0 + Σ wi·ΔWi，用无梯度优化器 NGOpt 在验证集不同支撑子集上反复搜索 w（搜索空间 [-1.5,1.5]^7，L1 稀疏正则 λ=0.05），得到多个低验证损失的局部最优解，去重后构成 M=9 个「组合原型」π1...π9。关键设计：放弃唯一全局最优，收集多样化局部最优——不同题型适配不同专家配比。
  • 实例级路由〔方法，2026〕：路由选择被形式化为分类任务——
  • 用参考解的 token 级 NLL 给每题打伪标签（NLL 最低的原型为该题标签）；
  • margin 过滤：Δn = 次低NLL − 最低NLL ≥ δ=0.02 才保留，滤掉原型间差异模糊的样本；
  • 512 条高置信样本训练 TF-IDF + 多项逻辑回归路由器（L2 正则）。
    推理时路由器预测原型索引 → 取出权重向量线性合并 LoRA，零在线优化。

1.3 关键实验数据

  • 〔数据，2026〕Qwen2.5-Math-Instruct-7B + AMR：AtomicMath Field 均分 Level1 64.4→68.1（+3.7）、Level2 59.3→63.7（+4.4）；Logic 均分 39.4→46.8（+7.4 最大增益）。
  • 〔数据，2026〕越级打怪：InternLM2-7B+AMR 的 Analysis L1 48.4 超 Abel-13B（40.4）；Qwen-7B+AMR 的 Analysis L2 73.5 超 Claude 3.7 Sonnet（68.1）和 GPT-4o（53.2），Geometry L2 53.8 超两者（39.0/36.3）。⚠️ 注意整体均分仍被 Gemini 2.5-Pro（71.6/70.7）碾压——胜利是分领域的，非全面。
  • 〔数据，2026〕消融阶梯（Qwen 基座）：混合数据联合训练单 LoRA +1.2 < 最佳单一原子 LoRA +2.8 < 静态全局组合 50.6→52.7 < 支撑集动态组合 +1.8 < AMR 实例级路由 56.4（最优）。「原子专业化 > 数据混合」与「实例级 > 全局静态」两级结论都有数据支撑。
  • 〔数据，2026〕LOO 逐专家剔除：Concept（概念理解）最关键——剔除后总分 56.4→52.7、Logic 46.8→42.4；其次 Analysis（55.4）、Algebra（55.7）；Forward/Backward/Geometry/Topology 剔除影响 <0.3。收益高度集中于少数核心专家。
  • 〔数据，2026〕超参敏感性：9 原型全用 > top-6 > top-4（56.4/54.3/53.8）；δ=0.02 最优；路由训练样本 512 最好（256/512/2048/全量7439 = 55.4/56.4/56.0/55.8）——少量精选 > 大量含噪。
  • 〔数据，2026〕效率：RTX 3090 上 256 题推理，在线动态搜索 184.0s vs AMR 66.7s，2.76× 加速（放弃在线优化的直接收益）。

三、归纳总结

3.1 「搜索-蒸馏-路由」范式框架

离线：专家库(LoRA×N) ──无梯度搜索(不同支撑子集)──→ 原型池(M个局部最优)
                                │
        伪标签：每题 NLL 最低的原型 + margin≥δ 过滤
                                ↓
在线：新问题 x ──TF-IDF──→ 轻量路由器 ──→ 原型 m* ──→ 权重向量 ──→ 合并专家 ──→ 生成

本质是把「实例级优化」这一昂贵计算 amortize 到离线阶段，在线只付一次分类器前向的代价。

3.2 三维护筛

  • 优点：①证据强度扎实——3 随机种子、消融/LOO/超敏/效率四组分析完备，结论链条干净（联合<单原子<静态<动态<实例级）；②margin 过滤 + 小样本最优（512>7439）对伪标签噪声的处理朴素有效；③工程可行——全流程 LLaMA-Factory + NGOpt 现成件，单卡 3090 可复现。
  • 缺点：①Math 域自证（AtomicMath 由同团队前身工作定义），域外泛化未测；②TF-IDF+逻辑回归是词面特征路由器，对语义同构但表面不同的问题（换元法换皮）可能路由错；③线性 LoRA 组合的负权重干涉风险未讨论；④对最强基座增益收窄（Qwen +3.7~4.4），暗示能力越强专家分工越模糊。
  • 借鉴点：①原型池而非单全局解——直接迁移到 skill bundle 设计：按任务类型维护 M 个「技能组合模板」而非单一万能流程；②NLL+margin 伪标签蒸馏——改造为「任务→技能组合」映射数据的生产方法：用执行结果评分代替 NLL，margin 过滤掉胜负不明的样本；③少量精选样本训练路由器——skill 路由器不需要海量数据，512 条高置信映射即可。

四、趋势判断

趋势1：能力分解后，「组合层」成为新战场（上升）

依据：Atomic Thinking 2025-09 只做分解与激活，AMR 2026-11 补组合路由，MDSKILL 2026-11 做技能内化检索——三篇同向。对我：机会——Hermes 的 skill 检索/组合层正是对应物，先发可积累数据。

趋势2：在线优化的「离线蒸馏化」持续（上升）

依据：AMR 用 2.76× 加速证明 amortize 可行；SPORK（07-08 精读）用自推测 fork 干同一件事。对我：Hermes Gateway 的模型选择/技能选择应走同一模式——昂贵探索离线做，在线只查表。

趋势3：轻量路由器 > 神经路由器（分化）

依据：AMR 明确拒绝 Transformer 路由器（延迟考虑），TF-IDF+logreg 足够；但 MDSKILL 用 Thompson 采样价值感知检索。短期看任务特征区分度：词面可分→轻量，语义需深层→神经。对我：skill 路由可先上轻量版（现有 skill-health-tier 数据即可训）。

趋势4：技能库的 Pareto 集中律（持续验证）

依据：AMR LOO 显示 Concept/Analysis/Algebra 三专家贡献绝大部分增益；EvoSOP 消融证明剪枝>创建。两篇独立工作同结论：库不需要大，核心少数。对我：skill 清理优先保核心技能做深，长尾技能大胆剪。

五、关联分析

5.1 与 MDSKILL 精读笔记（2026-11-05）的关联

同一主线的两周连续命中：MDSKILL 讲「技能记忆的检索内化」（Beta/半衰期/Thompson 采样动态检索，消融差 20.4 分），AMR 讲「技能专家的组合路由」（原型池+margin 过滤）。两者共同证明：库本身不是瓶颈，选择/组合层才是最大杠杆。差异：MDSKILL 在 prompt 层（技能内容注入），AMR 在权重层（LoRA 合并）——对 Hermes 而言 prompt 层可立即落地，权重层需训练资源。

5.2 与 EvoSOP 精读笔记（2026-07-10）的关联

EvoSOP 的 Prune 模块（消融证明剪枝>创建）与 AMR 的 LOO 分析互为印证：专家/技能贡献高度不均，维护全量库是负收益。AMR 补充了 EvoSOP 没给的定量证据（剔除单一专家的精确损失）。

5.3 与 microduck RL 训练线的关联

LOO 的「Concept 专家最关键」与课程训练中「基础能力先于高阶技能」同构——鸭子 RL 里先站稳（基础）后迈步（高阶）的课程顺序正是 Concept-first 的实体版。跨域一致性增强对该排课逻辑的信心。

5.4 与量化交易的关联

原型池 = 策略组合库；margin 过滤 = 只在分类置信时下注（regime 判别模糊时空仓）；512 精选样本 > 全量 = 用高质量样本校准策略权重。可直接映射到 A 股周期模型：Wyckoff 阶段判别器的置信门限就是 δ。

六、金句摘录

「A static combination such as applying fixed global weights to all problems fails to adapt to the diverse demands of different questions, often introducing irrelevant noise.」— 全局固定权重会引入无关噪声，这正是「万能流程」失败的原因。
「We use this NLL-selected label as a tractable proxy for prototype preference, rather than assuming that it is the unique semantic optimum.」— 伪标签是代理不是真理，margin 过滤是对这个诚实的工程回应。

八、拓展应用推荐

  • 自动化排障（watchdog/error-monitoring）：故障样本 → 排障技能组合原型路由，margin 低时走人工规则兜底
  • cron 任务分发：cron prompt 的任务描述 → TF-IDF 路由到「技能包」，替代当前全量 skill 列表注入的粗放模式
  • 量化策略选择：行情 regime 特征 → 策略组合权重原型，δ 置信门限控制模糊期空仓
  • Colab/训练车道调度：任务画像 → 车道组合（哪些脚本+哪些检查项打包），复制「离线搜索原型+在线轻查表」

九、指南分析

  • 可复用结构：「昂贵探索 → 离线原型库 → 伪标签蒸馏 → 轻量在线路由」四步范式，适用于一切在线代价高的选择问题（模型选择、工具选择、策略选择）。
  • 实验设计范本：消融阶梯（联合<单原子<静态<动态<实例级）每级只加一个变量，因果链清晰；LOO 逐项剔除给出重要性排序——比只报总量更可信。
  • 反例警示：小样本（512）优于全量（7439）训练路由器——数据多≠好，置信过滤后的少量数据常常更值钱，采集数据时要同时采集「置信度」维度。
  • 写作判据：诚实标注伪标签是 proxy 而非最优解，再用 margin 过滤工程化处理——承认方法局限与工程补救并存，比声称最优更有说服力。
