# LLM 驱动的量化因子挖掘 2026：从 Prompt 循环到自进化架构

> **学习日期**: 2026-07-29
> **来源**: arXiv 2025-2026 最新论文精读
> **核心论点**: LLM 因子挖掘正在经历从 "prompt-level 循环" 到 "parameter-level 自进化" 的范式跃迁，2026 年三篇里程碑论文各自代表一条技术路线。

出处：arXiv 2606.29194 / 2605.15412 / 2603.16365 | 2026-03 ~ 2026-06

## 一、技术演进全景（内容整理）

2025-2026 年 LLM 驱动的 alpha 因子挖掘领域出现了**三代技术架构**的清晰演进路径：

| 代际 | 核心架构 | 代表方法 | 关键局限 |
|------|---------|---------|---------|
| **第一代** | Prompt-level 生成-评估-反馈循环 | AlphaAgent, Chain-of-Alpha | 上下文爆炸、反馈漂移、大模型生成偏好趋同 |
| **第二代** | 程序级代码生成 + 知识注入 | FactorEngine, AlphaForgeBench | 依赖固定评估器，评估器盲区导致过拟合 |
| **第三代** | RFT 内化 + 多 Agent 自进化 | QuantEvolver, Agora(SJS) | 训练成本高、单 seed 验证不充分 |

## 二、三篇里程碑论文深度解析

### 2.1 QuantEvolver：从反馈循环到策略更新（RFT 路线）

**arXiv**: 2605.15412 | 2026-05-14

**核心创新**：将因子评估的"反馈"从 prompt 层面提升到**参数层面**（Reinforcement Fine-Tuning）。

**技术架构**：
- **Miner LLM** 被强化微调，直接内化历史优化经验
- 不再在 prompt 中堆叠历史候选因子和反馈 → 消除上下文爆炸
- **Diversity-Complementarity Reward**：兼顾因子多样性和互补性
- **Regime Backtest**：基于市场制度分段回测
- 持续积累高质量因子到 **Mined Factor Database**

**解决的三个核心问题**：
1. **上下文爆炸**：prompt 循环中历史因子不断堆叠 → 改为参数学习
2. **大模型生成偏好趋同**：大 LLM 的稳定偏好导致表达式结构性相似 → RFT 打破偏好锁定
3. **反馈漂移**：迭代反馈累积偏移 → 策略更新提供一致方向

**关键洞察**：prompt 循环的本质是"外挂记忆"，RFT 的本质是"内化记忆"。这与 Agent 领域的 OPD（On-Policy Distillation）思想一致——将外部知识压缩进参数空间。

### 2.2 Agora / SJS：密封联合搜索（多 Agent 自进化路线）

**arXiv**: 2606.29194 | 2026-06-28

**核心创新**：提出 **Sealed Joint Search (SJS)** 框架——将因子搜索和评估器本身都视为搜索对象，但通过信息流结构约束防止联合搜索退化为自我确认。

**关键发现**（论文最深刻的贡献）：
> "A search that converges against a fixed scorer overfits whatever the scorer cannot penalize"

这解释了为什么现有自动化 alpha mining 普遍存在 **out-of-sample generalization gap**：不是因为搜索算法不够好，而是因为**评估器的盲区被搜索算法系统性利用**。

**Agora 架构设计**：
- 5 个 LLM agent 类，通过 3 个通道通信
- 演化 8 个技能库 + 基于 AlphaGen 算子的 alpha 库
- 3 个评估器写报告聚合为一份简报，**保留分歧而非投票**
- 在 CSI 1000 上运行 100 轮

**实验结果**：
- 2026 年 91 天 holdout（密封自所有 LLM 输入）：Sharpe **+1.87**
- 最佳基线：+1.334（最优 seed）/ -0.755（跨 seed 均值）
- 将 Agora 的两个指标预加载到冻结库消融：仅恢复 +2.25 Sharpe 差距中的 +0.40
- 两个关键指标是**涌现的**而非设计的

**SJS 的五条结构约束**：
1. **角色分解**（Role decomposition）
2. **类型化角色间通信**（Typed inter-role communication）
3. **来源密封读取**（Provenance-sealed reads）
4. **版本化存储**（Versioned stores）
5. **基底本地晋升**（Substrate-local promotion）

### 2.3 FactorEngine：程序级知识注入因子发现

**arXiv**: 2603.16365 | 2026-03-17

**核心创新**：将因子视为 **Turing-complete 代码**，通过三个分离实现效果和效率双提升。

**三个关键分离**：
1. **逻辑修订 vs 参数优化**：LLM 负责方向性搜索，贝叶斯负责超参搜索
2. **LLM 引导搜索 vs 本地计算**：减少 LLM 调用次数
3. **LLM 使用 vs 本地计算**：可执行代码 vs 不可执行公式

**知识注入管道**：
- 从非结构化金融研报 → 可执行因子程序
- 闭环多 Agent 提取-验证-代码生成
- **经验知识库**支持轨迹感知精炼（包括从失败中学习）

**实验亮点**：IC/ICIR、Rank IC/ICIR、AR/Sharpe 全面超越基线。

## 三、技术路线对比与趋势判断

### 3.1 演进本质

| 维度 | 第一代 Prompt 循环 | 第二代程序级 | 第三代 RFT/自进化 |
|------|-------------------|------------|------------------|
| **知识载体** | Prompt 上下文 | 可执行代码 | 模型参数 + 代码库 |
| **优化信号** | 文本反馈 | IC/Sharpe 评分 | RFT 策略梯度 / 评估器联合演化 |
| **记忆机制** | 外挂（context 堆叠） | 经验知识库 | 参数内化 + Mined Factor DB |
| **多样性保障** | Prompt 工程 | 逻辑/参数分离 | Diversity-Complementarity Reward |
| **过拟合对抗** | 弱 | 贝叶斯正则化 | SJS 信息流约束 |
| **可解释性** | 高（文本公式） | 高（可审计代码） | 中（涌现指标难解释） |

### 3.2 趋势判断与查询拓展

**趋势判断**：

1. **RFT 路线（QuantEvolver）**：工程化最可行，可直接将现有 prompt 循环系统升级为参数学习。瓶颈在于需要足够的种子因子和制度化训练任务。

2. **SJS 路线（Agora）**：理论最深刻，直接攻击评估器盲区这个根本问题。但多 Agent 协作 + 评估器联合演化的工程复杂度极高，且单 seed 验证不够充分。

3. **程序级路线（FactorEngine）**：最实用的中间态，将因子从"公式"提升为"程序"，表达能力质变。知识注入管道可复用现有金融研报。

**查询拓展方向**：
- AlphaForgeBench (2602.18481) 如何定义"severe behavioral failure mode"？
- Agora 的 3 个评估器具体使用了哪些指标？分歧保留机制如何工程实现？
- QuantEvolver 的 Regime Backtest 如何识别市场制度切换点？
- FactorEngine 的经验知识库是否可以迁移到非金融领域？

## 四、对 Hermes 量化系统的启发

### 4.1 直接可落地

1. **Factor DSL → 可执行代码**：当前 `llm-factor-mining` skill 如果还停留在公式级，应升级为程序级（参考 FactorEngine 的三个分离）
2. **IC 验证框架升级**：`quant-ic-validation` skill 应增加 **Regime 分段回测**（QuantEvolver 的关键创新）
3. **因子库持久化**：建立 **Mined Factor Database**，记录每个因子的 IC 衰减曲线和适用 regime

### 4.2 中期方向

4. **从 Prompt 循环到 RFT**：这是最大的架构升级机会。当前因子挖掘如果依赖 prompt 堆叠历史反馈，应设计 **RFT 微调管线**
5. **评估器盲区意识**：Agora 的核心发现（固定评估器 → 系统性过拟合盲区）应写入风控规则。单一 IC/Sharpe 评分不够，需多评估器 + 保留分歧

### 4.3 风险提示

6. **Agora 的单 seed 警告**：Sharpe +1.87 是单 seed 结果，且信号集中在 short-side。实际部署需要多 seed 验证 + long-side 信号补充
7. **RFT 训练成本**：需要 GPU 资源和足够的种子因子，Jetson Orin Nano 不适合训练（仅推理）

## 六、归纳总结

**一句话总结**：2026 年 LLM 因子挖掘正在从"prompt 外挂循环"走向"参数内化自进化"，三条路线各有优劣——RFT 最工程化、SJS 理论最深、程序级最实用。

**五大核心发现**：
1. **评估器盲区是过拟合根因**（Agora/SJS）：固定评分函数 → 搜索算法系统性利用评估器无法惩罚的缺陷
2. **参数内化 > 上下文堆叠**（QuantEvolver）：RFT 将历史优化经验压缩进参数，消除上下文爆炸和反馈漂移
3. **因子应从公式升级为程序**（FactorEngine）：Turing-complete 代码表达力远超符号公式
4. **多样性保障需显式设计**：Diversity-Complementarity Reward + 多评估器保留分歧
5. **涌现优于设计**：Agora 的两个关键指标是涌现的，预加载到冻结库仅恢复 18% 的 Sharpe 差距
