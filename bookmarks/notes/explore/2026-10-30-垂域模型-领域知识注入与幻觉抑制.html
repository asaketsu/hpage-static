一、摘要

领域知识注入与幻觉抑制是同一枚硬币的两面：参数化注入（SFT/CPT）内化知识但引发灾难性遗忘与过拟合；上下文注入（RAG）易更新但检索错误会把幻觉直接传导进答案。2025-2026 的主线是从"二选一"走向"分层组合 + 可验证信号闭环"。三个数字锚点：①保险垂域 INS-S1 做到幻觉率 0.6%（HHEM）同时领域分 90.14 超 DeepSeek-R1（82.47）且通用能力不掉——证明专精与通用可以不 trade-off；②核安全监管考试实证：不做参数更新的配置在 14 场考试中 0 场达标，SFT+固定分块 RAG 达标 8/14——执业级知识必须进参数；③RAGognizer 把幻觉检测头作为训练信号联合微调，Llama2-7B 幻觉率 56.98%→13.29%。核心反直觉发现：微调并不强化参数记忆，而是抑制幻觉——模型更少"凭权重说话"，但说的时候可靠得多（PKP×PR 分解实证）。

二、关键发现

2.1 注入路线四分法与"参数必要性"铁证

  • GSI Agent（arXiv:2603.15643）给出干净的四分法：
  • 动态注入=RAG（易更新，依赖检索质量）
  • 静态注入=SFT（进参数，难更新）
  • 适配器=LoRA（低成本，容量有限）
  • 提示工程=Prompt（零训练，脆弱）
  • NRC 核反应堆操作员执照考试（arXiv:2607.22067，31B 多模态）：法规阈值 80%，评估 8 种适配×检索组合，唯一规律是无微调配置 0/14 达标；最强配置 = Gemini 蒸馏 CoT 的 SFT + 固定分块 RAG（8/14）。结论：认证级/执业级领域掌握，纯 RAG 或纯 prompt 无法达成，参数更新是必要非充分条件
  • 对适航/结构强度这类"零容忍幻觉"域，这是路线选择的直接证据

2.2 PA-RAG：知识注入微调的两种失败模式（arXiv:2502.08356，IBM Research）

  • 条件记忆偏置（Conditional Memorization Bias）：训练时每题静态分配"检索成功/失败"场景→模型对一部分文档学会依赖检索、对另一部分学会硬背，推理时面对相反场景就崩
  • 标准答案过拟合（Canonical Answer Overfitting）：每题只配一个 canonical 答案→模型学到的是风格伪模式而非知识本身
  • 解法两件套：
  • 上下文增强（CA-RAFT）：同一题混造"检索成功+检索失败+干扰文档"多种样本，教会模型判断"何时信检索、何时信参数"
  • 知识改写（Knowledge Paraphrasing）：同题合成多个答案变体微调（承 Allen-Zhu & Li 2024 预训练改写结论，首次迁移到微调段）
  • 遗忘防线两件套：自选择重放缓冲（用模型自己的预测而非 gold response 重放通用指令）+ 领域标识符（问题前加域前缀，帮模型区分新知识与既有能力）
  • 收益：token 级召回 +10%，通用能力保持

2.3 INS-S1：工业级"可验证精通 + 幻觉控制"范式（arXiv:2603.14463，蚂蚁集团）

  • 两大方法论创新：
  • 可验证数据合成系统：精算推理+合规的层级化数据集（超越"简单知识注入"，构造带严格逻辑约束的多源合成管线，自蒸馏保通用能力）
  • 渐进 SFT-RL 课程框架：动态数据退火（data annealing）+ RLVR（可验证推理）与 RLAIF（AI 反馈）协同配比，通过数据配比与奖励信号优化同时实现"领域约束+防遗忘"
  • 结果：INSEva（自发布 39k+ 基准）90.14 超 DeepSeek-R1（82.47）与 Gemini-2.5-Pro；幻觉率 0.6%（HHEM）为该域纪录低位；通用基准对 backbone 无显著退化
  • 关键叙事：反驳"垂域化必掉通用能力"（DianJin-R1 等金融模型灾难性遗忘的反例）

2.4 幻觉抑制的三个新机制层级

  • 训练级｜检测头联合优化（RAGognizer，arXiv:2604.15945）：把基于内部状态的幻觉检测头集成进 LLM，语言建模与幻觉检测联合 LoRA 微调→内部状态对幻觉的可分性提升，生成时幻觉率随之下降（Llama2-7B：56.98%→13.29%，可答性 F1 70.94→91.86），无指令改动、无质量损伤。附 RAGognize 数据集（自然发生的闭域幻觉+token 级标注）
  • 推理级｜上下文门控（CGKI-LLM，London Met 2026）：免微调路线——查询分解→候选知识获取→语义相关性计算→门控过滤无关知识→组 prompt。PubMedQA 准确率 84.3%→89.2%，幻觉率 7.2%→3.8%。证明"灌进来的上下文越相关，幻觉越少"——RAG 的问题常不在检索器而在"不相关内容也照灌"
  • 度量级｜声明级评测（C-FEX/PKP，arXiv:2603.23047）：ROUGE/BertScore 在长技术文本上失效；C-FEX 把每条响应声明归因到来源（prompt 或参考答案），PKP（参数知识精度）× PR（参数输出率）分解。核心发现：RAG-SFT 后模型"凭权重说话"频率下降但正确率上升——微调的价值是让模型学会闭嘴而非学会多记；微调后 7B 可匹敌 72B 基线

2.5 注入的代价面：收益有限性与新攻击面

  • CLAP（arXiv:2604.21525，制造场景闭环后训练）：QLoRA-SFT 平均增益温和（总分 +0.0098），5 批次仅 3 批改善、部分回退；GRPO 暴露高 KL 风险；事实抽取仍必须靠 RAG；应用链回放作为发布门禁（adapter 是否适配目标应用链，用 100 条回放案例判定）
  • 成员推断攻击（MIA）新面（EACL 2026 Findings）：知识注入（SFT/RAG）扩大隐私攻击面；EPD 防御框架聚合"注入模型+基座+裁判模型"三方输出，MIA 成功率最高降 27.8%（SFT）/526.3%（RAG）——注入私有语料（如型号资料/EBOM）前必须过隐私评估

四、对现有工作的价值（Skill/项目改进建议）

  • P0｜domain-llm-training-pipeline skill 增补注入数据配方：SFT 数据构造加 PA-RAG 双增强——①每题混配"金标准文档+干扰文档+无文档"三态上下文；②同题多答案改写。防条件记忆偏置（当前管线只有单态：有上下文）。另加"领域标识符前缀+自选择重放缓冲"两件套防遗忘
  • P0｜AeroStructFM 评测体系补声明级指标：10-27 笔记已立"领域基准=合规证据链"叙事，C-FEX/PKP 正是缺失的度量层——结构强度问答的幻觉判定应从"ROUGE/裁判总分"升级为"逐声明归因（条款依据/参数来源/模型编造）"，与适航符合性验证的逐项追溯逻辑同构
  • P1｜幻觉抑制三层组合拳（按成本递增）：先做 L1 上下文相关性门控（免训练）→ 数据层 PA-RAG 增强 → 若幻觉仍是瓶颈再上 RLVR 课程（可验证：载荷计算/规范条款引用天然可自动判分，是 RLVR 理想域）
  • P1｜注入前隐私门：型号资料/AD 指令/供应商数据入库即过 MIA 评估，EPD 式三方聚合是参考架构
  • P2｜发布门禁借鉴 CLAP：adapter 发布前跑 N 条应用链回放（领域问答真实链路），防"离线指标涨、线上回退"

五、Actionable Insights

  1. 训练领域 SFT 数据时，检索成败场景必须按题混合而非按文档静态分配——这是最便宜的反偏置手段，零算法改动
  2. 评测幻觉率优先声明级归因（每句话从哪来），总分制（ROUGE/LLM 整体打分）会系统性掩盖"编造但流利"的答案
  3. "微调让模型少说而非多说"——垂域模型的正确预期是降低参数输出率 PR、提升参数精度 PKP，而非期待模型背下全部规范
  4. 免训练防线（上下文门控）与训练防线（数据配方/RL课程）按边际成本排序部署，幻觉指标决定是否升级下一层
  5. 高风险域（适航/保险/核电）的共识：无参数更新的方案过不了执业级门槛，RAG 的角色是"事实接地"而非"知识掌握"

六、关键风险与盲点（来源级别标注）

  • INS-S1 数字为蚂蚁自报 + 自发布基准 INSEva 评测（官方论文但厂商自评，HHEM 幻觉率自测——参照自评审计原则打七折看）；"不掉通用能力"结论需第三方复验
  • NRC 实验仅 31B 单模型单域（14 场考试），"无微调 0/14"结论外推到其他域需谨慎（官方论文）
  • PA-RAG 的 +10% 召回在 2-3 个数据集上测得，规模有限（同行评议前预印本）
  • CLAP"5 批仅 3 批改善"是匿名制造数据，无公开数据集可复核（工业报告）
  • RAGognizer 检测头需要访问内部状态，闭源 API 模型不可用（开源复现可行）
  • 盲点：知识编辑（ROME/MEMIT 类精准编辑）路线本次未覆盖；多模态领域知识注入（图纸/试验曲线）证据几乎空白——恰是飞机结构域最需要的形态

七、一页速查

路线：RAG(动态/易更新) vs SFT(静态/进参数) vs LoRA(适配器) vs Prompt(脆弱)——执业级必须进参数（NRC 0/14 铁证）
注入失败模式：条件记忆偏置(检索场景静态分配) + 标准答案过拟合(单答案) → 解法=混合三态上下文+答案改写(PA-RAG)
幻觉抑制五层：上下文门控(免训练,7.2→3.8%) → 数据配方(PA-RAG) → SFT-RL课程(INS-S1, 0.6% HHEM) → 检测头联合训练(56.98→13.29%) → 声明级评测+回放门禁(PKP/CLAP)
反直觉：微调≠强化记忆，=抑制幻觉+学会闭嘴（PKP↑ PR↓）
代价：注入私有语料=MIA 攻击面扩大（EPD 防御）；LoRA-SFT 收益批次间不稳定（5批仅3批改善），发布必须过应用链回放
适航映射：载荷/条款引用天然可验证=RLVR 理想域；声明级归因评测与符合性验证逐项追溯同构
