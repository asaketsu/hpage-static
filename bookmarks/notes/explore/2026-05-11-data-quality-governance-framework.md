# 数据治理与数据质量框架

> 📅 2026-05-11 | 🏷️ auto-explore | 来源: 36氪、Atlan、Ataccama、NYU、LinkedIn

## 核心摘要

数据质量框架（Data Quality Framework）是组织为确保数据在全生命周期中满足准确性、完整性、一致性、时效性而建立的标准化流程体系。2025-2026年的核心趋势是 **AI Agent 自动化治理** 取代人工巡检——AI 将自动识别异常、诊断问题、提出修复建议，数据管理员只需验证和审批。联合治理（Federated Governance）成为主流模式，各业务域自主管理数据同时遵守企业级标准。中国企业参考 DAMA-DMBOK 和 DCMM 框架，形成"三域十三项"治理体系。

## 关键发现

### 数据质量六维度
1. **准确性 (Accuracy)** — 数据是否反映真实世界
2. **完整性 (Completeness)** — 必填字段是否齐全
3. **一致性 (Consistency)** — 跨系统数据是否一致
4. **时效性 (Timeliness)** — 数据是否及时更新
5. **唯一性 (Uniqueness)** — 是否有重复记录
6. **有效性 (Validity)** — 是否符合业务规则

### 2025-2026 十大趋势（36氪）
- **AI Agent 驱动治理**: 自动监控数据集、实时标记差异、预测性分析
- **联合责任制**: 数据质量不再是 IT 独担，嵌入各业务部门日常工作流
- **数据产品化**: 关键数据作为产品输出，带元数据、血缘追踪和质量指标
- **预测性 MDM**: 系统主动识别潜在问题并自动修复
- **业务用户赋能**: 低代码/无代码工具让非技术人员参与数据管理
- **集中式计算回潮**: Databricks/Snowflake/Fabric 等平台整合

### 企业治理架构（Atlan 模型）
- **治理委员会 (Governance Council)**: 业务/IT/安全/法务高层，定义企业策略
- **域级治理 (Domain-level)**: 各团队在统一标准下自主管理
- **自动化工作流**: 审计时自动导出血缘图、访问日志、策略文档
- **元数据驱动**: 企业级元数据支撑知识管理

### 中国特色框架
- DAMA-DMBOK + DCMM 双框架融合
- "三域十三项": 规划域(标准体系、数据架构) → 实施域(数据获取、加工) → 管理域(平台管理)
- 数据资产入表、数据要素市场化政策推动

## 对猫仔工作的实际价值

1. **量化交易数据管线**: 行情数据的质量直接影响策略回测可信度——可借鉴六维度评估框架，为数据源建立自动化质量监控
2. **Agent 系统记忆质量**: 猫仔的记忆系统（M-Flow/Memory）本质也是数据治理问题——需确保记忆的准确性、时效性、去重
3. **Skills 知识库治理**: Skills 日益增多，需要类似"联合治理"模式——核心框架集中管理，领域 Skills 分布式维护
4. **自动化巡检升级**: 用 AI Agent 思路改进 watchdog 和 health check——从被动响应到主动预测
