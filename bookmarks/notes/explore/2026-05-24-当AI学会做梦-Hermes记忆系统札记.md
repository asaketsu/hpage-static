## 一、核心问题与解决方案

### 问题：AI Agent 的"健忘症"

传统 AI Agent 每次对话从零开始，历史记录受限于 context window，关闭对话等于抹去一切。同一个 Agent 连续工作一周，每天醒来都是白纸。

**用户原话**: "不要胡说八道" — 需要一套记忆系统让重要信息真正沉淀下来。

### 解决方案：双层记忆架构

| 层级 | 实现 | 特点 | 局限 |
|------|------|------|------|
| **短期记忆** | Hermes 原生 Memory (MEMORY.md) | 零门槛、实时生效、无需额外服务 | 仅本地、不跨设备/不跨 Agent 实例 |
| **长期记忆** | PowerMem 向量数据库 | 语义搜索、跨会话持久化 | 需额外服务、有写入开销 |

**记忆巩固时间**: 每天凌晨 1:00（服务器低负载时段）——作者称之为"做梦时间"。

## 二、10 标签 GPS 系统

记忆检索的核心是标签系统，借鉴图书馆分类逻辑但 AI-Friendly：

| 标签 | 含义 | 示例 |
|------|------|------|
| `tag1_time` | 时间 | `2026-05-23` |
| `tag2_topicA` | 主主题 | `服务器`, `AI框架` |
| `tag3_topicB` | 次主题 | `部署`, `安全` |
| `tag4_keywordA` | 高频词 | `Tomson`, `qwenpaw` |
| `tag5_keywordB` | 技术栈 | `ollama`, `minimax` |
| `tag6_keywordC` | 工具/服务 | `hermes`, `openclaw` |
| `tag7_project` | 项目 | `192.168.3.230`, `Halo` |
| `tag8_action` | 动作类型 | `安装`, `配置`, `排查` |
| `tag9_status` | 状态 | `成功`, `失败`, `待处理` |
| `tag10_priority` | 优先级 | `P0`, `P1`, `P2` |

这 10 个标签构成记忆的 **GPS 坐标** — 通过标签组合快速定位任意记忆碎片。

## 三、关键工程细节

### 1. `--no-infer` 性能优化

| 模式 | 耗时 | 说明 |
|------|------|------|
| 默认（带 LLM 推理） | 35~90 秒 | 分析内容、语义拆分、去重 |
| `--no-infer` | 3~6 秒 | 直接写入，无推理开销 |

> `--no-infer` 参数在官方 CLI 文档中**未列出**，是实测发现的隐藏参数。

**启示**: 文档和代码之间总有裂缝，只有实践者才知道的秘密。

### 2. 触发词机制

当用户说以下表达时，自动触发 PowerMem 搜索：

- "你还记得..." / "Do you remember..."
- "你记不记得..."
- "回想一下..."
- "之前我们..."
- "上次那个..."
- "那时候..."

**核心思想**: 把隐式诉求显式写进 Skill 的 trigger 列表，用户无需说"帮我搜一下 PowerMem"。

### 3. 技能架构

整个记忆系统封装为 **Hermes Skill** — 把操作流程、依赖、参数、边界情况打包成可复用、可搜索、可迭代的单元。

> 技能即知识。

## 五、与 Hermes 体系的对比与借鉴

### 当前 Hermes 记忆系统

| 层级 | 实现 | 状态 |
|------|------|------|
| L1 | MEMORY.md（Hermes 内置，每 session 注入） | ✅ 已实现 |
| L2 | short-term/（7 天过期） | ✅ 已实现 |
| L3 | topics/（长期 Topic 索引） | ✅ 已实现 |

### 与 DevOpsMain 方案对比

| 维度 | DevOpsMain 方案 | Hermes 原生 |
|------|----------------|-------------|
| 长期记忆 | PowerMem 向量数据库 | 无（仅本地文件） |
| 标签系统 | 10 标签 GPS | 无结构化标签 |
| 触发词 | 显式 trigger 列表 | 依赖 session_search 语义检索 |
| 记忆巩固 | 凌晨 1:00 Cron | 无定时任务 |
| 跨实例共享 | 通过 PowerMem 向量库 | 仅限本地 |

### 可借鉴点

| 借鉴项 | 适用场景 | 优先级 |
|--------|----------|--------|
| **10 标签 GPS 系统** | 为 Hermes 的 memory 写入增加结构化标签字段 | 高 |
| **触发词机制** | 在 Skill 中显式定义记忆检索的触发词 | 中 |
| **记忆巩固 Cron** | 定时将短期记忆整理/归档到长期存储 | 中 |
| **`--no-infer` 优化** | 如使用 PowerMem 或其他向量库，注意写入性能 | 低（依赖外部工具） |

## 六、核心洞察

1. **文档与代码的裂缝** — `--no-infer` 参数未出现在官方文档中，实测发现。这提醒我们：任何工具的完整能力边界，文档永远只是冰山一角。

2. **记忆的本质** — "不是存储本身，而是存储之后还能被调取出来的那个瞬间。" 这句话精准定义了记忆系统的核心价值。

3. **触发词的设计哲学** — 用户不需要知道"PowerMem"这个技术名词，只需要说自然语言"你还记得..."，系统自动路由到正确的检索机制。这是用户体验的关键。

4. **技能即知识** — 记忆系统最终封装为 Skill，意味着知识不仅被存储，还被封装成可复用的操作流程。
