## 一、摘要

系列第四篇，补上辐射维度的完整拼图：10-14 实测结论说「490km/4 个月尺度上辐射不是操作限制」，今天回答**为什么 COTS 芯片敢上天、辐射什么时候会变成操作限制、两条技术路线怎么分野**。核心是一个工程悖论：传统宇航级抗辐射 ASIC 用 0.35µm CMOS 工艺，商用 AI 加速器 sub-10nm，算力差数个数量级（卢森堡大学 SnT 2023 判定深度学习需求相对存量抗辐射处理器需「数个数量级提升」）。业界解法不是造「抗辐射版 H100」，而是分成两条路线：**路线 A（COTS+系统容忍）**用商用 GPU/FPGA 加辐射缓解 wrapper——Unibap（AMD APU+PolarFire FPGA，iX5100 只有 0.5U）、Aitech S-A1760 Venus（Jetson 系列，术语精确叫 radiation-*characterized* 而非 hardened）、Starcloud（2025-11 直接把 H100 送入轨，2026-10 上 Blackwell）；**路线 B（宇航级重造）**以 NASA JPL+Microchip 的 HPSC 为代表，2026-02 开始测试，实测性能约为现有抗辐射芯片 500 倍、当前航天计算机 100 倍。

## 二、关键发现

### 2.1 Starcloud H100：数据中心思路而非芯片加固思路

- 2025-11 初入轨的 NVIDIA H100 是「史上最强在轨处理器」，比此前任何在轨 GPU 算力高 **100 倍**（CNBC 2025-12）；任务目标直白——验证高功率 GPU 在真空/辐射/反复热循环下的可靠性
- 已完成**首次太空模型训练**：Karpathy 的 NanoGPT + 莎士比亚全集 → 输出莎士比亚英语；同时在轨运行 Google Gemma LLM 推理
- 商业负载：Capella Space SAR 影像推理（海上救生艇定位/森林火灾）
- 抗辐射策略不在单芯片，而在**规模**：短任务周期 + 未来多 GPU 冗余（下一颗星 2026-10 集成 Blackwell + 云平台模块）——把地面数据中心的「坏一块换一块」逻辑搬上天
- 环境优势叙事：持续光照 + 深空辐射制冷、零淡水消耗（YC 评述）

### 2.2 NASA HPSC：路线 B 的 500 倍跃迁

- JPL + Microchip 联合开发，含 CPU + 计算卸载 + 高级网络 + 内存 + IO 完整系统（新华网 2026-05-19）
- 计算能力 = 当前航天计算机 **100 倍**；2026-02 启动的辐射/热冲击/机械冲击测试早期结果显示实际性能约为现有抗辐射芯片 **~500 倍**
- 定位深空自主（通信延迟无法地面遥控的场景）+ 载人登月/火星——即辐射真正成为操作限制的任务域
- 关键点：HPSC 依然走完整宇航资格认证（与 Starcloud 的 COTS 快速迭代形成路线对照）

### 2.3 DNN 特有的辐射风险：SEU 静默传播

PatSnap 综述给出对 AI 推理最致命的机理刻画：

- 辐射损伤双机制：**TID**（总剂量，累积性退化）+ **SEE**（单粒子效应，瞬态事件）
- SEE 家族：SEU 翻转 / SEL 闭锁（大电流再生，可烧毁）/ SEB 烧毁 / SEGR 栅穿 / MBU 多位翻转 / SED 扰动 / SET 瞬态脉冲
- **DNN 特有风险**：单粒子翻转打中权重/中间激活/控制寄存器，错误经层层前向传播到输出，**全程不触发任何 fault flag**——「静默数据损坏」对自主在轨决策（目标检测→触发动作）是最高危失效模式
- 细几何 CMOS（sub-10nm）对 SEE 更敏感，但宇航级 0.35µm 的代价是算力断崖 + 噪声底 ~2099 e⁻ RMS 一类的性能折衷（Wakasa Wan 2018 实测）
- SAR 实时处理被迫 FFT 定点化（北理工 2017/2018），精度损失管理成为资格认证一部分

### 2.4 路线 A 的工程范式：COTS + 三层缓解

- **Unibap（CEAS Space J. 2020, 68 引用）**：AMD 28nm G-series APU + MicroSemi/PolarFire FPGA 异构架构，SpaceCloud iX510仅 **0.5U（10×10×5cm）**；14nm Ryzen APU 已评估为下一代候选；TensorFlow/PlaidML 跑 CNN 基准——「与地面云工具链通用」是部署成本核心论点
- **加固三原则**（未来天玑，中国星载 AI 工程总结）：**可恢复性**（故障后及时恢复）/ **无后效性**（本次故障不影响后续任务）/ **可纠正性**（运行时异常自动纠正）——COTS 路线的可靠性不是「不出错」而是「错了能兜住」
- 硬件层：结构加厚 + 多重组合屏蔽可使总剂量水平降低 **2~4 个数量级**；软件层：冗余/信息冗余/时间冗余/硬件重构
- 量化设计方法：σ-LET 曲线 Weibull 拟合 + 空间质子能谱积分 → 预测单粒子翻转率；系统级双机热备 + 单机重载 <5s → 分系统不连续工作概率可压到 **2.05×10⁻⁸ Upsets/system·day**（中国专利 CN103605835A 实例）

### 2.5 2026 行业格局：COTS 路线已成主流，辐射顾虑让位于架构设计

TerraWatch 2026 版全景（对比 2023 版的关键变化）：

- **边缘从「后装」变「一阶架构决策」**：Planet 下一代 Owl 星座原生集成 NVIDIA GPU（与 Pelican 队列 tip-and-cue 协同）；Satellogic "AI-First" 架构多模型并行 + 发射后可更新
- 供应链成熟：Ubotica 11 次任务 30+ 在轨模型；Unibap SpaceCloud 多星座部署；EDGX/Aethero 新玩家持续出货
- 基础模型上轨道：IBM TerraMind.tiny 地理空间基础模型已跑在 Planetek AI-eXpress 上
- 轨道数据中心实体化：Starcloud H100 → Axiom 2026-01 首批节点 → Google+Planet **Suncatcher（TPU 上星）**
- 中国平行生态：三体计算星座 2025-05 首批 12 星，已演示星间分布式计算 + **80 亿参数模型在轨部署**（当前在轨最大之一）；STAR.VISION STRING 计算单元 + 100Gbps 激光星间链路
- 新架构辩论：星上处理 vs 高速光学下行直传——结论趋向「按用例混合」，与 10-10 语义压缩笔记的判断一致

## 三、对工作的价值

- **DNN SEU 静默传播 ↔ 我们的部署守卫同构**：duck_run 部署链的 act-ACT0 基线 clip ±0.06rad + dact 2°/tick 限幅 + 死区 0.8°，本质就是「异常值不得通过前向传播」的软件层缓解——航天级思路（无后效性原则）在真机部署的免费复用；后续任何长时无人值守推理（ASC 云台、nexa-local-inference）都该保留这类输出异常门
- **Jetson 平台的辐射相关性排序**：本机 Orin Nano（LPDDR5 无 ECC）在地面宇宙线中子本底下 bit flip 率极低（海平面 ~14 neutron/cm²/hr vs LEO 高 2-3 个数量级），日常部署不需担心；但**长时间无人值守任务（过夜训练/云台值守）值得加输出级一致性检查**——这正是 SEU 静默传播教训的地面版
- **量化精度 vs 容错的 trade-off 是开放研究点**：int8 量化后单 bit 翻转对数值的扰动幅度相对更大，但网络冗余度（过参数化）提供天然容错——在轨实证数据稀缺，可入论文转化队列（与 weekly-paper 选题池对接）
- **术语三分法直接可抄**：评估任何"航天级 AI 芯片"宣传时先问是 hardened/tolerant/characterized 哪种——Aitech 官网措辞用 characterized 是精确的法务级表述，中文报道常混译为"抗辐射"造成能力高估

## 五、一页速查

> - 核心悖论：宇航级 0.35µm vs 商用 sub-10nm，算力差数量级；解法不是加固 H100 而是 COTS+系统容忍
> - 术语三分：hardened（工艺级，算力最弱）/ tolerant（COTS+wrapper）/ characterized（实测表征）——读报道先分类
> - Starcloud H100（2025-11）：在轨最强 100×；首个太空训练模型（NanoGPT+莎士比亚）；策略=规模冗余非芯片加固；2026-10 上 Blackwell
> - NASA HPSC：宇航级重造路线，实测 ~500× 现有抗辐射芯片，2026-02 开测，面向深空自主+登月火星
> - DNN 特有风险：SEU 打中权重/激活/控制位 → 层层静默传播，无 fault flag → 自主决策静默损坏
> - SEE 家族：SEU/SEL/SEB/SEGR/MBU/SED/SET；SEL 闭锁可烧毁需断电保护
> - 加固三原则：可恢复/无后效/可纠正——COTS 路线靠"错了能兜住"而非"不出错"
> - 屏蔽效果：结构加厚+多重组合屏蔽降总剂量 2~4 个数量级；双机热备+5s 重载 → 不连续工作概率 2.05e-8/天
> - 2026 格局：Planet Owl/Satellogic 原生集成 GPU；三体星座 12 星+8B 模型在轨；Suncatcher 要把 TPU 送上天
> - 与 10-14 呼应：490km 短任务 COTS 可行（热/能量先卡）；深空长寿命才轮到辐射当操作限制
