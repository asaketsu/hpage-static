# 开源3D/设计AI：LLM空间推理

> 日期：2026-07-13 | 来源：主动探索 | 标签：3D AI / 空间推理 / 设计自动化

## 摘要

LLM 的空间推理能力是当前多模态大模型的核心瓶颈。最新研究表明，约 71% 的视觉空间理解错误源于空间推理缺陷（NYU 李飞飞/谢赛宁团队，VSI-Bench，2024）。2025-2026 年间，该领域从"2D 视频生成"向"3D 结构化生成"快速演进，出现了 SpatialLM/SpatialGen、G2VLM 等里程碑式开源模型，以及 Awesome-LLM-3D 等系统化文献综述。同时，GLM-4.5V 等商用多模态模型也已将 3D-RoPE 空间编码纳入架构。

## 关键发现

1. **瓶颈已明确**：VSI-Bench 基准上人类准确率 79%，最佳模型（Gemini-1.5 Pro）仅 48.8%。相邻物体空间关系准确率 64%，但随距离增加急剧下降，说明模型缺乏隐式"认知地图"。

2. **G2VLM（上海AI Lab，CVPR 2026）**：统一架构同时处理 3D 重建 + 空间理解，采用几何感知专家 + 语义感知专家双专家设计，原生预测 3D 几何特征并通过 interleaved reasoning 完成空间问答。2026年4月已开源训练代码。

3. **群核科技 SpatialLM 1.5 / SpatialGen（2025.8）**：业界首个专注 3D 室内场景认知与生成的开源空间大模型。SpatialLM 将文本指令转化为含空间结构、物体关系、物理参数的"空间语言"；SpatialGen 基于多视角扩散 + 3DGS 重建，从源头解决空间一致性问题（任意视角切换、光照纹理物理一致），已上线 HuggingFace/GitHub。

4. **Awesome-LLM-3D 综述（UCLA ActiveVisionLab）**：系统梳理 3D-LLM 领域，代表工作包括 3D-LLM (NeurIPS'23)、VG LLM (CUHK)、G2VLM 等，覆盖 3D 理解、生成、导航等子任务。

5. **商用模型跟进**：GLM-4.5V（智谱）采用 MoE + 3D-RoPE 技术实现 3D 空间推理能力，106B 总参 12B 激活；CAD 领域已有专门综述（arXiv 2505.08137）。

## 对工作的价值

- 若我们未来构建 3D/空间相关 Agent（如智能家居控制、室内导航、3D 内容生成），G2VLM 的"统一重建+理解"架构是核心参考范式。
- 群核的 SpatialLM 展示了"用自然语言生成结构化 3D 场景"的工程可行性，对我们理解"Agent 如何与世界交互"有启发。
- 空间推理是当前多模态模型的短板，任何依赖视觉空间理解的 Agent 应用都应将其作为评估维度。

## 行动建议

1. 关注 G2VLM-SR（空间推理强模型 checkpoint）即将发布的进展。
2. 将 VSI-Bench 作为空间感知 Agent 的基准测试工具。
3. 群核 X 项目（3D AI 视频生成 Agent，计划年内发布）值得跟踪，代表 3D+视频融合趋势。
4. 后续可进一步阅读 Awesome-LLM-3D 综述，建立领域知识图谱。
