概述

Scrumboy 是一个轻量级、自托管的 Trello/Jira 替代方案。零配置启动（无需 .env、TLS、加密密钥），内置实时协作、语音指令、便签墙、MCP/AI Agent 支持。面向小团队和独立开发者设计。

核心特性

特性 说明
自定义工作流 每个项目可定义任意泳道组合
实时 SSE 看板 多用户即时同步更新
Webhooks 事件触发 POST JSON（如 todo.assigned）
Sprint 管理 创建/激活/关闭 Sprint，支持1-2周默认周期
标签系统 继承 + 自定义颜色
语音指令 (VoiceFlow) 确定性语音命令操控看板
便签墙 (Sticky-Note Wall) 每个项目可拖拽便签
PWA 浏览器安装，移动端体验优秀
匿名共享看板 全功能模式和匿名模式均支持
审计日志 append-only audit_events 表
备份/恢复 JSON 导入导出，支持合并或替换策略
2FA TOTP 支持（需设置加密密钥）
OIDC/SSO 支持 OpenID Connect 单点登录

MCP 集成（AI Agent 支持）

这是最大亮点 — 原生支持 MCP (Model Context Protocol) JSON-RPC 2.0：

  • 端点：POST /mcp/rpc
  • 认证：Bearer token（API Token，无需浏览器会话）
  • 支持 initialize / tools/list / tools/call
  • AI Agent 可直接创建/管理 todo、项目、Sprint

这意味着 Hermes Agent、Claude Code 等可以通过 MCP 直接操控项目看板。

优势

  1. 零配置启动 — go run 或 docker up 即用
  2. 单二进制 + SQLite — 无外部依赖，资源占用极低
  3. MCP 原生支持 — AI Agent 可直接集成，目前同类唯一
  4. PWA + 语音 — 移动端友好，语音操控是独特差异化
  5. Jetson 友好 — Go 编译为 ARM64，SQLite 轻量，适合我们的环境

劣势 / 风险

  1. AGPL v3 — 修改后必须开源，商业使用受限
  2. 项目早期 — 仅 199 commits，53 stars，社区小
  3. 单人维护 — markrai 独立开发，长期维护不确定
  4. 无甘特图/时间追踪 — 功能比 Jira/Plane 简单
  5. 无 Git 集成 — 不能直接关联 PR/Commit

潜在用途（我们的场景）

  1. AI Agent 任务管理 — 通过 MCP 让 Hermes 直接管理 todo/Sprint
  2. 轻量项目看板 — 替代当前的 kanban skill，获得可视化界面
  3. 跨设备访问 — PWA + 局域网部署，手机/平板随时查看
  4. Jetson 本地部署 — Go + SQLite 极轻量，7.4G RAM 绰绰有余
