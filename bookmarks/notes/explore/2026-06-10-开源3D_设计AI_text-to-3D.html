开源3D/设计AI: text-to-3D 生成技术调研

日期: 2026-06-10 | 类型: auto-explore | 来源: 3daistudio.com 行业报告 + arXiv + HN Algolia

摘要

Text-to-3D 生成已从实验室走入工业化阶段。2026年市场规模达 $3.23B，年增速 30.9%，预计 2030 年达 $9.4B。传统建模需 3-5 天的工作流，现在仅需秒级。开源模型（TRELLIS.2、TripoSR）已达到生产级质量，闭源模型（Seed3D 2.0、Rodin）在精细度上仍有优势。

关键发现

1. 模型格局：没有单一赢家

  • Seed3D 2.0（字节跳动）：2026年4月发布，人类偏好盲测中几何和纹理胜率 69%-90%，当前 SOTA
  • Hunyuan3D 2.1/3.x（腾讯）：纹理和 PBR 质量最佳，开源权重但有地区许可限制（EU/UK/KR 不可用）
  • TRELLIS.2（微软）：4B 参数，MIT 协议完全商用，24GB VRAM 单卡 20 秒生成 1536 分辨率资产 — 开源首选
  • Tripo 3.0（VAST AI）：速度冠军（<30s），拓扑干净，原生 PBR
  • Rodin Gen-2（Deemos）：影视级保真度，适合 hero asset
  • TripoSR / SF3D：MIT 协议，6-8GB VRAM 亚秒级生成，入门门槛最低
  • Hi3DGen：MIT 协议，几何精度最优

2. 开源 vs 闭源：差距在缩小

  • TRELLIS.2（MIT）、TripoSR（MIT）、Hi3DGen（MIT）可完全商用
  • Hunyuan3D 2.1 开源但社区许可有地区限制
  • 实际团队策略：开源做批量+降成本，闭源做精品资产

3. API 成本已降至美分级

  • Stable Fast 3D: ~$0.08/模型
  • 3D AI Studio: $0.05-$0.50
  • Meshy/Tripo: $0.10-$0.30
  • Rodin: $0.50+
  • fal.ai 托管 TRELLIS 低至 $0.02/次

4. MCP + Agent 化趋势

  • Blender 官方 MCP server 已发布，AI 助手可直接驱动建模
  • Agent → MCP → 多后端（Rodin/Meshy/Tripo/ComfyUI）全链路打通
  • 3D 生成正从"人点按钮"变成"Agent 编排"

5. Gaussian Splatting 成为基础设施

  • 从论文到标准化格式仅 3 年（比 PBR 快一个数量级）
  • OpenUSD 已加入原生 Gaussian splat schema，glTF 正在批准 KHR_gaussian_splatting 扩展
  • Splats 用于真实场景捕获，AI mesh 用于可编辑资产 — 互补而非竞争

6. 最新学术进展（arXiv 2026-05/06）

  • MCTS + VLM 用于 text-to-3D 室内场景：用蒙特卡洛树搜索提升大场景一致性（arXiv:2606.06002）
  • T2Mo：基于 3D 轨迹+文本的可控动态形状生成（arXiv:2606.05162）
  • Structural Energy Guidance：解决 text-to-3D 中 Janus 问题（多面问题），提升视角一致性（arXiv:2605.19876）

对工作的价值

  1. Jetson Orin 部署机会：TripoSR/SF3D 只需 6-8GB VRAM 亚秒推理，Jetson Orin Nano Super（8GB）可能直接跑，适合边缘端实时 3D 生成场景
  2. MCP 集成：已有 Blender MCP server，可以探索 Hermes Agent 通过 MCP 驱动 Blender + text-to-3D 后端的全自动建模流程
  3. ComfyUI 本地部署：开源模型可通过 ComfyUI 跑本地推理管线，不依赖外部 API
