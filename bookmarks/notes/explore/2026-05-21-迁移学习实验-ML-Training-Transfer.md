# 迁移学习实验：ML Training Transfer

> 实验日期：2026-05-21 | 平台：Jetson Orin Nano (aarch64) | PyTorch 2.6.0 + CUDA 12.6

## 1. 迁移学习基础知识

### 1.1 什么是迁移学习

迁移学习（Transfer Learning）是将一个领域（源域）上学到的知识应用到另一个相关领域（目标域）的机器学习方法。核心思想：**不必每次从零开始，可以利用已有的知识加速新任务的学习**。

现实类比：学会了骑自行车后，学骑摩托车比完全零基础快得多。

### 1.2 为什么需要迁移学习

| 问题 | 传统训练 | 迁移学习 |
|------|----------|----------|
| 数据量需求 | 大量标注数据 | 少量数据即可 |
| 训练时间 | 长（从头学特征） | 短（复用特征） |
| 标注成本 | 高 | 低 |
| 性能上限 | 受限于数据质量 | 可超越 |

### 1.3 核心概念

- **源域（Source Domain）**：已有丰富标注数据的领域
- **目标域（Target Domain）**：需要解决的新领域
- **域偏移（Domain Shift）**：源域和目标域之间的分布差异
- **特征提取器（Backbone）**：神经网络中提取通用特征的前几层

### 1.4 常见迁移策略

```
策略1: 零样本迁移（Zero-shot Transfer）
  直接将源域模型用于目标域，不做任何修改
  → 最简单，但域偏移大时性能差

策略2: 冻结特征提取器 + 微调分类头（Frozen Backbone）
  冻结backbone参数，只训练新的分类器
  → 参数少，训练快，适合目标域数据少的场景

策略3: 全网络微调（Full Fine-tuning）
  用源域权重初始化，全部参数用小学习率更新
  → 灵活，但需要更多数据防止过拟合

策略4: 从头训练（Train from Scratch）
  不使用任何预训练知识，纯靠目标域数据训练
  → 基线对比，数据足够时可能最优
```

### 1.5 迁移学习适用场景

- **仿真到现实（Sim-to-Real）**：在仿真环境训练 → 部署到真实机器人
- **跨数据集**：ImageNet 预训练 → 医疗影像分类
- **跨模态**：文本模型 → 适配到特定领域文档
- **少样本学习**：只有几十个标注样本的新任务

## 2. 实验设计

### 2.1 实验目标

通过 5 种策略的对比实验，直观展示迁移学习的价值：

1. 不同迁移策略在域偏移场景下的性能差异
2. 微调 vs 从头训练的收敛速度对比
3. 冻结 vs 全量微调的权衡

### 2.2 数据集

| 数据集 | 描述 | 样本数 |
|--------|------|--------|
| 源域：MNIST | 标准手写数字（干净） | 训练60K / 测试10K |
| 目标域：DomainShiftMNIST | 旋转±20° + 高斯噪声σ=30 + 高斯模糊σ=1.0 | 训练60K / 测试10K |

域偏移模拟了「仿真→真实」场景：源域是理想的仿真数据，目标域加入了真实环境中的旋转、噪声和模糊。

### 2.3 模型架构

**SmallCNN** — 轻量CNN分类器（468,202 参数）

```
Input: 1x28x28 灰度图
├── Block 1: Conv(1→32) → BN → ReLU → Conv(32→32) → BN → ReLU → MaxPool → Dropout
│   输出: 32x14x14
├── Block 2: Conv(32→64) → BN → ReLU → Conv(64→64) → BN → ReLU → MaxPool → Dropout
│   输出: 64x7x7
└── Classifier: Linear(3136→128) → ReLU → Dropout → Linear(128→10)
    输出: 10类概率

TransferModel: 可选择冻结/不冻结 backbone，替换分类头
```

### 2.4 五组实验

| 实验 | 策略 | Epochs | 学习率 | 说明 |
|------|------|--------|--------|------|
| Exp1 | 源域训练 | 6 | 1e-3 | 标准MNIST上训练baseline |
| Exp2 | 零样本迁移 | 0 | - | 直接用Exp1模型测目标域 |
| Exp3 | 冻结backbone + 微调 | 3 | 5e-4 | 只训练分类器 |
| Exp4 | 全网络微调 | 3 | 1e-4 | 全部参数用小LR更新 |
| Exp5 | 从头训练 | 6 | 1e-3 | 目标域数据从头训 |

训练配置：Batch size=128, Optimizer=Adam, Scheduler=StepLR(step=5, γ=0.5)

## 3. 训练过程

### 3.1 Exp1：源域训练（标准 MNIST）

| Epoch | Train Loss | Train Acc | Test Loss | Test Acc | Time |
|-------|-----------|-----------|-----------|----------|------|
| 1/6 | 0.2412 | 92.53% | 0.0422 | 98.59% | 44s |
| 2/6 | 0.0953 | 97.22% | 0.0293 | 98.95% | 45s |
| 3/6 | 0.0735 | 97.83% | 0.0388 | 98.72% | 44s |
| 4/6 | 0.0661 | 98.08% | 0.0260 | 99.17% | 44s |
| 5/6 | 0.0553 | 98.37% | 0.0201 | 99.31% | 43s |
| 6/6 | 0.0382 | 98.90% | 0.0174 | **99.43%** | 45s |

总耗时 ~4.5min。模型在干净MNIST上达到99.43%准确率。

### 3.2 Exp2：零样本迁移

源域模型直接在目标域测试 → **95.96%**

域偏移导致准确率下降 3.47%，说明模型学到的特征不够鲁棒。

### 3.3 Exp3：冻结Backbone + 微调分类器

| Epoch | Train Loss | Train Acc | Test Loss | Test Acc | Time |
|-------|-----------|-----------|-----------|----------|------|
| 1/3 | 0.1706 | 95.18% | 0.0512 | 98.24% | 48s |
| 2/3 | 0.0912 | 97.26% | 0.0434 | 98.67% | 48s |
| 3/3 | 0.0825 | 97.53% | 0.0380 | **98.68%** | 48s |

可训练参数：仅分类器部分（约10K），训练快，收敛快。

### 3.4 Exp4：全网络微调

| Epoch | Train Loss | Train Acc | Test Loss | Test Acc | Time |
|-------|-----------|-----------|-----------|----------|------|
| 1/3 | 0.4384 | 86.76% | 0.0644 | 97.91% | 62s |
| 2/3 | 0.1372 | 96.14% | 0.0459 | 98.51% | 62s |
| 3/3 | 0.1065 | 96.95% | 0.0400 | **98.68%** | 62s |

注意 Epoch 1 的 Train Loss 很高（0.4384），因为全量微调初期分类器被重新初始化，但最终收敛到与冻结微调相同的 98.68%。

### 3.5 Exp5：从头训练（Baseline）

| Epoch | Train Loss | Train Acc | Test Loss | Test Acc | Time |
|-------|-----------|-----------|-----------|----------|------|
| 1/6 | 0.3087 | 90.51% | 0.0664 | 97.74% | 62s |
| 2/6 | 0.1478 | 95.65% | 0.0576 | 98.11% | 62s |
| 3/6 | 0.1242 | 96.39% | 0.0450 | 98.61% | 62s |
| 4/6 | 0.1065 | 96.94% | 0.0451 | 98.37% | 62s |
| 5/6 | 0.0939 | 97.26% | 0.0381 | 98.74% | 62s |
| 6/6 | 0.0779 | 97.75% | 0.0341 | **98.95%** | 62s |

需要完整的 6 个 epoch 才收敛到 98.95%。

## 4. 结果分析

### 4.1 总体对比

| 策略 | 目标域准确率 | 训练Epochs | 总训练时间 |
|------|-------------|-----------|-----------|
| 源域模型（MNIST测试） | **99.43%** | 6 | ~4.5min |
| 零样本迁移 | 95.96% | 0 | 0 |
| 冻结backbone + 微调 | 98.68% | 3 | ~2.4min |
| 全网络微调 | 98.68% | 3 | ~3.1min |
| 从头训练（基线） | 98.95% | 6 | ~6.2min |

### 4.2 关键发现

**发现1：域偏移的影响显著**
干净模型直接迁移到偏移域，准确率从 99.43% 骤降到 95.96%（-3.47%）。这说明在分布差异面前，即使源域表现完美，零样本迁移也有明显损失。

**发现2：微调有效恢复性能**
无论是冻结微调还是全量微调，3 个 epoch 就恢复到 98.68%，接近从头训练 6 个 epoch 的 98.95%。

**发现3：冻结 ≈ 全量微调**
在本实验中，两者最终准确率完全相同（98.68%），说明 CNN 的浅层特征（边缘、纹理）对旋转/噪声/模糊已经足够鲁棒，不需要更新。

**发现4：从头训练意外最优**
98.95% 略高于迁移方法。原因：目标域数据充足（60K），模型可以直接学到底层特征。但如果目标域数据很少（如只有 1K 样本），迁移学习的优势会非常明显。

### 4.3 GPU vs CPU 性能

| 指标 | CPU (Jetson) | GPU (Orin) | 加速比 |
|------|-------------|-----------|--------|
| 每 epoch (源域训练) | 208s | 44s | **4.7x** |
| 每 epoch (全量微调) | - | 62s | - |
| 总实验时间 | 预计 40+ min | **~16 min** | 2.5x+ |

## 5. 代码架构

```
ml-training-transfer/
├── src/
│   ├── models.py          # SmallCNN + TransferModel 模型定义
│   ├── datasets.py        # MNIST 加载 + DomainShiftMNIST 域偏移生成
│   ├── train_utils.py     # 训练/评估/历史记录
│   ├── visualize.py       # 训练曲线/策略对比/样本可视化
│   └── run_experiment.py  # 完整实验主程序（5组实验）
├── data/                  # MNIST 数据（自动下载）
├── results/               # 实验输出（模型/历史/图表）
└── README.md
```

### 核心代码说明

**域偏移生成** (`datasets.py`)：
- `DomainShiftMNIST` 类对 MNIST 图像施加组合变换
- 支持 4 种偏移类型：rotation / noise / blur / combined
- combined 模式：旋转±20° + 高斯噪声(σ=30) + 高斯模糊(σ=1.0)

**迁移模型** (`models.py`)：
- `TransferModel` 封装 backbone + 新分类器
- `freeze_features` 参数控制是否冻结特征提取器
- 迁移时保留 backbone 权重，仅替换分类头

**训练管线** (`train_utils.py`)：
- `train_model()` 完整训练循环，自动保存历史和模型
- 使用 Adam + StepLR 调度器
- 只优化 `requires_grad=True` 的参数

## 6. 结论与实践建议

### 何时选择哪种策略

| 场景 | 推荐策略 | 理由 |
|------|----------|------|
| 目标域数据极少（<1K） | 冻结backbone | 防止过拟合 |
| 目标域数据中等（1K-10K） | 全量微调 | 平衡适应性和稳定性 |
| 目标域数据充足（>10K） | 从头训练 or 全量微调 | 数据足够直接学 |
| 快速验证/原型 | 零样本迁移 | 零成本看基线 |
| 实时/资源受限部署 | 冻结backbone | 训练快，参数少 |

### 本实验的局限

1. **任务过于简单** — MNIST 10类分类，CNN 容易达到高准确率，迁移学习优势不明显
2. **域偏移人工构造** — 真实的 Sim-to-Real 偏移更复杂（光照、遮挡、物理差异等）
3. **模型过小** — 468K 参数的 CNN 表征能力有限
4. **缺少域自适应方法** — 未尝试 DANN、MMD 等高级迁移技术

### 改进方向

- 使用更大模型（ResNet-18）在更复杂的数据集（CIFAR-10 → STL-10）上实验
- 引入无监督域自适应（UDA）方法
- 尝试渐进式解冻（Progressive Unfreezing）
- 添加 Few-shot 场景（只用 1%/5% 目标域数据微调）
