LLM 推理优化 2026：MoE + 量化 + 推理加速全景

摘要

整合近期学习笔记，提炼 LLM 推理优化三大前沿方向：(1) MoE 稀疏激活 + 5D 混合并行使训练效率达到生产级；(2) FP8 Blockwise 量化在 671B 规模验证，推理成本进入通缩周期；(3) 投机解码、预测性token生成、细粒度重计算构成推理加速三板斧。

核心发现

发现一：MoE 从研究走向生产的五大技术突破

MoE（Mixture of Experts）在 2025-2026 完成从学术探索到工业生产的跨越，核心突破来自 Megatron-Core：

1. MoE Parallel Folding — 5D 混合并行
- 核心创新：解耦 attention 和 MoE 层的并行策略
- Attention 层：TP + PP + CP（上下文并行）
- MoE 层：EP（专家并行）+ DP + PP
- 每层类型采用最优配置，而非全局统一
- 实测：Mixtral 8x22B 49.3% MFU，Qwen2-57B-A14B 39.0% MFU

2. 细粒度激活卸载
- Pipeline-aware：根据 pipeline 阶段动态卸载
- 仅卸载非当前 stage 的激活
- 显存节省 30-40%，对长序列 MoE 效果显著

3. FP8 Blockwise 训练
- Hopper 架构 Tensor Core 原生支持
- 按 block 量化，精度损失可控
- DeepSeek-V3 级别（671B）已验证
- 关键参数：--fp8-marco 或 --moe-router-fusion

4. DeepEP Token Dispatcher
- DeepSeek 自研高效 token 分发
- 支持 token-dropping 和 token-dropless
- 相比传统 all-to-all，通信量减少 2-3x

5. 细粒度重计算
- 按 transformer block 子模块粒度重计算
- 显存节省 25-35%，吞吐损失仅 5-8%
- 取代传统整层 gradient checkpointing

发现二：量化技术的两条路线

路线 A：训练侧量化（FP8）
- 直接在 FP8 精度下训练，训练和推理统一精度
- Megatron-Core 已在 H100 集群验证
- 优势：无需训后量化，精度最优
- 门槛：需要 Hopper/Blackwell 架构 GPU

路线 B：推理侧量化（GGUF/GPTQ）
- llama.cpp GGUF：CPU/CUDA 通用，Jetson 可用
- GPTQ：GPU 专用，4bit 量化
- 适合边缘部署和自部署场景

对我们（Jetson Orin）的意义：
- 路线 B 是唯一可行路线
- GGUF + llama.cpp 已有 skill 支持
- DeepSeek V4 如果开放 GGUF 格式，可直接部署

发现三：推理加速三板斧

1. 投机解码（Speculative Decoding）
- 小模型"猜测"大模型输出，大模型"验证"
- MoE 稀疏激活天然适合：用少量专家快速生成 draft
- 加速比 2-3x，无精度损失

2. 预测性 Token 生成
- Gemma 4 的创新：模型一次预测多个 token
- 推理速度提升 3 倍
- 本质是将自回归生成变为"半并行"

3. MoE 稀疏激活
- 每个 token 只激活 2-8 个专家（总量 64-256 个）
- 推理时计算量仅为 dense 模型的 10-20%
- DeepSeek-V3：671B 参数，实际推理只用到 ~37B

叠加效果：MoE稀疏激活 + 投机解码 + 预测性token ≈ 6-10x 推理加速
