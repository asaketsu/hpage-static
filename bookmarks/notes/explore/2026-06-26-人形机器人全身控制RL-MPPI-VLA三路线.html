核心背景

人形机器人全身控制（whole-body control）长期存在三难：

  1. RL 方法：鲁棒稳定性强，但行为与训练目标/命令接口紧耦合，新增反馈目标需重训
  2. 优化控制（OC/MPC）：精确可解释，但计算开销大、难处理接触丰富场景
  3. VLA 模型：泛化与语言推理强，但缺乏动力学一致性、数据稀缺、安全性难保证

2026-06 这三篇论文恰好代表三条路线各自的突破，且彼此可组合。

三大技术路线详解

路线 1：WOLF-VLA — 最优控制合成 + VLA 语言驱动（2606.25591）

核心思路：用最优控制（OC）合成动力学可行的人形运动轨迹作为「高质量 demonstration」，再训练 VLA 直接从自然语言生成运动策略。

关键创新：
- 构建覆盖 6 类运动任务的动力学可行轨迹数据集，参数化环境变化/物体颜色/放置/视觉干扰
- 联合训练：关节轨迹 + ego-centric 视觉 + 自然语言指令
- 产出策略对初始条件变化具有鲁棒性，具备强推理能力
- 系统性消融研究验证每个模态的贡献

价值：解决了 VLA 应用于全身接触丰富运动时「数据稀缺 + 缺乏动力学一致 demonstration + 难编码最优性与安全性」三大障碍。全部开源，建立可复现基准。

路线 2：RGB — RL 先验引导的 MPPI 反馈控制器（2606.25123）

核心思路：不把 RL 策略当作最终控制器，而是作为 MPPI（Model Predictive Path Integral）采样的先验，偏置 rollout 趋向动力学可行行为。任务目标通过模块化 MPPI 代价项指定。

关键创新：
- RL 策略 = 采样先验（sampling prior），而非最终控制
- MPPI 闭环持续在线修正 RL 先验以满足新目标，无需重训策略
- MuJoCo 仿真在 29-DoF Unitree G1 上实现平均 280 Hz 稳定高频控制
- 任务级精度超越纯 RL 基线（修正直线行走中的系统性漂移，跟踪全身参考信号）

深层意义：RL 与 MPC 不再二选一，而是 RL 提供行为先验 + MPPI 提供精确修正的分层协作。这与 LLM 推理中 System-1（直觉生成）+ System-2（审核修正）的范式同构。

路线 3：异步上半身任务空间跟踪（2606.25706）

核心问题：高层规划器输出稀疏、低频的任务空间轨迹，而全身控制器高频运行 → 规划与执行间存在时序异步（temporal asynchrony）和全身控制结构不完整。

关键创新：
- 师生蒸馏（teacher-student distillation）初始化 student policy
- 条件输入：完整缓存的未来轨迹 + 执行时间索引
- 滑动窗口全局奖励减少帧漂移，无需显式帧估计
- MPC 模块补全稀疏参考为浮动基座 + 上半身引导
- action 层与 FK 层自引导约束策略漂移

结果：Unitree G1 仿真 + 硬件实验显示，在低更新率下跟踪更优，超越同步与解耦基线，对分布外运动更安全。

对双轮仿生腿项目的启发

当前项目：STS3025BL×4 舵机腿 + 4015 BLDC×2 + ODrive 双轮 + STM32H743 + Pixracer R15。可直接借鉴：

  1. RGB 的「先验+修正」分层思想 — 舵机做低层稳定先验，STM32/ODrive 上层做 MPPI 式轨迹修正，避免重训
  2. 异步跟踪的滑动窗口奖励 — 解决双轮平衡（高频）与腿关节规划（低频）的时序错配，无需显式帧同步
  3. WOLF-VLA 的 OC 合成数据 — 用 Pinocchio 动力学库生成动力学可行的轨迹作为参考，降低真机试错成本

核心发现总结

  1. 2026 全身控制 = RL 提供鲁棒先验 + MPC/MPPI 提供精确修正 + VLA 提供语言泛化，三者不再是竞争而是分层协作
  2. RGB 证明 280Hz 全身控制可行，RL 策略作为「采样先验」而非「最终控制器」是范式级转变
  3. WOLF-VLA 全量开源（数据+模型+基准）为人形运动 VLA 提供首个可复现基线
  4. 时序异步是全身控制被低估的工程难点，滑动窗口全局奖励是优雅的解法
