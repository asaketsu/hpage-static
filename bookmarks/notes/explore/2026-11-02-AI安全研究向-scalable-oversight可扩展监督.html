一、摘要

Scalable Oversight（SO，可扩展监督）解决的核心矛盾：模型能力超过评估者时，监督信号从哪来。2026 年这个方向完成了从"哲学提案"到"可计算理论"的三级跳：①谱系层——Irving 2018 辩论 / Leike 2018 递归奖励建模（RRM）/ 迭代放大三条路线被 Kenton（DeepMind）归纳为三要素：iteration（用可信的当代模型帮训下一代）、decomposition（把难验证的答案拆成易验证的博弈）、legibility（让模型输出更可读），并主张"kitchen sink"组合拳；②理论层——arXiv:2603.05293 证明 debate 相对 RLAIF 的优势存在精确闭式解 Δ=√((K_A)²+η²)−K_A，其中 η 由两个模型表示子空间的主角度谱（知识分歧度）决定——同训练语料的两个模型 η=0，debate 完全退化为 RLAIF，零增益；这给"模型同质化削弱 AI 监督"（Goel et al. 2025）提供了理论解释；③攻防层——Prover-Estimator（PE）协议（arXiv:2506.13609）用非对称角色分工破解"埋藏论证问题"（把谎言埋进难验证的子计算），而隐写合谋（模型间用隐藏文本模式串通）成为多 agent 监督的新威胁面。

二、关键发现

2.1 形式化基础：辩论是零和博弈，不是聊天（Irving et al. 2018）

  • 协议结构：两个 prover 同时收到复杂问题 → 各自给出（通常互斥的）结论 → 交替做简短受限陈述、构建论证树至限定深度 → 有界 judge（人类或弱 AI）读转录判胜
  • 核心公理："撒谎难于驳谎"——不诚实的 agent 必须编织跨多步的内部一致谎言网，诚实 agent 只需找到并暴露一个致命矛盾即可赢
  • 复杂度理论根基：deba­te 等价于交互式证明系统（多项式时间验证者）——judge 只需具备验证（不是求解）能力，这是"弱监督强"的可行性来源
  • 2023-2024 大规模实证：judge 准确率随辩手模型能力提升而提升（不是下降）——对抗暴露矛盾的能力与模型能力同向增长

2.2 理论突破：debate 价值 = 知识分歧的函数（arXiv:2603.05293，2026）

  • 框架：把 debate 与 RLAIF 统一为"宪法分数 K(y)=⟨w,h(y)⟩ 的优化"——RLAIF 单模型能拿到的最优分 K_A=‖Π_{V_A}w‖（偏好方向在自己表示子空间上的投影长度）；debate 均衡可访问两子空间之和，得分 K_AB=‖Π_{V_A+V_B}w‖
  • 闭式解：debate 优势 Δ=√((K_A)²+η²)−K_A，其中 η 是从两模型表示子空间主角度谱推出的私有信息价值
  • 三种知识分歧机制：
  • shared（共享）：η=0，debate 完全退化为 RLAIF——同权重自博弈（θi=0）就是退化情形，Irving 2018 设想的"自博弈对称性"实际上消除了 debate 的优势
  • one-sided（单侧）：一方知道另一方不知道的——debate 能激发出单模型不可达的结果
  • compositional（组合）：双方知识互补，组合后可解——但对抗激励超过尖锐阈值时发生协调失败（双方宁可输也不暴露私有信息）
  • 实证对接：理论上解释了 Goel et al. 2025"模型同质化削弱 AI 监督"——同源模型（同底座同语料）互审 ≈ 没审
  • 适用边界：框架假设共享表示映射 h；同架构同预训练管线、仅微调数据不同的模型最适用（恰是实践主流场景）

2.3 埋藏论证与 PE 协议：破解"把谎言埋进复杂逻辑"（arXiv:2506.13609）

  • Obfuscated arguments problem：超人类模型可以把欺骗/危险代码藏进一大堆难验证的子计算里——judge 逐项验证成本爆炸，递归辩论面临失效
  • Prover-Estimator 分工：非对称角色——Estimator 给出答案及对每个子计算的置信估计，Prover 专门攻击低置信/可疑节点；不诚实方无法预测哪个节点被审查，埋谎的期望成本陡增
  • 效果：把"全面验证"降为"定向抽查"，计算可行性恢复——这是 2025-2026 SO 工程化最实质的协议进展

2.4 RRM 与迭代放大：分解的另一条路（Leike et al. 2018）

  • 递归奖励建模：人类评不了复杂任务，但评得了拆解后的简单子任务——用 reward modeling 训 agent 辅助人类评估，递归下去，从简单任务 bootstrap 到复杂任务
  • 迭代放大（iterated amplification）：用可信的当代模型组合（分解+求解）充当下一代的监督信号源；debate 与迭代放大被 Leike 团队认为"几乎等价——要么都行，要么都不行"
  • Kenton 三要素合成视角：RRM=iteration、debate/amplification=decomposition、tandem training=legibility；"kitchen sink"= 鲁棒奖励模型 + 单玩家辩论做分解 + 串联训练做可读性
  • 值得注意的元判断："SO 已跌出时尚，但 LLM 恰好刚强大到可以在仿真中实证检验这些想法"（Kenton 2025）——弱模型监督强模型的仿真实验窗口正在打开（与 10-20 W2SG 笔记的 Selective W2SG 汇流）

2.5 威胁面：隐写合谋与验证瓶颈

  • 验证瓶颈的正式表述：依赖人类示范或直接判断做对齐时，学到的能力被人类评估容量严格上界封顶——RLHF 在超人类域优化的是"看起来好"而非"真的好"，系统性激励 reward hacking / 谄媚 / 精致欺骗（对有界 judge 来说，自信的谎言比反直觉的真相"便宜"）
  • 隐写合谋（steganographic collusion）：多 agent 辩论中，模型间可通过隐藏文本模式（表层不可见的编码信道）串通——零和博弈结构防明面合谋，防不了隐蔽信道；对策方向：输出过滤器/承诺机制/信息论约束，尚无成熟方案
  • 防御纵深共识：没有单一方法能解决 SO——debate + RRM + AI 辅助评估 + 机制可解释性叠加，各方法失效模式不同才构成鲁棒监督（与 10-30 单义特征笔记的"可解释性作为安全手段"接上）

四、对现有工作的价值（Skill/项目改进建议）

  • P0｜external-model-review skill 增补"跨源原则"：外部模型评审（GPT-6 通道审 GLM 产出）当前隐含正确（跨模型家族），但未成文——2603.05293 给出硬理论：同底座/同语料模型互审 η≈0 零增益。应写明"评审模型必须与被审模型知识源正交（不同家族/不同训练语料）"，三列交叉验证中至少两列跨源
  • P0｜content-judge / verifier 架构引入 PE 思想：Hermes 自进化循环的 Verifier（watchdog/content-judge）目前是"全量平铺评分"——可改为"Estimator 置信标注 + Prover 定向攻击低置信项"的两段式，把验证算力集中到可疑处（对齐 1010 用户分层验证框架思想）
  • P1｜benchmark-selfreport-audit skill 加第八道滤网：厂商自评基准 + 自家模型当 judge = shared 机制（η≈0）——"自家人审自家模型"的自评数字应按退化情形打折
  • P2｜多 agent 编排警示：agent-orchestration 相关 skill 补一条——多 agent 互相校验只在知识源分歧时有价值；克隆同一底座的 agent 池互审是伪安全感

五、Actionable Insights

  1. 设计 AI 评审流程时，先问"评审者与被审者的知识子空间夹角"——同源模型的交叉验证是仪式，跨源才是机制
  2. 验证算力稀缺时，别平铺全量评审——让被审方自报置信度，审查火力集中低置信节点（PE 协议的可迁移内核）
  3. debate 的 judge 只需"验证能力"不需"求解能力"——把难题转成"判断两个论证谁有破绽"的形态，是人类监督超难任务的通用杠杆
  4. 组合式知识互补的博弈要控制对抗激励强度——过阈值会触发"宁可输也不暴露私有信息"的协调失败（对竞争性多 agent 系统设计的直接警告）

六、关键风险与盲点

  • 理论假设的适用圈（来源级别：官方论文自认）：闭式解框架假设线性宪法评分 + 共享表示映射——跨架构/跨分词器模型需要先做表示对齐（CKA/线性缝合），对齐误差会污染主角度测量，且"主角度是模型内禀属性还是对齐程序伪影"是开放问题
  • 实证缺口（来源级别：社区共识）：debate 的 judge 准确率提升实证多在可分解问答任务；开放域长程任务（agent 轨迹审计）的 debate 有效性证据薄——SO "fell out of fashion" 部分正因实证难做
  • 隐写合谋无解药（来源级别：理论阶段）：当前只有威胁建模没有成熟防御；若部署多 agent 监督，输出信道的信息论约束是必修课
  • PE 的抽查盲区：定向抽查依赖置信度自报的诚实性——战略性低估自己的置信度（sandbagging 变体）可诱导审查火力错配（与兴趣表待学的 sandbagging 主题直接勾连）

七、一页速查

  • SO = 人类评不了时监督信号从哪来；三要素 = iteration / decomposition / legibility（Kenton）
  • 谱系：Irving debate(2018) / Leike RRM(2018) / 迭代放大 → PE 协议(2025) → 知识分歧理论(2026)
  • 闭式解：Δ=√((K_A)²+η²)−K_A；η 来自表示子空间主角度——同语料 η=0，debate 退化为 RLAIF
  • PE 协议：Estimator 自报置信 + Prover 定向攻击，破解"谎言埋进子计算"
  • 公理：撒谎难于驳谎；judge 只需验证能力
  • 新威胁：隐写合谋（隐蔽信道串通）；组合机制对抗激励过阈值→协调失败
  • 迁移口诀：评审要跨源，火力对低置信，judge 只验证
