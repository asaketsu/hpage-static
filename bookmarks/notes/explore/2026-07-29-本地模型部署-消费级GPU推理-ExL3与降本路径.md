### 2. EXL3 量化格式（核心技术增量）

**痛点背景**：多数 SOTA 量化技术使用成本高昂。例如 AQLM 量化 70B 模型需约 720 GPU-hours（A100 服务器），撰写时成本约 $850。

**EXL3 解决方案**：
- 基于 **QTIP**（Cornell RelaxML），是 QTIP 的精简变体
- 转换只需输入模型（HF 格式）+ 目标比特率
- 运行时计算 Hessian + fused Viterbi kernel，单步完成量化
- **速度对比**：小模型几分钟，70B+ 模型在单张 RTX 4090 上数小时
- **GEMM kernel**：Marlin 启发设计，在最优条件下（4bpw, RTX 4090）接近 memory-bound 延迟
- 转换后的模型在 token 级别保留质量

**转换命令**：
```bash
python convert.py -i <hf_model> -o <output> -w <workdir> -b <bitrate>
# 中断恢复
python convert.py -w <workdir> -r
```

**局限**：Ampere GPU（RTX 30 系列）上的 kernel 效率仍需优化；低比特率下尚未完全达到 memory-bound。

### 4. 退役服务器 GPU 降本路径（Hackaday 2026-05）

**方案**：NVIDIA V100（16GB，SXM2 接口）+ PCIe 转接板 → 消费级主板。

- **成本**：SXM2 版 V100 约 $100 + 转接板约 $100 = ~$200 获得 16GB VRAM
- **对比**：同款 PCIe 版 V100 售价 $300-1000+
- **性能**：对比 RTX 3060 12GB，V100 token/s 略高、效率略高，但待机功耗更高
- **注意**：V100 为 2017 年 Volta 架构，无视频输出，最新 CUDA 支持有限；评论指出同价位 RTX 3060（$250）因有最新 CUDA 支持更实用
- **适用**：预算极紧、需要 >12GB VRAM 跑大模型（如 gpt-oss:20b）的极客玩家，非生产推荐

### 5. 8GB VRAM 低端卡优化实战（HackerNoon 2026-03）

目标硬件：RTX 3060 8GB / RTX 2060 / GTX 1080 / 6-8GB 笔记本 GPU。

**核心策略**：
- 4-bit 量化（Q4_K_M）是精度/显存最佳平衡
- 分层 GPU offload（-ngl 35：35 层上 GPU，余 CPU）
- 降低上下文（-c 2048 vs 默认 4096/8192）
- 推荐引擎优先级：llama.cpp（最低端最高效）> vLLM > Ollama

**实测速度（8GB GPU）**：
- Mistral 7B Q4_K_M：25-40 tokens/s（~4GB VRAM）
- Llama 3 8B Q4：20-35 tokens/s（~5GB VRAM）
- Phi-3 Mini Q4：~3GB VRAM，更快

**OOM 排障**：-ngl 降至 20 或 -c 降至 1024；避免同时加载多模型。

## 对工作的价值

1. **Jetson Orin 部署无直接关联**：ExL3 仍需 CUDA 12.4+ 和较新消费级 GPU，Jetson（Ampere）的 GEMM kernel 效率未优化，短期内不适用。但 EXL3 的"单卡量化大模型"思路值得跟踪。
2. **量化技术选型更新**：历史笔记中量化对比（GGUF/EXL2/GPTQ/AWQ）应补充 EXL3 作为 2026 新选项，尤其是需要快速转换大模型时的首选。EXL3 单卡转换 70B 的能力是 EXL2/AQLM 的数量级提升。
3. **消费级 GPU 投资决策**：
   - **RTX 5090（32GB GDDR7）**：2026 实测比 4090 快 33%，是目前单卡跑 70B Q4 的最佳消费级选择
   - **RTX 4090（24GB）**：ExL3 官方基准 GPU，性价比仍高
   - **RTX 3060 12GB**：最低门槛卡，社区公认性价比之王
   - **V100 16GB（SXM2 改造）**：仅极客尝鲜，不推荐生产
4. **架构兼容性**：ExL3 已覆盖我们关注的 GLM/Qwen/Gemma 全系列，未来若配消费级工作站可优先评估 ExL3 + TabbyAPI 作为 Hermes 本地 fallback 引擎。
