# Molmo 指向能力（Pointing & Grounding）深度解析

> 嗅探学习 | 2026-08-25 | 来源: AllenAI 官方博客 + Bentoml 综述
> 前序笔记: [MolmoAct2 机器人动作推理模型分析报告](../2026-05-29-MolmoAct2-机器人动作推理模型分析报告.md)
> 关联主题: MolmoWeb（指向驱动的网页 Agent）、MolmoAct2（指向驱动的机器人动作）

## 摘要

Molmo 的指向能力（Pointing / Grounding）是 Ai2 团队在 2026 年推出的两项重要技术突破：**MolmoPoint**（2026-03）和 **MolmoWeb**（2026-04），加上 MolmoAct2 中对「像素级指向」的继承。核心结论：Ai2 用**「grounding token」**替代了传统的「文本坐标输出」方式，让 VLM 通过直接选择视觉 patch 来完成指向，更准、更快、更省 token。这一范式创新从图像指向扩展到视频追踪、GUI 操作、网页导航、机器人抓取等全场景。

## 关键发现

### 1. 范式革命：从「写坐标」到「选视觉证据」

传统 VLM 指向方式的痛点：
- 生成文本坐标（如 "x=327, y=182"）或对应坐标 bin 的 token
- 迫使模型学习一个别扭的坐标系
- 输出 token 多（8 token/点），高分辨率下极不稳定
- 跨模态无法扩展（无法指向文本或音频）

MolmoPoint 的新范式：模型**直接在自己的视觉 token 上做选择**——先选粗粒度 patch，再选子 patch，再定位精确点。三阶段用 3 个特殊 token 表示：
- `<PATCH>` — 粗粒度区域选择
- `<SUBPATCH>` — 子区域精化
- `<LOCATION>` — 最终点位置

**核心洞察**：模型已经有视觉 token 了，为什么不直接用它们来指向？

### 2. 三阶段粗→精 Grounding 架构

```
阶段1: 模型对 ViT 高层视觉 token 做 attention → 选择粗 patch
阶段2: 用低层 ViT 特征精化到子 patch
阶段3: 在子 patch 内预测精确位置
```

附加设计：
- **旋转嵌入（Rotary Embeddings）**：编码候选 patch 到上一选中点的距离，避免重复指向、保证顺序一致
- **no-more-points 类别**：模型可主动停止，而非被强制选下一个 patch

训练效率收益显著：仅 8192 条训练样本就比坐标基线高 ~20 F1 分。

### 3. 三个专项模型 + 两个新数据集

| 模型 | 用途 |
|------|------|
| MolmoPoint-8B | 通用图像/视频指向 |
| MolmoPoint-GUI-8B | 软件界面（桌面/网页/手机） |
| MolmoPoint-Vid-4B | 视频专门优化 |

新数据集：
- **MolmoPoint-GUISyn**：36K 高分辨率截图，200万+标注点（LLM 生成 HTML → Playwright 提取 bounding box → 每元素 5 条指令）
- **MolmoPoint-TrackData**：覆盖更广泛物体和场景的人类标注追踪轨迹 + 复杂遮挡/运动合成轨迹

### 4. 基准表现（均为开放模型 SOTA）

PointBench（指向能力综合基准）：
- MolmoPoint-8B：70.7%（↑ 从 Molmo 2 的 68.7%）
- 推理/空间推理子项提升约 5 个点

PixMo-Points：
- MolmoPoint-8B：89.2 F1（↑ 从 85.2）

GUI Grounding：
- ScreenSpot-Pro：61.1
- OSWorldG：70.0
- 同数据下训练 vs 坐标基线，grounding token 版本领先 2-9 点

视频追踪：
- MeViS：SOTA
- Molmo2-Track：+5.7 J&F 总提升

### 5. 指向能力的生态化延伸

指向能力不是孤立功能，而是 Ai2 多模型生态的**共同底座**：

- **MolmoWeb**（2026-04）：基于截图的网页 Agent，用指向能力决定「点哪个按钮」，不依赖 HTML/无障碍树。超越 GPT-4o 级别专有模型（更少参数）。
- **MolmoAct2**（2026-05）：Molmo2-ER backbone 的三大具身能力之一即「像素级指向」，是机器人抓取位置预测的基础。
- **MolmoBot**：机器人操纵方向
- **MolmoSpaces**：3D 感知基础设施
- **WildDet3D**：AR/VR 与数字场景理解

学术界已验证 Molmo 指向能力的可复用性：
- 哈佛 + Broad Institute：直接用 Molmo 指向能力追踪实验视频中的动物行为，无需重新训练
- 爱丁堡大学：Molmo 用于 AI 监督多模态辩论框架
- 特伦托大学：利用 Molmo 全开放训练管线，探测和重塑 VLM 对空间关系的理解

### 6. 对工作的价值

- **指向即解释**：模型可让用户「看到」它在看哪里，可解释性大幅提升
- **指向即计数**：模型通过逐个指点来完成计数，与人类认知方式一致
- **指向即控制**：机器人抓取点、UI 点击位置、视频追踪目标，全部统一为同一机制
- **跨模态可扩展**：grounding token 范式理论上可扩展到文本、音频 token
- **训练更便宜**：指向能力不再需要大量数据配比调优，少量样本即可收敛

### 7. 行动建议

1. **关注 grounding token 范式**：这不仅是 Molmo 的优化，可能是 VLM 指向能力的通用新范式。值得评估是否可迁移到我们的项目
2. **跟踪 MolmoWeb 的浏览器自动化路线**：纯视觉截图驱动的网页 Agent 是 OpenAI/Anthropic 之外的另一条路线
3. **评估 MolmoPoint 在我们的硬件上的部署可行性**：8B 参数级别可能适配 Jetson 边缘部署
4. **关注 GUISyn 数据合成管线**：LLM 生成 HTML → Playwright 提取的自动化标注流程可复用
