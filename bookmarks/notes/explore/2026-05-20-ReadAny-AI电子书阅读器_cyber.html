📋 摘要

ReadAny 是一款 AI 驱动的跨端电子书阅读器（1.2k⭐，GPL-3.0），支持 EPUB/PDF/MOBI。核心亮点：语义搜索（Hybrid RAG） + 上下文感知 AI 对话 + 技能系统。Monorepo 架构（pnpm workspace），桌面端 Tauri，移动端 Expo React Native，Core 层共享。LangChain + sqlite-vec 构建本地优先的 RAG 管线。

🔍 值得借鉴的设计

1. Semantic Reading Context (SRC) — 上下文感知

追踪用户操作类型：reading | highlighting | searching | navigating

生成上下文快照：当前章节、CFI 位置、可见文本、最近标注。AI 对话自动注入上下文。

2. Hybrid Search — Vector + BM25 融合

三种模式：Vector（sqlite-vec + 内存兜底）/ BM25（倒排索引）/ Hybrid

Hybrid 用 RRF (Reciprocal Rank Fusion, k=60) 合并排序，5 分钟 TTL 缓存，优雅降级。

3. CJK Tokenizer — 多语言分词

中日韩混合处理："AI人工智能" → ["hello", "世", "界", "ai", "人工", "智能", "世界"]

中文 bigram + 日文假名 + 韩文 + 中英停用词 50+ + NFKC 标准化

4. Segment-aware Chunker — 精确 CFI 映射

每个 chunk 保留精确 CFI 定位，300 tokens / min 50 / overlap 20%

5. System Prompt 6 段式架构

Role → Book Context → SRC → Tools → Workflow → Constraints

强制 addCitation 工作流防幻觉：Retrieve → Register → Reference

6. AI Tool 体系

通用：listBooks, searchAllHighlights/Notes, getReadingStats, getSkills, mindmap

RAG：ragSearch, ragToc, ragContext（需 vectorized）

分析：summarize, extractEntities, analyzeArguments, findQuotes, compareSections

引用：addCitation（强制注册来源 [N] 标记）
