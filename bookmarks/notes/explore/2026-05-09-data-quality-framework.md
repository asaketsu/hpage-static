# 数据治理：数据质量框架 (Data Quality Framework)

> 📅 2026-05-09 | 🏷️ 数据治理, 数据质量, AI-Ready Data
> 🔗 来源: lakefs.io, datagalaxy.com, ewsolutions.com

---

## 核心摘要

1. **数据质量框架**是一套原则、流程和工具的组合，用于监控、提升和保障组织内的数据质量，是数据治理的核心执行层。
2. 数据质量框架 ≠ 数据治理：框架聚焦数据本身的正确性/完整性/一致性，治理覆盖数据全生命周期（访问、安全、合规）。
3. AI 时代数据质量更为关键——AI 模型需要可信、有文档、无偏见的数据，否则 garbage in garbage out。
4. 自动化验证+数据版本控制（如 lakeFS 的 branching 策略）是现代数据质量框架的基础设施层。
5. 10 大治理最佳实践之首：**指定数据所有者和问责制**，无主人的数据没有未来。

## 关键发现

### 数据质量框架核心组件
| 组件 | 说明 |
|------|------|
| **Data Workflow** | 在管道各阶段（采集、转换、存储、分析）嵌入质量检查 |
| **Quality Rules** | 基于维度定义可量化的质量规则（准确性、完整性、一致性、时效性、有效性） |
| **Validation & Cleansing** | 自动化验证+清洗，减少人为错误 |
| **Monitoring & Alerting** | 持续监控质量指标，异常自动告警 |
| **Data Version Control** | 零拷贝隔离、分支、原子回滚——数据变更的安全网 |

### 数据质量 vs 数据治理
- **数据质量框架**：聚焦数据"好不好"——正确性、完整性、一致性、时效性
- **数据治理**：覆盖"怎么管"——策略、角色、问责、合规、全生命周期管理
- 两者是**互补关系**：质量是治理的执行层，治理是质量的战略层

### 10 大数据治理最佳实践 (DataGalaxy 2025)
1. 指定所有权和问责制（Data Owner + Data Steward）
2. 定义并文档化策略和流程
3. 建立业务术语表（Business Glossary）
4. 动态元数据管理策略
5. 自动化数据血缘追踪（Lineage）
6. 嵌入数据质量监控
7. AI-Ready 数据准备
8. 合规性持续审计
9. 数据产品化思维
10. 持续改进文化

### 低质量数据的四大风险
- **资源浪费**：修错数据消耗时间/人力/机会
- **运营低效**：库存错乱、发货错误、预测失准
- **合规风险**：GDPR/CCPA 违规导致罚款
- **声誉损害**：客户体验下降，信任流失

## 对猫仔工作的实际价值

### 1. 量化分析场景
- 股票量化分析高度依赖数据质量：行情数据缺失/错误直接导致策略回测失真
- 可在数据管道中加入**自动化质量检查**：缺失值率、异常值检测、时间连续性校验

### 2. Agent 系统场景
- Agent 记忆系统本质也是数据——记忆质量直接影响 Agent 行为
- 可借鉴"数据质量维度"定义记忆质量指标：准确性、时效性、一致性

### 3. 知识库管理
- 笔记/知识库需要类似数据治理的框架：定义、分类、生命周期管理
- "数据无主人则无未来"同样适用于知识资产
