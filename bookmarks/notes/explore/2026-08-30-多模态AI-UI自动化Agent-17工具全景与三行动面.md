# 多模态 UI 自动化 Agent：17 工具全景与 Computer-Use 2.0 三行动面

> 探索日期：2026-08-30 | 兴趣等级：L2 | 来源数量：3 篇 | 前序：[2026-06-21 Computer-Use三大范式](../2026-06-21-Computer-Use-Agent三大范式-2026年Claude-OpenAI-Gemini桌面与浏览器自动化对比.md)

## 摘要

UI 自动化 Agent 领域从"三厂商架构赌注"（前序笔记）进化到两个新共识：**(1) Computer-Use 2.0 概念升级**——从"截图-点击循环"扩展为三行动面动态选择的能力；**(2) 生态成熟**——10 开源 + 7 商业工具形成完整分层。本笔记聚焦生态全景与概念增量，不重复三范式对比。

## 关键发现

### 1. Computer-Use 2.0：三行动面模型（cua.ai）

定义升级：computer use 是**能力**而非单一产品/模型/交互方式——agent 在三个行动面间按任务动态切换：

```
┌─ coding surface ──── 写代码并运行（文本原生、重复操作、批量文件）
├─ tool-use surface ── 结构化调用 API/函数/MCP（类型化输入输出）
└─ UI surface ─────── 点击/输入/滚动（无 API 软件，GUI 是唯一契约）

model → agent harness → driver → OS/应用   （四层分离，同一 driver 换模型/harness 复用）
```

**核心判断力 = 选面的 skill**：稳定 web 流程用 browser automation 足够，明确集成用 API，跨界面/视觉状态/登录态/无 API 软件才需要 computer use。

### 2. 开源十杰（按定位分层）

- **通用桌面**：UI-TARS（字节，多模态模型家族 + Desktop 应用 + Agent TARS 全栈，MCP 支持）；Agent S3（跨 OS，视觉 grounding + 反思 + 混合 Python/Bash 逃生舱）
- **浏览器专项**：Browser Use（最易上手，官方已提供 Hermes/OpenClaw skill 安装）；Stagehand（AI 导航陌生页 + 代码精确步，**缓存动作免模型重放**，网站变化才召回 AI）；Skyvern（Playwright + vision 多 agent，带代理/CAPTCHA/并行云服务）；Agent-E（AG2 框架，规划与导航分 agent）
- **确定性路线**：OpenAdapt（**人工演示一次 → 可检查工作流 → 确定性回放，健康运行零生成模型调用**，不确定时暂停人工复核）
- **跨设备**：UFO³（微软，动态任务图分配到 Windows/Linux/Android 多设备并行）
- **端侧**：AgentCPM-GUI（OpenBMB 8B，Android 端侧，**30+ 中文 App 专项训练**，中英双语，RL 调优先思考后行动）
- **全栈基建**：CUA（建/跑/训/评一体 + Docker/VM 沙箱）

### 3. 商业七家

ChatGPT Work（轻量桌面+浏览器）、Claude Cowork（长任务生产力）、Gemini in Chrome Auto Browse（Chrome 原生）、Perplexity Personal Computer（macOS always-on + Comet 浏览器）、Genspark Claw、Amazon Nova Act（企业浏览器）、Manus Browser Operator。

### 4. 交叉洞察（与前序笔记及本机体系）

- **OpenAdapt 确定性回放 ≡ Skill 固化理念**：演示一次→固化→免 LLM 重放，与 Hermes"龙虾法则：重复任务→SKILL.md→cron"完全同构，是 GUI 领域的 skill 化
- **三行动面选择 ≡ 工具权限三层模型**：AGENTS.md 的允许/确认/禁止三层与"选最直接界面"原则呼应——UI 自动化是最后手段而非默认
- **Stagehand 缓存重放**与 Skill A/B 测试的候选版本思路相通：AI 生成→缓存→验证→固化

## 关键风险与盲点

- Turing Post 为商业媒体综述，工具能力声明未逐一实测（社区复现级）
- 商业产品（Cowork/ChatGPT Work 等）迭代极快，表格时效性 ~3 个月
- OSWorld SOTA 仍仅 38.1%（OpenAI CUA），全桌面自动化远未成熟——浏览器域最成熟

## 一页速查

> **三行动面**：coding（文本/重复）→ tool-use（有 API）→ UI（无 API 唯一契约）；**选最直接的界面**，UI 自动化是兜底不是默认。
> **选型**：最易上手=Browser Use；确定性回放=OpenAdapt；AI+代码混合=Stagehand；中文安卓端侧=AgentCPM-GUI；跨设备=UFO³。
> **分层**：model（感知+提议动作）→ harness（指令/记忆/权限）→ driver（UI 工具层）→ OS。
> **成熟度**：浏览器 > 桌面 > 移动；OSWorld 38.1% 是天花板现状。
