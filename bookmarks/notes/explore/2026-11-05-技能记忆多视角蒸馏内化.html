核心问题与研究动机

Agent RL（如 GiGPO/GRPO）在多轮交互任务上受稀疏延迟奖励制约。技能记忆（skill memory）把交互轨迹中的教训总结成文本 prompt 注入上下文，是常见的增强手段。但真正的自进化要求把外部化的经验内化进模型参数——不依赖检索也能用。On-Policy Self-Distillation（OPSD）是内化通路：skill-view 分支当教师、skill-free 分支当学生做 token 级 KL 蒸馏。

痛点在监督质量：自生成技能记忆混杂无效/有害/幻觉策略，且不同决策功能（该看什么、该做什么、该不该继续）纠缠在一起，冗余与冲突掩盖各自贡献。直接前向蒸馏会把错误行为传播进共享参数，甚至让技能分支跑输无技能分支。

论文的四方向对照实验（WebShop）给出硬证据：

  • 无蒸馏 < 双向 < 前向单独最差方向之一；反向蒸馏（skill-free 纠正 skill-view）单独最强
  • 前向蒸馏的 Top-K token 重叠率低且波动、熵差大且不稳 → 持续分布错位、监督不可靠
  • 但前向仍显著优于无蒸馏 → 技能里确实有真知识，问题在"如何可靠转移"

内容整理（方法论）

框架三模块：动态技能检索 → 多视角 rollout 探索 → 知识增益门控的多视角蒸馏。全部技能分支与 skill-free 分支共享同一套策略参数 θ，RL 底座为 GiGPO（episode 级 + step 级优势）。

  1. 动态技能度量（Beta 后验 + 时间衰减 + Thompson 采样）

  2. 双指标分离：Reliability（绝对成败证据 z_rel = y）与 Advantage（相对无技能基线 z_adv = (1+y-ȳ_free)/2，ȳ_free 为同任务 skill-free rollout 平均成功率）

  3. 时间衰减：证据权重 w = 2^(-(t-t_i)/H)，H 为半衰期，历史战绩指数折扣，防止技能价值被旧证据锁死
  4. Beta 后验：α/β 累加折扣证据（均匀先验），证据多的技能分布集中易区分，证据少的保留不确定性

  5. 检索两段式：先按查询-上下文余弦相似度取 Top-K，再按 Thompson 采样分 S = q̃_rel + q̃_adv 排序（q̃ 从各自 Beta 分布采样）——利用与探索平衡，防偶然成功技能霸占检索位

  6. 三功能视角技能池（解纠缠的核心）

  7. 状态锚定（state grounding）："现在知道什么"——识别任务相关观测/物体状态/约束/缺失信息，区分已验证事实与假设，动身前先取证

  8. 行动规划（action planning）："接下来做什么"——动作选择、子目标建立、操作排序
  9. 执行控制（execution control）："该继续还是该换"——前置条件检查、无效行为检测、中间结果验证、错误恢复；观测与预期矛盾时重谋而非硬撞

  10. 另有整合分支（combined）：三视角知识联合注入。三个功能池 + 整合 = 4 条 skill-view 分支 + 1 条 skill-free 分支并行 rollout

  11. 知识增益门 + 结果驱动师生配对

  12. 锚组（anchor group，沿 UCOB）：同任务 + 同锚状态（相同前缀状态）的决策记录归组，组内可比

  13. 增益门：strict（skill-view 成功数 > skill-free 且 skill-free 成功数 = 0）与 relaxed（skill-view 成功数 > skill-free）
  14. 师生配对 g(τ_t, τ_s)：仅当教师轨迹成功而学生失败时配对；方向分三类——前向（skill→free，受增益门约束）、反向（free→skill 纠正，1-门）、跨视角（view→view，不同视角互补知识，不受门约束）

  15. 蒸馏损失：OPSD 的 token 级 KL，联合损失（joint loss）优于分离损失

  16. 自进化闭环：内化后的策略产出更好轨迹与更高质量技能记忆 → 反哺检索与蒸馏。

关键实验结果与数据

基准：ALFWorld（6 任务族成功率）、WebShop（128 任务评测集，分数/成功率）、Search-QA（7 个单跳/多跳数据集准确率）。

主结果（Table 1，对标最强基线 UCOB）：

  • ALFWorld 总成功率：93.8%（Qwen3-1.7B，+7.1）/ 95.3%（3B，+3.1）/ 96.1%（7B，+2.3）
  • WebShop 成功率：82.8%（1.7B，+8.1）/ 80.5%（3B，+3.2）/ 84.4%（7B，+3.9）
  • Search-QA 平均：42.1（1.7B）/ 43.4（3B）/ 48.4（7B，三基座中 7B 档第一；论文诚实说明该基准更依赖检索质量与证据理解、缺少可复用技能的重复环境状态，技能增益有限）
  • 模型越小增益越大：1.7B 档 ALFWorld 86.7→93.8、WebShop 74.7→82.8——技能内化显著补偿小模型先验不足

蒸馏权重与损失（Table 2，1.7B）：

  • λ_MD = 0 / 0.1 / 0.2 / 0.5 → ALFWorld 81.3 / 88.3 / 93.8 / 79.7，WebShop 46.9 / 77.3 / 82.8 / 67.2（0.2 为甜点，过大反噬）
  • 联合损失 93.8 vs 分离损失 83.6（ALFWorld）

检索策略消融（Table 3，1.7B，ALFWorld/WebShop）：

  • 完整动态检索 93.8 / 82.8
  • 仅相关性检索（无价值度量）73.4 / 65.6 —— ALFWorld 上差 20.4 分，全文最大单一杠杆
  • 去 Reliability 83.6 / 74.2；去 Advantage 91.4 / 76.6；去 Thompson 采样 88.3 / 72.7；去时间衰减 90.6 / 76.6

主消融（Figure 6）：

  • 去掉蒸馏整体 = 最大退化；蒸馏保留变体中去多视角 rollout 影响最大
  • 关键反转：在 MDSKILL 框架内前向蒸馏变成有益项（噪声被门控与多视角过滤后，前向监督变可靠）——与 S3 裸分析中"反向单独最强"形成对照，说明方向优劣是监督质量的函数，不是方向的固有属性
  • 蒸馏稳定性：多视角版 token 重叠更高、熵差更小更稳；skill-view 优势（skill-view 成功率 - skill-free 成功率）趋近零不深负 = 记忆不再拖累进化中的策略

查询拓展

  • OPSD 谱系：Zhao et al. 2026（On-Policy Self-Distillation 原始目标，GKD 的 on-policy 化）；RLSD / Skill-SD / StepOPSD / SDAR / UCOB——UCOB（锚组配对）是 MDSKILL 最强前驱与直接对照
  • 技能增强 RL 谱系：SkillRL、D2Skill、SkillC、SAPO、Skill1
  • RL 底座：GiGPO（Group-in-Group Policy Optimization，episode+step 双层优势分配）；GRPO
  • 经验记忆线：Shinn et al. 2023（Reflexion）、Wang et al. 2023（Voyager 技能库）——文本技能记忆的两个源头
  • 多教师蒸馏选轨：outcome-based teacher-student grouping 与 best-of-N 轨迹筛选（llm-as-a-verifier 框架）同族
  • 本文与前读 SPyCE（技能-策略协同进化 + 分层技能抽象）、EvoSOP（工具生命周期四模块）构成"Agent 技能自进化"三部曲：SPyCE 管技能怎么长，EvoSOP 管工具怎么管，MDSKILL 管技能怎么内化进参数

归纳总结

  • 一句话：技能记忆的内化瓶颈不在"有没有知识"而在"监督可不可靠"——按决策功能解纠缠 + 按结果价值选技能 + 按增益门控蒸馏方向，三条防线把噪声监督过滤成可靠监督
  • 三层贡献递进：①诊断（前向蒸馏传播噪声、功能纠缠掩盖贡献，Top-K 重叠/熵差实证）②方法（Beta+衰减+Thompson 的价值感知检索；三视角池；strict/relaxed 增益门 + 前向/反向/跨视角配对）③证据（三基座三基准 SOTA，消融闭环验证每个组件）
  • 反直觉点两条：反向蒸馏单独最强（学生纠正教师）；但框架完整后前向变有益——方向无固有优劣，监督质量决定一切
  • 最强单一杠杆是检索的价值感知（20.4 分差距），而非蒸馏方向本身——对工程落地者这是优先级排序信号
  • 与"检索策略才是真正的 alpha"命题直接共振：技能库同样成立——检索/选择策略 > 记忆本身

趋势判断

  • Agent 自进化研究正从"外挂记忆"转向"参数内化"：Reflexion/Voyager 式文本记忆是第一代，OPSD 系蒸馏内化是第二代，MDSKILL 代表第三代（内化质量工程化：解纠缠+门控+价值感知）
  • 技能价值度量从静态转向策略相对（policy-relative）：技能好坏不是绝对属性，随策略进化而变（内化后冗余、被更强策略超越），半衰期衰减是对这一动态性的直接承认
  • 小模型受益更大的结论与端侧 Agent 趋势互馈：技能内化是 1-3B 级模型补先验缺口的系统性手段，对边缘部署（Jetson 级）价值高于云端大模型
  • 蒸馏方向研究将走向"条件化路由"：MDSKILL 的增益门本质是按证据路由蒸馏方向，未来会看到更细粒度（token 级/步骤级）的路由门
  • 下一步自然延伸：多 Agent 技能共享下的内化（技能跨策略迁移时的度量对齐）、技能遗忘（内化后的显式 prune，呼应 EvoSOP 剪枝>创建结论）

指南分析

若要把"价值感知技能检索"落到自有系统，按论文配方的最小实现路径：

  1. 埋点：每次技能注入后记录 (skill_id, task_id, 成败 y)。锚组用 task_id 近似（没有锚状态就先粗粒度）
  2. 双指标维护：z_rel = y；z_adv 需要同任务无技能对照——无 A/B 条件时可退化为只用 Reliability + 时间衰减（论文消融显示去 Advantage 只掉 2.4/6.2，去 Reliability 掉 10.2/8.6，Reliability 优先）
  3. Beta 后验 + 半衰期：α = 1 + Σ w·z，β = 1 + Σ w·(1-z)，w = 2^(-Δt/H)；H 取值可从训练/使用周期量级起步（论文 Appendix B 有配置）
  4. 检索两段式：先语义 Top-K（现有能力），再 Thompson 采样重排——一行采样代码，防霸位
  5. 升降级门：relaxed 门（成功数 > 基线）做晋升门槛，strict 门做"明星技能"标记；连续负 Advantage 触发复核而非直接删除

避坑两条：λ/权重类超参过大反噬（0.5 档全面劣于 0.2 档）；Search-QA 类"状态不复现"的任务上技能增益天然有限，别硬套。

拓展应用推荐

对 Hermes Agent 生态的借鉴点分档：

  • P0 技能检索价值化：当前技能选择=描述匹配（等价论文的 relevance-only 73.4 档），引入 Reliability Beta+半衰期+Thompson 重排可望吃到最大单项杠杆。与 skill-health-tier（production/beta/skeleton 分层）融合：health 由静态分级升级为动态后验。埋点可挂在会话结束的任务成败信号上。工作量：中（埋点+一个排序模块）
  • P1 晋升门控：skill-ab-testing 的候选转正判据引入 relaxed 增益门（带技能成功 > 基线成功），替代单一功能测试通过即转正；skill-review 复核触发条件=连续负 Advantage。工作量：小
  • P1 技能三视角标签：诊断类（先查状态再动手，对应大量排查 skill）/规划类（编排工作流）/执行守卫类（验证门禁、安全红线）——给 SKILL.md frontmatter 加 view 字段，检索时按任务阶段选池，减少功能纠缠。工作量：小（打标）+ 中（检索改造）
  • P2 蒸馏数据选择：offline-policy-distillation（多教师合并单学生）的教师轨迹筛选可引入 outcome-based 配对——只蒸馏"学生失败而教师成功"的锚组段落，天然对齐 MDSKILL 增益门。DUCK 策略蒸馏线可直接对照
  • P2 量化因子库同构：因子 IC 的滚动衰减 ≈ 半衰期证据折扣；因子轮换的探索/利用平衡可用 Beta+Thompson 替代固定权重——与 quant-ic-validation 的 IC 验证框架拼接
  • ❌ 暂不适用：OPSD 本体（需要可训练策略权重与同任务对照 rollout），Hermes 是推理期 Agent 无参数更新通路，只能吸收其"选择与门控"思想而非蒸馏损失本身

局限性与未来方向（论文自述+推断）

  • Search-QA 增益有限：依赖检索质量与证据综合、缺少可复用技能发挥的重复环境状态（论文自认，非所有任务域都吃技能红利）
  • 依赖同任务多 rollout 的成败信号做度量与门控——单次执行、无对照的任务形态（如一次性运维操作）需要近似替代
  • 锚状态配对沿 UCOB，长视野任务中锚组可能稀疏；三视角池的维护成本（三套反思 prompt）随环境适配增长
  • 未触及：内化后的技能显式清理（何时从库里删）、跨策略/跨模型技能迁移的度量对齐、多 Agent 共享技能池的信用分配
