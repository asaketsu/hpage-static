SingGuard-Bench — 多模态安全护栏基准

探索时间: 2026-07-13 | 来源: arxiv 2606.22873, inclusionAI/Sing-Guard

摘要

SingGuard 是 InclusionAI 提出的策略自适应多模态 LLM 安全护栏模型家族。核心创新是将"安全策略（policy）"作为运行时输入，给定自然语言规则，逐条检查目标内容，同时预测安全标签与触发的具体规则。配套基准 SingGuard-Bench 含 56,340 条样本、覆盖 80+ 细粒度风险类型，横跨多模态问答、对抗攻击与动态规则评估三种场景。

关键发现

  • 策略自适应 (Policy-Adaptive)：区别于 Llama Guard / WildGuard / Qwen3Guard 等固定标签集护栏，SingGuard 支持运行时动态注入自然语言安全策略，灵活应对不同业务场景的规则变更
  • 跨模态联合风险：基准专门包含"单模态无害但组合后产生恶意意图"的跨模态案例（如图片+文本组合攻击），填补现有护栏只检测单模态的空白
  • 动态规则评估：在运行时策略切换场景下，策略遵循准确率从 0.6465 提升至 0.7415，证明模型具备真实的策略推理能力
  • 统一多模态能力：一个模型家族覆盖纯文本、纯图像、图文混合、多语种，以及 query-side / response-side 两侧安全检查
  • 输出结构：同时给出安全判定（safe/unsafe）+ 触发的具体规则，便于审计与合规

对工作的价值

  • 我们的 Hermes Agent 系统对外接入飞书/微信等多平台，若未来涉及多模态内容（图片+文字）安全审核，SingGuard 的策略自适应特性比固定分类护栏更适合定制化场景
  • 基准的"跨模态联合风险"设计思路可直接借鉴：我们评估 Agent 输出安全性时，也应关注文本+上下文组合产生的隐性风险，而非只看单条内容
  • 动态规则评估方法可作为我们实现可配置安全策略层的参考架构

行动建议

  1. 关注 inclusionAI/Sing-Guard GitHub 仓库，跟进模型权重与评测代码开源进度
  2. 后续做 Agent 安全评估时，可引入"策略注入+逐条检查"范式替代固定分类
  3. 在 homepage-dashboard 或 Agent 安全护栏设计中，预留 policy-as-input 接口
