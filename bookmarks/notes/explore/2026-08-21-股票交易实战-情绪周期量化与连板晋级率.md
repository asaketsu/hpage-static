## 核心问题

情绪周期人人会背"冰点→启动→发酵→高潮→退潮"，但实战需要回答两个可操作的问题：

1. **今天市场处于哪个阶段？**——需要量化的判定标准，不是感觉
2. **这个阶段该干什么？**——需要与仓位/选股策略联动的行动表

## 一、情绪温度计：三大核心数据的量化标准

### 1.1 三指标速查表（多源交叉验证版）

| 指标 | 冰点/退潮 | 温和/复苏 | 主升/发酵 | 高潮/过热 |
|------|-----------|-----------|-----------|-----------|
| **涨停家数** | <20-30 | 30-50 | >50 | 百股涨停 |
| **连板高度** | ≤3板 | 3→6板抬升 | 5-7板 | >7板 |
| **昨日涨停今日溢价** | <1%（恶性为负） | 1-2% | >3% | 极致一致（缩量加速） |
| **连板晋级率** | 11-12% | 30-40% | >50% | 近60% |
| **炸板率** | >30% | 15-30% | <15% | 骤升预警 |
| **跌停家数** | 40+ | <15 | <5 | 潮见顶日骤增 |

> 晋级率数据锚点（2026年实测）：7月2日阴分歧周期确认日晋级率仅 **11%-12%**（首板约72只→二板16只）；7月26日情绪回暖日 **55.56%**（9只连板→10只）；2月9日回暖确认 **50%**；8月12日高涨期**近60%**。晋级率是最灵敏的周期切换先行指标——涨停家数还在高位时，晋级率已先跌入冰点。

### 1.2 情绪分值法（2021经典版，仍是骨架）

```
退潮期 <20分：涨停<30家，跌停多，连板高度≤3板。严禁出手。
冰点期 20-50分：从6-7板打到3-4板那天出现，核按钮密集。
复苏期 50-70分：市场常态（占比最大），高度3-4板逐步抬升至6-7板。
高潮期 100+分：百股涨停，断板次日照样反包，无脑打板的天下。
```

**关键规律**：冰点期一般1-2天，**每月都有，每次冰点后就是试错新龙头的好时机**。退潮期绝对无赚钱效应，任何模式都失效，防守是唯一策略。

### 1.3 阶段判定信号树

```
每日收盘 3 分钟自检：
├─ 龙头脸色：龙头抗跌/连板 = 上行 | 跌停/断板无承接 = 下行
├─ 赚钱效应：昨涨停今均溢价 >2% = 良性 | <0% 且跌停增多 = 恶性
└─ 分歧性质：缩量回调快速反包 = 中继 | 放量滞涨/炸板不回 = 见顶

启动确认：板块2-3只首板成功晋级2-3板（资金共识形成）
退潮确认：涨跌家数比<0.5 + 反核指数持续为负 + 无新题材承接
```

## 二、四大阶段操作策略表（与半仓制对齐）

| 阶段 | 仓位上限 | 核心动作 | 选股方向 | 禁忌 |
|------|----------|----------|----------|------|
| 冰点启动 | 试仓≤10% | 盯新题材首板（政策/技术突破催化） | 首板 + 竞价爆量弱转强 | 回避前周期老龙头（易被抽血） |
| 发酵主升 | 5成（半仓制上限） | 持有主线龙头，断板不慌 | 龙头 + 中军 + 完整梯队板块 | 满仓追缩量加速板 |
| 高潮分化 | 减半兑现 | 龙头爆量分歧日分批止盈 | 只做总龙头 | 跟风股、中位股（杀跌先锋） |
| 绝望退潮 | **空仓** | 等冰点，不抄底 | — | 任何模式都失效，严禁出手 |

> 口诀（新浪财经版）：**冰点观望等拐点，回暖加仓做主线，高潮减仓落口袋，退潮空仓保本金。**

**三做三不做**（知乎图鉴版）：
- 做：启动期首板、高潮期龙头、冰点逆势板
- 不做：退潮期中位股、高潮期跟风股、分歧期缩量加速板

## 三、弱转强与分歧转一致：唯一值得学的买点技术

### 3.1 分歧的本质（2026-08 东财实战版核心）

```
一致是风险，分歧是机会
├─ 良性分歧：主线上升途中，核心股放量震荡但未破5日线 → 主力洗盘
│   └─ 确认：分歧次日高开>2% + 竞价抢筹 + 30分钟内反包 → "分歧转一致"买点
├─ 恶性分歧：放量滞涨 + 炸板不回封 + 板块指数背离 → 见顶信号
└─ 周期前提：只在情绪上升期的主线板块有效；退潮期的分歧 = 下跌中继
```

### 3.2 弱转强九要件（时间窗口 9:25-9:35）

| 要件 | 标准 | 失败信号 |
|------|------|----------|
| 前日弱合理 | 放量烂板/炸板但未破5日线 | 情绪好时走弱=不合理 |
| 次日竞价超预期 | 高开2-5% + 匹配量比放大 | 低开=转强失败 |
| 分时快速脱离成本 | 30分钟内站稳均价线拉升 | 15分钟不脱离=失败 |
| 板块共振 | 中军企稳 + 跟风跟涨 | 个股涨停板块跌=孤立 |
| 量能健康 | 转强可缩量，封板需温和放量 | 全程缩量拉升或爆量滞涨=假 |
| 位置正确 | 启动期或上升中继龙头 | 退潮期高位弱转强=诱多 |
| 逻辑未破 | 题材催化仍在发酵 | 纯技术反包持续性差 |
| 市场地位 | 板块内辨识度最高（前龙/卡位龙） | 独立走势杂毛股 |
| 止损纪律 | 次日未转强立即止损 | 抗单=分歧-衰退螺旋 |

### 3.3 看强做强：短线选手的底层操作模式

> 分歧状态中找**持续抗跌+跟随板块**的高辨识度个股（烂板/炸板/断板无所谓）；板块修复时（无论弱修复强修复），**率先完成分歧转一致的个股就是板块前排**。每次分歧转一致，不断向前排靠拢。

## 五、关键风险与盲点

- **指标的滞后性与瞬时性**（东财作者明确警告）：情绪拐点往往先于指标确认，任何"情绪指数"都是代理变量估算，只能定性参考。**解决**：用多维信号矩阵（涨跌家数比+连板高度+成交额变化+龙虎榜结构）综合感知，放弃寻找精准情绪值。
- **统计口径差异**：连板晋级率各家算法不一（含不含ST/未开板新股/一字板），7月2日复盘显示涨停数91-156只因口径而异。**自建系统必须钉死口径**（建议：不含ST、不含未开板新股，与财联社口径对齐）。
- **淘汰率陷阱**：晋级率50%看着高，但意味着**50%断板**——打板期望收益 = 晋级后平均涨幅×50% + 断板平均亏损×50%，需同时统计晋级溢价分布才完整。
- **来源级别声明**：以上全部为社区实战复盘总结（知乎/东财财富号/财联社数据），非学术论文；分值阈值（20/50/70/100）是经验拟合，未经大样本回测。**按铁律：外源因子必须本地回测 n>100 才可进策略**。
- **注册制后情绪结构变化**：有交易员观察到全面注册制后短线情绪长期在冰点下方小幅波动，指标需约700个交易日数据重新稳定——历史阈值可能系统性偏移。

## 六、一页速查

> **每日3分钟定调**：① 连板晋级率（<20%冰点 / 30-40%复苏 / >50%主升）② 昨涨停今溢价（<1%退潮 / >3%主升）③ 连板高度（≤3退潮 / >7高潮）
>
> **行动铁律**：冰点试仓10%盯新首板 | 复苏加仓做主线龙头 | 高潮分批兑现只留总龙头 | 退潮空仓
>
> **唯一买点**：情绪上升期 + 主线板块 + 良性分歧 + 次日弱转强（9:25-9:35确认，15分钟不脱离成本=失败）
>
> **见顶三联**：总龙头换手>40% + 跟风集体炸板 + 次日无反包
>
> **心法三条**：股票是概率学求平均数 | 小输大赢 | 下有界线上不封顶
