动态止损策略深度对比：ATR vs 固定百分比 vs 追踪止损

一、三种止损策略核心原理

1. ATR 动态止损（Average True Range Stop）

核心思想：利用平均真实波幅（ATR）衡量市场波动性，将止损距离与波动性动态挂钩。

计算公式：

止损价 = 买入价 - N × ATR(period)
做多止损：Stop = Entry - Multiplier × ATR
做空止损：Stop = Entry + Multiplier × ATR

参数说明：
- ATR周期（period）：通常取 14 日
- ATR倍数（Multiplier）：常见 1.5×~3×
- ATR 本身 = max(H-L, |H-PrevClose|, |L-PrevClose|) 的 N 日移动平均

关键特征：
- 波动大时止损宽，避免被正常波动震出
- 波动小时止损窄，锁定更多利润
- 本质上是让市场自身的波动节奏决定止损距离
- Wilder（1978）在 New Concepts in Technical Trading Systems 中首次提出 ATR 指标

Chandelier Exit（吊灯止损） 是 ATR 止损的经典变体：

做多止损 = 最高价 - Multiplier × ATR
做空止损 = 最低价 + Multiplier × ATR

止损位始终跟随最高/最低价动态调整。

2. 固定百分比止损（Fixed Percentage Stop）

核心思想：以买入价为基准，设定固定的跌幅百分比作为止损触发条件。

计算公式：

止损价 = 买入价 × (1 - StopPercent%)
例：买入价 10 元，止损 5% → 止损价 = 10 × 0.95 = 9.50 元

关键特征：
- 最简单直观的止损方法
- 止损距离恒定，不随市场波动变化
- 容易实现、容易理解、容易执行
- ths-auto-trader 当前默认策略即为此类（-5% 止损）

3. 追踪止损（Trailing Stop）

核心思想：止损位随价格上涨而不断上移（做多时），但不会下移。锁定浮动利润的同时给价格留出回调空间。

计算方式：
- 固定点数追踪：从最高价回撤固定点数触发
- 百分比追踪：从最高价回撤固定百分比触发
追踪止损价 = 持仓期间最高价 × (1 - TrailPercent%) 例：最高涨至 12 元，追踪 5% → 止损 = 12 × 0.95 = 11.40 元
- ATR追踪止损：从最高价回撤 N×ATR 触发（即 Chandelier Exit）

关键特征：
- 盈利时自动缩紧止损，保护利润
- 亏损时止损位不变，提供初始保护
- 百分比追踪与 ATR 追踪是最常用的两种变体

三、A股适用场景建议

3.1 场景一：大盘蓝筹 / 白马股（低波动）

推荐：固定百分比止损（3%-5%） 或 ATR止损（2×ATR）

  • 蓝筹股波动较小，固定百分比已足够覆盖日常波动
  • ATR 倍数可取较低值（1.5×~2×），避免止损过宽
  • 止损后考虑是否有基本面变化再决定是否回补

3.2 场景二：中小盘成长股（中等波动）

推荐：ATR 动态止损（2.5×~3× ATR） 或 ATR追踪止损

  • 波动性因股而异，ATR 能自动适配不同个股
  • 建议用 14 日 ATR，倍数 2.5~3 倍
  • 结合 Chandelier Exit 保护趋势利润

3.3 场景三：题材股 / 涨停板战法（高波动）

推荐：ATR 动态止损（3×~4× ATR） + 追踪止损组合

  • 高波动品种需要更宽的止损空间
  • ATR 倍数取 3~4 倍，避免被日内震幅洗出
  • 可叠加百分比止损作为硬止损（如 -8%~-10%）

3.4 场景四：中长期持仓（波段 / 趋势跟踪）

推荐：ATR 追踪止损（Chandelier Exit） 为主

  • 天然适合趋势跟踪，盈利越多止损越紧
  • 参数建议：ATR(20), 3×ATR 倍数
  • 可以在周线级别计算 ATR 以减少噪音

3.5 场景五：网格交易 / 量化高频

推荐：固定百分比止损（2%-3%） 或 ATR止损（1.5×ATR）

  • 单次止损小，依赖高频多次交易
  • 简单策略减少计算延迟

五、实战注意事项

5.1 A股特殊规则

  1. T+1 限制：当日买入无法当日止损，隔日开盘可能跳空越过止损位
  2. 建议：ATR 止损中适当加大倍数（+0.5×），留出跳空缓冲

  3. 隔夜风险无法通过日内止损规避

  4. 涨跌停板：10%/20% 涨跌停可能无法成交

  5. 建议：在止损逻辑中加入跌停板检测，次日优先处理

  6. 追踪止损在连续涨停时可能计算偏差，需特殊处理

  7. 集合竞价：9:25 确定开盘价，可能直接跳过止损价

  8. 建议：使用开盘价触发止损，而非盘中逐笔判断
  9. ths-auto-trader 应在 9:30 开盘后第一时间检查止损条件

5.2 止损策略组合建议

最佳实践：多层止损架构

第一层：硬止损（固定百分比 -8%~-10%）
  → 保护极端风险，永远不会被移除

第二层：ATR 动态止损（2.5×ATR(14)）
  → 根据波动自适应，日内主止损

第三层：追踪止损（盈利 > 3% 后激活）
  → 盈利时逐步锁定利润
  → 使用 Chandelier Exit 或百分比追踪 5%

5.3 常见陷阱

  1. 过度优化止损参数：回测中"最优"参数往往是过拟合

  2. 建议：使用参数区间而非单一值（如 2~3×ATR 而非固定 2.37×ATR）

  3. 忽略交易成本：止损触发后还有滑点和佣金

  4. A股佣金约 0.025%~0.1%，印花税卖出 0.05%

  5. 设置止损时需考虑至少 0.2% 的交易成本缓冲

  6. 止损后立即回补：被止损后不要立即重新买入

  7. 建议：设定冷却期（至少 1~2 个交易日）

  8. 或等待重新出现明确的买入信号

  9. 止损位太近：导致频繁止损，累积大量交易成本

  10. 建议：止损触发频率控制在总交易次数的 30%~40% 以内

  11. 忽视成交量信号：

  12. 放量跌破止损位 → 果断止损
  13. 缩量触及止损位 → 可考虑给 0.5%~1% 的缓冲

5.4 ths-auto-trader 实现建议

# 推荐的止损策略实现框架
class StopLossManager:
    def __init__(self, entry_price, atr_value):
        self.entry = entry_price
        self.hard_stop = entry_price * 0.92       # 硬止损 -8%
        self.atr_stop = entry_price - 2.5 * atr_value  # ATR止损
        self.highest = entry_price                # 追踪最高价
        self.trailing_active = False              # 追踪止损是否激活
        self.trailing_buffer = 0.05               # 追踪回调 5%

    def update(self, current_price, atr_value):
        self.highest = max(self.highest, current_price)

        # 盈利 3% 后激活追踪止损
        if current_price >= self.entry * 1.03:
            self.trailing_active = True

        # 计算各层止损
        stops = {
            'hard': self.hard_stop,
            'atr': self.entry - 2.5 * atr_value,
            'trailing': self.highest * (1 - self.trailing_buffer) if self.trailing_active else 0
        }

        # 取最高止损价（最紧的保护）
        active_stops = [v for v in stops.values() if v > 0]
        return max(active_stops)

    def should_stop(self, current_price, atr_value):
        stop_price = self.update(current_price, atr_value)
        return current_price <= stop_price, stop_price
