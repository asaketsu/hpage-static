## 归纳总结

Jev（9-15 出 stealth）本质是回答"这条消息进哪个盒子"——退款还是登录问题、demo 请求还是推销。作者用开源模型在 Nebius Token Factory 上五步复刻：①任何 LLM 变分类器（state+问题+字母选项，读单字母 logprobs 得全选项概率，~390 in/1 out token）；②合成数据三陷阱防御（写练与写测必须不同模型防同源虚高/85%+ 近重复删除/独立模型洗标签值 +9 分）；③诚实评分（Wilson 95% 区间+锁定测试集+只数单边对）；④开源克隆技巧实测（问两次消位置偏置不值、温度缩放不够路由、Qwen 与 Jev 错误零重叠=路由空间存在但被过度自信封死）；⑤LoRA 微调（Qwen3-30B-A3B+38MB adapter+15 分钟）追平 Jev（Support 99.1% vs 99.4% 平局）且**快 2 倍**（139ms vs 270ms）。核心论点：**模型是简单部分，数据和评分决定数字是否有意义**。成本拐点：月 44M 消息自建 GPU 打平 Jev；一次性积压用临时 GPU 便宜 70 倍。

## 内容整理：五步工程法

**Step 1 任何 LLM → 分类器**：
```
system prompt + state + question + 字母选项(A/B/C/D)
→ 只要一个字母 → 读该 token 的 logprobs → 全选项概率+置信度
```
~390 input tokens + 1 output token——便宜到可以高频调用。

**Step 2 数据三陷阱**（决定分数是否有意义）：
| 陷阱 | 后果 | 防御 |
|---|---|---|
| 测试像训练（同模型写两份） | 共享习惯，分数虚高 | Qwen3-235B 写练习 + DeepSeek V4 Flash 写测试，绝不混 |
| 近重复（85%+ 相似） | 两边都是近拷贝=见过作业再被打分 | 训练侧优先去重 |
| 标签错 | 直接污染双向 | 独立模型（Nemotron 3.5 Lightning）重标，分歧放一边（练 11%/测 13%）——**洗标签值 +9 分不改模型** |

加料：风格多样（短/怒/啰嗦/错字/转发链）+ 硬模式（每类一批借邻类词的look-alike）。

**Step 3 诚实评分**：每个分数带 Wilson 95% 区间；同消息全引擎对比，**只数"只有一个引擎对"的消息**（比总准确率信息量大）；测试集锁定永不进训练/prompt。

**Step 4 克隆技巧实测**：
- 问两次（正序+倒序平均，消首字母偏置）：+0.7 在误差条内，双倍成本不值
- 诚实置信度：Qwen 13 错 vs Jev 9 错**零重叠**（完美路由器=100%）——但 Qwen 96.5% 消息 99%+ 自信（含 13 错中 10 个）=过度自信封死路由空间
- 温度缩放：错误置信度 95.6%→87.1%，仍不够路由阈值
- 智能路由：第二意见必须**错得不同**； unsure 5% 只挪 <1 点

**Step 5 微调配方**：Qwen3-30B-A3B（MoE 3B 活跃）+ LoRA rank16/alpha32（38MB）+ 3 epochs/lr 1e-4/batch16 + 每任务 1000-1400 清洁消息 + **训练格式=测试格式完全同构**（同一 build_task 函数防漂移）+ 15 分钟。结果：Support 99.1% vs 99.4%（39% 是巧合=平局）；Sales 98.7% vs 99.8%（Jev 真赢）；速度 2 倍。加 400 同源合成邮件追差距：错 10→11，**同源数据到顶**。

## 内容整理：选型决策表

| 场景 | 方案 |
|---|---|
| 常规量在线收件箱 | Jev 或零样本 API |
| 超高稳态量 | 自建微调+自有 GPU（RTX PRO 6000 在月 44M 消息打平 Jev） |
| 一次性积压 | 临时 GPU（比 Jev 便宜 70 倍）用完关 |

局限自白：AI 写的测试消息比真实流量干净（加 100 条人工标注再信分数）；checker 塑造测试集故不能既当裁判又当选手；速度取决于部署位置。

## 📊 趋势判断

决策模型（Decision Model）作为独立品类正在从 LLM 中分叉：Jev 两周内逼出 OpenAI/AWS 跟进，说明"单字母输出+概率"这个最小契约有真实需求——它是 LLM 调用图谱里最便宜的确定性节点。但本文证明**这个品类的护城河很浅**：38MB LoRA+15 分钟+千条清洁数据就能追平——护城河不在模型在数据管道（三陷阱防御）与评分诚信（Wilson/锁定集）。预测：决策模型会像"embedding 服务"一样快速商品化，价值沉淀在垂直场景的标签资产与评估基准上。"新类别 vs 换皮分类器"之争的答案：技术上是换皮分类器，商业上是新计费单位。
