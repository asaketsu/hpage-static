PROFINET/EtherCAT 实时以太网 — 飞行帧处理 vs 交换式以太网，工业实时通信选型全景

生成日期 2026-11-08

摘要

EtherCAT 与 PROFINET 的对决不是"谁更快"，而是两种实时哲学：EtherCAT 用"飞行处理"（processing on the fly）——主站发一帧以太报文，穿过所有从站，每个从站在帧飞行的硬件通路上直接读走自己的输出数据、插入输入数据，最后一台从站经全双工路径回传；无存储转发、无每节点协议栈，从站用专用 ASIC（如 Beckhoff ET1100），典型周期 31.25µs、抖动 <1µs。PROFINET 用交换式以太网 + 一致性等级分层——RT 类在以太网 L2 做优先级（1-10ms 软实时），IRT 类在 PROFINET 感知交换机上做硬件时隙预留（250µs 等时同步）。市场格局（HMS 2025）：工业以太网已占新装节点 79%，PROFINET 27% > EtherNet/IP 23% > EtherCAT 17%，但 80% 的工厂里协议选择由 PLC 品牌决定而非技术优劣。2026-2030 的主线不是协议替代，而是收敛到共享 TSN 物理层 + OPC UA 监控模型。

关键发现

F1 两种实时哲学的机制差异

EtherCAT 飞行处理:
  Master ──帧──▶ Slave1[读输出/插输入] ──▶ Slave2[...] ──▶ SlaveN ──┐
     ▲                                                            │
     └────────────── 全双工路径原路返回 ◀──────────────────────────┘
  每从站延迟 ≈ 硬件位流处理(~1µs级), 无 store-and-forward, 无协议栈弹栈

PROFINET 交换式:
  IO-Controller ──▶ [管理型交换机 QoS] ──▶ IO-Device × N
  RT:  Eth-VLAN优先级(0x8000), 软实时, 周期 1-10ms
  IRT: 交换机硬件时隙预留(需 PROFINET 感知交换机), 250µs 等时同步
  DCP 发现协议自动分配设备名(免 DHCP)
维度 EtherCAT PROFINET
标准/组织 ETG (2003 Beckhoff 发布) PI (西门子系, PROFIBUS 继承者)
典型周期 31.25 µs RT 1-10ms / IRT 250 µs
抖动 <1 µs（分布式时钟 DC） IRT <1 µs / RT 低 ms 级
实现载体 从站专用 ASIC (ET1100) 或 FPGA RT=软件栈+普通交换机; IRT=硬件交换机
拓扑 线型菊花链/环，分支需 junction 星/线/环，交换式自由
开放性 IEC 61158, 2005 年至今 46 次技术变更多为勘误（核心稳定） 规范全开放，无许可摩擦（TIA 第三方设备库深）
同步机制 Distributed Clocks（传播延迟补偿，jitter << 1µs） IRT 分布式同步

中文工程界的三级口径（途舰自动化/TI 白皮书）：PROFINET A 类(CbA 组件化 ~100ms，楼宇) / B 类(RT ~10ms，工厂自动化) / C 类(IRT <1ms，运动控制专用硬件)——IRT 与 EtherCAT 同样不走 TCP/IP 传实时数据，硬件实时。

F3 最大 greenfield 架构错误：EtherCAT 穿标准交换机

"No. EtherCAT requires dedicated network segments... engineers specify a single managed switch backbone and then discover that EtherCAT cells cannot share it."

  • EtherCAT 不可路由穿过标准管理型交换机——存储转发会破坏时序。跨机通信需 OPC UA 网关、Modbus TCP 桥或并行骨干网
  • 正确架构：每个 EtherCAT cell 在主站控制器后面，主站用第二协议把汇总数据发上工厂骨干网——工业级管理交换机在 EtherCAT cell 上游，不在其内部
  • PROFINET RT 任意 QoS 管理交换机即可；IRT 必须 PROFINET 感知交换机（硬件时隙预留）

F4 功能安全：三 profile 全部 SIL 3，不许混用

安全 profile 载体协议 IEC 标准 参考实现
FSoE EtherCAT IEC 61784-3-12 Beckhoff TwinSAFE, Ixxat Safe T100
PROFIsafe PROFINET/PROFIBUS IEC 61784-3-3 Siemens S7-1500F + ET 200SP-F
CIP Safety EtherNet/IP IEC 61784-3-2 Allen-Bradley GuardLogix + POINT Guard

三者都能到 IEC 61508 的 SIL 3——安全完整性不是差异化因素，差异化的是你工厂已有哪家的安全控制器。同一安全功能内混用安全 profile 无任何厂商支持；协议网关只在标准数据层，不过安全数据。

F5 网关时延账（衔接 11-07 工业通信网关笔记）

桥接 典型网关 时延代价
EtherCAT ↔ EtherNet/IP HMS Anybus X-gateway, EL6692+EL6631 5-50 ms
PROFINET ↔ EtherNet/IP HMS Anybus, ProSoft PLX 5-20 ms
任意 → SCADA (Modbus/OPC UA) 原生 PLC OPC UA server 50-500 ms

工程红线：运动数据穿网关，10ms 周期变 30-60ms——运动闭环必须单协议；网关只过非实时数据（产量计数/配方/报警状态）。这与 11-07 笔记"边缘网关混合架构"互为印证：网关是监控层数据管道，不是实时层延长线。

两条元规律：①"正确的协议"几乎从不是技术最优问题，而是你的团队在用哪个工程工具；②同一实时闭环内混协议几乎总是错的，监控层混协议是正常且被支持的。

F7 2026-2030 趋势：TSN 收敛而非替代

"The shift is not protocol replacement — it is convergence on a shared TSN physical layer with OPC UA as the supervisory model."

  • TSN 交换机市场 $1.8B(2025) → $7.2B(2034)，16.7% CAGR——整体工业以太网增速(7.9%)的两倍以上
  • PROFINET over TSN 与 ODVA CIP Safety over TSN 均瞄准 2027-2028 在共享 TSN 交换机上跑亚毫秒周期
  • 采购铁律：2026-2028 发交换机 RFQ 时指定 TSN-capable 硬件，即使当前协议用不到——增量成本小，2029 年整机柜换交换机的成本不小
  • 三大协议到 2030 年都不会被替代，它们在获得 TSN profile

对工作的价值

  1. 工业通信三层拼图补全：Modbus/OPC-UA（11-04，监控/IT-OT 层）+ 本篇（PROFINET/EtherCAT，设备实时层）+ 工业通信网关（11-07，层间管道）——选型时可完整回答"哪层用哪个协议、层间怎么接、代价几毫秒"
  2. 单片机侧资源判断：EtherCAT 从站需专用 ASIC/FPGA（MCU 软实现不现实）；PROFINET RT device 可软件栈实现（STM32+LwIP 级别）；IRT 需硬件支持——与 11-04 的 Modbus(~10KB) / OPC UA(~150KB) 资源阶梯合并后，MCU 选型的协议成本一目了然
  3. 机器人项目对照：DUCK 的 STS 舵机走 RS485 总线（1Mbps 轮询式），对比 EtherCAT 100Mbps 飞行处理——理解了为什么多轴协调运动(≥8轴 sub-ms)工业界标配 EtherCAT，而 hobby 级舵机阵列靠降周期+插值容忍

行动建议

  1. 验收测试规格写法：同时写中位周期 + 99.9 分位最坏抖动，用硬件 tap + Wireshark 镜像口验证，不信 PLC 自带诊断计数器（"cycle time is meaningless without jitter"）
  2. 交换机采购 2026-2028 一律 TSN-capable
  3. 运动环单协议铁律写进架构评审清单；网关只准过非实时数据
  4. 遇厂商选型材料：cycle time 数字一律标注"厂商声明，需带实际节点数+负载实测"

关键风险与盲点

  • "哪个协议最快"是无意义问题——瓶装线 50ms 需求上 EtherCAT 是浪费；32 轴高速 pick-and-place 才需要每一微秒（官方验证：TSL/ETG 交叉数据）
  • 数据源偏差：ETG 白皮书夸 EtherCAT、PI 夸 PROFINET 是结构性利益——引用市场份额用 HMS（网络组件厂商，中立）、技术对比用双源交叉（本篇已做）
  • 中文社区（知乎机构号）内容多为编译转述，数字需对照英文一手源（本篇 TI/途舰数字已与 TSL/ETG 交叉核对一致）

一页速查

EtherCAT=飞行帧+ASIC 从站+菊花链，31.25µs/<1µs，不可穿标准交换机，运动控制之王。
PROFINET=交换式+等级分层(RT 1-10ms 软/IRT 250µs 硬)，星型自由拓扑，西门子生态，DCP 免 DHCP 发现。
市场(HMS 2025)：PROFINET 27% > EtherNet/IP 23% > EtherCAT 17%；80% 工厂由 PLC 品牌定协议。
安全：FSoE/PROFIsafe/CIP Safety 全 SIL 3，选已有控制器家族，禁止混用。
网关：穿网关 5-50ms + 抖动×3-6，运动环禁穿。
趋势：不是替代是 TSN 收敛($1.8B→$7.2B)，2026-2028 交换机 RFQ 指定 TSN-capable。
