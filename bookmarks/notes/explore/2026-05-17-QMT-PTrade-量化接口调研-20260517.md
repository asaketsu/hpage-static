# 券商 QMT/PTrade 量化交易接口调研

## 1. QMT（迅投）

### 1.1 产品定位
- **开发商**：迅投科技（同花顺子公司）
- **定位**：面向个人投资者的量化交易平台
- **支持券商**：国泰君安、中信建投、银河、海通等 30+ 券商

### 1.2 开通条件（2024-2025）

| 券商 | 资金门槛 | 其他要求 |
|------|----------|----------|
| 国泰君安 | 50 万 | 交易经验≥6 个月 |
| 中信建投 | 50 万 | 风险测评 C4 以上 |
| 银河证券 | 30 万 | 部分券商可协商 |
| 海通证券 | 50 万 | 需签署协议 |
| 华泰证券 | 50 万 | 线上申请 |

**通用条件**：
- 资金门槛：30-50 万（可协商）
- 交易经验：≥6 个月
- 风险测评：C4（积极型）以上
- 无违规记录

### 1.3 功能特点
- **研究端**：Python 策略编写 + 回测
- **交易端**：实盘下单 + 风控
- **数据**：Level-2 行情 + 基本面数据
- **API**：`xtquant` Python 库

### 1.4 代码示例
```python
from xtquant import xtdata
from xtquant.xttrader import XtTrader

# 连接
xtdata.connect_ws()

# 获取行情
data = xtdata.get_full_tick(['SH.600000'])

# 下单
xttrader.order_stock('SH.600000', 100, 'BUY', 10.5)
```

## 2. PTrade（恒生）

### 2.1 产品定位
- **开发商**：恒生电子
- **定位**：机构级量化交易平台，部分券商对个人开放
- **支持券商**：招商、广发、国信、申万宏源等

### 2.2 开通条件

| 券商 | 资金门槛 | 其他要求 |
|------|----------|----------|
| 招商证券 | 100 万 | 机构客户优先 |
| 广发证券 | 100 万 | 需线下申请 |
| 国信证券 | 50 万 | 部分可协商 |
| 申万宏源 | 100 万 | 机构通道 |

**通用条件**：
- 资金门槛：50-100 万（高于 QMT）
- 更偏向机构客户
- 部分券商仅对高净值个人开放

### 2.3 功能特点
- **专业级**：支持多账户管理
- **低延迟**：直连交易所
- **风控**：内置风控模块
- **API**：REST + WebSocket

## 3. 对比总结

| 维度 | QMT（迅投） | PTrade（恒生） |
|------|-------------|----------------|
| **资金门槛** | 30-50 万 | 50-100 万 |
| **个人友好度** | ⭐⭐⭐⭐ | ⭐⭐ |
| **券商覆盖** | 30+ | 20+ |
| **学习曲线** | 中等 | 较陡 |
| **延迟** | ~100ms | ~50ms |
| **适合人群** | 个人量化爱好者 | 机构/高净值 |
