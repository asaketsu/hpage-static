核心问题与研究动机

自进化 LLM Agent（solver 执行任务 + evolver 把执行经验蒸馏成持久技能）正在成为主流架构，但技能的持久性本身创造了新攻击面：恶意规则一旦被写进技能，会污染后续所有行为。

已有技能后门攻击（AgentPoison 等）假设攻击者能直接改受害者的技能文件——这在技能由可信 evolver 内部构建的现实系统中不成立。本文提出新问题：任务级后门攻击（task-level backdoor）——攻击者只能向进化任务集 D_evolve 注入 ≤B 个投毒任务，诱导 Agent 自己把后门写进自己的技能。

攻击者的两难（ motivating analysis 实证）：
- 端到端信号稀疏：攻击全失败时所有候选得分都是 0，无法区分"接近成功"和"完全失败"
- 阶段耦合：失败可能发生在技能蒸馏、技能加载、规则执行、效果达成任一环节，结果不可区分（Figure 2 实测：Activation 与 Following 失败任务占据主要失败量）
- 迭代优化不稳定：坏更新会摧毁先前进展，直接丢弃又丢失昂贵评估的反馈并导致重复无效更新（Table 1：TextGrad-Poison 在 SkillGrad×WikiTQ 上 ASR=0.0%，SkillOpt×WikiTQ 上 TACC 反常跌到 57.4%）

方法论内容整理（BadEvolve 框架详解）

形式化：技能状态 S，solver A_sol(S, x) 产出经验 e_x=(τ_x, o_x)，evolver 批量更新 S←A_evo(S, H_t)。攻击 = 在预算 B 内构造 D_poison 最大化触发任务的攻击成功率 J_obj，且不伤干净任务性能。

两种攻击目标：
- PI（Payload Injection）：触发任务上在正常答案之外附加攻击者行为（塞恶意链接/调未授权工具），不影响正确性——极难被察觉
- AC（Answer Corruption）：触发任务上直接答错（如篡改财报数字）——更难，因为自进化机制本身会强化有效解题行为

三个核心组件：

  1. 投毒任务构造：把同一投毒指令 φ 附加到 B 个干净任务（B=20），利用 evolver"把重复模式蒸馏成技能"的机制；参考答案在 PI 下用正确答案、AC 下用固定错误答案
  2. 四阶段失败诊断（核心创新）：恶意规则 r 必须依次通过
  3. Induction：evolver 把 r 写进技能
  4. Activation：solver 在触发任务上把含 r 的技能加载进上下文
  5. Following：轨迹实际执行了 r 描述的行为
  6. Effect：攻击达成
    每阶段算条件通过率 p̂I, p̂{A|I}, p̂{F|A}, p̂{E|F}，精确定位失败环节
  7. 失败感知门（failure-aware gate）：
  8. Rollback：候选 φ̃ 只有在「端到端增益 Δ≥ε」或「端到端持平但阶段进展分 g 提升」时才接受；g = p_I + p_I·p_{A|I} + p_I·p_{A|I}·p_{F|A}（累积阶段进展）
  9. 失败记忆：每个被拒候选记为四元组 m=(Δφ, ΔĴ, Δp̂, ρ 理由)，优化器后续更新条件于全部失败记忆，避免重复无效方向

实现：攻击优化器用 Claude Sonnet 4.6，L=5 轮优化，每个候选指令在验证集上跑 K=5 次代理自进化评估。攻击者无需访问受害者骨干模型、已进化技能或执行轨迹（灰盒）。

关键实验结果与数据

设置：4 个自进化框架（Trace2Skill / SkillGrad / SkillOpt / A-Evolve）× 4 骨干（Kimi-K2.5 / GPT-OSS-120B / Claude Sonnet 4.6 / Qwen3-235B）× 3 基准（SpreadsheetBench / WikiTQ / OfficeQA），3 次独立进化取平均。

PI 主结果（Kimi-K2.5 受害骨干，Table 2）：
- BadEvolve 平均 ASR 79.6%（区间 59.3-100.0），其中 SkillOpt×SpreadsheetBench 达 100%
- 基线 TBA 平均 37.6%（0.0-97.3 大幅波动），TextGrad-Poison 平均 27.8%（0.0-98.7）
- 隐蔽性：BadEvolve 的 CACC 仅比干净进化低 1.1pp——后门几乎不伤正常性能
- 归因干净：BadEvolve 与 TextGrad-Poison 用同一优化器、同一证据、同一预算，唯一差异是阶段反馈+失败门 → +51.8pp

AC 主结果（WikiTQ×A-Evolve，Table 3）：
- Kimi-K2.5：DASR 80.0%，TACC 从 86.0 砍到 19.6（-66.4pp），CACC 变化 ≤0.2pp
- Sonnet 4.6：DASR 54.1%（更强骨干更难攻但依然失守）
- 机制解剖：优化后的指令把"腐蚀"表述成一个解题步骤，evolver 把它蒸馏成看似合法的触发条件步骤，solver 照做——不靠记忆投毒任务的答案（投毒任务与测试集不相交）

灰盒迁移（Table 4）：受害骨干固定 Kimi-K2.5，换代理骨干平均 ASR 仍 84.6%；WikiTQ×SkillOpt 用 GPT-OSS-120B 或 Qwen3-235B 当代理反而 100%，高于同骨干的 66.7%——攻击不需要猜对受害者模型

消融（Figure 4）：
- 去阶段反馈（\SF）：OfficeQA×SkillGrad 掉到 0.0%
- 去 Rollback（\RB）：WikiTQ×Trace2Skill 掉到 33.3%
- 去失败记忆（\FM）：OfficeQA×SkillGrad 掉到 0.0%
- 结论：Rollback 防倒退 + 失败记忆防重复，二者互补缺一不可

预算曲线（Figure 5）：B∈{1,5,10,20,30,40}，ASR 随 B 单调上升，效用始终保持在 CACC₀ 附近

案例研究（最有教学价值）：
- TextGrad-Poison 反复误判失败原因（归咎指令缺失/长度/措辞），而阶段通过率显示实际卡在 Induction（p̂_I=0.4）
- BadEvolve 定向修 Induction → p̂_I 0.4→0.8，ASR 40.0%→79.5%（第 2 轮）
- Rollback 实战：第 2/4 轮候选导致 ASR 跌到近 0% 被丢弃，保留候选单调爬升 77.5%→87.5%

创新点分析

  1. 问题级创新：从"改技能文件"降级到"只投喂任务"——攻击假设与现实开放进化任务源（用户提交/公开来源）对齐，威胁模型成立性大增
  2. 四阶段诊断是通用方法论：把稀疏端到端信号分解为链式条件通过率，本质是信号归因，适用于一切"多环节管线+只有最终指标"的系统（技能系统、RAG、CI/CD）
  3. 失败感知门的形式化：两级接受准则（端到端 OR 中间进展）+ 失败记忆四元组，是 LLM 驱动迭代优化的稳定器，可直接移植到任何 LLM-as-optimizer 场景
  4. 归因严谨：同优化器同预算的对照设计让 +51.8pp 的增益无歧义地归到方法本身

局限性与未来方向

  • 只攻不防：论文明确把防御留作 future work——触发条件模式检测、技能谱系审计、进化任务来源验证都是空白
  • 攻击成本不低：每候选 5 次代理自进化 × 5 轮 = 25 次完整自进化模拟，对长进化管线开销可观
  • 触发器投放假设：测试时攻击者需能给目标任务附加 trigger，实际部署中依赖用户输入通道的可达性
  • 扩展方向（作者自述）：把攻击面从技能扩展到记忆和提示词等其他 harness 组件

归纳总结

一句话：自进化 Agent 的技能蒸馏管线是新的供应链攻击面——BadEvolve 证明不需要碰技能文件，只需 20 个投毒任务 + 5 轮失败感知优化，就能让 Agent 自己写出平均 79.6% 成功率（PI）的触发后门，同时正常性能仅损失 1.1pp。

三条硬结论：
- 端到端分数驱动的迭代优化在多阶段管线上必然盲飞（TextGrad-Poison 27.8% vs BadEvolve 79.6%，同优化器同预算）；阶段条件通过率是最小充分诊断信息
- 灰盒成立且反直觉：代理骨干与受害骨干不同时攻击反而可能更强（100% vs 66.7%），"隐藏骨干型号"不是有效防御
- "经验即指令"：任何能写入持久层的通道都等价于代码执行通道，重复注入是诱导蒸馏的攻击签名（B 个任务同一指令 φ）

趋势判断

  • Agent 安全重心迁移：提示注入/越狱（会话级）→ 记忆投毒（持久级）→ 技能投毒（可复用行为级）→ 任务级技能投毒（间接级，本文）。攻击面随 Agent 自我修改能力同步扩张，学习管线安全将成为 2027 年 Agent 系统的必答题
  • 赛道正在热化：concurrent work 2608.05563 已出现，防御侧论文窗口已开（本文明确不做防御），「触发条件模式检测/技能谱系 provenance/进化任务来源签名」三个方向预计 6-12 个月内出现首批系统工作
  • 对自进化框架的工程启示：开源自进化框架（本文指出 A-Evolve/SkillOpt 等均开源）= 攻击者可完整复现进化过程做离线优化，"框架开源+任务源开放"的组合需要内置来源验证层，否则等于把供应链私钥公开
  • LLM-as-optimizer 稳定器需求外溢：本文的 rollback+失败记忆本质是无梯度黑盒优化的信任域方法，预计会从攻击研究反哺到 prompt 优化/Agent 自改进的主流方法

指南分析

防御方可立即执行的五道检查（按论文四阶段反推）：
1. Induction 防御：技能 diff 审查——新增规则含触发条件语义（if 标记/关键词 then 行为）即拦截人工审
2. 注入签名检测：审计进化任务集——B 个任务携带高度相似指令 φ + AC 下参考答案异常统一，是投毒的双重指纹
3. Activation 监控：技能加载日志——检测"仅在特定 trigger 任务上被加载"的技能，正常技能的加载分布应与任务主题相关而非与特定标记相关
4. Effect 兜底：关键输出双通道校验——高价值决策数字由独立模型/规则通道复核
5. 来源治理：进化任务来源分级签名，外部来源任务蒸馏的技能进隔离观察期，观察期内不进入高权限调用链

（防御成本不对称：以上五道均为静态检查/日志级手段，无需改动进化算法本身）
