生成日期 2026-11-02

一、摘要

合成数据领域增强已从"提示词生成 QA 对"进化为多阶段、知识接地、带质量门禁的工业管线。三个数字锚点：①电信域（arXiv:2509.25736）用 HippoRAG 知识图谱检索 + 三模型分工（检索器/生成器/精炼器）+ 定制 RAGAS 过滤，全程零人工标注产出 RFT 排障数据，混合策略在质量保持率上碾压单策略（49.2% vs 21.5%）；②汽车诊断域（arXiv:2511.21748，Hitachi）从 3B 小模型做到 MCQ 任务比 2B-9B 开源模型最高 +25%，数据侧成本仅 22 GPU 小时标注 + 2 人时人工复核，管的是 DAPT 403M token 底座语料的策展；③工具链层（Red Hat SDG Hub，2025-11）把 Docling 文档解析 + YAML 流编排 + vLLM 批量推理拼成开箱即用的开源栈。核心反直觉发现：合成数据的质量瓶颈不在生成器而在"接地与过滤"——不接领域知识源的合成（BARE 式自由生成）在技术域会幻觉化；不过滤的合成（无 RAGAS 门禁）会把低质样本直接喂进 RFT。

二、关键发现

2.1 多阶段知识接地生成：电信排障域的零标注管线（arXiv:2509.25736）

  • 管线四件套：HippoRAG 从领域知识图谱检索上下文 → base generator 合成候选 QA → refinement model 用 top-k 文档精炼总结 → 定制 RAGAS 评分过滤低质样本，产出 RFT 数据
  • 与 BARE 的关键差异：BARE（base-refine 两段式）只保证多样性，缺结构化接地，在技术域会幻觉；本管线把"每个答案可追溯到知识图谱节点"作为硬约束
  • 混合策略铁证：base-only / instruct-only / hybrid 三种生成策略的质量保持率 21.5% / 26.8% / 49.2%——混合（基座模型出多样性 + 指令模型出格式）不是锦上添花，是翻倍
  • 场景：RAN 无线接入网排障，输入工程师告警查询，输出整合告警日志/配置管理/性能计数器多源证据的分步排障方案
  • 评测量身定制：BLEU/BERTScore 对程序性推理失效，改用 RAGAS 的 faithfulness/relevance/correctness + 电信专属 specificity 指标

2.2 DiagnosticSLM：管制工业域 3B 小模型的全链经济学（arXiv:2511.21748，Hitachi）

  • 三段训练管线：DAPT（领域适配预训练）→ DSFT（领域 SFT）→ DPO（偏好优化），底座 Llama-3.2-3B，2×RTX 4090 即可训练——管制环境（数据不出域）+ 低资源的完整范本
  • 数据策展经济学（本篇最硬的数字）：
  • 自底向上语料：内部文档抽关键词（Llama-3-70B-4bit）→ 定向 Google 搜索 → 706,971 网页 / 403M token
  • 相关性过滤：LLM 标注 2 万样本花了 22 GPU 小时（证明全量 LLM 标注贵到不可行）→ 抽样人工复核仅 2 人时，低错误率支撑继续用 LLM 标签
  • 成果：MCQ 任务比同档或更大（2B-9B）开源模型最高 +25% 准确率，QA/补全/摘要持平或胜出；配套发布 4 个诊断域基准（DiagnosticMCQ/QA/Comp/Sum）
  • DPO 段用的是通用 UltraFeedback 偏好对——领域偏好数据缺位是公开承认的短板（未来工作），说明"领域 DPO 数据合成"仍是空白区

2.3 工具链成熟：SDG Hub 把合成管线变成 YAML 配置（Red Hat，2025-11）

  • blocks + flows 抽象：block 是最小功能单元（LLMChatBlock/JSONStructureBlock/TextParserBlock），flow 用 YAML 声明式编排，可异步扩展、逐步调试、schema 校验
  • 企业文档三步走：Docling 把 PDF/Word/扫描件转结构化 Markdown → 现成 flow 从文档生成 QA 对 → SFT + RL 出领域模型
  • 实战案例：IBM 财报问答——多步查询（"找出两条营收同比增长但固定汇率下转负的业务线并报告百分比变化"）RAG 拼不对信息，合成 QA 微调后可答
  • 意义：合成数据管线从"每项目手搓脚本"进入"可复用基础设施"阶段——与 InstructLab 的贡献流同源

2.4 任务关键小模型的跨模型蒸馏合成（arXiv:2509.13047，海事）

  • GPT-4o + o3-mini 双模型分工（语言模型出 QA 多样性、推理模型出逻辑正确性）把原始 AIS 船舶轨迹数据转成 QA 对 → SFT Magistral Small 24B 等小模型
  • 要点：原始传感器/结构化数据 → 语言化 QA 对是"非文本领域数据"进 LLM 的通用桥；引用 Gerstgrasser 2024（累积式混合真+合成数据破递归崩溃诅咒）

2.5 质量门禁与崩溃防线

  • Model collapse 三条件（10-30 前序已立）在此具体化为工程对策：混入真实数据（种子语料）保底 + RAGAS 门禁拒收低质 + 多样性指标监控（成对余弦相似度 0.36 为健康线，instruct-only 飙到 0.60 = 模式坍缩预警）
  • 合成数据用途分化：SFT 数据（格式/风格）、RFT 数据（可验证推理链——电信排障方案天然可程序化验证）、DPO 偏好对（当前最缺）
  • Scale AI 成本研究（FITML@NeurIPS24）：不同生成策略（人工/模板/LLM 改写/LLM 自由生成）在不同预算下成本-效果曲线交叉——没有普适最优策略，只有预算-任务匹配

四、对现有工作的价值（Skill/项目改进建议）

  • P0｜domain-llm-training-pipeline skill 增补合成数据模块：当前管线假设训练数据已存在，应加"领域数据合成"前置阶段——种子文档 → 知识接地 QA 合成 → RAGAS 门禁 → 按配方混入。10-20 笔记立的"绝对量>配比"结论在适航域受限于标注成本，合成管线正是破局点
  • P0｜AeroStructFM 数据供给侧对齐 DiagnosticSLM 范本：同为管制行业（适航 vs 汽车）+ 数据不出域 + 结构化手册知识，三段管线（DAPT→DSFT→DPO）与 2×4090 资源档可直接对标；适航条款/AD 指令/故障案例可复刻"关键词→定向搜集→LLM 标注过滤"策展链
  • P1｜排障类任务的 RFT 合成：结构故障排查/维修决策与电信排障同构（多源证据整合+分步方案），且天然可程序化验证——是 RLVR 理想域（与 10-30 笔记 P1 建议闭环）
  • P2｜多样性监控落地：合成批次出厂前跑成对余弦相似度（0.36/0.60 阈值线），防模式坍缩样本混入

五、Actionable Insights

  1. 领域数据不够时，正确顺序是"先接地后生成"——自由生成（无知识图谱/检索锚点）在技术域等于批量制造幻觉训练样本
  2. 混合生成策略（基座模型+指令模型）质量保持率翻倍，成本几乎不变——生成器选型不是单选题
  3. LLM 标注的经济学账：标注用 LLM、复核用抽样的"LLM 标注+人工抽检"组合，比全人工便宜两个数量级（22 GPU 时 vs 等效人年）
  4. 领域 DPO 偏好对的合成是当前公开空白（DiagnosticSLM 用通用 UltraFeedback 凑合）——查新后可作为周论文切入方向

六、关键风险与盲点

  • 循环退化风险（来源级别：官方验证，Gerstgrasser 2024）：多代纯合成递归仍会崩溃，累积式混合（真种子+合成扩展）是已验证对策，但长期多代效应缺纵向研究
  • 合成偏差固化（来源级别：社区复现）：合成数据继承生成器的知识盲区——适航域用通用大模型生成时，条款引用错误会被 RAGAS 的 faithfulness 挡住一部分，但"遗漏"（该说没说）无门禁可挡
  • 评测自证循环（来源级别：推理）：合成数据训练 + 基准也是合成的 = 自说自话；DiagnosticSLM 的 4 基准部分由同类管线生成，+25% 数字需谨慎外推
  • 隐私放大（承接 10-30 MIA 发现）：合成样本若泄露种子语料统计特征，等于把私有手册"洗"进可公开的模型

七、一页速查

  • 管线五层：语料策展 → 知识接地生成 → 多模型混合 → RAGAS 门禁 → 三段训练（DAPT/DSFT/DPO）
  • 质量瓶颈在接地与过滤，不在生成器；混合策略 49.2% vs 单策略 21.5%
  • 管制域范本：3B 小模型 + 403M token DAPT + 2×4090 → MCQ +25%
  • 多样性红线：成对余弦相似度 0.36 健康 / 0.60 坍缩预警
  • 空白区：领域 DPO 偏好对合成、合成遗漏检测、多代纵向效应
  • 迁移口诀：先接地、混生成、严门禁、真种子保底
