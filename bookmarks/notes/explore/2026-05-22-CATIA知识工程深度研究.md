| 术语 | 全称 | 含义 | 性质 |

## 摘要

CATIA **Knowledgeware** 是 Dassault Systèmes 在 CATIA V5/V6/3DEXPERIENCE 中内置的一套**设计知识捕获、重用和自动化**产品族。它遵循 KBE（Knowledge-Based Engineering）方法论，通过参数（Parameters）、公式（Formulas）、规则（Rules）、检查（Checks）、反应特征（Reactive Features）、设计表（Design Tables）、目录（Catalogs）、Power Copy 和 User Feature 等机制，将工程师的设计经验、标准和约束编码为可执行的工程知识，实现从"手工画图"到"知识驱动设计"的范式转变。

## 二、核心功能详解

### 2.1 参数（Parameters）

参数是知识工程的**基础数据单元**，所有设计变量都通过参数表达。

**参数类型：**

| 类型 | 说明 | 示例 |
|------|------|------|
| 长度（Length） | 线性尺寸 | `孔径 = 10mm` |
| 角度（Angle） | 角度值 | `倒角角度 = 45deg` |
| 实数（Real） | 无量纲数值 | `安全系数 = 2.5` |
| 整数（Integer） | 整数值 | `螺栓数量 = 4` |
| 字符串（String） | 文本 | `材料 = "AL6061-T6"` |
| 布尔（Boolean） | 是/否 | `是否需要倒角 = true` |
| 特征（Feature） | 引用几何特征 | `参考面 = PartBody\Plane.1` |
| 列表（List） | 有序集合 | `尺寸列表 = [10, 20, 30]` |

**关键特性：**
- 支持多值参数（Multiple Values）— 限制可选范围
- 支持增量模式（Incremental）— 自动按步长递增
- 可在规格树中直接拖放关联
- 支持 Rename — 通过语义化命名提升可读性

### 2.2 公式（Formulas）

公式定义参数间的**数学关系和逻辑依赖**。

**语法结构：**
```
目标参数 = 表达式
```

**常用函数库：**

| 类别 | 函数 | 说明 |
|------|------|------|
| 数学 | `sin()`, `cos()`, `tan()`, `sqrt()`, `abs()`, `pow()` | 标准三角和数学运算 |
| 数学 | `round()`, `ceil()`, `floor()`, `int()` | 取整函数 |
| 统计 | `min()`, `max()`, `mean()` | 极值和均值 |
| 字符串 | `length()`, `concat()`, `substring()` | 文本操作 |
| 测量 | `distance()`, `angle()`, `area()`, `mass()` | 几何测量 |
| 零件 | `GetMinimumThickness()`, `GetVolume()` | 物理属性 |
| 曲线 | `Curvature()`, `Length()` | 曲线分析 |

**示例：**

```
// 标准件选型
螺栓直径 = if (载荷 > 5000N) { 12mm } else { 8mm }

// 壁厚计算（基于压力容器公式）
壁厚 = (设计压力 × 内径) / (2 × 许用应力 × 焊缝系数 - 设计压力) + 腐蚀裕量

// 模态参数化
齿轮模数 = if (传递功率 <= 5kW) { 2 } else if (传递功率 <= 20kW) { 3 } else { 4 }

// 关联设计
安装孔间距 = 外壳宽度 - 2 × 边距
```

### 2.3 规则（Rules）

规则是**条件-动作**对，当条件满足时自动执行操作，是最强大的知识表达方式。

**类型：**

| 规则类型 | 触发方式 | 典型场景 |
|---------|---------|---------|
| **Rule**（手动规则） | 手动触发或通过宏调用 | 复杂逻辑分派 |
| **Reaction**（反应规则） | 参数变化时自动触发 | 联动更新、自动修正 |
| **On-Change Reaction** | 特定参数变化触发 | 精确监听 |
| **Time-driven Rule** | 定时触发 | 周期性检查（少用） |

**Rule 语法结构：**
```
Rule 规则名称
  Let 变量声明
  If 条件表达式
    动作语句
  Else
    备选动作
  EndIf
```

**实战示例：**

```
// 示例1：标准件自动选型规则
Rule 螺栓选型规则
  Let boltGrade (String)
  If 载荷等级 == "轻载"
    boltGrade = "4.8"
    螺栓直径 = 6mm
  Else if 载荷等级 == "中载"
    boltGrade = "8.8"
    螺栓直径 = 10mm
  Else
    boltGrade = "12.9"
    螺栓直径 = 14mm
  EndIf
  螺栓规格 = concat("M", int(螺栓直径/mm), "-", boltGrade)
EndRule

// 示例2：钣金工艺检查反应
Reaction 钣金厚度检查
  Let minBendRadius (Length)
  minBendRadius = 板厚 * 2
  If 弯曲半径 < minBendRadius
    Message("警告：弯曲半径小于最小值（板厚×2）")
    弯曲半径 = minBendRadius
  EndIf
EndReaction

// 示例3：孔位阵列自适应
Rule 孔位自适应布局
  Let spacing (Length)
  spacing = (边长 - 2 * 边距) / (孔数 - 1)
  If spacing < 最小间距
    Message("孔间距过小，建议减少孔数或增大边长")
  EndIf
EndRule
```

### 2.4 检查（Checks）

检查用于**验证设计合规性**，不修改参数，仅报告状态。

**语法：**
```
Check 检查名称
  Condition = 布尔表达式
  Message("不满足时的提示信息")
  Severity = 0  // 0=信息, 1=警告, 2=错误
EndCheck
```

**应用场景：**

```
// 最小壁厚检查
Check 最小壁厚检查
  Condition = 最小壁厚 >= 2mm
  Message("壁厚不足2mm，可能影响结构强度")
  Severity = 2
EndCheck

// 材料匹配检查
Check 材料合规检查
  Condition = 材料密度 in [2.7, 7.85]  // 仅允许铝/钢
  Message("材料不在允许范围内")
  Severity = 1
EndCheck

// 装配干涉检查
Check 装配间隙检查
  Condition = 最小间隙 > 0.5mm
  Message("装配间隙不足，存在干涉风险")
  Severity = 2
EndCheck
```

**检查报告类型：**
- ✅ **OK**（绿色）— 满足条件
- ⚠️ **Warning**（黄色）— 警告级别
- ❌ **Error**（红色）— 严重违规

### 2.5 设计表（Design Tables）

设计表将**Excel/文本表格**与 CATIA 参数关联，实现系列化产品设计。

**工作机制：**

```
Excel 表格 → 设计表关联 → 参数驱动 → 自动生成变体
```

**表格结构示例（法兰系列）：**

| 法兰型号 | DN | 外径 | 螺栓孔数 | 螺栓孔径 | 厚度 | 密封面直径 |
|---------|-----|------|---------|---------|------|----------|
| DN50 | 50 | 165 | 4 | 18 | 20 | 102 |
| DN80 | 80 | 200 | 8 | 18 | 24 | 133 |
| DN100 | 100 | 235 | 8 | 22 | 26 | 158 |
| DN150 | 150 | 300 | 12 | 22 | 30 | 208 |

**使用方式：**
1. 在 Excel 中创建参数表（首行为参数名）
2. 通过 `Insert > Knowledge > Design Table` 导入
3. 选择要关联的参数
4. 通过切换行实现设计变体

**高级用法：**
- 嵌套设计表：主表+子表联动
- 条件过滤：`Filter = (DN >= 50) and (DN <= 200)`
- 宏驱动切换：通过 VBA/CAA 自动遍历所有配置

### 2.6 目录（Catalogs）

目录是**可重用设计元素的有组织集合**，类似"超级零件库"。

**目录内容类型：**
- 零件（Parts）
- 装配体（Assemblies）
- Power Copy
- User Feature
- 文档（Documents）
- URL 链接

**目录层级结构：**
```
Catalog: 企业标准件库
├── Chapter: 紧固件
│   ├── Family: 螺栓
│   │   ├── M6×20
│   │   ├── M8×30
│   │   └── M10×40
│   ├── Family: 螺母
│   └── Family: 垫圈
├── Chapter: 轴承
│   ├── Family: 深沟球轴承
│   └── Family: 圆锥滚子轴承
└── Chapter: 型材
    ├── Family: 角钢
    └── Family: 槽钢
```

**CATCatalogFile.catalog 文件格式：**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<Catalog>
  <Chapter Name="紧固件">
    <Family Name="螺栓">
      <Component Name="M6x20" File="bolt_M6x20.CATPart"/>
      <Component Name="M8x30" File="bolt_M8x30.CATPart"/>
    </Family>
  </Chapter>
</Catalog>
```

### 2.7 Power Copy

Power Copy 是**可参数化复用的特征组模板**，将一组关联的设计特征打包为可重用模板。

**创建步骤：**
1. 设计原始特征组（含完整参数和约束）
2. `Insert > Knowledge > Power Copy` → 选择特征
3. 定义输入参考（Input References）：哪些面/线/点需要用户指定
4. 发布参数（Published Parameters）：哪些参数允许用户修改
5. 保存到目录或文件

**应用流程：**
```
选择 Power Copy → 指定输入参考（面/线/点）→ 修改参数 → 自动生成
```

**典型应用：**
- 标准安装孔组（通孔+沉孔+倒角）
- 散热齿阵列
- 加强筋模板
- 卡扣连接特征

### 2.8 User Feature（UDF）

User Feature 是**封装了内部逻辑的黑盒特征**，对外只暴露接口参数。

**与 Power Copy 的区别：**

| 特性 | Power Copy | User Feature |
|------|-----------|--------------|
| 内部可见性 | 完全可见 | 黑盒封装 |
| 参数暴露 | 全部可见 | 选择性暴露 |
| 编辑方式 | 编辑原始特征 | 仅修改暴露参数 |
| 保护性 | 无 | 内部逻辑受保护 |
| 适合场景 | 标准特征复制 | 专有设计封装 |

**UDF 创建步骤：**
1. 设计并测试原始特征
2. `Insert > Knowledge > User Feature` → 选择特征
3. 定义输入（Inputs）：参考几何
4. 定义输出（Outputs）：结果几何
5. 发布参数（Publications）：允许修改的参数
6. 保存为 `.CATPart` 文件

### 2.9 反应特征（Reactive Features）

反应特征实现**事件驱动的自动响应**，当指定事件发生时自动执行。

**事件类型：**
- `ValueChange` — 参数值变化
- `AttributeChange` — 属性变化
- `FeatureCreate` — 特征创建
- `FeatureDelete` — 特征删除
- `Open` — 文件打开
- `Save` — 文件保存

**示例：**
```
Reaction 自动标注更新
  Trigger = ValueChange(设计版本号)
  Action:
    图框版本 = 设计版本号
    日期 = currentDate()
    Message("设计版本已更新为: " + 设计版本号)
EndReaction
```

### 2.10 列表和循环（Lists & Loops）

**列表操作：**
```
// 创建列表
Let myList (List)
myList = List(1, 2, 3, 4, 5)

// 列表操作
myList.Append(6)        // 添加元素
myList.Remove(2)         // 移除索引2的元素
myList.Size()            // 获取大小
myList.GetItem(3)        // 按索引获取

// 列表遍历
For i From 1 To myList.Size()
  // 操作 myList.GetItem(i)
EndFor
```

**循环结构：**
```
// For 循环
For i From 1 To 孔数量
  Let angle (Angle)
  angle = 360deg / 孔数量 * (i - 1)
  // 创建孔特征在角度angle处
EndFor

// While 循环
Let count (Integer)
count = 0
While count < 最大迭代次数
  count = count + 1
  // 迭代计算
EndWhile
```

### 2.11 知识模式脚本（Knowledge Pattern / Generative Knowledge）

知识模式脚本用于**批量自动生成重复性几何**。

**脚本示例（散热齿阵列生成）：**
```
KnowledgePattern 散热齿生成器
  // 输入参数
  Input: 基板长度 (Length), 齿高 (Length), 齿宽 (Length), 齿间距 (Length)
  
  // 计算
  Let 齿数 (Integer)
  齿数 = int(基板长度 / (齿宽 + 齿间距))
  
  // 循环生成
  For i From 0 To 齿数 - 1
    Let x (Length)
    x = i * (齿宽 + 齿间距)
    CreatePad(齿高, 齿宽, at=x)
  EndFor
  
  Output: 散热齿阵列几何体
EndKnowledgePattern
```

## 三、Knowledge Expert（KWE）— 企业级规则引擎

### 3.1 Rule Base 与 Rule Set

Knowledge Expert 提供结构化的**规则库管理**，是 KWA 的企业级升级版：

```
Rule Base: 企业设计规范
├── Rule Set: 材料规范
│   ├── Rule: 材料选择规则
│   ├── Check: 材料合规检查
│   └── Rule Set: 有色金属子集    ← 可嵌套
│       └── Rule: 铝合金选型
├── Rule Set: 尺寸规范
│   └── Rule: 最小壁厚
└── Rule Set: 工艺规范
```

**关键概念：**
- **Rule Base** = 顶层容器，一个 Part 可有多个 Rule Base
- **Rule Set** = 逻辑分组（类似代码中的 package/module），可嵌套
- **Rule** = 产生式规则（If-Then），**可修改**参数值
- **Check** = 约束检查（布尔表达式 + 诊断消息），**不能**修改参数

### 3.2 推理机制

1. **前向推理**（默认）：从已知条件 → 推导结论 → 修改参数
   - KWE 中所有 Rule 都是前向推理
   - 执行顺序由 Rule Set 内的位置或优先级决定
2. **无后向推理**：KWE 不支持目标驱动的反向推理链
   - 如需"已知目标求参数" → 用 KWA 的优化功能或外接求解器
3. **冲突消解策略**：
   - 优先级数值越高越优先（默认=0）
   - 同优先级时后定义的覆盖先定义的
   - `NoLoop` 关键字防止循环触发

### 3.3 三种求解模式

| 模式 | 英文 | 执行逻辑 | 适用场景 |
|------|------|---------|---------|
| 顺序 | Sequential | 从上到下逐条执行 | 规则间无冲突、执行顺序重要 |
| 冲突消解 | Conflict Resolution | 优先级高的覆盖低的 | 多条规则可能影响同一参数 |
| 传播 | Propagation | 变化沿依赖链传播 | 参数联动、级联更新 |

### 3.4 KWE 扩展语法

```
Rule 专家规则名
  Priority = 10
  NoLoop        // 防止循环触发
  
  Let 材料 (String)
  Let 应力 (Real)
  
  If PartBody\材料参数 == "Q235"
    if 屈服应力 > 235MPa
      PartBody\安全系数 = 1.5
    endif
  EndIf
EndRule
```

### 3.5 Check + 诊断报告

```
Check 壁厚检查
  Condition = PartBody\壁厚 >= PartBody\最小壁厚
  Message("壁厚 " + PartBody\壁厚 + "mm 低于最小要求 " + PartBody\最小壁厚 + "mm")
  Severity = 2    // 0=信息(蓝), 1=警告(黄), 2=错误(红)
EndCheck
```

**诊断报告**（Diagnostic Report）：
- Tools > Generate Report → 输出 HTML/TXT
- 列出所有 Check 的通过/失败状态
- 可嵌入企业审核流程
- 失败的 Check 标红并附 Message 文本

```
┌─────────────────────────────────────────┐
│  KWE 诊断报告                           │
├──────────────┬──────┬───────────────────┤
│ 规则名称     │ 状态 │ 消息              │
├──────────────┼──────┼───────────────────┤
│ 最小壁厚检查 │ ❌   │ 壁厚1.5mm < 2mm   │
│ 材料合规检查 │ ✅   │ AL6061-T6 合规    │
│ 拔模角度检查 │ ⚠️   │ 建议≥3°拔模      │
│ 装配间隙检查 │ ✅   │ 间隙0.8mm > 0.5mm │
└──────────────┴──────┴───────────────────┘
```

### 3.6 KWE vs KWA 分工

| 维度 | KWA | KWE |
|------|-----|-----|
| 定位 | 知识建模（参数+公式+规则） | 知识执行与合规验证 |
| 规则规模 | 单条，零件级 | Rule Base，企业级 |
| 合规检查 | 简单 Check | 诊断报告 + 审核流程 |
| 用户角色 | 设计工程师 | 知识工程师/标准化部门 |
| 跨 Part 引用 | 需 Publication | 需 Publication + Rule Base 链接 |
| 与 CAA 交互 | `CATICkeParmFactory` | `CATIKweRuleSet` / `CATIKweRuleBase` |

### 3.7 企业级最佳实践

1. **Rule Set 按标准分类**：一个 Rule Set = 一个国标/企标
2. **Check 全覆盖**：每个关键参数至少配一个 Check + Severity=2
3. **优先级分层**：安全相关=100，功能相关=50，工艺偏好=10
4. **NoLoop 必加**：修改参数的 Rule 一律加 NoLoop，否则 CATIA 崩溃
5. **诊断报告集成**：设计评审前生成报告，替代人工检查清单
6. **版本管理**：Rule Base 通过 Enoviav6/3DEXPERIENCE 管理版本

## 四、CAA API 知识工程接口

通过 CAA（C++）API 可以编程访问知识工程功能：

### 4.1 参数访问

```cpp
// 获取参数集
CATICkeParmFactory_var spParmFactory = spPart;

// 创建参数
CATICkeParm_var spDiameter = spParmFactory->CreateLength("螺栓直径", 10.0);

// 读取参数值
double value = spDiameter->Value()->AsReal();

// 设置参数值
CATCkeGlobals::SetParmValue(spDiameter, 12.0);

// 查找参数
CATICkeParm_var spParm;
CATCkeGlobalFunctions::GetParmDictionary()->FindParm("壁厚", spParm);
```

### 4.2 公式操作

```cpp
// 创建公式
CATICkeFormula_var spFormula;

    CATListValCATICkeParmVar(参数列表));
```

```cpp
// 获取规则集
```

## 🔍 AI 融入 CATIA 知识工程的研究方向

### 方向1：LLM 辅助规则生成
- 用自然语言描述设计意图 → LLM 自动生成 KWA 规则代码
- 减少工程师学习曲线，降低 KBE 采用门槛

### 方向2：智能参数推荐
- 基于历史设计数据训练 ML 模型 → 自动推荐参数值
- 例如：给定载荷工况，自动推荐螺栓规格、壁厚、材料

### 方向3：设计合规性智能审查
- 将企业标准/AIAG/AS9100 等标准数字化 → LLM 解读 → 自动生成 Check 规则
- 传统做法需要人工逐条编码规则，AI 可以加速这个过程

### 方向4：生成式设计 + KBE
- AI 生成拓扑优化方案 → KBE 编码设计约束 → 自动生成制造可行的 CAD 模型
- CATIA 2026x 已推出 AI-Driven Generative Experiences

### 方向5：知识图谱驱动的智能设计
- 将企业设计知识构建为知识图谱 → 图检索 + LLM 推理 → 自动化设计决策
