开源 AI 编程式 3D 建模 — 学习笔记

嗅探日期：2026-07-07 ｜ 类型：auto-explore

摘要

"AI 编程 3D 建模"指的不是文字/图片直接生成网格（如 Tripo/Meshy/TRELLIS 的扩散模型路线），而是 让 AI 编程 Agent（Claude Code、Codex）通过生成源代码（build123d/OpenSCAD/CadQuery）来产出参数化、可版本管理、可制造的专业 CAD 模型。这是 2026 年兴起的新范式：模型即代码（Model-as-Code）。代表项目是 earthtojake 的 text-to-cad Harness，它让编码 Agent 读懂仓库后自动生成 STEP/STL/3MF/URDF 等工程格式，配合本地 CAD Explorer 实时查看几何体。

关键发现

  • 范式分野（2026 年明确）：
  • 扩散模型路线 — TRELLIS 2、Hunyuan3D、Meshy、Tripo：图片/文字 → 网格/高斯溅射，擅长游戏资产、概念原型，但拓扑不可控、不可参数化。
  • 代码生成路线 — text-to-cad、CadQuery+LLM、Zoo.dev ML-CAD：文字 → Python/build123d 源码 → 参数化 STEP，拓扑干净、可制造、可版本管理、可迭代。
  • text-to-cad Harness 核心能力（earthtojake，2026-05 发布）：
  • 基于 build123d + OpenCascade，完全本地运行，无云依赖。
  • 导出格式齐全：STEP、STL、3MF、DXF、GLB、URDF（机器人描述）。
  • 内置 React/Vite 的本地 CAD Explorer，实时查看几何体并精确迭代。
  • 稳定 @cad[] 引用机制：AI 能"记住"之前生成的零件并增量修改，解决多轮编辑的一致性问题。
  • 内置 Skill：URDF 机器人描述、ROS 2/MoveIt 运动规划、制造预检（manufacturing preflight）。
  • TRELLIS 2（微软）：综合最佳开源，图片→高斯溅射，视觉质量领先，免费本地无限生成，约 15-30 秒/模型。trellis2.app 提供网页版。
  • Hunyuan3D（腾讯）：开源最佳替代，自托管免费，约 15 秒/模型，社区比 TRELLIS 小。
  • MCP 化趋势：Meshy、Chisel 等已发布 MCP server，让 Claude/Agent 直接调用 3D 生成能力，无需切窗口。Chisel 走"基元 + 布尔 CSG"的代码路线，无 GPU 也能跑。
  • 2026 生态总结：3DAIGC 工作流已被拆解为 MeshGen、重拓扑、UV 展开、纹生成、网格分割、自动绑骨、网格编辑等独立环节（Open3DStudio 已实现全本地流水线）。

对工作的价值

  • 机器人开发直接相关：text-to-cad 内置 URDF + ROS 2/MoveIt skill，正好补齐我之前做 exoskeleton-control / dual-mcu-robot / servo-arm-control 时"机械结构 CAD 自动生成"的空白——可以让 AI 直接出零件 + URDF 描述文件。
  • 开源硬件项目加速：open-source-hardware-project skill 里的"3D 打印（OpenSCAD 参数化）"环节，可升级为 build123d + AI 代码生成，质量更高、迭代更快。
  • Skill 复用模式：text-to-cad 的 @cad[] 引用机制和"内置 Skill（URDF/运动规划/制造预检）"架构，与我自己的 Skill 体系高度同构，可借鉴其"代码即模型、版本即规范"的设计哲学。
  • 本地化优先：text-to-cad 全本地、TRELLIS/Hunyuan3D 自托管，符合我 Jetson Orin 边缘部署方向——可在本地 GPU 上跑 3D 生成而不依赖云 API。

行动建议

  1. 试用 text-to-cad：clone earthtojake/text-to-cad，跑一个简单零件（如 L 型支架），验证 build123d + Claude Code 的代码生成质量与 STEP 导出可用性。
  2. 评估 TRELLIS 2 在 Jetson 上的可行性：检查显存（需 ≥8GB）、CUDA 版本兼容性，若可行则作为本地图片→3D 资产流水线。
  3. 沉淀 Skill（条件触发）：若 text-to-cad 验证可用，创建 ai-cad-codegen skill，串联"需求描述 → AI 生成 build123d 代码 → 导出 STEP/URDF → CAD Explorer 预览"，补全机器人/硬件项目的结构设计环节。
  4. 关注 Chisel MCP：无 GPU 的纯代码 CSG 路线，可作为 Jetson 算力不足时的降级方案。
