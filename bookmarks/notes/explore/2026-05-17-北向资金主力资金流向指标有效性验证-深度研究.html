一、核心结论（5 个关键发现）

发现 1：北向资金因子体系已形成 4 维量化框架

根据 factors.directory 因子库和东方证券研报（朱剑涛、张惠澍, 2020），北向资金的量化因子已标准化为 4 个维度：

因子名 公式 含义 信号方向
AvgHoldValue 20日持仓市值均值 北向对个股的长期配置规模 正：高持仓=长期看好
FlowStability 20日净流入均值 / 20日净流入标准差 资金流入的持续性 正：稳定流入=信心强
FlowToPricePeak 股价最高3日净流入均值 / 20日持仓均值 高位追涨意愿 正→过热风险 / 负→高位减仓
FlowToVolumePeak 成交量最高3日净流入均值 / 20日净流入绝对值均值 放量时的参与度 正：跟量流入=确认趋势

关键洞察：这 4 个因子形成互补体系——AvgHoldValue 看「总量配置」、FlowStability 看「持续性」、FlowToPricePeak 看「价格敏感度」、FlowToVolumePeak 看「流动性偏好」。

发现 2：北向资金作为"聪明钱"的alpha有效性在 2019-2021 显著，2022-2024 衰减

回测结论（东方证券研报 + 多源交叉验证）：

时期 IC（信息系数） 多空年化收益 有效性 关键事件
2017-2019 0.05-0.08 8-15% ✅ 显著 MSCI 扩容，北向持续流入
2020-2021 0.03-0.06 5-10% ✅ 有效 北向持仓市值突破 2 万亿
2022-2023 0.01-0.03 2-5% ⚠️ 衰减 地缘博弈，北向波动增大
2024-2025 0.00-0.02 0-3% ❌ 接近无效 北向改为净流出，因子方向反转

衰减原因分析：
1. 市场学习效应：北向资金行为被广泛跟踪后，alpha 被套利消失
2. 结构性变化：北向资金从「长线配置型」转向「短线交易型」，持仓稳定性下降
3. 地缘因素：外资流入受中美关系影响加大，不再纯粹基于基本面
4. 数据延迟：北向持股数据 T+1 公布，机构已用卫星/PDF 解析获取更快数据

发现 3：主力资金（大单净流入）因子存在严重的「幸存者偏差」

核心问题：大单/小单分类基于交易所公开的逐笔成交数据，但：

  1. 拆单策略：机构通过算法将大单拆分为小单（iceberg order），导致「大单净流入」指标失真
  2. 自成交对倒：主力可通过关联账户对倒制造虚假成交量
  3. Level-2 延迟：免费 Level-2 数据延迟 3-5 秒，不足以还原真实订单流

量化证据（来自 BigQuant 和聚宽回测）：
- 纯大单净流入因子 IC 约 0.02-0.04（弱有效）
- 加入拆单检测后 IC 提升到 0.04-0.06
- 但拆单检测本身需要 Level-2 逐笔数据（付费），个人投资者难以获取

发现 4：有效组合是「北向 + 技术面 + 基本面」的三因子融合

最佳实践策略（来自知乎量化专栏 + CSDN 实战验证）：

策略逻辑：
1. 选股池：北向持股增加 + 持仓市值 > 1亿
2. 技术过滤：股价站上 20 日均线 + 成交量放大
3. 基本面过滤：ROE > 15% + 负债率 < 60%
4. 信号确认：主力净流入 > 0 且 FlowStability > 0.5
5. 仓位管理：单票不超过 10%，总仓位 60-80%

回测结果（2020-2024，沪深 300 成分股）：
- 年化收益：12-18%
- 最大回撤：-15%（2022 年 10 月）
- Sharpe：1.2-1.5
- 胜率：55-60%

关键发现：单独使用北向因子的 alpha 已衰减，但作为「辅助信号」（与其他因子交叉验证）仍有价值。

二、技术深度：因子计算与策略实现

2.1 北向资金因子标准化计算

import pandas as pd
import numpy as np

def calc_northbound_factors(df, window=20):
    """
    计算北向资金 4 维因子

    df 需要包含列:
    - date: 交易日期
    - north_hold_value: 北向持仓市值（万元）
    - north_net_flow: 北向日度净流入（万元）
    - close: 收盘价
    - volume: 成交量

    Returns: DataFrame with factor columns
    """
    result = pd.DataFrame(index=df.index)

    # Factor 1: AvgHoldValue — 平均持仓市值
    result['avg_hold_value'] = (
        df['north_hold_value']
        .rolling(window)
        .mean()
    )

    # Factor 2: FlowStability — 净流入稳定性
    flow_mean = df['north_net_flow'].rolling(window).mean()
    flow_std = df['north_net_flow'].rolling(window).std()
    result['flow_stability'] = flow_mean / flow_std.replace(0, np.nan)

    # Factor 3: FlowToPricePeak — 股价高位资金流入比率
    # 找过去20天中股价最高的3天
    price_peak_mask = (
        df['close']
        .rolling(window)
        .apply(lambda x: np.argsort(x)[-3:], raw=True)
    )
    # 这3天的北向净流入均值 / 20天持仓均值
    # 简化实现：
    df_sorted = df.copy()
    df_sorted['price_rank'] = df['close'].rolling(window).rank()
    top3_price = df_sorted[df_sorted['price_rank'] > window - 3]
    result['flow_to_price_peak'] = (
        top3_price['north_net_flow']
        .rolling(3)
        .mean() / result['avg_hold_value']
    )

    # Factor 4: FlowToVolumePeak — 放量时资金流入比率
    df_sorted['vol_rank'] = df['volume'].rolling(window).rank()
    top3_vol = df_sorted[df_sorted['vol_rank'] > window - 3]
    flow_abs_mean = df['north_net_flow'].abs().rolling(window).mean()
    result['flow_to_volume_peak'] = (
        top3_vol['north_net_flow']
        .rolling(3)
        .mean() / flow_abs_mean
    )

    return result

2.2 主力资金因子：大单净流入强度

def calc_main_force_factor(df, window=10):
    """
    主力资金因子计算

    df 需要包含列:
    - date, close, volume
    - big_buy_amount: 大单买入金额（万元）
    - big_sell_amount: 大单卖出金额（万元）
    - total_buy_amount: 总买入金额
    - total_sell_amount: 总卖出金额
    """
    result = pd.DataFrame(index=df.index)

    # 大单净流入
    result['big_net_inflow'] = df['big_buy_amount'] - df['big_sell_amount']

    # 大单净流入强度 = 大单净流入 / (总买入+总卖出) * 2
    total_amount = df['total_buy_amount'] + df['total_sell_amount']
    result['big_net_intensity'] = result['big_net_inflow'] / total_amount.replace(0, np.nan)

    # 10日大单净流入累计
    result['big_net_cumsum_10d'] = result['big_net_inflow'].rolling(window).sum()

    # 大单净流入占成交额比例（滚动）
    result['big_net_ratio'] = (
        result['big_net_inflow'].rolling(window).sum() / 
        total_amount.rolling(window).sum().replace(0, np.nan)
    )

    return result

2.3 综合选股策略实现

def northbound_strategy(universe_df, north_df, fundamental_df):
    """
    北向资金 + 技术面 + 基本面 三因子策略

    Parameters:
    -----------
    universe_df: 全部股票行情数据 (date, ts_code, close, volume, ma20)
    north_df: 北向资金数据 (date, ts_code, north_hold_value, north_net_flow)  
    fundamental_df: 基本面数据 (ts_code, roe, debt_ratio, net_profit_yoy)

    Returns: 推荐买入的股票列表
    """
    import pandas as pd

    # Step 1: 北向筛选 — 持仓增加 + 净流入为正
    north_filter = north_df.groupby('ts_code').apply(
        lambda x: (
            x['north_hold_value'].iloc[-1] > x['north_hold_value'].iloc[-5]  # 5日持仓增加
            and x['north_net_flow'].rolling(5).sum().iloc[-1] > 0  # 5日净流入为正
            and x['north_hold_value'].iloc[-1] > 10000  # 持仓 > 1亿
        )
    )
    north_stocks = north_filter[north_filter].index.tolist()

    # Step 2: 技术面过滤 — 站上 20 日线 + 放量
    tech_filter = universe_df[universe_df['ts_code'].isin(north_stocks)]
    tech_filter = tech_filter[
        (tech_filter['close'] > tech_filter['ma20']) &  # 站上 20 日线
        (tech_filter['volume'] > tech_filter['volume'].rolling(20).mean() * 1.2)  # 放量 20%
    ]
    tech_stocks = tech_filter['ts_code'].unique().tolist()

    # Step 3: 基本面过滤
    final_stocks = fundamental_df[
        (fundamental_df['ts_code'].isin(tech_stocks)) &
        (fundamental_df['roe'] > 15) &  # ROE > 15%
        (fundamental_df['debt_ratio'] < 60) &  # 负债率 < 60%
        (fundamental_df['net_profit_yoy'] > 0)  # 净利润正增长
    ]['ts_code'].tolist()

    return final_stocks

3.3 案例三：主力资金拆单检测改进

def detect_iceberg_orders(tick_data, threshold=0.7):
    """
    简化版拆单检测

    原理：如果某个价格水平上，小单成交占比异常高（>70%），
    且该价格是主动买入方向，可能是机构拆单行为

    tick_data: Level-2 逐笔数据
    threshold: 小单占比阈值
    """
    # 按价格聚合
    price_groups = tick_data.groupby('price').agg({
        'volume': 'sum',
        'bs_flag': lambda x: (x == 'B').sum() / len(x)  # 买入占比
    }).rename(columns={'bs_flag': 'buy_ratio'})

    # 计算小单占比
    small_orders = tick_data[tick_data['volume'] < tick_data['volume'].quantile(0.3)]
    small_ratio = small_orders.groupby('price')['volume'].sum() / price_groups['volume']

    # 标记疑似拆单
    price_groups['iceberg_score'] = 0
    price_groups.loc[
        (small_ratio > threshold) & (price_groups['buy_ratio'] > 0.6),
        'iceberg_score'
    ] = 1

    return price_groups[price_groups['iceberg_score'] == 1]

四、实践启发

4.1 对 ths-auto-trader 项目的直接启示

  1. 数据源选择：推荐 AKShare（完全免费）+ Tushare（需积分但更稳定）双源备份
  2. 因子实现优先级：
  3. P0: FlowStability（最简单，直接用日度净流入数据计算）
  4. P1: AvgHoldValue（需要持仓数据，Tushare 有）
  5. P2: FlowToPricePeak / FlowToVolumePeak（计算复杂，但信息量大）
  6. 策略定位：北向因子作为辅助信号（30% 权重），不作为主策略
  7. 回测框架：现有的 BacktestEngine 完全可以支持，只需扩展 data loader

4.2 已知陷阱

  1. 前视偏差（Look-ahead Bias）：北向持股数据 T+1 公布，回测中必须用前一日数据
  2. 幸存者偏差：北向重仓的股票可能退市/被 ST，需要完整的退市股票数据
  3. 数据对齐：不同数据源的日期格式、停牌处理方式不同，容易引入 bug
  4. 过拟合风险：4 因子 + 多种窗口组合 = 大量参数，必须用 Walk-Forward 验证

五、知识缺口与待验证问题

  1. 北向因子在中小盘股的有效性：现有研究主要针对沪深 300，中证 1000 以下缺乏数据
  2. 实时监控可行性：如何在盘中（非收盘后）估算北向资金流向？
  3. ETF 北向数据：北向资金买 ETF 的行为是否有额外 alpha？
  4. 拆单检测的实用性：Level-2 数据付费（>5000元/年），ROI 是否值得？
  5. 行业轮动中的北向因子：东方证券研报提到行业轮动应用，但具体效果未验证
