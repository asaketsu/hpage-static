一、内容整理

1.1 核心问题

LLM 后训练中 RL 已成核心组件（DeepSeek-R1、通用 Agent、coding agent），但存在一个根本性的粒度错配：训练信号是轨迹结束后才揭示的标量结果奖励（outcome reward），而优化更新发生在单个 token 级别。"最终结果应如何归因到轨迹中的 token"——这就是信用分配（credit assignment）问题。此前信用本身缺乏公认的数学刻画，各方法用各自算法相关的量来操作化。

本文两阶段贡献：
- 理论：三个正则条件唯一确定 token 级信用，统一解释 OPD/RLOO/GAE 现象
- 方法：由理论动机推出 PACT（Policy Aligned Critic Training），数学推理 72.87%（超 GRPO 8.80pp），SWE-bench Verified 67.4%

1.2 形式化框架：奖励信息流

轨迹 Y = (q, T₁, O₁, T₂, O₂, …, T_τ, O_τ)，其中 Tᵢ 是策略生成的 token，Oᵢ 是环境返回的观察（工具响应/环境转移/用户反馈）。允许 Oᵢ=∅，此时退化为普通自回归生成。终端奖励 R = R(Y)。

信息流用 σ-代数过滤刻画：F_i = σ(q, T₁, O₁, …, Tᵢ, Oᵢ)，条件奖励预测 V_i = E[R|F_i]。

1.3 三个正则条件与唯一表示定理

  • 完整性（Completeness）：Σ Cᵢ = R − E[R|F₀]，信用之和完全解释最终奖励对初始预测的偏离
  • 前缀一致性（Prefix Consistency）：共享相同前缀的两条轨迹，其累计信用 Sᵢ 必须相等——前缀生成后信用即固定，未来实现不应修改历史信用
  • 中性（Neutrality）：E[Cᵢ | F_{i-1}] = 0，下一 token 的期望信用为零，不系统性高估/低估

定理 1（唯一表示）：满足三条件的 token 级信用唯一存在，且为鞅差序列：Cᵢ = Vᵢ − V_{i-1} = E[R|Fᵢ] − E[R|F_{i-1}]。附录 C.2.3 证明三条件各自必要（去掉任一条都允许其他信用方案）。

推论 1：任意连续分段聚合得粗粒度信用 C^(k) = V_{b_k} − V_{a_k−1}，turn 级归因是特例。

1.4 用唯一表示重新解释现有算法

定理 2（OPD 教师是隐式评论家）：定义理想教师 q*t 为 KL 正则化奖励改进的最优分布 argmax E{a~q}[Q_t^π(a)] − β·KL(q‖p_t)。则理想教师下 OPD 的更新方向 = (1/β) × 唯一信用诱导的策略梯度。教师通过 KL 目标提供信用，无需显式价值头。

定理 3（RLOO 梯度无偏）：RLOO 的响应级信号 (Rᵢ − R̄_{-i}) 虽是粗粒度，但期望下与 token 级信用诱导的梯度贡献相等。但仅期望相等≠统计效率相等：条件期望 V_t 是 MSE 最优预测器，而 RLOO 基线保留有限结果的随机性，长程场景波动可能淹没局部信用信号。

定理 4（近似信用稀疏性）：R∈[0,1] 时 E[Σ Cᵢ² | F₀] = Var(R|F₀) ≤ 1/4，超过 ε 的信用个数期望 ≤ 1/(4ε²)，与响应长度无关。长程生成中绝大多数 token 的信用极小。

GAE 误差分解（本文最实用的分析）：设评论家误差 V̂ᵢ = Vᵢ + εᵢ，TD 残差 δ̂ᵢ = Cᵢ + εᵢ − ε_{i-1}，则 GAE 优势：

Â_t^λ = Σᵢ λ^(i-t)·Cᵢ  −  ε_{t-1}  +  (1−λ)·Σᵢ λ^(i-t)·εᵢ
        └── 真实信用累积 ──┘  └前缀误差┘  └── 中间评论家误差泄漏 ──┘
  • λ<1 时中间评论家误差通过最后一项保留；由定理 4，真实信用信号很小 → 误差项可与真信号同量级甚至占主导
  • λ=1 时中间误差项消失：Â_t¹ = R − V̂_{t-1}，只剩前缀误差
  • 这解释了 DeepSeek-R1 报告 PPO λ=1 优于 λ=0.95，以及 SAO 的长度自适应 λ→1 设计
  • 实验佐证：本文 PPO(λ=0.95) 直接训练崩溃（26.31%，低于基模 41.01%），PPO(λ=1.0) 恢复到 59.71%

1.5 PACT 方法

动机：PPO 式训练存在策略-评论家滞后——D_k ~ π_k 上计算优势的评论家值来自 π_{k-1} 训练的参数，评论家永远落后一个策略更新。当信用靠相邻条件值差分得到时，这个滞后尤其致命。

两大组件：

  • 概率化价值估计（BCE 评论家）：评论家参数化 V̂ = σ(z)，用软 BCE 损失替代 MSE。对 R∈[0,1] 两者最优解相同（都是 V^π），但 BCE 收敛显著更快、正负样本价值分离度 Δ± 更大。呼应 Farebrother et al. 2024 的分类式价值估计
  • 离策略评论家同步（Actor-then-Critic）：每轮迭代先用当前评论家支持 actor 优化；actor 全部更新完成后，对同一 rollout 批做一次额外前向传播，配合更新前记录的 log 概率，得到更新前后策略的重要性比率 I_t；把评论家训练目标从 R 替换为 I_t·R（测度变换：V_{t-1}^π = E_μ[I_t·R|F_{t-1}]），使迭代结束时评论家对齐到已更新的 actor

工程细节：精确续接比率方差高，实践中用 detached 当前 token 重要性比率作代理，屏蔽比率超出 [ρ_min, ρ_max]=[0,6] 的 token 级评论家损失。只需一次额外前向传播，零额外 rollout，开销极低。

1.6 关键实验结果

数学推理（Qwen3.5-4B，DAPO-Math-17k 子集 3200 题，优先选初始策略 pass@1 失败的题；OpenCode agentic harness；Dressage 框架；每轮 512 轨迹；上下文 128k；Avg@16 准确率）：

  • Base：41.01%
  • GRPO(ε_high=0.28)：64.07%
  • PPO(λ=0.95)：26.31%（训练崩溃）
  • PPO(λ=1.0)：59.71%
  • SAO：51.14%
  • PACT 去掉 IS 修正：67.74%
  • PACT：72.87%（AIME 2025 83.12 / AIME 2026 85.21 / BeyondAIME 51.69 / HMMT Nov. 2025 71.46）

Agentic 编码（Qwen3.6-35B-A3B，OpenSWE 环境，Codex agent + Harbor 框架，终端验证器奖励）SWE-bench Verified：

  • Base 60.8% / GRPO 65.4% / PPO(λ=1) 65.0% / SAO 63.6% / PACT 67.4%

消融：
- BCE vs MSE 评论家（固定 rollout 策略对照）：BCE 在两种模型规模上都同时取得更低 BCE+MSE 损失和更大价值分离
- 重要性采样修正：+5.13pp（67.74→72.87），四个基准全部提升，训练奖励曲线更稳定

1.7 局限性（作者自述，附录 F）

  • 唯一性条件于三个正则条件——如同更换欧氏平行公理得到不同几何，换条件可能得到不同表示
  • 信用是统计性的而非因果性的：基于条件期望，不刻画替换单个 token 的反事实因果效应
  • 只刻画"信用应该是什么"，未解决实践中如何精确估计——高效估计器留作未来工作

二、查询拓展

2.1 GAE（Generalized Advantage Estimation）

Schulman 2015 提出的优势估计器，用 λ 指数加权 TD 残差在偏差（λ=0 即 TD(0)，依赖评论家）与方差（λ=1 即 Monte Carlo，依赖采样）间插值。传统 RL 观点认为 λ=0.95 是稳妥折中；本文的误差分解给出相反结论：当奖励只有终端信号且信用天然稀疏时，中间评论家误差是主要污染源，λ=1 反而更优——因为此时"方差"其实来自有限 rollout 的奖励随机性，而非信用本身。

2.2 RLOO 与 GRPO

RLOO（Ahmadian 2024）：同 prompt 采 G 条轨迹，用其余 G−1 条的平均奖励作 leave-one-out 基线，回归 REINFORCE 路线，避免训练价值模型。GRPO（DeepSeekMath）：组内归一化优势 + PPO 式裁剪，是当前 LLM 后训练主流。本文定理 3 为这类"免评论家"方法提供了理论合法性（期望梯度等价），同时指出其统计效率上限（响应级随机性）。

2.3 On-Policy Distillation（OPD）

Lu 2025：在学生自采样轨迹上用教师的 token 级密集监督训练，已被代数化重构为 KL 约束的密集 RL（师生 log 密度比充当 token 级优势）。本文补上信用层面的缺口：理想教师（KL 正则化奖励改进者）诱导的梯度恰好正比于唯一信用诱导的梯度——教师就是不带价值头的评论家。

2.4 鞅差序列（Martingale Difference Sequence）

公平博弈的数学模型：E[Cᵢ|F_{i-1}]=0 意味着在当前信息下无法预测下一步信用。定理 1 表明唯一信用天然是鞅差——这与量化金融中"价格是鞅、信息即时反映"的框架同构，Vᵢ 扮演条件期望价格，Cᵢ 是新信息冲击（innovation）。

2.5 分类式价值估计

Farebrother et al. 2024（HL-Gauss 等）：把回归目标离散化/二值化后用交叉熵训练，在 Atari/DMLab 上优于 MSE 回归。本文软 BCE 版本保留 [0,1] 连续语义（sigmoid 输出），论证最优解不变但优化景观更友好。

3.2 方法对比要点

  • vs PPO：核心差异是更新顺序依赖关系。PPO 中 actor/critic 相互独立更新、评论家滞后一个策略；PACT 串行化（actor 完成后用 IS 修正目标训练评论家），额外成本仅一次前向传播
  • vs GRPO/RLOO：保留评论家但让它"跟得上"，换取细粒度信心的统计效率；GRPO 省评论家但受响应级噪声限制
  • vs SAO：SAO 靠长度自适应 λ 逼近 1 来缓解同一问题；PACT 直接 λ=1 并从源头（对齐 + BCE）提升评论家质量

四、趋势判断

趋势1：LLM RL 的"理论补课"阶段到来

依据：信用分配这类基础概念正被逐步公理化（本文三条件唯一性、此前 RUDDER/VinePPO/RLOO 各自的构造）。类似 2018-2020 年 RLHF 理论化浪潮，agentic RL 的成功实践正在倒逼数学根基重建。预计 12 个月内会出现更多"表示定理→算法改进"的论文范式。

趋势2：λ=1 / 免中间评论家将成为 LLM 长程训练默认

依据：DeepSeek-R1 实证 + SAO 长度自适应 + 本文 GAE 分解三方汇聚。当奖励是稀疏终端信号时，传统 RL 的偏差-方差直觉（偏好 λ<1）不成立，中间评论家误差是主要污染源。

趋势3：Actor-Critic 在 LLM RL 中复活，但形态改变

依据：纯组基线方法（GRPO 系）统治两年后，PACT 显示"对齐良好的评论家"仍有 8.8pp 空间。趋势不是回到老 PPO，而是带同步机制的新型评论家（IS 修正、分类目标、概率化输出）。

趋势4：agentic（含工具观察 Oᵢ）与纯生成 RL 理论统一

依据：本文框架原生支持 Oᵢ≠∅ 的交互轨迹，SWE-bench 实验验证理论在 agentic 场景成立。为后续 harness-aware RL（如 OpenForgeRL 路线）提供了统一的信用语言。

五、关联分析

5.1 与 ReGRPO 精读笔记的关联

ReGRPO（2606.31392，2026-07-02 笔记）用结构化反思 schema 改进 GRPO 的信号质量；本文从理论侧解释了为什么 GRPO 的组基线"能用但有上限"（期望等价但统计效率受限）。两者互补：ReGRPO 改奖励端，PACT 改价值估计端。

5.2 与 LongStraw 精读笔记的关联

LongStraw（2607.14952）的 GRPO 逐分支回放是时间换空间；本文 PACT 的 IS 修正目标 I_t·R 本质也是"用旧分布样本训练新策略下的价值"——同一个测度变换工具，一个用在轨迹回放，一个用在评论家目标。

5.3 与 microduck/RSL-RL 训练管线的关联（Jetson/机器人）

DP5/H1 等双足 RL 训练用 rsl_rl 的 GAE。机器人奖励多为密集塑形（存活 bonus、速度跟踪），信用不稀疏，λ=0.95 仍合理；但技能级稀疏终端奖励（如"站稳 10 秒"二值成功）训练变体应直接 λ=1，本文给出了理论依据。BCE 评论家技巧（奖励归一化到 [0,1] 后 sigmoid + 软 BCE）可作为 FastSAC/FastTD3 价值头的低成本实验项。

5.4 与量化交易的关联

鞅差框架与 Ornstein-Uhlenbeck 过程估计同属条件期望/信息流语言：Cᵢ 对应价格新息（innovation），Vᵢ 对应条件公允价。LLM 因子挖掘工作流（GRPO 式组相对奖励）可借鉴定理 3 的警示——响应级基线的统计效率上限，因子评估时应对单因子做组内多采样以压噪声。

六、金句摘录

「Credit assignment therefore requires an additional characterization beyond the Markov formulation.」— 马尔可夫性只保证信息流的概率结构，不回答"功劳怎么分"。

「Just as replacing Euclid's parallel postulate leads to different but internally consistent geometries, adopting different requirements for credit may lead to different representations.」— 理论谦逊的范本：唯一性是条件化的。

「the critic error term can become comparable to, or even dominate, the true credit signal」— 长程稀疏奖励下 GAE λ<1 的死因诊断。

七、拓展应用推荐

7.1 对 Hermes Agent 生态

  • P1 · 借鉴点：Agent 轨迹的信用可视化诊断
    Hermes 的 cron 任务/多步工具调用轨迹是天然的 (q, T, O) 序列。可离线计算 Vᵢ 代理（如用结果奖励回归每步状态特征），画出信用鞅差分布，定位"哪个工具调用环节贡献了成败"。工作量：中等（需轨迹记录 + 轻量回归）。已有 trajectory recording 中间件构想（OpenForgeRL 笔记 P0）可顺带支撑。

  • P2 · 借鉴点：子任务委派的 RLOO 式评估
    delegate_task 多候选执行时，leave-one-out 组基线做相对评价在期望上等价于细粒度信用——为现有的 Best Effort 委派质量评估提供理论兜底。

7.2 对 RL 训练管线（microduck / DP5 / H 系列）

  • P0 · 可直接移植：稀疏终端奖励变体切 λ=1
    rsl_rl 的 GAE lambda 配置一行改动。适用判定：奖励以二值成功/失败为主、塑形项弱的训练变体。配合本文的崩溃案例（PPO λ=0.95 直接 26%），建议站桩/行走类稀疏奖励变体优先实验。

  • P1 · 可实验：BCE 价值头
    奖励归一化 [0,1] → critic 输出过 sigmoid → 软 BCE。改 rsl_rl 的 value loss 约 20 行。预期收益：critic 收敛加速、正负轨迹价值分离更大（更快出现判别性 reward shaping 信号）。

  • P2 · 需工程改造：Actor-then-Critic 同步
    需要训练循环支持"actor 更新后回扫 rollout 批做一次前向 + IS 比率屏蔽"，rsl_rl 需改 minibatch 循环结构，工作量较大，收益上限 +5pp 级（论文消融 5.13pp）。

7.3 对量化研究

  • P2 · 方法借鉴：组内多采样压基线噪声
    LLM 因子/策略生成评估时，同 prompt 多 rollout（G≥8）+ RLOO 基线，而非单次采样打分。理论依据：定理 3 期望等价 + 方差分析。

八、指南分析

（作为日后动手时的操作指南浓缩）

  1. 何时该用本文结论：训练信号是终端稀疏奖励（数学对错、任务成败、SWE 通过与否）且响应/轨迹长（>数千 token 或多轮工具交互）
  2. λ 选择决策树：奖励密集塑形 → 维持 λ≈0.95；奖励二值终端 → 直接 λ=1，并监控是否出现本文所述 λ<1 崩溃
  3. PACT 复现要点：λ=1；critic 用 sigmoid+软BCE；actor 更新全部完成后单次前向回扫取 detached 当前 token IS 比率；屏蔽 [0,6] 区间外比率；actor 侧保持 DIS 裁剪（数学 [0.7,6.0] / 编码用 PPO clip）
  4. 评估纪律：数学类用 Avg@16 + 无污染基准（AIME/HMMT 当季、BeyondAIME）；编码类 SWE-bench Verified；必须含 PPO(λ=0.95) 崩溃对照以验证误差分解主张
  5. 阅读优先级建议：定理 4 + GAE 分解（3.3 节）> PACT 方法（4 节）> 唯一表示（2 节）； proofs 在附录 C，必要性证明（C.2.3）对理解三条件最有帮助
