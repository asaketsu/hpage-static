## xdotool 容错模式
- 7类异常：窗口焦点丢失/控件偏移/网络超时/涨跌停/余额不足/客户端崩溃/非交易时段
- 重试：指数退避 2s*N，最多 3 次
- 适用：所有 xdotool GUI 自动化场景

## 多数据源热备模式
- 优先级排序（tushare > akshare > 缓存），逐级降级
- 校验：非空 + 无全空行 + 数值范围合理
- 适用：所有外部 API 调用场景

## Jetson Orin 量化交易约束
- easytrader 不可用（Windows only），xdotool 是唯一 GUI 方案
- THS 有 Linux 客户端但功能受限
- numpy/pandas ARM64 性能略低
- 推荐 AKShare（纯 Python）+ tushare 双源
- QMT 需 Windows VM 或远程 API 桥接
