# akshare/tushare 数据源稳定性对比

> 探索级别: L2 (技术调研)
> 探索时间: 2026-05-19
> 来源: web_search + 文档分析

---

## 核心对比

| 维度 | Tushare | AKShare |
|------|---------|---------|
| **数据源** | 官方 API (RESTful) | 网页爬虫聚合 |
| **稳定性** | ⭐⭐⭐⭐ 高 (企业级) | ⭐⭐ 依赖上游网站 |
| **成本** | 积分制 (部分免费) | 完全免费 |
| **响应速度** | 快 | 取决于反爬策略 |
| **错误率** | 低 | 较高 (接口失效风险) |
| **适用场景** | 企业/高频/生产环境 | 个人研究/教学/原型 |

---

## 关键发现

### Tushare 优势
1. **API 稳定性高** — RESTful 接口统一，响应速度快，错误率低
2. **数据质量规范** — 数据清洗完善，适合企业级应用
3. **社区活跃** — 文档完善，问题响应快
4. **适合生产环境** — 高频交易系统、金融建模首选

### Tushare 劣势
1. **积分门槛** — 高级接口需要积分 (5000+)
2. **成本问题** — 部分数据需付费

### AKShare 优势
1. **完全免费** — 无需注册，开箱即用
2. **数据源广** — 覆盖多市场与另类数据
3. **灵活性高** — 适合快速原型验证

### AKShare 劣势
1. **稳定性风险** — 依赖上游网站，字段变更导致接口失效
2. **IP 限制** — 频繁调用可能被限
3. **维护成本高** — 需频繁更新以适应网站结构变化
4. **不适合实盘** — 延迟和断供风险不可接受

## 对 ths-auto-trader 的启示

### 推荐方案
| 场景 | 推荐数据源 |
|------|-----------|
| 策略回测 | Tushare Pro (数据质量高) |
| 实时行情 | 券商 API (QMT/同花顺) |
| 研究原型 | AKShare (免费快速) |
| 生产环境 | Tushare + 本地缓存 |

### 最佳实践
1. **双数据源备份** — Tushare 为主，AKShare 为辅
2. **本地缓存机制** — 避免重复调用，降低断供风险
3. **异常处理** — 接口失效时自动切换备用源
4. **定期更新** — AKShare 需保持最新版本
