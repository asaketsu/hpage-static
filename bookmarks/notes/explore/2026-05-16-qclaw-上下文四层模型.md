# QClaw 上下文四层模型

## 概念
QClaw（Hermes Agent）的上下文管理采用4层模型：

| 层级 | 名称 | 特点 | 示例 |
|------|------|------|------|
| L1 | System Prompt | 不变，启动时加载 | 人格、规则、Skill列表 |
| L2 | Tool Output | 动态，需压缩 | 文件内容、搜索结果 |
| L3 | Skill Context | 按需加载 | SKILL.md、模板文件 |
| L4 | External RAG | 检索注入 | Obsidian Vault、项目文档 |

## 覆盖度评估
用此框架评估上下文是否覆盖当前任务所需知识。缺失层 → 需要额外检索或加载。
