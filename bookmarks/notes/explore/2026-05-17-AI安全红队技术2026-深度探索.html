核心发现

1. AI 系统攻击面扩展

攻击面 描述 风险等级
Prompt Injection 通过恶意提示绕过安全限制 🔴 高
Jailbreak Attacks 诱导模型输出禁止内容 🔴 高
Data Poisoning 训练数据被污染 🟠 中高
Model Extraction 窃取模型参数/权重 🟠 中
Supply Chain 第三方模型/插件漏洞 🟠 中
Agent Hijacking 劫持 AI Agent 执行恶意操作 🔴 高

2. 2026 年红队技术演进

Prompt Injection 新变种

  • 多模态注入：通过图像/音频触发恶意行为
  • 间接注入：通过检索增强（RAG）注入恶意上下文
  • 越狱链式攻击：多轮对话逐步突破安全边界

Agent 系统攻击

  • 工具调用劫持：诱导 Agent 调用危险工具
  • 上下文污染：在对话历史中注入恶意指令
  • 技能滥用：利用高权限技能执行越权操作

3. 防御策略矩阵

攻击类型 防御方案 成熟度
Prompt Injection 输入过滤 + 输出验证 ✅ 成熟
Jailbreak 安全对齐 + 红队测试 ✅ 成熟
Agent Hijacking 权限分级 + 审计日志 ⚠️ 发展中
Data Poisoning 数据验证 + 模型监控 ⚠️ 发展中
