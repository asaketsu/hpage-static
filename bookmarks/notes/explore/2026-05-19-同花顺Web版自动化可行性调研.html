同花顺 Web 版自动化可行性调研

级别: L2 (技术调研)
探索时间: 2026-05-19
主题: 同花顺 Web 版自动化可行性 — Playwright/Puppeteer 替代方案评估

背景

当前同花顺自动化交易主要依赖 Windows 客户端 + xdotool GUI 自动化，在 Linux 环境下存在以下痛点：
- Windows 客户端依赖 Xvfb 虚拟帧缓冲，稳定性差
- xdotool 坐标定位在分辨率/DPI 变化时失效
- 无法跨平台部署

核心问题: 同花顺是否提供 Web 版交易界面？能否用 Playwright/Puppeteer 替代 GUI 自动化？

调研发现

1. 同花顺 Web 版现状

同花顺官网 (https://www.10jqka.com.cn) 提供：
- ✅ 行情浏览: 实时行情、自选股、资讯
- ✅ i问财: AI 金融搜索引擎（自然语言选股）
- ✅ 登录入口: 支持手机号/账号/微信扫码
- ⚠️ 交易功能: 需选择开户券商，输入资金账号 + 交易密码

关键发现:
- 同花顺 Web 版主要提供行情和资讯服务
- 交易委托需要跳转到券商的交易系统
- 同花顺本身不提供完整的 Web 交易界面，而是作为行情信息聚合平台

2. Web 版交易流程

根据官方 FAQ 和网页内容：
1. 访问 https://www.10jqka.com.cn
2. 点击「交易」板块
3. 选择开户对应的券商
4. 输入券商资金账号、交易密码
5. 进入券商的交易系统（非同花顺原生）

结论: 同花顺 Web 版交易实际上是跳转到券商系统，不同券商的交易界面差异极大，无法统一自动化。

3. Playwright/Puppeteer 适用性分析

场景 Playwright Puppeteer 可行性
同花顺 Web 行情 ✅ 支持 ✅ 支持 高
i问财数据抓取 ✅ 支持 ✅ 支持 高（已有 pywencai）
券商 Web 交易 ⚠️ 各券商差异大 ⚠️ 各券商差异大 低
跨券商统一自动化 ❌ 不可行 ❌ 不可行 不可行

Playwright vs Puppeteer:
- Playwright: 支持多浏览器（Chromium/Firefox/WebKit），API 更现代，适合复杂场景
- Puppeteer: Chrome/Chromium 专用，更轻量，适合简单场景
- 推荐: Playwright（更稳定、跨浏览器）

4. 替代方案对比

方案 优点 缺点 推荐度
easytrader 成熟稳定，支持多券商 依赖 Windows 客户端 ⭐⭐⭐⭐
QMT/xtquant 官方 API，稳定可靠 资金门槛 30-50 万 ⭐⭐⭐⭐⭐
Playwright Web 跨平台，无需客户端 各券商界面差异大 ⭐⭐
Puppeteer Web 轻量 同上 ⭐⭐
xdotool GUI 通用 稳定性差，仅限 Linux ⭐

核心结论

❌ 同花顺 Web 版自动化不可行

原因:
1. 同花顺 Web 版不提供完整交易功能，交易需跳转到券商系统
2. 各券商 Web 交易界面差异极大，无法统一自动化
3. 券商系统通常有反自动化机制（验证码、设备指纹、行为检测）
4. Web 自动化在安全性和合规性上存在风险

✅ 推荐方案

阶段 推荐方案 说明
短期 easytrader 继续用 Windows 客户端 + 自动化
中期 QMT (xtquant) 资金达标后申请官方 API
长期 PTrade 机构级通道，延迟更低

🔄 过渡方案

如果必须在 Linux 环境运行：
1. Wine + 同花顺客户端: 尝试用 Wine 运行 Windows 客户端
2. 远程桌面: 用 Windows 虚拟机 + RDP/VNC
3. 云主机: 在云服务器部署 Windows + 客户端

技术参考

Playwright 基础示例

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()

    # 访问同花顺官网
    page.goto("https://www.10jqka.com.cn")

    # i问财搜索
    page.fill("#search-input", "今日涨停的股票")
    page.click("#search-button")

    # 获取结果
    results = page.text_content(".search-result")
    print(results)

    browser.close()
