## 1. 同花顺（THS）平台概览

同花顺（Hithink RoyalFlush, 300033.SZ）是中国最大零售交易终端之一，服务数千万散户，为几乎所有主流券商提供行情与交易接入。

**核心定位**：THS 本身不是券商，而是**前端交易终端**，通过用户已有券商账户路由订单。

---

## 2. THS 量化交易基础设施

### 2.1 iFinD 金融数据接口

| 能力 | 说明 |
|------|------|
| 覆盖范围 | A股/债券/期货/期权/基金实时+历史数据 |
| 基本面 | 财报、公司行为、供应链 |
| 另类数据 | 卫星、Web流量、舆情 |
| SDK | Python / C++ / C# / Java / Excel |
| 实时推送 | WebSocket tick 级别 |
| 批量查询 | RESTful HTTP |
| 定价 | 机构级年费，高校/研究有折扣 |

### 2.2 量化交易终端

THS 提供专用量化终端（量化版），功能包括：
- **回测引擎**：分钟级/tick级数据
- **可视化策略构建**：拖拽式
- **Python 策略脚本环境**
- **模拟交易**（Paper Trading）
- **直连券商下单**
- **风控模块**：仓位限制、止损、回撤控制

## 3. 自动化交易方案

### 3.1 官方半自动化（条件单/智能交易）

- **条件单**：价格/量/技术指标触发订单
- **网格交易**：内置区间网格
- **智能盯盘**：监控+提醒
- **自动打新**：IPO 自动申购

> 局限：半自动，全量化需额外工具

### 3.2 开源自动化方案

#### easytrader（shidenggui）
- **架构**：Python → THS 客户端 GUI 自动化（pywinauto/pyautogui）→ 券商下单
- **API**：`user.buy(security, price, amount)` / `user.sell(...)`
- **支持**：THS / 华泰客户端等
- **局限**：GUI 依赖、脆弱（UI 更新易 break）、延迟高

#### vnpy
- 完整 Python 交易框架，CTP 支持为主
- 可接入 THS 数据源

#### 其他框架
- **backtrader** / **zipline-reloaded** / **rqalpha**

### 3.3 数据获取方案

| 工具 | 说明 |
|------|------|
| pytdx | 通达信协议逆向，实时数据 |
| tushare / akshare | 开源数据库，部分含 THS 数据源 |
| iFinD SDK | 机构级，付费 |
| 东财/THS 免费 API | 有限、有延迟 |

## 4. 技术挑战

| 挑战 | 详情 |
|------|------|
| **GUI 依赖** | 零售自动化依赖 Windows 客户端 GUI，脆弱且慢 |
| **API 门槛** | iFinD 昂贵，散户无编程接口 |
| **延迟** | GUI 自动化引入 200ms-2s 延迟，不适合高频 |
| **合规** | 中国监管限制散户全自动化交易 |
| **稳定性** | THS 客户端频繁更新导致脚本失效 |
| **数据质量** | 免费源有缺口/延迟，tick级需付费 |

## 5. 近期趋势（2024-2025）

1. **AI 功能扩展**：智能选股、自然语言策略查询
2. **Web 量化平台**：quant.10jqka.com.cn，浏览器端回测+部署
3. **ML 集成**：因子库、特征工程、模型训练管线
4. **移动端**：有限但增长的算法功能
5. **监管收紧**：2023 新证券法后算法交易监管加强

## 6. 实践启发

### 对量化开发者的建议
1. **数据优先**：先解决数据源（推荐 akshare 免费入门 → tushare pro → iFinD 机构级）
2. **回测验证**：利用 THS 量化平台或 backtrader 做严格回测
3. **自动化方案选择**：
   - 入门：easytrader + THS 客户端（Windows）
   - 进阶：vnpy + 券商 API（需申请）
   - 机构：iFinD + 自研系统
4. **合规意识**：确保策略不触碰监管红线（如频繁撤单、闪电崩盘类策略）
