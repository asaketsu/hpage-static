# MHA2MLA：将任意 Transformer LLM 迁移到 DeepSeek MLA 架构

> 来源：复旦 NLP 实验室 (arXiv:2502.14837, ACL 2025) | [GitHub](https://github.com/JT-Ushio/MHA2MLA)
> 日期：2026-08-02

## 摘要

MHA2MLA 是首个数据高效的微调框架，能将基于 MHA/GQA 架构的预训练 LLM（如 Llama）迁移到 DeepSeek 提出的 MLA（Multi-Head Latent Attention）架构，无需从头预训练。仅用 0.3%~0.6% 预训练数据即可恢复性能，KV cache 压缩率最高达 97%。

## 关键发现

**核心痛点**：MHA/GQA 模型的 KV cache 随序列长度线性增长，推理时访存瓶颈严重。MLA 通过低秩 KV 联合压缩大幅降低 cache 大小，但已有模型无法直接用 MLA 推理（架构不兼容），从头训练成本极高。

**两大技术创新**：
- Partial-RoPE（部分旋转位置编码）：MLA 需要将位置相关维度（保留 RoPE）和位置无关维度（NoPE，可压缩）分离。MHA2MLA 提出 S₂-范数策略，按每个 2D 旋转子空间对注意力分数的平均贡献排序，移除贡献低的维度，保留关键位置信息
- Joint SVD（联合奇异值分解）：对拼接后的 Key 和 Value 投影矩阵做联合 SVD 分解，得到低秩压缩矩阵和升维矩阵，中间的 KV 联合低秩表示与 MLA 缓存对象完全对齐

**实验数据（Llama2-7B）**：
- d_kv=16 时压缩率 87.5%，性能仅降 3.0%（优于 2-bit 量化的 6.2% 降幅）
- 结合 4-bit 量化后压缩率 92.19%，LongBench 仅降 0.5%
- 极端配置压缩率 96.87%，性能降 3.2%
- 兼容 KV 量化、剪枝等压缩技术，可叠加使用

**扩展方向**：
- MHA2MLA-VLM：将迁移扩展到视觉语言模型，引入模态自适应 Partial-RoPE，仅需 1.8B tokens 微调
- TransMLA（NeurIPS 2025）：直接将 GQA 模型转为 DeepSeek 代码库兼容格式，LLaMA-2-7B 压缩 93% KV cache，8K 上下文加速 10 倍，仅需 6B tokens 微调

## 对工作的价值

- 边缘部署：Jetson 等显存受限设备上，MLA 可显著减少长上下文推理的 KV cache 占用，与现有量化方案叠加可进一步降本
- 已有模型复用：无需重训即可让 Llama/Qwen 等 GQA 模型获得 MLA 推理加速，降低迁移门槛
- 推理引擎兼容：迁移后的模型可直接使用 vLLM/SGLang 对 DeepSeek 架构的深度优化（FP8 量化、多 token 预测等）

## 行动建议

- 关注 TransMLA，它直接产出 DeepSeek 代码库兼容格式，工程落地更直接
- 在 Jetson 上优先测试小模型（SmolLM-135M/360M）的迁移效果，评估端侧推理收益
- 注意 Partial-RoPE 在超长序列（>100K tokens）场景可能影响部分模型的长文本能力
- 迁移需额外微调步骤，无法零样本直接应用，需评估微调算力成本
