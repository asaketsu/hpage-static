# 本地模型部署：异构混合推理

> 日期：2026-08-22 | 来源：web_search + web_extract（llm-d.ai、SitePoint、AI-Compass 等）

## 摘要

本地模型部署已从实验性走向工程化。2026年的核心趋势是「异构混合推理」：在单一集群中混合使用不同代际、不同厂商的 GPU（NVIDIA/AMD/昇腾），并通过统一路由层（如 llm-d、KTransformers）按工作负载特征调度推理请求。本地推理的 TTFT 可达 15-30ms（vs 云端 100-300ms），日调用量超 1000 万 token 时 12-18 个月即可回本。

## 关键发现

1. **llm-d：跨厂商推理编排层**
   - IBM + Red Hat + NxtGen 联合发布，支持 NVIDIA/AMD/Google TPU 三厂商混合集群
   - 基于 Kubernetes/OpenShift，通过 vLLM Pod + 统一 InferencePool 路由
   - 支持前缀缓存感知路由（precise tokenizer 版 + xxhash 近似版）
   - 实验环境：4+8+8 张异构 GPU，100G RoCE 互联，granite-8B + sarvam-30B MoE
   - 下一步：跨加速器的 Prefill/Decode 拆分——计算密集 prefill 走一厂商、带宽密集 decode 走另一厂商

2. **KTransformers + SGLang 合作：异构推理进入主流**
   - 清华趋境科技的 KTransformers 算子库合入 SGLang，实现 Multi-GPU+CPU 混合推理
   - 场景：GPU 受限但 CPU 富余的本地机器（如我们的 Jetson Orin），原本跑不动的模型获得新路径
   - 将更多 expert 层放在 GPU，CPU 承担辅助推理

3. **vLLM 分离式推理（Disaggregated Prefill/Decode）**
   - vLLM 2025-2026 版本引入 P/D 解耦：prefill 计算密集、decode 内存带宽密集
   - 可针对不同阶段使用不同硬件或调度策略，提升 GPU 利用率
   - 开启方式：`--enable-disaggregated-prefill`

4. **本地推理 vs 云端成本模型（2026）**
   - 日 100 万 token：云端 $600-900，本地 $2500-4000
   - 日 1000 万 token：云端 $6000-9000，本地 $3500-6000
   - 日 1 亿 token：云端 $60000-90000，本地 $8000-15000
   - 断点：日 >1000 万 token 持续使用时，本地在 12-18 月回本

5. **2026 本地部署工具链全景**
   - Ollama：极简入门（底层 llama.cpp）
   - vLLM：云端灵活标杆，支持 P/D 解耦
   - SGLang：高频 Agent 场景，KV 缓存持久化
   - TensorRT-LLM：NVIDIA 极致性能
   - oMLX：Apple Silicon 原生
   - LM Studio 0.4.0：支持 MLX 格式
   - 国产：昇腾（MindIE）、沐曦、寒武纪、摩尔线程、灵境云边缘节点

6. **端侧推理突破**
   - Qualcomm Hexagon NPU 已在手机端跑 7B 级模型
   - 本地可服务请求占比从 2024 年 23% 升至 2026 年 80%+

## 对工作的价值

- **JBot 本地推理优化**：当前用 sensenova 云端模型，若本地 Jetson 部署 7B/8B 量化模型（Qwen/Gemma/Llama），可利用 KTransformers CPU+GPU 混合路径降低对云端依赖
- **异构推理方案**：如果未来同时有 NVIDIA Jetson + AMD/其他算力，llm-d 可作为统一编排层
- **成本优化**：当前 Hermes 日均 token 消耗若接近百万级，本地部署可显著降低长期成本
- **数据合规**：敏感数据不出域，适合 Agent 长期记忆/知识库本地化
