单片机实时控制环（电机/舵机PWM）— 定时器硬PWM、级联环带宽与抖动纪律

生成日期 2026-11-01

摘要

单片机实时控制环的核心不是 PID 公式而是定时纪律：PWM 必须由硬件定时器产生（软件 delay 循环 = CPU 全占 + 中断抖动，多路必乱）；控制环采样率必须比被控对象主时间常数快 5-10 倍（dt ≤ τ/10）；级联环（电流→速度→位置）每层带宽拉开约 5-10 倍。对舵机而言，50Hz/0.5-2.5ms 是 RC 舵机的"通信协议"而非控制环本身——数字舵机内部跑 300Hz+ 独立位置环，外部 PWM 只是设定值传递。这与 DUCK 的"策略输出通道被固件位置环压缩后的有效带宽"洞察直接同构。

关键发现

F1 RC 舵机 PWM 的本质：50Hz 设定值传递，不是控制环

  • 标准信号：周期 20ms（50Hz），高电平 0.5~2.5ms，1.5ms 为中位，对应 -90°~+90° 线性映射
  • 舵机内部是独立闭环：PWM 脉宽 → 与电位器电压比较 → 电压差正负决定电机正反转 → 齿轮带动电位器归零。MCU 发的只是设定值，位置环在舵机里
  • ⚠️ 实测差异大：SG90 各厂克隆可接受脉宽范围不一（有的 0.5-2.5ms 全程，有的 0.7-2.3ms 顶机械限位）。盲发极限脉宽 = 顶死嗡鸣发热
  • ⚠️ 红线：舵机输入脉冲必须 50Hz(±5%) 且不超上限脉宽——过快/过宽的脉冲串会使内部 H 桥 MOSFET 直通（shoot-through），几秒内烧毁

F2 硬件定时器生成 PWM：STM32 参数速算模板

72MHz 主频 → PSC=72-1 → 定时器计数时钟 1MHz（1 count = 1µs）
ARR=20000-1 → PWM 周期 20ms = 50Hz
CCR=500~2500 → 高电平 0.5~2.5ms，分辨率 1µs ≈ 0.09°/count（180° 行程）
公式: Freq = CK_PSC / (PSC+1) / (ARR+1);  Duty = CCR / (ARR+1)
  • 多路舵机：同一定时器不同通道共用计数器（同频率），各通道 CCR 独立设占空比——这是正解
  • 多路中断法（传统 51 单片机）：正脉冲宽度 < 周期 1/8 时，可在 1 周期内分时启动各路上升沿，T0 定脉宽、T1 定 20ms 基准
  • Arduino Servo.h 用 Timer1 时序中断轮转开关脚，上限 12 路（ISR 耗时约束）；更多路用 PCA9685（I2C 16 路，自带振荡器，零 CPU 占用）
  • ESP32 对应件：LEDC / MCPWM 外设（与 10-29 笔记的 esp_driver_ledc/esp_driver_mcpwm 组件直接衔接）

F3 软 PWM 是反模式：抖动即性能

  • digitalWrite(HIGH); delayMicroseconds(1500); ...：CPU 全占、任何中断都引入抖动、多路时序灾难
  • 硬件 PWM 的价值 = 零 CPU 负载 + 零抖动。实测基准：BLDC 位置环每 50µs 更新、抖动 ≤1.2µs，才能把 6000RPM 下转矩纹波压在 2.3% 以内
  • 这解释了为什么 µs 级确定性热环需要裸机 Core（前序笔记 ESP32 Core1 直控范式）：调度器抢占引入的抖动直接转化为转矩纹波/角度抖动

F4 PWM 分辨率决定低速线性度

  • 8-bit（256 档）：24V 电机最小步进 0.094V，低于 0.3V 静摩擦死区无法起步
  • 12-bit（4096 档）：0.0059V/步，可从 0.15V 受控缓升
  • 但分辨率换算力：一个 PMSM 电流观测器从 48µs 涨到 61µs 环时，直接超 50µs deadline → 编码器位置滞后。分辨率与时限的权衡要在实测环时数据上做，不能拍脑袋加位宽

F5 采样率铁律：dt ≤ τ/10

被控对象 τ 推荐 dt 实现方式
温度环 30-300s 1-5s millis() 轮询可接受
流量环 0.5-3s 50-200ms 软定时
电机速度环 10-100ms 1-10ms 必须硬件定时器 ISR，不能 millis()
电流环(FOC) ~ms 级 50-100µs PWM 同步中断 + 硬件采样
  • 慢于 τ/4 = 混叠 + 调参不稳；快于 τ/50 = 浪费 CPU 且 D 项放大传感器噪声
  • 编码器测速：低速用周期测量法（测两个边沿间隔，v = 1/dt），高速用脉冲计数法——固定窗口计数在低速连续返回零

F6 级联环带宽分离：每层 5-10 倍

工业伺服标准拓扑（Yaskawa/Kinetix 同款）:
  内环 电流环 ~10kHz (1-10kHz)   ← PI only（感性负载无需 D）
  中环 速度环 ~2kHz  (100Hz-1kHz) ← P+I
  外环 位置环 ~1kHz  (10-100Hz)   ← P+D
  • 每层输出 = 内层设定值；带宽从内到外递减约一个数量级
  • 投运顺序铁律：先关电流环（小阶跃验证 2 个 PWM 周期内跟踪）→ 再速度环（Kp 加到微振荡后减半，加 Ki 消漂移）→ 最后位置环
  • 对 DUCK 的映射：RL 策略(50Hz, pi5) → 固件位置环(kp_fw=32) → 舵机内部环(300Hz+) 本质就是这个级联——策略层带宽被内层压缩，"有效带宽 = min(各层)"，与 1009 讨论的物理上限判断一致

F7 MCU 上的 PID 实现三件套（防坑）

  • 速度式（增量型）PID：u[n] = u[n-1] + Kp·Δe + Ki·Ts·e + Kd·Δ²e/Ts——天然免设定值突跳的 D-kick，积分饱和被限制在单项内，8-bit MCU 用 Q10 定点实现
  • Derivative on measurement：对测量值而非误差求导，设定值阶跃不再打满执行器——工业控制器默认做法
  • Anti-windup 条件积分：输出饱和且误差同号时本周期不积分。缺了它，长时间顶饱和后第一次释放设定值 = 暴力过冲
  • 低速带死区 + bumpless transfer（进 PID 带前把积分器初始化为当前输出）：|v| < 5% vmax 时开环微调，不强行闭环调节零速度
  • 整定起点：FOPDT 开环阶跃（τ≈80ms, L≈20ms, K≈0.7 → Kp≈6.9, Ti≈40ms, Td≈10ms），Z-N 天然 ~25% 过冲，保守场景 Kp 减半 Ti 加倍

F8 数字舵机的高刷新率陷阱

  • 数字舵机内部 MCU 以 300Hz+ 驱动电机 → 保持力更强、静止功耗更低，但对 PWM 线噪声更敏感（采样更精）
  • 部分数字舵机接受 200-500Hz 输入刷新率（低延迟）：高端件（BMS-127@250Hz）明显更顺滑；廉价 SG90@250Hz = 30 秒内嗡鸣过热——提刷新率前必须查手册或实测
  • 多路同步更新是硬要求：8 路顺序 delay(20) 更新 = 6.25Hz 等效刷新率，运动必顿挫；所有脉宽必须在同一 20ms 窗口内同相发出

对现有工作的价值（对工作的价值）

  • DUCK/STS 舵机链路理解升级：STS3215 总线舵机 = "F6 级联 + 内部环"的串行变体——UART 指令设定值 + 内部位置环，与 RC-PWM 舵机同构。速度寄存器(step/s)本质是给内环设定值做斜率限制，之前校准踩的"速度100负载欠行程"坑 = 内环未 settle 的表现，与 F5 的采样/settle 纪律互证
  • ASC 云台 ESP32 固件：舵机 PWM 直接用 LEDC/MCPWM 硬件外设（F2），禁软 delay；脉宽上限红线（F1 shoot-through）对应限位 EEPROM 铁律——超行程脉宽不仅顶机械限位还可能烧桥
  • 自瞄控制环设计：云台跟踪是位置环套视觉环，视觉帧率(~30-60Hz) < 云台环(<1kHz)，dt ≤ τ/10 给出"云台内环可以跑多快"的定量判据
  • 与本域前序笔记闭环：FreeRTOS 调度笔记的"实时任务" + ESP32 裸机笔记的"µs 级确定性热环"在本主题得到控制论层面的量化依据（抖动→纹波的 50µs/1.2µs/2.3% 基准）

行动建议

  1. ASC 固件若现用软 delay/analogWrite 默认频率，迁移到 LEDC 硬件 PWM + 1µs 分辨率配置（PSC/ARR 速算模板可直接套）
  2. DUCK 台架测试报告里引用级联带宽框架：解释现象时显式区分"策略层带宽/固件位置环带宽/舵机内环带宽"三层，避免把内环饱和误判为策略问题
  3. 任何新舵机（含克隆件）上电前先 0.5ms 步进扫极限脉宽实测机械限位，不信任手册标称（F1 实测差异）

关键风险与盲点

  • 本笔记 PWM 参数以 STM32F103(72MHz)/Arduino Uno(16MHz) 为基准，ESP32 LEDC 时钟树不同但公式同构（来源：官方教程+社区，交叉验证）
  • "50Hz ±5% 红线"来自改装舵机社区实践（德文源），厂商手册未必明说——对正品舵机可能是保守约束（来源级别：社区复现）
  • 级联环带宽具体数值（10kHz/2kHz/1kHz）是工业伺服典型值，小型舵机云台的合理值需按执行器 τ 实测标定

一页速查

  • RC 舵机 PWM：50Hz，0.5-2.5ms，1.5ms 中位；是设定值传递，位置环在舵机内
  • 硬件 PWM 三公式：Freq=CK/(PSC+1)/(ARR+1)；Duty=CCR/(ARR+1)；STM32 经典配置 1MHz 计数 + ARR 20000
  • 采样率：dt ≤ τ/10；电机环必须定时器 ISR；电流环与 PWM 同步
  • 级联：电流(10kHz)→速度(2kHz)→位置(1kHz)，每层 5-10 倍分离，从内向外逐环闭合
  • MCU PID 三件套：速度式 + derivative-on-measurement + 条件积分 anti-windup
  • 红线：不超上限脉宽（shoot-through 烧桥）；廉价舵机不试 >50Hz 刷新；抖动=转矩纹波（50µs/1.2µs/2.3% 基准）
