## 核心问题与研究动机

LLM 部署效率是实际应用的关键瓶颈。现有模型压缩方法存在两大问题：

1. **量化误差的逐层独立优化**：大多数 PTQ 方法在每层独立优化量化误差，忽略了误差在网络中的累积和传播效应，导致全局性能退化
2. **剪枝和量化的分离执行**：传统流水线要么单独应用剪枝或量化，要么按固定顺序串行执行（先剪枝后量化或反之），忽略了两者的非正交耦合关系

研究动机：现有 SoTA 方法（Atom、ResQ、BiLLM、PTQ-1.61 等）在超低比特（1-3 bit）下性能急剧退化，需要一种**端到端联合优化**框架来同时优化剪枝决策和混合精度量化策略。

## 方法论（详细）

### 核心思想：TOGA（Train-Once-Get-All）

框架命名为 **TOGA**，核心理念是一次训练超网络（hypernetwork），同时获得最优的剪枝掩码和混合精度量化分配。

### 三大技术创新

**创新 1 — 全局误差传播最小化的混合精度 PTQ**

- 将 bit-width 分配问题重新表述为**二值掩码优化**问题
- 使用超网络（hypernetwork）在端到端任务损失上直接训练这些二值掩码
- 与传统方法的关键区别：
  - 传统方法：基于 Hessian/梯度/激活统计量的逐层贪心搜索
  - TOGA：直接优化全局 end-to-end loss，自动发现跨层依赖关系
- 量化公式：`F_quant(X, M) = Q_h(X) · M + Q_l(X) · (1-M)`
  - M 为二值掩码，决定每个通道用高精度(Q_h)还是低精度(Q_l)
- 结合 activation-based channel reordering + GPTQ 进一步优化

**创新 2 — 联合优化统一搜索空间**

- 将结构化剪枝决策（P_in, P_out 掩码向量）和混合精度量化策略（M 掩码）放在同一个搜索空间中
- 探索了两种组合顺序：
  - 量化→剪枝：`F_prune(F_quant(W, M), P_in, P_out)`
  - 剪枝→量化：`F_quant(F_prune(W, P_in, P_out), M)`
- 文献表明 prune-then-quantize 序列通常效果更好
- 结合 DISP-LLM 结构化剪枝方法实现联合优化

**创新 3 — 自定义 CUDA Kernel**

- 针对 W4A4 + W8A8 混合精度矩阵乘法开发专用 CUDA kernel
- 实现实际的推理加速，而非仅理论压缩比

### 训练配置

- 单卡 NVIDIA A100 (80GB VRAM)
- 仅量化：2000 步训练
- 联合剪枝+量化：10000 步训练
- batch size = 1，重复 5 次取平均

## 关键实验结果与数据

### 超低比特量化（1-3 bit）

对比 SoTA weight-activation 量化（Llama-2-7B）：

- WikiText-2 困惑度（越低越好）：
  - SpinQuant W3A3: 438.11
  - Atom W(3.2)A(3.2): 12.12
  - ResQ W(3.2)A(3.2): 7.35
  - **TOGA-q W(3.2)A(3.2): 7.30**（最优）
- C4 困惑度：**TOGA-q 6.40** vs Atom 10.34 vs ResQ 6.53
- Zero-shot 平均准确率：**TOGA-q 56.03%** vs ResQ 42.45% vs Atom 38.36%

对比 SoTA weight-only 量化：

- WikiText-2 困惑度降低最高 **59%**（相对 BiLLM）
- C4 困惑度降低最高 **85%**

### 主流混合精度（INT4/INT8）

- 困惑度与 SoTA 竞争方法相当
- 但推理性能显著领先：
  - **2x prefill 加速**（vs FP16）
  - **6.5x 峰值内存降低**（vs FP16）
  - 比 2:4 半结构化稀疏方法额外 **30% 更快 prefill**
  - 额外 **10% 内存节省**

### 联合剪枝+量化

- vs SparseGPT+GPTQ、OBR 等 SoTA 联合方法：困惑度 + 推理性能全面领先

### 测试模型

Llama-3.2-1B, Llama-3.2-3B, Llama-2-7B, Llama-2-13B, Llama-3-8B, Llama-3.1-8B, Mistral-7B-v0.3, Qwen-3-8B

## 创新点分析

1. **全局 vs 局部**：首次将混合精度量化中的 bit-width 分配问题从逐层贪心搜索提升为端到端全局优化，直接在最终任务损失上训练
2. **统一搜索空间**：将剪枝掩码和量化掩码放在同一优化目标下联合搜索，避免了串行管道的累积次优性
3. **实用性**：配套 CUDA kernel 确保压缩后的模型有实际推理加速，不只是纸面上的压缩比
4. **二值掩码重表述**：将 bit-width 分配转化为可微的二值掩码优化，配合超网络实现端到端梯度优化

## 局限性与未来方向

1. **显存瓶颈**：需要将整个 LLM 加载到 GPU 上运行，80GB GPU 只能处理到 32B 参数模型，对 70B+ 模型会 OOM
2. **超网络训练开销**：联合优化需要 10000 步训练，虽然只需一次但仍有计算成本
3. **alpha tensor 显存**：在 α-CROWN+BaB 完整验证模式下，per-neuron alpha tensor 是主要显存瓶颈（而非权重矩阵）
4. **未来方向**：计划采用分布式训练或 offloading 技术来处理超大模型

## 借鉴点

### 🔨 P0 — 混合精度量化策略可移植到 Jetson 部署

- TOGA 的 W4A4 + W8A8 混合精度方案直接适用于 Jetson Orin Nano 的 TensorRT 部署
- 关键通道（如 attention score、FFN 输出中的 salient channels）保留 INT8，其余 INT4
- 可借鉴 channel reordering 策略：按激活幅度排序后分组量化
- 预估工作量：2-3 天实现 TensorRT plugin + 量化管线改造

### 🔨 P1 — 全局误差传播视角用于 Agent 模型压缩

- 当前 Hermes Agent 使用多个 LLM 调用（planning/tool-use/reflection），逐模型独立量化会累积误差
- 借鉴 TOGA 思路：将整个 Agent pipeline 的端到端成功率作为优化目标，而非逐个模型独立量化
- 预估工作量：5-7 天设计实验框架

### ✅ P2 — 二值掩码优化方法已部分覆盖

- 现有 GGUF 量化技能已覆盖基础量化场景
- TOGA 的超网络方法可作为增量改进，在更高压缩比需求时启用

### ❌ P3 — 自定义 CUDA kernel 暂不适用

- Jetson Orin 的 CUDA 架构与 A100 不同，混合精度 kernel 需重写
- 当前 TensorRT 已提供较好的混合精度支持，自定义 kernel ROI 不高
