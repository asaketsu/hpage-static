## 摘要

arXiv 综述（2501.02189v7）将 VLM 演进划分为五个纪元：Era 1 对比式双塔（CLIP/BLIP）→ Era 2 投影器式 LLM 骨干（LLaVA/Qwen2-VL）→ Era 3a 原生多模态输入（Gemini 3.6/Claude Opus 4.6/Qwen3.8-Max）→ Era 3b 统一多模态输入输出（Emu3/Janus-Pro）→ Era 4 世界-动作模型（Cosmos 3/Kairos）。2026 年前沿从"给 LLM 接视觉编码器"彻底转向"预训练单一多模态主干"，GRPO 系后训练成为多模态推理对齐的事实标准，但 modality gap（模态鸿沟）经 CrossMath 和 BabyVision 实测**不随规模收敛**。

## 一、五纪元架构演进（关键发现 1）

```
Era 1: 对比式双塔        Era 2: 投影器式骨干     Era 3a: 原生多模态输入
 CLIP / BLIP              LLaVA / Qwen2-VL        Gemini 3.6 / Claude 4.6
 ┌─────┐  ┌─────┐        ┌─────┐  ┌──────┐      ┌──────────────┐
 │ IMG │──│ TXT │        │ ViT │→│ Proj │→LLM   │  单一多模态   │
 │ Enc │  │ Enc │        └─────┘ └──────┘      │   Trunk      │
 └──┬──┘  └──┬──┘           ↑                    │ (img+txt+vid)│
    └──对比──┘           视觉为辅，文本为核心     └──────────────┘
                                            ↑
               Era 3b: 统一输入输出          │  Era 4: 世界-动作模型
               Emu3 / Janus-Pro             │  Cosmos 3 / Kairos
               ┌──────────────┐            │  ┌──────────────┐
               │ 理解+生成共享 │            └──│ 感知+生成+决策 │
               │  同一 Trunk   │               │  闭环预测动作  │
               └──────────────┘               └──────────────┘
```

五个纪元的核心变化不是"新组件"的发明，而是**融合位置和输出范围的变化**：

- **融合位置上移**：从外部投影器对齐（Era 2）→ 预训练阶段共享 token 空间（Era 3a）
- **输出范围扩展**：从纯文本输出（Era 2/3a）→ 多模态生成（Era 3b）→ 动作预测（Era 4）
- **模态角色转变**：视觉从"辅助通道"变为"与文本平权的表示空间"

## 二、2026 前沿家族格局（关键发现 2）

当前前沿已从"独立单点发布"变为"少数实验室的多模态家族快速迭代"：

- **闭源前沿**：GPT-5.6 Sol（OpenAI）、Gemini 3.6 Flash（Google，1M 上下文）、Claude Opus 4.6（Anthropic）、Grok 4.5（xAI，~1.5T 参数 500K 上下文）
- **开源前沿**：Qwen3.8-Max（2.4T/95B active）、Qwen3.6-27B（27B dense，1M 上下文，SWE-bench 77.2 超越 397B 前代）、Kimi K3（2.8T/104B active，1M 上下文）、MiniMax M3（428B/23B active）
- **特殊定位**：GLM-5V-Turbo（智谱，vision-to-code 专用，CogViT + MTP 多 token 预测，200K 上下文）、Claude Mythos（Anthropic 首次以安全为由 gated preview，仅 ~50 合作方可用）

> Qwen3.6-27B 的关键突破：27B dense 模型在 SWE-bench Verified 上超越 397B-A17B MoE 前代，引入"preserved thinking"标志跨多轮 agent 任务保持推理上下文。**密度 > 稀疏的实证信号**。

## 三、GRPO 系后训练对齐（关键发现 3）

2025-2026 多模态后训练的收敛趋势：**GRPO + 精细信用分配 + 回放卫生**。

| 方法 | 年份 | 信号类型 | 核心创新 |
|------|------|----------|----------|
| MM-RLHF | 2025 | DPO | 120k 偏好对 + Critique-Based Reward Model |
| MM-Eureka | 2025 | RLOO | 规则 RL 诱导更长更强多模态推理链 |
| Vision-R1 | 2025 | GRPO | DeepSeek-R1 式推理激励迁移到 VLM |
| R1-VL | 2025 | 逐步 GRPO | 强化中间推理步而非仅最终答案 |
| S-GRPO | 2026 | 监督 GRPO | 冷启动：真实轨迹 + GRPO 稳定弱初始策略 |
| Faithful GRPO | 2026 | 约束 GRPO | 显式一致性约束减少视觉-空间捷径推理 |
| ZPPO | 2026 | Prompt-zone 策略优化 | 用 prompt 级教师指导替代梯度蒸馏 |
| AlphaGRPO | 2026 | GRPO + 分解奖励 | 从理解扩展到生成和编辑 |

VLM 对齐比 LLM 多两重负担：(1) 模型必须在仅部分语言化的证据上推理；(2) 奖励信号须区分真实视觉 grounding 与似是而非的语言先验答案。

## 四、Modality Gap 不随规模收敛（关键发现 4）

CrossMath 基准（2026-04）在相同数学题上隔离纯文本、纯图像、图文三种输入，测得前沿 VLM 仍严重依赖文本先验。BabyVision（2026-04）用幼儿级感知任务测试，SoTA VLM 在幼儿能完成的任务上失败。

> 产业调查信号：68% 从业者认为 VLM 增长将因训练数据耗尽而停滞——与 LLM 面临的数据墙同步。57% 预期每年用更少标注数据达到同等性能，效率提升快于数据量需求。

## 五、评测范式迁移

| 旧范式 | 新范式 | 代表基准 |
|--------|--------|----------|
| 短式 VQA | 长视频推理 | Video-MME-v2（3300+ 小时标注） |
| 访问计数 | 对抗鲁棒性 | WebForge（自动构建环境+弹窗噪声）、GameWorld |
| 正确性评分 | 校准敏感 | ExtractBench（schema 驱动结构化抽取）、OSReward（长程 GUI agent 自评） |
| 文本 QA | 模态隔离诊断 | CrossMath（视觉 vs 文本贡献隔离）、BabyVision（幼儿级感知） |

WebVoyager 已"饱和"于 97-98%，评测焦点从"能不能做"转向"能不能稳定"。

## 六、对现有 Skill/笔记的改进建议

- **[P1] patch `llm-inference-optimization` skill**：补充 VLM 效率优化新趋势——QUOTA（联合 token 剪枝 + W4A4 量化校准，破除朴素叠加脆性）和 Fast-dVLM（AR VLM → block-diffusion VLM，6×+ 解码加速）。两者证明"视觉 token 效率已是精度×剪枝×解码范式的多轴问题"。
- **[P2] 补充 `embedded-firmware-dev` / `embodied-ai-control` skill**：Era 4 世界-动作模型（Cosmos 3/Kairos）对具身 AI 控制架构有直接影响——感知+生成+决策单循环模型可能替代当前 VLM+策略分离架构。
- **[P2] 更新 `vision-image-recognition` skill**：当前依赖 vision_analyze 单模型调用，可补充 modality gap 诊断意识——当 vision 报错或结果差时，考虑文本先验干扰而非仅模型不可用。

## 七、关键风险与盲点

- **数据墙逼近（来源：Voxel51 产业调查，社区级）**：68% 从业者预期 VLM 增长因数据耗尽停滞，但 57% 同时预期效率提升快于数据需求下降——两信号矛盾，需持续观察哪个先到。
- **Claude Mythos gated release（来源：whatllm.org，单一来源）**：首次前沿实验室以安全为由限制旗舰模型公开发布，仅 ~50 合作方可用。这是行业级信号但来源单一，需官方确认。
- **GRPO 收敛风险（来源：arXiv 综述，学术级）**：八种 GRPO 变体同时涌现说明最佳实践尚未稳定，过度拟合某一变体可能在 3-6 个月后过时。

## 八、一页速查

> **VLM 五纪元**：对比双塔(CLIP) → 投影器骨干(LLaVA) → 原生多模态输入(Gemini3.6) → 统一输入输出(Emu3) → 世界-动作(Cosmos3)
>
> **2026 格局**：9 大前沿家族(GPT/Gemini/Claude/Grok/Qwen/Gemma/DeepSeek/Kimi/MiniMax)，开源旗舰 Qwen3.6-27B dense 超 MoE 前代
>
> **后训练铁律**：GRPO + 信用分配 + 回放卫生 = 事实标准；VLM 对齐比 LLM 多视觉 grounding 负担
>
> **核心警示**：modality gap 不随规模收敛(CrossMath/BabyVision 实证)；68% 从业者预警数据墙
