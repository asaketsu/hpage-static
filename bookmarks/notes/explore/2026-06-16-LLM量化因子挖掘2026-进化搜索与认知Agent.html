摘要

2026 年上半年，LLM 驱动的量化因子挖掘领域出现密集创新。以 QuantaAlpha（轨迹级进化搜索）、CogAlpha（七层认知 Agent 层级）和 BrainAlpha（自主多 Agent 系统）为代表的新框架，将因子挖掘从"LLM 生成单个公式"推进到"结构化进化搜索 + 多 Agent 协作认知"的新范式。QuantaAlpha 使用 GPT-5.2 在 CSI 300 上实现 IC 0.1501、年化收益 27.75%、最大回撤仅 7.98%——相比 RD-Agent 的 IC 提升近 3 倍。这些框架的共性是：将因子挖掘重新定义为搜索问题而非生成问题，用进化操作（变异/交叉）替代朴素的多轮对话，用多 Agent 层级替代单一 planner。

一、核心发现

发现 1：QuantaAlpha——轨迹级进化搜索，搜索优于权重更新

核心洞察：在教师轨迹预算稀缺时，执行驱动的搜索比权重更新（SFT/DPO）更可靠。将每次端到端因子挖掘运行视为一条挖掘轨迹（mining trajectory），通过轨迹级变异和交叉改进因子。

三阶段单轨迹架构：

  1. 假设生成（Idea Agent 𝒜ᵢ）：通过结构化知识整合生成市场假设，条件化于市场观测、领域先验（金融理论）、参数规范。

  2. 可控因子构造（Factor Agent 𝒜f）：

  3. 生成符号表达式 → 解析为 AST（中间表示） → 编译为可执行代码
  4. 一致性验证：LLM 验证器检查假设 h、语义描述 d、符号表达式 f 之间的对齐，以及 f 与代码 c 之间的忠实度
  5. 复杂度控制：𝒞(f) = α₁·SL(f) + α₂·PC(f) + α₃·log(1 + |Ff|)，其中 SL=符号长度、PC=自由参数、Ff=原始特征数

  6. 冗余控制：通过 AST 最大公共同构子树匹配 s(fᵢ,fⱼ) = max|V(Sᵢ)|，拒绝超过复杂度/冗余限制的因子

  7. 因子评估（Evaluation Agent 𝒜e）：标准化回测评估，三类指标（预测能力、收益表现、风险控制），维护成功/失败模式的评估历史。

进化两原语：

  • 变异（Mutation）：自我反思诊断次优决策节点 k，仅重写局部动作，冻结前缀到 sₖ。可更新假设、符号表达式或编译代码。

  • τ_child = (s₀, a₀, …, sₖ, Refine(aₖ), s'ₖ₊₁, a'ₖ₊₁, …, s'ₙ)

  • 交叉（Crossover）：基于轨迹奖励选择父代子集，识别高性能片段（假设模板、构造模式、修复动作），合并为连贯序列，具有可验证的血统。

  • τ_child = Crossover(τ⁽¹⁾, …, τ⁽ᵏ⁾)

消融实验结论：
- 变异是探索和轨迹修复的主要驱动力（移除后 IC 下降 0.0292，ARR 下降 9.81%）
- 规划主要稳定策略级结果
- 交叉利用和继承已验证模式（较小但一致的贡献）

发现 4：AlphaAgent 的 alpha decay 正则化——对抗因子衰减

AlphaAgent 的核心贡献是针对 alpha decay（因子衰减）的正则化探索：

  • 显式正则化：在因子生成过程中施加约束，减轻拥挤效应和 alpha 衰减
  • 抗衰减因子：生成的因子在牛熊市中持续有效
  • 跨市场泛化：在 CSI 500 和 S&P 500 上均有显著 alpha

QuantaAlpha 在 CSI 300 挖掘的因子有效迁移到 CSI 500 和 S&P 500，分别提供约 40.28% 和 19.1% 的 4 年累计超额收益——表明在市场分布偏移下具有强鲁棒性。

二、技术细节深入

QuantaAlpha 的数学形式化

Alpha 挖掘目标：
f* = arg max_{f∈ℱ} ℒ(f(X), y) − λℛ(f)

轨迹奖励：
R(τ) = ℒ(f_τ(X), y) − λℛ(f_τ)

系统目标：
π* = arg max_π 𝔼_{τ∼π}[R(τ)]

其中 ℒ 为预测损失，ℛ 为正则化项（复杂度+冗余），λ 为权衡系数。进化搜索的目标是优化策略 π（即"如何生成好的挖掘轨迹"），而非直接优化单个因子 f。

CogAlpha 的自适应代际选择

每代选择：
- Top 2 有效因子：作为正面引导样本
- 2 个表现最差的无效因子：作为反面引导样本

这种"好坏对比"的 prompt 设计，让 LLM 同时学习"做什么"和"不做什么"，形成更强的信号梯度。

三、实践启发

1. 对 Hermes 量化 Skill 的直接改进

Hermes 已有 llm-factor-mining、agentic-alpha-research、quant-ml-pipeline 等 skill。关键可采纳点：

技术点 来源 Hermes 现状 改进方向
轨迹级变异/交叉 QuantaAlpha 无 在 llm-factor-mining 中引入轨迹存储和进化操作
AST 复杂度/冗余控制 QuantaAlpha 无 添加因子复杂度评分和去重
多 Agent 质量检查 CogAlpha 部分 增加 Code Quality → Repair → Judge → Logic Improve 四阶段
七层维度覆盖 CogAlpha 无结构化 在选股/因子筛选中引入结构化维度清单
信息泄露检测 CogAlpha 无 在回测前添加未来函数检测单元测试

2. 进化搜索 vs 微调——对 Agent 系统的普适启示

QuantaAlpha 的核心发现"搜索优于权重更新"对 Hermes 的 Skill 进化有直接启发：
- 当前 Hermes 的 Skill 改进主要靠"发现问题→手动 patch"（类似微调）
- 可以引入"轨迹级进化"思路：记录成功的任务执行轨迹，对轨迹做变异/交叉自动生成新的工作流变体

3. 模型选择策略

量化因子挖掘对模型的推理能力敏感度很高。QuantaAlpha 的结果表明：
- IC 排序：GPT-5.2 > Deepseek-V3.2 > Qwen3-235B > Claude-4.5
- 但稳健性（MDD）：Claude-4.5 最优

对于 Hermes 的量化任务，建议使用智谱 GLM-5.1 + Deepseek 组合：GLM 用于假设生成和因子构造，Deepseek 用于代码验证和复杂推理。

四、知识缺口与后续方向

  1. BrainAlpha 完整方法：SSRN 论文需获取全文，目前仅有摘要和 Table 1 对比。
  2. 因子可解释性：QuantaAlpha 的 AST 表示和 CogAlpha 的 detailed comments 都追求可解释性，但实际部署中用户信任度评估缺失。
  3. 实盘验证：所有结果基于历史回测，实盘滑点、冲击成本对 IC 的侵蚀程度未评估。
  4. 计算成本：进化搜索（10 并行方向 × 多代）的 LLM token 消耗巨大，成本效益比需量化。
  5. Alpha decay 时间常数：新生成的因子在实盘中多久开始衰减？QuantaAlpha 的抗衰减正则化效果需要更长时间的样本外验证。
