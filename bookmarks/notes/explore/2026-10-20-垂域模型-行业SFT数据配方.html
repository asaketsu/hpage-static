一、摘要

行业SFT的数据配方核心问题不是"比例调多少"，而是"每项能力的绝对数据量够不够"。阿里DMT论文实证：性能冲突的根源是异构数据的绝对数量而非混合比例；通用能力"早熟"（千条级即饱和），专业能力需持续喂养。华为盘古官方实践给出基准配方：行业:通用=1:4（8万行业+31万通用）。2025年arXiv论文把配比问题形式化为优化问题，用小规模实验拟合参数推导最优权重，域间损失仅比网格搜索最优高0.66%。对CPT方向（1020指定优先）的直接启示：DMT的k值重放机制就是SFT版的rehearsal防遗忘策略。

二、关键发现

2.1 数据绝对量主导，配比是次要因素（DMT论文 RQ3）

  • 控制实验解耦"量"与"比"后：in-domain数据绝对量固定时，改变其他域比例对性能影响极小
  • 唯一例外：域间数据有重叠时（如ShareGPT本身含代码对话），比例会引发可见波动
  • 实践含义：别再纠结精确配比，先问"我的行业数据绝对量到门槛了吗"

2.2 混合效应随资源量反转（RQ2）

  • 高资源冲突：数据充足时（各取全部或1/4），混训全面劣于单域微调——异构数据成"噪声"
  • 低资源协同：数据稀缺时（各取1/256），混训反而优于单域——多样性即正则化
  • 转折点：LLaMA-7B约在1/64~1/16区间；模型越大（33B）协同增益越显著

2.3 各能力扩展规律异构（RQ1）

  • 通用对齐：早熟+平顶——约1000条高质量数据（1/256~1/64）即够用，与LIMA"Less is More"呼应
  • 数学推理：数据量严格正相关，喂不饱就不涨
  • 代码：小模型曲线不规则，33B才呈对数线性——分布差异要靠大模型泛化跨越

2.4 DMT双阶段策略（RQ4，防灾难性遗忘）

阶段1: 全部专业数据(行业+代码/数学) 混合充分微调 → 学深学透
阶段2: 全部通用数据 + k比例专业数据(k≈1/256) → 通用对齐+专业"唤醒"
  • k=1/256时LLaMA-33B数学能力GSM8K从44.24回升至56.36，接近多任务学习水平，MT-Bench不降反微升
  • k>1/4后专业提升饱和、通用开始受损——k是"保持通用vs不忘专业"的权衡旋钮
  • t-SNE可视化：数学簇独立，代码与通用表征重叠——这解释了为何代码能力最易被通用训练冲刷

2.5 盘古官方基准配方（金融场景实证）

  • 31万通用 + 8万行业，行业:通用=1:4
  • 通用底座：smoltalk-chinese（70万条全合成）+ OpenThoughts3-1.2M（85万数学+25万代码+10万科学）
  • 行业数据合成两路：①self_qa从专业书籍抽问答对（arXiv:2305.11952）②按业务场景样例做LLM指令泛化（arXiv:2212.10560）
  • 格式：JSONL，context/target/system三键

2.6 配比形式化为优化问题（arXiv:2508.11953, 2025-08）

  • 把SFT数据配比建模为最小化验证损失的优化问题：参数化"有效数据迁移"+微调scaling laws
  • 用小规模混合实验拟合参数→推导最优权重，数学证明保证无域掉队
  • Llama3.1-8B/70B、Qwen2.5-32B验证：与网格搜索最优权重持平（per-domain loss均值仅高0.66%）
  • 洞察：同族模型的最优权重高度相似——一次拟合，族内复用

三、关键概念

行业SFT数据配方决策树
├─ 行业数据绝对量 < 1万条?
│   ├─ 是 → 混合通用数据(低资源协同效应) + LLM合成扩增(self_qa/指令泛化)
│   └─ 否 → 走DMT两阶段:
│            阶段1: 行业+相关专业数据全量
│            阶段2: 通用数据 + k=1/256行业数据重放
├─ 通用能力 → 千条级高质量即可,勿堆量(早熟平顶)
└─ 配比精确调优需求强 → 小规模拟合+优化求解(arXiv:2508.11953)

CPT衔接（1020指定优先方向）：DMT阶段2的k值重放=SFT版rehearsal。CPT防灾难性遗忘的温度重放/多轮退火与DMT同构——"绝对量主导+少量重放防遗忘"是贯穿SFT/CPT两阶段的通用规律。行业:通用=1:4的盘古经验可作为CPT数据配比的初始锚点（CPT阶段行业占比通常更高，需重标定）。

六、关键风险与盲点

  • DMT基于LLaMA 7B-33B + 旧数据集（ShareGPT/Code Alpaca），现代模型（Qwen3/GLM系）指令遵循起点高，"通用早熟"阈值可能更小【社区复现级】
  • 1:4配比是金融场景单点官方实践，非跨行业定律；制造/法律等领域密度不同需重标【官方文档，单案例】
  • 2508.11953以验证损失为代理指标，下游任务指标提升不总是同步（其表中AGIEval/ Safety有波动）【官方验证，arXiv未定稿】

七、一页速查

  • 绝对量>配比：in-domain数据量固定时，改比例几乎不影响性能
  • 通用早熟（~1k条饱和），专业喂不饱不涨；代码最易被通用训练冲刷（表征重叠）
  • 高资源混训=冲突，低资源混训=协同（多样性即正则化）；转折点~1/64-1/16
  • DMT：全量专业→通用+k=1/256专业重放；GSM8K 44.24→56.36
  • 盘古基准：行业:通用=1:4（8万+31万）；合成两路=self_qa抽书+场景指令泛化
  • 配比优化可形式化求解（小规模拟合→最优权重），同族模型权重可复用
  • CPT同构：k重放↔温度重放，"绝对量+重放防遗忘"跨阶段通用
