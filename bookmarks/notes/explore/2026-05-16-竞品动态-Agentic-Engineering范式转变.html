发现二：Agentic Engineering 三层架构成型

Karpathy 正式将"Vibe Coding"更名为"Agentic Engineering"。三层架构清晰浮现：

  • L3 编排层：任务分解、多Agent协作、上下文压缩与恢复
  • L2 执行层：代码搜索/编辑/测试/调试，验证门禁（lint/test/build）
  • L1 基础层：AST语义索引、渐进式披露、模型路由

最关键的洞察：真正的差异化不在 L2（执行），而在 L3（编排） 和 L1（上下文管理）。

Claude Code 的四大核心策略：
1. 渐进式披露：先加载签名，按需加载实现 → Token 消耗 ↓90%
2. 状态机循环：压缩→预算→搜索→执行→验证，防 context 溢出
3. Steer Hook：用户中途可纠偏，不"一条路走到黑"
4. 检查点机制：长任务自动保存进度快照

验证门禁从建议变强制：
- Claude Code: Hard Gates — 提交前必须通过测试
- Codex CLI: 沙箱执行 + 沙箱外操作需批准
- Airbnb 60% 新代码由 AI 编写 → 验证自动化不再是可选

发现三：MoE 训练达到生产级，推理加速体系成型

训练侧：Megatron-Core 完成模块化重构，MoE 五大系统级优化：
1. MoE Parallel Folding（5D混合并行）— attention 和 MoE 层解耦并行化
2. 细粒度激活卸载 — Pipeline-aware，显存节省 30-40%
3. FP8 Blockwise 训练 — Hopper 原生支持，671B 规模验证
4. DeepEP Token Dispatcher — 通信量减少 2-3x
5. 细粒度重计算 — 显存节省 25-35%，吞吐损失仅 5-8%

DeepSeek-V3 实战数据：671B 参数，1233 TFLOPS/GPU，49.3% MFU

推理侧趋势：
- Gemma 4 的预测性token生成，3倍推理加速
- MoE 稀疏激活天然适合投机解码（speculative decoding）
- Megatron Bridge + vLLM/TGI 互操作性增强
