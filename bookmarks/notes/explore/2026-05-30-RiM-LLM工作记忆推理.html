摘要

Reasoning in Memory (RiM) 是一种全新的潜在推理方法，用固定长度的"记忆块"(memory blocks) 替代自回归生成的推理步骤。受人类工作记忆启发，记忆块是特殊 token 组成的固定序列，在单个前向传播中处理完毕，实现计算高效的隐式推理。通过两阶段课程学习（先用推理步骤监督建立记忆块语义，再移除中间监督直接优化最终答案），RiM 在 GSM8K 等推理基准上匹配或超越 Coconut 等潜在推理方法，同时延迟仅为 CoT 的 1/10~1/30。

核心问题与研究动机

问题：当前 LLM 推理能力提升依赖 test-time compute scaling，即生成中间 token（chain-of-thought），但这把内部计算和外部通信耦合在一起。模型被迫用自然语言"外化"每一步思考，效率低下。

动机：人类认知中，工作记忆可以在内部持有和操纵信息，无需将中间步骤外化为语言。能否让 LLM 也具备类似能力？

关键矛盾：
- CoT 推理 = 用语言做计算 = 耦合了推理与生成
- latent reasoning（如 Coconut）= 用连续 token 做推理 = 仍需自回归逐步生成
- RiM = 用固定 token 序列做推理 = 单次前向传播，完全解耦

方法论

1. 记忆块 (Memory Blocks) 设计

  • 记忆块由 M 个特殊 token <m> 组成，插入在问题 token 之后
  • K 个记忆块顺序排列，每个块之间有一个"读出"(readout) 位置
  • 关键特征：记忆块是固定的，不需要自回归生成
  • 整个序列可以用 custom causal mask 实现单次前向传播

2. Custom Causal Mask

  • 每个读出位置只能看到问题 + 之前的记忆块
  • 记忆块之间形成递进结构：第 k 个块可以利用前 k-1 个块的信息
  • 类似于"层层递进的隐式思考"

3. 两阶段课程学习

Stage 1 — 推理步骤监督（建立语义）
- 每个记忆块后，监督模型预测下一个显式推理步骤
- 目标：让记忆块学会存储和变换任务相关信息
- 类比 JEPA 风格的预测表示学习：固定记忆块学习预测缺失的推理结构
- 1 个记忆块对应 1 个推理步骤，提供密集监督信号

Stage 2 — 最终答案精炼（去除脚手架）
- 移除推理步骤监督，直接训练模型预测和精炼最终答案
- 使用固定 K 个记忆块，训练 anytime answer objective
- 每个读出位置生成一个答案预测，损失函数覆盖所有读出位置
- 关键洞察：Stage 1 建立的隐式工作空间被转化为更高效的推理能力

关键实验结果

主实验（Table 1）— GSM8K / GSM-Hard

RiM (Final Block) vs 基线对比：

  • GPT-2: RiM 33.6% vs Coconut 31.1% vs SFT 15.4% (GSM8K Greedy)
  • Llama-3.2-1B: RiM 42.1% vs Coconut 36.9% vs SFT 23.9% (GSM8K Greedy)
  • Llama-3.2-3B: RiM 48.8% vs Coconut 41.3% vs SFT 36.2% (GSM8K Greedy)

延迟对比（TTFT）：
- RiM 延迟 = SFT w/o CoT（不生成推理 token 的基线）
- Coconut 延迟是 RiM 的 7 倍（GPT-2: 53ms vs 7.6ms）
- CoT 延迟是 RiM 的 28 倍（Llama-1B: 420ms vs 16ms）

Any-Block 读出（Table 2）— 更强性能

  • Llama-3.2-1B RiM any-block: GSM8K Pass@8 达到 76.8%，远超 CoT 的 64.7%
  • 延迟仍仅为 CoT 的 1/26

隐式计算验证（Section 4.1）

  • 通过 CKA (Centered Kernel Alignment) 分析记忆块的上下文表示
  • 训练过程中，记忆块表示从"主要由 token 身份决定"逐渐变为"高度依赖输入"
  • 不同记忆块发展出不同的功能角色（类似不同推理子任务）
  • 证明模型确实在记忆块中进行了有意义的隐式计算

训练效率

  • 8× NVIDIA H200-SXM-144GB GPU 上训练
  • Stage 1: 6 epochs（最多 13 个记忆块）
  • Stage 2: 2 epochs（8 个记忆块）
  • 每 1000 步保存 checkpoint 用于分析

创新点分析

  1. 范式突破：首次提出用固定 token 序列替代自回归推理步骤，完全解耦内部计算与外部生成
  2. 两阶段课程：Stage 1 用显式推理步骤做"语义锚定"，Stage 2 移除锚定直接优化答案——类似"先教写字，再教默写"
  3. 单次前传推理：K 个记忆块在单次 forward pass 中完成，延迟不随推理步数线性增长
  4. Anytime 输出：每个记忆块后都有一个答案预测，天然支持 early exit
  5. 跨模型泛化：在 GPT-2 / Llama-3.2-1B / 3B 三个规模上均有效

局限性与未来方向

局限性：
- 目前仅在数学推理基准（GSM8K / GSM-Hard / SVAMP）上验证，泛化性待考察
- 记忆块数量 M×K 是超参数，需要调优
- Llama-3.2-3B 的 any-block 性能（57.3%）低于 CoT（66.9%），说明大模型上 CoT 仍有优势
- 隐式推理可解释性降低——无法直接查看中间推理步骤

未来方向：
- 扩展到更广泛的推理任务（代码生成、逻辑推理、科学推理）
- 探索记忆块的可解释性工具
- 与 process reward models 结合
- 在更大模型上验证 scaling behavior

借鉴点

🔨 P0 — Hermes Agent 推理效率优化

  • 记忆块 + 单次前传 思路可借鉴到 Agent 工具调用链：当前 Agent 每次工具调用都需完整的 prompt→response 周期，如果能在 latent space 中完成多步工具规划，可大幅降低推理延迟
  • Anytime 输出 天然适配 Agent 的渐进式决策：简单问题早退出，复杂问题多步推理

🔨 P1 — Jetson Orin 边缘推理优化

  • RiM 的核心优势是单次前向传播完成多步推理，对边缘设备极友好
  • 当前 Jetson 上跑 CoT 推理受 token 生成速度限制（~15 tok/s），RiM 可将多步推理压缩为固定序列单次前传，推理时间可能降低 5-10 倍
  • 评估方案：在 Llama-3.2-1B 上训练 RiM → 转换 GGUF → Jetson 部署测试

⚠️ P2 — 训练管线移植

  • 两阶段课程学习需要 GSM8K 类似的(问题, 推理步骤, 答案)格式训练数据
  • 对 Hermes 场景：可用 Agent 执行日志(问题, 工具调用链, 结果)作为训练数据
  • 需要工程改造：自定义 causal mask + memory block token + 两阶段训练循环

P3 — 与现有 skill 的关联

  • llm-inference-optimization skill 中的推测解码可配合 RiM 使用
  • edge-llm-quantization skill 的量化方案可直接应用于 RiM 模型

关联论文

  • Coconut (Deng et al., 2024) — 连续 latent token 做推理，RiM 的直接对标方法
  • Think before you speak (Hao et al., 2025) — Coconut 扩展，引入阶段训练
  • Pause Token (Goyal et al., 2024) — 用暂停 token 增加计算，RiM 的早期探索
  • Chain-of-Thought (Wei et al., 2022) — 经典显式推理基线
  • JEPA (LeCun, 2022) — 预测表示学习框架，Stage 1 的理论基础
  • Pause-Eat-Spawn (Shen et al., 2025) — 另一种 latent reasoning 方法

💡 启发

  • 推理不一定需要生成：RiM 证明了 LLM 可以在隐藏状态中完成多步计算，这挑战了"推理=生成"的基本假设
  • 课程学习的威力：先用显式监督建立语义，再移除监督让模型自由发挥——这个"脚手架→去脚手架"的范式在 Agent 训练中也可借鉴
  • 固定计算预算：记忆块提供了可预测的推理成本（K×M tokens，恒定），这对边缘部署和成本控制至关重要

🔮 预判

  • RiM 代表了 test-time compute scaling 的新方向：不是生成更多 token，而是在 latent space 做更多计算
  • 预计 6-12 个月内会出现 RiM + MoE / RiM + 量化的组合方案，进一步推动边缘推理效率
  • 对 Agent 系统的影响：multi-step tool planning 可能在 latent space 完成，只输出最终执行结果
