一、摘要

通用基准饱和后评测正在"向下碎片化"为垂域基准：MMLU 已被所有前沿模型攻破 88%+，Stanford AI Index 2025 显示 MMMU/GPQA/SWE-bench 一年内分别上涨 18.8/48.9/67.3 分——基准一旦失去区分度就不再是基准，只是入场券。Gartner 预测 2027 年企业 GenAI 过半为垂域模型（2024 仅 1%）。但本笔记的核心结论是反面：榜单高分≠生产可用——医疗评测仅 5% 用真实病历、ChemBench 赢了化学家却输在基础题的过度自信、Claude Opus 4.5 换个 harness 从 80.9% 掉到 45.9%。领域基准的正确打开方式 = 从业者出题（医生/律师/适航工程师）+ 分解式评分标准 + 专家标注飞轮校准 LLM 裁判。

二、关键发现

2.1 通用榜饱和 → 垂域基准爆发（市场与结构）

  • CAICT《大模型基准测试体系研究报告(2024)》：2023 一年新增 209 个基准数据集，超过此前 5 年总和；分布=语言 53%/行业 21%/多模态 13%/安全 7%
  • 垂域基准的共同性质：由领域从业者（医生/律师/化学家/安全分析师）出题，而非 ML 研究者写通识题
  • 中文生态已有系统盘点：luban-agi/Awesome-Domain-LLM 收录各行业模型+数据集+评测基准三件套

2.2 标杆基准的构建模式（可复制模板）

  • HealthBench（OpenAI 2025-05，医疗新标杆）：5,000 轮多轮对话 × 48,562 条评分细则，262 名医生/26 科室/60 国编写——不对标准答案打分，对"医生写的 rubric"打分（模型必须提到什么/避免什么/ caveat 到什么程度），LLM 裁判按 rubric 判。这就是临床带教评审的模式
  • LawBench（中文法律）：51 个模型 × 20 任务，按认知三层（记忆/理解/应用）组织，结论=开源模型"离可用还差很远"
  • LegalBench-RAG：6,858 专家标注问答对 × 7,900 万字符真实法律文书——首个评测法律 RAG 检索半场的基准；生产失败大多发生在检索而非推理
  • FinBen：36 数据集/24 任务/7 类，首个含股票交易任务的开放金融基准

2.3 榜单分≠生产可用（三条铁证）

  • 医疗真实性危机：761 篇医疗评测研究系统综述，仅 ~5% 用真实患者数据；RCT 显示医生用 GPT-4 临床推理无显著提升（尽管模型单测分很高）
  • ChemBench（Nature Chemistry 2025）：LLM 平均分超过 19 位化学家，但分子复杂度与准确率零相关=背题不是推理；基础安全题照样错且错的答案与对的答案同置信度
  • Harness 敏感性：同一 Claude Opus 4.5 在 SWE-bench Verified 80.9% vs SEAL harness 45.9%——测试装置换掉，分数减半
  • 金融领域叠加效应：一步算错步步错（FinQA 人类专家 F1 天花板 ~84%），92% 均分掩盖 8% 不对称代价的错误

2.4 构建方法论：COMP-COMP 框架（EMNLP 2025 Findings）

数据堆量不是领域基准的最优原则。港理工 PolyBench 论文提出全面性×紧凑性双指标：

Comprehensiveness(全面性) → 语义召回：覆盖领域全部语义空间
Compactness(紧凑性)      → 语义精度：压冗余、降噪声
机制：
  1. 语料+题目编码到统一语义空间，KDE 核密度估计监控分布
  2. 语料-题目交互：从语料的欠表征区域生成新题（补盲区）
  3. 认知分层(Bloom 分类法四级)：
     KM 知识记忆(是/否题) → KU 知识理解(单块检索)
     → KA 知识应用(多块组合推理) → KC 知识创造(开放观点题)
  4. 训练/评测一致性检查防污染（多数基准忽视=分数虚高）
开源：github.com/Anya-RB-Chen/COMP-COMP

2.5 评测者架构：分解式标准 + 专家飞轮

  • DeCE 框架（EMNLP-Industry 2025）：单一 pointwise 评分把辖区准确性/引用支持/程序步骤/义务覆盖全部压成一个数——分解式领域标准显著优于通用 rubric（实测 GPT-4o/Gemini-2.5-Pro/DeepSeek-R1/Llama-3.1-405B/法律微调 70B）
  • LLM 裁判系统性偏置在监管域放大：位置偏置/冗长偏置/虚构引用（引用密度高反而得分高，但引的是已废止条款）
  • 生产架构=三层分层：确定性检查(可验证项) + LLM 裁判(语义项) + 规则门(安全项)；专家金标准集校准 LLM 裁判 + 周期性人工重校准防漂移；前期标注投入可降低后续专家介入 ~80%
  • 标注质量用 IAA 度量：Cohen's kappa / Krippendorff's alpha（92% 裸一致率可能 kappa 仅 0.16）

2.6 航空领域基准已出现（与用户领域直接相关）⭐

  • ALUE（MITRE+FAA，2025-09-17 发布）：Aerospace Language Understanding Evaluation——首个航空领域 LLM 评测基准，支持自定义数据集/开源与垂域模型/用户自定义 prompt/多量化指标；评 LLM 生成回答的正确性，并显式评估幻觉/偏置/隐私风险；定位=安全关键系统的 LLM 使用前 assurance 工具
  • CAMB（arXiv:2508.20420）：民航维修（civil aviation maintenance）工业级基准，能区分不同 embedding 模型与 LLM 的领域知识差距
  • NASA AIAA 论文：航空领域微调 + LLM-as-a-judge（Gemini 2.0 Flash 裁判）自动化超参筛选
  • 法规侧：EU AI Act 2025-08-02 生效、高风险合规大限 2027-08-02；FDA 已建议临床文档 AI 用专科医生专家评审——领域专家评测正从质量改进变成合规要求

三、关键概念：领域基准分层地图

领域评测基准分层（按"离真实执业的距离"排序，分数递减）
────────────────────────────────────────────
L1 学科考试型(已饱和)   MedQA/司法考试/MMLU → 选择题,区分度死
L2 推理阶梯型           FinQA/TAT-QA/LegalBench → 干净输入上的多步推理
L3 检索半场型           LegalBench-RAG → 真实大文书库上先找对再答对
L4 从业者任务型(rubric)  HealthBench/PLawBench/LawBench → 专家细则打分
L5 生产真实性型(稀缺)    真实病历/真实案卷上的专家评审 → 仅5%研究触及
────────────────────────────────────────────
规律: 模型在 L2 表现好 → L3 变弱 → L4 最差
      生产失败多在 L3(检索), 不可接受风险多在 L5

四、对现有工作的价值（Skill/项目改进建议）

  • P0｜AeroStructFM 策划书：五级验证体系可直接对标 ALUE/CAMB——航空已有官方基准先例，飞机结构领域基准=「数字适航验证」的新形态；EU AI Act 高风险合规评测(2027 大限)与 CCAR 适航符合性逻辑同构，"领域基准=合规证据链"的叙事成立。构建时可整体套用 COMP-COMP：本体驱动出题(适航条款/构型项/EBOM 结构) + Bloom 四级认知分层 + KDE 覆盖度监控 + 训练/评测一致性防污染
  • P1｜content-judge skill：评分表从单点总分改为 DeCE 分解式标准（每维度独立可评：事实正确/引用支持/义务覆盖/程序步骤），并加"虚构引用检测"专项——已有 notes-eval-gate 确定性检查思路与之同构，可合并
  • P2｜domain-llm-training-pipeline skill：现有"文档包→训练"流水线缺评测环节，补"基准构建"章节（数据配方[10-20 笔记]→训练→基准验收闭环）

六、关键风险与盲点

  • Kili/Galileo 均为标注平台厂商，"必须专家人工评审"论点自带商业立场（来源级别：厂商内容，方向正确但程度存疑）
  • Gartner 50% 预测与"5% 真实病历"数字均为转引未核原文
  • ALUE 具体任务构成/指标细节未读原始论文（仅新闻稿），引用时需标注
  • Harness 敏感性（80.9%→45.9%）警示：任何单一榜单数字禁止跨平台直接对标——与既有"跨平台数字禁直接对标"原则互证
