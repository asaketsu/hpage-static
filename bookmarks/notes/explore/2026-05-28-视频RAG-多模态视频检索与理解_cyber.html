Memory）** 成为主导方向，原因是： - 视频天然是事件序列，而非孤立帧的集合 - 长视频（>1小时）中，时间因果关系和场景转换无法被flat向量捕捉 - 图能保存语义关系跨越多个片段 **代表系统：** | 系统 | 图结构类型 | 效果 | |------|-----------|------| | **VimRAG** (arXiv:2602.12735) | 动态有向无环图（DAG） | 多模态RAG基准SOTA | | **Vgent** (arXiv:2510.14032, NeurIPS 2025 Spotlight) | 语义关系图 + 推理验证步骤 | MLVU +3~5.4%，超过所有视频RAG SOTA +8.6% | | **AVA** (arXiv:2505.00254, NSDI 2026) | 事件知识图谱（EKG） | LVBench 62.3%，VideoMME-Long 64.1% | | **Event-Causal RAG** (arXiv:2605.06185) | 状态-事件-状态（SES）图 + 双存储记忆 | 支持无限长视频推理 | **核心洞察**：图不仅存储帧的描述，还编码"发生了什么" → "导致了什么" → "后来怎样了"的因果链，这让长视频QA质量大幅提升。 --- ### 核心发现 2：场景级分割（Scene-level Segmentation）优于帧级检索 **问题根源**：早期Video RAG以固定间隔（如1fps）抽帧，导致： - 同一场景的帧被重复检索（冗余） - 跨场景边界的语义关系断裂 - 对于134小时以上的超长视频，检索效率极低 **场景级方案的突破：** **SceneRAG** (arXiv:2506.07600) 的核心思路： 1. 用 **ASR（自动语音识别）** 获取时间戳转录文本 2. 用转录文本的语义边界检测场景切换点 3. 在场景级别构建知识图谱 4. 检索时以场景为单位，而非单帧 **结果**：在 LongerVideos 基准（含134小时以上视频）上，SceneRAG 赢得 **72.5% 胜率**，远超帧级方法。 **Scene-RAG** (arXiv:2603.27259, CVPR 2026 Highlight) 进一步揭示了"长上下文VLM会遗忘"的问题：即使把视频帧全部塞入模型上下文，VLM仍会"忘记"早期内容。Scene-RAG 使用动态场景记忆解决遗忘问题，将VLM性能提升 +2.50%。 --- ### 核心发现 3：自适应检索策略（Adaptive Retrieval）成为新前沿 不同的用户查询需要不同深度的检索： - "这个视频讲什么？" → 只需高层摘要 - "第23分钟发生了什么？" → 需要精确时间定位 - "所有涉及红色汽车的片段在哪里？" → 需要全局视觉搜索 **AdaVideoRAG** (arXiv:2506.13589, NeurIPS 2025) 提出三层知识索引： 1. **文本层**：ASR转录 + 视频描述 2. **视觉层**：帧嵌入 + 视觉特征 3. **知识图谱层**：实体关系图 根据查询复杂度，动态选择调用哪一层（或多层组合）。这既节省计算资源，又提高了精准度。 **OneClip-RAG** (arXiv:2512.08410, Apr 2026) 将效率推到极限： - 在单块 RTX 4090 上，1小时视频在 **<1.2分钟** 内完成检索 - 将 Qwen3-VL 8B 提升到接近 GPT-5 水平的性能 - 核心：one-shot 片段检索，避免多轮迭代 Pipeline） ``` 原始视频 ↓ [抽帧] fps采样 / 场景切换检测 ↓ [多模态特征提取] ├── 视觉: VLM描述帧内容（CLIP/Gemini/Qwen-VL） ├── 语音: ASR转录（Whisper） └── 音频: 音频特征提取 ↓ [结构化表示] ├── 文本向量（dense embedding） ├── 视觉向量（image embedding） └── 知识图谱节点（实体+关系） ↓ [向量数据库存储] ├── HNSW 索引（快速近邻搜索） └── IVFPQ 索引（大规模场景） ``` ### 2. 检索策略对比 | 策略 | 代表工具 | 适合场景 | 局限 | |------|---------|---------|------| | **帧级密集检索** | CLIP+FAISS | 短视频、视觉对象查找 | 冗余高、无时序 | | **ASR文本检索** | Whisper+BM25 | 有对话的视频 | 无视觉内容 | | **场景级检索** | SceneRAG | 长视频、叙事型内容 | 场景边界检测难 | | **图结构检索** | VimRAG/Vgent | 超长视频、因果推理 | 构建成本高 | | **自适应检索** | AdaVideoRAG | 通用问答 | 复杂实现 | ### 3. 检索效率优化 **PANORAMA** (arXiv:2510.00566) 提供了 ML 驱动的近似最近邻搜索（ANNS）： - 学习正交变换，优化向量空间布局 - 兼容 IVFPQ、HNSW、MRPT、Annoy 等主流索引 - 在零召回率损失的前提下实现 **2~30倍加速** **LUMA-RAG** (arXiv:2511.02371)：终身多模态代理记忆系统 - 流式处理：新内容实时加入 HNSW 热索引 - 定期归档到 IVFPQ 冷索引 - Recall@10 = 0.94，Safe@1 = 1.0 --- ## 代码示例 ### 示例 1：基础视频RAG管道（基于场景级分割） ```python import whisper import cv2 import numpy as np from sentence_transformers import SentenceTransformer import faiss from PIL import Image import json # Step 1: 音频转录（获取时间戳） def transcribe_video(video_path): model = whisper.load_model("base") result = model.transcribe(video_path, word_timestamps=True) return result["segments"] # [{start, end, text}, ...] # Step 2: 场景边界检测（基于转录语义） def detect_scene_boundaries(segments, similarity_threshold=0.7): embedder = SentenceTransformer("all-MiniLM-L6-v2") texts = [seg["text"] for seg in segments] embeddings = embedder.encode(texts) boundaries = [0] for i in range(1, len(embeddings)): # 余弦相似度 sim = np.dot(embeddings[i-1], embeddings[i]) / ( np.linalg.norm(embeddings[i-1]) * np.linalg.norm(embeddings[i]) ) if sim < similarity_threshold: boundaries.append(i) return boundaries # Step 3: 场景描述（视觉 + 文本融合） def describe_scene(video_path, start_sec, end_sec, vlm_model): """提取场景关键帧并用VLM生成描述""" cap = cv2.VideoCapture(video_path) fps = cap.get(cv2.CAP_PROP_FPS) # 抽取中间帧 mid_frame = int((start_sec + end_sec) / 2 * fps) cap.set(cv2.CAP_PROP_POS_FRAMES, mid_frame) ret, frame = cap.read() cap.release() if not ret: return "" image = Image.fromarray(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)) # 调用 VLM 生成描述（这里用占位符） description = vlm_model.describe(image) return description # Step 4: 建立向量索引 def build_video_index(scenes): """scenes: [{start, end, text, visual_desc, embedding}]""" embedder = SentenceTransformer("all-MiniLM-L6-v2") # 融合文本描述和视觉描述 combined_texts = [ f"[时间 {s['start']:.1f}s-{s['end']:.1f}s] {s['text']} {s.get('visual_desc', '')}" for s in scenes ] embeddings = embedder.encode(combined_texts) # FAISS HNSW 索引 dim = embeddings.shape[1] index = faiss.IndexHNSWFlat(dim, 32) index.add(embeddings.astype(np.float32)) return index, scenes, embeddings # Step 5: 检索 + 生成 def video_rag_query(query, index, scenes, embedder, llm, top_k=3): # 检索 query_vec = embedder.encode([query]).astype(np.float32) distances, indices = index.search(query_vec, top_k) # 组装上下文 context = "\n\n".join([ f"场景 {i+1} [{scenes[idx]['start']:.1f}s-{scenes[idx]['end']:.1f}s]:\n{scenes[idx]['text']}" for i, idx in enumerate(indices[0]) ]) # 生成回答 prompt = f"""基于以下视频片段回答问题： {context} 问题：{query} 回答：""" return llm.generate(prompt) # 主流程 if __name__ == "__main__": video_path = "wildlife_footage.mp4" # 1. 转录 segments = transcribe_video(video_path) # 2. 场景分割 boundaries = detect_scene_boundaries(segments) # 3. 构建场景列表 scenes = [] for i in range(len(boundaries)): start_idx = boundaries[i] end_idx = boundaries[i+1] if i+1 < len(boundaries) else len(segments)-1 scenes.append({ "start": segments[start_idx]["start"], "end": segments[end_idx]["end"], "text": " ".join(s["text"] for s in segments[start_idx:end_idx+1]) }) # 4. 建索引 embedder = SentenceTransformer("all-MiniLM-L6-v2") index, scenes, _ = build_video_index(scenes) # 5. 查询 answer = video_rag_query( "日出时山丘上的大象在哪个片段？", index, scenes, embedder, llm=None # 接入你的LLM ) print(answer) """基于 Event-Causal RAG 思想构建视频事件图""" def __init__(self): self.graph = nx.DiGraph() def add_state(self, state_id, timestamp, description): self.graph.add_node(state_id, type="state", timestamp=timestamp, description=description) def add_event(self, event_id, start_time, end_time, description): self.graph.add_node(event_id, type="event", start_time=start_time, end_time=end_time, description=description) def connect_ses(self, before_state, event, after_state): """State → Event → State 因果链""" self.graph.add_edge(before_state, event, rel="triggers") self.graph.add_edge(event, after_state, rel="results_in") def query_causal_chain(self, event_id): """查询某事件的前因后果""" predecessors = list(self.graph.predecessors(event_id)) successors = list(self.graph.successors(event_id)) return { "event": self.graph.nodes[event_id], "caused_by": [self.graph.nodes[p] for p in predecessors], "leads_to": [self.graph.nodes[s] for s in successors] } # 构建示例 g = VideoEventGraph() g.add_state("s1", 0.0, "平静草原，无动物") g.add_event("e1", 5.2, 8.7, "狮群从左侧进入画面") g.add_state("s2", 8.7, "草原上有狮群，斑马群在远处") g.connect_ses("s1", "e1", "s2") chain = g.query_causal_chain("e1") print(chain) ``` --- ## 与现有工作的关联
