# Token 定价战 — LLM 推理成本三年崩塌 99% 的格局与应对
> 探索日期 2026-08-26 | 兴趣等级 L2 | 来源 6 篇 | 前序：free-model-apis skill、model-fallback-chain skill

## 摘要
2023-03 GPT-4 上线 $30/$60 每百万 token；2026-04 Gemini 3.1 Flash 只要 $0.10/$0.40——三年降 99.7%，且能力同期反超当年旗舰。2026-07-30 OpenAI 再降价后，主流 API 地板已到 $0.20/M input（GPT-5.6 Luna）。价格战由 MoE 架构、硬件竞争、推理优化、五巨头竞争、规模摊薄五力共同驱动，未见底。

## 关键发现
1. **价格阶梯已固化（2026-08 实测数据）**：
   - 地板层：$0.05–0.20/M input（Gemini 3.0/3.1 Flash、GPT-5.6 Luna 0.20/1.20），免费层已有 43 个模型（pricepertoken 追踪 610+ 模型）
   - 中间层（生产主力）：$1.5–3/M input（GPT-5.4 Mini 1.50、Gemini 3.1 Pro 2.00、Claude Sonnet 4.6 3.00），SWE-bench 全部 62–68%，18 个月前的世界最强水平
   - 旗舰层：$5–15/M input（GPT-5.6 Sol 5/30、Claude Opus 4.6 15/75），仅留给硬推理场景
2. **通缩结构不对称**：a16z LLMflation 指出低端价格崩塌 100×，但旗舰 output 价反而坚挺——OpenAI o1 的 $60/M output 与 2020 年 GPT-3 持平。厂商主动放弃低端市场换量，靠旗舰层守住毛利。
3. **降价五驱动力量化**：MoE（3–5×）、AMD MI400/TPU v6/Trainium3 硬件竞争（2024 年以来推理算力成本 −40%）、推测解码+连续批处理+KV cache 优化（2–3×）、五巨头份额战、十亿级日请求摊薄固定成本。
4. **架构含义比价格本身重要**：wavect 实测 2026 年同质量 bar 的 AI 功能推理成本仅为 2024 年报价的 30–60%。多模型路由、级联验证、投机执行从"理论最优但用不起"变成默认架构——smart routing 实测省 60–80%。
5. **商业模式连锁反应**：Agent 产品普遍放弃按 token 计价，转向 per-seat / per-task credits / 按 resolution 计费（coding agent 约 $150–250/开发者/月）；"用 AI 要省着用"的设计原则翻转为"liberally use"。

## 核心概念
```
成本崩塌曲线（frontier 级，$/1M tokens，wavect 归一化）:
            2024        2026
推理旗舰    15 / 75  →  3 / 15     (−80%)
通用旗舰    3 / 15   →  0.6 / 3   (−80%)
中间层      0.5/1.5  →  0.1/0.3   (−80%)
缓存输入    —        →  0.3       (新维度，降更狠)
```
路由决策矩阵（质量要求 × 成本敏感）：低质量需求一律 Flash 级；高要求任务才升 Sonnet/Opus——缓存命中率、升级率、batch 占比成为新的成本预测变量。

## 对工作的价值
- Hermes 的 model-switch / model-fallback-chain / adaptive-inference-routing 技能栈正踩在"smart routing 省 60–80%"的风口上——多供应商比价（同模型不同端点价差可达 8×，如 Bedrock vs Fireworks 的 Llama 4）应成为路由的常规维度。
- 本机 Jetson 本地推理（Ollama）的经济性窗口被压缩：云端 $0.10/M 时代，本地部署的卖点只剩隐私/离线/零边际扩容，不再是省钱。

## 行动建议
1. P1：zhipu-quota-monitor 到期后的 fallback 决策应纳入"价格阶梯"数据——中间层 $2/M 级模型已能覆盖大部分 cron 任务质量需求。
2. P2：free-model-apis skill 补充 2026-08 价格快照（43 个免费模型、地板 $0.20、中间层 $2 主力），防止用 2024 年价格直觉做选型。

## 关键风险与盲点
- 价格数据来自聚合站（cloudzero/pricepertoken/aimagicx），时效性强、波动快，仅作量级参考不可当报价（社区数据）。
- 未降价的隐性成本：高并发延迟、egress 流量、向量库托管、evals 人力——账单降了但工程判断更值钱（wavect 官方观点）。
- 定价战可能随需求爆炸逆转：a16z 提示若 agent 用量指数增长，算力瓶颈可能重新推价。

## 一页速查
> 三年 99.7% 降幅；地板 $0.20/M、中间层 $2/M 是主力、旗舰守住 $15+/M。路由+缓存+级联=默认架构，省 60–80%。Agent 计价转向 per-seat/per-task。本地推理卖点只剩隐私离线。
