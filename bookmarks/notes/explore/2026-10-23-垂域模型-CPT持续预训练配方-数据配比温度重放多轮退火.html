摘要

本篇为 CPT（Continued Pre-training）的逐参数配方笔记，与 09-18 方法论笔记互补（那篇回答"何时做 CPT + 阶段流程"，本篇回答"每个旋钮拧到多少"）。三个核心旋钮：①数据配比 α=领域占比，工程默认起点 0.7（70% 领域 / 30% 通用回放），权威案例 BloombergGPT α≈0.51、Code Llama α≈0.85，可用 DoReMi 用小模型自动寻优；②通用数据回放是最便宜的防遗忘杠杆，5%-30% 区间，EvoLM 实测混入 5% 即可大幅缓解灾难性遗忘；③学习率 η_CPT=(0.01~0.1)×η₀，配余弦退火 + re-warming 短暂回温，训练中用"通用基准回退 >2-3% 即干预"的遗忘监测门控选点。

关键发现

1. 数据配比：公式、权威案例与选值逻辑

D_mix = α·D_domain + (1-α)·D_general    （α ∈ [0.5, 0.9]）
  • 工程默认起点 α=0.7：123ofAI 给出的 practical rule——70% 领域 + 30% 通用回放 + LR=0.05×η₀，同时盯领域 PPL（应降）和通用基准（回退不超 2-3%）
  • BloombergGPT α≈0.51：363B 金融 token / 708B 总 token，金融域从头混训
  • Code Llama α≈0.85：85% 代码 + 8% 代码注释性文本 + 7% 通用——代码与预训练分布近，可压低通用占比
  • ChatHome（家装域）：领域:通用 1:5~1:10，即领域占比仅 9%-17%（分布差距小的域可用极端配比）
  • AMD 多语 CPT：30% 芬兰语 + 30% 英语 + 30% 代码 + 10% 数学的均衡配比，专防强分布转移下的遗忘
  • EvoLM（100+ 受控模型实验）：最优配比 42B 领域 + 8B 通用 ≈ 16% 通用回放
  • 自动寻优：DoReMi / DoGE 用小模型搜各域权重再迁移到大模型；Data Mixing Laws 可建模预测

选值逻辑：领域与预训练分布距离越远、语料越小 → 通用占比取高段（25-30%）；距离近（如代码）可压到 5-10%。

2. 回放（Replay）：最便宜的防遗忘杠杆

  • FutureAGI 2026 工程实践：每 batch 混 5-20% 通用 token（FineWeb-Edu / RedPajama / Dolma 采样），几乎零额外算力成本对冲遗忘
  • EvoLM 实测：纯领域 CPT → 通用能力急剧遗忘；混 5% 通用回放即可大幅缓解
  • 回放两大参数：replay ratio（批内占比）+ replay frequency（重放频率）
  • 进阶手段：
  • EWC 正则：λ/2·Σ F_i(θ_i-θ₀,i)²，Fisher 信息约束关键权重
  • 梯度投影：避开通用能力的重要梯度方向
  • 模型合并：Task Arithmetic 丢弃 50% 增量参数 + 2 倍缩放（Attention 层丢 60%、MLP 层丢 30%），遗忘率比线性插值低 35%
  • OpenReview 新发现：预训练阶段就混入少量领域数据（upstream 决策）比 CPT 时才回放更抗遗忘——上游混入构建的遗忘抵抗力优于下游补救

3. 学习率与多轮退火调度

η_CPT = β·η₀,  β ∈ [0.01, 0.1]        （比预训练峰值低 10-100 倍）
η(t) = η_min + ½(η_CPT-η_min)(1+cos(πt/T)),  η_min = 0.1×η_CPT
  • 实例：Llama 3 预训练 3e-4 → CPT 用 3e-6~3e-5；7B 常用 3e-5（约 1/10）
  • Re-warming（Gupta 2023）：基座以余弦衰减到近零收尾时，CPT 开头短暂回温 LR 有助恢复可训练性；warmup 占总步数 1-5%
  • warmup_ratio 参照：预训练 0.01 / SFT 0.03 / CPT 取更大（<10B token 小语料尤其，平滑过渡）
  • 基座用余弦训的 → CPT 也用余弦（优于 WSD 调度），保持调度器谱系一致
  • 多轮（课程化）配比退火：Data Mixer 支持课程学习——初期高通用占比 → 逐步提高领域浓度 → 遗忘监控触发时反向回调；CPT 缩放定律（分布转移 + LR 退火双因子）可预测任意步的验证损失
  • 两条铁律：优化器必须重置（严禁加载预训练优化器状态）；CPT 初期 loss 先升后收敛属正常现象，勿误判
  • AMD 实战反直觉发现：多 epoch 重复数据无增益（1 epoch 足够），高 LR（8B 用 3e-4）在多语场景反而有效——强分布转移下结论与常规 CPT 不同，需按域验证

4. 遗忘监测门控与选点

  • 训练中每数千步跑通用基准子集（MMLU/ARC/HellaSwag）；通用回退 >2-3% 触发干预：提高通用占比 / 降 LR / 加 EWC
  • 最优 checkpoint ≠ 最终 checkpoint：选"领域性能最大 且 通用回退 < 阈值"的点，末段退化时果断止损
  • 术语澄清："温度重放"在主流文献中不是独立旋钮——回放的主旋钮是占比与频率；"温度"对应退火隐喻（LR annealing 源自模拟退火）。若指回放数据的温度加权采样，本次信源未覆盖，留待实战验证

对工作的价值

  • 直接喂 AeroStructFM 垂域线：飞机结构域与通用语料距离中等偏远（适航条款/结构报告/EBOM 术语密度高），起步配比建议 α=0.6-0.7（通用回放 30-40% 偏保守侧）
  • 与 10-20 行业 SFT 数据配方衔接成完整流水线：CPT（本篇配方：α=0.7 + 回放 + 余弦 re-warm）→ SFT（绝对量 > 配比 + DMT 两阶段 + 盘古 1:4）
  • aircraft-req-sft-mini 若从 SFT 升级到 CPT：7B 底座三件套可直接抄——LR 3e-5 起点 / α=0.7 / 通用回退 3% 红线
  • 遗忘监测门控 = 用户"训练判死止损"哲学在 CPT 场景的同构实现（阈值化早停 + 黄金档交付）
