标题: A First-Principles Derivation of LLM Policy Optimization: From Expected Reward to GRPO and Its Structural Extensions
日期: 2026年6月16日
领域: 强化学习 / LLM 策略优化 / GRPO
作者: Ziyan Huang et al.

一、核心问题与研究动机

问题

LLM 策略优化方法（从 REINFORCE → PPO → GRPO → 后 GRPO 变体 → Agentic RL → GRPO-OPD）发展迅速，但现有综述按领域或时间线组织，无法回答实践者最核心的诊断问题：

给定一个训练失败，是什么机制导致了它？什么最小干预可以解决它而不引入更糟的失败？

动机

  • PPO 需要价值函数（critic）估计优势，对于长思维链任务和稀疏/二值奖励，critic 既计算昂贵又数值不稳定
  • GRPO 用组内相对奖励替代 critic，解决了内存和稳定性问题，但后续方法层出不穷，缺乏统一框架
  • 需要一种可诊断、可扩展的框架来定位每个方法在优化目标中的干预位置

二、核心框架：轨迹侧 vs 奖励侧

论文提出从第一性原理出发，以期望奖励目标 $J(\theta) = \mathbb{E}_{\tau \sim p_\theta(\tau)}[R(\tau)]$ 为起点，将梯度估计器分解为两个因子：

侧 因子 含义
轨迹侧 (Trajectory Side) $p_\theta(\tau)$ 轨迹概率，由策略 $\pi_\theta$ 和环境动力学 $P$ 决定
奖励侧 (Reward Side) $R(\tau)$ 奖励信号，包括奖励获取、归一化、塑形和转换为优势估计

核心洞察：每种方法修改其中一个或两个因子来解决前一种方法的特定失败。

三、方法论详解

Part I: 从 RL 目标到每步 LLM 形式

推导路径：
1. MDP 基础：状态空间 $\mathcal{S}$、动作空间 $\mathcal{A}$、转移核 $P$、奖励 $R$、折扣因子 $\gamma$
2. 轨迹概率分解：$p_\theta(\tau) = \rho_0(s_0) \prod_{t=0}^{T-1} \pi_\theta(a_t|s_t) P(s_{t+1}|s_t,a_t)$
3. 对数导数技巧：将不可微的梯度转化为采样友好的期望形式
4. 回报到-go (reward-to-go)：因果正确性，只考虑当前动作之后的奖励
5. 优势估计：$A_t = Q_t - V_t$，用优势替代原始回报降低方差
6. GAE (Generalized Advantage Estimation)：用 $\lambda$-return 平衡偏差-方差
7. PPO-Clip：重要性采样 + 裁剪约束策略更新幅度

LLM-MDP 对应关系：
- 状态 = 当前生成的 token 序列
- 动作 = 下一个 token 的选择
- 转移 = 确定性（LLM 生成是确定性的给定策略）
- 奖励 = 任务特定的验证信号

Part II: GRPO 与单轮景观

GRPO 的核心创新：
- 奖励侧替代：用组内相对奖励归一化替代 per-token critic
- 计算 $G_i = \text{reward}(o_i) - \text{mean}(\{\text{reward}(o_j)\}_{j=1}^G)$
- 消除了 critic 模型，降低内存需求约 50%

后 GRPO 变体分类（按轨迹侧/奖励侧/耦合干预）：

类别 代表方法 解决的问题
收集 GRESO, Prompt Replay, PODS rollout 收集效率
压缩与复用 ThinkPrune, DAST, RePO, ExGRPO 减少 token 浪费
多样性 TreeRPO, DIVER, DRA-GRPO, DSDR 避免模式坍塌
修复 S2R, SCoRe, PAG 纠正错误轨迹
Clip 与粒度 DAPO, SAPO, GSPO 裁剪策略优化
密度 GRPO-VPS, SPO 增加训练信号密度
塑形 LASER, S-GRPO 过程奖励信号
统计偏差校正 Dr.GRPO, Lopti 组内统计偏差

Part III: 结构性扩展

7. Agentic RL（轨迹侧扩展）

  • 将轨迹从单轮生成扩展到多轮环境交互
  • 动作空间扩展：web 搜索、代码执行、GUI 交互
  • 新失败模式：rollout 有效性、环境噪声、工具调用失败
  • 代表方法：WebRL, CuSearch, DeepResearcher, Search-R1, SWE-RL

8. GRPO-OPD 混合（奖励侧扩展）

  • 原始 OPD：用 KL 散度替代奖励目标，退出策略梯度框架
  • GRPO-OPD 混合：保留 $J(\theta)$ 目标，将教师信号作为奖励的一个组件
  • 四个奖励侧算子：$\mathcal{T}_A$ 重要性比、$\mathcal{T}_B$ 优势、$\mathcal{T}_C$ 期望内蒸馏、$\mathcal{T}_D$ 外部正则化

四、关键实验结果与数据

论文为综述性论文，不报告新实验结果，但总结了现有方法的量化发现：

  • GRPO vs PPO：内存需求降低约 50%，在数学推理任务上达到相当或更好的性能
  • DAPO：通过动态 rollout 长度和过滤，训练效率提升显著
  • GSPO：去除 token 级裁剪，简化实现并保持性能
  • GRPO-OPD 混合：在保持奖励最大化目标的同时，利用教师信号加速收敛

五、创新点分析

1. 两轴诊断框架

将复杂的策略优化方法空间映射到两个清晰的维度（轨迹侧/奖励侧），使方法比较和失败诊断变得系统化。

2. 耦合失败识别

识别出单一侧修复无法解决的耦合失败，例如：
- 多样性不足 + 奖励信号稀疏 → 需要同时修改轨迹收集策略和奖励塑形
- 环境噪声 + 组内归一化偏差 → 需要同时修改 rollout 有效性和统计校正

3. 框架边界定义

明确区分：
- 策略梯度线（本文框架覆盖）：保留 $J(\theta)$ 目标
- DPO 线：退出策略梯度框架，用偏好似然替代
- KL 最小化 OPD 线：用蒸馏目标替代奖励目标

4. 可扩展性

框架可自然扩展到 Agentic RL 和 GRPO-OPD 混合，证明其诊断能力不仅限于单轮 token 生成。

六、局限性与未来方向

局限性

  1. 仅覆盖策略梯度线：DPO、ORPO 等偏好优化方法需要独立的推导框架
  2. 未涉及离线 RL：所有方法都是在线策略优化
  3. 多模态扩展未覆盖：视觉-语言模型的策略优化有特殊考虑
  4. 计算资源假设：假设可访问 GPU 集群，未讨论边缘/单卡场景

未来方向

  1. 耦合失败的联合设计：如何系统性地同时优化轨迹侧和奖励侧
  2. 边界案例探索：策略梯度框架的极限在哪里
  3. Agentic RL 的标准化评估：多轮交互的统一 benchmark
  4. GRPO-OPD 的理论与实践：教师信号与验证信号的最优组合

七、借鉴点（关联 Hermes Agent / Jetson Orin / 量化交易）

✅ 已部分实现

借鉴点 当前状态 增量价值
工具调用优化 Hermes 已有 MCP 工具调用 GRPO 的组内相对奖励可用于工具调用成功率优化
轨迹多样性 已有 multi-agent 编排 DIVER/DRA-GRPO 的多样性机制可防止 agent 模式坍塌

🔨 可直接移植

借鉴点 工作量 说明
组内相对奖励归一化 低 可直接用于 Hermes Agent 的多候选响应排序和奖励计算
重要性采样 + 裁剪 中 可用于 Agent 策略微调，避免分布漂移
GAE 优势估计 中 可用于量化交易策略的长期回报评估

⚠️ 需工程改造

借鉴点 关键障碍 说明
Agentic RL 多轮交互 环境接口标准化 Hermes 已有工具调用，但需要统一的环境反馈机制
GRPO-OPD 混合训练 教师信号获取 需要高质量 teacher policy，可能依赖闭源模型
过程奖励塑形 细粒度验证信号 需要为每个推理步骤设计可验证的 reward

❌ 暂不适用

借鉴点 原因
