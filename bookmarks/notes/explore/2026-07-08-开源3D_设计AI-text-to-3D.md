# 开源 3D / 设计 AI：Text-to-3D 生成全景（2026）

## 摘要

Text-to-3D 技术在 2026 年已从研究玩具变为价值 32 亿美元的成熟产业。核心范式是"文生图 → 图生几何 → 纹理贴图 → 导出"四步管线，生成时间从 3-5 天压缩到秒级。开源模型中 TRELLIS 2（微软，MIT 许可）和 Hunyuan3D 2.1/3.x（腾讯）领跑，闭源侧 Tripo AI 和 Rodin 各有专长。

## 关键发现

### 市场规模
- 2026 年 AI 3D 市场 32.3 亿美元（同比 +30.9%）
- 预计 2030 年达 94 亿美元（CAGR ~30%）
- 关联赛道：AI 3D 资产生成+纹理，2026 年 19.5 亿 → 2036 年 128.4 亿美元

### 模型梯队（2026 当前格局）

**第一梯队（SOTA）**
- Seed3D 2.0（字节跳动）：几何+纹理 SOTA，人类偏好胜率 69-89.9%
- Hunyuan3D 2.1/3.x（腾讯）：最佳纹理和 PBR，开源权重但社区许可限制 EU/UK/韩国
- TRELLIS 2（微软）：开源标杆，4B 参数，24GB 显存 20 秒出 1536 分辨率资产，MIT 许可

**速度/轻量梯队**
- Tripo 3.0（VAST AI）：30 秒内出图，拓扑干净，原生 PBR，获阿里百度 5000 万美元融资
- TripoSR / Stable Fast 3D：消费级硬件（6-8GB 显存）亚秒级草稿
- Meshy 5/6：最成熟管线（生成+纹理+绑骨+插件生态）

### 开源 vs 闭源
- 开源优势：免费、自托管、无 per-model 成本，适合批量生成
- 闭源优势：零配置、最佳打磨质量、可预测定价
- 最佳实践：开源做量+成本控制，闭源做精品资产

### 技术趋势
1. **无单一模型全能**：同一输入跑 2-3 个引擎对比，取最优已成为标准工作流
2. **聚合器崛起**：3D AI Studio（创作者）、fal.ai/Replicate（开发者）、ComfyUI（自托管）
3. **MCP + Agent**：Blender 官方 MCP server 已发布，AI Agent 可直接调用 3D 工具链
4. **Gaussian Splatting 基础设施化**：OpenUSD 已原生支持，glTF 正在标准化扩展
5. **API 成本极低**：TRELLIS 在 fal.ai 仅 $0.02/次，Stable Fast 3D 约 $0.08/次

## 对工作的价值

1. **快速原型**：描述物体 → 秒级出 3D 模型，加速产品/工程设计迭代
2. **成本降低**：传统 3D 建模外包 $800/角色，AI 生成 $0.02-1/次，成本降低 3-4 个数量级
3. **Agent 集成**：MCP 协议让 AI Agent 可直接调用 Blender 等工具，自动化 3D 管线成为可能
4. **Jetson 边缘部署潜力**：TripoSR/Stable Fast 3D 在 6-8GB 显存即可运行，Jetson Orin（8GB）可本地推理

## 行动建议

1. **立即可用**：通过 trellis2.app 或 3D AI Studio 免费试用，零门槛体验
2. **本地部署**：在 Jetson Orin 上部署 TripoSR 或 Stable Fast 3D，实现离线 3D 生成
3. **API 集成**：通过 fal.ai API（$0.02/次）接入 TRELLIS，低成本嵌入现有工作流
4. **MCP 探索**：关注 Blender MCP server 生态，评估 Agent 驱动的自动化 3D 管线
5. **持续关注**：Seed3D 2.0 若开源将是新标杆，保持跟踪字节跳动动态
