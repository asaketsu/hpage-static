## 一、核心内容：代理模型两级闭环（完整还原）

### 1.1 问题与方法

飞机概念设计需评估 10⁴-10⁶ 候选构型，纯 CFD（RANS 单次 1 小时-1 天）不可行。代理模型方案：

```
低保真物理核（VLM，毫秒级）→ 批量生成数据 → A100 训练代理（MLP/GNN/FNO）
  → 代理毫秒级粗筛 10⁶ 候选 → top-k 高保真复核 → 最优构型 + 误差报告
```

### 1.2 项目实测数字（全部本地验证）

| 环节 | 实测结果 |
|------|----------|
| 物理核精度 | CL-α 斜率 vs Prandtl 理论 **偏差 0.0%**（AR=6/8/10 三档） |
| 数据生成 | 5000 样本 / 8 秒（6 维设计空间分层随机采样） |
| 两级闭环 | 200k 候选粗筛 **3.1 秒**（纯 VLM 需 100+ 秒）|
| 高保真调用削减 | 200000 → 50 = **4000×** |
| 代理引导价值 | top50 均值 vs 随机盲选 **+689%**（t8 硬实证） |
| 最优解物理性 | b=11.4m / λ=0.32 / Λ≈2° / CL=0.545 / L/D≈197——高展弦比滑翔机构型，符合空气动力学直觉 |
| 代理精度 | numpy 冒烟 R²=0.877（A100 torch 256×3 层预期 >0.99） |

### 2.2 使用性评估

**能干什么**：概念设计阶段的总体参数优化（6 维：展长/弦长/锥削/掠角/扭转/迎角），秒级完成原需数天的方案筛选。
**不能干什么**：细节气动设计（翼型修型/激波捕获）需要 CFD 数据源和场级代理（GNN/FNO）——本项目留了升级接口。
**A100 的真实角色**：5000 样本 MLP 单卡 15 分钟即可；8 卡的用武之地在**场级代理**（网格 10⁵ 节点 × 10⁴ 样本的 GNN/FNO 训练）和多保真大数据集。

### 2.3 指导性意见

- **先小后大**：MLP+标量输出（本管线）先跑通闭环，再升级 GNN/FNO 场级——架构复杂度换数据量的前提是闭环已验证
- **代理边界=采样边界**：优化搜索空间绝不能超出训练数据覆盖，边界外预测是幻觉
- **物理核宁浅勿错**：低保真核必须锚定理论（本项目 0.0% 偏差），错误的核会系统性污染全部训练数据
- **价值验证用 top-k 均值**：代理引导 vs 随机的对比必须看集合均值，单点 max 被极值噪声支配
- **何时不用代理**：评估次数 <1000 时直接物理核暴力；只有 10⁵+ 候选时代理才是杠杆

### 2.4 案例可寻

- 本项目最优解（滑翔机构型）即案例——最优设计参数与气动直觉完全一致
- arXiv 2510.08582 同构管线（VLM+代理+多算法优化）独立佐证
- Stanford ADL 系列（GNN 多保真缩放律）是数据量扩展的参考曲线

### 2.5 使用方法借鉴（30 分钟复现）

```bash
cd ~/uclaw/project/aero-surrogate-pipeline

# A100: torchrun --nproc_per_node=8 train/train_surrogate.py --data ... --epochs 500
```

## 三、查询拓展

1. **FNO 为什么是下一代**：算子学习学的是"PDE 解算子"而非离散映射——换网格/换几何不用重训，对飞机设计"几何连续变化"的搜索空间是天然匹配
2. **多保真的本质**：VLM（毫秒/个）与 CFD（小时/个）的信息密度差 6 个量级——Co-Kriging/迁移学习用 10⁵ 低保真样本学"形状"，10³ 高保真样本学"修正"，是数据性价比最优解
3. **气弹耦合扩展**：+结构核（NASTRAN 级梁模型）→ 双场代理 → 颤振约束优化——多物理场的"场"数每加一，代理的杠杆率翻倍（每场都省同样量级的求解时间）
4. **与 Lean 笔记的闭环**：代理上适航认证需形式化误差界——"NN 预测误差 < ε 在全域 D 内成立"的 Lean 定理化是 AI 设计工具装机的最后一公里

## 五、趋势判断

1. **两级闭环是 AI4CAE 的通用范式**：代理粗筛+物理复核的模式可平移到结构/热/电磁每个场——飞机设计实验室的能力核心应是"造代理"而非"买软件"
2. **场级代理（FNO/GNN）正在跨过实用门槛**：Stanford/达索/NASA 的 2026 工作都在收敛到"离散化无关架构"，2-3 年内进入工业软件
3. **多保真是中小团队的唯一可行路径**：纯高保真数据集的成本只有大厂负担得起，"低保真打底+高保真修正"是算力民主化的关键
4. **代理+形式化验证是装机认证的最后一公里**：与 Lean 笔记的交叉点——预测置信度数学化以后，代理才能进适航循环
