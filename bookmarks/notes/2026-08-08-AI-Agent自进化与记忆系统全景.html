记忆系统 write-manage-read 形式化

2026 年的关键理论进展（arXiv:2603.07670）将 Agent 记忆形式化为三步循环：

Write（写入）
  ├── 感知提取：从对话/行动中抽取信息
  ├── 编码：转化为可存储的表示（向量/图/文本）
  └── 存储：写入持久层（KV / 向量库 / 知识图谱）

Manage（管理）
  ├── 合并：去重+冲突解决
  ├── 遗忘：衰减/淘汰过时记忆
  ├── 巩固：高频访问记忆提升权重
  └── 重组：重新组织记忆结构

Read（读取）
  ├── 检索：语义/关键词/混合搜索
  ├── 排序：相关性+时间衰减+重要性加权
  └── 注入：将检索结果注入 Agent 上下文

这个模型解释了为什么 Mem0 能做到 91% 延迟降低——不是每条记忆都走完整 write-manage-read 循环，而是按重要性分层（热记忆直接在上下文，温记忆快速检索，冷记忆存档）。

归纳总结

统一进化框架确立：2025-2026 年，自进化 Agent 从零散论文走向统一理论框架——四组件模型（System Inputs / Agent System / Environment / Optimisers）覆盖了所有可进化维度（模型/提示词/记忆/工具/工作流）。

记忆系统成为核心赛道：Mem0 以 62K★ 确立生产标杆，但新项目不断涌现——TeleMem 用叙事提取超越 Mem0 19%，TencentDB 提供完全本地方案，Memvid 用 Rust 做到 0.025ms P50 延迟。选型核心权衡：准确率 vs 延迟 vs 隐私 vs 部署复杂度。

write-manage-read 形式化是理论突破：2026 年首次将 Agent 记忆形式化为统一循环，解释了分层存储为什么有效——热/温/冷记忆走不同深度的管理路径。

EvoClaw 暴露了自进化的残酷现实：连续进化设置下，Agent 性能从 >80% 暴跌至 ≤38%。单次进化≠持续进化——这是自进化 Agent 的最大挑战。

编码 Agent 赛道高度集中：Claude Code（140K★）+ Codex（104K★）+ OpenHands（83K★）三足鼎立，Pi 作为"自扩展 Agent Harness"代表新范式。

趋势判断

  • Agent 记忆从"功能"升级为"基础设施"：Mem0 62K★ vs LangChain 143K★——记忆系统 Star 数已接近 Agent 框架本身，说明社区认可记忆是 Agent 的独立基础设施层
  • 自进化从"研究概念"走向"工程实践"：Live-SWE-agent（运行时进化，77.4% SWE-bench）和 Ouroboros（24h 30+进化周期）证明自进化在工程上可行
  • 连续进化是下一个攻坚方向：EvoClaw 的 >80%→38% 性能悬崖是明确的 unsolved problem——Agent 能进化一次不代表能持续进化
  • MCP+A2A 双协议生态形成：MCP（工具连接）+ A2A（Agent 间通信）的互补协议正在标准化，A2A x402 甚至引入链上支付实现 Agent 商业化
  • 腾讯入局 Agent 记忆赛道：TencentDB Agent Memory（14K★）提供四级渐进存储的完全本地方案——对隐私敏感场景（金融/医疗）有重要价值

关联分析

  • 与 Hermes Agent Skill 系统的直接对标：Hermes 的 Skill+Memory 架构与 agent-skills（81K★）+ Mem0（62K★）是同一赛道。Hermes 的 evolver skill 对标 evolver（EvoMap，8.9K★）——都是"错误→规则→经验"的自进化引擎。但 Hermes 的是单 Agent 内循环，evolver 是独立进化引擎
  • 与用户 Agent 优化兴趣的关联：用户关注的 Agent Harness/Loop/FDE 架构对应 Pi（自扩展编码 Agent + Agent Harness，83.8K★）和 STELLA（自适应编排器）——说明 Agent Harness+自进化是 2026 年主流方向
  • 与量化选股 Agent 的关联：dynamic_pool_manager.py 的"每日刷新池+5天无信号移除"机制本质是 write-manage-read 记忆循环的一个实例——写入（涨停信号）→管理（去重+过期）→读取（选股参考）
  • 与 Memory Refiner 的关联：memory-refiner skill 对标 memU（24/7 主动 Agent 记忆）和 EverMemOS——都是跨会话/跨平台的持久记忆管理
