## 归纳总结

**一句话**：MuJoCo-UE 联合仿真插件把 MuJoCo 的物理调试能力（接触力/关节轴/肌腱）与 UE 的 PBR 渲染管线打通，核心是一套快捷键驱动的视口调试叠加层 + 与渲染捕获解耦的分割相机体系，直接服务 sim2real 的视觉数据生产。

**核心价值点**：
1. **物理调试叠加层**（键1-5）：接触力箭头、碰撞线框、关节轴+极限弧——把 MuJoCo 原生 viewer 的诊断能力搬进 UE，且箭头按法向力大小缩放。
2. **三种分割模式**（键6）：Island（约束岛）/实例分割（逐刚体 Halton 色调）/语义分割（逐铰链类）——像素级精确掩膜，直接喂视觉训练。
3. **肌腱可视化**（键7）：激活度 0-1 映射到管径（0.5×-2×）+ 颜色（深蓝→亮红），路径取自 `mjData.wrap_xpos` 真实运动学包裹点。
4. **关键设计决策**：视口叠加层与相机捕获模式**解耦**——SceneCapture 会拍到叠加材质，持续输出的 RGB/分割流必须走专用捕获模式，两者互不污染。

## 内容整理：快捷键与功能分层

### 1. 快捷键全景

| 键 | 功能 | 技术要点 |
|------|------|------|
| 1 | 接触力箭头 | 黄色箭头，大小按法向力缩放 |
| 2 | 铰链视觉网格可见性 | 隐藏视觉网格，保留碰撞/调试层 |
| 3 | 关节碰撞线框图 | 洋红色线框，逐碰撞几何体 |
| 4 | 关节轴 + 极限弧 | 彩色箭头指示轴线方向与当前/极限角度 |
| 5 | 快速转换碰撞线框 | 同3，针对 UMjQuickConvertComponent 道具 |
| 6 | 刚体着色器叠加 | Off→Island→实例分割→语义分割循环 |
| 7 | 肌腱/肌肉管状渲染 | 粗细+颜色跟踪肌肉激活 |
| P / R | 暂停 / 重置仿真 | 物理线程级 |
| O / F | 轨道相机切换 / 解雇 Impulse 参与者 | |
| Shift+F1 / Esc | 控制界面 / 退出 | |

### 2. 三种分割模式对比（键6）

| 模式 | 着色粒度 | 键控方式 | 用途 |
|------|---------|---------|------|
| **Island** | 约束岛（接触/关节/相等约束连通组） | 与 MuJoCo `engine_vis_visualize.c::addGeomGeoms` 一致 | 诊断约束传播、接触拓扑 |
| **实例分割** | 逐刚体 | Halton 键控 × 关节类哈希 × 刚体ID | 像素级掩膜 → 视觉训练数据 |
| **语义分割** | 逐铰链类（非实例） | BP_Humanoid 同类同色 | 类别级数据增广/场景理解 |

**睡眠模式调节**：`bModulateBySleep` 开启时睡眠物体 V×0.35、S×0.9（比上游 MuJoCo 略激进以适配 UE PBR 光照），Details 面板可实时调。

### 3. 肌腱渲染细节（键7）

| 信号 | 视觉编码 |
|------|---------|
| 肌肉激活 0-1 | 半径 0.5×→2×，颜色深蓝→亮红 |
| 限长肌腱（无肌肉） | 同款插值，由 `(ten_length - range_lo)/(range_hi - range_lo)` 驱动 |
| 中性肌腱 | 中等紫色，标称半径 |

- 路径来源：`mjData.wrap_xpos / wrap_obj / ten_wrapadr / ten_wrapnum`（运动学后真实包裹切点）
- 实现：`USplineMeshComponent` 变形 `/Engine/BasicShapes/Cylinder`（初始半径 50cm，scale = radius_cm/50）
- 逐段独立 `UMaterialInstanceDynamic` → 同一肢体两块肌肉颜色截然可分
- 无物理/无碰撞/无阴影/视口不可选，惰性创建+复用，肌腱减少时隐藏不销毁

### 4. 相机交互已知问题（关键陷阱）

> 键6 叠加层**替换真实材质** → 任何 `USceneCaptureComponent2D` / `UMjCamera` / 截图工具都会拍到叠加层而非底层场景。

**正确做法**：持续 RGB/深度/分割输出走**每摄像机捕获模式**（InstanceSegmentation / Real），与键6视口状态无关；若必须同屏调试+捕获，先按 6 到 Off 再开捕获。

### 5. 跨版本兼容实现

- 着色器：每个网格一个 `UMaterialInstanceDynamic`，父级 `/Engine/BasicShapes/BasicShape_Material`，BeginPlay 探测 Color/BaseColor/Tint 矢量参数取第一个匹配——**零 .uasset 依赖**，跨 UE 版本兼容。

## 趋势判断

1. **「物理引擎 + 游戏引擎」分工协作正在标准化**：MuJoCo 管物理精度、UE/Unity 管渲染与数据生成，单一引擎全包（Isaac Sim）之外的轻量组合路线在开源社区升温。
2. **分割标签成为 sim2real 基础设施**：仿真自带像素级掩膜 + 域随机化 = 视觉策略预训练标配，UE 生态把这类能力做进插件层说明需求已从论文走向工程。
3. **调试可视化向「叠加层架构」收敛**：视口叠加层与数据捕获通道解耦、材质参数探测替代硬编码资源依赖——跨版本兼容的工程手法值得所有仿真工具链借鉴。
4. 对具身智能训练成本的影响：UE PBR 渲染真值分割免标注，训练数据成本从「标注驱动」降到「渲染驱动」，与我们的「训练分布=验收分布」思路（E31d 考试化）同构。

## 指南分析

**操作要点速查**（拿即用）：
1. 调接触异常 → 键1（力箭头）+ 键3（碰撞线框），箭头大小即法向力
2. 调关节顶限位 → 键4（轴+极限弧），当前角 vs 极限角一屏可比
3. 查看约束传播/接触拓扑 → 键6 切 Island 模式
4. 产分割训练数据 → **不要用键6**，改用每摄像机捕获模式（InstanceSegmentation/Real）
5. 调肌腱传动策略 → 键7 看激活-颜色-管径实时联动
6. 捕获 RGB 前若开过键6 → 必须按 6 循环到 Off 再捕获
7. 睡眠物体不显眼 → Details 面板调 SleepValueScale / SleepSaturationScale
8. 扁平弦线外观（贴近原生 MuJoCo）→ TendonArcSubdivisions 降为 0

**陷阱清单**：SceneCapture 污染（见上）、肌腱管初始 50cm 需 scale 换算、快速转换道具与普通道具线框键位不同（3 vs 5）。

## 拓展应用推荐

1. **microduck 视觉观测升级预研**：在现训 DUCK 变体上加 1 路 egocentric 相机观测，先用 MuJoCo 原生 rgb + segmentation 输出验证策略可收敛，再评估是否引入 UE 管线提保真度（对照实验：原生渲染 vs UE 渲染的 sim2real 迁移差）。
2. **真机调试对照工具**：pi5 联调时的接触冲击/限位顶死问题，可在仿真侧用键1/键4 复现同款工况做归因，形成「真机现象 → 仿真复现 → 可视化定位」闭环。
3. **DREAM/Sim2Real 数据流水线候选**：若启动「仿真渲染预训练 + 真机微调」路线，本插件（或同构方案）作为分割标签工厂，替代人工标注。
