归纳总结

Sebastian Raschka（《从零构建大模型》作者）为新书《Build a Reasoning Model (From Scratch)》录制了 8 集共 11 小时的免费配套视频课：以 Qwen3 0.6B 预训练底模为起点，用 PyTorch 逐行实现推理模型的完整技术栈——评测验证器 → 推理时扩展（采样/self-consistency/自我修正）→ GRPO 强化学习（RLVR）→ DeepSeek R1 蒸馏。这是目前少见的「0.6B 小模型上把推理模型全管线写一遍」的教学级实现，与 DeepSeek R1、GPT-5 Thinking 等大规模推理模型的开发路径同构。

一句话定位：不是概念科普课，是「跟着敲完 = 你亲手造过一个推理模型」的代码课，前置只要 Python + PyTorch。

关联分析

与库内笔记的互补关系：

  • 《2026-05-04-LLM对齐训练范式RLHF-DPO-GRPO-DAPO》是 GRPO/RLVR 的理论范式全景（4模型RLHF→1模型GRPO 演进），本课是其逐行实现版——理论笔记讲清「为什么」，本课演示「怎么写」。两篇对照阅读效果最佳。
  • 《2026-05-04-Hands-On-Modern-RL现代强化学习实战课程》(WalkingLabs) 是广度型课程（CartPole→DQN→PPO→RLHF→Agentic RL→VLM RL 全谱系），本课是深度型单管线（只做推理模型一件事做到底）。广度打基础、深度做透一个，二者不冲突。

与我们自身体系的映射（这是本课对我们最有价值的视角）：

课程模块 我们体系中的对应物 可互证点
ch03 验证器（抽取→归一化→等价检查） benchmark-selfreport-audit 六道滤网 / notes-eval-gate 确定性检查 「验证器即奖励」= 确定性门禁思想在 RL 里的应用；我们 eval 门禁与 RLVR reward 同构
ch06 GRPO 组内相对优势 duck RL 训练（PPO 系） 组相对优势 vs GAE：小 batch 下组内基线更稳，与机器人 RL 的经验互证
ch07 reward hacking / entropy 塌缩 rl-policy-diagnosis skill（站桩 reward-hack 防陷阱） LLM RL 与机器人 RL 的 reward hacking 形态不同（格式作弊 vs 姿态作弊）但诊断指标思想同源：entropy 监控+奖励曲线交叉
ch08 R1 蒸馏（teacher→student 监督训练） offline-policy-distillation skill（多教师策略合并单学生） 机器人策略蒸馏与 LLM 推理蒸馏同框架：teacher 生成数据 + student 交叉熵/行为克隆，on/off-policy 选择逻辑一致
ch04 推理时扩展（采样+投票） inference-time-scaling skill（Best-of-N、PRM 引导） 课程是 skill 的教学实现版；skill 里的 PRM 引导采样课程未覆盖（增量）

引擎类比（视频 1 的框架，值得吸收）：推理模型 = 引擎，agent harness = 让引擎能干活的机械。当前代 LLM 几乎全是推理模型或带推理模式 → 理解 agent 必先理解推理模型。这个「引擎/机械」二分与我们 agent-primitive-architecture（Agent 三原语）的分层视角可直接对话。

趋势判断

  1. 推理模型教学进入「从零实现」阶段：2025 年概念科普（什么是 CoT/test-time compute）→ 2026 年从零实现课（Raschka 11h、WalkingLabs 全谱系）。学习材料成熟度标志：能教人亲手造 = 技术已标准化。
  2. 0.6B 成为推理模型教学标准载体：小到 CPU/单卡可跑，大到完整复现 R1 路径（RLVR+蒸馏）。类比当年 nanoGPT之于 LLM 预训练教学的地位。
  3. RLVR+蒸馏双路线叙事定型：Raschka 用 8 集明确「训练时扩展（RL）vs 蒸馏（借力大模型）」两条独立路径收尾对比——这与 DeepSeek R1 论文结构同构，已成业界标准叙事框架。
  4. 验证器是新的护城河：课程把「验证器设计」单列一集且强调一器两用（评测+奖励）——可验证奖励的质量上限 = 推理模型的能力上限，验证器工程正在成为独立学科。

拓展应用推荐

  1. 验证器思想移植：ch03 的「答案抽取→归一化→等价检查」三段式可强化我们的 notes-eval-gate/benchmark-selfreport-audit——特别是「等价性检查」层（不是字符串相等，是语义等价）。
  2. 训练看板指标补全：ch07 的 entropy 塌缩监控 + clipped ratio 统计，可作为 duck RL 巡检脚本 (rl-policy-diagnosis) 的指标补丁候选——LLM RL 已验证这些指标对 reward hacking 的预警价值。
  3. 蒸馏 on/off-policy 选择框架：ch08 的蒸馏方式矩阵（soft/hard × on/off-policy）可作为 offline-policy-distillation skill 的决策树补全参考。
  4. 90 分钟 LinkedIn 概念版可作为给非技术人解释推理模型的现成素材源。
