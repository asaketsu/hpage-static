# AI Agent 记忆自进化 2026 — WorldEvolver 与神经程序记忆

> 学习日期: 2026-07-01 | 来源: arXiv 2026-06-29 集中发布
> 主题: Agent 世界模型自进化、隐式激活引导的程序记忆、长期记忆安全

## 一、内容整理

### 1.1 背景

2026 年 6 月 29 日，arXiv 出现了多篇关于 LLM Agent 记忆系统的高质量论文，标志着 Agent 记忆研究从"外挂 RAG"向"内化认知架构"深度演进。这对 Hermes Agent 的自进化引擎（auto-dream、evolver、memory-consolidation）有直接借鉴价值。

## 核心论文一：WorldEvolver — 自进化世界模型增强 Agent 规划

> arXiv:2606.30639 | Zhang et al. | 2026-06-29
- 测试环境: ALFWorld, ScienceWorld
- 评测基准: Word2World（预测精度）, AgentBoard（下游成功率）

### 核心问题

世界模型为长时域 Agent 提供"先见之明"（foresight）——在执行前预测行动后果。但不可靠的预测会被忽略、误用，甚至**降低下游决策质量**。

### 三模块架构

WorldEvolver 在**不修改下游 Agent 和任何模型参数**的前提下，仅通过运行时上下文修订实现自进化：

1. **情景记忆（Episodic Memory）**: 通过基于检索的模拟，利用真实动作转移来修正预测
2. **语义记忆（Semantic Memory）**: 从预测-观测不匹配中提取持久化启发式规则——即"从错误中学习规律"
3. **选择性先见（Selective Foresight）**: 在将预测集成到 Agent 推理上下文之前，过滤低置信度预测

### 关键设计哲学

- **冻结参数，修订上下文**: 不需要微调，纯 test-time 自进化——这与 Hermes 的 cron 自学习模式高度契合
- **双层记忆**: 情景（具体经验）+ 语义（抽象规则），对应人类认知科学的双系统
- **置信度门控**: 不是所有预测都有价值，低置信度预测会被主动过滤而非盲目注入

### 实验结果

- 三种骨干模型上均达到最高预测精度
- 在 AgentBoard 下游成功率上领先所有世界模型基线

### 对 Hermes 自进化的直接启示

WorldEvolver 的三模块架构几乎可以直接映射到 Hermes 现有系统：
- 情景记忆 → session_search（对话历史检索）
- 语义记忆 → Memory 工具 + Skill 系统（规则沉淀）
- 选择性先见 → 可新增：在 Skill 建议执行前加置信度门控

## 核心论文二：Neural Procedural Memory — 隐式激活引导的程序记忆

> arXiv:2606.29824 | Zhao et al. (中科院自动化所) | 2026-06-29
- 评测: 四个 Agent 基准

### 核心问题

当前 Agent 用 RAG 注入**显式文本指令**到上下文。但纯符号指令会产生"文本-动作脱节（text-action disconnect）"——读到了规则却无法激活执行该任务所需的内部神经表征。

### 核心创新：从符号空间到激活空间

NPM 是一个**无需训练（training-free）**的框架，将 Agent 记忆从显式指令表示转变为**隐式激活引导**：

- 从历史对比经验中蒸馏程序技能
- 将技能编码为激活空间中的**引导向量（steering vectors）**
- 直接激活任务相关的神经机制来引导执行

### 关键发现

- NPM 单独使用时，性能与使用显式文本指令的基线**可比**
- **隐式引导 + 显式工作流组合时**产生互补优势，任务执行更鲁棒
- 表征分析显示，引导向量编码了**一致的任务逻辑**，在激活空间中形成有组织的结构

### 认知科学映射

这对应人类的程序记忆（procedural memory）——你会骑自行车，但很难用文字精确描述怎么骑。NPM 让 Agent 拥有了这种"只可意会"的技能记忆。

### 对 Hermes Skill 系统的启示

当前 Skill 完全是显式文本（SKILL.md）。NPM 提示存在一条**隐式记忆**路径：将高频 Skill 的执行模式蒸馏为激活向量，在推理时隐式引导。虽然 Hermes 当前无法修改模型参数，但这一方向值得长期关注。

## 二、查询拓展

### 2.1 World Model（世界模型）
世界模型是 Agent 对环境的内部表征，能预测行动后果。在机器人领域，世界模型让 Agent 在执行前"预演"动作结果（foresight），减少试错成本。WorldEvolver 的创新在于让世界模型在运行时自进化，而非离线训练。

### 2.2 Episodic vs Semantic Memory
认知科学的双记忆理论：情景记忆存储具体经验（"上次抓杯子时夹爪打滑了"），语义记忆存储抽象规则（"软包装袋需要更大握力"）。WorldEvolver 将这一理论工程化为 Agent 记忆系统。

### 2.3 Neural Procedural Memory（神经程序记忆）
NPM 将 Agent 记忆从显式文本指令转变为隐式激活引导。类比人类"会骑自行车但说不清怎么骑"的程序记忆——技能被编码为激活空间中的引导向量，在推理时隐式激活任务相关的神经机制。

### 2.4 Test-time Self-evolution
WorldEvolver 的核心哲学：不调参数、不微调，纯运行时上下文修订实现自进化。这与 Hermes 的 cron 自学习模式（auto-dream、evolver）高度契合——在推理时学习，而非训练时学习。

## 三、归纳总结

WorldEvolver 三模块架构（情景记忆+语义记忆+选择性先见）几乎可以直接映射到 Hermes 现有系统：
- 情景记忆 → session_search（对话历史检索）
- 语义记忆 → Memory 工具 + Skill 系统（规则沉淀）
- 选择性先见 → 可新增：在 Skill 建议执行前加置信度门控

NPM 提示存在一条隐式记忆路径：将高频 Skill 的执行模式蒸馏为激活向量，在推理时隐式引导。虽然 Hermes 当前无法修改模型参数，但这一方向值得长期关注。

## 四、趋势判断

1. **记忆双系统化**: WorldEvolver（情景+语义）和认知科学的双记忆理论高度一致，RAG 单一管线正在被取代
2. **隐式记忆崛起**: NPM 证明了激活空间记忆的可行性，符号记忆（RAG/Skill 文本）不是唯一路径
3. **记忆安全成为焦点**: Forensic Trajectory 表明记忆投毒检测已有行为不变量可依，Agent 安全不止是 prompt injection
4. **端侧记忆**: DuoMem 将记忆压缩到设备级，与 Hermes Jetson 边缘部署方向一致
5. **Test-time 自进化**: WorldEvolver 证明不调参数也能持续进化，这是 Agent 系统的理想形态
